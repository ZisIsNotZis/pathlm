# M · 状态载体

- **原语**：II（沿序列推进） × 记忆
- **命题**：跨步信息存在哪里、怎么压。

## 定义

载体决定「能否丢、能否重算、能否检索」。KV cache 只是众多载体之一；
载体选择直接决定部署内存与保留能力。

## 子维度

M1 载体类型 · M2 载体压缩

## 本地总体结论

本地有 KV 载体（+ eviction 压缩）与**显式记忆槽的旁路写入通道**（M1 ticket 35
首验，但跨种子未稳健）；递归状态 / 外部存储 / 权重载体仍零经验——这是
「右移压缩」主线的落点。
