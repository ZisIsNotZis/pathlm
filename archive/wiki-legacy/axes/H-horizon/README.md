# H · 视界（一次前向产生几个位置）

- **原语**：II（沿序列推进） × 头
- **命题**：一次前向预测几个未来位置、这些位置在训练时被什么内容填充、输出如何组合与验证。

## 定义

MTP 族。本轴的核心不是「质量」（满深度与半栈答案的差距仅 0.0003），
而是成本：草稿从哪来、接受率多高、验证多贵。

## 子维度

H1 每步输出位置数 · H2 训练内容填充 · H3 组合方式 ·
H4 头与主干关系 · H5 验证机制

## 本地总体结论

税效比全项目最好的一条：n_mtp 1→2 税 +0.041、2→3 +0.0166（递减），
换 Medusa 批量验证 1.68–1.90× tok/s @13M；@100M 墙钟塌到约 1.0–1.35×。
算力账须用解析比 R=(1+γ)/(1+τ)：R≈1.07–1.27（两规模都 >1）⇒ spec 是
算力亏损，买到的是顺序前向次数（tokens/forward≈2.4），不是算力；
「只剩 FLOPs 口径」是把墙钟前向比 `c_wall` 当算力比的符号错误（与宽度配对，非算力）；
正确性门禁上 100M enwik8 k=2 有 gap 0.0079 的平局翻转（级联 68 token，两轮复现）
⇒ 逐位相等不是跨规模判据。
否证：朴素概率复合是
数学错误（CE 3.96 vs 1.58）；条件链 deploy 0.547 < direct 0.560
（草稿质量瓶颈，~31% 草稿错误）；consistency loss 中性。
冻结主干只训头（H4）实测 @100M 零税 → 最便宜的真空白。
