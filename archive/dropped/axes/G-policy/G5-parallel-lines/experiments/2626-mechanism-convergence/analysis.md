## 0. 人话摘要（先看这段）

**我们在追的问题**：上一波（X1）发现，「让同一主干的多条随机路径的隐状态彼此不相关」（表征级去相关，
λ=0.1）在 13M 上**真的起作用**——8 路集成比无去相关臂好 **0.0246 bpc**、还几乎不花钱。但那只是
**6000 步的快照**：判据量还在快速移动（每 1000 步掉 0.06）。**这一波把同一配置跑到 24000 步
（4 倍训练量），问：机制熬不熬得过收敛？**

**测出来三句话**：

1. **机制熬过了收敛，但停在门槛线上。** 24k 终点「无去相关臂的 8 路集成」比「λ=0.1 臂的 8 路集成」
   差 **+0.0144 bpc**（配对置信区间 [−0.0158, −0.0130]，不含 0）——按方法论 **Δ<0.014 不可排序**，
   这里 **0.0144 只是刚刚越过门槛**，算「**保持**」但**幅度收窄到阈值本身**（X1 快照是 +0.0246）。
   四点轨迹：@6k **−0.0063（反转）** → @12k **+0.0147** → @18k **+0.0150** → @24k **+0.0144**
   ⇒ 机制**在 12k 之后稳定在 0.0145 附近**，不再增长也不再消失。
2. **但多线（8 倍推理）仍然打不赢单线。** 主判据 24k 终点 **+0.0346 bpc**（CI [0.0298, 0.0407]，
   不含 0 且为正）⇒ 8 路集成比同 token 预算、同 seed 的**单线 stock 仍差 0.0346**，还要花 8× 推理。
   缺口四点：@6k **0.1102** → @12k **0.0554** → @18k **0.0406** → @24k **0.0346**。
3. **判据量这次基本收敛了。** 主判据缺口末窗（18k→24k）斜率 **−0.001/1k**（X1 的 6k 窗口是
   **−0.060/1k**，速率降了约 **60×**）；机制净效应末窗斜率 **−0.0001/1k**（几乎是平的）。

> **一句话**：**「表征级去相关」这个机制是真的、且熬过了收敛（净效应 0.0144 ≥ 0.014）；但它买到的那点
> 集成增益远不够补上「单主干多路径 vs 单线」这个部署缺口（还差 0.0346，且 8× 算力）——而那个缺口这次
> 几乎收敛了，不是「没练够」。**

> **名词就地解释**：**bpc** = 每字符比特数（越低越好）；**K 路径集成** = 采 K 条随机路径、把各自下一词
> 概率平均后再打分（K=8 = 8 倍前向算力）；**成对 JS** = 两条路径预测分布的 Jensen-Shannon 距离（bits），
> **越大 = 两条线越不相关**；**clean 税** = 为机制在单线质量上付出的 bpc 代价；**λ（w_repr_decorr）**
> = 表征去相关罚则的权重；**收敛** = 判据量随训练不再明显移动。

## 0.1 六问（`AGENTS.md` 汇报纪律）

1. **它是干什么的**：让一个共享主干在训练时学会「随手丢层」的多条随机路径，**并让这些路径的
   隐状态彼此不相关**，好在推理时把多路预测平均、拿到比单线更准的结果。
2. **相对普通的 decoder-only transformer 改了什么**：**结构完全不变**（13M：d256/12L/8H/T512，
   **13,076,483** 参数，三臂逐位相同）。改动只在**计算路径与损失**：`l1` 每步按 `p_skip=0.1` 随机丢层；
   `repr01` 再每步多采一条并行路径，对两条路径 **trunk 隐状态**做跨路 Pearson 相关罚则
   （`w_repr_decorr`=0.1）。**参数量增量 = 0**（构造性事实，对账机检）。
3. **为什么要改**：集成增益只来自成员**误差不相关**；共享主干成员天然相关 ⇒ 要么贵 N× 独立训练，
   要么显式付钱买多样性。X1 已证「表征级罚则在 13M 真去相关」，本波问它**能不能熬过收敛**。
4. **怎么测的**：**三臂单因素阶梯**（`stock → l1 → repr01`），同一评测流（enwik8 val 后 10M，
   训练从不碰），指标 = **K 路径集成 clean bpc**（K=1/2/4/8）＋**成对 JS** ＋**确定性路径对照**；
   口径 = **matched-step 快照**（各 393.2M tokens、同 lr、同 seed、同一条 24000 步 cosine 调度），
   显著性 = 60 批**配对** bootstrap 95% CI。**不用 oracle、不与真值比**。
5. **测出来多少**：见 §1/§3；一句话——机制净效应 24k 终点 **+0.0144（保持，CI 不含 0）**，
   主判据 **+0.0346（仍不成立）**；四点轨迹见 §1。
6. **结论与下一步**：**采纳**「表征级去相关（λ=0.1）在 13M 的净效应能熬过收敛，但它本身就停在
   0.014 的可排序门槛上」；**不采纳**「多线（8× 推理）在 13M 打得赢单线」。未测项见 §10
   （50M 的 0.0322 缺口**不被本实验覆盖**；λ 更小是否更稳；独立初始化成员）。

## 4. 判据逐条判读（对应 `README.md` §4）

### 4.1 主判据（部署问题）——**仍不成立**

- 预登记形式 `bpc_repr01@K8 − bpc_stock@K1`：**+0.0346**（配对 CI [0.0298, 0.0407]，不含 0 且为正）。
- 代数对账：任务形式 = `−reading_B(l1@K1, stock@K1, repr01@K8).reduced`，`run.py` 断言一致。
- **算力价签**：`repr01@K8` = **8× 前向/token**，`stock@K1` = **1×** ⇒ **多花 8 倍推理，bpc 还差 0.0346。**
- K 曲线单调逼近而**未穿过**单线（**单点只描述形状，不外推 K→∞**）。

### 4.2 机制判据（本实验一号问题）——**保持，但贴门槛**

- 预登记三态：24k 终点 **+0.0144 ≥ 0.014 ⇒ 保持**；配对 CI [−0.0158, −0.0130] 不含 0。
- **幅度诚实读数**：0.0144 只比 0.014 的可排序门槛高 **0.0004**（≈3%），且四点里最低值就是它 ⇒
  结论应表述为「**机制净效应熬过收敛、稳定在门槛线上**」，而**不是**「机制显著更强」。
- 配套成对 JS：`repr01` **0.0237** > `l1` **0.0223** bits（仍更不相关，但差距仅 0.0014 bits，
  X1 同口径快照是 0.0112 bits）⇒ 去相关的**强度**在收敛尺度上大幅收窄。
- **两列分量（`§17.17`）**：机制整体税（`l1−stock`@K1）= **+0.0790**（battery 口径 1.4306 vs 1.3479 =
  +0.0827）；而去相关对单线质量的增量（`repr01−l1`@K1）= **−0.0112**（battery 1.4169 vs 1.4306 =
  **−0.0137**，即去相关臂单线**反而略好**）⇒ 净效应为正**不是**「税被吃掉的假象」，是「集成增益
  （+0.0032）＋几乎免费的税」共同结果。

- **但仍是快照口径**：24k 终点主判据缺口 **+0.0346 > 0**，且**禁外推** ⇒ 不据此外推它是否最终翻负。
