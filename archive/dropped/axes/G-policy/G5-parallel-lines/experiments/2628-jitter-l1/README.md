## 0. 一句话

2627（ticket 44-X1）把 `repr01` 臂重跑一遍，测出机制净效应 `l1@K8 − repr01@K8` 的 run-to-run
极差 **0.0035**，据此把「机制熬过收敛」升格为「稳健」。但 `l1@K8` 是 **2626 的固定读数**
（没有重跑）⇒ 那个极差只含 `repr01` 臂自身抖动，是净效应抖动的**下界**。本实验把 **`l1` 臂也
同配置同 24k 再跑一遍**，用**两臂合并极差**（`repr01` 的 0.0035 与 `l1` 臂抖动**取大**）复核
「稳健」结论，并把口径从下界升为**两臂完整口径**。

## 1. 命题（可证伪）

**同配置、同 24k 步、同 seed=0 的两次 `l1` 训练，其 `l1@K8` 读数差有多大？把 `l1` 臂自身抖动
与 `repr01` 臂抖动（0.0035）合并（取大）后，机制净效应「稳健」的结论还站得住吗？**
按预登记阈值（§4）把 2627 的「稳健」结论定为 **维持稳健 / 仍贴门槛 / 降级不可排序**。

## 2. 干预与单因素声明（精确表述）

**唯一变量 = `l1` 臂的训练随机性（多跑一遍）**：`l1` 臂的配置、seed、步数、评测协议**全部不变**。

| 臂 | 来源 | 说明 |
|---|---|---|
| `l1_A` | 2626 | 路径机制基准 run A（`p_skip=0.1, w_repr_decorr=0`）——2627 里的固定被减数，本实验要重跑它 |
| `l1_B` | 2628 | 路径机制基准 run B——**同配置、同 24k、同 seed=0 重跑**（本实验唯一新训练） |
| `repr01_A` | 2626 | 去相关臂 run A（λ=0.1），2627 已有 |
| `repr01_B` | 2627 | 去相关臂 run B（λ=0.1），2627 已有 |

- `2628/configs13m/l1.json` 与 `2626/configs13m/l1.json` **逐字节相同**
  （sha256 `284b102f…`），由单测 `tests/test_jitter_l1.py::test_l1_config_byte_identical_to_v2`
  钉死；变异 M1 抓红且逐字节还原。**没有新增开关、没有改模型/损失/调度**。
- `l1` 臂是**对照臂**（`w_repr_decorr=0`）：无去相关罚则、无额外并行前向 ⇒ `intervention.alive=False`、
  `extra_forward_per_step=0`，这是**预期**（不是「未激活的开关」）。参数量 **13,076,483**，与
  `repr01` 臂逐位相同（去相关是纯损失项）。
- **规模配方**：13M = `d256/12L/8H/T512/mlp×6`，`bs32 × 24000 步` = 每臂 **393.2M tokens**，
  同 lr（1e-3）、同 seed（0）。
- **评测协议**：与 2627 逐字段相同——60-batch probe（`seed=11`、`bs=32`、K∈{1,8}）+ 200-batch battery；
  评测函数 `tools/evalkit/ensemble_probe.path_ensemble_bpc`，本入口用 `probe_tts.bpc_k` 做同一性自检。

## 4. 判据线（预登记，跑之前写下，跑完不得改）

### 4.1 一号问题（抖动判决，**primary**）

> 记 `l1` 臂两次读数 `l1_A@K8`、`l1_B@K8`，其**极差** `l1_jitter = |l1_B@K8 − l1_A@K8|`；
> `repr01` 臂两次读数的极差 `repr01_jitter = |repr01_B@K8 − repr01_A@K8|`（2627 已测 = 0.0035，
> 本轮重测复算）。**两臂合并极差 `combined_range = max(l1_jitter, repr01_jitter)`**（取大）。
> 按 **V2 效应本身 `effect = 0.0144`** 判三态：
> 1. **`combined_range ≥ 0.0144`（效应本身）⇒ 机制结论降级回「不可排序」**（写进账本）；
> 2. **`combined_range < 0.005`（≪ 效应）⇒ 维持「稳健」**，并把口径从**下界**升为
>    **两臂完整口径**（写进账本）；
> 3. 其余 ⇒ **仍贴门槛 / 未决**（抖动可观但未到吞掉效应）。

- **基准是谁**：`l1_A` 臂（同 2626 曲线、同 24k 步、同 seed 的单路径机制模型）。
- **代价项相对谁算**：`repr01@K1 − l1@K1`，与基准**同一口径**。
- **primary**：本判据是 primary；主判据（多线 vs 单线缺口）不在本实验范围内（V2 已判 +0.0346 不成立）。
- **算力账**：`l1@K8` 与 `repr01@K8` 都是 8× 前向/token；四个读数的**算力相同**，故抖动是纯训练抖动。

**并列披露（非 primary，避免「取大」掩盖对抗性配对）**：

1. **最坏情形加和** `worst_case_additive_range = l1_jitter + repr01_jitter`（净效应 = 两被减数之差，
   两个极端同时出现的上界）；
2. **四组合极差** `combos_range = max(净效应四组合) − min(...)`（恒等于两臂之和，由 `run.py` 落盘）。
   **判决只用 §4.1 的 `combined_range`（取大）**；两列并列值如实报出，若二者跨过不同阈值，须写明。

### 4.2 §17.17 分量分解（净和不可排序时**必给**）

> 净效应 = **集成增益（K1−K8）− clean 税（vs `l1_A@K1`）**。分别报 `repr01_A`、`repr01_B` 两 run 的
> `clean_tax = repr01@K1 − l1_A@K1` 与 `ensemble_gain = repr01@K1 − repr01@K8`，并给两者之差；
> 据此区分「机制无用」与「机制有效但代价抵消」。

### 4.3 必报项

1. **跨运行复现**：本轮重评 `l1_A`/`repr01_A`（2626）与 `repr01_B`（2627）应与既有记录
   （K8 1.4089 / 1.3945 / 1.3910；K1 1.4389 / 1.4277 / 1.4237）**逐位相同**
   （评测确定性；由 `run.py` 断言并入账）。
2. **配对 CI**：`l1_B − l1_A` 与 `repr01_B − repr01_A` 各自的 60 批配对 bootstrap 95% CI（`seed=21`）。
3. **200-batch battery**：四臂的 clean bpc 与两对差值（独立协议）。
4. **成对 JS**（K=8）四臂。
5. **确定性路径对照**：`l1_B` 强制 `p_skip=0`，增益应恰好 0 且 K 条路径 logits 逐位相同。
6. **活性量每 200 步**（`gnorm`/`n_paths`/`skip_frac`/`repr_decorr`）与 `gate_skips`（须为 0）。
7. **收敛门禁（§17.15）**：落在决定判据的量上——两次 `l1` 读数都在**共享的 24k 末点**直接测；
   并报两 run 的训练总 CE 末窗斜率（**并报**，不得代替判据量口径）。

### 4.4 口径与禁令

- **口径**：matched-step **快照**（每 run 24000 步、同一 24k cosine 调度、同 seed=0）；
  K 曲线用 **60-batch probe 协议**（与 13M 锚点同函数同 seed）。
- **禁外推（§17.11）**：两次读数只给出**本配置、本规模、本调度**下的抖动；**不得**外推到其他 seed、
  其他规模、其他任务。**只报极差，不报置信区间外推**（n=2 无法估分布）。
- **口径事实（升格后）**：本实验**重跑 `l1` 臂** ⇒ 合并极差**同时含两臂**自身抖动，
  不再是 2627 的**下界口径**（`repr01` 的 0.0035 + 本轮重测的 `l1` 臂抖动）。
- **仍不覆盖**：**50M 的 0.0322 缺口**（§23 第 6 问的未测项）——本实验只做 13M；其他 seed 亦未测。
- **失败决策树**（结论可疑时按序排除）：① 测量（配对 CI/复现检查）→ ② 实现（`l1_B` 是否真是同配置、
  `gate_skips` 是否为 0）→ ③ 规模/收敛（两 run 是否同轨、CE 斜率是否接近）→
  ④ 随机性本身（CUDA 非确定性 ⇒ 该点抖动就是这么大）。

## 10. 既有做法（prior art，`SCHEMA §18`）

**检索条件**：本环境**联网检索不可用**（未注册 web / `web_search` 工具）。因此外部系统一律标 **`记忆·未核`**，
只作设计方向、**不得作判据**；本地条目标 `本地实测` 并给路径。完整分诊见
`axes/G-policy/PRIOR_ART_DECORRELATION.md`（ticket 37 知识线）。

1. **谁做过**：**run-to-run 方差 / seed 敏感性**是深度学习实验的通用议题；本环境典型先例如
   `记忆·未核`（如 "Deep Reinforcement Learning that Matters" 论 seed 方差），本地先例是
   `SCHEMA §17.18` 记录的 **ticket 41-Z3 事故**：同配置两次训练读数差 **15×** ⇒ 该腿降级为辅助腿
   （`本地实测`，`SCHEMA.md §17.18`）；紧随其后的本地先例是 **2627**：同配置重跑 `repr01` 一臂，
   极差 0.0035（`本地实测`，`2627-mechanism-jitter/analysis.md`）。
2. **为什么这么设计**：2627 已把「机制净效应是否稳健」的问题**缩到只剩 `l1` 臂自身抖动未测**——
   它把 `l1@K8` 固定复用 2626 读数，故 0.0035 是**下界**。要让「稳健」站得住，必须把**被减数**
   也重跑一遍，把口径补成**两臂完整口径**（2627 `analysis.md §10` 未测项 #1 原文）。
3. **它的实测结果**：本仓库**没有**「同配置同 24k 重跑 `l1`、估被减数抖动」的既有读数（`(c)`，
   联网不可用不能证伪其存在）；2627 自己把这条列为「未测项 #1」。
4. **我们的增量在哪**：
   - 把 2627 的**下界口径**补成**两臂完整口径**（`l1` 臂自身抖动直接测）；
   - **零新配置**（逐字节同配置）⇒ 抖动是纯随机性，不掺杂配方漂移；
   - 先做跨运行复现检查（重评 2626/2627 权重逐位相同）⇒ 抖动只来自训练、不含评测；
   - 给出「取大」primary 与「加和/四组合」并列两列，避免单一汇总口径掩盖对抗性配对。

## 11. 能力面 + 共享面分析（`SCHEMA §22` / `§22.8`，派发前已做）

**能力面**（`grep -n "ValueError\|互斥" pathlm/depth_ar.py`）：

- 所有互斥校验都在 **depth-AR 引擎**（`attn_sparse_k / train_window / attn_linear / n_kv_heads /
  carry_rule / topology` 两两互斥、block 类二选一）。**G5 多线机制不在该引擎里**——它走 loop-era
  引擎 `pathlm/model.py` + `train_m1.py`。
- 本实验要的组合：`p_skip=0.1`（既有）+ `w_repr_decorr=0`（**关**）。`sample_path` 对 `p_skip` 无互斥；
  `validate_pcap` 禁止 `w_diversity` 与 `w_repr_decorr` 同时开（本实验两个都是 0，不涉及）。
- **结论：所需组合在引擎里存在，无不可组合项；本线不改任何引擎文件。**

他人改动；变异脚本 `mutate.py` 的配置类变异写-读-还原并校验 sha256 逐字节相同，语义接缝用运行期
