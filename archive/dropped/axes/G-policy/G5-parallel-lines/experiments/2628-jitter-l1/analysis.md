## 0. 人话摘要（先看这段）

**我们在追的问题**：上一波（2627）发现「让共享主干的多条随机路径隐状态彼此不相关」（表征级去相关，λ=0.1）
在 13M 上真的起作用——8 路集成比不去相关的臂好 **0.0144 bpc**，而门槛是 0.014。2627 把 **`repr01` 臂
重跑一遍**，两次读数差 0.0035（只有效应的 1/4），于是把结论升格为「**稳健**」。**但那个估算有个缺口**：
被减数（`l1@K8`）用的是 2626 的老读数、**没重跑** ⇒ 0.0035 只是**下界**，真实抖动只会更大。
本轮把**基准臂（`l1`）也同配置同 24k 重跑一遍**，补齐两臂口径。

**测出来三句话**：

1. **基准臂自己重跑，读数差 0.0074 bpc——比去相关臂的抖动（0.0035）大一倍。** `l1_A@K8 = 1.4089`，
   本轮 `l1_B@K8 = 1.4163`，差 **0.0074**；而去相关臂两次差只有 **0.0035**。⇒ 抖动主要来自**基准臂**这一侧。
2. **两臂合并抖动（取大）= 0.0074，是效应本身（0.0144）的 51%。** 按跑前写死的规则（<0.005 才算「≪」，
   ≥0.0144 才算「被吞掉」），**落在中间** ⇒ 预登记判决 = **仍贴门槛 / 未决**。⇒ **2627 的「升格稳健」
   在补全两臂口径后不成立**：真实抖动有效应的一半那么大，「稳健」的说法撤回，回到「贴门槛 / 未决」。
3. **但机制本身没有消失。** 把两臂各自的两次读数做 2×2 组合，机制净效应 `l1@K8 − repr01@K8` 四次取值
   **都 ≥ 0.0144**（0.0144 / 0.0179 / 0.0218 / 0.0253），**没有一次跌破门槛**。⇒ 机制的好处是真的、
   且在所有观测组合里都为正；只是「比门槛高出的余量」**没有比抖动大**，所以不能说「稳健」。

> **一句话**：**去相关机制的好处在这个点上确实存在（所有组合都为正且 ≥ 门槛），但「稳健」这个词站不住**
> ——补全两臂口径后，抖动（0.0074）是效应（0.0144）的约 **一半**，按预登记规则，结论从 2627 的
> **「稳健」退回「仍贴门槛 / 未决」**。范围**只限 13M / seed=0 / enwik8**；50M 缺口未覆盖（禁外推）。

> **名词就地解释**：**bpc** = 每字符比特数（越低越好）；**K 路径集成** = 采 K 条随机路径、把各自下一词
> 概率平均后再打分（K=8 = 8 倍前向算力）；**机制净效应** = `l1@K8 − repr01@K8`（正 = 去了相关的臂集成更好）；
> **run-to-run 抖动** = 同配置同 seed 重训后读数的差异（本环境来自 CUDA 非确定性，非配方漂移）；
> **两臂合并极差** = 每臂各自两次读数的极差，取两者**较大者**（本实验 pre-registered primary）。

## 0.1 六问（`AGENTS.md` 汇报纪律）

1. **它是干什么的**：让一个共享主干在训练时学会「随手丢层」的多条随机路径，**并让这些路径的隐状态
   彼此不相关**，好在推理时把多路预测平均、拿到比单线更准的结果。本波只问：这个机制带来的那点好处，
   **在把基准臂也重跑一遍之后，还算不算「稳」**。
2. **相对普通的 decoder-only transformer 改了什么**：**结构完全不变**（13M：d256/12L/8H/T512，
   **13,076,483** 参数，四个检查点逐位相同）。改动只在**计算路径与损失**：每步按 `p_skip=0.1` 随机丢层；
   去相关臂再对两条路径的 trunk 隐状态做跨路 Pearson 相关罚则（`w_repr_decorr=0.1`）。**参数量增量 = 0**。
3. **为什么要改**：集成增益只来自成员**误差不相关**；共享主干成员天然相关 ⇒ 要么贵 N× 独立训练，
   要么显式付钱买多样性。V2/2627 已证「在 13M 上真去相关」；本波问这个结论的**抖动界**是否完整。
4. **怎么测的**：**同配置重跑基准臂**（`l1`，同 24k 步、同 seed=0、配置**逐字节相同**），与 V2 既有读数比，
   再与 2627 已测的去相关臂抖动合并（取大）；指标 = **两臂 @K8 的 run-to-run 极差**（+ 配对 CI +
   分量分解 + 复现检查 + 200 批独立协议）。口径 = matched-step 快照 / 60-batch probe / 与 13M 锚点同函数同 seed。
5. **测出来多少**：见 §1/§3；一句话——**基准臂抖动 0.0074、去相关臂抖动 0.0035、合并极差 0.0074（效应 51%）**
   ⇒ 预登记判决 **`on_threshold`（仍贴门槛 / 未决）**；四种组合的净效应 0.0144 / 0.0179 / 0.0218 / 0.0253 都 ≥ 门槛。
6. **结论与下一步**：**撤回** 2627 的「稳健」措辞（两臂口径下不成立），结论回到**「仍贴门槛 / 未决」**；
   **不覆盖**「50M 的 0.0322 缺口」「其他 seed」——未测项见 §10。

## 3. 一号问题：抖动判决（`results_13m.json::jitter`）

| 量 | run A | run B | 差 / 极差 |
|---|---|---|---|
| `l1@K8` | 1.4089 | **1.4163** | **0.0074**（本实验新增：基准臂自身抖动） |
| `repr01@K8` | 1.3945 | **1.3910** | **0.0035**（2627 已测，本轮重测复现） |
| 200-batch battery：`l1` | 1.4306 | 1.4367 | **+0.0061**（同向佐证） |
| 200-batch battery：`repr01` | 1.4169 | 1.4132 | **−0.0037**（同向佐证） |

- **两臂合并极差（取大，primary）= max(0.0074, 0.0035) = 0.0074**，是效应 0.0144 的 **51%**。
- **并列口径（非 primary）**：最坏情形加和 = 0.0074 + 0.0035 = **0.0109**；四组合极差同样 = **0.0109**
  （恒等于两臂之和）。两列都落在**同一个** `on_threshold` 带内 ⇒ **不出现跨阈值分歧**。
- **预登记判决（README §4）**：`0.005 ≤ combined_range = 0.0074 < 0.0144` ⇒ **`on_threshold`**
  （既不是「<0.005 维持稳健」，也不是「≥0.0144 降级不可排序」）⇒ **结论仍贴门槛 / 未决**。
- **净效应四组合**（`l1_{A,B}@K8 − repr01_{A,B}@K8`）：**0.0144 / 0.0179 / 0.0218 / 0.0253**，
  **全部 ≥ 门槛 0.0144** ⇒ 机制**没有消失**；补上 `l1_B` 之后净效应**只增不减**（被减数变大）。
  这说明：真实抖动**不会把净效应推回跌破门槛**（n=2 内），但「比门槛高出的余量」**不大于抖动**。
- **配对 CI**：`l1_B − l1_A = +0.0074`（CI [0.0061, 0.0088]）；`repr01_B − repr01_A = −0.0034`
  （CI [−0.0045, −0.0024]）。两次读数的差**统计上可见**，但幅度都落在 0.014 的不可排序带内。
- **禁外推（`§17.11`）**：以上只描述**本配置、本规模（13M）、seed=0、本任务**下的抖动；
  **不得**外推到其他 seed / 规模 / 任务。n=2 **不报分布外推**（不拟合、不给区间估计）。
- **口径事实（升格后）**：本实验**重跑 `l1` 臂** ⇒ 合并极差**同时含两臂**自身抖动，
  **不再是 2627 的下界口径**（那时 `l1@K8` 固定复用 2626）。

## 4. §17.17 分量分解（净效应的两列）

| 分量（相对 `l1_A@K1`） | `repr01_A` | `repr01_B` | 增量（B−A） |

| clean 税 `repr01@K1 − l1_A@K1` | **−0.0112** | **−0.0152** | **−0.0040** |

## 9. 口径与成本

- **训练**：单臂 `l1` 24000 步，墙钟 **16.8 min**，峰值显存 **2616.2 MB**（远 <5GB net）；
  按单臂整程持锁（单臂无法分片释放，§20.1），持锁期间后台心跳每 60s。
- **评测**：纯推理 **1.38 min**，取锁整程持锁（<15 min）；本进程净分配峰值 **692.4 MB**。
- **共享卡占用（§20.3，如实记账）**：跑前 `nvidia-smi memory.free` = **7206 MiB**（外部常驻 `llama-server`
  占用约 17 GB）、跑后 = **7595 MiB**；训练实测 **~42 ms/step**（16.8 min/24k，与 2626 `l1` 的 55.8 ms
  同量级）⇒ **未被显著拖慢，故不改步数**（保「同 24k」口径）。峰值 2616.2 MB < 5GB，未触礼貌线。
- **算力价签**：四个 `@K8` 读数都是 **8× 前向/token**；四次读数算力相同 ⇒ 抖动是纯训练抖动。

## 10. 未测项与下一步（显式，按价值排序，均给成本）

1. **50M 的 0.0322 缺口不被本实验覆盖**（`SCHEMA §23` 第 6 问）：本实验只做 13M；50M 的机制净效应
   抖动是否同样大**未测**。最小实验：50M `l1`/`repr01` 各跑到 ~48k 步，≈4–5 h（需与主 Agent 议预算）。
2. **其他 seed 未测**：本实验只做 seed=0。补 seed=1/2 的 `l1`/`repr01`（各 13M、24k）≈ 4×~20 min，
   可把「极差」升级为「跨 seed 标准差」，直接回答「抖动是否只是 seed=0 的偶然」。
3. **3+ 次重跑未做**：本实验每臂 n=2（极差口径）⇒ 无法估**分布**（禁外推）。要报标准差需 3+ 次重跑。
4. **抖动来源未定位**：`l1` 臂抖 0.0074 明显大于 `repr01` 臂 0.0035——是否与 2626 `l1` 的
   墙钟（22.3 min）明显慢于本轮（16.8 min）、或其 CUDA kernel 选择差异有关，**未测**。
5. **门槛风险（更新）**：机制结论现在**贴门槛且抖动占效应一半**——若要把结论从「未决」推回「稳健」，
   唯一路径是**多次重跑取分布**（见未测项 2/3）或**放大效应**（如 `w_repr_decorr` 调参）。
