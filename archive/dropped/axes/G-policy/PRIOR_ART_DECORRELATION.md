术语就地解释：
`去相关`（decorrelation）= 让多条预测线的**误差**彼此不相关，这样平均才能把误差抵消；
`深集成`（deep ensemble）= 独立初始化/训练多个完整模型再平均；
`N× 推理`= 集成 K 个模型就付 K 倍推理算力；
`成对 JS`= 两条线预测分布之间的 Jensen-Shannon 距离（bits），越大越不相关；
`税`（tax）= 为换来多样性而在**单线**质量上付的 bpc 代价；
`bpc`= 每字符比特数（越低越好）；
`ECE`= 置信度校准误差（越低越好）；
`trunk`= 多条线共享的主干网络。

## 0.1 人话摘要（先看这段）

**我们在追的问题是：想让一个模型「一次想出好几条不同的答案然后取平均」，有多条路可以
让这几条答案彼此不相似——除了「干脆训好几个模型」之外，还有别的便宜办法吗？**

本文把业界已知的「去相关来源」列成一张清单，量三件事：**它业界做透了吗、它有多贵、
它能不能不牺牲单线质量**。结论先给：

1. **「独立多模型（深集成）有效，但代价是 N 倍推理」——这已经可以当定论写结论，不实验。**
   它是目前唯一被反复确认有效的去相关来源，但贵在一个「乘法」：K 条线就是 K 倍推理算力。
   我们 G5 想找的正是它的**便宜替代**。
2. **便宜替代里，大部分（MC-dropout / 噪声注入 / 仅换数据序）业界也做透了，且公认比深集成弱。**
   ⇒ 写结论，不实验。
3. **唯一可能有真空白、也正是我们刚测过并判负的**：**在单模型、共享主干上用训练期罚则
   买去相关**。我们 50M 的结果是：罚则**没有买来去相关**（成对 JS 反而从 0.0333 掉到
   0.0250 bits），却让单线税从 13M 的 **−0.0086** 变成 50M 的 **+0.0710**（battery 口径）。
   业界有没有「多样性罚则导致表征同质化」的同类记录或理论？**本文第 3 节**给候选机制，
   但**必须标 `不确定` 并说明为什么现在判不了**。
4. **收口建议（第 5 节）**：**建议把 G5 当前路线收口**（两档规模判负 + 便宜替代已被业界判弱 +
   唯一真空白已在自己手上判负）。若上层坚持再花一笔预算，本文给**唯一一个**最小决定性实验
   （修掉 42.7% 的 gate 跳过混杂 + 换一个真正不同的去相关源），附预算与判据草案。

## 1. 去相关来源清单（六类，逐类四问 + 分诊）

> 分诊符号：**(a)** = 业界已做透 ⇒ 写结论、不实验；**(b)** = 真空白/设定实质不同 ⇒ 做实验；
> **(c)** = 查不到 ⇒ 记方向、不得据此判 (a)。**因联网不可用，本文凡 (a) 一律降级标注为
> `(a·记忆待核)`**——即「按记忆是 (a)，但联网时应复核」。这是 §21 的硬要求。

### 大类 A · 独立种子 / 独立训练（深集成）

| 项 | 内容 |
|---|---|
| **谁做过** | **Deep Ensembles**（Lakshminarayanan et al. 2017，`记忆·未核`）：独立初始化 + 独立数据序训多个模型再平均；**Fort et al. 2019**（`记忆·未核`）：把集成增益归因于「独立成员落在损失面的不同模式（mode）」；**Snapshot Ensembles**（Huang et al. 2017，`记忆·未核`）：单个训练轨迹取多个快照近似集成。 |
| **为什么这么设计** | 集成的误差只有在成员**误差不相关**时才被平均掉；共享主干/共享初始化的成员天然高度相关。独立成员的「独立」同时来自**初始化**与**数据序**两个来源。 |
| **实测结果** | 图像/分类/不确定度任务上**普遍有效**（`记忆·未核`，不引精确数字）；**成本是 N× 训练 + N× 推理**。**本地对照**：共享主干的多线集成增益仅 **+0.0008~+0.0015**（可忽略，`本地实测`，`.scratch/08-tts-probe/evidence`）——**它正是「不独立 ⇒ 不去相关 ⇒ 零增益」的反面证明**。 |
| **我们的增量** | 无。G5 想找的是它的**便宜替代**，不是复现深集成。 |
| **分诊** | **(a·记忆待核)** ⇒ **写结论、不实验**。 |

### 大类 B · 不同数据序（data order）

| 项 | 内容 |
|---|---|
| **谁做过** | 深集成内部就同时变数据序；单列「只换数据序」的工作较少被单独报告（`记忆·未核`）。相关：**数据顺序/课程学习**对损失面落点有影响（`记忆·未核`）。 |
| **为什么这么设计** | 若两个成员只看过同一数据的不同顺序，它们的误差可能仍然同源 ⇒ 只换顺序可能比只换初始化弱。 |
| **实测结果** | `不确定`：**「仅换数据序」是否比「仅换初始化」带来更多多样性，我记不准**。Fort et al. 的结论倾向「初始化是主驱动」（`记忆·未核`）。**本地未单独测**。 |
| **我们的增量** | 若做，增量应是「固定初始化、只换数据序」的**单因素**隔离——本地未做。 |
| **分诊** | **(c 倾向)**：查不到确切的单因素结论 ⇒ **不得据此判 (a)**；但它在我们的单因素阶梯里属于「不改变模型结构、只改输入顺序」的便宜选项，值得作为**备选源**在最小实验里一试。 |

### 大类 C · 不同深度 / 路径（depth / path）

| 项 | 内容 |
|---|---|
| **谁做过** | **Stochastic Depth**（Huang et al. 2016，`记忆·未核`）：训练期随机丢层作正则；**LayerSkip**（Meta 2024，`记忆·未核`）：早退出口；**MSDNet / BranchyNet**（`记忆·未核`）：多深度出口集成。**本地**：`p_skip=0.1` 随机丢层产生 K 条路径再平均（`本地实测`，`2620-*`）。 |
| **为什么这么设计** | 复用同一主干与同一份训练，不必训 N 个模型；推理时重采路径即得 K 条「便宜多线」。 |
| **实测结果** | **本地**：路径机制的**机制税随规模缩小 54%**（13M **+0.1748** → 50M **+0.0810**，battery，`本地实测`）——方向对；**但确定性路径集成恰好得 0**（`stock` 与评测期强制 `p_skip=0` 的 `divl1` 两次都是 0.0000，8 条路径 logits 逐位相同），**深度集成也失败**（早层是**严格更差**的估计器，不是「弱但可用的投票者」）(`本地实测`，`.scratch/08-tts-probe/evidence`)。 |
| **我们的增量** | 路径随机化**本身不制造足够去相关**（50M 上最好多线 K8 仍差单线 0.0223）。 |
| **分诊** | **路径/深度作为去相关源：业界有占位（stochastic depth / LayerSkip）(a·记忆待核)；但「50M 上共享主干多路径打不赢单线」是本地量化观察 (b 已判负)**。 |

### 大类 D · 正交化 / 多样性罚则（orthogonalization / diversity penalty）

| 项 | 内容 |
|---|---|
| **谁做过** | ① **Negative Correlation Learning**（Liu & Yao 1999，`记忆·未核`）：把成员间协方差写成罚则；② **Ensemble diversity 综述**（Brown et al. 2005，`记忆·未核`）：显式多样性度量与「多样性–准确率权衡」；③ **表征去冗余 / 白化**（**Barlow Twins** Zbontar et al. 2021；**VICReg** Bardes et al. 2022，`记忆·未核`）：对**特征**去相关，不是对输出分布；④ **DIAYN**（Eysenbach et al. 2019，`记忆·未核`，RL 技能多样性）——同类思想但在 RL。 |
| **为什么这么设计** | 直接对「想要的性质」（成员不相似）写损失，比靠独立初始化去「碰」更可控。 |
| **实测结果** | `不确定`：以上多在**分类/SSL/RL**、且多为「多样性作正则」语境；在**自回归语言模型 + 共享主干 + 输出分布 JS 罚则**下是否回本，**未见可直接对照的公开受控结果**。**本地**：capped-−JS + `w_diversity=0.05`（`本地实测`，`2620-*`）——**50M 判负**，见第 2/3 节。 |
| **我们的增量** | **换尺度（13M→50M）+ 单因素阶梯 + 基准写死 + 确定性对照 + 成对 JS 读数**，把「回本没有」变成可判定二元结论。这是本类唯一 (b)。 |
| **分诊** | **机制存在性是 (a·记忆待核)；「单模型共享主干 + 输出 JS 罚则」的具体形态 = (b)，且已被本地判负**。 |

### 大类 E · verifier 重排（best-of-n + verifier）

| 项 | 内容 |
|---|---|
| **谁做过** | **Best-of-n with verifier**（Cobbe et al. 2021 `记忆·未核`）；**奖励模型重排**（InstructGPT/RLHF 系，`记忆·未核`）；**Self-Consistency**（Wang et al. 2022，`记忆·未核`）：多样本 + 投票。**本地**：三信号正交监测栈（prob0 管对错 / 路径分歧 js 管语义 / distinct-2 管塌缩，`本地实测`，`.scratch/22-gen-quality/evidence`）。 |
| **为什么这么设计** | **不在生成侧买多样性，而在选择侧挑**：先廉价地采样出多样候选，再用判别器/投票挑最好的。这与「训练去相关」是**正交的**两条路。 |
| **实测结果** | 有强 verifier 时稳定增益（`记忆·未核`，不引数字）；代价 = n× 生成 + verifier。`不确定`：verifier 弱或分布外时增益会消失。**本地**：没有外部 verifier 对照，只有自评信号。 |
| **我们的增量** | 若做，增量是「用我们自己的三信号栈当 verifier 做重排」——但**这是 G1/G3 的题，不是 G5 的去相关题**；且 G5 已证多线本身不去相关（verifier 再好也无「多样候选」可挑）。 |
| **分诊** | **(a·记忆待核)** ⇒ 写结论、不实验（作为去相关源，它不是 G5 的空白；作为候选挑选器另属 G1/G3）。 |

### 大类 F · dropout / 噪声注入（noise injection）

| 项 | 内容 |
|---|---|
| **谁做过** | **MC Dropout**（Gal & Ghahramani 2016，`记忆·未核`）：推理期开 dropout 当近似贝叶斯集成；**Ovadia et al. 2019**（`记忆·未核`）在分布偏移下比较：**MC dropout 系统性弱于深集成**；**Noisy Student / 权重/激活加噪** 等（`记忆·未核`）。 |
| **为什么这么设计** | 用「训练时已存在的随机性」当免费的集成来源，零额外模型。 |
| **实测结果** | `不确定`确切数字；定性上业界共识倾向「便宜但更弱」（`记忆·未核`）。**本地**：dropout/噪声注入未单独作为去相关源测。 |
| **我们的增量** | 无。 |
| **分诊** | **(a·记忆待核)** ⇒ 写结论、不实验（它已被公认为深集成的弱近似，不是空白）。 |

## 2. 「深集成有效但 N× 推理」是否已是定论？

**本文的判定：就「有效性」与「成本形态」两点而言，可以当定论写结论、不实验；
但「N× 推理能否被某个便宜替代跨过」尚未定论，而那正是 G5 想回答的第二个问题。**

拆成三段，逐段给证据等级：

1. **「深集成有效」= 高置信的 `(a·记忆待核)`。** 独立性（初始化 + 数据序）带来误差去相关，
   平均降低方差 ⇒ 质量/不确定度普遍改善。**本地反面印证**：不独立（共享主干）时集成增益
   仅 **+0.0008~+0.0015**（`本地实测`，`.scratch/08-tts-probe/evidence`）——
   **「有效」的前提正是「独立」，这条在我们自己的数据上也成立**。
2. **「代价是 N× 推理」= 构造性事实，不需要实验。** K 个独立模型平均 = K 次前向/token，
   没有免费午餐；这正是我们 `2620-*` 里写进结论句的**算力价签**（`divl1@K8` = 8×，`stock` = 1×）。
3. **「便宜替代能否跨过 N×」= 未定论，且是我们唯一该投的地方。** 候选便宜替代
   （数据序/深度路径/dropout/噪声/训练罚则）逐一对照，业界各自的强度是 `记忆·未核` 的定性排序
   （大体：深集成 > MC-dropout ≈ 噪声 > 仅换数据序），**但在「共享主干 + 单因素受控 + 50M
   自回归 bpc」这一具体设定下，公开受控对照查不到**（联网不可用，不能证伪其存在 ⇒ 只能记 `(c)`，
   不得据此判 (a)）。**我们刚测的 capped-−JS 罚则 = 这一类的本地判负实例。**

> **一句话**：**「深集成有效但 N× 推理」= 写结论的 (a)；「有没有便宜替代」= 真问题，
> 且我们已有的唯一实测答案（训练罚则）是「没有」。**

**若可检索应查什么**：
`deep ensembles Lakshminarayanan 2017`, `Fort 2019 deep ensembles loss landscape mode`,
`can you trust your model uncertainty Ovadia 2019`, `MC dropout vs deep ensemble`,
`ensemble diversity Brown 2005`, `negative correlation learning Liu Yao`,
`Barlow Twins / VICReg redundancy reduction`, `snapshot ensembles Huang 2017`,
`conditional computation ensemble decorrelation`。

## 3. 解释我们的失败：多样性罚则为何让表征同质化？

**现象（本地实测，可回溯）**：

| 量 | `l1`（无罚则） | `divl1`（capped-−JS, w=0.05） | 走向 |
|---|---|---|---|
| 成对 JS（K=8，bits） | **0.0333** | **0.0250** | **罚则让线更像了** |
| 集成增益（K1−K8） | 0.0539 | 0.0385 | 随之下降 |
| 去相关税（battery，相对 `l1`） | — | 13M **−0.0086** / 50M **+0.0710** | 由负转正 |

来源：`axes/G-policy/G5-parallel-lines/experiments/2620-decorrelation-at-scale/results.json`
（`pairwise_js_at_kmax`：`l1 mean_bits=0.033320`、`divl1 mean_bits=0.025044`；
`criteria.taxes` 与 `battery_clean_bpc`：`divl1−l1 = 1.5897−1.5187 = 0.0710`）。

**本文能给的解释分三层，诚实标级：**

1. **算术层的硬事实（确定，可核对）**：奖励项对损失的**直接贡献量级只有 `0.05 × JS ≈ 0.003` nats**，
   远小于实测的单线差 **+0.0710**（`2620-*` analysis §6 已写）。
   ⇒ **税不可能主要来自奖励项的标量大小**，只能来自**梯度路径**或**被跳过的步**。
2. **测量层的混杂（确定，已声明）**：`divl1` 的 pre-step grad-norm gate 在 12000 步里
   **跳掉 5121 步（42.7%）**，实际只约 6900 次更新（`results.json::intervention.gate_skips`，
   与 `n_diversity_observations=6879` 自洽）。⇒ **「税为何变贵」不能干净归因**，
   契约 §4.4 只排除到「测量/实现」，未排除「规模/设计」两类。
3. **机制层的候选理论（`不确定`，业界无直接前例可引）**：
   - **候选 1 · 共享主干 + 同 CE 目标的向心力**：两条路径共享 trunk、吃**同一个** next-token
     交叉熵目标 ⇒ 它们被同一个「预测真实下一个 token」的力拉向同一分布；一个 **0.05 权重的
     capped 罚则**在梯度上远弱于 CE，训练自然收敛到同质（训练侧 JS 轨迹从 step0 的
     **0.538247** 掉到末值 **0.020559**，均值 0.073716，`本地实测`）——
     **符合「罚则太弱、不足以对抗 CE 向心力」**。
   - **候选 2 · capped（截断）罚则的梯度空洞**：`min(JS, cap)` 在 `JS ≥ cap` 时梯度为 0；
     若训练早期 JS 常高于 cap，罚则时有时无；若低于 cap，罚则又弱。**截断本身可能让
     「去相关压力」的覆盖不连续**（`不确定`：本地未单独测 cap 的敏感性）。
   - **候选 3 · 罚则把两条线推向「彼此不同但各自更差」的分布**，方差上升超过偏差下降 ⇒
     净单线税为正——这是经典的**多样性–准确率权衡**（Brown 2005 一类，`记忆·未核`）；
     但**「罚则导致表征同质化」这个方向**（罚则反而让线更像）**在业界公开记录里我找不到
     直接对应**（`记忆·未核`）；α 侧有「**表示塌缩**（dimensional collapse）」的近亲
     记录：对比学习里若去冗余/正则设计不当，表征会塌缩到低维子空间
     （Jing et al. 2022，`记忆·未核`）——**这只是结构性类比，不能当作我们的直接证据**。

**结论与不确定声明**：

> **「多样性罚则导致表征同质化」在我们这里是一个实测现象（JS 0.0333→0.0250），
> 但「为什么会这样」目前只有候选机制，且被 42.7% 的 gate 跳过混杂，本文判 `不确定`。**
> 业界**没有**我能引用的同类「多样性罚则 ⇒ 成员更相似」的直接受控记录（`记忆·未核` +
> 联网不可用，不能排除其存在）。**排除了哪些别的解释**：排除了「奖励项标量太小」（算术层
> 已否），排除了「增益只是多算几次的平均假象」（确定性路径对照恰好 0.0000）；
> **未排除**「欠训练（42.7% 跳过）」「罚则形态（cap/权重）在 50M 不适配」「设计本身有害」三类。

**若可检索应查什么**：
`diversity regularization collapse ensemble`, `negative correlation learning degradation`,
`representation collapse contrastive learning Jing`, `ensemble agreement penalty self-defeating`,
`KL divergence diversity loss mode collapse`, `deep ensemble members converge same solution`。

## 4. 机器可读分诊表（`SCHEMA §21`）

```
A 独立种子/独立训练(深集成) | (a) | 独立性带来误差去相关、普遍有效，但代价 = N× 训练 + N× 推理 | 结论：有效性与 N× 成本形态已是定论，不实验。来源类型：业界结论（记忆·未核）+ 本地反面印证（共享主干增益 +0.0008~+0.0015）。
B 不同数据序               | (c) | 「仅换数据序 vs 仅换初始化」的单因素强弱查不到确切结论 | 记方向：作为便宜备选源，可在最小实验中一试；不得据此判 (a)。来源类型：记忆·未核。
C 不同深度/路径            | (a/部分 b) | stochastic depth / LayerSkip 等占位成熟；本地判负：50M 最好多线 K8 仍差单线 0.0223 | 结论：路径随机化的机制税随规模缩小 54%（+0.1748→+0.0810），但不足以翻盘。来源类型：业界（记忆·未核）+ 本地实测。
D 正交化/多样性罚则        | (a 机制 / b 具体形态) | NCL/Barlow-Twins 等机制存在；单主干+输出 JS 罚则形态本地判负（JS 0.0333→0.0250，税 −0.0086→+0.0710） | 结论（本地）：capped −JS 不是有效去相关源；成因不确定。来源类型：本地实测 + 记忆·未核。
E verifier 重排            | (a) | best-of-n + verifier / 奖励模型重排 / 自一致 均有成熟占位 | 结论：作为去相关源不属 G5 空白（另属 G1/G3 的挑选器题）；不实验。来源类型：业界结论（记忆·未核）+ 本地三信号栈复核。
F dropout/噪声注入         | (a) | MC dropout 作近似集成、公认弱于深集成 | 结论：写结论、不实验。来源类型：业界结论（记忆·未核）。
```

**分诊要点**：六类中**五类判 (a)**（写结论、不实验）；**真空白只剩一个**——即
**D 类在「单模型 + 共享主干 + 输出分布罚则」这一具体形态**，而它**已经被我们 13M/50M 两档判负**。
⇒ **G5 当前路线没有「待补的关键对照」，只剩「是否换一个去相关源」的开放问题。**

**但按 `SCHEMA §23`「预算内极致」，必须把「未测项显式化成下一步最小实验」**——见下。

### 5.2 若继续：**唯一一个**最小决定性实验（只做这一个，做完无论正负都收口）

**为什么是它**：当前失败里**唯一没排除、且不换赛道就能排除**的混杂，是
**42.7% 的 gate 跳过**（欠训练）**+ 罚则形态**。把这两个一起修掉、并换一个**真正不同的
去相关源**，就能一次性判定「D 类是不可救的 / 还是只是我们这一版没调好」。

| 项 | 设计 |
|---|---|
| **命题** | 在**无 gate 跳过**（或把 gate 跳过率压到 <5%）且用**表征级去相关**（而非输出 JS）时，单主干多路径能否做到 **成对 JS 显著 > `l1` 的 0.0333** 且 **去相关税 ≤ 集成增益**。 |
| **干预（相对 `l1` 只改一处）** | 把 `w_diversity` 的输出 JS 罚则替换为**隐藏态去冗余**（Barlow-Twins/VICReg 式：对两条路径的 `h` 做**非对角协方差惩罚**），权重 1 档（先测活性再定值）；**同时**移除/放宽 `gnorm>1e4` gate（或改为仅 nan/inf 保护），使有效更新步数 = 总步数。 |
| **对照** | 三臂单因素阶梯：`stock`（阶梯底）/ `l1`（路径机制）/ `divl1_v2`（表征去相关）。同 seed、同 token 预算（沿用 98.3M tokens 口径）。 |
| **判据草案（预登记，Δ 符号统一为 `Δ = bpc_对照 − bpc_实验`，正=改善）** | **主判据**：`bpc_divl1_v2@K1 − bpc_l1@K1 ≤ 0.014`（税在方差界内，即「几乎不付单线税」）**且** 成对 JS(`divl1_v2`) **> 0.0333**（真的更不相关）。**并列**：`bpc_l1@K1 − bpc_divl1_v2@K8 > 0` 且配对 CI 不含 0（集成净收益翻正）。**必报**：机制税、去相关税两套口径分开；活性量每 200 步（JS/skip_frac/gnorm/有效步数）；确定性路径对照（应恰好 0）。**基准** = `l1`（同路径机制），**代价项**与基准同口径（`SCHEMA §17.14`）。 |
| **预算** | 沿用 `2620-*` 实测步时：`stock/l1` ≈ 8.8/8.3 min，`divl1` 双路径 ≈ 12.8 min ⇒ **训练 ≈ 30 min + 评测 ≈ 5 min + 冒烟 ≈ 2 min ≈ 40 min**；取整给 **`gpu_wall_budget: 60 min`**（含等锁余量）。峰值显存：`divl1` 双图实测 **5610 MB**（超 ≤5GB 纪律，需按契约记账或降 bs）。 |
| **取证与并发** | 需 GPU ⇒ 取锁、按 `SCHEMA §20.1` **按臂释放/重取**（留 ≥60s 窗口）；单测覆盖「只在声明键上不同」；`reconcile_numbers.py` 逐字段对账。 |
| **否证路径（失败决策树）** | ① 测量（probe 协议与 13M 同方法）→ ② 实现（表征罚则活性/无 gate 跳过）→ ③ 规模（是否仍欠训练）→ ④ 设计（表征级去相关也无效 ⇒ **正式收口**）。 |

> **若实验超预算或判据不可兼得**：按 `SCHEMA §8` **停下向主 Agent 裁决**，
