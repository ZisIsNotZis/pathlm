# CRITIQUE — R2-distillation（独立批判审计，fork=false）

## ① 是什么
用更大的模型教小模型（logit/中间层/数据蒸馏），作为"小模型质量来源"的现成答案；本格登记它作为"同参数等智商"的竞争参照线。

## ② 对着什么 sota，我们偏离在哪
业界标准（Hinton 2015 / DistilBERT / TinyBERT / MiniLLM，`记忆·未核`）：蒸馏是小模型的标准来源，常优于同尺寸从头训练。我们**零本地实验**、**零可核实出处**（`axes/R-references/PRIOR_ART.md` 明写"本环境未注册任何 web 工具"）。

## ③ 五类问题逐条判定
- **开倒车：无**（本来也不该复现业界）。
- **过程错误：有（制度层）。** `axes/R-references/PRIOR_ART.md` §2 把 R2 判 **(a)「业界已研究透 ⇒ 不跑实验」**，而同一文件 §0 自述"无法在线核证"。这违反 `SCHEMA.md §21`（`(a)` 只能由可核实出处支撑；检索不可用 ⇒ 只能记 `(c)` 待核）——与 2026-10-02 已对 A/W/C 若干格执行的 **C14 更正**（`docs/REMEDIATION.md:60`）自相矛盾。
- **结论错误：n/a**（无本地数字）。但 `catalog.yaml:1221–1228` 的 `industry` 写"与本项目『同参数等智商』命题直接竞争"——**无可执行判据**：判据写的是"小模型质量 vs 训练成本"，而本项目没有 teacher。
- **无意义：是。** 蒸馏改变的是"小模型从哪来"，而本项目把来源固定为 enwik8 自训；无论蒸馏多好，都不改变"某条算力路径值不值"的判断（正好落在 `AGENTS.md` 编排模式的删除判据上）。单卡 4090 + 13M 尺度也没有可用的 teacher。
- **值得做：否。**
