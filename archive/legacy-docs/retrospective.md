## 1. 起点：回环时代的设计冻结（2026-09-14/15）

**原始 idea**：常规 LLM 解码是"每 token 一次全栈前向"的串行均匀计算，低效。设想改为
**概率驱动的碎片化精细算力分配**——利用 MTP 头给出的已校准概率（prob0），让模型按
位置置信决定每个 token 花多少算力：低置信位置回环重入多过几遍（retry）、层路径可以
打乱重排（shuffle/skip/redo）、输入可以损坏训练以获得修复能力（corruption），
用"权重复用 + 回环"换 token 吞吐。

**冻结架构**（`docs/design.md`，commit `8a4d1b5`）：stage ring 0–4（多 token 并行预测
骨架）、每 round 独立采样层路径、聚合原则、训练配方。数据与尺度定案：char 级 enwik8、
13M（d=256/12L）起步、RTX 4090 单卡包络（commit `f1c6edb`）。

**当时的核心命题**：低置信位置的每 FLOP 收益更高；均匀分配是浪费。这条命题后来
获证（ticket 14 选择性实验），但"用哪种机制去分配"的答案出人意料。

## 2. 引擎迭代期：回环族的系统性探索（ticket 01–14，2026-09-14~16）

### M0 微型探针（ticket 02，~1M 参数，commit `1b60f2b`/`27418ae`）

四判据三过一败：prob0 校准 PASS（ECE 0.004–0.011）、集成 ≥ 最佳单路径 PASS（边际
+0.0008~+0.0015）、consistency loss 收紧估计 PASS（cosine 0.9525→0.9882）、
**直接传输 retry FAIL（结构性 no-op）**。最后一个负结果是全项目第一条铁律的起点：
**retry 若不改变状态，信息量为零**——12 层深栈一次重入不是固定点（M1 修正了这一
外推），但"无传输的重入无价值"贯穿始终。

### M1 主引擎与首轮 run（ticket 03–05，13M，commit `e38349f`/`480d50b`）

B0 锚点 **1.5074 bpc**（公开数字范围内，外部锚成立）。七个 run 五过两败：
损坏修复真实（I1 wrong-token 52.8%）、retry 精炼真实（C1 +2.1pp，r1→r3 单调）、
早退真实（L2 深度 6 平台、1.4× 解码）；**token retry 未门控 FAIL**（R1 −4.6pp，
量化掉不确定性——failure mode 反过来设计了门控）、**needle 召回 FAIL**（信号饥饿，
每 needle batch 只有 1 个监督 token）。补充轮（ticket 05）：mixture 重入消除 token
灾难（C5 −1.3pp vs R1 −4.6pp）、retry 曲线 ~r3 饱和、X2v2 needle 重设计 PASS
（窗口内 84.9%）。

### M2 广度扫描：元素税定律（ticket 06，commit `a03a579`）

第一批"跨机制的一般规律"：**破坏 identity/order 结构的元素贵**（shuffle +0.545、
skip +0.175、wrong-token +0.127），**保留或 flag identity 的近乎免费**（mask +0.059、
noise ±0、redo +0.044）。shuffle 的硬边界：locality 0.5 训练容忍 eval ≤0.5、全随机
崩到 3.84。这条定律后来在深度自适应形态上以 +0.44 的形态税再次应验。

### 机制补全与组合律（ticket 07–09，commit `7b47555`/`aa97bcf`/`39b1838`）

- 距离惩罚免费（X1 **−0.007**，唯一改善 clean bpc 的元素）且修好锚通道（76.8%→93.3%）。
- **TTS 探针判死质量叙事**（ticket 08）：组合增益 ∝ 路径多样性（L1 −0.047）、
  确定性路径 checkpoint 集成恰得 0、**没有任何组合打赢 B0**——元素税吞掉集成收益。
  这直接改写了项目卖点：不卖质量，卖可控性。
- M3 组合律（ticket 09）：**shuffle 是组合毒药**（一切含 shuffle 组合落 2.2+ bpc、
  与修复拮抗 repair 51%→38%）；唯一真组合增益是共享修复机器的次可加（IX1 +0.087
  < 0.277 之和）；多样性必须练进去（DIVL1 同时改善 baseline 与斜率 −0.062 > −0.047）。

### 有效性大清理：混杂排除的范式（ticket 10–12，commit `57d64a7`/`d6a9898`/`216a00a`）

这是方法论上最重要的阶段。ticket 11 用四缺陷审计**撤回了整个 retry 矩阵的排序结论**：
6 个 latent cell 跨度仅 0.011 bpc，而单格种子散布 0.0138 已超全部跨度；D2 config
混杂（漏 `n_mtp` 虚高税值）、D1 重入 gauge（direct/linear mixture 测到的是 ~30×
rescale 而非 latent mean）、D3 未训练 accumulator、D4 方差。**保留下来的可靠结论**：
retry 税本身可靠（+0.146…+0.178）；门控价值在修复侧；**所有已发布税是 1.1-epoch
上界**（D5：+0.364@1k → +0.122@24k，~3k 起平台）。ticket 12 夜间研究补上因果确认
（修复 gauge 后 mixture r2 单调 2.71→1.936，pre-fix 发散到 95.2——爆炸是 gauge 不是
机制）与条件链裁决（oracle 0.682 ≈ node1、deploy 0.547 < direct 0.560——草稿质量
瓶颈，部署不采纳）。INT2 集成（**+0.309 次可加 < ~0.58 之和**，损坏输入 **−1.79 bpc
vs B0**）与 29M 规模探针（税 +0.174 不缩、E2E 差距收窄系基线不那么脆）收尾。

### 四实验与采纳账本（ticket 13–14，commit `9abc181`/`9954425`）

- **逐位置 latent 门控证伪**：direct 重入是固定点，`torch.where` 无可切换；状态掩码
  不省算力，收益需稀疏 gather/scatter——此路不通。
- **needle×损坏三路豁免全败**（anchor 召回 0.764→0.016/0.033/0.035，任务级豁免还把
  clean bpc 1.680→1.997）：容错训练与精确复制目标冲突。用户随后裁决"无需模式信号"
  （目标恒为正确 token）。
- **n_mtp=3 + Medusa 批量验证 POSITIVE**：**1.68–1.90× 实测 tok/s，税仅 +0.0166**，
  独立复现——全项目唯一"税小收益大"的机制。
- **分配选择性获证**（ticket 14，3 checkpoint 交叉验证）：按 prob0 只对最低 15% 位置
  开第二轮，INT2 的 r1→r2 从 −0.0193（有害）翻到 **+0.0211**（有益）、C1M
  +0.0570→**+0.1284**（2.2 倍）——愿景核心命题成立。附带发现：**dense-exit 监督摧毁重试精炼**
  （ALLOC 各桶全负）——这是后来"整形 vs 自适应"定律的第一次露头。

**阶段末的 mindset**：回环族机制被系统性探索完毕，采纳账本定稿（report §3.8）。
当时认为终极形态 = spec + 门控 retry + 损坏 + 驱逐 + 早退的组合。

## 3. 第一次转向：规模判读改写机制价值（ticket 15–22，2026-09-17~18）

### Slider 端到端（Rung 3，ticket 15，commit `257b6ec`）

分配器四件套在 13M 建成并验证：校准（fire 曲线 split gap ≤ 0.004）→ 双货币成本模型
（a2 部署口径校准后预测误差全线 ≤ ±13%）→ 求解器 → 验证解码；**严格占优点复现**
（corrupt 下 k=1 τ=0.98 = **0.635 fwd/tok @ 2.0502 bpc**，vs plain 1.0 @ 2.0545——
少 37% forwards 且 bpc 更好）；在线质量代理 TF 窗口
ECE 0.0011–0.0079。诚实的负结果：**自由生成段 prob0 劣化检测反向**（当时判"吸引子
混淆"，后被 ticket 22 证伪为 n=1 假象）。

### Rung 4：100M 定案（ticket 16–17，commit `c520d65`/`25704b8`）

- **税首次不随规模增长**：13M +0.147 → 29M +0.174 → **100M +0.126**（2 seeds 配对
  +0.118/+0.134）。
- **能力溢价持续**：损坏输入下 B0 崩至 3.551（r2 反而 4.18——无机制二次 pass 更脆），
  机制模型 2.015→1.949，**E2E 差距 ≥1.54 bpc**；prob0 校准存活（ECE ≤0.0091）。
- Slider 全链在同一 100M 权重上自洽（成本预测 ≤11.1%、spec 严格占优复现 0.566
  fwd/tok）；**但门控重试质量杠杆在 100M 消失**（τ 轴平坦 ±0.002）——第一个
  "机制价值随规模自衰减"信号。

### exit×retry 定律与渐近口径（ticket 18/19/21，commit `83bf1ac`/`8401b5e`/`9fe4cf1`）

- **整形 vs 自适应是同一梯度的两面**（ticket 18，100M 复测更锐利 ticket 21）：probe
  式头（trunk stop-grad）保 retry（−0.0098）但 exit 质量贵（depth 6 +0.93）；dense
  整形 exit 轴好（+0.199）但杀 retry（+0.0146）。**两全证伪**，且剂量响应随规模变化：
  dense 0.2 在 13M 温和、100M corrupt 崩溃（+1.73）。自适应 profile（probe）是 100M
  明确赢家（税≈0、门控更强 −0.029）。
- **渐近口径定案**（ticket 19，4.4 epoch，2 seeds）：税 +0.126 → **+0.082**（收缩
  35%，曲线单调降）；**等训练口径 13M +0.122 → 100M +0.082——税真正随规模下降**，
  快照口径的"不缩"全是 1.1-epoch 上界。能力溢价随训练**扩大**（corrupt gap
  1.54 → 1.89，源口径 1.54（1.1ep）→ 1.89）。B0_asym 1.341 ≈ 13M 渐近 1.346：396M tokens 下参数增益饱和
  （data-limited）。

### spec 缩放判决（ticket 20，commit `a864bcf`）

接受级联规模稳定（a₂ 0.80、a₃|a₂ 0.767↑、2.4 tok/fwd 不变），但 100M 前向
compute-bound（宽度-3 成本 3.4–5.3× vs 13M 1.28×）——**spec 墙钟收益消失**
（k=2 仅 1.15–1.29×、k=1 转负）。fp 平局翻转首现（top-2 gap 0.008 处翻 argmax，
1/400 token）——"spec==greedy 逐位相等"是 13M 规模性质。

### 回环时代的收尾资产（ticket 22/22b，commit `c6c356f`/`25f5914`）

纯推理工作，与转向无因果但属同一时期：路径分歧度（同窗多路径 TF 重评分成对 JS）
是**真实但不完备**的生成段质量信号（AUC 0.66–0.69 > prob0 0.58–0.62；生成段 js
严格 real 0.0114 < corrupt 0.0250 < random 0.0390）；吸引子塌缩窗 js→0 盲区由
distinct-2 重复率补上（**AUC 0.9815**，人工标注）——三信号监测栈定形。混杂物排除：
ticket-15"13M prob0 反向"经 n=6 复刻**未复现**（系单 prompt 假象），账本修正。

**触发转向的判读**：三个杠杆在 100M 的成绩单——retry 质量杠杆自衰减（17）、
spec 墙钟收益消失（20）、exit×retry 不可两全（18/21）——合起来指向：**这套机制
在规模下的价值在质量与可控性，不在吞吐**。"回环换速度"的原始 idea 在部署口径上
已无路可走。

## 4. 第二次转向：目标重聚焦（2026-09-20，用户决策，commit `4280dec`）

用户明确重聚焦：**等参数、等智商、decode 选择性更快**。回环（重试/修复）方向作为
解码加速手段正式退役（证据：retry 三次加速失败 + 目标竞争实测），全部机制账本
（§1–§7 与 findings）保留为有效证据，架构哲学由 `docs/mental_model.md` §0 接管：

- 错误处理：损坏训练+重试修复（去噪骨架+AR 混合体）→ **纯 AR：预防 + 验证式重采**；
- 深度：固定 + 回环重入 → **渐进精化**（同空间逐层增强，深度可跳可退）；
- 速度两轴 = 深度自适应（早退/MoD）+ 自 spec（浅层草稿全栈验证）。

新形态：时钟沿提交（commit=采样→embed，唯一不可跳过）；训练 = 纯 AR + **全深度
并行监督** + **逐通道携带门**（h_{k+1}=h_k+g⊙Refine(h_k)）+ 随机退出深度；定稿
不变量 = 候选序列全深度重打分。**宽度约束**（workspace = d − 有效读出秩）作为
一等设计约束写入。触发证据在 §0 中明确归档：tickets 14–22。

## 5. 机制验证期：深度自适应 AR（ticket 23 系，2026-09-28）

### 23 首验：四性质成立，形态税判据证伪（commit `1586745`）

小模型（d=128/256，L=4/8，GPU 11.4 min）四性质：深度精化**成立**（曲线全单调，
B: 6.250→2.4161）、**宽度-workspace 假设成立**（d=256>V 时 null 空间 62 维、
26 条功能性读取；d=128<V 结构性 0——携带信息确被后续读取）、出口提交可用（半栈
TF 接受率 **0.9667**）、门行为健康（浅层开深层微开）。**但形态税 +0.6786 ≫ 0.05
判据线**。归因 ablation：监督稀释 +0.512 主因、混合填充扰动 +0.167 次因，代码 bug
以 14 个语义单测排除。意外发现：**soft 提交 OOD 污染 context**（rescore 6.9 vs
hard 1.2）——此后三度复现，成为贯穿性副发现。

### 23b–23d：税源定位的三轮混杂排除（commit `b8c9f86`/`88aa341`/`5d5a983`）

- **23b 监督加权 sweep 全败且单调反向**（w∈{1, 0.1, 0.02, 退火}，w 越低 depth-L
  越差 2.45→2.73）——归因改判：浅层全深度监督是**表示正则**而非稀释主因；
  carry 门乘性瓶颈/欠拟合升级为税主嫌。
- **23c 三消融因果分解**：欠拟合是主因（3.33× 训练把税 +0.713 → +0.121，收缩
  83%）；aux 非无罪（dense trunk 上即 +0.284）但其穿 trunk 的梯度是净收益
  （stop-grad 恶化至 2.7129、浅层门不再打开、tf@4 0.973→0.791）——浅头 stop-grad
  化排除。
- **23d 残税分解**：+0.121 = {dense 欠拟合 −0.209 + aux 残余 +0.108 + 门/填充固有
  +0.222}；matched-step 真税 @12k = +0.3295（较 3.6k 收缩 54%，未平台化）；100M
  外推 ≈ +0.21（区间 +0.15…0.23）——训练加长过不了 |税|<0.05，需配方级干预。

### 23e fill 变体对决（commit `6b27b5e`）

三分支同配置唯一变量 = KV 填充策略：**fill 1.8582 胜 ragged nofill 1.9438**
（+0.0856 ≫ ±0.03 平局带）——23 首验时"填充是负分量"的判断系欠拟合伪影+对照混淆
（当时 nofill 臂同时无随机退出），matched 步数下反转；可选 **proj-fill（逐层恒等
初始化 adapter）= 1.8356，全深度逐深度支配 fill，族内新最优**。

**阶段末的 mindset**：形态的机制地基（精化、workspace、出口、门）全部按设计工作；
剩下的问题是那个绕不开的税——它随规模怎么变？

## 6. 规模判决：形态税 @100M（ticket 24/24b，2026-09-28）

### 24 主判读与混杂声明（commit `7cdcdaa`）

同 token 预算（98.3M = 1.09 epoch）、24000 步、32 min：**税 +0.4563**（clean
1.9175 − B0_100M 1.4612）——高于 13M matched 同预算 +0.31，未过 +0.5 恶化线。
**形态税未随规模收缩、方向反向**——与 ticket-19"税随规模下降"（回环 retry 的
渐近口径）方向相反，判读混杂如实声明：对照 B0 系跨引擎 + 本 run 用 final 2× 配方，
规模/配方/引擎归属本轮不可分。机制侧全部存活且**出口资产变厚**：depth 曲线 13 格
单调（极端半栈平台 d6−d12=0.0003）、**tf@4 0.9726 / tf@6 0.9946**、墙钟实测
exit-4 **3.1×** / uniform-exit **1.8×**；门 100M 新形态 = 全层从 carry 初始化
0.119 收小（「渐进开门」未出现）；soft OOD 污染跨规模复现。

### 24b 拆混杂：干净归属（commit `7725891`）

## 7. 归因收口：税结构性存在（ticket 25，2026-09-29，commit `2e86924`）

用户提出两个候选机制，三臂 @100M 同引擎实验判决（判读表四格，落第 4 格）：

- **H-短视（B 臂：结构切分 readout 360/workspace 360）——否证且反向**：clean
  2.1475，税 +0.6863，恢复 **−50.4%**（负 = 恶化）。机制探针显示模型把状态能量
  **整体迁出读出空间**（切片能量占比 depth0 0.85 → depth2 0.026 → ≈0；null 能量
  100% 但 functional_dirs=176——workspace 被真用、读出空间被放弃），伴随门动力学
  反转（layer 3–11 p90=1.0）与深度曲线尾部倒退。还有一个副发现：tied 表不对称
  漂移（读出梯度只打 E[:, :360]，输入态能量比 0.85 vs 随机基线 0.50）——切分
  不但没把 workspace "还给"模型，反而把整个表示都挤出了被监督的子空间。
  **教训：涌现 workspace 优于结构强加切分**。
- **H-时长（C 臂：48k + 冷却退火）——否**：名义恢复 +16.4%（<50% 线）；同引擎
  48k 锚拆解后**形态特异收回 ≈ 0**——形态税 24k 锚 +0.4362 → 48k 锚 **+0.4372**
  （零收缩），C 对 A 的改善 0.0746 与 dense 侧训练收益 0.0756（1.4813→1.4057）
  **逐位镜像**——名义恢复全部是通用训练收益。
- **收口判决**：两干预（读出空间切分 / 2× 训练+冷却）均不能收回税，对照本身健康
  （dense-48k 1.4057 < B0 1.4612，纯 dense 2× 训练收益 −0.0555）——**税结构性
  存在，「等智商免费加速」正式证伪**。三臂全部先 20 步冒烟验证接线（B 验证切片
  生效、C 验证退火调度与公式逐点一致）再全跑；7 个新可失败单测含两组变异验证
  （切片忽略/调度退化均抓红），全套 129 绿。
- **交易终值**：+0.38~0.44 bpc 底座损失换 exit-4 ≈3.1× / uniform-exit ≈1.8× 墙钟、

  配方 = C（48k+冷却，等效验证吞吐 122.8 tok/s vs A 112.9，+9%）。**税只能被
  交易，不能被收。**

## 8. 最终结论与一般性教训

### 结论一：推理路径侵入必付结构性税（四个独立设计一致验证）

| 设计 | 侵入方式 | 代价 | 证据 |
|---|---|---|---|
| 回环 retry/corruption 族 | 重入 + 输入分布改变 | 税 +0.12~0.19（回环时代全账本） | tickets 04–19 |
| dense-exit 整形 | 浅层目标塑形 trunk | 杀 retry（两全证伪） | tickets 14/18/21 |
| 深度自适应 AR（全深度监督+携带门+填充） | 每层旁路精化 | **+0.44 bpc @100M，96% 干净归属** | tickets 23–24b |
| 读出结构切分 | 强加 readout/workspace 边界 | **恶化** +0.69（−50.4% 恢复） | ticket 25 |

四个独立设计、两个规模、同引擎对照，全部指向同一结论：**主干被改，税就来**。
元素税定律（M2）早已给出微观版本：shuffle +0.545、skip +0.175——连层执行顺序
都携带 ~0.5 bpc。

### 结论二：「等智商免费加速」不成立

形态税对「结构切分」（H-短视）与「2× 训练 + 冷却退火」（H-时长）两个干预都分文
不收回；13M→100M 斜率为正；4.4-epoch 渐近口径（回环时代）之外，深度自适应形态的
快照与 2× 训练两口径一致不收缩。唯一的正路是把侵入做成**旁路**：MTP/spec
（forwards 口径全程有效；墙钟收益是 launch-bound 现象）、probe 式早退（@100M
零税、门控更强）——**不动主干的判断头可以免费，动主干本体必付税**。

### 结论三：负结果与过程资产的价值

- **测量方法学**（贯穿 25 个 ticket 的护栏）：受益域先于测量；三列账本（税 | 收益 |
  各自货币）；双方差界（nondeterminism 0.0019 / 种子 ≤0.0138，Δ<0.014 不可排序）；
  所有已发布税标注口径（1.1-epoch 上界 vs 4.4-epoch 渐近 vs matched-step）；
  双货币记账（forwards vs FLOPs，结论会分歧必须双报）；冒烟 + 变异测试（每臂先
  20 步全电池再全跑；每个语义开关有可失败单测）。
- **混杂排除范式**：ticket 11 撤回整个矩阵排序（cell 跨度 < 种子散布）、24b 三臂
  拆混杂（形态/引擎/配方三列归属）、25 判读表四格（干预-恢复因果判决）——
  三个可复用的审计模板。
- **监测栈**：prob0（token 对错，ECE 0.001–0.011）+ 路径分歧度 js（语义分歧，
  塌缩域盲区）+ distinct-2 重复率（塌缩检测 AUC 0.9815）——三信号正交、零额外前向。
- **25 个 ticket 的完整证据链**：每个结论都有 run 目录、resolved config、对照与
  commit；索引见 `docs/artifacts.md`。

### 如果重来一次

1. 先测"选择性"再建机制（ticket 14 的实验其实可以放在 ticket 04 之前）；
2. 对照与实验臂**同引擎同配方**从第一天开始（24b 的三臂拆混杂本可省掉）；
3. 口径（快照/渐近/墙钟/FLOPs）在写契约时锁定，而不是在判读时补注；
4. n=1 的负结果必须复现后再入账本（13M prob0 反向的教训）。
