## 5. 失败路径与原因

1. 损坏 × 精确复制目标冲突（三路豁免全败）——「保住信息」与「容错修复」是互相抢容量的两个目标
2. 依赖曲线实测（ticket 31-I）：单距离曲线在 d≥32 上贡献 ≤0.004；但**累计不免费**——只保留最近 32/64/128/192 个位置分别 +0.212/+0.081/+0.020/+0.004 bpc（主 Agent ERRATA：单点曲线不得累加外推）
3. **窗口训练的直接检验（ticket 32-O，用户最初设想的判决）：不成立。** 训成「只看最近 32 + 8 锚点」：质量 1.4836 → 1.5701（税 **+0.0866**，6× 判据线，落在历史 X2 带内）；**依赖右移未测出**（d∈[8,32] 伤害差 +0.0008 预定口径 / +0.0133 工作点口径，均 <0.014）；**「信息被搬到近处」被否证**——窗口外的针召回 0.4588 vs 同掩码无记忆地板 0.4545（+0.004，等于没有记忆），而窗口内 0.6506 vs 0.4458（+0.205）⇒ **是「丢了」不是「搬了」**（X3 假保留陷阱的正面实例）。负结果同配置重跑复现（税 0.0821 / 判据② +0.0014 / 窗口外 gap −0.0046）
