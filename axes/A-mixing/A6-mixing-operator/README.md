## 5. 失败路径与原因

1. **成本实测量反方向**：整模型一步 24.34 → 54.02/54.76 ms（**2.22×/2.25× 慢**），进程峰值显存 1.47 → 2.55/2.57 GB（1.7×）；孤岛参考实现（真稀疏 gather）仍 1.63×/2.13× ⇒ 「T=256 净开销」是结论而非实现 bug
2. **质量也越界**：k=32 的 Δ 达 −0.0166（>0.014），k=64 仅落在噪声带内（−0.0095）；两臂 loss 斜率同方法可比（0.0025/0.0037/0.0031，极差 0.0012）⇒ 水平差不是收敛差
3. 交叉点只有公式外推（注意力占比 14.3%@256 → 72.7%@4096），**长 T 端未实测**；2× 训练点未做 ⇒ 限快照口径
4. **第四点同 step 第二快照（ticket 46-W2，3000→6000 步）**：Δ = +0.0044 → **+0.0042**（两快照都在带内）⇒ **「窗口不亏」在同 step（6000）的第二快照下保持**；**未排除**收敛解释——跨上下文绝对 loss 不可比、两臂末窗斜率仍 −0.16/1k（均未收敛）、token 预算 49.15M vs 98.30M 不同。仍：n=1、四点属混合口径、禁外推
5. **第四点 T=2048（ticket 45-L1，`qk-normfrom512`）**：Δ2048 = **+0.004361**（带内）⇒ 四点形状 **更差 → 更差 → 不亏 → 不亏**；稳定性前置通过（full@2048 gnorm_max **7.22**、跳步 0）。**重要限制（执行者自报）**：四点**收敛度不等**（T=2048 是 3000 步快照、loss 1.54，而 T=1024 是 6000 步、loss 1.21）⇒ 「窗口代价随 T 消失」**不得**读作同收敛/渐近结论（该读法**已由 `2636`（52-A6U）统一口径并判为**在本 n 下不可判定**，见本列表 52-A6U 条）；窗口臂峰值 **5.91 GiB** 超 5GB 礼貌线（按 §20.2 记账、保持 bs8 以维持四点可比）；注意力占比实测 0.1696/0.2914 vs 公式 0.5714；窗口墙钟仍不省（r_time 1.06–1.27）
6. **修复后的干净三点（ticket 43-V1，全部启用长度条件档 `qk-normfrom512`；六臂 49.15M token/臂半预算快照）**：**稳定性前置通过**（full@1024 `gnorm_max` **7.25** <100、跳步 0 ⇒ 三点可信），形状 = **窗口更差 → 窗口更差 → 不亏**（Δbpc = **−0.015752 / −0.015101 / +0.009264**，band 0.014）；⇒ （旧读法「**窗口代价随 T 增大而消失**」**已由 `2636`（52-A6U）统一口径：在本 n 下不可判定**，见本列表末 52-A6U 条；本条只作历史快照）。但窗口在当前实装下**墙钟无稳定收益**（r_time 1.07–1.19；稠密 bool 掩码不兑现 FLOPs 节省）；注意力占比实测远低于公式（已如实标注）。限制：n=1、半预算与旧点（98.3M）**不可比**、T=512 仅超带 8%（贴边）、禁外推
7. **长 T 崩溃已定位并修复（ticket 42-W1）**：元凶 = **第 1 层注意力 logits 无界增长**（带探针训练：L1 logits RMS 从 step200 的 0.60 单调涨到 step6800 的 **86.1**，其余层早已平台；炸掉的模型该量达 1.9e5/3.6e5、注意力塌缩成一点（top1 0.95/0.97、熵 0.10/0.07 nats），并留下永久疤：`blocks.1.qkv` 权重范数 **109.5/131.5** vs 健康臂 16.4–25.2）。**修复 = QK-Norm**（逐头 L2 归一 q/k，**零新增参数**）：把 logits 钉在 ±√32≈5.66 ⇒ 两 seed `gnorm_max` **1740.9→7.25 / 29578.6→7.58**、跳步 0/0，末态 clean bpc 从 1.5104/1.6064（差 0.096）变为 **1.5432/1.5437（差 0.0005）**。**诚实限制**：全局 QK-Norm 会波及短 T（T=512 Δbpc=+0.0314 越界、T=256=+0.0103 带内）⇒ 推荐**长度条件档 `qk-normfrom512`**（T≤512 零 hook，T=512 实测 Δ=−0.0016）。另发现本任务训练**非 run-to-run 逐位可复现**（同配方重跑 max|Δloss|=0.032）⇒ 预登记的逐位口径不可用，已改用「结构性零 hook + Δbpc」并交底
8. **long-T 训练不稳定已确证（ticket 41-Z1，seed=1 双臂同配方复跑）**：`full` 臂 gnorm 爆炸**复现且更猛**（seed1 **29578.6** vs seed0 1740.9；跳步 3 次；爆炸点 ~step 6200 vs 9800；`win` 臂两 seed 均稳：7.35/7.66）⇒ 按预登记判据 R1/R2 成立，记「**long-T 训练不稳定**」为**工程债**，**T=1024 该点永久不可归因**（三点趋势照旧：更差@256 → 不亏@512 → 不可归因@1024；band 分类未事后改）。质量读数印证「是基线坏了不是窗口好了」：seed1 Δ=+0.102211 但基线 bpc 比 seed0 差 0.096 ⇒ Δ 涨的是基线坏掉的程度。n=2 仍禁外推；显存 1.915 GiB 未越线
9. **长 T 第三点 T=1024（ticket 40-Y2）**：Δ = **+0.023419**（>0.014 ⇒ 字面「更好」），但**判为不可归因**——基准 `full-1024` 臂自身不稳定（`gnorm_max=1740.92` vs win 臂 7.35；两臂 loss 到 ~step 9800 几乎逐点相同、之后 full 上冲）⇒ 三点形状记为 **更差 → 不亏 → 不可判**（band 分类照字面保留、未事后改判据）。实测注意力占比 5.41%@256 → 10.78%@512 → **28.29%@1024**（公式 14.29/25.0/40.0，实测偏低）；显存 1.915 GiB；**窗口墙钟两轮均更慢（1.71×/1.17×，方向一致），理论省 20% FLOPs 未兑现**；口径差异（本点 bs8 vs X3 的 bs32）已标注、n=1 禁外推。下一步（已排）：seed=1 双臂同配方重跑判「爆炸是否 seed 特异」
10. **长 T 首探（ticket 39-X3，T=256→512，扩绝对位置表 +0.94% 参数）**：**窗口算子在 T=512 首次进入「不亏」带**（Δ256 = −0.014836 带宽判「亏」、Δ512 = −0.008730 判「不亏」⇒ 记交叉点首个观测点）；但 raw Δ 两点**同号（都略负）**，两种读法都报、主口径=带宽分类；**n=1 单点、不外推**（§17.11/§17.16）。注意力占比**实测** 5.41%@256 → 10.78%@512（+1.99×）与修正后公式 14.29%→25.00%（+1.75×）趋势一致；峰值显存 2.697 GiB；**墙钟测不出方向**（两轮相反）且窗口走稠密 bool 掩码 ⇒ 理论省 12.5% 等效 FLOPs **未兑现**；§19 合成腿四臂全在 chance（enwik8 权重在分布外任务上不会回忆）⇒ **空结果、不能区分两臂**，如实报并列下一步
11. **线性注意力（ticket 33-R）：干预在当前实装下不可行**——三次尝试分别在 step 800/~500/400 停摆（faulthandler 栈落在 `loss.backward()`；停摆前 `den_min` 触 clamp 下限 1e-6、`phi_min` 触 0、gnorm 尖峰 5065.9 vs 基线 0.4–0.8）；5 次诊断二分（chunk 32/64/256 × eps × expandable_segments）全部跑完 ⇒ **非确定性运行时停摆**，不是确定性 bug。执行者拒绝削步数/换算子救场，如实记不可行
12. 线性注意力的**成本交叉点已实测**（理论与实测并报）：理论 MACs/token/层 131072 → 49664（分块 −62.1%）/ 16896（流式 −87.1%）、推理缓存 T=256 时 −93.6%；**实测整模型 ms/step 比值 2.58@256 → 2.35@512 → 1.74@1024 → 1.53@2048（2048 内未回本）**；注意力子层孤岛在 T=1024 首次反超（0.96×）、T=2048 为 0.68×；峰值显存 1.41–1.47×（涨）
