# A6-mixing-operator · 混合算子

> 轴：**A 序列混合机制** ｜ 状态：**✅ judged**

> **判读**：内容选择式 Top-K 稀疏注意力在 **T=256 上净亏**：质量越删越差（k=32 越界有害、k=64 只在噪声带内），成本**实测上升** 2.2×（慢且更占显存）——稀疏的收益要到长上下文才可能出现。

## 1. 命题

用什么算子合并被看见的信息（不改变可见集合，只改变合并方式与成本）。

## 2. 选项枚举（本格全部可能取值）

1. `softmax 注意力（本项目基底）`
2. `Top-K 稀疏注意力（内容选择式，NSA/MoBA 族）`
3. `线性注意力 / kernel 化`
4. `SSM / 递归扫描（Mamba/RWKV 族）`
5. `卷积（局部固定核）`
6. `池化（PoolFormer 式无参数混合）`
7. `MLP-Mixer（token 维全连接混合）`
8. `傅里叶 / 全局变换（FNet 族）`

## 3. 状态（我们做了什么 / 行业做了什么）

**本地已测**：理论：保留键数 −87.5%/−75%、注意力 FLOPs −43.75%/−37.5%（QKᵀ 因内容选择不可省）、整模型每 token FLOPs −6.25%/−5.36%、**KV 缓存 −0%**（结构性）

**行业口径**：长上下文吞吐上稀疏/线性/SSM 明显占优；短上下文质量上偏差不一，
混合架构（注意力 + SSM 层交替，Jamba/Zamba 式）成为主流折中。
**本地实测为其补上「T=256 时净亏」的下界**：稀疏算子必须先跨过注意力占比的交叉点。

## 4. 结论与数字

- **税**：k=32 Δ = **−0.0166**（越 0.014 界，配对 20/20 批同向，t=−7.7）；k=64 Δ = **−0.0095**（带内但配对可检出，16/20，t=−4.1）；基线 full 1.5304（同配置历史 1.5287 / 重跑 1.5279）；剂量单调（k 越小越差）
- **收益**：理论：保留键数 −87.5%/−75%、注意力 FLOPs −43.75%/−37.5%（QKᵀ 因内容选择不可省）、整模型每 token FLOPs −6.25%/−5.36%、**KV 缓存 −0%**（结构性）
- **判读**：内容选择式 Top-K 稀疏注意力在 **T=256 上净亏**：质量越删越差（k=32 越界有害、k=64 只在噪声带内），成本**实测上升** 2.2×（慢且更占显存）——稀疏的收益要到长上下文才可能出现。

## 5. 失败路径与原因

1. **成本实测量反方向**：整模型一步 24.34 → 54.02/54.76 ms（**2.22×/2.25× 慢**），进程峰值显存 1.47 → 2.55/2.57 GB（1.7×）；孤岛参考实现（真稀疏 gather）仍 1.63×/2.13× ⇒ 「T=256 净开销」是结论而非实现 bug
2. **质量也越界**：k=32 的 Δ 达 −0.0166（>0.014），k=64 仅落在噪声带内（−0.0095）；两臂 loss 斜率同方法可比（0.0025/0.0037/0.0031，极差 0.0012）⇒ 水平差不是收敛差
3. 交叉点只有公式外推（注意力占比 14.3%@256 → 72.7%@4096），**长 T 端未实测**；2× 训练点未做 ⇒ 限快照口径
4. **长 T 第三点 T=1024（ticket 40-Y2）**：Δ = **+0.023419**（>0.014 ⇒ 字面「更好」），但**判为不可归因**——基准 `full-1024` 臂自身不稳定（`gnorm_max=1740.92` vs win 臂 7.35；两臂 loss 到 ~step 9800 几乎逐点相同、之后 full 上冲）⇒ 三点形状记为 **更差 → 不亏 → 不可判**（band 分类照字面保留、未事后改判据）。实测注意力占比 5.41%@256 → 10.78%@512 → **28.29%@1024**（公式 14.29/25.0/40.0，实测偏低）；显存 1.915 GiB；**窗口墙钟两轮均更慢（1.71×/1.17×，方向一致），理论省 20% FLOPs 未兑现**；口径差异（本点 bs8 vs X3 的 bs32）已标注、n=1 禁外推。下一步（已排）：seed=1 双臂同配方重跑判「爆炸是否 seed 特异」
5. **长 T 首探（ticket 39-X3，T=256→512，扩绝对位置表 +0.94% 参数）**：**窗口算子在 T=512 首次进入「不亏」带**（Δ256 = −0.014836 带宽判「亏」、Δ512 = −0.008730 判「不亏」⇒ 记交叉点首个观测点）；但 raw Δ 两点**同号（都略负）**，两种读法都报、主口径=带宽分类；**n=1 单点、不外推**（§17.11/§17.16）。注意力占比**实测** 5.41%@256 → 10.78%@512（+1.99×）与修正后公式 14.29%→25.00%（+1.75×）趋势一致；峰值显存 2.697 GiB；**墙钟测不出方向**（两轮相反）且窗口走稠密 bool 掩码 ⇒ 理论省 12.5% 等效 FLOPs **未兑现**；§19 合成腿四臂全在 chance（enwik8 权重在分布外任务上不会回忆）⇒ **空结果、不能区分两臂**，如实报并列下一步
6. **线性注意力（ticket 33-R）：干预在当前实装下不可行**——三次尝试分别在 step 800/~500/400 停摆（faulthandler 栈落在 `loss.backward()`；停摆前 `den_min` 触 clamp 下限 1e-6、`phi_min` 触 0、gnorm 尖峰 5065.9 vs 基线 0.4–0.8）；5 次诊断二分（chunk 32/64/256 × eps × expandable_segments）全部跑完 ⇒ **非确定性运行时停摆**，不是确定性 bug。执行者拒绝削步数/换算子救场，如实记不可行
7. 线性注意力的**成本交叉点已实测**（理论与实测并报）：理论 MACs/token/层 131072 → 49664（分块 −62.1%）/ 16896（流式 −87.1%）、推理缓存 T=256 时 −93.6%；**实测整模型 ms/step 比值 2.58@256 → 2.35@512 → 1.74@1024 → 1.53@2048（2048 内未回本）**；注意力子层孤岛在 T=1024 首次反超（0.96×）、T=2048 为 0.68×；峰值显存 1.41–1.47×（涨）
