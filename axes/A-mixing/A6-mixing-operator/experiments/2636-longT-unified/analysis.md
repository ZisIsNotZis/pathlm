## 人话摘要（先看这段）

**要干什么。** A6 格此前有一条看着很漂亮的长上下文结论：「窗口（只看最近一半历史）的**质量代价
随序列长度 T 增大而消失**」——在 T=256/512 上窗口比全因果差约 0.015 bpc（越过了 0.014 噪声界），
到 T=1024/2048 就掉回噪声带内。审计（`.scratch/50-critical-audit/A-Audit.md`）指出这条结论**靠不住**：
四点里步数是 24000/12000/6000/3000 不等，而优化器的学习率调度以**步数**为分母（退火刻度不同），
而且 T=2048 那点还是「补到 6000 步」的混口径。本实验就是去统一这个口径：**把四点都放在同一个
步数（6000 步）下重跑**，再把「窗口到底省不省」用一次会话里测出来的**质量 / 解析 FLOPs / 实测墙钟 /
峰值显存**四条腿一次讲清。

**怎么做的。** T=1024 与 T=2048 的同 step（6000 步）两点此前已存在（`2626`/`2629`，同引擎、同 bs8、
同 seed0、同修复档），**只读复用**（逐字段等价见 §8）；本实验**新跑** T=256 / T=512 两点
（full/窗口各一臂 × 两 seed，共 8 臂，各 6000 步）。

**测出来多少（先看关键数字）。**

**同 step（都是 6000 步）四点：**

| T | 窗口 | 全因果 bpc | 窗口 bpc | Δ = 全因果 − 窗口 | 判定 | token/臂 |
|---|---|---|---|---|---|---|
| 256 | 128（占 50%） | 1.946343 | 1.949885 | **−0.003542** | **不亏（带内）** | 12.29M |
| 512 | 256（占 50%） | 1.786939 | 1.791467 | **−0.004528** | **不亏（带内）** | 24.58M |
| 1024 | 512（占 50%） | 1.712069 | 1.702805 | **+0.009264** | **不亏（带内）** | 49.15M |
| 2048 | 1024（占 50%） | 1.705365 | 1.701179 | **+0.004186** | **不亏（带内）** | 98.30M |

**同 token（各 49.15M）四点（旧口径，全部只读复用）：** 窗口更差@256（−0.015752）→ 窗口更差@512
（−0.015101）→ 不亏@1024（+0.009264）→ 不亏@2048（+0.004361）。

**这两张表给出了本轮最重要的一句话：** 同一条研究，两种「口径」给出的短 T 结论不同（同 token 判
「越界亏」、同 step 判「带内不亏」），但**这个差异（0.0123）本身就落在本格判据量的噪声内**
（§4：Δ 的跨 seed 极差 **0.0095 / 0.0062**）⇒ **本 n 下旧结论（「窗口代价随 T 消失」）不可判定**，
两种口径也**不得合并成一条曲线**。**「口径敏感」是未排除的解释之一，不是已证实的发现**；一个可能
机制是短 T 在「同 token」下多训 4× 步数、在「同 step」下少训 4× token——**同 T、同配方下**可核：
`full-256-s6k` 末态 loss **1.4157** vs `2626` 的 `full-256-clean`（同 T/同配方/24000 步，同 token 口径
的对应臂）末态 loss **1.218** ⇒ 本实验 T=256 点**远未收敛**。（**跨 T 的绝对 loss 不可比**，不得
用它论证欠训练——这正是 `2629` 的 ERRATA 已撤回的论证方式。）

**决定性的一条（噪声门限本格自测）：** 本轮把 T=256/512 的**四个臂各换 seed 重跑一次**（八臂全齐）。
**判据量（Δ）的跨 seed 极差** = **0.009459（T=256）/ 0.006231（T=512）**；单臂 bpc 跨 seed 极差
0.0030–0.0158 只作参考（它是**极值估计**、且量的是**另一个随机变量**）。四条 |Δ| ≤ 0.0093 ⇒
**四点 Δ 全部落在本格判据量噪声内，跨 T 的排序（以及「窗口代价随 T 消失」）不成立**。
**边界**：T=1024/2048 两点**没有 seed 复本**（只读引用 2626/2629），故这两点按工程带 0.014 读。

**四条腿「省不省」（同一次会话实测，见 §5）：** 一次会话里对 T×{full,窗口} 各测了整模型一步墙钟与峰值显存。

| T | 解析 FLOPs（注意力） | 解析 FLOPs（整层 all-in） | 实测墙钟 r_time = 窗/全（轮1 / 轮2） | 实测峰值显存 r_mem = 窗/全（轮2） |
|---|---|---|---|---|
| 256 | **−50%** | −7.1% | 1.028 / 0.992 | 1.17 |
| 512 | **−50%** | −12.5% | **0.984 / 0.915** | 1.49 |
| 1024 | **−50%** | −20.0% | 1.076 / 1.069 | 2.04 |
| 2048 | **−50%** | −28.6% | **1.273 / 1.784** | **3.31** |

**⇒ 口径裁决：解析 FLOPs 省（注意力砍一半，整层降幅随 T 增大）；实测墙钟**无稳定收益**——
T=512 两轮都略快（0.98/0.92）、T=256 一轮 1.03 一轮 0.99、**T≥1024 两轮一致更慢**（1.076/1.069、
1.273/1.784）；共享卡占用使比值本身摆动 ±20%，除 T≥1024 外测不出方向；**峰值显存更费**（窗口臂
物化稠密 T×T 掩码，1.17→3.31 倍，T 越大越费）。** 即：**「窗口在当前实装下没有稳定的墙钟收益、
且显存更费（随 T 恶化）」**。

**禁外推。** 本结论只覆盖 **7.16M / bs8 / seed0 / enwik8 / S=6000（T=256/512 新臂）** 与只读复用的
T=1024/2048 同 step 点；不外推到其它 T、规模、batch、token 预算、数据集或渐近极限；不给「交叉点 T*」。

## 1. 这条研究线是什么 + 相对普通 transformer 改了什么（AGENTS.md 六问）

1. **它是干什么的**：让模型在长上下文里**只看最近一段历史**（滑动窗口），而不是每个位置都看前面全部。
   若能在不亏质量的前提下做到，就省掉远距离注意力的算力/内存。
2. **相对普通 decoder-only transformer 改了什么**：**只改训练期可见集**——普通全因果
   `keep[i,j] = (j ≤ i)`；窗口 `keep[i,j] = (j ≤ i) ∧ ((i−j) < w)`，`w = T/2`（同相对刻度 50%）。
   **参数完全不变**（掩码零参数）。全部臂套 `2625` 的**长度条件档 QK-Norm**（`qk-normfrom512`）作为
   长 T 稳定性修复（零参数；T ≤ 512 臂 `n_qkv_hooks == 0`，逐算子等于 stock）。
3. **为什么盯着它**：注意力 FLOPs 随 T² 增长，长 T 上按位置丢弃远端键是标准省算法；但质量代价是否
   随 T 缩小，本项目此前只有**混合口径**的四点，必须统一口径后重判。
4. **怎么测的**：同一主干（d=256/L=8/h=8/mlp=4、bs8、seed0、lr1e-3、enwik8 前 90M/末 10M），
   四点**同 step S=6000**；每点 full 与 window（w=T/2）两臂；主判据 = clean bpc（enwik8 评测流，
   `window_seed=2`，20 批 × bs16）的 `Δ = bpc_full − bpc_window`。
5. **测出来多少**：同 step 四点 **全部落在噪声带内**（Δ = −0.0035 / −0.0045 / +0.0093 / +0.0042）；
   同 token 副口径四点 **窗口更差 → 窗口更差 → 不亏 → 不亏**；两口径之差（0.0123）**落本格判据量
   噪声内（0.0095）** ⇒ **旧结论不可判定**（不得宣称「翻转」或「口径敏感」）。
6. **结论与下一步**：旧结论「窗口代价随 T 消失」在本 n 下**不可判定**；可站住的是**成本腿**：
   FLOPs 省、**墙钟无稳定收益、显存更费**。要拿到干净的质量形状，需要 **n≥2 seed + 每点足够收敛** 的关键格（§11）。

## 2. 判据 C1：质量 —— 同 step 四点与同 token 副口径（只描述、禁外推）

**主判据口径**：`Δ(T) = bpc_full(T) − bpc_window(T)`（正 = 窗口更好）；native 工作点（full = 全因果；
window = 自身训练掩码）。工程方差带 **0.014**；本格自测判据量噪声见 §4。

**同 step（S=6000）四点：**

| T | 窗口 | bpc_full | bpc_window | Δ native | 带宽分类 | steps | token/臂 |
|---|---|---|---|---|---|---|---|
| 256 | 128 | 1.946343 | 1.949885 | **−0.003542** | 不亏（噪声带内） | 6000 | 12.288M |
| 512 | 256 | 1.786939 | 1.791467 | **−0.004528** | 不亏（噪声带内） | 6000 | 24.576M |
| 1024 | 512 | 1.712069 | 1.702805 | **+0.009264** | 不亏（噪声带内） | 6000（引用 2626） | 49.152M |
| 2048 | 1024 | 1.705365 | 1.701179 | **+0.004186** | 不亏（噪声带内） | 6000（引用 2629） | 98.304M |

- 形状（同 step）：**不亏 → 不亏 → 不亏 → 不亏**。
- **token 预算随 T 线性**（12.29M→98.30M）：同 step 口径下**不可能**同时对齐 token（`tokens = steps·bs·T`），
  这是物理事实，已按 §2 预登记声明。

**同 token（49.152M/臂）副口径四点（全部只读复用）：**

| T | Δ native | 带宽分类 | steps |
|---|---|---|---|
| 256 | −0.015752 | 窗口更差（越界） | 24000 |
| 512 | −0.015101 | 窗口更差（越界） | 12000 |
| 1024 | +0.009264 | 不亏（噪声带内） | 6000 |
| 2048 | +0.004361 | 不亏（噪声带内） | 3000 |

**两种口径的对照（本轮唯一诚实的读法）：**

- 同 token 口径短 T 判「越界亏」（−0.0158 / −0.0151），同 step 口径短 T 判「带内不亏」（−0.0035 / −0.0045）。
- 但**两口径之差（0.0123）本身落在本格判据量的噪声内**（Δ 跨 seed 极差 0.0095，§4）⇒
  **本 n 下无法判定哪个口径更真**：不得宣称「翻转」、不得宣称「口径敏感是发现」。
- **未排除的解释**（必须并列，不得择一断言）：
  - 短 T 在「同 token」下拿到更多步数（T=256 是 T=2048 的 8×），退火更久；
  - 短 T 在「同 step」下 token 更少：**同 T、同配方**的证据 = `full-256-s6k` 末态 loss **1.4157**
    vs `2626` `full-256-clean`（同 T/同配方/24000 步）**1.218** ⇒ 本实验 T=256 点远未收敛。
  - **跨 T 的绝对 loss 不可比**（`2629` ERRATA 已撤回该论证），只用**同 T** 的内对照。
- ⇒ 结论：**「窗口代价随 T 消失」在本 n 下不可判定**；也**不得**把两条口径合并成一条曲线。

**收敛口径（§17.15/§16）**：判据损失 = enwik8 CE（bpc），取训练日志 loss 末窗斜率（八臂）：

| 臂 | 末态 loss | 末窗斜率 (nats/1k) |
|---|---|---|
| full-256-s6k | 1.4157 | −0.148 |
| win128-256-s6k | 1.4101 | −0.174 |
| full-512-s6k | 1.0606 | −0.074 |
| win256-512-s6k | 1.0706 | −0.043 |
| full-256-s6k-s1 | 1.3651 | +0.068 |
| win128-256-s6k-s1 | 1.3625 | +0.045 |
| full-512-s6k-s1 | 1.1271 | −0.072 |
| win256-512-s6k-s1 | 1.1248 | −0.059 |

⇒ 两臂**同 step 同调度**，故 Δ 是 **matched-step 对照**；绝对水平是**快照**（末窗斜率多非零、
T=256 臂远未收敛）。

## 4. 判据 C4：噪声门限**本格**自测（四对 seed）

- **单臂跨 seed 极差**（同配置、唯一差别 seed，八臂全部跑齐）：

| 臂 | bpc(seed0) | bpc(seed1) | 单臂极差 |
|---|---|---|---|
| `full-256-s6k` | 1.946343 | 1.930552 | 0.015791 |
| `win128-256-s6k` | 1.949885 | 1.943553 | 0.006332 |
| `full-512-s6k` | 1.786939 | 1.796186 | 0.009247 |
| `win256-512-s6k` | 1.791467 | 1.794483 | 0.003016 |

- **判据量（Δ）的跨 seed 极差**（同一点两臂各用同一 seed 相减）：
  T=256：Δ = −0.003542(seed0) → −0.013001(seed1)，极差 **0.009459**；
  T=512：Δ = −0.004528(seed0) → +0.001703(seed1)，极差 **0.006231**。
- **本格判据量噪声**取 **0.009459**（Δ 跨 seed 实测极差的最大值）。**注**：单臂 bpc 的 0.0158 是
  **极值估计**、且量的是**另一个随机变量**（单臂水平，不是两臂之差），**不作判据门限**，只作参考。
  **评测批内配对差**：四臂/八臂共用同一评测流（`window_seed=2`、同 20 批 bs16）⇒ 批级噪声在 Δ 中
  **共模抵消**（按构造 ≈0），故不另计。
- **含义**：§2 四条 |Δ| ≤ 0.0093 ≤ 本格判据量噪声 0.0095 且 ≤ 工程带 0.014 ⇒ **四点 Δ 全部不可排序**。
- **边界（P1-2）**：T=1024/2048 两点**没有 seed 复本**（只读引用）；本格噪声只在 T=256/512 测得，
  把 0.0095 套到 T=1024/2048 只是**工程外推**，已在 §11 列为待补。
- **与 2625 的对照**：`2625` 在同一 13M/enwik8 谱系上测得 T=512 单臂两次重跑极差 **0.0045**；
  本轮测得单臂 0.0030–0.0158 ⇒ **噪声是格/点/臂相关的**，进一步支持审计 §4-①：
  **不存在单一全局可排序线**（这正是审计引用的 ticket 11 原文「no single global floor」）。

## 5. 判据 C3：四条腿「省不省」（逐 T 回答）

同一会话内对 8 个配置（T × {full, window}）实测整模型一步 fwd+bwd 中位墙钟与 torch 峰值显存
（套 QK-Norm 同配方）。**两轮**并报：轮1 = `smoke/smoke.json`（preflight），轮2 = `eval.json`（评测）。

| T | 注意力 FLOPs − | 整层 all-in FLOPs − | r_time 轮1 | r_time 轮2 | r_mem 轮2 | 峰值 full→win (GiB, 轮2) |
|---|---|---|---|---|---|---|
| 256 | 50% | 7.14% | 1.028 | **0.992** | 1.169 | 0.296 → 0.346 |
| 512 | 50% | 12.5% | 0.984 | **0.915** | 1.487 | 0.456 → 0.678 |
| 1024 | 50% | 20.0% | 1.076 | 1.069 | 2.036 | 0.911 → 1.855 |
| 2048 | 50% | 28.57% | 1.273 | 1.784 | 3.305 | 1.688 → 5.579 |

- **质量腿**（= §2 Δ）：四点全带内（但见 §2/§4：不可当趋势）。
- **解析 FLOPs 腿**：**省**。注意力每 token 每层 MACs `2·w·d` vs `2·T·d` ⇒ 恒 **−50%**
  （窗口 = T/2）；整层 all-in 降幅 = **`512w / (512T + 786432)`**（`w = T/2` ⇒ `256T/(512T+786432)`）
  ⇒ **−7.1% / −12.5% / −20.0% / −28.57%**（随 T 增大），与 `cost.theory` 一致。
- **实测墙钟腿**：**无稳定收益**。逐 T：T=256 **1.028 / 0.992**（两轮跨 1）；T=512 **0.984 / 0.915**
  （两轮都略快，但幅度 ≤0.085，与 T=256 的 1.028 同量级 ⇒ 共享卡占用下**测不出方向**）；
  T=1024 **1.076 / 1.069**；T=2048 **1.273 / 1.784**（**T≥1024 两轮一致更慢**）。
  共享卡占用使该比值本身摆动 ±20%。⇒ 只能说「**T≥1024 一致更慢；T≤512 测不出方向；无稳定收益**」，
  稠密 bool 掩码照算满 T×T 再遮掉，理论省下的注意力 MACs **没有兑现**。
- **仪器口径（P2-6）**：上面引的「注意力孤岛/整模型步时」沿用 `2622`/`2626` 的**既有定义**
  （**单层注意力孤岛** fwd+bwd 中位墙钟 ÷ **整模型 8 层**一步中位墙钟），与公式 `512T/(512T+786432)`
  的**单位不齐**（公式是 MAC 占比、整模型量级）⇒ 只作**趋势参照**，不作判据。轮2 实测占比：
  full 0.131 / 0.109 / 0.134 / 0.325，window 0.115 / 0.132 / 0.214 / 0.302；轮1 full 0.114 / **0.067** / 0.102 / 0.235。
- **峰值显存腿**：**不省，且随 T 恶化**。窗口臂物化稠密 T×T 掩码，r_mem = **1.169 / 1.487 / 2.036 / 3.305**
  （T 越大越费）；T=2048 窗口臂 **5.58 GiB > 5GB 礼貌线**（§20.2 记账：本行即显式偏离；余量仍 ≫8GB）。
- **一句话裁决**：**解析 FLOPs 省；实测墙钟无稳定收益（T≥1024 一致更慢）；峰值显存更费（随 T 恶化）。**
  窗口算子在本实装下**只在纸面上省算力**——实用化前提是把稠密掩码换成真正的带状/块稀疏核（§11）。

## 9. 失败路径与排除（SCHEMA §5）

| 试了什么 | 结果 | 排除了什么解释 |
|---|---|---|
| 复用 W1 的 QK-Norm hook | 单测（T≤512 零 hook 且逐位不变 / T>512 挂 hook 且改前向 / 零参数）+ 6 条变异全抓红 | 排除「开关是死的 / 长度条件档偷偷改短 T」 |
| 四点 full 臂是否稳 | 八臂 `gnorm_max ∈ [6.55, 7.70]`、跳步 0 + 引用臂 7.25/7.22 | 排除「长 T 崩溃」（QK-Norm 修复后） |
| 四点是否因口径不同而不同 | 同 token 与同 step 两套读数并报 | 两口径之差落本格判据量噪声内 ⇒ **旧结论不可判定**（不宣称翻转） |

## 11. 禁外推与下一步最小实验

**禁外推**：本结论只覆盖 **7.16M / bs8 / seed0 / enwik8 / S=6000（T=256/512 新臂）** 与只读复用的
T=1024/2048 同 step 点；**不外推**到其它 T、规模、batch、token 预算、数据集或渐近极限；不给
「交叉点 T*」的数值断言。

**下一步最小实验（带成本）**：
1. **真窗口核**（块稀疏 / windowed FlashAttention）替换稠密 bool 掩码 ⇒ 检验 FLOPs 节省能否兑现为
   墙钟收益（当前 T≥1024 一致更慢、T≤512 测不出方向）；这是「窗口算子实用化」的关键前置，也是本格
   成本腿从「纸面省」到「实测省」的唯一路径。
2. **第三轮空卡成本探针**（≈1 min/档 × 8 档）：共享卡占用使墙钟比值摆动 ±20%，把「T≤512 是否真略快」
   测硬。
3. **判据量噪声扩到四点 + 收敛度对齐**：T=1024/2048 各补两 seed（≈2×2×5 min），并选一个四点都更接近
   收敛的 token 预算（≈60–90 min）；用于给「四点是否真在一个带内」下更硬的结论。
4. **第二规模点**（如 100M）：本格结论限 13M。

## 附：机制归属（诚实标注）

本实验的干预是 **`train_window = T/2` 的位置窗口**——按 `.scratch/50-critical-audit/A-AUDIT.md` §4-② 的
分类，位置窗口的机制归**A3（窗口/锚点）**，本实验的目录在 A6 是因为 `2622`–`2629` 这条长 T 系列
历史上建在此处（审计已点出这是「机制错格」，本仓诚实保留并在此标注，不做搬运）。
**本实验对 A6（合并算子）的意义 = 给出「窗口算子」在长 T 上的同口径成本四腿基线**：它证明**只改可见集、
不改合并算子**时，理论省算力（−50% 注意力 MACs）**没有兑现为稳定的墙钟收益**、且**峰值显存更费**
（1.169→3.305×）。A6 自己的算子（内容 top-k / 线性）在这条基线上并不更省：见 `2614`/`2637`。
