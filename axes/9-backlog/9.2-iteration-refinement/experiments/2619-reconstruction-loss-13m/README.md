## 1. 命题

**在局部先验无法补全的合成任务上，只给「从可见状态重建被窗口遮住的内容」这条
训练信号（不改前向结构、不加显式记忆槽），普通 dense 模型能不能学会「搬运」？**

一句话可证伪的形式：*「B（λ=1.0 重建项）的关联回忆准确率 ≥ A（λ=0）+ 3pp
且两者二项 95% CI 不重叠」*。

**人话版**：任务是这样的——开头 8 组「暗号 → 答案」，中间塞两百多个无意义的
填充符，最后再问其中几组（问的时候，那些暗号早就掉出「只能往前看 16 格」的
视野了）。开局那个模型没有「口袋」（无记忆槽），只有一条注意力的窗口。
这条线问的是：**在训练时额外罚它「把刚掉出视野的那一格重建出来」，它会不会因此
学会把信息一路交班带过去？** 带过去了 ⇒ 关联回忆的命中率会从瞎猜（1/64 ≈ 1.6%）
抬起来；没带过去 ⇒ 还是瞎猜。

## 2. 单因素声明

- **基底**：本仓 stock dense decoder-only trunk（`DepthARModel(dense=True)`：
  tied 读出 + 无 final LayerNorm + 顺序残差），13.5M（d256×12 层×8 头×mlp6×T256）。
- **唯一变量 = 训练信号**：`A`（λ=0，纯 CE）→ `B`（λ=1.0，CE + 重建项）。
  **前向结构逐位一致**：解码头不参与模型自身 logits（单测
  `test_recon_head_init_does_not_disturb_other_params` /
  `test_recon_default_off_matches_v1_bitwise` 钉住「有头/无头两臂主干逐位相同」）。
- 其余逐字段一致（含 seed=0）：模型规格、训练配方、数据生成器、可见性掩码、
  步数、批大小、学习率、优化器、评测协议。逐字段对照见 `analysis.md` §3。
- **两臂都有同一个解码头**（d→V 线性，+52,736 参数 = +0.39%）：A 臂里它
  **未被训练**（λ=0 ⇒ `add_recon_term` 原样返回主损失、`p.grad is None` ⇒ AdamW
  整条跳过，连 weight decay 都不作用）。因此「臂间差异」不可能是参数量或初始化
  差异造成的——这是一条**训练信号**的单因素对照。
- **必要性例外（显式记账）**：为了让「需求」真的存在，训练与评测都用
  `train_window=16 / train_anchors=0` 的可见性掩码（ticket 32-O 既有开关），
  且重建目标偏移 `recon_window = 16 = train_window`。这不是第二个机制，而是
  本契约指定的任务与目标定义（三臂完全相同）。

## 3. 干预定义（实现而非标签）

```
重建目标：行 i（隐状态行号，与主损失同一约定：行 i 的读出预测 token i+1）
          ⇒ 目标 = tokens[i − 16]     ← 刚掉出可见窗口的那一格
损失：    total = CE_trunk + λ · mean_i CE(recon_head(h_i^L), tokens[i − 16])
头：      单层线性 d→V（无 bias、**不 tied**），fp32（autocast 关闭）
```

为什么目标恰好是「刚掉出窗口的那一格」（**物理论证，单测用真实掩码钉住**）：
窗口掩码下位置 i 的可见集 = `[i−15, i]` ⇒ `i−16` **不可见**；而位置 i−1 的可见集
= `[i−16, i−1]` ⇒ 同一格**仍可见**。于是这条损失在物理上只要求一件事：
**每一格在离开窗口前，把这一格交班给下一格的隐状态**；一路交班累积起来
= 残差流必须当递归记忆用。这正是 `2617-design-rightcarry` §1.1 记录的梯度缺口
（只看最终 CE 时，最短路径是「当场读源」，没有任何梯度奖励搬运）。

- **精度与稳定门（硬要求）**：重建项在 `torch.autocast(enabled=False)` 内算
  （fp32），并走主循环**同一个** pre-step grad-norm gate（`gnorm > 1e4` 或非有限
  ⇒ 跳过该步）。依据：F4 的既有教训——负/reward 类损失在 bf16 下两次发散。
- **λ=0 逐位等价基线（硬要求）**：`add_recon_term` 在 λ=0 时**原样返回同一个
  loss 对象**（不是 `loss + 0·x`）⇒ 不建图、无浮点运算、不消耗随机数；单测钉住
  对象同一性（`test_recon_lambda_zero_returns_same_loss_object`）+ 头参数
  `grad is None`（`test_recon_head_dead_at_lambda_zero_grads_flow_at_lambda_one`）。
- **λ 的取值**：预登记 `λ = 1.0`（与主 CE 等权，多任务损失的教科书缺省），
  **不在结果上再调**。两臂的 `loss`/`recon` 两项都逐 200 步落盘，供读者核对
  两项的量级比（见 `analysis.md` §4）。
- **单因素护栏**：`recon_window > 0` 要求 `dense` + `topology="sequential"` +
  `train_window > 0`，且与 `attn_sparse_k` / `attn_linear` / `n_kv_heads` /
  `carry_rule` 互斥（一次只改一个因素）。

## 4. 判据线（**逐字抄录**自契约 U2 线，一字未改）

> - 在 **无显式记忆槽** 的普通 dense 模型上，加 **重建/充分性损失**（把被窗口遮掉
>   的内容从可见状态重建出来）：两臂 = 有 / 无 该损失（其余逐字段一致，λ=0 必须
>   逐位等价基线，float32 + pre-step grad-norm gate）。
> - **判据（预登记）**：主腿在**关联回忆准确率**（不是 bpc）；有损失臂相对无损失臂
>   **≥ +3pp 且 CI 不重叠** ⇒ 「训练信号能让无通道模型学会搬运」成立；否则记「在
>   13M/12k 不成立」。
> - 成本：2–3 臂 × ~12 min；预算 ≈45 min。

以下为**本实验的操作化**（读数前写下；不改上面三条）：

| 编号 | 判据 | 操作化 |
|---|---|---|
| **c0 前提校验** | 无损失臂必须 ≈ chance | `A` 的关联回忆准确率（K=8）的 Wilson 95% CI **下界 ≤ max(3·chance, 0.02)**；若显著高于 chance ⇒ 设置有问题（窗口/任务漏洞），先修设置再判 |
| **c1 主判据** | 有损失臂 ≥ 无损失臂 + 3pp 且 CI 不重叠 | `B − A ≥ +3.0pp` **且** Wilson 95% CI 不重叠（CI 口径与 2618 契约 U 一致） |
| **c2 毁源对照臂（强制）** | 任何一臂若在毁源后仍保持高准确率 ⇒ 该臂判读作废 | 评测时用 `corrupt_span` 毁掉源片段 `[0, 2K)`；作废条件 = 毁源后准确率的 **CI 下界 > max(4·chance, 0.03)** |
| **c3 重跑臂稳健性（预登记的解读规则，不是新判据）** | 训练侧双稳态是本批已知风险 | `B_rep`（与 `B` 逐字段相同的同 seed 重跑）若**不**满足「≥ A + 3pp 且 CI 不重叠」，则 c1 的「成立」结论**降级为「不可复现 ⇒ 待定」**；若 B 与 B_rep 之间 CI 不重叠（同配置两次差异显著）⇒ 直接记为「训练侧双稳态，本尺度不可分辨」 |
| **辅助腿（不作判据）** | 变距离回忆距离曲线、泛化档 K∈{4,16}、clean CE 税（trunk CE 与答案行 CE）、loss 斜率（同方法）、活性量轨迹 | 逐项在 `analysis.md` 报 |

- **禁止**：把 bpc 当主判据（训练侧 bpc 噪声 ~0.0156 已超方差界 0.014，见
  `analysis.md` §3）；用单点曲线外推（SCHEMA §17.11）；把「没搬」写成
  「机制不可能」（SCHEMA §19）。
- **本实验的判据只针对本尺度**：结论句式固定为「13M / 12k 步 / 该任务上」（成立或
  不成立），不外推到其他规模。

## 7. 对照与方差（SCHEMA §3 / §9）

1. **`A`（λ=0）**：输入分布/要预测什么/部署中对应什么 = 与 B 完全相同的合成任务批、
   同一位置集、同一个 13M stock 模型（不加任何搬运结构/信号）。
2. **毁源对照臂（评测期，每臂强制）**：把源片段 `[0, 2K)` 换成同分布新随机符号，
   其余逐位不变 ⇒ 「读数是不是真的来自那段远处内容」。
3. **`B_rep`（重跑臂，c3）**：同配置同 seed 重跑，量**训练侧散度**。
   依据：本批 2618 实测到同配置两次（plain 写臂）相差 **+3.271pp**（CI 不重叠）
   ⇒ 该训练配方在本尺度上存在**多 pp 级训练侧散度**，单跑一次不足以支持 +3pp 结论。
4. **方差界**：判据用**准确率 + 二项 CI**（不用 bpc）。评测侧同 seed 整批重跑应逐位
   相同（`results.json::reproducibility`）；训练侧散度以 `B vs B_rep` 的答案行 CE 与
   主腿准确率之差报出。
5. **历史对照复用**：`2618` 的 `U0` 臂（无通道 + 窗口 16 + 纯 CE，同 seed 同配方）
   作为**外部参照点**报出（同为 λ=0、同为无通道），但**不作本实验的对照臂**
   （对照臂 = 同批同修订的 `A`）；口径与差异见 `analysis.md` §7。

## 10. 失败决策树（测量 → 实现 → 规模 → 设计）

1. **测量**：`A` 显著高于 chance？→ 查窗口是否生效（`window_mask` 活性量）、
   查询-key 距离分布、局部先验读数；先修设置再判。
2. **实现**：重建项活性为 0（`recon_ce` 恒定 / `head_gnorm = 0` / 头权重没动）→
   先跑变异验证（M1–M5）排除死开关、错索引、λ=0 守卫失效。
3. **规模/信号**：重建项活着（`acc_symbol` > 1/V）但三臂都 ≈ chance ⇒ 在
   13M/12k 上「不成立」（SCHEMA §19：**不得**表述为「机制不可能」）。
4. **设计**：`B` 高于 chance 但**毁源不掉** ⇒ 读数不是搬来的信息，该臂判读作废。
5. **归因**：`B` 与 `B_rep` 之间就不一致 ⇒ 先归因**训练侧散度**（本批已知多 pp 级），
   按 c3 降级为「待定」，不写成「训练信号有效/无效」。

## 11. 既有做法（prior art，SCHEMA §18；**不得声称首创**）

1. **谁做过**：
   - **Compressive Transformer**（Rae et al., 约 2019）：压缩记忆 + **compression loss**
     （从压缩记忆重建被丢掉的原始记忆）——**记忆·未核**（本环境联网检索不可用；
     上一轮情报已列为「最该优先核证」的一条）；
   - **AutoCompressors**（Chevalier et al., 约 2023）：summary 向量 + **重建损失**训练；
   - **ICAE**（Ge et al., 约 2024）：L 个 memory slot ≈ 长上下文，**自编码（重建）**训练；
   - **RECOMP**（Xu et al., 约 2023）：检索文档压缩器，明确对比**重建/抽取目标 vs 蒸馏**；
   - **500xCompressor**、**DMC**（约 2024）：压缩记忆/ KV 压缩，报告需配继续预训练或蒸馏。
   以上均 `记忆·未核`，出处与关键词清单见
   `axes/1-time/1.1.4.1-explicit-memory/experiments/2617-prior-art-memory/PRIOR_ART.md`
   （§「既有做法」与 §「若可检索应查什么」）与 F4 课题页备注。
2. **为什么这么设计**：压缩/有损载体只能丢信息不能增信息，只看最终 CE 时
   「把信息写进载体再读出来」比「当场读源」多一个瓶颈 ⇒ 没有梯度奖励搬运；
   重建/充分性损失的作用就是**人为补上这个梯度**（动机与本文档 §3 的物理论证同构，
   但**不是我们的新论点**）。
3. **它的实测结果**：业界在小/中规模上报告重建目标对压缩载体的**可恢复性**有效
   （`记忆·未核`，具体数字**未核、不得当判据**）；本项目本地先验是
   **consistency loss（同类辅助损失）在 13M 上中性**（`本地实测`，F4 课题页：
   IX4 1.6589 ≈ C1 1.6549）⇒ 不能想当然有收益。
4. **我们的增量在哪**（三条，缺一不成立）：
   (i) **13M + 局部先验抗性任务**（SCHEMA §19 的合成天平，不用 enwik8）；
   (ii) **单因素受控**：只改训练信号，前向结构逐位一致、两臂同参数量同初始化，
       并给出 λ=0 的**逐位等价**证明（业界工作没有这个位点）；
   (iii) **载体是「无显式记忆槽」的残差流**（不是压缩器自身的 slot/summary），
       即回答「只给信号、不发口袋，能不能逼出搬运」。
   ⇒ 这三个限制条件下的受控对照「疑似空白」，但**我们不说无人占位**：
   本实验是「换尺度 + 换任务 + 剥离因素」的验证，不是首次提出。

## 12. 局部先验抗性（SCHEMA §19）声明

- 主腿任务 = **合成长程任务**（多查询关联回忆 / 变距离回忆）：答案由写入的
  (key,value) 表唯一确定，局部先验（只看最近 8–16 个 token 的最强预测器）
  实测退化为 chance（`run.py` 每次运行都落 `local_prior` 读数）。
- 本实验**不跑 enwik8 腿**，因此**不下任何关于强局部先验任务（真实文本）的结论**；
  §19 要求的「两组数」在本实验退化为单组（合成 = 弱局部先验），
  「真实文本腿缺失」作为 residual risk 写进 `analysis.md`（补充成本 ≈2 臂 × 12 min，
  未在本预算内）。**禁止**把本实验的结论写成「在语言建模上无效」。
