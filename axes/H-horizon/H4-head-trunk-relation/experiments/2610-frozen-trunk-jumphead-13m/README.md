# 2610 · 冻结主干 + 只训跳跃头（等 FLOPs 判决）· 13M

## 1. 命题

在**冻结**的 13M dense decoder-only 主干上只训一个跳跃头（预测 t+2），
在**等 FLOPs** 条件下与「连跑两次前向」比较：

> 1 次前向 + 跳跃头（成本 1 单位）能否达到 2 次前向（成本 2 单位）质量的 ≥81%？

已知锚（回环时代、13M、joint 训练）：node-2 直接头 argmax 命中 **55.97%**，
node-1 **68.8%**，条件接受率 **65.8%**（给定 node-1 正确则 **77.3%**）。
本实验回答的是**同一问题的冻结主干版本**——因为挂头是唯一实测零税的旁路，
它决定了「跳跃头作为独立研究线」是否成立。

## 2. 单因素声明

只改一个因素：**头与主干的关系**（冻结主干 + 只训头）。主干、数据、评测、token
预算与对照臂全部相同。基底 = 主流标准 decoder-only transformer（dense AR）。
**非必要性例外**：无（主干不需要非标准改动，这正是本格的价值）。

## 3. 指标表（逐项分析）

| 维度 | 指标 | 与谁比 |
|---|---|---|
| 解决什么问题 | 视界轴草稿/多跳的成本问题（headroom 在成本而非质量） | — |
| 代价 | Δ clean bpc（挂头前后，同主干）——预期 ≈0（旁路零税） | 冻结主干自身 |
| 有效性 | 等 FLOPs 命中率比（头 1 单位 vs 两跳 2 单位） | 直接头 + 2 次前向 |
| 收益·用法 1（草稿） | t+2 条件接受率（能否作为 spec 的宽草稿） | 直接头（node-1） |
| 收益·用法 2（分配） | 头置信度的 ECE（能否用置信决定验证/不验证） | prob0 校准基线 |
| 可控性 | 头置信度-命中率的分层单调性 | — |
| 副产品 | 冻结主干是否被证明「可挂任意头而不受影响」 | probe 头 @100M 零税锚 |

## 4. 判据线（预先写下）

- **成功**：冻结头在 t+2 的 argmax 命中率 ≥ **0.81 ×** 直接两跳命中率
  （以实测的直接两跳为分母，锚约为 0.688 ⇒ 阈值 ≈ 0.557）；
  且**主干 clean bpc 变化 |Δ| < 0.014**（零税验证）。
- **中性**：命中率在 [0.557, 0.60) 且校准良好 ⇒ 记录为「可用草稿，不足以替代两跳」。
- **失败**：命中率 < 0.557 ⇒ 判「冻结主干上跳跃头无头寸」，转入教学：为什么联合训练
  的 55.97% 反而更高（信息可用性的差异）。
- **校准判据（探索性）**：头置信度的 ECE ≤ 0.01 且分层单调 ⇒ 可作为分配信号。

## 5. 对照与方差

- **对照 1**：同一冻结主干的直接头（t+1）；**1 次前向**预测 t+2 的命中也测（作为头的能力分母）；
- **对照 2**：2 次前向（第一次用直接头提交 t+1，第二次预测 t+2）——这是等 FLOPs 的对手；
- **对照 3（可选，+5 min）**：同主干**联合训练**头（不冻结），看冻结是否损失质量；
- seed：头训练 2 seeds（头很小，种子成本低）；方差界 Δ < 0.014。

## 8. 失败决策树

| 症状 | 诊断顺序 | 处置 |
|---|---|---|
| 命中率低于阈值但 t+1 直接头正常 | 头容量/训练不足 | 先加头容量或步数（仍单因素）再判 |
| 命中率 ≈ 0.5 | 实现 bug（未正确 shift 目标） | 变异验证 + 单测（本项目曾发生 off-by-one，M0 关键 review 发现） |
| 主干 bpc 变了 | 冻结失败 | 检查 requires_grad / 优化器参数组 |
| 与 joint 的 55.97% 差很多 | 设计差异（信息可用性） | 记录为结论，不追加机制 |
