# H3-composition · 多位置预测的组合方式

> 轴：**H 视界（一次前向产生几个位置）** ｜ 状态：**✅ judged**

> **判读**：**【命题边界（2026-10-02 更正，C6）】本格测的是「冻结表征上的重复潜在映射与门控」**：direct `T(h)` / composed `T(T(h))` / gated 混合，全部只被 CE(t+2) 监督。它**不回答**用户要的概率路径组合问题（`p(x_{N+2}|h)=Σ_z p(z|h)p(x_{N+2}|h,z)` vs `p_direct`）——`T∘T` 既非「N+1 再加一」、也非「直接 N+2」、更非两者的概率混合（无概率、第一遍不受 N+1 监督）。下述结论**只对该受限命题成立**，不得用作「先 N+1 再 N+2 被否证」。**在该受限命题下被判负**：门控混合 0.4738 仅比直跳 0.4672 高 +0.0020（<0.014 噪声带），且等参数无门对照 0.4785 更高 ⇒ 增益归容量不归门控；门不是「选择」而是**坍缩到连跳**（96.7% 位置 g≈0.82，被压掉的直跳分支只训到 0.262 vs 单训 0.467）。**【2026-10-02 R6 新结果，取代 2613 作为本格命题的正式回答】**：Spec 三臂 `2631-spec-three-arms`（唯一变量 = 第 N+2 草稿位的分布来源：`direct` 从同一状态一次直接出 / `combined` 两条分布按概率混合 λ=0.5 / `chain` 先出 N+1 再以之为条件出 N+2）在 13.4M×2 seed 与 53.9M×1 seed 上一致给出 **direct ≈ combined（配对差 95% CI 含 0，不可排序）> chain（显著更差）**；53.9M 点 α₁/α₂|₁ = **0.844/0.872（direct）· 0.829/0.853（combined）· 0.657/0.826（chain）**、τ = **1.58/1.54/1.20**、tok/fwd = **2.58/2.54/2.20**、墙钟加速比 = **1.58/1.57/1.39**、等效算力净账 = **0.48/0.49/0.56**；三臂发出流与原生贪心**逐位相同**（门禁 9/9）。**2613 降级为背景实验**：它测的是冻结表征上的重复潜在映射 T∘T 与门控，回答的不是本命题（复核 A6）。

## 5. 失败路径与原因

1. **命题边界（C6，2026-10-02）**：本格全部臂只吃 CE(t+2)、`T∘T` 无概率与条件监督 ⇒ **不能**回答用户「N+1 再加一 vs 直接 N+2 vs 概率混合」的问题；该问题已由 R6 的 Spec 三臂（`2631-spec-three-arms`）回答——**direct ≈ combined（不可排序）> chain（显著更差）**，本实验（2613）降级为背景实验
2. **主判据未过**：gated 0.4738 vs 阈值 max(direct 0.4672, composed 0.4718)+0.014 = 0.4858 ⇒ Δ = +0.0020
3. 草稿接受率 0.6113（< 0.90）⇒ 不可作草稿
4. **等参数无门对照 direct_eq（394,496 参数，与 gated 逐位相同）反而最高 0.4785** ⇒ 那 +0.0020 归容量、不归门控结构（SCHEMA §15）
5. 门**坍缩到单支**：起点 g≡0.5 → 均值 0.82（96.7% 位置偏两跳），被抑制的直跳分支退化到 0.262（单独训练为 0.467）⇒ 不是「选择组合深度」而是「偏好一支」
6. 2× 训练（4000 步）后 Δ = +0.0042 仍 < 0.014；快照口径（四臂同窗斜率 −0.060~−0.069/1k 仍在下降）
7. 契约缺陷（主 Agent 认领）：sigmoid 门 + 单边零 + 「起步等价 direct 或 composed」三者不可兼得（σ(0)=0.5）
