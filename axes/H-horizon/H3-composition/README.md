# H3-composition · 多位置预测的组合方式

> 轴：**H 视界（一次前向产生几个位置）** ｜ 状态：**✅ judged**

> **判读**：自门控组合**被实测否决为主张**：门控混合 0.4738 仅比直跳 0.4672 高 +0.0020（<0.014 噪声带），且等参数无门对照 0.4785 更高 ⇒ 增益归容量不归门控；门不是「选择」而是**坍缩到连跳**（96.7% 位置 g≈0.82，被压掉的直跳分支只训到 0.262 vs 单训 0.467）。

## 1. 命题

直接头与多跳组合如何合并——这是用户提出的「自门控非线性组合」所在格。

## 2. 选项枚举（本格全部可能取值）

1. `只用直接头`
2. `链式条件（concat+proj，DeepSeek 式）`
3. `朴素概率乘积`
4. `DP lattice 置信加权（设计 §5 已定义，从未端到端测量）`
5. `自门控选组合深度（一次跳 k vs 跳 1 走 k 次，由 sigmoid 门决定）`
6. `beam 多线 + 重排`

## 3. 状态（我们做了什么 / 行业做了什么）

**本地已测**：省算力：等效 1.95×（H4 口径）；门是可观测量（g 分布 + 逐桶命中单调 0.17→0.68）

**行业口径**：见 `docs/playbook.md` 与参照线 `R-references/`。

## 4. 结论与数字

- **税**：（头机制，挂冻结主干：零税；头的税见 H1）
- **收益**：省算力：等效 1.95×（H4 口径）；门是可观测量（g 分布 + 逐桶命中单调 0.17→0.68）
- **判读**：自门控组合**被实测否决为主张**：门控混合 0.4738 仅比直跳 0.4672 高 +0.0020（<0.014 噪声带），且等参数无门对照 0.4785 更高 ⇒ 增益归容量不归门控；门不是「选择」而是**坍缩到连跳**（96.7% 位置 g≈0.82，被压掉的直跳分支只训到 0.262 vs 单训 0.467）。

## 5. 失败路径与原因

1. **主判据未过**：gated 0.4738 vs 阈值 max(direct 0.4672, composed 0.4718)+0.014 = 0.4858 ⇒ Δ = +0.0020
2. 草稿接受率 0.6113（< 0.90）⇒ 不可作草稿
3. **等参数无门对照 direct_eq（394,496 参数，与 gated 逐位相同）反而最高 0.4785** ⇒ 那 +0.0020 归容量、不归门控结构（SCHEMA §15）
4. 门**坍缩到单支**：起点 g≡0.5 → 均值 0.82（96.7% 位置偏两跳），被抑制的直跳分支退化到 0.262（单独训练为 0.467）⇒ 不是「选择组合深度」而是「偏好一支」
5. 2× 训练（4000 步）后 Δ = +0.0042 仍 < 0.014；快照口径（四臂同窗斜率 −0.060~−0.069/1k 仍在下降）
6. 契约缺陷（主 Agent 认领）：sigmoid 门 + 单边零 + 「起步等价 direct 或 composed」三者不可兼得（σ(0)=0.5）

## 6. 判据与判决实验设计

- **判据**：同 FLOPs 的质量（等算力对照）+ 草稿接受率 + 组合置信度的校准（ECE）
