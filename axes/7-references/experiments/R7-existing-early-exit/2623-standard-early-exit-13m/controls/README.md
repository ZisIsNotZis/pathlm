## 2. 噪声门限（本格自测）

| 量 | 值 | 来源 |
|---|---|---|
| 同配置跨 run 漂移（stock） | **0.0003 bpc**（1.5287 → 1.5284） | 历史锚点 `23d-dense-B-12k` vs 本波 `r7-stock-s0` |
| 同配置跨 run 漂移（C1 现配方） | **0.0007 bpc**（1.8582 → 1.8575） | 历史 `23c-H2-w0-12k` vs 本波 `r7-c1-legacy-s0` |
| 同配置跨 run 漂移（tf@4） | **0.0025**（0.9694 → 0.9719） | 同上 |
| 仓内种子散布（bpc） | ≤ 0.0138 | `harness/methodology.md` §2（历史测量） |
| **本格 σ_cell** | **未直接测**（seed-1 重复被预算砍掉，见契约 §6） | 结论按「≥0.2110 的差异」判读：比实测漂移大 300×、比仓内种子带大 15× |

> 说明：本波所有**用于判读的差异**（配方 0.1218–0.2610、门 0.0718–0.2110、形态 0.2573–0.5901、
> MoD 0.3980）都远大于上表两个界，因此「σ_cell 未直接测」不改变任何结论；
> 但**小差异**（如 D1 里等权配方下的门效应 0.0718）应按「≥0.0138 的种子带」保守对待。
