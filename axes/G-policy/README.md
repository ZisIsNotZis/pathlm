# G · 策略与调度

- **原语**：横切（I 与 II 之上）
- **命题**：谁选路径、用什么货币记账、观测什么信号、怎么校准、多线如何并行。

## 定义

横切轴。任何「路径空间」都需要一个选择器与一个计价方式；
本轴记录已建成的分配器（Slider）与已测的信号与障碍。

## 子维度

G1 选择器 · G2 货币 · G3 观测信号 · G4 校准 · G5 并行多线

## 本地总体结论

前置条件已证：prob0 校准 ECE 0.002–0.011 跨规模存活；选择性成立
（低置信 15% 开火把重试从 −0.019 翻成 +0.021 / C1M +0.128，2.2 倍）；
三信号监测栈（prob0 + 路径分歧 js AUC 0.66–0.69 + 重复率 AUC 0.9815）。
已测障碍（多线调度的真问题）：共享 trunk 的 voter 太相关（集成增益
+0.0008~+0.0015 可忽略）；确定性路径 K-path 集成恰得 0；多样性必须练进去。
