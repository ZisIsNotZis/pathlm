研究「谁决定一条路径怎么走」：固定 / 输入无关阈值 / 逐 token 阈值（prob0 门控）/
学习门 / 离线求解器（Slider）/ 在线多线调度器。本仓建成的是**离线求解器 + 校准闭环**。

- 业界标准：ACT / MoD / CALM / LayerSkip / MoE 路由 / SelectiveNet——`axes/G-policy/PRIOR_ART.md`
  块① 逐条列出，并自判 **(a)**（`:52` 分诊表：「阈值/门控/学习路由/早退作为选择器，业界有
  MoD/ACT/CALM/MoE 成熟占位」）。

  ⇒ G1 的「空白」实际上是一个被判死的方向。

## ③ 五类问题逐条判定

1. **开倒车：有。** 见 ②。

2. **过程错误：有。**
   - **「严格占优」用了带内差**：`catalog.yaml:1094` / `G1-selector/README.md:16`
     「严格占优点复现」的原证据是 `.scratch/15-slider-rung3/evidence/SUMMARY.md` §3：
     `k=1 spec τ=0.98` bpc **2.0502** vs plain **2.0545** ⇒ **Δbpc = 0.0043 < 0.014**
     （`docs/methodology.md:19`）。⇒ bpc 侧**不可排序**，「bpc 更好」不成立。
   - **两格同证据**：G1 的三条 evidence（`.scratch/15`、`.scratch/17`、`.scratch/14`）
     与 F3-stopping 的 evidence **完全重合**，结论句也几乎一样（选择性/校准/求解器）。
     ⇒ 同一批实验被写进两个格子的状态灯，重复计数。
   - 本格 **无自有实验目录**（`find` 显示只有 `2515-slider-rung3/README.md` 等
     backfill 存根，指向 `.scratch`）⇒ 不满足 SCHEMA §3 的实验目录契约。

3. **结论错误：有。**
   - 「选择器本身不加税」（`catalog.yaml:1093`）。设计上单轮 `mixture == overwrite`
     （`pathlm/model.py:531-540`）确实**不引入质量税**，但门控一开火就**多付前向**
     （corrupt 输入 τ=0.98 开火 22.16%，`.scratch/15-.../SUMMARY.md` §1），
     把「不加税」放在 `tax` 字段会误导读者以为选择器免费。
     **正确**：把「质量税 = 0（设计保证）／成本 = 开火率 × 第二轮成本」分开写。
   - 「前五种已建成或已测」（`catalog.yaml:1090`）——「已建成」里含 G5 的死方向
     （在线多线调度器），措辞应剥离。

4. **无意义：部分是。** 与前五种选择器（业界做透）相关的「研究」不产生增量；
   真正剩余的「在线多线调度器」已被 G5 判死。⇒ 本格应降级为方法论/工程记录，不再是研究格。

5. **值得做：低（并入 F3）**。若要做，只做一件事：把「同质量带内的成本优势」测干净。

## ④ 建议动作

- **改措辞**：`tax` 字段拆成「质量税 / 成本（开火率）」；删「严格占优」的 bpc 说法。
- **删去**「在线多线调度器是空白」这一待做项（依赖 G5，已判死）。

## ⑤ 正确验证方式（若并入后重做）
