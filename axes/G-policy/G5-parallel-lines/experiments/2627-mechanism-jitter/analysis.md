## 0. 人话摘要（先看这段）

**我们在追的问题**：上一波（V2）发现「让共享主干的多条随机路径隐状态彼此不相关」（表征级去相关，λ=0.1）
在 13M 上**真的起作用**——8 路集成比无去相关臂好 **0.0144 bpc**。但**那个 0.0144 只比「不可排序门槛
0.014」高 0.0004（≈3%）**，结论**贴在门槛上**。所以必须回答：**这个 0.0144 稳不稳？同配置再跑一遍，
两次读数会差多少？**

**测出来三句话**：

1. **两次同配置同 24k 的读数差 0.0035 bpc——只有效应本身的 24%。** run A（V2 既有）净效应
   **+0.0144**，run B（本轮重跑）净效应 **+0.0179**；两次的**极差 = 0.0035 < 0.005**。按跑前写死的
   规则（README §4：极差 <0.005 ⇒ 升格稳健）⇒ **机制「熬过收敛」的结论从「贴门槛」升格为「稳健」**。
   ❌ **已撤销**（45-G1 补跑 `l1` 臂：两臂合并极差 0.0074 = 效应 51% ⇒ `on_threshold`；见文末修正记录）。
2. **两次都在门槛之上。** A 恰好落在门槛（0.0144 ≥ 0.014），B 高出 0.0039 ⇒ 两次都判「保持」，
   没有一次跌破门槛 ⇒ 「机制有效」不是单次侥幸。
3. **但这句话的作用范围很窄。** 极差只度量了**去相关臂（repr01）自己**的抖动（`l1@K8` 是固定复用
   V2 的读数，没有重跑 ⇒ **这是净效应抖动的下界**）；而且**只做 13M、enwik8、一个 seed（seed=0）**，
   50M 的 **0.0322** 缺口**不被本实验覆盖**（禁外推）。

> **一句话**：**「表征级去相关」的净效应是**稳的**——同配置重跑的差值 0.0035 只有效应 0.0144 的约
> 1/4，两次都越过门槛；所以 V2 那句「机制熬过收敛」曾升格为「稳健」（❌ **已被 45-G1 撤销**，见文末）。但稳健**只在 13M / seed=0 /
> 本任务上**成立（下界口径，未测 50M）。**

> **名词就地解释**：**bpc** = 每字符比特数（越低越好）；**K 路径集成** = 采 K 条随机路径、把各自下一词
> 概率平均后再打分（K=8 = 8 倍前向算力）；**机制净效应** = `l1@K8 − repr01@K8`（正 = 去了相关的臂
> 集成更好）；**run-to-run 抖动** = 同配置同 seed 重训后读数的差异（本环境来自 CUDA 非确定性，非配方漂移）；
> **极差** = 两次读数之差（n=2）。

## 0.1 六问（`AGENTS.md` 汇报纪律）

1. **它是干什么的**：让一个共享主干在训练时学会「随手丢层」的多条随机路径，**并让这些路径的
   隐状态彼此不相关**，好在推理时把多路预测平均、拿到比单线更准的结果。本波只问：这个机制带来的
   那点好处**在重跑时稳不稳**。
2. **相对普通的 decoder-only transformer 改了什么**：**结构完全不变**（13M：d256/12L/8H/T512，
   **13,076,483** 参数，全部检查点逐位相同）。改动只在**计算路径与损失**：每步按 `p_skip=0.1` 随机丢层，
   另对两条路径的 trunk 隐状态做跨路 Pearson 相关罚则（`w_repr_decorr=0.1`）。**参数量增量 = 0**。
3. **为什么要改**：集成增益只来自成员**误差不相关**；共享主干成员天然相关 ⇒ 要么贵 N× 独立训练，
   要么显式付钱买多样性。V2 已证「在 13M 上真去相关」，本波问它**换一次随机数还成不成立**。
4. **怎么测的**：**同配置重跑单臂**（`repr01`，同 24k 步、同 seed=0、配置**逐字节相同**），
   与 V2 既有读数比；指标 = **机制净效应** `l1@K8 − repr01@K8` 的**极差**（+ 配对 CI + 分量分解 +
   复现检查）。口径 = matched-step 快照 / 60-batch probe / 与 13M 锚点同函数同 seed。
5. **测出来多少**：见 §1/§3；一句话——**极差 0.0035 < 0.005 ⇒ 升格「稳健」**（❌ **该判已被 45-G1 撤销**，见文末）；两次净效应
   0.0144 与 0.0179 都在门槛之上。
6. **结论与下一步**：**原采纳**「机制净效应在 13M 上稳健（run-to-run 极差 0.0035）」——❌ **该结论已被 45-G1 撤销**（补跑 `l1` 臂后两臂口径 `on_threshold`）；
   **不覆盖**「50M 的 0.0322 缺口」「`l1` 臂自身抖动」（45-G1 已补上）「其他 seed」——未测项见 §10。

## 3. 一号问题：抖动判决（`results_13m.json::jitter`）

| 量 | run A（2626） | run B（2627） | 差（B−A） |
|---|---|---|---|
| `repr01@K8` | 1.3945 | **1.3910** | −0.0035 |
| 机制净效应 `l1@K8 − repr01@K8`（`l1@K8`=1.4089 固定） | **+0.0144** | **+0.0179** | **+0.0035** |
| 200-batch battery clean bpc | 1.4169 | 1.4132 | −0.0037 |

- **极差 = |0.0179 − 0.0144| = 0.0035**（n=2 ⇒ 差与极差同值）。
- **预登记判决（README §4）**：`range = 0.0035 < 0.005` ⇒ **`upgraded_to_robust`**（升格稳健）；
  与降级阈值 0.0144 相距很远，**不触及「不可排序」**。❌ **本判为下界口径，已被 45-G1 撤销**
  （补跑 `l1` 臂：两臂极差 0.0074 ⇒ `on_threshold`；见文末修正记录）。
- **配对 CI**：`repr01_A@K8 − repr01_B@K8 = −0.0034`（CI [−0.0045, −0.0024]，配对口径不含 0；
  两臂各自的 CI **重叠**）⇒ 两次读数的差**统计上可见但幅度落在 0.014 的不可排序带内**——这正是
  「抖动小」的量化表达（不是「两 run 无差别」，而是「差别远小于门槛」）。
- **口径事实（下界）**：本实验**固定 `l1@K8`**（复用 2626），故极差**只**含 `repr01` 臂的抖动 ⇒
  是净效应抖动的**下界**；`l1` 臂自身抖动**未测**（见 §10）。
- **禁外推（`§17.11`）**：以上只描述**本配置、本规模（13M）、seed=0、本任务**下的抖动；
  **不得**外推到其他 seed / 规模 / 任务。n=2 **不报分布外推**（不拟合、不给区间估计）。

## 4. §17.17 分量分解（净效应的两列）

| 分量（相对 `l1_A`） | run A | run B | 增量（B−A） |
|---|---|---|---|
| clean 税 `repr01@K1 − l1@K1` | **−0.0112** | **−0.0152** | **−0.0040** |
| 集成增益 `repr01@K1 − repr01@K8` | **0.0332** | **0.0327** | **−0.0005** |
| 净效应（= (repr01 增益 − l1 增益) − clean 税；见 README 修正注） | **+0.0144** | **+0.0179** | +0.0035 |

> **读法**：run B 的净效应更高，主要来自**它的 clean 税更负**（去相关对单线质量是轻微正收益，
> B 更明显），而不是集成增益更大（两 run 的集成增益几乎相同，差 0.0005）。⇒ 两次读数
> **都**是「机制有效（集成增益 > 0）且代价近零」，差异只是二阶的 tax 波动；**不存在「机制无用」的
> 解读空间**。这也说明净效应的抖动主要由**单线质量**那一项贡献，而非增益项。

## 9. 口径与成本

- **训练**：单臂 `repr01` 24000 步，墙钟 **27.4 min**，峰值显存 **4995.8 MB**（<5GB net）；
  按臂取/放 GPU 锁，`sleep 65` 后释放（§20.1）。评测纯推理 **1.4 min**，取锁整程持锁（<15 min）。
- **共享卡占用（§20.3）**：跑前 `nvidia-smi memory.free` 记 **10595 MiB**（外部常驻 llama-server），
  实测 **72.0 ms/step**（与空卡 2626 的 72.3 同 ⇒ **未被显著拖慢，故不改步数**），
  跑后 **19438 MiB** 空闲 ⇒ 余量始终 ≥8GB（§20.2）。峰值 **4995.8 MB < 5GB**，未触礼貌线。
- **算力价签**：`l1@K8` 与 `repr01@K8` 都是 **8× 前向/token**；两次读数算力相同 ⇒ 抖动是纯训练抖动。

## 10. 未测项与下一步（显式，按价值排序，均给成本）

1. **`l1` 臂自身的 run-to-run 抖动未被覆盖**（本实验固定 `l1@K8`）⇒ 极差是**下界**。最小实验：
   同配置重跑 `l1` 一臂（13M、24k）**≈28 min**，给出「净效应抖动的完整两臂口径」。
2. **50M 的 0.0322 缺口不被本实验覆盖**（`SCHEMA §23` 第 6 问）：本实验只做 13M；50M 的机制净效应
   是否同样稳健**未测**。最小实验：50M `l1`/`repr01` 各跑到 ~48k 步，≈4–5 h（需与主 Agent 议预算）。
3. **其他 seed 未测**：本实验只做 seed=0。补 seed=1/2 的 `repr01`（各 13M、24k）≈ 2×28 min，
