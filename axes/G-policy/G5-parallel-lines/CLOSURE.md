## 0. 一句话（人话）

给一个共享主干装上「多条随机路径」，推理时把这多路预测平均起来，理论上比单线更准。**测下来：这个机制
在 13M 上真的让路径更不相关（机制存在），但在 50M 上没能去相关（机制失效）；而在最要紧的那条线上——
「多路平均到底能不能打赢同预算的单线」——13M 和 50M 两档都输，而且要多付 8 倍推理算力。**
13M 那份「机制有效」还**贴在门槛上且稳健性未定**（重跑一遍的抖动就有效应的一半）。
⇒ **这条路线在当前形式下没有部署价值，本格收口。**

## 1. 已测事实（逐条，带证据锚点）

### 1.1 机制「存在」：13M 有、50M 无

- **13M 机制成立**（ticket 39-X1，`experiments/2622-decorrelation-v2/`）：修掉 gate 跳过混杂、
  并把去相关从「输出层 −JS 罚则」换成**表征级**（两条随机路径隐状态的跨路径 Pearson 相关罚则）后，
  机制被分离出来——λ=0.1 时成对 JS **0.0249 → 0.0361**（路径确实更不相关）、clean 税 **−0.0042**
  （去相关反而轻微微改善单线质量）、`l1@K8 − repr01@K8 = +0.0246` > 方差带 ⇒ **按预登记规则放行 50M**。
- **50M 机制失效**（同实验）：**符号翻转**——成对 JS **0.0322 < l1 的 0.0333**（路径并未更不相关）、
  `l1@K8 − repr01@K8 = −0.0100` < 0.014（落在不可排序带）⇒ **该机制在 50M 不成立**。

### 1.2 机制「熬过收敛」但结论贴门槛；补测两臂后**稳健性未定**

- **24k 收敛点**（ticket 43-V2，`experiments/2626-mechanism-convergence/`）：24k 终点机制净效应
  `l1@K8 − repr01@K8 = +0.0144`（配对 CI [−0.0158,−0.0130] 不含 0），而 `§17.14` 的不可排序门槛是
  **0.014** ⇒ **只高 0.0004（≈3%）**。同实验主判据 24k = **+0.0346**（CI [0.0298,0.0407]），
  且判据量末窗斜率 −0.001/1k ⇒「多线回不了本」**不是没练够**。
- **抖动补点（下界口径）**（ticket 44-X1，`experiments/2627-mechanism-jitter/`）：只重跑 `repr01` 臂
  （`l1@K8` 固定复用 2626）⇒ 极差 **0.0035** ⇒ 一度「升格稳健」。
- **抖动补全（两臂口径）**（ticket 45-G1，`experiments/2628-jitter-l1/`）：补跑 `l1` 基准臂 ⇒
  `l1_A@K8 = 1.4089` → `l1_B@K8 = 1.4163`，**`l1` 自身抖动 0.0074**；**两臂合并极差（取大）= 0.0074
  = 效应 0.0144 的 51%** ⇒ 按**同一条预登记规则**（≥0.0144 降级 / <0.005 升格 / 其余 `on_threshold`）
  判 **`on_threshold`（仍贴门槛 / 未决）** ⇒ **44-X1 的「稳健」撤销**。
- **机制并没有消失**（同实验）：两臂 × 两次读数做 2×2 组合，净效应 **0.0144 / 0.0179 / 0.0218 / 0.0253
  全部 ≥ 门槛**，无一次跌破。
- **范围（禁外推，`§17.11`）**：以上只限 **13M / seed=0 / enwik8**；n=2 只报极差，不报分布外推。

### 1.3 部署判据（主判据）**两规模都不过**

- **判据（`§11` 诚实对手）**：多线 K=8 集成 vs **同 token 预算的单线 stock** 比 clean bpc（越低越好），
  CI 不得重叠。**不是**和 oracle / 真值比。
- **读数**：**13M 最好 λ 下 +0.1052**、**50M +0.0322**（CI 均排除 0）⇒ **两档都判「多线更差」**；
  代价恒为 **8× 推理算力**（K=8 次要前向/token）。
- **尺度方向（如实报反例一侧）**：路径随机化的**机制税随规模缩小 54%**（13M +0.1748 → 50M +0.0810）
  ⇒「多线本身的代价」在大规模变小；但**部署缺口在 50M 仍剩 +0.0322**，远大于门槛 ⇒ 方向虽有利，**未跨越**。

### 1.4 判据质量护栏（已做，缺一不可）

- **确定性路径对照 = 0.0000**：8 条路径 logits 逐位相同 ⇒ 集成增益只来自「路径真的不同」，
  不是「多算几次 / softmax 平均这个动作」。
- **跨运行复现 6/6 逐位相同**（2628）⇒ run-to-run 抖动只来自训练、不含评测；200-batch 独立协议同向佐证
  （`l1` +0.0061 / `repr01` −0.0037）。
- **参照线（`§21`）**：独立训练多模型（deep ensembles）是**已知有效**的去相关源、代价 N× 推理；
  本格实测的两个「便宜替代」（capped−JS 罚则、表征级去相关）**都没能跨过 N×**。

## 3. 结论句（正式收口判断）

> **建议收口为：「机制存在但稳健性未定；部署判据两规模均不过 ⇒ 该路线（多线 K 路集成）在当前形式下无部署价值。」**
>
> - **机制**：13M 存在（路径确实更不相关）、50M 失效（没能去相关）；13M 净效应在 24k 收敛点 **+0.0144**，
>   但两臂 run-to-run 抖动 **0.0074 = 效应 51%** ⇒ **`on_threshold`（稳健性未定）**。
> - **部署**：同 token 预算的诚实单线在 **13M（+0.1052）** 与 **50M（+0.0322）** 都赢，且多线要付 **8× 推理**。
> - **两句话不矛盾**（`§17.17` 的关键区分）：「机制在 13M 有效（集成增益 > 0 且 clean 税近零）」与
>   「多线回不了本」可以同时为真——这是**「机制有效但代价抵消」**，**不是「机制无用」**。
> - **因此**：本格**不得**读作「多线不可能」（`§19`），只读作**「在当前形式 / 当前两个尺度 / 当前推理预算下不划算」**。

## 4. 什么新证据会重开该格（判据线，预登记）

> 任一成立即**重开**；全部可证伪，且必须满足：预登记判据 + 诚实对手（`§11`）+ CI 不重叠 + 禁外推（`§17.11`）。

1. **部署判据在 ≥2 档规模一起跨过**：多线 K 路集成相对**同 token 预算单线**的缺口由正转负，且 ≥2 档规模
   CI 都不重叠、|Δ| > 0.014 方差带。（当前两档都 +0.03 以上 ⇒ 要求**方向反转且越过门槛**。）
2. **换掉 8× 推理代价**：出现能把 K 路集成压到 ~1× 推理成本（或 ~1× 前向）而质量不塌的做法 ⇒
   判据的「代价侧」实质改变（这属**新方法**，不是旧路的补点）。
3. **机制稳健性升格**：≥2 个 seed 下 `l1`/`repr01` 两臂合并极差 **< 0.005**（按 2627 `§4` 预登记规则升格「稳健」），
   **且**同规模部署缺口仍为正（用来证明「机制稳健 ≠ 部署可用」）。——这条不改部署结论，只把 §1.2 的
   `on_threshold` 定死。
4. **机制在 50M 复现**：换一种去相关源（非 capped−JS）在 50M 让成对 JS **> l1**、且
   `l1@K8 − repr01@K8` > 2× 方差带（≥0.028），**并同时报部署判据**。
5. **`carry × GQA × non-dense` 组合实验判负**：若多线收益在该产品级非 dense 路径上**消失或反转**
   ⇒ 与本格现有失败方向一致 ⇒ **加深收口（不重开）**。
6. **对账更正**：任何对锚点实验（2622 / 2626 / 2628）的 `ERRATA` 使部署缺口落回方差带内 ⇒ **立即重开**。

**不构成重开理由**：单点 / 单 seed / 单规模的有利读数（`§17.11` 禁外推）；与 oracle 类的比较（`§11`）；
只报净和不报分量（`§17.17`）；判决腿落在训练分布外且同配置重跑方差 ≥ 结论效应（`§17.18`）。
