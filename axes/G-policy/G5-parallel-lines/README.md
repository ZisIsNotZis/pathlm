# G5-parallel-lines · 并行多线机制

> 轴：**G 策略与调度** ｜ 状态：**✅ judged**

> **判读**：**收口（两规模 + 24k 收敛点，预登记判据）**：多线设想的**机制**在 13M 成立、在 **50M 失效**，而**部署判据两个规模都不过**（8× 推理算力仍输同 token 预算单线：13M 最好 λ 下 +0.1052、50M +0.0322，CI 均排除 0）⇒ **该路线在当前形式下无部署价值**；未测项（13M 收敛后、λ 细扫、50M λ=1.0）已列明成本。**【2026-10-02 用户 review：本格的「多线」是执行方**自设命题**（同一主干采 K 条随机跳层路径再集成），**不是**用户要的投机解码；用户判定该类跳层集成**无意义且多花算力** ⇒ 结论在自设命题下保留，但本格**不得**再代表「多线 / 投机」线；真正的投机研究缺口见 `docs/OPEN_PROBLEMS.md` P-02。】

## 1. 命题

如何同时推进多条概率线并合并——引擎与调度的核心格。

## 2. 选项枚举（本格全部可能取值）

1. `单线（贪心）`
2. `beam search`
3. `多路共享主干`
4. `去相关 voter（显式训练多样性）`
5. `verifier 重排`

## 3. 状态（我们做了什么 / 行业做了什么）

**本地已测**：13M：DIVL1 同时改善 baseline 与集成斜率（−0.062 > −0.047）——**该收益在 50M 反转**（去相关税由 −0.0086 变 +0.0710 且线间更相似，见 failure）；路径随机化**机制税随规模缩小 54%**（+0.1748 → +0.0810）

**行业口径**：见 `docs/playbook.md` 与参照线 `R-references/`。

## 4. 结论与数字

- **税**：**去相关税（ERRATA 更正）**：battery 口径 **13M −0.0086 / 50M +0.0710**（capped −JS 压力）；旧文写的 +0.023 是**误标**——0.0227 实为 `L1@K8 − DIVL1@K8`（去相关臂集成更好的**收益**），已更正
- **收益**：13M：DIVL1 同时改善 baseline 与集成斜率（−0.062 > −0.047）——**该收益在 50M 反转**（去相关税由 −0.0086 变 +0.0710 且线间更相似，见 failure）；路径随机化**机制税随规模缩小 54%**（+0.1748 → +0.0810）
- **判读**：**收口（两规模 + 24k 收敛点，预登记判据）**：多线设想的**机制**在 13M 成立、在 **50M 失效**，而**部署判据两个规模都不过**（8× 推理算力仍输同 token 预算单线：13M 最好 λ 下 +0.1052、50M +0.0322，CI 均排除 0）⇒ **该路线在当前形式下无部署价值**；未测项（13M 收敛后、λ 细扫、50M λ=1.0）已列明成本。**【2026-10-02 用户 review：本格的「多线」是执行方**自设命题**（同一主干采 K 条随机跳层路径再集成），**不是**用户要的投机解码；用户判定该类跳层集成**无意义且多花算力** ⇒ 结论在自设命题下保留，但本格**不得**再代表「多线 / 投机」线；真正的投机研究缺口见 `docs/OPEN_PROBLEMS.md` P-02。】

## 5. 失败路径与原因

1. **规模判决（ticket 37-V3，50M=5184 万参数、stock→l1→divl1 阶梯，各 9830 万 token 同 seed）**：实测 divl1 的 8 路径集成 1.5620 vs 单线 1.4505，**差 0.1115（CI 不重叠）**——这是**快照结论**；但**不得**表述为「即使去相关完全不起作用也输」，因为 `l1@K8`(1.4727) 与 `stock@K1`(1.4505) 的缺口 0.0223 与 13M 实测的去相关收益 0.0227 同量级 ⇒ **符号未排除**（R1 P1）；且该臂 gate 跳过 42.7% 步
2. **参照线（§21，业界已知）**：独立训练多模型（deep ensembles）是已知有效去相关源、代价 N× 推理；**未定论的是「便宜替代能否跨过 N×」**——我们唯一实测的便宜替代（capped-−JS 训练罚则）在该设定下判负（且其税随规模由 −0.0086 变 +0.0710、成对 JS 由 0.0333 降到 0.0250，即**没能去相关**）
3. **下一步唯一决定性实验（K9 建议，预算 ≈60 min）**：修掉 gate 跳过混杂（保证该臂吃满更新）+ 换成**表征级**去相关（而非输出 JS 罚则），预登记判据 = (K 路径集成 − 单线) > 0 且 CI 不重叠。**在该实验出结果前，本格不得收口。**
4. **机制结论：仍贴门槛／未决（ticket 45-G1 推翻上一轮的『稳健』）**：44-X1 只重跑 `repr01` 得到极差 **0.0035**（下界口径）并据此升格为稳健；**45-G1 补跑 `l1` 臂后，`l1` 自身抖动 = 0.0074 ⇒ 两臂合并极差 0.0074 = 效应的 51%** ⇒ 按预登记规则（极差 ≥0.0144 降级 / <0.005 升格 / 其余 on_threshold）判 **`on_threshold`** ⇒ **上一轮「升格为稳健」撤销**。未消失的证据：四种 2×2 净效应组合全部 ≥ 门槛（0.0144/0.0179/0.0218/0.0253）⇒ 机制没消失，但**稳健性未成立**。仅 13M/seed=0；50M 的 0.0322 缺口未覆盖
5. **（已被 45-G1 撤销）44-X1 的下界口径读数：**：run A **+0.0144** / run B **+0.0179**，**极差 0.0035（仅效应本身的 ~1/4）**，按跑前预登记规则（极差 <0.005 ⇒ 升格）⇒ **V2 的「机制熬过收敛」从『贴门槛』升格为『稳健』**（两次读数都在门槛之上）。护栏：① 跨运行复现权重逐位相同（抖动只来自训练、不含评测）；② 独立 200-batch battery 协议佐证 −0.0037（同向同量级）；③ §17.17 分量分解显示两次都是『集成增益>0 且 clean 税近零』⇒ 无「机制无用」解读空间；④ 极差为**下界口径**（`l1@K8` 复用 2626）、仅 13M/seed=0，**50M 的 0.0322 缺口未覆盖**
6. **收敛后定论（ticket 43-V2，三臂 24k＝4× 训练量）**：**机制熬过收敛但贴在门槛上**——24k 终点「无去相关臂的 8 路集成」比「去相关臂的 8 路集成」差 **+0.0144 bpc**（配对 CI [−0.0158,−0.0130] 不含 0），而 §17.14 的不可排序门槛是 0.014 ⇒ **只高 0.0004**；四点轨迹 @6k **−0.0063（反转）** → @12k +0.0147 → @18k +0.0150 → @24k +0.0144（12k 后稳定）。**主判据 24k = +0.0346**（CI [0.0298,0.0407]），四点 0.1102→0.0554→0.0406→0.0346 ⇒ 仍差 0.0346 且要 8× 推理。**判据量已基本收敛**：主判据缺口末窗斜率 **−0.001/1k**（X1 的 6k 窗口为 −0.060/1k，小 60×）、机制净效应斜率 −0.0001/1k ⇒「多线回不了本」**不是没练够**。**口径事实（如实标注）**：`train_m1.py` 的 cosine 按总步数归一 ⇒ 本实验 @6k 是 24k 调度的中途（lr≈0.868×base），与 X1 的 6k（lr→0.1）**不可逐位对照**，未伪报一致。**门槛风险**：机制结论只高门槛 0.0004 ⇒ 已排 run-to-run 抖动补点（ticket 44-X1）
7. **决定性实验（ticket 39-X1）**：**修掉两个混杂后机制被分离**——(i) gate 跳过混杂已修（pre-step gate 只对**非有限**梯度跳过，`clip_grad_norm_` 处理有限大值；所有臂 `gate_skips=0`、观测数=总步数）；(ii) 罚则换成**表征级**（两条随机路径隐状态的跨路径 Pearson 相关罚则，取代 2620 的 capped −JS 输出罚则）。结果：**13M 机制成立**（λ=0.1：成对 JS 0.0249→**0.0361**、clean 税 **−0.0042**（反而改善）、`l1@K8 − repr01@K8 = +0.0246` > 方差界 ⇒ 按预登记规则放行 50M）；**50M 机制失效**（JS 0.0322 **<** l1 的 0.0333，路径并未更不相关；`l1@K8 − repr01@K8 = −0.0100` < 0.014 不可排序）⇒ **收口**
8. **部署判据（主判据）两规模都不过**：多线 K8 集成 vs 同 token 预算单线 stock——13M 最好 λ 下 **+0.1052**、50M **+0.0322**（CI 均排除 0），且代价是 **8× 推理算力**
9. **未测项（§23 第 6 问，含成本）**：① 13M 跑到 24k 看机制净效应是否熬过收敛（≈30 min）；② λ ∈ {0.03, 0.3} 细扫税/增益权衡；③ 50M 的 λ=1.0 与「收敛后的 50M 机制」（显式未测）。**注意**：即使 ① 成立，主判据在 50M 的缺口仍有 0.0322 未跨越
10. **机制诊断（V3）**：路径随机化机制税随规模**缩小 54%**（13M +0.1748 → 50M +0.0810），但**去相关训练反而更贵**（−0.0086 → **+0.0710**）且**没能去相关**——成对 JS 从 l1 的 0.0333 掉到 divl1 的 **0.0250**（更像了）⇒ capped-−JS 不是有效去相关源
11. **确定性路径对照恰好 0.0000**（8 条路径 logits 逐位相同，60/60 批）⇒ 集成增益只来自「路径真的不同」
12. **未排除的解释（V3 如实声明）**：divl1 臂的 grad-norm 门跳过 5121/12000 步（42.7%）、实际约 6900 次更新 ⇒ 「去相关税为何变贵」三解释未排除（罚则有害/欠训练/权重不适配大规模）；**主判据仍是「快照结论」**：它不依赖 divl1 的训练质量（对照用的是 l1 的 8 路径集成，与 divl1 的 gate 无关），故 `−0.1115 ⇒ 50M 仍不成立` 有效；但**不得**据此声称上述三条未排除解释已被排除——它们只影响「去相关税为何变贵」这一附属问题
13. 共享 trunk 的 voter 太相关：集成增益仅 +0.0008~+0.0015（可忽略）
14. 确定性路径 checkpoint 的 K-path 集成恰好得 0（8 条路径 logits 逐位相同）——**【2026-10-02 更正（C9）】不能由此推出「beam search 产出的多线也落在死区」**：beam 的候选**前缀不同**，与「同一路径的确定性重复」不是同一命题；本实验**不否证** beam
15. 深度集成失败：置信头只排序深度、不排序逐 token 可靠性

## 6. 判据与判决实验设计

- **判据**：质量增益（同 FLOPs）+ 线间相关度 + 每线边际收益曲线
