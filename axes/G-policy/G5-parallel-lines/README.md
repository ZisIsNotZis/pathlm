# G5-parallel-lines · 并行多线机制

> 轴：**G 策略与调度** ｜ 状态：**◐ partial**

> **判读**：**实测结论（快照）**：13M 与 50M 上，我们**已测的**多线臂都输给同 token 预算的单线（50M：divl1@K8 1.5620 vs stock@K1 1.4505，差 0.1115，CI 不重叠）；但**「去相关若真起作用、能否补上缺口」未排除**——13M 实测去相关压力让 K=8 集成**更好** +0.0227（DIVL1@K8 1.6227 < L1@K8 1.6454），与 50M 的缺口 0.0223 **同量级**，而 50M 该臂的 gate 跳过 42.7% 步、实际只学约 6900 步 ⇒ **主判据的符号未定**（R1 复核 P1）。因此本格状态为 partial：机制问题（有效的去相关源）仍开放。

## 1. 命题

如何同时推进多条概率线并合并——引擎与调度的核心格。

## 2. 选项枚举（本格全部可能取值）

1. `单线（贪心）`
2. `beam search`
3. `多路共享主干`
4. `去相关 voter（显式训练多样性）`
5. `verifier 重排`

## 3. 状态（我们做了什么 / 行业做了什么）

**本地已测**：13M：DIVL1 同时改善 baseline 与集成斜率（−0.062 > −0.047）——**该收益在 50M 反转**（去相关税由 −0.0086 变 +0.0710 且线间更相似，见 failure）；路径随机化**机制税随规模缩小 54%**（+0.1748 → +0.0810）

**行业口径**：见 `docs/playbook.md` 与参照线 `R-references/`。

## 4. 结论与数字

- **税**：**去相关税（ERRATA 更正）**：battery 口径 **13M −0.0086 / 50M +0.0710**（capped −JS 压力）；旧文写的 +0.023 是**误标**——0.0227 实为 `L1@K8 − DIVL1@K8`（去相关臂集成更好的**收益**），已更正
- **收益**：13M：DIVL1 同时改善 baseline 与集成斜率（−0.062 > −0.047）——**该收益在 50M 反转**（去相关税由 −0.0086 变 +0.0710 且线间更相似，见 failure）；路径随机化**机制税随规模缩小 54%**（+0.1748 → +0.0810）
- **判读**：**实测结论（快照）**：13M 与 50M 上，我们**已测的**多线臂都输给同 token 预算的单线（50M：divl1@K8 1.5620 vs stock@K1 1.4505，差 0.1115，CI 不重叠）；但**「去相关若真起作用、能否补上缺口」未排除**——13M 实测去相关压力让 K=8 集成**更好** +0.0227（DIVL1@K8 1.6227 < L1@K8 1.6454），与 50M 的缺口 0.0223 **同量级**，而 50M 该臂的 gate 跳过 42.7% 步、实际只学约 6900 步 ⇒ **主判据的符号未定**（R1 复核 P1）。因此本格状态为 partial：机制问题（有效的去相关源）仍开放。

## 5. 失败路径与原因

1. **规模判决（ticket 37-V3，50M=5184 万参数、stock→l1→divl1 阶梯，各 9830 万 token 同 seed）**：实测 divl1 的 8 路径集成 1.5620 vs 单线 1.4505，**差 0.1115（CI 不重叠）**——这是**快照结论**；但**不得**表述为「即使去相关完全不起作用也输」，因为 `l1@K8`(1.4727) 与 `stock@K1`(1.4505) 的缺口 0.0223 与 13M 实测的去相关收益 0.0227 同量级 ⇒ **符号未排除**（R1 P1）；且该臂 gate 跳过 42.7% 步
2. **参照线（§21，业界已知）**：独立训练多模型（deep ensembles）是已知有效去相关源、代价 N× 推理；**未定论的是「便宜替代能否跨过 N×」**——我们唯一实测的便宜替代（capped-−JS 训练罚则）在该设定下判负（且其税随规模由 −0.0086 变 +0.0710、成对 JS 由 0.0333 降到 0.0250，即**没能去相关**）
3. **下一步唯一决定性实验（K9 建议，预算 ≈60 min）**：修掉 gate 跳过混杂（保证该臂吃满更新）+ 换成**表征级**去相关（而非输出 JS 罚则），预登记判据 = (K 路径集成 − 单线) > 0 且 CI 不重叠。**在该实验出结果前，本格不得收口。**
4. **机制诊断（V3）**：路径随机化机制税随规模**缩小 54%**（13M +0.1748 → 50M +0.0810），但**去相关训练反而更贵**（−0.0086 → **+0.0710**）且**没能去相关**——成对 JS 从 l1 的 0.0333 掉到 divl1 的 **0.0250**（更像了）⇒ capped-−JS 不是有效去相关源
5. **确定性路径对照恰好 0.0000**（8 条路径 logits 逐位相同，60/60 批）⇒ 集成增益只来自「路径真的不同」
6. **未排除的解释（V3 如实声明）**：divl1 臂的 grad-norm 门跳过 5121/12000 步（42.7%）、实际约 6900 次更新 ⇒ 「去相关税为何变贵」三解释未排除（罚则有害/欠训练/权重不适配大规模）；**主判据仍是「快照结论」**：它不依赖 divl1 的训练质量（对照用的是 l1 的 8 路径集成，与 divl1 的 gate 无关），故 `−0.1115 ⇒ 50M 仍不成立` 有效；但**不得**据此声称上述三条未排除解释已被排除——它们只影响「去相关税为何变贵」这一附属问题
7. 共享 trunk 的 voter 太相关：集成增益仅 +0.0008~+0.0015（可忽略）
8. 确定性路径 checkpoint 的 K-path 集成恰好得 0——beam search 产出的多线正落在这个死区
9. 深度集成失败：置信头只排序深度、不排序逐 token 可靠性
