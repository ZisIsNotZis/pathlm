### ① 这个课题是什么（我自己的话）
改「每一层怎么把状态往前推一步」：从标准的 `h + Δ(h)` 改成带上一个**逐通道门**的 `h + g(h)⊙Δ(h)`（g 由该层输入算出、负偏置初始化到 ≈0.12 恒等起步），以此支撑「任意深度都能读出一个可用的答案」。

### ② 对着什么 sota，我们偏离在哪
- 门控残差 / Highway / ReZero / GLU 门是业界标准件；把门做成**输入条件化**（`g=σ(W·h+b)`）与 MoD/条件化（AdaLN）同族。本地增量声明是「这个门在同空间精化形态下是形态税的承载者」。
- **偏离 1（能力面，最要紧）**：本引擎**没有「门关、其余不变」的开关**。`train_depth_ar.py:282-285,453` 里唯一的 `--dense` 一次性关掉**门 + 随机退出 + 混合填充 + 全深度监督**四件。因此「门是税承载者」无法被单因素臂验证。
- **偏离 2（设计意图未兑现）**：catalog 的「渐进开门」假设在 100M **反了**：门从初始化 0.119 **收小**到 g0≈0.070、深层 0.006–0.011（`.scratch/24-depth-ar-100m/evidence/100m-s0/gate_log.jsonl`、`24b-eq-s0/gate_log.jsonl:96-101`）。也就是说 100M 下的「精化」实际上是「layer 0–1 的小门 × 大 delta」，深层门趋近恒等。

### ③ 五类问题逐条判定
**1 开倒车：部分。** 门控本身是业界标准；「门让极深网络可训」是既有结论。本格真正的问题不是开倒车，而是把「形态税的承载者」挂到一个没有隔离对照的机制上。

**2 过程错误：有——缺隔离对照 + 链式分解被后续数据推翻。**
- `catalog.yaml:584` 的税声明来自 `23c` 的链式分解 `.scratch/23-depth-ar/evidence/23c-decomposition.json`：「门+退出+填充 +0.4285（vs `nofill` 2.2496 ⇒ **门本身 +0.228**、退出+填充 +0.200）」。我复算了这一项：2.2496 − 2.0216 = 0.2280 ⇒ **「门」是余项，不是被隔离量出来的**（nofill 与 W0 同时差着「随机退出采样 + 填充」两件事）。
- 更关键：被当作常数的「退出+填充 +0.200」在 matched 12k 下**反号**——`23e`（`.scratch/23-depth-ar/evidence/SUMMARY.md §12`）：`nofill − fill = +0.0856`，即 fill 是**负分量（-0.0856）**。因此 3.6k 那次「门 +0.228」的推导前提已废；12k 只剩「门/填充合计 +0.222」（`23d-decomposition.json::gate_exit_fill_inherent_12k`），门自己的份额**仍未测出**。
- `23c` 自己也在 §10 写明「链式分解依赖加入顺序，2×2 缺两角（dense+aux-stopgrad、门堆栈+w=0）」。

**3 结论错误：有。** 正确结论应是：**「门 / 随机退出 / 混合填充这个堆栈在 aux 对齐下合计 +0.222 bpc（12k，且 3.6k→12k 仍在收缩，未平台化）；其中门的份额未测出。门在 100M 从 0.119 收小到 ~0.007，说明『渐进开门』这一结构假设未兑现。」** 现在的 `catalog.yaml:584` 把「之一」写成结论，缺了未测声明。

**4 无意义：无。** 若这 0.22 bpc 能被拆掉（例如门可换成裸残差），整条 C 线的价值判断会翻转 ⇒ 这是**最值得做**的一格。

**5 值得做：是，而且最便宜。** **现成的 `23d-H1-12k`（dense trunk + 全深度 aux、无门/退出/填充）只缺一次 `tf@4` eval（≈5 min）**：它的 `results.json` 里没有 `tf_acceptance` 字段（我查过：只有 `depth_curve` / `bpc` / `dense_aux: true`）。这个数字直接回答「出口资产是不是必须靠门堆栈才能拿到」。

### ④ 建议动作
**补做 + 重做（不删除）：**
1. **补 `tf@4`/`tf@6` 到 `23d-H1-12k`**（≈5 min，纯推理）——判决「出口资产能否不付门堆栈的税」。
2. **加一臂 gate-off（g≡1，保留随机退出 + 填充 + aux）**，12k，≈10 min——唯一能隔离门税的臂。
3. 在 100M 至少加**一个** gate-off 或 `--dense --dense-aux` 臂，让「门堆栈 +0.22」在 100M 有对应点。
4. 修 `catalog.yaml:584` 的措辞（加「未隔离测量」）。

### ⑤ 正确的验证方式
- **该涨**：clean bpc（同深度读出）；`tf@k`（出口资产）；门的活性量（逐层 `gate_mean`、每 200 步一行落盘——这条已合规）。
- **该跌**：`gate_mean` 本身（若「渐进开门」成立，浅层 g 应上抬；实测 100M 全层收小，这是该假设的反证，应作为「该跌」的观测点写进契约）。
- **必须不变**：除门以外一切逐字段相同；`g≡1` 与 dense 在同接线/同填充下的等价性（可失败单测钉住）；深度-bpc 曲线单调性；活性量与训练日志逐点可对。
