## 0. 人话摘要（先看这段）

**这件事要做的是什么**：语言模型的注意力只看最近 16 个位置时，更早的内容就再也看不到了。本实验
在同一条任务、同一份 token 预算、同一份可见性下，正面对撞两条补回来的路——**implicit**（什么都不加，
只把可见性缩到最近 16，逼模型把有用的信息留在近处）与 **explicit**（给每层一个固定大小的「本子」，
每层把自己的内容写进去、按自己的问题读出来；这叫完备机制）。

**结论先给**：**explicit 完备机制在「质量」和「可检索性」两条腿上都真的把窗口外的信息搬回来了，
而且不是噪声；implicit 这条腿则完全停在原地。** 但它只在一个具体配置（逐层独立状态 + γ=1）上成立，
换配置（γ=0.99）或换退化实现（12 层共用一个状态）就站不住——所以这是「设计对不对」的问题，
不是「机制完全不行」，也不是「随便怎么配都行」。

**质量腿（clean bpc，越低越好）**：完备机制臂 `carrypl16_s0` = **1.527595**，同窗口的 implicit 臂
`win16_s0` = **1.628110**（`quality_leg.*.bpc_win16`），即完备机制**好 0.100515 bit/字符**
（配对 CI [0.094630, 0.106286] bit，`effects.explicit_minus_implicit` 第 1 项）。
人话量级：这个差值 = 本格自测噪声带 σ_cell（0.001661）的 **60 倍**、跨格参考带（0.014）的 **7.2 倍**；
作为参照，`2639` 记录的「窗口 16 → 全量 attention」差距是 0.125421 bit（`1.1.4.1-explicit-memory/project.yaml`
conclusion 正文；等价地全量锚 ≈ 1.628110 − 0.125421 = 1.502689），所以完备机制**补回了这段差距的
80.1%**，而它花的内存是每位置 393,216 B（= 窗口 32 的字节数，其中 196,608 B 是那个固定状态，
与序列长度无关）。`2639` 把它记成人话是「质量约等于窗口 111 的纯注意力，只花窗口 32 的内存」。

**可检索性腿（needle 召回，越高越好）**：在**同索引硬子集**上——即六条臂在「不插针」条件下**全都答不出**
的那 2699 根针，这批针上地板恒为 0（`needle_leg.hard_subset_same_index_cross_arm.intersection`）——
完备机制答出 **10.226%**（276/2699，Wilson 95% CI [9.139%, 11.426%]），而 implicit 的两条臂分别只有
**0.704%**（19/2699）与 **1.000%**（27/2699）。对撞差 = **+9.522 pp**，两比例差（正态近似/未 pooling） 95% CI
**[8.336, 10.708] pp**（`…intersection.explicit_minus_implicit.carrypl16_s0_minus_win16_s0`）；
本 worker 用 `needle_raw.json` 独立复算该子集（19/27/276 根，逐位一致）并做配对 bootstrap，得
**[8.315, 10.606] pp**，与记录值同结论。人话量级：这批针的盲猜概率 ≈ 1/206 = **0.49%**，
implicit 是它的 1.4–2 倍（等于没有记忆），完备机制是它的 **21 倍**、是 implicit 臂的 **15 倍**；
但**它也只答出约十分之一**——搬是搬回来了，搬回来的只是一小部分。

**负对照（该跌的跌了）**：implicit 两臂在整体 beyond 桶上相对各自的配对地板是 +0.049 pp
（CI [−1.480, 1.577] pp）与 −0.135 pp（CI [−1.665, 1.396] pp），**CI 都含 0**，即逐位复现了 `2634`
的读法「无区分力」（`needle_leg.judgement.per_arm`）。

**仪器有效性（前提）**：无通道臂对被毁前缀**逐位不敏感**（`max_abs_logit_diff_on_eval_rows` = 0.0，
`far_source_probe.win16_s0/win16_s1`），而完备机制对同一被毁前缀敏感 **+0.032965 bit**
（逐簇配对 bootstrap CI [0.026986, 0.038727]）；把通道读出增益置零（`channel_off`）后，这份敏感度
**精确回到 0.0** ⇒ 被毁前缀只能经显式状态到达被评行，这条因果链是闭合的。

**代价与边界（不许外推的部分）**：完备机制比纯窗口臂多 264,296 参数（+1.95%，`selfchecks`）；
**完备臂只有 seed 0 一个 checkpoint**（`train_meta` 只有 `carrypl16_s0`/`carrypl16d_s0`），所以
上面所有「完备机制 vs implicit」的差值都没有训练种子重复——CI 量的是针的抽样不确定性，**不是**
checkpoint 的不确定性；同一个完备机制换 γ（γ=0.99 时 T=256 下只留 7.6% 历史）后召回从 10.2%
掉到 2.9%，说明配置敏感度大于 CI。只适用于 enwik8 / T=256 / 13M / 12k 步 / 该可见性快照。

## 1. 六个必答问题

1. **它是干什么的**：在不扩大注意力窗口的前提下，让模型把「窗口外看过的内容」留下来，
   需要在预测下一个字节时取回来用。本实验比的正是两条路：**implicit 路**（只把可见性压到
   最近 16 个位置，逼模型自己把信息留在近处）与 **explicit 路**（额外给模型一个固定大小的
   本子：每层把内容写进去、每层按自己的问题读出来）。
2. **相对普通 decoder-only transformer 改了什么**：
   - implicit 臂 = **零新增参数**：主干与普通 transformer 逐位相同，只改注意力可见掩码
     （每个 query 只看最近 16 个位置）。
   - explicit 臂 = 主干不动，在每层注意力输出后加一路记忆读出 `a ← a + γ_ℓ ⊙ (S_ℓ q_t)`；
     完备版（E1）给**每层一个自己的状态**、写门 `β` 与键/值都取自**该层当前 hidden**、
     状态按 delta 规则写 `S ← γS + β(v − S k̂)k̂ᵀ`。改动量级：**+264,296 参数（+1.95%）**；
     状态 **12×8192 = 98,304 floats**（= 每位置等效 196,608 字节，与序列长度无关）。
3. **为什么要改**：注意力窗口外的信息对 implicit 路**结构上不可达**（这是隐式的全部代价）；
   explicit 路用一个与长度无关的载体去承接这些信息，是长上下文账单有界的候选途径。
   痛点是**质量-内存权衡**，本实验量的是它的**可检索性**那一半。
4. **怎么测的**：**同任务、同 token 预算、同可见性、同一台仪器**（`2634` 的仪器逐字节复制），
   在同一批已训练 checkpoint 上做纯推理对比。对照 = 同窗口 16 的**无通道**臂（implicit，
   两个种子）；干预 = 显式臂（`carrypl16_s0` 完备机制为主，`carrypl16d_s0` γ=0.99 并列，
   `carry16_*` 退化的单共享槽作完备度对照）。指标与口径：
   ①**毁源敏感度** `Δbpc_far`（把被评行 180 个位置之前的窗**外**前缀换成随机字节，看被评行
   损失变化；无通道臂必须**逐位不敏感**——这是仪器有效的前提）；
   ②**needle v3 短语针召回**（`beyond` 桶 vs 配对无针地板，并在**同索引硬子集**上做跨臂比较）；
   ③**clean bpc**（窗口 16 掩码，96×16 窗口序）与既有记录值逐位复现；④因果性。
5. **测出来多少**：见下表（每格都在 `results.json` 有键路径；标签栏给键路径）。

   ——质量腿（+0.100515 bpc，CI 排除 0）与可检索性腿（硬子集 +9.522 pp，CI 排除 0）同向且都被

## 3. 臂内噪声带与读法（σ_cell 为主、0.014 为参考）

- **本格自测带 σ_cell = 0.001661 bpc**（`sigma_cell.bpc_win16`，取 `carry16_s0|carry16_s1` 的
  配对极差；`win16_s0|win16_s1` 极差 0.000983 更小）。它是**同配置换训练种子**的 2 样本极差
  ⇒ 描述量，不是方差上界，也不是任何单臂的置信区间。
- **跨格参考带 0.014 bpc**（`criteria.bands.cross_cell_source` = `harness/methodology.md` 的 13M 跨 run
  漂移界，限配对 Δ、≥5 窗口）。两带**并列报、不得混用**（`criteria.bands.rule`）。
- bpc 类读数按两带并列给量级（不作判据；判据是逐一配对 Δ 的 CI）：
  - `carrypl16_s0 − win16_s0` = +0.100515 = **60.5× σ_cell** = **7.2× 0.014** → 远出双带。

## 6. 未测项与下一步最小实验

- **完备臂的种子重复（最高优先）**：`carrypl16_s0` 只有 seed 0 ⇒ 主对撞的差值没有训练种子重复，
  而 γ=1/γ=0.99 之间 3.6× 的召回差说明配置敏感度 > CI。
  最小实验 = 训 `carrypl16_s1`（同配置换种子）+ 复用本目录 `run.py` 重跑（训练 ≈30 min，纯推理 ≈3 min）。
- **γ 扫描**：只测了 {1.0, 0.99} 两点，0.99 在 T=256 下只留 7.6% 历史（等于几乎无记忆）。
  最小实验 = γ ∈ {0.999, 0.9999} 两臂训练 + 同仪器评测（≈2×30 min）。
- **归因拆分**：`2661` 对撞的是「有/无通道」这一类；`carrypl16` 相对 `carry16` 之间仍有 3 个自由度
  （逐层状态、内容写门/写入源、chunk 64→256）⇒ 10.2% 的召回**不能**归因到其中哪一个（`2639` 已
  把它列为 `1.1.4.1` 的最大缺口）。最小实验 = {逐层状态 + h₀ 写} 与 {单共享槽 + 当前 hidden 写} 两臂。
- **第 0 层不读**（`read_share_by_layer[0]` = 0.016）：要么是「底层不做长程检索」的合理分工，
  要么是实现缺陷。最小实验 = 层 0 单独消融的评测期反事实（纯推理，≈分钟级）。
- **量化点未叠加**：本实验的横轴是「窗口 16」一个字节点，未把 R1 的 int8/int4 KV 放到同一张
  (每位置等效字节, bpc) 图上。
- **真实长上下文（T ≫ 256）未测**：状态是固定成本，它的摊平优势在本快照上不可见。
- **合成任务腿未做**（SCHEMA §19 要求真实文本 + 合成两组并报）；M-08/M-09 两处旧归因的撤销仍属 WP3。
