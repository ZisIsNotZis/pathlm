## 1 要回答的判决问题

`project.yaml::milestone.output` 要求一份判决包：「`{全因果, local+global, block+stripe, 线性核}` 在
**相同每 token 可见量/每位置字节**下的 clean bpc + **长程召回** + **每 token 等效 FLOPs**，含 n≥2 与
**线性核无伤质量点**」。前两格已交**质量腿**（`2677` 局部+全局、`2683` 块粒度），但

1. **率类腿只留了指针**（指向 `2662` 的落盘），本项自己没给过召回读数；
2. **成本腿只有结构上界**（`12288 B × k_eff` 之类的解析量），没有在同一次前向里数过；
3. **WP2 未开始**：线性核的规范质量点要么带伤（`2616`「den 触 clamp、gnorm 899385、25 跳步」、
   `2637` 的 7.16M 6000 步），要么**核已被改**（`2637` 的 QK-Norm 档把 φ 输入钉在有界区间）。

本实验一次补齐三条，并把「补齐」写成可证伪的形式：

- **Q（质量，主判）**：同配方同 seed 下 `Δ = bpc_full − bpc_linear` 若**两 seed 同向且都越 +0.014** ⇒
  线性核在本尺度优于全因果；都落带内 ⇒ 无质量增量；都越 −0.014 ⇒ 更差；两 seed 不同向 ⇒ 不可判。
  **前提是健康门 H 先过**（数值无伤），不过则记「未取得」。
- **H（健康门，WP2 的前提）**：线性臂必须同时满足 ① `grad_skips == 0`；② `gnorm_max ≤ 12`
  （已训纯注意力臂实测 9.39–10.80 的 1.2× 上界）；③ 评测前向里 `den < 1e-30` 的 query-头行占比
  **== 0**（分母 guard 从不生效）；④ φ 的零占比 ≤ 1e-3。四条全过才算「无伤」。
- **R（召回腿）**：与 `2662` **同一台针仪器、同一判据**——每臂 `beyond`（或全保留臂的 `overall`）
  与 `far_slot` 桶的「植入 vs 配对无针地板」两比例差，Newcombe 95% CI 下界 > 0 **且**按针配对
  bootstrap CI 下界 > 0 ⇒ 该臂该桶「高于地板」；否则记「不高于地板」并按观测比例报所需针数。
- **F（成本腿）**：在**产生 bpc 读数的同一次前向里**按实际掩码数注意力 MAC，分
  `equiv_macs_per_token`（真稀疏核上应花的量）与 `executed_macs_per_token`（本条实装真正算掉的量）
  两列报，并与稠密基线（`full`）和窗口臂（`win24a0`）对照。

## 2 单因素声明

**唯一变量（质量腿）= 注意力算子**：全因果 softmax 对归一化线性核（φ=elu+1，O(T) 分块实装）。
四条新臂同一配方逐字段一致：d=256 / L=12 / h=8 / T=256 / mlp_mult=6 / dropout=0 / bs=32 / lr=1e-3 /
12k 步 / 98.3M token（enwik8 前 90M 训练、末 10M 评测、vocab 206）；机器可读副本见 `config.json`。
`params_added = 0`（线性块与 stock `Block` 逐位同构，单测钉住）。

| 臂 | 来源 | 可见模式 | 每位置可见键数 `k_eff` | 每位置 KV 字节（fp16） | 参数量 |
|---|---|---|---|---|---|
| `full_s0` / `_s1` | **本实验训练** | 全因果（主判对照） | 256 | 3,145,728 | 13,536,768 |
| `linear_s0` / `_s1` | **本实验训练** | 线性核（φ=elu+1，全历史，算子 O(T)） | 全历史 | 常数（流式状态；本实验不实测） | 13,536,768 |
| `win24a0_s0` / `_s1` | 复用 `2677` | 均匀条带最近 24（窗口臂参照） | 24 | 294,912 | 13,536,768 |
| `block8l4_s0` / `_s1` | 复用 `2683` | 块条带（远块专桶的臂） | 24 | 294,912 | 13,536,768 |
| `win16a8_s0` / `_s1` | 复用 `2662` | 局部+全局 16+8（同字节第三模式） | 24 | 294,912 | 13,536,768 |

**线性臂的数值档（为什么它不是换核）**：引擎默认 `φ = F.elu(x)+1`，对 `x ≲ −17` 时 `1 − exp(x)` 在
fp32/bf16 里舍入回 1 ⇒ φ 下溢为 0（分母塌陷、guard `1e-6` 生效、梯度按 `1/eps` 放大）。本实验把
**同一个函数**换成无消去求值 `exp(min(x,0)) + relu(x)`，并把分母 guard 的 eps 从 `1e-6` 降到 `1e-30`
（`out = num / max(den, eps)`，eps 越小越接近数学定义）——**φ 的形式、归一化式、参数量、配方都不变**
（`stable_linear.py`；进程内替换，共享文件不动）。线性臂的 `linear_chunk` 取 **32**（引擎默认 64 的一半）：它只改「块内显式打分 / 块间累积状态」的分界，数学等价、不改核，取 32 是为了把单臂墙钟压进预算（见 §5）。。这不是「换核」：换核指改 φ 的形状或把输入归一化
（`2637` 的 QK-Norm 档就是后者，`project.yaml::conclusion` 已把它记为「另一个算子」）。

**干预的负对照（冒烟，不进判据）**：同一配方跑两个 300 步的档——引擎默认 φ（`smk_engine_phi`）与
本实验的无消去档（`smk_stable_phi`）——把「原实现在同配方下确实数值塌陷、而本档没有」变成可看的
读数；12k 的正式臂只跑无消去档（引擎默认档的带伤读数已有 `2616` / `2637`）。

## 3 判据线（预登记，写死后不得改）

Δ 方向统一（`harness/SCHEMA.md` §17.3）：**Δ = bpc_对照 − bpc_实验，正 = 实验更好**。

| # | 判据 | 判定线 | 该涨 / 该跌 / 必须不变 |
|---|---|---|---|
| **H** 健康门（WP2 前提） | 逐线性臂四条：`grad_skips == 0`；`gnorm_max ≤ 12`；评测前向 `den < 1e-30` 的行占比 == 0；φ 零占比 ≤ 1e-3 | 四条全过 ⇒ 该臂「无伤」，质量腿可判；任一条不过 ⇒ 质量腿记「未取得（数值腿带伤）」并写明哪条、数值多少、要拿到无伤点需要什么（改核 or 改配方及其成本） | 必须满足 |
| **Q** 质量（主判） | 同 seed 配对 Δ = `bpc_full − bpc_linear`，对 0.014 带；两 seed 各判一次；三态 + 不可判 | Δ ≥ +0.014（两 seed 同向且都越带）= 线性核更好；`|Δ| < 0.014`（两 seed 都落带内）= 无质量增量；Δ ≤ −0.014（两 seed 同向且都越带）= 更差；不同向 / 只有一个越带 = 不可判（不取平均当结论） | 该涨（省算力的算子不该付质量税） |
| **R1** 召回（逐臂） | 每臂的 `beyond` 桶（全保留臂用 `overall`）「植入 vs 配对地板」：Newcombe 95% CI 下界 > 0 **且** 配对 bootstrap CI 下界 > 0 | 两 CI 都过 ⇒ 该臂「高于地板」；否则「不高于地板」并按观测比例报所需针数（公式见下） | 该涨（能看见的内容该被召回） |
| **R2** 远块专桶 | `far_slot` = 短语在块条带掩码下 7 个位置全可见、在均匀条带（最近 24）下至少一个位置不可见的针；同一判据 | 块条带臂在该子集上「高于地板」⇒ 远块这条路径在**率类**读数上可被利用；否则记「不高于地板 / 样本不足 ⇒ 不可判」+ 所需针数 | 该涨（远块若有用，就该在这一桶上体现） |
| **R3** 负对照（必须不变） | 均匀条带臂（`win24a0`）在 `far_slot` 上**看不见**这些针 ⇒ 它的「植入 vs 地板」CI 必须含 0 | CI 下界 > 0 ⇒ 仪器被污染（该桶里有别的信息来源），按 `proof.anomaly` 登记并停下复查 | 必须不变 |
| **R4** 样本量规则 | CI 下界 ≤ 0 时按观测比例报 `n* = ceil((z₀.₉₇₅+z₀.₈₀)²·(p₁(1−p₁)+p₀(1−p₀))/(p₁−p₀)²)`（z = 1.959964 / 0.841621，双侧 0.05、把握度 0.8）；`p₁ ≤ p₀` 时报「不存在（效应 ≤ 0）」 | 每个未判出的桶都必须带 `n*`，不许只写「不可判」 | 必须给出 |
| **F1** 等效 FLOPs | 逐臂在产生 bpc 的同一次前向里数：`equiv_macs_per_token`（按实际可见键数）与 `executed_macs_per_token`（本条实装真正算掉的）分两列 | 两列都落盘，公式与逐层计数一并落盘（可复算） | 该跌（equiv 列相对全因果） |
| **F2** 结构关系（必须不变） | (a) `win24a0` 与 `block8l4` 的 `equiv` 逐位相等；(b) 24 键臂 / `full` 的 `equiv` 比值 = 22.922/128.5 = 0.1784±1e-3；(c) 线性臂的 `equiv` 按 `linear_attn_chunked` 的算式计数（对 T 线性），T=256 的绝对值如实报、不外推到更长 T | 关系不成立 ⇒ 计数或掩码接错，读数作废 | 必须不变 |
| **⑧** 复用臂等值门 | 六个复用臂（`win24a0` / `block8l4` / `win16a8` 各两 seed）在本实验重算的 clean bpc 必须**逐位复现** `2683` 落盘值 | 不逐位相同 ⇒ 评测口径漂移，先对账不判 | 必须不变 |
| **⑨** 申报不进判据 | 墙钟、峰值显存、步时（`train_declaration` / `measured_step`）只申报；`harness/methodology.md` §3 禁把墙钟当判据 | — | — |

**不跨量纲**：0.014 bpc 带只用于 bpc 配对差；召回是率类，只用两比例差 CI（R1–R4）。

## 4 指标口径（操作性定义）

- **clean bpc**：`masked_logits(model, x, keep)` → 因果移位 CE 的 token 平均（bits/char，越低越好）；
  `n_batches = 96`、`batch_size = 16`、`window_seed = 2`（与 `2677` / `2683` **同一批窗口** ⇒ 臂间差是
  配对差）。每臂在自身可见性下评测：`full` 用 `None`、`linear` 用 `None`（训练路径就是因果线性核）、
  三个 24 键模式用各自的显式掩码。
- **配对统计**：逐窗口 `bits` 的配对 Δ 的均值 / 标准差 / 标准误 / t 值 / 同向窗口数。
- **召回**：needle v3（真实 enwik8 短语针，`phrase_len=6`，答案 = 短语下一字节，top-1 命中）；
  配置与 `2662/config.json::needle` 逐字段相同（64 批 × 16 行 × 8 针/行，`seed=3`，归属桶一律
  `anchors=8`）。**植入 / 配对控制用同一批次、同一针位**（`meta` 逐位相同，程序断言）。逐臂用它
  **自己训练时那张掩码**评测（分布内，不换掩码）。
- **每 token 等效 MAC**：`flops_count.count_attention`——用模块前置钩子取每个注意力块**实际收到**的
  掩码与形状：softmax/掩码块 `macs = 2·kept_pairs·d_head`（`None` 掩码 ⇒ 因果 `T(T+1)/2` 每行）；
  线性块 `macs = B·H·(2·T·dh² + 2·T·C·dh + 2·T·dh)`（逐项对应 `linear_attn_chunked` 的 einsum，
  `C = min(linear_chunk, T)`）；每层除以 `B·T` 后对层求和；`FLOPs = 2·MACs`。
  `executed` 列 = 本条实装真正算掉的量（稠密 bool 掩码下掩码臂仍算整张因果矩阵）。
- **健康审计**：`linear_phi_audit.audit` 在真实评测批上逐层量 φ 的零占比（引擎默认档 vs 无消去档）、
  稳定档 φ 的最小值与 `den < eps` 的行占比；fp32（评测前向实际精度）与 bf16（训练 autocast 精度）
  两档都落盘。

## 5 预算与成本

| 项 | 值 |
|---|---|
| GPU 预算 | 四条新臂训练 `full_s{0,1}` ≈9.5 min/臂 + `linear_s{0,1}` ≈17 min/臂 + 冒烟两档 ≈1 min + 评测（bpc 十臂 + 召回十臂 + FLOPs 十臂 + 健康审计）≈5 min ≈ **60 min**（本实验自报上限 120 min） |
| 单臂命令超时 | **25 min**（`train_arms.sh` 的 `timeout`；本仓惯例 20 min，本实验按下面那条实测抬高 5 min） |
| 显存 | 逐臂实测 `peak_gpu_mem_mb`；礼貌线 5GB net（`harness/SCHEMA.md` §20.2） |
| 可中断性 | 每 200 步落 `train_log.jsonl`；断点即重取锁重跑该臂 |

**实测步时与预算的偏差**（预登记时已声明 + 落地时实测更新）：`linear` 臂在 bs32 / T=256 上比 `full`
慢约 2.3×（`2616` 记 2.58×；本实验预热实测 101 ms/step @ chunk=64、95 ms/step @ chunk=32），12k 步
≈20.2 min / ≈19 min。本仓惯例是「单臂 ≤20 min」，余量只有约 1 min，而共享卡上还有别人的推理进程在跑
⇒ 被 20 min 掐断会整条臂作废。因此**四条新臂统一 25 min 上限**（预算偏差，不改判据、不改配方、
不改步数、不缩 token 预算）；若某臂仍超时，按失败树记为「该臂未取得」并如实登记。

## 6 失败决策树

| 症状 | 处置 |
|---|---|
| 线性臂训练 NaN / 发散 / 超时 | 该臂不进判据；按 H 记「未取得」并给原因与所需成本（改配方档的实测读数、改核档的引用） |
| 健康门 H 任一条不过 | 质量腿记「未取得（数值腿带伤）」，落盘哪条不过与数值；**不得**把带伤运行的 Δ 当规范质量点 |
| 复用臂读数不复现 `2683` | 评测口径不一致 ⇒ 先对账，不判 |
| `far_slot` 针数太少（CI 含 0） | 按 R4 报所需针数，记「不可判 + 样本量」；**不得**把「不显著」写成「远块没用」 |
| 均匀条带臂在 `far_slot` 上高于地板（R3 破） | 仪器污染 ⇒ 停下复查该桶定义，读数作废 |
| F2 的结构关系不成立 | 计数或掩码接错 ⇒ 读数作废，先修仪器 |
| 两 seed 质量方向相反 | 报「本 n 下不可判」，不取平均当结论 |
