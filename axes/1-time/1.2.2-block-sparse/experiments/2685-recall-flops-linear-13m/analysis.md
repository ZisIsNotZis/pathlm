# 2685 · `1.2.2` 里程碑的另两腿（召回 / 每 token 等效 FLOPs）与 WP2（线性核无伤质量点）：判读

## 0 人话摘要（先说结论，再上表）

本实验把 `1.2.2` 里程碑缺的那一半补齐：**长程召回**（此前只留指针指向 `2662`）、**每 token 等效
FLOPs**（此前只有结构上界）、以及 **WP2 的线性核无伤质量点**（此前两档都有伤或改过核）。

三句话版本的结论：

1. **线性核终于有了一个数值无伤的规范质量点**：只把 φ 的**求值方式**换成无消去形式
   （`exp(min(x,0)) + relu(x)`，与 `elu(x)+1` 同一个函数）、把分母 guard 的 eps 从 `1e-6` 降到
   `1e-30`（不改核、不加参数、不改配方），四条健康门全过：跳步 0、`gnorm_max` 9.87 / 10.73（健康带
   9.4–10.8 之内）、评测前向 `den < 1e-30` 的行占比 0、φ 零占比 0。质量读数 Δ = bpc_全因果 − bpc_线性 =
   **−0.076059（seed 0，t −34.14）/ −0.071275（seed 1，t −33.16）**（两 seed 同向、都越 0.014 带
   5.1–5.4 倍），判词 **线性更差（两 seed 越带、同向）**。人话：**线性核的质量税是真的、不是数值塌陷
   造成的假象——把数值腿修干净之后，它仍然比全因果多付 0.071–0.076 bpc。**
2. **召回腿这次自己给了读数**（同一台针仪器、同一判据，十臂 × 8192 针）：**全因果臂高于地板
   24.341 / 25.903pp，线性臂也高于地板但只有 8.936 / 9.180pp（约全因果的三分之一）**；三个 24 键模式在
   `beyond` 桶上都落在地板上（−0.056 ~ +0.574pp，CI 全含 0）⇒ **「只看 24 个键」把窗外召回抹平**。
   `far_slot` 专桶（只有块条带的远块能看见的针，n=33）上 **`block8l4_s0` 高于地板（+27.273pp，两条 CI
   都过）**、`block8l4_s1` 只过配对 bootstrap（+21.212pp，Newcombe 含 0，按 R4 需 `n*`=83）、均匀条带与
   局部+全局都不高于地板（R3 负对照没有被破坏）⇒ **远块这条路径在率类上有一条正面读数，但两个 seed
   没有同时立住**，按预登记记「未判出 + 所需针数」，不写成「远块没用」也不写成「远块被用上」。
3. **每 token 等效注意力 FLOPs 从「结构上界」换成「同一次前向里的计数」**：三个 24 键模式的 `equiv`
   **逐位相等 = 11,736 MAC/token/层**，等于全因果 65,792 的 **0.1784 倍**（= 解析预期 22.922/128.5）；
   线性臂 33,280 = 全因果的 **0.506 倍**（T=256 一点，对 T 线性）。而 `executed`（本条实装真正算掉的量）
   在三个掩码臂上**仍是 65,792**（稠密 bool 掩码）⇒ 定律 11 的「纸面省幅不兑现」在这里就是一个数。

**三支分开写（本条要的那一刀）**：

- **本实现不成立 = 否**：掩码活（十臂逐位同参 13,536,768）、复用臂等值门 6/6 逐位复现 `2683`、
  线性臂四条健康门全过、φ 的零占比 0（引擎默认档同一次前向是 0.2202 / 0.2447，逐层最大）⇒ 负读数不是
  「开关没接上」或「数值塌陷」。
- **机制不成立 = 是（本尺度、等预算前沿意义上）**：四个点各自出判——局部+全局比均匀条带差 0.023 bpc
  （`2677`，越带）、块粒度落带内无质量增量（`2683`）、线性核差 0.071–0.076 bpc（本实验，越带）、而三个
  24 键模式在率类上贴着地板 ⇒ 在本尺度（13M / T=256 / 每位置 24 键或 O(T) 算子）上，**这些低预算注意力
  变体没有一条在「质量-代价前沿」上占到便宜**：省钱的那些在质量上更差、质量一样的不省钱。
- **本尺度不可判 = 3 条，各有其词**：(a)「远键是否承载可用信息」——`2683` 的评测期反事实是分布外操作，
  本实验的分布内率类腿只在一个 seed 上立住（另一个 `n*`=83）⇒ 仍不可判；(b) 宽预算 / 更长 T 上的排序
  （200 键剂量点 n=1、T 只测 256）；(c) 本实装不是块常量掩码，换真块稀疏核后的省幅与质量都要重估。

## 1 六问（格式契约，`harness/SCHEMA.md` 的「研究线的六问汇报格式」）

**1 它是干什么的。** 给 `1.2.2` 的判决包补齐率类与成本两条腿，并给线性核一个**规范**质量点：
前两格（`2677` / `2683`）只判了「同 24 键下非均匀性值不值」的质量腿，召回与等效算力此前只引用别人
的落盘或解析上界；线性核的旧读数要么带伤（`2616` / `2637` 的 7.16M 运行），要么把核改掉了
（`2637` 的 QK-Norm 档）。

**2 相对普通 decoder-only transformer 改了什么。** 质量腿唯一变量 = **注意力算子**：把全因果 softmax
换成归一化线性核 `out_i = Σ_{j≤i} φ(q_i)·φ(k_j) v_j / Σ_{j≤i} φ(q_i)·φ(k_j)`，φ = `elu(x)+1`，
O(T) 分块实装（`linear_attn_chunked`），**新增参数 0**（与 stock `Block` 逐位同参）。数值档只改
φ 的求值方式与分母 guard 阈值（见 §2）。召回 / FLOPs 两条腿**不改模型**，只换测量仪器。

**3 为什么要改。** `project.yaml::milestone.output` 要求「clean bpc + 长程召回 + 每 token 等效 FLOPs，
含 n≥2 与线性核无伤质量点」。只有质量腿时，这张「质量-代价前沿」缺一维：说「块稀疏省字节」有结构
上界，说「线性核省算力」只有纸面 FLOPs，而召回这一维完全没测过。缺这三条，前沿图上的每个点都只有
一半坐标。

**4 怎么测的。** 十条臂、同一配方（d=256 / L=12 / h=8 / T=256 / mlp×6 / bs32 / lr=1e-3 / 12k 步 /
enwik8 前 90M 训练、末 10M 评测）：四条新训（`full` 与 `linear` 各两 seed，本实验训练）、六条复用
（`win24a0` / `block8l4` / `win16a8` 各两 seed）。bpc 用 96 批 × bs16、`window_seed=2` 的**逐窗口配对**；
召回用 needle v3（与 `2662` 逐字段相同的配置：64 批 × 16 行 × 8 针/行、`phrase_len=6`、`seed=3`）；
FLOPs 用模块前置钩子在**产生 bpc 的同一次前向**里取实际掩码与形状后计数。判据线见 `README.md` §3，
机器可读副本 `config.json::judgement`，落盘 `results.json`。

**5 测出来多少。** 见 §3–§6 的表；数字的键路径在 §10。

**6 结论与下一步。** 质量腿判**线性更差**（−0.076059 / −0.071275，两 seed 同向、都越带），且这次是
**无伤档**的读数（四条健康门全过）⇒ WP2 的验收「给出无伤 Δbpc 或明确记为未取得」按前半条交付；
召回腿判「全因果 > 线性 > 三个 24 键模式（贴地板）」、远块专桶一个 seed 立住一个 seed 不足；
成本腿把 0.1784 与 0.506 两个比值落成计数。**下一步**：远块专桶补针到 `n*`≥83（同 checkpoint、
0 训练 token、≈1 min GPU）；以及 `project.yaml::gaps` 里的其余条目（真稀疏核兑现省幅、T≥2048 的
第二个规模点）。

φ 零占比 **0.0 / 0.0**；分母 guard 的 eps 从 `1e-6`（会把 `num/max(den,eps)` 的梯度按 `1/eps` 放大）

`tests/test_stable_linear_phi.py` 钉住这三条（同一函数、塌陷区保正、`install()` 真的换掉引擎全局）。

**线性臂的 `linear_chunk` = 32**（引擎默认 64 的一半；只改「块内显式打分 / 块间累积状态」的分界，

**一处声明已更正**：`results.json::config.linear.linear_chunk` 原由 `run.py` 硬写成 64，与本实验实际
跑的 32（`config.json`、`train/*/results.json`、以及 `flops_leg` 的线性计数算式 C=32 三者一致）不符，
已就地改为 32；该字段只声明实跑配置、不参与任何读数，比值与判词不受影响。

## 6 成本腿 F（每 token 等效注意力 FLOPs，同一次前向里的计数）

两列分开报：`equiv` = 按**实际可见键数**算（真稀疏核上应花的量）、`executed` = **本条实装真正算掉的**
量（稠密 bool 掩码下掩码臂仍算整张因果矩阵）。

| 臂 | 每行可见键数（`mean`） | `equiv` MAC / token / 层 | `executed` MAC / token / 层 | `equiv` / `full` |
|---|---|---|---|---|
| `full_s0` / `_s1` | 128.5（因果） | 65,792 | 65,792 | 1.000 |
| `linear_s0` / `_s1` | —（O(T) 算子） | 33,280 | 33,280 | **0.506** |
| `win24a0_s0` / `_s1` | 22.922 | **11,736** | 65,792 | **0.178** |
| `block8l4_s0` / `_s1` | 22.922 | **11,736** | 65,792 | **0.178** |
| `win16a8_s0` / `_s1` | 22.922 | **11,736** | 65,792 | **0.178** |

结构关系（判据 F2，必须成立）：两个 24 键模式的 `equiv` **逐位相等**（11,736 = 11,736）；24 键 / `full`
的比值 = 11736/65792 = **0.178381**（解析预期 22.922/128.5 = 0.178381，差 < 1e-3）；线性臂按
`linear_attn_chunked` 的算式计数、对 T 线性（T=256 的绝对值如实报，不外推到更长 T）。

**口径与一处措辞不符（如实披露）**：落盘的 `equiv_macs_per_token` 实算为「逐层 MAC 之和 ÷ (B·T·层数)」
⇒ 它是**每层平均、每 token** 的量，而不是 `formula.per_token` 字面写的「对层求和」。整模型每 token 的
量 = 落盘值 × 12 层（`full` 789,504 / 24 键 140,832 / 线性 399,360 MAC），三个比值与口径无关。
本实验判的全是**臂间比值**（0.178 / 0.506），不受这一项影响；改字面或改除数都要动绑定过的
`flops_count.py`（会打破「契约先于读数」的定序、须重跑计数），因此本轮只在判读里写明，不改正文件。

## 8 边界（不能从本实验读出来的东西）

- **召回读数只到「这个臂在它自己的掩码下能不能召回窗外内容」这一层**：`far_slot` 子集按掩码定义、
  各臂同索引可比，但它仍是**分布内**读数——它不回答「换掩码会怎样」（那是 `2683` 的反事实，
  且 `2683` 已把那条归因记为不可判）。反过来，`block8l4_s0` 的这一条正面读数**不能**单独升级成机制
  结论：另一个 seed 的 Newcombe CI 含 0，按预登记只能记「未判出 + `n*`=83」。
- **线性核的省幅不在等效 MAC 上兑现为墙钟**：T=256 上线性臂的 `equiv` 是全因果的 0.506 倍（同一台计数
  仪器），它的更大省幅在**每位置字节**（常数状态，未实测）与**更长 T**（等效 MAC 对 T 线性）上；
  本实验只测 T=256 一点，不外推到 T≥1024。
- **线性档不是「引擎默认档」的质量数**：`2616` 记的塌陷（899385 gnorm / 25 跳步、den 自 step 800 贴
  clamp）在本实验的 **300 步冒烟负对照里没有复现**：两档都健康（`gnorm_max` 9.87 对 9.87、跳步 0、
  `den_min` 0.898 对 1.305、`phi_min` 0.0039 对 0.0031，`smoke/{smk_engine_phi,smk_stable_phi}/results.json`）
  ⇒ 300 步太短，「默认档会塌陷」这条前提取证于 `2616`，冒烟只证明「两档在前 300 步无差别」。
  因此本实验的 Δ 是**无伤档**的读数；「默认档在 13M 上的规范质量点」仍是未取得（要拿到它得先让默认档
  健康，而那需要改核或改配方，见 `project.yaml::gaps`）。
- **只测 enwik8 / T=256 / 13M / 12k 步 / seed 0–1**：不跨规模、不跨语料、不跨 T 外推；召回是
  6 字节短语 top-1，不等于生成质量。
- **`LAG` 只测 4、块粒度只测一个设定**（`2683` 的边界，本实验不改）。
- **`far_slot` 只有 33 针**：它是「只可能经远块看见」的针，占 8192 针的 0.4%，所以它的 CI 宽
  （±20pp 量级）；`n*`=83 是同一个效应量下双侧 0.05 / 把握度 0.8 的规划值。
