# 2615 · 稳定性与噪声底专报（三种压缩优先级对决）

契约：同目录 `README.md`。原始数据：`results.json::reproducibility` / `::noise_floor`。
所有数字来自 `results.json` 的那一次全电池（`run.py`，墙钟 **101.57 s**（共享卡；同样的全跑独立跑了四遍：100.01 / 124.99 / 103.56 / 101.57 s），**4444** 次前向，峰值显存 **318.0 MiB**）。

## 1. 复现性（同 seed、同进程重跑）

三个档位（`distance:N=64` / `lru:k=64:N=64` / `content:N=64`）各重跑一遍：

| 配置 | damage 运行 1 | damage 运行 2 | \|差\| |
|---|---|---|---|
| `distance:N=64` | 1.248019 | 1.248019 | 1.8e-08 |
| `lru:k=64:N=64` | 1.330958 | 1.330958 | 1.1e-08 |
| `content:N=64` | 1.210212 | 1.210212 | 3.12e-07 |

最大差 3.12e-07 ≪ 契约阈值 0.005 ⇒ **通过**（差异来自 fp32 累加顺序，不是随机性：
窗口序、针批、删除集全部由 seed 钉死）。

**更强的一条**：整个全电池（92 个配置、两条腿、4444 次前向）**独立跑了四遍**
（墙钟 100.01 / 124.99 / 103.56 / 101.57 s），逐键比对 `results.json`（3181 个数值键）得到
**0 个数字差异**——墙钟差 25 s 来自共享卡争用，不是随机性。

## 2. 噪声底（两条腿各一条独立来源）

| 来源 | 设定 | 实测散布 |
|---|---|---|
| 依赖腿 · 跨**评测窗口 seed** | seed ∈ {3,4,5,6}（n=4），成对 damage | `distance:N=32`：均值 0.637487，**σ = 0.004157**；`lru:k=64:N=32`：均值 0.694733，σ = 0.004103；`content:N=32`：均值 0.668107，σ = **0.008274** |
| 保留腿 · 跨**针 seed** | seed ∈ {3,13,23}（n=3，每 seed 512 根针） | `full`：0.6797/0.7305/0.6777，σ = 0.0299；`distance:N=32`：σ = 0.0303；`lru:k=64:N=32`：σ = 0.0249；`content:N=32`：σ = 0.0313 |
| 保留腿 · 二项抽样（解析） | n=4096 根针，p ≈ 0.687 | SE = √(p(1−p)/n) = **0.72pp**；分桶（anchor n=508）⇒ 2.1pp |

**读法**：

- 依赖腿的判据门槛 0.014 比跨窗口 seed 噪声（σ ≤ 0.0083）**大 1.7 倍以上**（对
  `content:N=32` 只大 1.7 倍，是最紧的一档；对 `distance`/`lru` 大 3.4 倍）。因此
  N=8 的 `lru` +0.0159 **贴着门槛**（1.9σ），而 `content` +0.0244（2.9σ）更稳；
  N=64 的 `content` +0.0378（4.6σ）稳。这些判断只在**位置预算**口径下成立——
  换成「被删因果对数」口径后全部重估（见 `analysis.md` §6）。
- 保留腿的跨针 seed 散布（σ ≈ 2.5–3.1pp）**大于**同规模二项 SE（0.72pp），说明针位抽样
  还有结构差异；但两条腿的所有配置比较都是**同一批针、逐针配对**的，配对后共享 seed 噪声。
- 主判据的召回腿门槛是 **≥10pp**；实测三条规则之间的最大召回差是 **+1.71pp**（N=8，
  `lru` vs `distance`），远小于 3σ ⇒ 「召回腿未达成」不是噪声边缘结论，而是结构性的
  （且见 §3 的算术不可达）。

## 4. 已知的不稳定来源与处置

1. **契约未定义 `lru` 的 k**：主臂预登记 k=64，另扫 k∈{32,128,256}。结论对 k 敏感
   （依赖腿：k=32/64/128 在 N≥32 都更差；k=256 伤害最低但召回崩）⇒ 报**敏感性表**，
   不挑一个 k 讲故事。k=256 时 `mass_recent[256] ≡ mass_total`，是契约括注
   「该位置收到的注意力权重之和」的字面读法。
2. **位置预算 ≠ 可见性代价**：三规则删同样多的**位置**，但删掉的因果 (query,key) 对数
   不同（N=8：2012 / 1562 / 1859）。这是本实验最大的口径风险，已用 56 点曲线做
   「同对数」重对齐（`analysis.md` §6），并在结论里以对齐后的数字为准。
3. **针的线索块属于 harness**：尾块 `[q0=200, 256)` 是提问块；有的规则（尤其 k=256 的
   全局质量规则）会把它删掉，召回随之下滑。这不是「记忆被压掉」，已用 12 个
   「候选池限制在正文窗口」的诊断臂分离（`analysis.md` §7）。
4. **小样本桶**：`anchor` 桶在 `distance:N=8` 只剩 508 根针（0.4587）；任何用该桶的
   陈述都带 n。`beyond` 桶的 n 在各规则下差别很大（179–2490），故并列报
   **共同可见子集**（同一批针、三条规则都判可见，n=1831–3077）。
5. **fp32 累加顺序**：逐批 `.double().sum()` 与 `cross_entropy(reduction="sum")` 之间
   有 ~1e-7 的差（共用掩码/逐样本掩码对照、复用对照都属于这一类），远小于 0.014 门槛。

## 5. 与契约 M / 2614 的稳定性对照

契约 M 报「同 seed 重跑最大差 3.1e-07、跨窗口 seed σ 0.0041–0.0185、跨针 seed σ 0.0258–0.0351」。
本实验在同一件仪器上重算 `prefix` 三点最大差 2.59e-07，跨窗口 seed σ ≤ 0.0083，跨针 seed
σ ≤ 0.0313 —— 同量级或更小。差别只在「本实验多跑了 3 条规则 × 3 档 + 敏感性 + 诊断臂」，
不是实现差异。
