# 2678 · 空洞采样 vs 连续窗口 · 分析（人话摘要 + 判据读数 + 边界）

## 0 人话摘要

**问题**：每 token 只看 32 个键时，把这 32 个位置**摊开到更远**（近端窗口 16 + 16 个等距空洞点
铺满整个前缀）比**只看最近的 32 个**更能保住远处信息吗？

**做了什么**：在同一个 13M / 8 层 / 256 宽 / T=256 / 12k 步的 dense 主干上，只换注意力「能看见
哪些位置」：对照臂 `win32` 看最近 32 个位置（复用 `2676` 的两条已训臂），实验臂 `dil32` 看
近端 16 个位置 + 16 个按行均匀铺满前缀的空洞点（本实验新训 seed 0 与 seed 1 两条）。两臂的
**每行可见键数逐行相等**（都 = min(32, i+1)）、参数量逐位相等（6,962,688）、主干**构造路径同源**
（同一个训练函数、同 seed 构造，转换前后各参数逐位不变；两个 run 各自训练后的 checkpoint 本来就不
相同，本实验**没有**把 dil 的初始权重与 `win32` 的 checkpoint 逐位比过）⇒ 唯一变量就是「挑哪 32 个位置」。

**测出来多少（本尺度）**：

- 质量：`dil32` 的 clean bpc 比 `win32` 低 **0.01195（seed 0）** 与 **0.00696（seed 1）**
  （Δ = bpc_win − bpc_dil，正 = 空洞更好；两 seed 同向、20 批配对、15/20 与 13/20 批同向，
  t = 2.48 / 1.69）。但 0.014 的配对噪声带是这条判据的门槛——**两个 seed 都落在带内**，
  所以按预登记只能说「**本尺度无质量增量、不可排序**」，不能说「空洞更好」。
- 参照线（只作对照、不与主判混用）：相对全因果，窗口臂贵 **0.09462 bpc**、空洞臂贵
  **0.08267 bpc** ⇒ 同样的 32 个键，把位置摊开只把这笔窗口税回收了约 0.012（13%），
  仍在带内。
- 长程召回（判据②③）：用仓内变距离回忆电池（`tools/evalkit/longrange_tasks.var_recall_batch`，
  距离 16/32/64/128/192/240）测四条臂。**每档加密到 64 批 × 32 个样本（2048 个样本/臂/档）后，
  所有臂在所有档的准确率都 ≤ 0.94× chance**（chance = 1/64 = 0.0156；最高 0.0146）⇒ 这件仪器在
  13M / 12k 步 / enwik8 字符级上**分辨不出任何一臂的召回能力**。8 批那一版里 seed 0 的 d64/d128
  「CI 不含 0」在 8 倍样本下退成 +0.005~+0.013 的**系统偏置**、方向仍是窗口臂更高，而两臂都 ≈0
  ⇒ 那两档是抽样噪声，不是「窗口臂更会召回」。判据②因此给不出正向证据；这是**仪器在本尺度没有
  分辨力**，不是「没有信号」的替代说法。
- 合成关联回忆对撞（判据⑧，本轮新加）：上面那条仪器问不出「远处信息能不能被搬」，所以改用
  **必须用远处信息**的任务直接测——多查询关联回忆（key 全在序列最前 16 个位置、每条查询的距离
  107–240，31 个键的窗口根本够不到）。`win32` 与 `dil32` 各两个 seed、同构造同 12000 步：
  **窗口臂 0.0155 / 0.0161（≈ chance 0.0156），空洞臂 0.3612 / 0.3685（23.1× / 23.6× chance）**，
  配对 Δ = acc_win − acc_dil = **−0.3457**（95% CI −0.3524…−0.3387）与 **−0.3524**
  （−0.3589…−0.3460），两个 seed 同向且都不含 0 ⇒ **在需要远处信息的任务上，空洞掩码确实把远处
  信息搬回来了**。限定见结论段。
- 结构侧（该涨、确实涨了，但换不到质量）：每行的最远可达距离从 **31（恒定）** 变成
  **i（`i ≥ 32` 时铺满整个前缀，实测最远 255）**，差异只发生在 256 行里的 **224 行**
  （`i ≥ 32`）。

**结论（两半，强度不同）**：

1. **真实文本上无质量增量（这一半被否证，n=2）**：enwik8 字符级 / 13M / 12k 步下，同 32 键把可见
   位置摊开相对取最近 32 个，clean bpc 差 +0.01195 / +0.00696，两 seed 同向但都落 0.014 带内 ⇒ 该
   断言不成立。可见范围确实变远（可达 31 → 255），但换不到质量。
2. **需要远处信息时机制可用（这一半成立，n=2）**：合成关联回忆上空洞臂 23× chance、窗口臂贴
   chance（上一段）⇒ **先前「本设计下无信号」的说法必须改掉**：它把「本任务不需要」误写成
   「测不出/搬不动」。

**两条限定（必须与结论一起读）**：

* **构造性差异**：这一对合成臂的差别是「**能不能覆盖到**」——窗口臂在距离 107–240 的 key 上
  根本看不到 key（key 在序列最前 16 位），所以它只能证明「掩码确实交付了远处信息」，**不得**读成
  「dilation 是同等可见键下更优的取样方式」；后者在真实文本读数上恰恰是被否证的那一半。
* **仪器侧**：召回电池（判据②③）在本尺度**无分辨力**（2048 样本/档仍是 ≤0.94× chance），所以
  「判据②给不出正向证据」的正当理由是仪器不够，不是「无信号」。

还剩下的边界是 (a) 稠密 bool 掩码没有把纸面省算力兑现成实测省算力，(b) 只有 T=256 / 12k 步 /
13M 一点。**下一步最小实验**：长 T（≥2048）+ 逐层递增 dilation 重做同一对臂（`1.2.1` 的 `gaps`）。

## 2 两臂结构（判据④的落盘列）

| 行 i | `win32` 可见集 | `dil32` 可见集 | 计数 | 最远距离 |
|---|---|---|---|---|
| `i ≤ 31` | 全部因果（`i+1` 个） | 同左（`i+1` 个） | `i+1` | `i` |
| `i = 240` | `[209, 240]` | `[0, 15, 30, 45, 60, 75, 90, 105, 119, 134, 149, 164, 179, 194, 209, 224]` + `[225, 240]` | 32 | 240（窗口臂 31） |

`dil32` 的第 t 个空洞点 = `round(t·(P−1)/15)`，`P = i − 15`：**按行均匀铺满前缀**。
固定 stride 在 `i < 136` 时取不满 16 个点，会让两臂可见键数不等、破同预算对照，所以逐行取
dilation 而不是全局固定 stride——这是本实验对「空洞」的实装定义，写在 `run.py::dilated_keep_mask`。

## 3 定律 10 的逐条核对：缺的是「任务需要」，不是「机制搬不动」

| 必须条件 | 本实验是否满足 |
|---|---|
| 信息确实超出可见范围 | **结构上满足**：可达距离 31 → 255 |
| 训练信号迫使其使用远处信息 | **真实文本不满足**：enwik8 字符级的局部先验足以补上这片上下文（定律 9 的「模型不需要」）；**合成关联回忆满足**（判据⑧：`dil32` 23× chance、窗口臂贴 chance） |
| 有真实稀疏核 | **不满足**：稠密 bool 掩码 ⇒ 纸面 `O(T·k)` 没兑现成实测省算力 |
| 效应超过本格自测噪声 | **真实文本不满足**：bpc 差 0.01195 / 0.00696 都小于 0.014 带；**合成任务满足**：差 0.35（23× chance、CI 不含 0） |
| 判据仪器有分辨力 | **召回电池不满足**（2048 样本/档仍 ≤0.94× chance）；**合成任务满足**（23× 于 5× 门槛） |

⇒ 真实文本这一半只能记成「**本任务不需要、本尺度无质量增量**」，**不得**读成「空洞搬不动远处
信息」——判据⑧ 已经证明它搬得动；也不能读成「空洞采样没有价值」，更不能读成「原来如此、
显而易见」。反过来说，判据⑧ 那一对臂的差别是「能不能覆盖到」（窗口臂看不到 key），所以它只
支持「掩码确实交付了远处信息」，不支持「同等可见键下 dilation 是更优的取样方式」。

## 4 与 `1.2.2` / `1.2.3` 的关系（同轴同尺度的三笔交易）

- `1.2.2`（局部+全局）：把 8 个键切给**最前 8 个恒可见全局槽**，比 24 个键全给最近位置
  **差 0.023**（两 seed 同向、越带）——那笔交易越带为负。
- `1.2.3`（内容 top-k）：同样 32 个键**按内容挑**比按位置挑**好 0.078 / 0.077**（n=2，越带）。
- 本项（空洞）：同样 32 个键**按位置摊开**比按最近位置挑，差 **0.01195 / 0.00696**（同向、
  落带内）⇒ 在「该用哪种可见集」的排序上，本次读到的是：**按内容挑 ≫ 按最近挑 ≈ 摊开挑 ≫ 全局槽挤占**。
  三条都来自 13M / T=256 / 同一配方，跨格比较只作**参考线**（不同格、不同 run，不是配对差）。

## 5 未测项与边界（预登记之外不推断）

1. 只有 T=256 与 k=32 一点；长 T（≥2048）上「摊开」的价值可能完全不同（交叉点未实测）。
2. 逐层递增 dilation（LongNet 式）未测：本实验各层用同一张掩码。
3. 真稀疏核未做：省幅只是纸面上界。
4. 召回电池（判据②③）在本尺度没有分辨力（见 §3）；「远处信息能不能被搬」已由判据⑧ 的合成关联
   回忆直接测到（n=2）。仍未测的是**真实文本 + 长 T** 下它值不值：合成任务证明的是「搬得动」，
   不是「真实语料上会回本」。
5. 单尺寸、2 个 seed，不外推到 53.9M 及以上。
