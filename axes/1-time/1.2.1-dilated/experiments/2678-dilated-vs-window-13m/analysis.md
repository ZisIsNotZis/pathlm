# 2678 · 空洞采样 vs 连续窗口 · 分析（人话摘要 + 判据读数 + 边界）

## 0 人话摘要

**问题**：每 token 只看 32 个键时，把这 32 个位置**摊开到更远**（近端窗口 16 + 16 个等距空洞点
铺满整个前缀）比**只看最近的 32 个**更能保住远处信息吗？

**做了什么**：在同一个 13M / 8 层 / 256 宽 / T=256 / 12k 步的 dense 主干上，只换注意力「能看见
哪些位置」：对照臂 `win32` 看最近 32 个位置（复用 `2676` 的两条已训臂），实验臂 `dil32` 看
近端 16 个位置 + 16 个按行均匀铺满前缀的空洞点（本实验新训 seed 0 与 seed 1 两条）。两臂的
**每行可见键数逐行相等**（都 = min(32, i+1)）、参数量逐位相等（6,962,688）、主干初始化同 seed
逐位相同 ⇒ 唯一变量就是「挑哪 32 个位置」。

**测出来多少（本尺度）**：

- 质量：`dil32` 的 clean bpc 比 `win32` 低 **0.01195（seed 0）** 与 **0.00696（seed 1）**
  （Δ = bpc_win − bpc_dil，正 = 空洞更好；两 seed 同向、20 批配对、15/20 与 13/20 批同向，
  t = 2.48 / 1.69）。但 0.014 的配对噪声带是这条判据的门槛——**两个 seed 都落在带内**，
  所以按预登记只能说「**本尺度无质量增量、不可排序**」，不能说「空洞更好」。
- 参照线（只作对照、不与主判混用）：相对全因果，窗口臂贵 **0.09462 bpc**、空洞臂贵
  **0.08267 bpc** ⇒ 同样的 32 个键，把位置摊开只把这笔窗口税回收了约 0.012（13%），
  仍在带内。
- 长程召回：用仓内变距离回忆电池（`tools/evalkit/longrange_tasks.var_recall_batch`，距离
  16/32/64/128/192/240、每档 8 批 × 32 个样本）测四条臂。**结果全部贴 chance**（chance =
  1/64 = 0.0156，四臂在各档的准确率 0.0000–0.0312，即每 256 个样本 0–8 个命中，最高只到
  chance 的 2 倍）⇒ **这件仪器在 13M / 12k 步 / enwik8 字符级上分辨不出任何一臂的召回能力**。
  按批聚类的配对 bootstrap 在 seed 0 的 d64/d128 两档「不含 0」，但那是 1–2 个命中驱动的、
  方向还是**窗口臂更高**，不能当「空洞搬来了远处信息」的证据。
- 结构侧（该涨、确实涨了，但换不到质量）：每行的最远可达距离从 **31（恒定）** 变成
  **i（`i ≥ 32` 时铺满整个前缀，实测最远 255）**，差异只发生在 256 行里的 **224 行**
  （`i ≥ 32`）。

**结论**：本尺度判「**空洞采样无净增量、不成立**」——按预登记否证线（远档召回没有支持空洞的
可分档 + clean bpc 两 seed 都落 0.014 带内）。按 `docs/playbook.md` 定律 10，这只覆盖
「**本设计下的本尺度**」：可见范围确实变远了，但 (a) enwik8 字符级的局部先验足以补上这片
上下文（定律 9 的「模型不需要」），(b) 只有 12k 步 / 13M 的训练信号，没有任何压力迫使它去用
远处那 16 个点，(c) 本实装是稠密 bool 掩码，纸面的省算力一点没兑现。**下一步最小实验**：
在长 T（≥2048）+ 需要跨段信息的任务上重做同一对臂（这是 `1.2.1` 的 `gaps` 第二、三条）。

## 2 两臂结构（判据④的落盘列）

| 行 i | `win32` 可见集 | `dil32` 可见集 | 计数 | 最远距离 |
|---|---|---|---|---|
| `i ≤ 31` | 全部因果（`i+1` 个） | 同左（`i+1` 个） | `i+1` | `i` |
| `i = 240` | `[209, 240]` | `[0, 15, 30, 45, 60, 75, 90, 105, 119, 134, 149, 164, 179, 194, 209, 224]` + `[225, 240]` | 32 | 240（窗口臂 31） |

`dil32` 的第 t 个空洞点 = `round(t·(P−1)/15)`，`P = i − 15`：**按行均匀铺满前缀**。
固定 stride 在 `i < 136` 时取不满 16 个点，会让两臂可见键数不等、破同预算对照，所以逐行取
dilation 而不是全局固定 stride——这是本实验对「空洞」的实装定义，写在 `run.py::dilated_keep_mask`。

## 3 为什么是「本设计下无信号」而不是「机制无效」（定律 10）

| 必须条件 | 本实验是否满足 |
|---|---|
| 信息确实超出可见范围 | **结构上满足**：可达距离 31 → 255 |
| 训练信号迫使其使用远处信息 | **不满足**：enwik8 字符级的局部先验足以补上这片上下文（定律 9 的「模型不需要」），12k 步、无必要性损失 |
| 有真实稀疏核 | **不满足**：稠密 bool 掩码 ⇒ 纸面 `O(T·k)` 没兑现成实测省算力 |
| 效应超过本格自测噪声 | **不满足**：bpc 差 0.01195 / 0.00696 都小于 0.014 带 |
| 判据仪器有分辨力 | **不满足（召回腿）**：四臂全贴 chance，任何 CI 差异都是 1–2 个命中 |

⇒ 结论只能记成「**本设计下无信号**」，不得读成「空洞采样没有价值」，也不得读成
「原来如此、显而易见」。

## 4 与 `1.2.2` / `1.2.3` 的关系（同轴同尺度的三笔交易）

- `1.2.2`（局部+全局）：把 8 个键切给**最前 8 个恒可见全局槽**，比 24 个键全给最近位置
  **差 0.023**（两 seed 同向、越带）——那笔交易越带为负。
- `1.2.3`（内容 top-k）：同样 32 个键**按内容挑**比按位置挑**好 0.078 / 0.077**（n=2，越带）。
- 本项（空洞）：同样 32 个键**按位置摊开**比按最近位置挑，差 **0.01195 / 0.00696**（同向、
  落带内）⇒ 在「该用哪种可见集」的排序上，本次读到的是：**按内容挑 ≫ 按最近挑 ≈ 摊开挑 ≫ 全局槽挤占**。
  三条都来自 13M / T=256 / 同一配方，跨格比较只作**参考线**（不同格、不同 run，不是配对差）。

## 5 未测项与边界（预登记之外不推断）

1. 只有 T=256 与 k=32 一点；长 T（≥2048）上「摊开」的价值可能完全不同（交叉点未实测）。
2. 逐层递增 dilation（LongNet 式）未测：本实验各层用同一张掩码。
3. 真稀疏核未做：省幅只是纸面上界。
4. 召回腿的仪器在本尺度没有分辨力（见 §3）⇒ 「远距离信息能不能被搬」这件事本身仍未在
   本仓被有效测量；需要「训练信号迫使使用长程」的任务（如合成关联回忆 + 长 T）。
5. 单尺寸、2 个 seed，不外推到 53.9M 及以上。
