# controls — 2622 · 长 T 首探 T=512

本实验的**对照臂**与主臂在**同一脚本、同一配方、同一数据流**下自包含双跑，不复用历史 run 作
判据臂（SCHEMA §9）。四个臂的相互关系：

| 臂 | 角色 | 对照关系 |
|---|---|---|
| `full-256` | T=256 的基线 | `win128-256` 的对照（同 T、同 token、同步数、同 seed） |
| `win128-256` | **第二点**（窗口 = T/2，相对刻度 50%） | 相对 `full-256` 的 Δ |
| `full-512` | T=512 的基线 | `win256-512` 的对照 |
| `win256-512` | **主臂**（窗口 = T/2） | 相对 `full-512` 的 Δ |

## §13 每个对照臂的三要素

- **输入分布**：char 级 enwik8（前 90M train / 末 10M eval），与主臂**同一份**；
- **要预测什么**：下一个字符（因果移位 CE）；
- **部署对应**：训练期可见窗口的开关（关闭 = 全上下文；T/2 = 位置式窗口注意力）。

## 口径

- **native 工作点**（判据①主口径）：窗口臂在**自身训练掩码**下评测；full 臂在全因果下评测。
- **release 口径**（并列）：窗口臂在**全可见**下评测（问「窗口训练出的权重还认不认远端信息」）。
- **方差界**：Δ < 0.014 不可排序（`docs/methodology.md §2`）。

## 已知限制（不在本实验预算内）

- n=1 单 seed，无重跑散度；Δ256=−0.0148 仅略微越过 0.014 界。
- 未做「同**步数**（12k@T=512）」的第二个口径点（本实验用 K10 主口径：同 **token** 98.3M）。
- 合成长程腿在 enwik8 训练的权重上是分布外任务 ⇒ 四臂全在 chance，**不能区分窗口与 full**；
  真正的对照需在合成任务上训练两臂（属另一实验）。
