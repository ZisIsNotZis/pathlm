# 2688 · 把两条「不可判」再补一步：判据② 的 k=128 到 n=5、判据⑥ 的 k=64 锚点杠杆到 n=4

> 归属：`axes/1-time/1.1.1-hard-window`（研究项 1.1.1「hard 窗口」）的 `WP2`（k 曲线两列口径）与
> `WP1` 的锚点腿收口。上游实验：同目录 `2686-window-kcurve-seed2-13m`（n=3 读数与「上一轮推断被否定」
> 的实测），再上游 `2682-window-kcurve-13m`（判据线与全部 n=2 读数）。
> 入口：`train_arms.sh`（取/放 §20 GPU 锁，逐臂；先过 `prereg_bind.py --require`）→
> `make_config.py`（训练后生成 `config.json`，落检查点 sha256）→ `run.py`（复现门 + 判据② + 判据③ + 自检）。
> 判据线与口径常数只写在**本文件与 `run.py`**（= `prereg_binding.json::contract_files`）。

## 1 命题（可证伪）

`2686` 把 `2682` 的两条读数补到 n=3，两条**仍是** `undecidable`：

| 项 | n=3 落盘值（`../2686-window-kcurve-seed2-13m/results.json`） | 区间 | 判定 |
|---|---|---|---|
| 判据② k=128 的训练期窗口税 | 0.012607 / 0.009808 / 0.002762，均值 **+0.008392**、`sd` **0.005073** | [−0.004211, +0.020995]（df=2） | `undecidable`（跨冻结带 0.000983；`n_req = 4`） |
| 判据⑥ k=64 的锚点杠杆价 `bpc(win64a) − bpc(win64)` | −0.007652 / −0.008982 / −0.003166，均值 **−0.0066**、`sd` **0.003047** | [−0.014171, +0.000971]（df=2） | `undecidable`（区间含 0） |

**本实验要判死的两句话**（判据线**继承**、不新增，见 §6 判据⑤）：

1. k=128 的窗口税在 **n=5** 下是不是**确定越带**（区间下界 > 冻结带 0.000983）；
2. k=64 的锚点杠杆价在 **n=4** 下是不是**确定非 0 且为负**（区间整体 < 0）。

预测（写下时本轮读数尚未产生）：

- 判据②：n=5 ⇒ df=4 ⇒ `t = 2.776`。若 `sd` 停在 0.005073 ⇒ 半宽 = 2.776·0.005073/√5 = **0.006298**，
  下界 = 0.008392 − 0.006298 = **+0.002094 > 0.000983** ⇒ **预测 `above_band`**。该预测成立的前提是
  `sd ≤ 0.005968`（由 `mean − t·sd/√5 > band` 反解）。若新 seed 的税明显更低（`2686` 的 seed 2 就是这样，
  税 0.002762 对 s0/s1 的 0.012607 / 0.009808）⇒ `sd` 上升、预测不成立 ⇒ **照实报 `undecidable`**，不得挑 seed。
- 判据③：n=4 ⇒ df=3 ⇒ `t = 3.182`。若 `sd` 停在 0.003047 ⇒ 半宽 = 3.182·0.003047/2 = **0.004848**，
  上界 = −0.0066 + 0.004848 = **−0.001752 < 0** ⇒ **预测 `decidable` / `price_negative`**。
  该预测成立的前提是 `sd ≤ 0.004148`（由 `mean + t·sd/2 < 0` 反解）。

**必须不变**：判据线与口径常数一字不改（冻结带 0.000983、`T_CRIT_95`、评测仪器 96×16 / `window_seed=2`）；
`2682` 与 `2686` 的契约文件一字节不动（两个目录都已绑定，改它就要重绑，`bound_at` 会被推到读数之后）。

## 2 为什么是这一步，而不是「换带」

- 两条不可判的**约束是区间宽度，不是带的量级**：n=3 的半宽 0.012604（k=128）与 0.007608（k=64 杠杆）
  都大于效应量本身（0.008392 与 0.0066）。
- **判据⑥ 的规则里没有带**（`../2686-window-kcurve-seed2-13m/README.md` §6 判据③ 与 `../2686-window-kcurve-seed2-13m/results.json::criteria.c3_anchor_lever_k64_n3.verdict.rule`：
  「t 区间不含 0 ⇒ 可判」）⇒ 带的量纲不可能是它的成因。
- **判据② 的带方向相反**：规则是 `above_band = 区间下界 > 带` ⇒ 带越**小**越容易判「税存在」。
  n=3 的下界是 −0.004211（负），任何 ≥ −0.0042 的带都判不出越带 ⇒ 卡住的是半宽 > 效应量，不是带的量级。
- **若真按「带 = 配对差散布」改**：`|mean − 带| = |0.008392 − 0.005073| = 0.003319` ⇒ 预登记功效式给
  `n_req = ⌈(2.9·0.005073/0.003319)²⌉ = 20`（现值 4）——比现在**更远**；若改成「mean vs 带」的点判据则
  0.0084 > 0.005 ⇒ 直接判「税存在」。两种读法结论相反 ⇒ 这个改法连「换成多大的带 + 配哪条判定规则」都还没定义，
  不该在本轮上抬成用户裁决。
- **按未改的规则只差 seed**：判据② 从 n=3 到 n=5（+2 臂）、判据⑥ 从 n=3 到 n=4（+1 臂 + 它的配对臂，共 2 臂）。
- **上一轮「补 1 个 seed 即判」被否定的实际内容**，是**基于 n=2 两点 `sd` 的半宽估计**（0.001979 / 0.00094
  涨到 0.005073 / 0.003047），不是「补 seed 这条路本身无效」：本轮用 n=3 的 `sd` 重算门槛（上面两条预测的
  前提 `sd ≤ 0.005968` / `≤ 0.004148`），是**同一条未改规则**的下一步。

## 3 显式非目标（本轮**不**做的事）

- **不换带**：「以配对差散布替代单臂噪声带」是判据带宽的口径取舍（`AGENTS.md` §3.3 纪律 3 的框架性取舍），
  按 §2 的算术它现在还不该上抬——先把这条便宜路径走完。它是 `project.yaml::gaps` 的口径登记项，不是本轮的收口路径。
- **k=192 不补到可判**：`2682` 的 k=192 均值 −0.000387、`sd` 0.002638 ⇒ 预登记功效式 `n_req = 32`，
  按实际 t 区间约需 n≈17（≈15 个新臂 ≈135 min GPU）⇒ 本实验**不取得**这条读数。
- **不重谈 T 子线**（`2636` 承接），**不加锚点 k 的第三档**，**不动 `2682` / `2686` 的契约与读数**。

## 4 单因素声明与仪器不变声明

- **基底**：stock dense decoder-only trunk（d256 × 12 层 × 8 头 × mlp6 × T256），与 `2662` / `2682` / `2686` 逐字段同一规格。
- **唯一新变量 = seed 3**（k=128 另加 seed 4）：`win128_s3` / `win128_s4` 相对已有 `win128_s0..s2` 只有 seed 不同；
  `win64_s3` 与 `win64a_s3` 同理——判据③ 是**同 seed 配对**价 `bpc(win64a) − bpc(win64)`，没有 `win64_s3` 就没有配对，
  不得改用未配对的跨 seed 差（那会把种子间质量散布 ≈0.003 混进 0.0066 的效应里）。
- **仪器逐字不变**：bpc = `realtext_probe.win16_bpc`，96×16、`window_seed=2`、391,680 个评测 token；
  `realtext_probe.py` 是本目录副本，与 `2682` / `2686` 的**逐字节相同**（`sha256 = dbddeb5f…`，`run.py` 的 `code_hashes` 会记它）。
- **掩码实现不改**：窗口臂用 `window_anchor_keep_mask(256,k,a)`；判据① 用共享底座的只读调用核对。
- **不改共享文件**：`pathlm/**`、`train_depth_ar.py`、`tools/**`、`tests/**`、元级文档一律不碰。

## 6 判据线（**预登记：写下后不得改**）

| # | 判据 | 判定线 | 该涨 / 该跌 / 必须不变 |
|---|---|---|---|
| ① | **复现门（仪器自检）** | 用本目录 `run.py` 重评 `2686` 目录内已有的 10 条 checkpoint（`full`、`win64_s0/s1/s2`、`win64a_s0/s1/s2`、`win128_s0/s1/s2`），clean bpc 与 `../2686-window-kcurve-seed2-13m/results.json` 落盘值**逐位相等**（6 位小数）。不等 ⇒ **本实验作废**，先修仪器，不得改判据线去凑 | **必须不变** |
| ② | **判据② k=128 的窗口税补到 n=5** | 逐 seed 税 `tax(128,s) = bpc(win128_s) − bpc(full)`（同 seed 配对，s ∈ {0,1,2,3,4}）；跨 seed 均值 + t 区间（双侧 α=0.05，df=4 ⇒ 2.776），按 `../2682-window-kcurve-13m/README.md` §5a 的**三分类**判：`above_band`（区间下界 > 冻结带 0.000983）/ `below_band`（区间上界 < 冻结带）/ `undecidable`（其余，**必须**附 `n_req`） | 该跌（k 越大税越小）；本档判「越带与否」 |
| ③ | **判据⑥ k=64 的锚点杠杆补到 n=4** | 逐 seed 价 `price(64,s) = bpc(win64a_s) − bpc(win64_s)`（同 seed 配对，s ∈ {0,1,2,3}）；跨 seed t 区间**不含 0** ⇒ 可判并报方向；**含 0** ⇒ `undecidable` + `n_req`；并与 k=16 的 −0.00706（`2681` 判据⑦，n=4）并列报 | 该跌（锚点使 clean bpc 更低 ⇒ 价为负） |
| ④ | **自检（必须不变）** | 因果性：只改后半段 token ⇒ 前半段 logits `max\|Δ\| == 0`（四个新臂各一次）；掩码可见对数与闭式 `visible_pairs(256,w,a)` 一致且等于 `(64,0)=14368` / `(64,8)=15876` / `(128,0)=24640`；四新臂与复用臂参数量逐位相同（13,536,768）；`recent_keep_mask(256,64)` / `(256,128)` 与对应窗口掩码逐位相同 | **必须不变** |
| ⑤ | **判据线继承声明（不是判据，是定序）** | 本实验**不新增判据线**：② 与 ③ 是 `2682` §5a / `2686` §6 的同一条规则在更大的 n 上重算，冻结带、`t` 表、功效式、三分类、配对规则**一格不动**。**补 seed 不改判据**：本轮只增大样本量，任何把判定线放宽的改动都不允许（要换带就另起一份契约，见 §3） | 必须不变 |

### 6a 判据② 的「不可判」写法（照抄 `2682` / `2686` 的冻结规则，不重算带）

`undecidable` 不是「没结论」，是「本 n 下不可判 + 给出所需样本量」：
`n_req = ceil((2.9·sd/|mean − σ_cell|)²)`（1.96+0.84 近似功效式）；`mean == σ_cell` ⇒ `n_req = null` 并注明
「效应恰在带边界上，样本量不救」。`σ_cell` **冻结为 0.000983**（`2662` 的两 seed 极差），本实验**不重算、不回填**；
本 n 的种子极差只作描述量（`seed_range_observed`）另报。跨格带 0.014 只作参考，两带并列、不混用。

### 6b 判据③ 的读法边界

价 `price` 是**同 seed 配对差**，因此它天然抵消了种子间质量散布；它的量纲仍是 clean bpc。判据③ 只判
「这个价在本 n 下是不是非 0」——**不判**「锚点值不值得买」：buy 的代价（可见键 64→72、每位置多 98,304 B KV）
与收益的净算术在 `../2682-window-kcurve-13m/analysis.md` 与 `2662` / `2679` 里，另有其判。

## 7 否证条件

- 判据① 不过 ⇒ 本实验作废：不写判词，先查窗口序 / 掩码 / 权重 / 仪器，修完重跑。
- 判据② 新 seed 的税与已有点反号或明显更低 ⇒ 如实报（`sd` 上升、区间更宽），**不得**剔除该 seed。
- 判据③ 新 seed 的价为正 ⇒ 如实报；若区间因此含 0，判词仍是「不可判」而不是「锚点无效」。
- 任何一条预测不成立 ⇒ 在 `analysis.md` 里写清「原本以为会怎样 / 实际怎样 / 排除了哪些别的解释」。

## 9 口径与纪律

- GPU：单卡共享，按 `harness/SCHEMA.md` §20 取锁；一次一个作业；单臂 `timeout 1200`（≤20 min）；
  等锁 >40 min 退让并如实登记（不抢别人的进程、不改别人的锁）。
- 判据线、冻结带、仪器参数**写下后不改**；读数只进 `results.json` 与 `analysis.md`，不进契约文件。
- 只做单轴单格实验；组合默认留白（`harness/SCHEMA.md` §4）。

## 10 复现

- 克隆内可重算的部分：`run.py` 的复现门与判据②③ 的算术都由本目录 `results.json` + `reproduce` 重算，
  但 bpc 读数需要权重（`*.pt` 不入库）⇒ 本实验对别的克隆是 `rebuildable_only`：
  按 §5 的配方重训 4 个新臂，再跑 `make_config.py && run.py`。
