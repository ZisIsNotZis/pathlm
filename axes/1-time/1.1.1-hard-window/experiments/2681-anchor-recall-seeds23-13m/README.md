# 2681 · 锚点召回腿补到 n=4：那个「不可判」是样本不够，还是仪器不够？

> 归属：`axes/1-time/1.1.1-hard-window`（研究项 1.1.1「hard 窗口」）的 **WP3 检索腿复核**。
> 入口：`train_arms.sh`（取/放 §20 GPU 锁，逐臂；先过 `prereg_bind.py --require`）→
> `make_config.py`（训练后生成 `config.json`，落检查点 sha256）→ `run.py`（复现门 + 质量腿 +
> 锚点召回腿 + **n=4 跨 seed 主判** + 毁源探针 + 自检）。
> 判据线与口径常数只写在**本文件与 `run.py`**（= `prereg_binding.json::contract_files`）；
> `config.json` 是训练后生成的产物（臂路径 + sha256），`run.py` 开跑前逐字段核对它。

## 1 命题（可证伪）

`2662` 把锚点臂（窗口 16 + 锚点 8）的召回腿量成 **不可判**：预登记门是「**两个 seed 都过两套 CI**」，
而 seed 0 只有配对 bootstrap 排除 0（+2.592pp，Newcombe CI 含 0），seed 1 两套 CI 都含 0
（+1.097pp）。`gaps` 记的下一步是「补 seed 2/3，把这条腿从 n=2 不可判变成可判」。

**本实验先把那一步能不能做到算清楚，再跑。** 一句话：*如果「不可判」的原因是**样本不够**，那
补 seed 就该把它压成可判；如果原因是**判定单位错了**（预登记门是逐 seed 的合取式，而单个
seed 的 1,003 根针根本没有分辨 1–3pp 的功效），那补再多 seed 也不会可判——因为它只增加合取项。*

可证伪的形式：*对同一仪器、同一配方，只把**种子数从 2 加到 4**（`win16a_s2/s3` 新训，
`win16a_s0/s1` 复用同一条 checkpoint 重评），用**种子层**的统计量判定*
⇒ 若 4 个 seed 的 `Δ_pp` 均值 > 0、≥3/4 同向、且**两个**跨 seed 区间的下界都 > 0，则这条腿
在本仪器上**可判**（锚点桶召回高于配对地板）；否则如实写「不可判」并指名是哪一级不够
（逐 seed 分辨力 / 跨 seed 变异）。

## 2 为什么这是该做的动作（换成这个口径的依据）

分诊表给本格的单一动作是「补 seed 2/3」。**补 seed 本身留着**（本实验训练 `win16a_s2/s3`）；
**换掉的是判定单位**，依据是 `2662` 已落盘读数的功效算术（不涉及本实验任何新读数）：

**（a）逐 seed 的门在现有仪器上功效近乎 0。** `2662` 的锚点桶 = 1,003 根针，锚点臂植入/地板
召回 ≈ 47–48% ⇒ 未配对两比例差的 95% 半宽 ≈ **±4.37pp**（实测 `[−1.774, 6.958]` 的半宽 4.366）。
要把下界推到 0 以上，需要的每 seed 针数 = `1.96²·p̄q̄ / Δ²`（`p̄q̄ ≈ 0.4977`）：

| 效应量 `Δ_pp` | 未配对两比例差（Newcombe 变体）需要的针/seed | 按针配对 bootstrap 需要的针/seed |
|---|---|---|
| 2.592（seed 0 实测） | ≈ 2,850 | ≈ 320 |
| 1.844（两 seed 均值） | ≈ 5,900 | ≈ 640 |
| 1.097（seed 1 实测） | ≈ 15,900 | ≈ 1,800 |

现有仪器 = **1,003 根/seed** ⇒ 对 1–3pp 的效应，**逐 seed 的合取式门必然判不出**；
加 seed 只是给这个合取式加约束项，因而**永远**到不了「两个（四个）seed 都过」。

**（b）为什么不是「加针」而是「换判定单位」。** 加针到 15,900 根/seed 需要 `n_batches`
从 64 提到 ~1,000（`needle_raw.json` 从 ~8.5 MB 涨到 ~135 MB），而且改的是针密度这个口径；
而**种子**才是「换成别的训练随机性还会不会为正」这一问题的重复单位——召回腿要回答的正是
后者。两级 bootstrap（重采 seed + seed 内重采针）把两级不确定性都算进去，且不改仪器。

**（c）本动作不碰的三样东西**：判据线（§5）、方差带（§5b 冻结 0.000983）、配对口径
（仍按针配对、仍报 Newcombe + 配对 bootstrap 两套）——**一项都不改**，只是把它们从「门」
降级为「如实报的读数」。

## 3 单因素声明与仪器不变声明

- **基底**：stock dense decoder-only trunk（d256 × 12 层 × 8 头 × mlp6 × T256），与
  `2662` / `2634` 逐字段同一规格。
- **唯一新变量 = 训练 seed**（0/1 → 再加 2/3）。`win16a_s2/s3`（窗口 16 + 锚点 8）与
  `win16_s2/s3`（窗口 16 + 锚点 0）的配方与 `2662` / `2634` 的对应臂**逐字段一致**，只差
  `--seed`。**纯窗 seed 2/3 是本实验训练的**：锚点臂的配对价格（`price_bpc`）需要同 seed 的
  纯窗对照，否则新 seed 只有半条腿。
- **仪器逐字不变**（这是 n=4 能成立的前提）：`realtext_probe.py` / `needle_stats.py` /
  bpc 96×16 `window_seed=2` / needle `n_needles=8, phrase_len=6, anchor_frac=0.25,
  n_batches=64, batch_size=16, seed=3, bucket_anchors=8` —— 全部与 `2662` 逐字段相同，
  并由**判据①复现门**机检：复用臂（seed 0/1）的 bpc 与锚点桶 `(n, planted_hits, control_hits)`
  必须与 `2662` 落盘值**逐位相同**。
- **不改共享文件**：`pathlm/**`、`train_depth_ar.py`、`tools/**`、`tests/**`、元级文档一律不碰；
  `realtext_probe.py` / `needle_stats.py` 是 `2662` 的目录内副本。

### 3b 臂清单的可选位（**在读数产生之前**登记的资源性收口）

本实验的 4 个新臂（`win16a_s2/s3`、`win16_s2/s3`）都要占一次 GPU 训练窗口，而本机上的
更高优先级作业随时会把卡占住。因此把**臂清单**分成两档，写死在 `run.py::CONTRACT_ARMS_*`：

- **必到（7 臂）**：`win16a_s0/s1/s2/s3`（召回到判据的 4 个被干预臂）、`win16_s0/s1`（seed 0/1 的
  配对价格 + 判据①的复现门）、`full`（全因果参照）。
- **可选（2 臂）**：`win16_s2/s3`——它们**只**服务质量腿（判据⑦）的同 seed 配对，**不进召回腿的
  任何判据**（判据②③ 的地板来自同一 generator 的 `plant=False` 控制臂，与纯窗臂无关）。

若可选臂因外部 GPU 占用未训完：`make_config.py` 把它们记入 `missing_new_arms`，本实验**照常出判**，
判据⑦ 的 n 如实回落到可用的 seed 数并在 `analysis.md` 与 `project.yaml::gaps` 里登记。
**判据线 ①–⑥ 的常数、阈值、CI 实现、方差带一字不改**；能变的只有判据⑦ 的样本量，且样本量只能变小
（= 只能让结论更弱，不会更强）。

## 5 判据线（**预登记：写下后不得改**）

| # | 判据 | 判定线 | 该涨 / 该跌 / 必须不变 |
|---|---|---|---|
| ① | **复现门（仪器自检）** | 复用臂 6 个 checkpoint 的 clean bpc 与 `2662::quality_leg.bpc` **逐位相等**，且 `win16a_s0/s1` 的 anchor / beyond 桶 `(n, planted_hits, control_hits)` 与 `2662` 落盘值逐位相等。不等 ⇒ **本实验作废**（读数不入账，先修仪器）；不得改判据线去凑 | **必须不变** |
| ② | **per-seed 读数（口径不变，如实报，不作门）** | 逐 seed `Δ_pp = 植入召回 − 配对地板召回`，两套 CI 并列：Newcombe 两比例差（正态近似/未 pooling）+ 按针配对 bootstrap（2,000 次）。**不挑 seed、不丢 seed** | 该涨（正 = 植入更高） |
| ③ | **n=4 主判（跨 seed）** | 4 个 seed 的 `Δ_pp`：①`≥3/4` 严格 > 0；②均值 `mean(Δ_pp) > 0`；③**两个**跨 seed 区间的下界都 > 0——区间 A = t 区间（df=3，双侧 α=0.05，`t=3.182`），区间 B = 两级 bootstrap（重采 seed + seed 内重采针，2,000 次，百分位 2.5/97.5）。**三项全过 = 可判**；任一不过 = **本 n 下不可判**，如实报 | 该涨 |
| ④ | **负对照（窗外仍停地板）** | `beyond` 桶（非锚针且有位置不可见）4 个锚点臂的植入 vs 地板差，Newcombe 95% CI **含 0** | 该跌（停地板） |
| ⑤ | **毁源敏感度（负对照）** | 两变体：A `far_all` 毁 `[0,64)`（锚点臂必然敏感，`premise_holds=false`）；B `beyond_anchor` 毁 `[8,64)`（锚点臂 `max|Δlogit| == 0`） | 必须不变（变体 B）/ 必然变（变体 A，物理事实） |
| ⑥ | **因果性 + 掩码自检** | 只改后半段 token ⇒ 前半段 logits 逐位不变（`max|Δlogit_prefix| == 0`）；`visible_pairs(16,8)=5868`、`(16,0)=3976`；锚点臂与纯窗臂参数量逐位相同（13,536,768） | 必须不变 |
| ⑦ | **质量腿（n=4，旁证）** | `price_bpc = bpc(win16a) − bpc(win16)`（同 seed）；报 4 个配对值与跨 seed 均值 + t 区间；与**冻结**的 0.000983 本格带、0.014 跨格带并列比 | 如实报 |

### 5a 判定单位变更的登记（本文件最重要的一条口径变更）

`2662` 的门写的是「**两个 seed 都过才算该腿有区分力**」。本实验把它改成 **§5 判据③ 的种子层
判据**，理由与范围写死在这里：

- **理由**：见 §2 的功效表——在 1,003 根针/seed 下，逐 seed 的合取式对本格实测的 1–3pp 效应
  功效近 0（需要 2,850–15,900 根/seed）；这不是「信号不存在」，是「仪器在这个 n 下分不出来」。
- **不变的部分**：CI 的两套实现、配对口径、α=0.05、每 seed 的针数、仪器参数、方差带
  （§5b）——**一字未改**；旧门要求的 per-seed 读数仍在 `results.json::criteria.c2_*` 里逐项
  如实报出，`passes_both` 逐 seed 也照旧给。
- **新加的部分**：跨 seed 均值与两个跨 seed 区间（`criteria.c3_cross_seed_n4`）。这是**新信息**
  （n=4、种子层），不是对旧读数的重新解释；旧读数的判定结论（不可判）不改写。
- **反悔的代价**：若判据③ 判「可判」，结论必须同时写出「逐 seed 的门仍未过」——两条同时成立
  （效应为正且可判；单 seed 的分辨力不够），不得只挑对自己有利的那条。

### 5b 方差带与两带纪律（冻结）

- 本格自测带 **`sigma_cell = 0.000983`** 是 `2662` 的两 seed 极差，**本实验不重算、不改**；
  4 个 seed 的极差会更大（样本更多必然更宽），那一列只作**描述量**另报
  （`quality_leg.bands.seed_range_observed_n4`），**不得回填成新带**。
- 跨格带 **0.014** 只作参考；两带**并列报、不混用**（C1 裁决）。召回等率类指标走 CI 下界，
  **不借用量纲不符的 bpc 带**。

## 6 否证条件

- 判据① 不过 ⇒ 本实验**作废**：不写判词，先查窗口序 / 掩码 / 针参数 / 权重，修完重跑。
- 判据③ 判「不可判」 ⇒ 结论必须写成「**仪器不够**」并指名哪一级不够（逐 seed 分辨力 / 跨 seed
  变异），**不得**写成「锚点无信号」，并给出下一步的最小实验与成本。
- 判据④ 出现某个锚点臂的 beyond 桶**显著高于**地板 ⇒ 锚点真的在搬运窗外内容（与 `2662`
  的结论冲突），必须复查掩码与探针，不得直接改结论。
- 出现 `Δ_pp` 异向（某些 seed 为负）⇒ 如实报异向，不得挑 seed。

## 7 成本与预算

- 训练：4 臂 × 12k 步（≈10–13 min/臂，`2662` 实测 13.07 / 9.43 min）⇒ **≤ 60 min GPU**；
  评测：9 臂 × (96 批 bpc + 64 批针 + 2 个毁源变体) ≈ 3 min GPU（`2662` 的五臂全电池实测 1.32 min）。
- **预算上限：90 min GPU / 210 min 墙钟**。不够时**砍什么**（SCHEMA §17.7 / §20.3）：
  先砍毁源探针的批数（96→32，只影响诊断列）> 再砍 `full` 臂（不影响判据）> **不砍臂、
  不砍 seed 数（n=4 是判据③的全部）、不砍判据线**。
- 共享机器纪律：单卡 4090 且 `local_lm_research` 优先 ⇒ **同一时刻只跑一个 GPU 作业**、
  逐臂取/放 `/tmp/pathlm_gpu.lock`、臂间 ≥61 s；等锁 >40 min 则退让并如实登记。
