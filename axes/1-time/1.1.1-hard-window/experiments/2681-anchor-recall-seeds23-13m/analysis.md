## 0 人话摘要（先看这段）

**问题**：上一轮（`2662`）量到「给窗口 16 的模型再加最前面 8 个字节恒可见（锚点槽）之后，
扎在锚点区里的针被接出来的比例比不扎针的地板高一点点」——seed 0 高 2.592 个百分点，
seed 1 高 1.097 个百分点——但按当时预登记的门（「**两个 seed 都要过两套 CI**」）判了**不可判**。
这一轮要判死的是：到底是样本不够，还是那个门本身分不出这么小的效应。

**答案：是门的问题，不是样本的问题。** 4 个 seed 一起来看，锚点区的召回**确实**高于地板：

- 四个 seed 的差分别是 **+2.592 / +1.097 / +0.997 / +2.393 个百分点**，**四个全为正**；
- 平均 **+1.770 个百分点**；
- 换成别的种子还成不成立？两个跨 seed 区间都排除 0：t 区间（df=3）**[0.434, 3.105]**、
  两级 bootstrap（重采种子 + 种子内重采针）**[0.698, 2.841]**。
- 人话量级：锚点区的植入召回约 **47–50%**（四个 seed 的 `planted_recall` = 0.481555 /
  0.482552 / 0.468594 / **0.497507**），地板也在这个水位（0.455633 / 0.471585 / 0.458624 /
  0.473579），所以 **+1.77pp 是相对地板约 +3.8%
  的抬升**——小，但方向稳定、四个种子一致。

**为什么「补 seed」本身补不出这个结论**：旧门是一个**逐 seed 的合取式**。单个 seed 只有 1,003 根
锚点区针，地板召回 ≈45–47%，未配对两比例差的 95% 半宽就是 **±4.37 个百分点**；要把下界推过 0，
1–3pp 的效应需要 **2,850–15,900 根/seed**（`README.md` §2 的功效表）。也就是说**单个 seed 永远过
不了那道门**，补 seed 只是往合取式里加约束项——n=4 也一样过不了：本轮四个 seed 的
`passes_both` **仍然是 false**（见 §2 判据②）。这不是自相矛盾，而是同一件事的两面：
**效应在种子层面可判、在单 seed 层面不可判。**

**仪器是被验证过的，所以这把「旧 2 个 seed + 新 2 个 seed」合起来算是有依据的**：复现门（判据①）
逐位成立——`2662` 那 5 个复用 checkpoint（`win16a_s0/s1`、`win16_s0/s1`、`full`）的 clean bpc、
以及锚点臂 anchor/beyond 桶的 `(n, planted_hits, control_hits)` 全部**逐位相同**。
同一个仪器、同一条 checkpoint、只多两个种子。

**质量腿也补到了 n=4（判据⑦）**：纯窗 seed 2/3 两臂（`win16_s2/s3`）在 GPU 让位排队后也训完了，
所以同 seed 的配对价格有 4 个：**−0.005583 / −0.007294 / −0.005658 / −0.009707 bpc**，
4/4 同向（负 = 锚点更好），均值 **−0.00706**，跨 seed t 区间（df=3）**[−0.010136, −0.003985]**
**不含 0** ⇒ 人话：**多花 50% 可见键换 0.35%–0.60% 的质量改善，四个种子都给这个方向**；
但仍**不越** 0.014 跨格带（`sortable_vs_0.014` 全 false）。

## 3 怎么读判据② 与判据③ 同时成立（这不是矛盾）

- **判据③ 回答的问题**：「换成别的训练随机性，锚点桶召回还会不会高于地板？」→ 会，均值 +1.77pp、
  两个跨 seed 区间都不含 0。这是**本实验要回答的那个问题**（也是 `2662` 留下的 `gaps` 里那条）。
- **判据② 回答的问题**：「**某一个** seed 自己能不能分辨出这个效应？」→ 不能。1,003 根针、
  未配对两比例差 ±4.37pp，而效应 1–3pp；功效表算出来要 2,850–15,900 根/seed。
- 所以两条读数的合并结论是：**锚点抬高锚区召回 = 真（种子层可判）；单个 seed 的仪器分辨力不够
  = 也真**。写成「锚点无信号」是错的；写成「每个 seed 单独都显著」也是错的。
- **不许拿这条去夸大规模**：`+1.77pp` 是在 enwik8 / T=256 / 13M / 12k 步 / 窗口 16 + 锚点 8 上、
  4 个 seed 的均值；跨尺度、跨任务不外推。

## 6 结论与下一步

- **结论**：锚点槽抬高了锚点区的召回（4 seed 均值 **+1.77pp**，4/4 同向，两个跨 seed 区间不含 0）
  ⇒ 「不可判」的成因是**判定单位（逐 seed 合取式）在本仪器的分辨力下功效近 0**，不是「无信号」。
  窗外桶仍停地板（4/4 CI 含 0）、对锚点槽之外的前缀仍逐位不敏感 ⇒ **锚点仍不是把远处搬近的通道**。
- **下一步最小实验**（不在本轮）：等键数 24 键对照臂（窗口 24 + 锚点 0），拆「哪 8 个键」那一半归因
  （1 臂 ≈10 min GPU + 复用 `axes/1-time/1.1.1-hard-window/experiments/2679-anchor-eval-ablation-13m/run.py` 评测）。
- **禁外推**：enwik8 / T=256 / 13M / 12k 步 / 窗口 16 + 锚点 8 / 4 个 seed。
