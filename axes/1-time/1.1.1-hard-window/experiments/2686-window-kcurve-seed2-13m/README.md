# 2686 · 把两条「不可判」补到 n=3：判据② 的 k=128 与判据⑥ 的 k=64 锚点杠杆

> 归属：`axes/1-time/1.1.1-hard-window`（研究项 1.1.1「hard 窗口」）的 `WP2`（k 曲线两列口径）与
> `WP1` 的锚点腿收口。上游实验：同目录 `2682-window-kcurve-13m`（判据线 + 全部 n=2 读数）。
> 入口：`train_arms.sh`（取/放 §20 GPU 锁，逐臂；先过 `prereg_bind.py --require`）→
> `make_config.py`（训练后生成 `config.json`，落检查点 sha256）→ `run.py`（复现门 + 判据② + 判据③ + 自检）。
> 判据线与口径常数只写在**本文件与 `run.py`**（= `prereg_binding.json::contract_files`）。

## 1 命题（可证伪）

`2682` 的两条读数在本 n（=2）下**不可判**，两条都已写明「补 1 个 seed 即判」：

| 项 | n=2 落盘值（`2682/results.json`） | 区间 | 判定 |
|---|---|---|---|
| 判据② k=128 的训练期窗口税 | +0.012607 / +0.009808，均值 **+0.011208** | [−0.006575, +0.028990]（df=1） | `undecidable`（跨冻结带 0.000983） |
| 判据⑥ k=64 的锚点杠杆价 `bpc(win64a) − bpc(win64)` | −0.007652 / −0.008982，均值 **−0.008317** | [−0.016766, +0.000132]（df=1） | `undecidable`（区间含 0） |

**本实验要判死的两句话**：
1. k=128 的窗口税在 n=3 下是不是**确定越带**（区间下界 > 0.000983）；
2. k=64 的锚点杠杆价在 n=3 下是不是**确定非 0 且为负**（区间整体 < 0）。

预测（写下时尚未产生本轮读数）：

- 判据②：`2682/analysis.md` 的推导给出 n=3 时半宽 ≈ 4.303·0.001979/√3 = 0.004917 < 0.011208 − 0.000983
  ⇒ **预测 `above_band`**。该推导假定新 seed 的税与已有点同量级；若新 seed 的税落得低（< ≈0.0035），
  跨 seed `sd` 会上升而使区间重新跨带 ⇒ **预测不成立也照实报 `undecidable`**，不得挑 seed。
- 判据③：同理半宽 ≈ 4.303·0.00094/√3 = 0.002335 < 0.008317 ⇒ **预测区间整体 < 0（可判为负）**，
  方向与 k=16 的 n=4 均值 −0.00706（`2681` 判据⑦）一致。若区间仍含 0 ⇒ 照实报 `undecidable`。

**必须不变**：判据线与口径常数一字不改（冻结带 0.000983、`T_CRIT_95`、评测仪器 96×16 / `window_seed=2`）；
`2682` 的 `README.md` / `run.py` 一字节不动（它已绑定，改它就要重绑，`bound_at` 会被推到读数之后）。

## 2 为什么这是该做的动作

- 两条不可判的**唯一**缺口是样本量，而每个 seed 的代价 ≈ 9 min GPU（`2682` 的 `train_driver.log`
  实测 8–10 min/臂）。补 1 个 seed 就把两条变成可判，是本格当前性价比最高的收口。
- 不能在 `2682` 里补：它的 `run.py::CONTRACT_ARMS` 与 `CONTRACT_SEEDS` 是**已绑定**的判据面
  （`prereg_binding.json`，`readings_existing_at_bind` 为空 = 绑定那刻目录内没有任何读数），
  加臂就必须改契约文件 ⇒ 只能 `--rebind`，而重绑会把 `bound_at` 推到读数之后，定序不再成立。
  所以**新臂另起一份契约**（本目录），旧读数原样引用为「既有种子的同仪器复评」。
- 与 `2681` 同一个做法：`2681` 就是给 `2662` 的 n=2 补 seed 2/3 而单开的目录。

## 3 显式非目标（本轮**不**做的事）

- **k=192 不补到可判**：`2682` 的 k=192 均值 −0.000387、`sd` 0.002638 ⇒ 预登记功效式给 `n_req = 32`，
  按实际 t 区间约需 n≈17（≈15 个新臂 ≈135 min GPU）。本轮**不取得**这条读数，判词继续写「本 n 下不可判」。
  替代路径（需用户裁决，不在本实验）：把带换成本格真正需要的量（价格散布而非单臂噪声），
  那条路要的是新契约，不是更多 seed。
- **不重谈 T 子线**（`2636` 承接），**不加锚点 k 的第三档**，**不动 `2682` 的两列口径**。

## 4 单因素声明与仪器不变声明

- **基底**：stock dense decoder-only trunk（d256 × 12 层 × 8 头 × mlp6 × T256），与 `2662` / `2682` 逐字段同一规格。
- **唯一新变量 = seed 2**（两个新臂 `win128_s2`、`win64a_s2` 各只有 seed 不同）**以及 seed 2 的配对臂
  `win64_s2`**——判据③ 是**同 seed 配对**价 `bpc(win64a) − bpc(win64)`，没有 `win64_s2` 就没有配对，
  不得改用未配对的跨 seed 差（那会把种子间质量散布 ≈0.003 混进 0.0083 的效应里）。
- **仪器逐字不变**：bpc = `realtext_probe.win16_bpc`，96×16、`window_seed=2`、391,680 个评测 token；
  `realtext_probe.py` 是本目录副本，与 `2682` 的逐字节相同（`run.py` 的 `code_hashes` 会记它的 sha256）。
- **掩码实现不改**：窗口臂用 `window_anchor_keep_mask(256,k,a)`；判据① 用共享底座的只读调用核对。
- **不改共享文件**：`pathlm/**`、`train_depth_ar.py`、`tools/**`、`tests/**`、元级文档一律不碰。

## 6 判据线（**预登记：写下后不得改**）

| # | 判据 | 判定线 | 该涨 / 该跌 / 必须不变 |
|---|---|---|---|
| ① | **复现门（仪器自检）** | 用本目录 `run.py` 重评 `2682` 目录内已有的 7 条 checkpoint（`full`、`win64_s0/s1`、`win64a_s0/s1`、`win128_s0/s1`），clean bpc 与 `2682/results.json` 落盘值**逐位相等**（6 位小数）。不等 ⇒ **本实验作废**，先修仪器，不得改判据线去凑 | **必须不变** |
| ② | **判据② k=128 的窗口税补到 n=3** | 逐 seed 税 `tax(128,s) = bpc(win128_s) − bpc(full)`（同 seed 配对，s ∈ {0,1,2}）；跨 seed 均值 + t 区间（双侧 α=0.05，df=2 ⇒ 4.303），按 `2682/README.md` §5a 的**三分类**判：`above_band`（区间下界 > 冻结带 0.000983）/ `below_band`（区间上界 < 冻结带）/ `undecidable`（其余，**必须**附 `n_req`） | 该跌（k 越大税越小）；本档判「越带与否」 |
| ③ | **判据⑥ k=64 的锚点杠杆补到 n=3** | 逐 seed 价 `price(64,s) = bpc(win64a_s) − bpc(win64_s)`（同 seed 配对，s ∈ {0,1,2}）；跨 seed t 区间**不含 0** ⇒ 可判并报方向；**含 0** ⇒ `undecidable` + `n_req`；并与 k=16 的 −0.00706（`2681` 判据⑦，n=4）并列报 | 该跌（锚点使 clean bpc 更低 ⇒ 价为负） |
| ④ | **自检（必须不变）** | 因果性：只改后半段 token ⇒ 前半段 logits `max\|Δ\| == 0`（三新臂各一次）；掩码可见对数与闭式 `visible_pairs(256,w,a)` 一致且等于 `(64,0)=14368` / `(64,8)=15876` / `(128,0)=24640`；三新臂与复用臂参数量逐位相同（13,536,768）；`recent_keep_mask(256,64)` 与该窗口掩码逐位相同 | **必须不变** |
| ⑤ | **k=192 的「不取得」登记（不是判据，是事实）** | `k=192` 在 n=2 下 `undecidable`，`n_req = 32`、按实际区间所需 n≈17 ≈135 min GPU ⇒ 本实验**不取这条读数**，`results.json::c5_k192_not_measured` 如实写清「未取得」与理由、并引用 `2682` 的 n=2 区间。**不得**把它写成「免费」或「越带」 | 如实报 |

### 6a 判据② 的「不可判」写法（照抄 `2682` 的冻结规则，不重算带）

`undecidable` 不是「没结论」，是「本 n 下不可判 + 给出所需样本量」：
`n_req = ceil((2.9·sd/|mean − σ_cell|)²)`（1.96+0.84 近似功效式）；`mean == σ_cell` ⇒ `n_req = null` 并注明
「效应恰在带边界上，样本量不救」。`σ_cell` **冻结为 0.000983**（`2662` 的两 seed 极差），本实验**不重算、不回填**；
本 n 的种子极差只作描述量（`seed_range_observed`）另报。跨格带 0.014 只作参考，两带并列、不混用。

### 6b 判据③ 的读法边界

价 `price` 是**同 seed 配对差**，因此它天然抵消了种子间质量散布；它的量纲仍是 clean bpc。判据③ 只判
「这个价在本 n 下是不是非 0」——**不判**「锚点值不值得买」：buy 的代价（可见键 64→72、每位置多 98,304 B KV）
与收益的净算术在 `2682/analysis.md` 与 `2662`/`2679` 里，另有其判。

## 7 否证条件

- 判据① 不过 ⇒ 本实验作废：不写判词，先查窗口序 / 掩码 / 权重 / 仪器，修完重跑。
- 判据② 新 seed 的税与另两个 seed 反号 ⇒ 如实报（`sd` 上升、区间更宽），**不得**剔除该 seed。
- 判据③ 新 seed 的价为正 ⇒ 如实报；若区间因此含 0，判词仍是「不可判」而不是「锚点无效」。
- 任何一条预测不成立 ⇒ 在 `analysis.md` 里写清「原本以为会怎样 / 实际怎样 / 排除了哪些别的解释」。

## 8 运行方式

```bash
# 1) 绑定契约（训练入口与共享训练器都会拦未绑定的实验）
python3 tools/prereg_bind.py axes/1-time/1.1.1-hard-window/experiments/2686-window-kcurve-seed2-13m \
  --contract README.md run.py
# 2) 训 3 个新臂（逐臂取/放 /tmp/pathlm_gpu.lock，单臂 timeout 20 min，臂间 ≥61 s）
ARMS="win128_s2 win64_s2 win64a_s2" bash train_arms.sh
# 3) 生成 config.json（臂路径 + 检查点 sha256 + 训练墙钟/rc）再出读数
python3 make_config.py && python3 run.py
```

## 9 口径与纪律

- GPU：单卡共享，按 `harness/SCHEMA.md` §20 取锁；一次一个作业；单臂 `timeout 1200`（≤20 min）；
  等锁 >40 min 退让并如实登记（不抢别人的进程、不改别人的锁）。
- 判据线、冻结带、仪器参数**写下后不改**；读数只进 `results.json` 与 `analysis.md`，不进契约文件。
- 只做单轴单格实验；组合默认留白（`harness/SCHEMA.md` §4）。

## 10 复现

- 克隆内可重算的部分：`run.py` 的复现门与判据②③ 的算术都由本目录 `results.json` + `reproduce` 重算，
  但 bpc 读数需要权重（`*.pt` 不入库）⇒ 本实验对别的克隆是 `rebuildable_only`：
  按 §5 的配方重训 3 个 seed-2 臂，再跑 `make_config.py && run.py`。
- 新臂的训练墙钟与返回码落在 `config.json`（`train_seconds` / `train_rc`），因为 `*.log` 是被忽略的派生物。
