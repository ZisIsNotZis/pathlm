# 2686 · 判读：把两条「不可判」补到 n=3 —— 两条仍是不可判，卡住的是区间宽度不是带

## 0 人话摘要

- **原本以为会怎样**：`2682` 的判据②（k=128 的窗口税）与判据⑥（k=64 的锚点杠杆）都只差「补 1 个 seed」，
  n=2 的区间半宽按推导会随 n=3 收窄一半以上 ⇒ 两条都变可判。契约（`README.md` §1）把这一步写成预测并写明，
  预测不成立也要照实报。
- **实际怎样**：**两条都还是「本 n 下不可判」**。k=128 的税 = 0.012607 / 0.009808 / **0.002762** bpc，
  均值 +0.008392、t 区间 **[−0.004211, +0.020995]**（跨冻结带 0.000983）；k=64 的锚点杠杆价 =
  −0.007652 / −0.008982 / **−0.003166**，均值 −0.0066、t 区间 **[−0.014171, +0.000971]**（含 0）。
- **为什么会这样**：新 seed 训出来的模型**整体更好**——`win128_s2` 的 clean bpc 比 s0/s1 低 0.010–0.008、
  `win64_s2` 低 0.007–0.008，`win64a_s2` 低 0.002–0.003 ⇒ **同 seed 配对差的两个量都往下走**，
  跨 seed 的散布反而**变大**：判据② 的 `sd` 从 0.001979 涨到 **0.005073**、判据③ 从 0.00094 涨到 **0.003047**。
  也就是说，本格判据用的带（**0.000983**）是「同一条臂两 seed 的极差」，而税/价是**两个臂各自带噪声的量相减**，
  它的真实散布是那条带的 **3–5 倍**（这条事实 2682 的 `gaps` 已登记为「带的量纲待定」，现在有了直接读数；
  但它**不是**两条判据卡住的成因，见 §4）。
- **排除了哪些别的解释**：仪器变了（否：复现门 ① 7/7 逐位相同）、掩码或配方错了（否：判据④ 自检全过 +
  与 `2682` 同配方只差 seed）、新 seed 训练异常（否：三臂 rc=0、参数量 13,536,768 逐位一致、训练墙钟 7.9–11.1 min
  与 `2682` 同档）。剩下的事实是**区间宽度**：配对差 `sd` 涨到 0.003–0.005，n=3 的半宽（0.0126 / 0.0076）
  都大于效应量本身（0.008392 / 0.0066）——**不是带选错**（判据⑥ 的规则里没有带；判据② 是「区间下界 > 带」，
  带越小越容易判越带），也**不是种子挑错**。
- **结论与下一步**：两条继续写「本 n 下不可判」。上一轮「补 1 个 seed 即判」被否定的具体内容是**基于 n=2 两点
  `sd` 的半宽估计**，不是「补 seed 这条路本身」：按 n=3 实测 `sd` 重算门槛，判据③ 只要 `sd ≤ 0.004148` 就判负
  （补 1 个 seed 到 n=4）、判据② 只要 `sd ≤ 0.005968` 就判越带（补 2 个 seed 到 n=5）⇒ 下一步是
  `../2688-window-kcurve-seed34-13m`。`k=192` 依旧不取得（n≈17、≈135 min GPU）。

## 2 判据②（k=128 的窗口税，n=3）

| seed | 臂 | bpc | 税 = bpc(win128) − bpc(full) |
|---|---|---|---|
| 0 | `win128_s0` | 1.515296 | +0.012607 |
| 1 | `win128_s1` | 1.512497 | +0.009808 |
| 2 | `win128_s2` | 1.505451 | **+0.002762** |

- 跨 seed 均值 **+0.008392**，`sd` **0.005073**，t 区间（df=2，4.303）**[−0.004211, +0.020995]**；
- 按 `../2682-window-kcurve-13m/README.md` §5a 冻结的三分类 ⇒ **`undecidable`**（区间跨带 0.000983）；
- 预登记功效式给 **`n_req = 4`**（n=2 时它给的是 1，见 `../2682-window-kcurve-13m/analysis.md:115`）；试验种子极差 0.009845 只作描述量，**不回填成新带**。
- 三个 seed **同向**（全为正）⇒ 「窗口在 k=128 上仍有正税」这个**方向**没被翻转；没判的是它是否越带。

## 3 判据③（k=64 的锚点杠杆价，n=3）

| seed | `win64a` bpc | `win64` bpc | 价 = bpc(win64a) − bpc(win64) |
|---|---|---|---|
| 0 | 1.547552 | 1.555204 | −0.007652 |
| 1 | 1.547006 | 1.555988 | −0.008982 |
| 2 | 1.545000 | 1.548166 | **−0.003166** |

- 跨 seed 均值 **−0.0066**，`sd` **0.003047**，t 区间 **[−0.014171, +0.000971]** ⇒ **含 0 ⇒ `undecidable`**；
- 功效式给 `n_req = 2`（这个数按 `|mean|` 算，不能读到「n=2 就够」——n=2 时它就是不可判，见 `2682`）；
- 三个 seed 同向为负，均值与 k=16 的 n=4 参照 −0.00706 同量级（`2681` 判据⑦），但**方向一致不等于可判**。

## 4 两条为什么都没翻转：区间宽度大于效应量，不是带的量纲也不是样本量没补够

| 量 | n=2（`2682`） | n=3（本轮） | 冻结带 0.000983 |
|---|---|---|---|
| 判据② 配对差 `sd` | 0.001979 | **0.005073** | 5.2 倍 |
| 判据③ 配对差 `sd` | 0.00094 | **0.003047** | 3.1 倍 |

- 冻结带 0.000983 的来源是 `2662` 上**同一条臂两 seed 的极差**（单臂噪声）；而判据②/⑥ 判的是
  **两个臂各自带噪声的量相减**，它的散布天然更大，且本轮三个 seed 显示它就在 0.003–0.005 这个量级。
- 于是「补 1 个 seed 即判」这个推断的**前提**（`sd` 停在 0.001–0.002）不成立：补进来的 seed 把那两个 `sd`
  推高了 2.6–3.2 倍，半宽反而只从 12.706·sd₂/√2 变到 4.303·sd₃/√3。
- 这不是「效应消失」：判据② 的三个税全为正、判据③ 的三个价全为负，**方向**稳定；不可判的是「是否越带/是否非 0」
  这个**量级判断**，卡住它的是**半宽 > 效应量**（0.0126 > 0.008392、0.0076 > 0.0066）。
- **带不是主因**（更正：本文件初版把成因写成「带的量纲」，那是错的）：判据③ 的预登记规则根本不含带
  （`README.md` §6 判据③：t 区间不含 0 即判）；判据② 的规则是 `above_band = 区间下界 > 带` ⇒ 带越**小**越容易
  判越带，n=3 的下界 −0.004211 为负，任何 ≥ −0.0042 的带都判不出越带。
- 按未改的规则只差 seed：判据③ 补到 n=4（`sd ≤ 0.004148`）、判据② 补到 n=5（`sd ≤ 0.005968`）即可判，
  以 `sd` 不涨为前提（`../2688-window-kcurve-seed34-13m`）。
- **「把带换成配对差散布」不是收口路径**，是口径登记项：若真按字面改，`|mean − 带| = |0.008392 − 0.005073| = 0.003319`
  ⇒ 功效式 `n_req = 20`（比现在的 4 更远）；若改成点判据「mean vs 带」则 0.0084 > 0.005 ⇒ 直接判「税存在」。
  两种读法结论相反 ⇒ 该路径连「换成多大的带 + 配哪条判定规则」都没定义，属框架性取舍（`AGENTS.md` §3.3 纪律 3），
  须先走完补 seed。

## 5 排除了哪些别的解释

- **仪器没变**：判据① 7/7 逐位相同（`full` 1.502689、`win64_s0/s1`、`win64a_s0/s1`、`win128_s0/s1` 全等）。
- **掩码与配方没变**：判据④ 自检全过——因果性前缀 `max|Δlogit| = 0.0`（三个新臂各一次）、可见对数
  `(64,0)=14368` / `(64,8)=15876` / `(128,0)=24640` 三处一致（闭式 + 硬编码 + 实测）、参数量 13,536,768 逐位相同、
  窗口掩码与共享底座的 `recent_keep_mask` 逐位相同。
- **新 seed 训练没异常**：三臂 rc=0，墙钟 8.00 / 7.92 / 11.07 min（`config.json` 的 `train_seconds` 480 / 475 / 664 s），
  与 `2682` 同配方同档（8–10 min/臂）；`full` 与全部复用臂的 bpc 与 `2682` 一致 ⇒ 数据流与窗口序没变。
- **不是「seed 2 挑出来的」**：seed 2 是唯一没跑过的种子，不是从多个里挑的；`seed_range_observed` 只作描述量。

## 6 边界（禁外推）

- 本判读只覆盖 **13M / L=12 / T=256 / enwik8 / 12k 步 / 该可见性快照**；不外推到更大规模、更长 T、别的分词口径。
- 判据② 的 k=128 只说明这一档；**不得**沿曲线外推「k≥128 免费」，也**不得**把 `undecidable` 读成「确定免费」或
  「确定有代价」。
- 判据③ 只判「这个价在本 n 下是否非 0」；**不判**「锚点值不值得买」（买价与净算术在 `2662` / `2679` / `2682`）。
- 三臂的训练墙钟与 rc 落在 `config.json`（`train_seconds` / `train_rc`），因为 `*.log` 是被忽略的派生物。

## 7 k=192：登记为「不取得」，不是读数

`results.json::criteria.c5_k192_not_measured` 如实写着：`k=192` 在 n=2 下 `undecidable`（均值 −0.000387、
区间 [−0.024091, 0.023316]），预登记功效式 `n_req = 32`、按实际区间约需 **n≈17（≈15 个新臂 ≈135 min GPU）**
⇒ **本实验不取这条读数**。本轮读数没有改变这个判断：卡住的是半宽而非带（见 §4），n≈17 是按未改的规则
算出的代价，仍然太贵。
