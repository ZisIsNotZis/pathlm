# 2679 · 评测期锚点消融：那份质量收益归「训练侧」还是「推理期可见性」？

> 归属：`axes/1-time/1.1.1-hard-window`（研究项 1.1.1「hard 窗口」）。
> 入口：`run.py`（纯推理，不训练；先 `python3 tools/prereg_bind.py <本目录> --require` 过门）；
> 契约常数在 `config.json::criterion`；读数 `results.json`；人话判读 `analysis.md`。
> 复用仪器：`../2662-hard-window-anchor-13m/realtext_probe.py::win16_bpc`（只读导入，逐字不改）。

## 1 命题（可证伪）

`2662` 量到：带 8 个恒可见锚点槽训练的臂（窗口 16 + 锚点 8），其 clean bpc 比同 seed 纯窗臂好
**−0.005583 / −0.007294**（两 seed 同向、越本格自测带 0.000983）。**但这条收益有两种互斥解释**：

- **H_A 推理期可见性**：收益来自「推理时真的多看见了 8 个位置」⇒ 评测期把锚点去掉，质量应退回纯窗水位。
- **H_B 训练侧**：收益来自「训练时见过 24 个键」这一训练条件本身（模型被训练得更好）⇒ 评测期把锚点去掉，
  质量基本不动。

一句话可证伪的形式：*对同一份 `win16a_s0` / `win16a_s1` checkpoint，只改**评测期**掩码
（`window_anchor_keep_mask(256,16,8)` → `(256,16,0)`），0 训练 token、0 权重改动*。
若 `Δ_abl = bpc(评测无锚点) − bpc(评测带锚点)` 两 seed 同向越过本格带，则 H_A 成立；若两 seed 都落在
带内（`|Δ_abl| < 0.000983`），则 H_B 成立。反向格（纯窗臂 + 评测期白给 8 个锚点）作为对照一并报出。

## 2 干预与单因素声明

- **基底**：stock dense decoder-only trunk（d256 × 12 层 × 8 头 × mlp6 × T256），与 `2662` / `2634` 逐字段同一规格。
- **唯一变量 = 评测期掩码的 `anchors` 一项**（8 → 0，以及反向 0 → 8）。臂、权重、数据、窗口序、批数一律不变。
- **不训练、不新增参数、不改共享文件**：本实验只读 `pathlm/**`、`tools/evalkit/**`，并在
  `sys.path` 上只读导入 `2662` 的 `realtext_probe.py`（不改它一个字节）。
- **必要性例外**：无（单一因子即可独立生效：掩码只改可见集）。

## 3 臂与格子（4 个 checkpoint × 2 个评测掩码 = 8 格，其中 4 格是复现门）

| checkpoint | 训练可见性 | 评测掩码 `(16,8)` | 评测掩码 `(16,0)` |
|---|---|---|---|
| `win16a_s0` | 窗口 16 + 锚点 8，seed 0 | `a_s0_eval_anchors8`（复现门） | `a_s0_eval_anchors0`（消融格） |
| `win16a_s1` | 窗口 16 + 锚点 8，seed 1 | `a_s1_eval_anchors8`（复现门） | `a_s1_eval_anchors0`（消融格） |
| `win16_s0` | 窗口 16 + 锚点 0，seed 0 | `w_s0_eval_anchors8`（反向格） | `w_s0_eval_anchors0`（复现门） |
| `win16_s1` | 窗口 16 + 锚点 0，seed 1 | `w_s1_eval_anchors8`（反向格） | `w_s1_eval_anchors0`（复现门） |

每格记录 `visible_pairs`（必须等于 5868 / 3976）、clean bpc、每窗比特与 token 数（供配对 bootstrap）。

## 4 判据线（**预登记：写下后不得改**）

| # | 判据 | 判定线 | 该涨 / 该跌 / 必须不变 |
|---|---|---|---|
| ① | **复现门**（本实验的仪器自检） | 四个「本方自有掩码」格子与 `2662::quality_leg.bpc` **逐位相等**（`1.622527` / `1.621799` / `1.628110` / `1.629093`）。不等 ⇒ 本实验作废（仪器或权重不一致），不得改判据线去凑 | **必须不变** |
| ② | **主判（归因）** | 逐 seed 的 `Δ_abl = bpc(评测 anchors=0) − bpc(评测 anchors=8)`；配对 bootstrap（按窗口聚类，10k 次，α=0.05）给 95% CI。两 seed 同向 `> 0`、CI 下界 `> 0`、且 `|Δ_abl| ≥ sigma_cell = 0.000983` ⇒ **H_A（推理期可见性承载）**；两 seed 都 `|Δ_abl| < sigma_cell` ⇒ **H_B（训练侧承载）**；其余（异向 / CI 含 0 / 骑带）⇒ **本 n 下不可判**，如实报 | 该涨（若 H_A） |
| ③ | **反向对照**（不设方向预登记） | 纯窗臂 `Δ_rev = bpc(评测 anchors=8) − bpc(评测 anchors=0)`；`|Δ_rev| < sigma_cell` ⇒ 「评测期白给 8 个锚点不改质量」；否则如实报方向与幅度 | 正负都报 |
| ④ | **必须不变**（负对照） | 只改后半段 token ⇒ 前半段 logits 逐位不变（两个掩码各跑一次，`max|Δlogit_prefix| == 0`）；掩码非退化：`visible_pairs(16,8)=5868`、`(16,0)=3976` | **必须不变** |
| ⑤ | **方差带与混用纪律** | 主判用**本格带** `sigma_cell = 0.000983`（`2662` 的两 seed 极差，描述量）；跨格 0.014 带**并列报、只作参考**，两带不混用（C1 裁决）；配对 CI 只含同一批窗口上的测量噪声，不含训练种子方差 | 口径 |
| ⑥ | **指标口径** | clean bpc（bits/byte，越低越好），96 批 × 16 × 256 token、`window_seed=2` 的同一窗口序；**墙钟不进判据** | 口径 |

**判读量级义务**：报 `Δ_abl` 与 `2662` 量到的锚点收益（`−0.005583` / `−0.007294`）及「窗口 16 → 全因果」
总缺口（`0.125421`）的比值——只报绝对 bpc 差不算判读。

## 5 否证条件

- 判据① 不成立 ⇒ 本实验**作废**（读数不入账，先修仪器）。
- 判据② 的两 seed **异向** ⇒ 停，如实写「本 n 下不可判」，不得挑 seed。
- 若消融后质量**大幅**变差（`Δ_abl` 远超 2662 量到的收益）⇒ 说明锚点在推理期比训练期更关键，
  结论要写成「评测期掩码敏感度 > 训练收益」，这是**允许**的判决，不是故障。

## 6 成本与预算

- `0` 训练 token；8 格 × 96 批前向 ≈ 数分钟 GPU + 一次因果性探针；`README` 预算 = 20 min GPU 上限。
- 取一次 `/tmp/pathlm_gpu.lock`（`run.py` 自带取放锁，`holder_pid` + 死进程回收 + 20 min 等待上限）。
- **预算不够时砍什么**：不砍格子（8 格是 2×2 的全体）、不砍判据；只允许把配对 bootstrap 次数
  10k → 2k 并在 `results.json` 记下来。
