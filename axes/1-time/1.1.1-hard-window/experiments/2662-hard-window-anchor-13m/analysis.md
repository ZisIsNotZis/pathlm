## 0. 人话摘要（先看这段）

**问题**：把可见范围压到只看最近 16 个字节时，再额外保留**最前面 8 个字节恒可见**（这就是
「锚点槽/sink」）——它值不值？代价是每位置多存 8 个键的 KV（+50% 的可见键数，从 16 到 24）。
两件事要分开：①它让**质量**涨了还是跌了；②它是不是把「远处的内容」搬到了近处。

**结论一句话**：**锚点是一笔「质量收益」，不是税**——两个种子都更好，且**超过本格自测带**；
但它**不是记忆通道**：它只把最前面 ≤8 个字节变得永远看得见，**搬不动远处**（窗外召回仍停在
配对地板）。**而它在召回上是否「真抬高了锚区」**，按预登记「两个 seed 都要过」的门槛**未达成**：
只有一个种子的配对 bootstrap 置信区间排除 0，另一个不排除。

三个读数，逐个说人话：

1. **质量腿（锚点的价格）**：同 seed 相比，锚点臂的 clean bpc 更低——
   种子 0：**1.6281 → 1.6225**（好 **−0.005583** bpc）；种子 1：**1.6291 → 1.6218**（好 **−0.007294** bpc）。
   （`quality_leg.price.0.price_bpc` / `.1.price_bpc`；bpc 越低越好。）参照系：本格换种子的波动是
   **0.000983** bpc（`quality_leg.bands.sigma_cell`），工程跨格带是 **0.014** bpc。两个种子的收益
   **都越过了本格自测带**（`sortable_vs_sigma_cell = true`），但**都没有越过 0.014 跨格带**
   （`sortable_vs_0.014 = false`）——**两带并列、不混用**。量级：约 **0.34%–0.45%**。
   **口径警告**：这个收益是在锚点臂的**更大可见集**（24 键 vs 16 键）下取得的，所以它**不是免费**的
   ——是「多花 50% 可见键」换来的质量，不是「同可见集下免费变好」。
2. **召回腿（锚点区能不能被取回）**：仪器把一条 6 字节短语扎在 `p<8`（锚点槽内），看模型能不能接出
   下一个字节；对照 = 同一序列**不植入**短语的配对地板（只剩语料先验）。锚点臂锚点桶植入召回
   种子 0 = **48.16% vs 地板 45.56% = +2.592pp**（两比例差（正态近似/未 pooling） 95% CI **[−1.774, 6.958]** 含 0；
   按针配对 bootstrap CI **[1.196, 4.187]** **不含 0**，`passes_both=false`）；
   种子 1 = **48.26% vs 47.16% = +1.097pp**（两比例差（正态近似/未 pooling） **[−3.275, 5.468]**、配对 bootstrap **[−0.299, 2.592]** **都含 0**）。
   ⇒ 按预登记「**两个 seed 都过才算该腿有区分力**」，`win16a_both_seeds_pass_both_ci = false`
   ⇒ **该腿在本 n 下不可判**（不是「被否证」，也不是「成立」）。
3. **负对照（窗外仍停地板）**：窗外桶（`p≥8` 且有位置不可见）两个种子的植入 vs 地板差
   = **+0.098pp（CI [−1.535, 1.73]）** / **−0.056pp（CI [−1.689, 1.577]）**，
   `criteria.c3_beyond_bucket_stays_at_floor` 的 `ci_contains_0` **两个 seed 都是 true**
   ⇒ **锚点没有把远处搬近**，它保住的是锚区。这是「锚点 = 少量恒可见槽（直接注意力），
   不是记忆通道」的关键区分。

**一句话**：锚点槽**值**（质量 +0.34~0.45%，两种子同向、越本格自测带），但**只是把最前面 8 格
变得恒可见**（窗外搬不动），而「锚区召回真被抬高」在 2 seed 上**没达到预登记门槛**。

## 1. 六个必答问题

1. **它是干什么的**：把每个位置的可见范围压成「最近 16 个字节」时，再保留**最前面 8 个字节永远
   可见**（这类恒可见槽业界叫 attention sink / 锚点）。本实验量的是这个锚点槽的两件事：
   质量值不值、能不能把锚区内容变得可召回。
2. **相对普通 decoder-only transformer 改了什么**：**只改训练与评测的可见掩码**——普通全因果是
   `keep[i,j]=(j≤i)`，本实验是 `window_anchor_keep_mask(256,16,8)`，即
   `keep[i,j] = (j≤i) ∧ ((i−j)<16 ∨ j<8)`。**不新增任何参数**（锚点臂与纯窗臂参数量逐位相同
   `13,536,768`，见 `selfchecks.*.n_params`）。改动量级：每位置可见键数 16 → 24（+50%），
   每位置等效 KV 字节 `196,608 → 294,912`（`rows[*].kv_bytes_per_position`）。
3. **为什么盯着它**：窗口把远距离注意力砍掉后，质量会掉（本项旧读数：只保留最近 32 个位置 =
   `+0.212` bpc）。业界（StreamingLLM）说留几个 sink 就能救回大部分质量。本实验在**真实文本**
   上把「锚点的价格」和「锚点的召回」分开量清楚，不再借旧合成任务读数。
4. **怎么测的**：5 臂——本 WP 训练 `win16a_s0/s1`（窗口 16 + 锚点 8，seed 0/1）；复用
   `2634` 的 `win16_s0/s1`（窗口 16 + 锚点 0）；复用 `2610` 的 `full`（全因果，上界参照）。
   唯一变量（锚点臂 vs 纯窗臂）= 掩码里的 `anchors`（8 vs 0）；锚点臂之间唯一变量 = seed。
   三条腿：① clean bpc（每臂在自己的可见性下评测，96×16 窗口序）；② needle v3 短语针
   （锚点桶 vs 配对地板 + 同索引硬子集）；③ 毁源敏感度（被毁前缀在锚点槽之外时逐位不敏感）。
   另加因果性 / 掩码非退化 / 复用臂逐位复现三个必须不变项。
5. **测出来多少**：见 §0 与 §2–§6 的表。参照系：纯窗臂 **1.6281 / 1.6291** bpc；
   每位置全因果参照 `full` = **1.502689** bpc（`quality_leg.bpc.full`）。锚点臂 1.6225 / 1.6218。
   ⇒ 锚点把「窗口 16 相对全因果的差距」（`gap_win16_full = 0.125421`）缩小到
   `gap_win16a_full = 0.119838`，**缩小约 4.5%**。
6. **结论与下一步**：**锚点 = 质量收益 + 锚区可见，不是信息右移通道**；召回腿在 2 seed 上
   **未达预登记门槛（不可判）**。下一步最小实验：加 seed（n≥4）把锚点桶召回的两套 CI 压到可判；
   或换更硬的地板（降低语料先验）以提高仪器的区分力。见 §9。

**判据④的必要偏离（预登记已写死，如实报）**：变体 A 被毁区 `[0,64)` **包含锚点槽 `[0,8)`**，
锚点臂直接看得到被毁的锚点槽 ⇒ 对它**不可能逐位不敏感**（物理事实，不是仪器故障）。故变体 A 对
锚点臂以 `require_no_overlap=False` 运行并记 `premise_holds=false`（=「不可判」，不是放行）。
变体 B 把锚点槽 `[0,8)` 保住、只毁 `[8,64)`，锚点臂 `max|Δlogit|=0.0` ⇒ **锚点对锚点槽之外的
远处内容逐位不敏感**，即锚点**没有搬运**远处内容。

|---|---|---|---|---|---|

**同 seed 价格 `price_bpc = bpc(win16a) − bpc(win16)`（负 = 锚点是质量收益）：**

| seed | `bpc(win16a)` | `bpc(win16)` | `price_bpc` | 符号 | 越本格带（0.000983）？ | 越 0.014 跨格带？ |
|---|---|---|---|---|---|---|
| 0 | 1.622527 | 1.628110 | **−0.005583** | 收益（更好） | ✅ 是（`sortable_vs_sigma_cell=true`） | ❌ 否 |
| 1 | 1.621799 | 1.629093 | **−0.007294** | 收益（更好） | ✅ 是 | ❌ 否 |

- **两带并列、不混用**（C1 裁决）：本格自测带 `quality_leg.bands.sigma_cell = 0.000983`
  （= 本实验自己的换种子极差，其中锚点臂内 `sigma_cell_per_kind.win16a = 0.000728`、
  纯窗臂内 `.win16 = 0.000983`，取二者最大值 0.000983）；跨格工程带
  `quality_leg.bands.cross_cell_band = 0.014`（主判、参考；两带**不得**混用）。
  ⇒ 锚点的收益**越过本格带**（可排序），但**未越 0.014 跨格带**。
- **量级**：−0.005583 / 1.628110 ≈ **0.34%**；−0.007294 / 1.629093 ≈ **0.45%**（越低越好）。
- **与全因果的差距**：`gap_win16_full = 0.125421` → `gap_win16a_full = 0.119838`，
  锚点把差距缩小 **0.005583 / 0.125421 ≈ 4.45%**。
- **口径警告（必须并报）**：锚点臂的 bpc 在**它自己的更大可见集**下测量（`k_eff=24` vs 16）
  ⇒ 这是**同预算、不同可见集**的比较。收益的代价 = 每位置多 **98,304 B** KV（+50%）。
  所以正确说法是「**锚点用 50% 更多可见键换到约 0.4% 的质量改善**」，不是「免费改善」。
- **归因未排除项**：本实验只测出「有锚点 vs 无锚点」的合计差，未做「把锚点臂在评测期关掉锚点」
  的消融 ⇒ 无法区分收益来自「锚点槽本身」还是「训练时见过更多键」。列为下一步（§9）。

## 4. 召回腿：锚点桶（`p<8`）与负对照（beyond 桶）

## 5. 毁源敏感度（判据④：锚点算不算信息右移）

仪器 `far_source_probe`：被评行 `[244,255)`，`rf = n_layers·(window−1) = 180`；两变体：
**变体 A `far_all`** 毁 `[0,64)`；**变体 B `beyond_anchor`** 毁 `[8,64)`（保住锚点槽 `[0,8)`）。
