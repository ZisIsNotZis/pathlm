## 2. 与同配置历史 run 的逐点交叉对照（跨批可比性）

`full` 臂与 ticket 30 的 `sequential-12k-s0` 臂（同 d256/L8/mlp4/12k/bs32/seq256/seed0，
`archive/wiki-legacy/axes/C-vertical/C3-inter-layer-topology/.../2613-...`）：

- 第 0 步 loss **逐位相同**（5.3131）⇒ 初始化与数据流一致；
- 61 个采样点上 loss 最大差 **0.0167**（step 600）、均值 0.005 ⇒ 属 bf16 kernel 非确定性
  （该批实测同配置重跑散度 0.0033 bpc），**没有系统性偏差**。

三臂之间的训练 loss（同批数据流）：

| 对照 | 最大 \|Δloss\| | 均值 \|Δloss\| | 第 0 步 |
|---|---|---|---|
| `topk32` vs `full` | 0.0485 | 0.0100 | 5.3143 vs 5.3131（+0.0012，随机选择的初始化税） |
| `topk64` vs `full` | 0.0358 | 0.0077 | 5.3131 vs 5.3131（逐位相同） |

⇒ 单批 loss 的抖动（±0.05）**远大于**臂间差，所以训练 loss 不能用来判质量；
质量判读必须用固定 20 批的 clean bpc（§7.2 的配对口径）。

## 3. 活性量在训练日志中的完整性（SCHEMA §10 / §17.4）

- 每 200 步同一行都带 `attn_sparse`（关闭时显式 `null`）；
- `kept_mean` 全程恒为理论值（30.0625 / 56.125），即**每一步干预都在生效**（不是偶发开火）；
- `sel_dist_mean` 随训练下降（topk32 从 66.7 → 24.8；topk64 从 71.4 → 38.0），
  说明模型在稀疏约束下把注意力收敛到更局部——这条曲线本身就是「稀疏改变了注意力分布」的证据；
- 逐层样本数 96,000 = **12,000 步 × 8 层**（每步累加、每 200 步把累计均值写进该行），
  与训练日志行数（61）自洽：61 行 = step 0 起每 200 步一次 + 末步 11999。
