# 2634-carry-realtext-13m · 对照臂说明（SCHEMA §13：每个对照臂写清「输入分布 / 要预测什么 / 部署对应」）

本实验的**唯一变量** = 有无写入通道（`carry_rule` ∈ {none, delta}）× 训练 seed {0,1}；
四臂同数据（enwik8 真实文本）、同可见性（窗口 16 + 锚点 0）、同 token 预算（98.3M）。

## 1. 主臂与诚实对手

| 臂 | 输入是什么分布 | 要预测什么 | 部署中对应什么 |
|---|---|---|---|
| `rt_none_s*`（诚实对手，基线） | enwik8 真实字节窗口，注意力只能看最近 16 个位置 | 下一个字节 | 「纯窗口注意力、没有显式记忆」的部署 |
| `rt_delta_s*`（主臂） | 同分布、同可见性，外加一个固定大小（8192 floats）的显式记忆槽 | 同 | 「窗口注意力 + 显式写入通道」的部署 |

- **诚实对手**满足 SCHEMA §11：与主臂**同成本或更低成本**（无通道臂参数还少 264,296），
  不是 oracle；
- **等参数对照**：`none` vs `delta` 不严格等参数（差 +1.95%）。本实验的对照是
  「有无该机制」，按 §15 的例外处理方式给出**通道消融**腿（把抓出的 `gate_w`/`carry_scale`
  置零 ⇒ 同权重、退化为同架构无通道前向）作为「等结构、只差通道是否被读」的对照。

## 2. 探针腿的三个对照（判据①③④）

| 对照 | 输入是什么分布 | 要预测什么 | 部署中对应什么 |
|---|---|---|---|
| **毁源输入** `x_corrupt`（前缀 [0,64) 换成随机字节） | 同窗口分布，但**第 180 个位置之前的内容被销毁**（被评行 [244,255) 的 12 层多跳感受野 ≥ 该边界 ⇒ 只有记忆槽能把它带过来） | 同（下一个字节） | 「远距离来源不可用」的部署 |
| **配对无针地板**（needle v3，`plant=False`） | 同一批真实文本、同一批针位，但**短语没有植入窗口** | 同（针的下一个字节） | 「记忆里没有这条信息」的地板 |
| **通道消融**（评测期 `gate_w=carry_scale=0`） | 同输入、同权重，只把通道的读/写通路关掉 | 同 | 「装了通道但读出被关」的部署 |

## 3. 方差界（本格自测，禁套全局 0.014）

- `σ_cell` = 同配置换种子的 `bpc_win16` 极差（`none_s0/none_s1`、`delta_s0/delta_s1` 两组取最大）。
- 同上，`Δbpc_far` 也用同配置换种子的极差作界。
- **2 样本极差是描述量、不是方差上界**（SCHEMA §2：准确率用 Wilson CI，bpc 用本格极差）。
- 探针腿的统计口径：**按窗口聚类的配对 bootstrap**（每个窗口 16 行共享同一段文本与同一份
  记忆状态 ⇒ 不是独立样本；与 2631 复核 B2 同一纪律）。

## 4. 口径与禁外推

- 绝对 bpc 只适用于 **enwik8 / 13M / 窗口 16 / 12k 步快照**；与 2616（window192，24×16 批）
  等历史读数的窗口序相同但批数不同 ⇒ **不与它们逐位可比**。
- `Δbpc_far` 是**敏感度**（必要条件），不是「帮上了忙」；它必须与 `bpc_win16` 一起读。
- needle 腿的针位由生成器 `seed=3` 决定，与模型 seed 无关 ⇒ 四臂**配对**。
