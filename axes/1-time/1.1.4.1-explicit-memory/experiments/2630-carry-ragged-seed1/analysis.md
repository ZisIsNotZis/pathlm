# 2630-carry-ragged-seed1 · 判读（carry × 随机退出 × proj-fill 的 seed=1 复现，n=2）

## 人话摘要（先读这一段）

**这条线在问什么**：上一批（2629，ticket 46-W1）给出了一个很有卖点的结果——把「delta
搬运通道」装到「随机退出 + proj-fill」这条产品配方上，**分布内召回没涨**（+0.36 个百分点，
在噪声里），但**训练分布外的越界腿大涨 +6.05 个百分点**（单查询，距离 241–255，样本
2048）。那条腿被解读成「通道确实在把远距离信息搬过来」。问题是：**它只有一次独立训练
（一个 seed）**。本线只改**随机种子**（seed=1），其余逐字段照抄，重跑两臂，和 seed=0 拼成
n=2，看这两条结论稳不稳。

**结论（人话）：不稳，而且两条都翻了符号。**

- **越界腿：不保持，直接反号。** seed=0 时通道**赢** +6.05 个百分点（95% CI
  [4.67, 7.44]，显著）；seed=1 时通道**输** −2.44 个百分点（95% CI [−3.67, −1.22]，同样
  显著）。两条腿的极差 **8.50 个百分点**，比效应本身还大。⇒ **不能**把 46-W1 的「通道在搬」
  记为稳健结论；它是一次单 seed 观测。这和仓里 2625 对「近 OOD 判决腿」的判断**一致**：
  这条腿族（距离超过训练上限）同配置重跑的方差极大（§17.18）。
- **分布内召回冗余：也不稳。** seed=0 时是「无增益」（+0.36pp，CI 跨 0）；seed=1 时通道
  **显著更差** −3.26 个百分点（CI [−4.27, −2.25]）。极差 3.62 个百分点，远超 1.4pp 的
  预登记阈值带 ⇒ 「搬运通道对召回冗余」这个结论**在 n=2 下不成立**（seed=1 是显著负向）。
- **出口资产（训练分布内 tf@4）：这个是稳的。** seed=0 差 −0.98pp、seed=1 差 +0.11pp，
  **两个 seed 都落在 1.4pp 预登记阈值带内**，极差 1.09pp ⇒ 「出口资产在 carry 存在时保持」这条
  **跨 seed 成立**（两臂都 ≥99%）。
- **enwik8 跨分布代理口径：不可跨 seed 比较。** 同一个**基准臂**（配方完全相同、只换 seed）
  在 enwik8 上的 tf@4 自己就从 93.69% 掉到 68.88%（差 **24.81pp**）⇒ 这个代理口径自身的
  seed 方差远大于要测的效应（seed0 −4.71pp vs seed1 +13.24pp）。2629 §9 把它标为「待确认」
  是对的；本线给出的是「该代理在此设定下**没有跨 seed 可比性**」，**不是**「carry 打坏了
  出口资产」。

**一句话**：**在 13M / 6k / 无窗口的设定下，「carry × 随机退出 × proj-fill」的两条关键读数
（越界腿 +6.05pp、分布内冗余）都**不跨 seed 稳定**——越界腿效应甚至反号；唯一跨 seed 稳定
的是「出口资产在训练分布内保持」（两 seed 都 ≤1.4pp 带内）。**

> **收敛口径警告（§17.15）**：seed=1 的**目标臂本身**在 6k 时答案行 CE 更高
> （3.1789 vs 基准 2.5615），且斜率更陡（−0.2209 vs −0.1858 nats/1k）⇒ 该臂**更欠拟合**。
> 因此 seed=1 的负向 Δ **可能部分是收敛快照效应、不纯是机制效应**；6k 快照下**无法分离**
> 二者。本线所有结论都只读**臂间增量**、绝对水平是快照（§16/§17.15）。

## §1 命题与干预

**命题**：把 2629（seed=0）的同配置换 seed=1 重跑两臂，与 seed=0 合并成 n=2，问
① 分布内召回差与越界腿差是否跨 seed 保持；② 越界腿的「在搬」是否稳健；③ 分布内冗余是否稳定。

**两臂（唯一变量 = `carry_rule`；跨 seed 层唯一变量 = seed）**：
`projfill_s1`（随机退出 + proj-fill，无 carry）vs `projfill_carry_s1`（同上 + delta 写），
seed=1、6k 步 × bs32 × T256 = 49.0M token。配方**逐字段复用 2629 的语义层**
（`ragged_projfill_arms`），只换 seed。

## §2 主判据：跨 seed（W2 判据①②③）

**分布内召回** = 训练型多查询 assoc-mqar（K8/Q8/gap14，随机退出，距离 107–240，n=16384）；
**越界腿** = 单查询关联回忆（距离 241–255 > 训练上限 240，n=2048，外推参照）。
效应 = 目标 − 基准（pp），附 `two_proportion` 95% 差值 CI。

| 腿 | seed=0（2629） | seed=1（本线） | 极差（pp） | 判据 |
|---|---|---|---|---|
| **分布内召回（随机退出，主）** | **+0.36**（CI [−0.66, +1.38]，p=0.487） | **−3.26**（CI [−4.27, −2.25]，p<1e−3） | **3.62** | ③ **不稳定**（seed=1 超带且显著负） |
| 分布内召回（去伪影块 d≤223） | −0.39（CI [−1.39, +0.61]） | −1.28（CI [−2.28, −0.29]） | 0.89 | ③ 稳定（都 ≤1.4pp） |
| 全深度（并列，部署全栈） | +0.49（CI [−0.54, +1.53]） | −7.78（CI [−8.79, −6.77]） | 8.28 | ③ 不稳定 |
| **越界腿（全深度，主）** | **+6.05**（CI [+4.67, +7.44]，p<1e−3） | **−2.44**（CI [−3.67, −1.22]，p=9.8e−5） | **8.50** | ② **不保持**（反号，各自显著） |
| 越界腿（随机退出） | +5.91（CI [+4.50, +7.32]） | −3.56（CI [−4.72, −2.41]） | 9.47 | ② 不保持 |
| tf@4 分布内（主口径） | −0.98（CI [−1.05, −0.91]） | +0.11（CI [+0.05, +0.17]） | 1.09 | 出口资产**保持**（都 ≤1.4pp 带） |
| tf@4 enwik8（跨分布代理） | −4.71 | +13.24 | 17.95 | 代理口径**无跨 seed 可比性** |

**判据②（越界腿稳健）** = `robust: false`——`same_sign_positive: false`、
`ci_lower_positive_each: false`（每 seed 差值 CI 下界都 > 0 这一条对 seed=1 不成立）。
⇒ **不得**把「机制确实在搬」记为稳健；2629 的 +6.05pp 是**单 seed 观测**。

**判据③（分布内冗余稳定）** = `stable: false`——`all_within_band: false`
（seed=1 的 |Δ|=3.26pp > 1.4pp 带）。

**逐 seed 原始计数（可核对）**

| seed | 臂 | 分布内召回（随机退出） | 越界腿（全深度） |
|---|---|---|---|
| 0 | 基准 `projfill` | 5340/16384 = **32.59%** | 51/2048 = **2.49%** |
| 0 | 目标 `projfill_carry` | 5399/16384 = **32.95%** | 175/2048 = **8.54%** |
| 1 | 基准 `projfill_s1` | 5466/16384 = **33.36%** | 111/2048 = **5.42%** |
| 1 | 目标 `projfill_carry_s1` | 4932/16384 = **30.10%** | 61/2048 = **2.98%** |

**读法**：**基准臂自己**在两 seed 间就漂了——越界腿 2.49%→5.42%（+2.93pp）、分布内召回
32.59%→33.36%（+0.77pp）。基准的这种漂移 + 目标臂更大的漂移叠加，正是「越界腿效应反号」的
来源。这与 §17.18 / 2625 的结论一致：**距离超过训练上限的腿在 6k 步下 run-to-run 方差极大，
不能当 n=1 判决腿**。

## §3 出口资产（判据②/⑤）

`tf@k` = depth-k 出口 argmax 与全栈 argmax 的一致率（越高越好）。

| 口径 | 臂 | seed=0 | seed=1 |
|---|---|---|---|
| **训练分布内（synth，主口径）** tf@4 | 基准 | 99.66% | **99.42%** |
| | 目标 | 98.68% | **99.53%** |
| | Δ | −0.98pp | **+0.11pp** |
| enwik8（跨分布代理） tf@4 | 基准 | 93.69% | **68.88%** |
| | 目标 | 88.98% | **82.12%** |
| | Δ | −4.71pp | **+13.24pp** |

- **主口径（训练分布内）跨 seed 稳定**：两 seed 的 |Δ| 都 ≤1.4pp（极差 1.09pp），两臂
  tf@4 都 ≥99% ⇒ 与 100M 锚点（0.9726）**同量级**（跨尺度、跨口径参照，**非**同一口径
  复现），且「出口资产在 carry 存在时保持」**跨 seed 成立**。**证据类型 = 量级**（不是等价比
  检验）。口径取舍见 2629 的 `CALIBER_DECISION.md`。
- **enwik8 代理口径跨 seed 不可比**：同一**基准臂**（配方逐字段相同，只换 seed）tf@4 从
  93.69% 掉到 68.88%（**24.81pp**）⇒ 该代理自身的 seed 方差远大于 carry 效应；把它当
  「100M 口径对齐」用在此设定下（合成训练 → 真文本）**不成立**。2629 §9 的「−4.71pp 待确认」
  到此可以结案为：**待确认的那条腿是代理口径噪声，不是 carry 打坏出口资产**。
  **与此一致的独立证据**：同批 `2630-tf4-samecaliber`（ticket 47-W1）把模型**直接在 enwik8 上
  训练**（enwik8 变成分布内口径）后，carry **不弄坏出口资产**——即分布错配（而非机制）才是
  本线 enwik8 代理数字乱跳的原因（`CALIBER_DECISION.md` §3 条件 1）。
- synth 口径 `tf@4 ≤ tf@6` 的单调性两 seed 都成立。

- **跨 seed 对账**：从**两份 `results.json` 的原始计数**（hits/n、tf 一致数/n）**独立重算**
  每 seed 的效应 + 差值 CI + 极差，与 `cross_seed` 派生字段逐项比对；并核对 seed=0 的效应
  与 2629 自己的 `increments` 一致（tol 1e-3，两比例 delta 是 3 位小数）。
- **毁源对照**：两口径两臂**全部有效**（毁源后 CI 下界 ≤ 4×chance）。
- **成对评测**：两 seed 的模型在**同一批 + 同一退出模式**上评测；两臂亦然。
- **能力面**（§22.8）：`capability_probe()` 复用 2629 语义层 + 单测钉住。
- **变异验证**：`mutate.py` **6/6 抓红、6/6 逐字节还原**。

## §8 结论与下一步

**结论**

1. **判据② —— 越界腿的「通道在搬」不稳健。** seed=0 的 +6.05pp（显著）在 seed=1 上**反号**
   为 −2.44pp（同样显著），极差 8.50pp。⇒ 按 §17.18/2625：该腿**降级为辅助腿**，
   46-W1 的 +6.05pp 只能记为**单 seed 观测**，**不得**当「机制在搬」的证据。
2. **判据③ —— 分布内召回冗余不稳定。** seed=0 +0.36pp（CI 跨 0）→ seed=1 −3.26pp
   （显著负，超 1.4pp 带）。⇒ 「搬运通道对召回冗余」在 n=2 下**不成立**；**但** seed=1 的
   目标臂更欠拟合（§4），负向 Δ **可能部分是收敛快照效应**，6k 无法分离。
3. **出口资产保持 —— 跨 seed 稳定（唯一稳健项）。** 训练分布内 tf@4 两 seed 都 ≤1.4pp 带内
   （−0.98 / +0.11pp），两臂都 ≥99% ⇒ 主口径「出口资产在 carry 存在时保持」**跨 seed 成立**。
4. **enwik8 代理口径结案**：该代理自身跨 seed 差 24.81pp（基准臂）⇒ **无跨 seed 可比性**，
   它不是「carry 打坏出口资产」的证据。
