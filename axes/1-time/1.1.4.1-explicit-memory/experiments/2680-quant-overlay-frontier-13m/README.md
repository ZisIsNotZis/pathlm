# 2680 · 把 KV 量化的 int8 档叠加到「每位置部署字节 vs clean bpc」图上

> 归属：`axes/1-time/1.1.4.1-explicit-memory`（研究项 1.1.4.1「显式记忆槽 / 线性状态」）。
> 入口：`run.py`（纯推理，0 训练 token；先过 `tools/prereg_bind.py <本目录> --require` 门）；
> 判据常数在 `config.json::criterion`；读数 `results.json`；人话判读 `analysis.md`。
> 复用仪器（只读）：`../2639-.../run.py` 的臂表口径、`../../../../5-quant/5.1-kv-quant/experiments/2632-kv-block-scale/block_arms.py`
> 的块标尺量化前向、`../../../1.1.1-hard-window/experiments/2662-.../realtext_probe.py` 的配对 bootstrap。

## 1 命题（可证伪）

`2639` 的前沿结论是：显式状态（`carrypl16_s0`）在 **393,216 B/位置** 处 bpc = **1.527595**，而同字节的
纯窗臂 `win32_s0` 是 1.595823 ⇒ carry 在**同字节**上占优 0.068228。但那张前沿只有 **fp16** 一档，
而 `5.1` 已判定 int8 块标尺近无损、每位置字节砍到 1/2 以下（6528·k vs 12288·k）——**纯窗族在量化档上
可以花更少的字节买同样的窗口**。所以本项自己列的缺口是：把量化点叠到同一张图上，看 carry 是否**仍**
不被支配。

一句话可证伪的形式：*对 `2638`/`2634` 已经训好的 7 条纯窗臂，只把**评测期**的 KV 换成 int8 + 块标尺
（G=32，0 训练 token）*，把新点与 `2639` 落盘的 fp16 点放在同一条（部署字节, clean bpc）横轴上，重算支配关系。
若存在 `total_bytes ≤ 393,216` 且 `bpc ≤ 1.527595 − 0.014` 的点 ⇒ **carry 点被支配**；否则 ⇒ 在本网格上
不被支配，并报出「决定性那一格」（int8 下 k≈60 = 391,680 B）是否在盘上。

## 2 干预与单因素声明

- **基底**：与 `2634`/`2638`/`2639` 逐字段同一 stock dense 规格（d256 × 12 × 8 头 × mlp6 × T256，13.5M）。
- **唯一变量 = 评测期 K/V 的数值格式**（fp16 → int8 + 块标尺 G=32）。臂、权重、掩码、数据、窗口序不变。
- **不训练、不新增参数、不改共享引擎**：量化前向来自 `2632` 的 `block_arms.masked_kv_quant_logits`（只读导入）。
- **必要性例外**：无。
- **两条口径限制（跑之前写死，不许事后改）**：
  1. `carry` 臂的块类不是 stock `Block`（`CarryChannelBlock`），`block_arms` 只认 stock `Block`/`GQABlock`
     ⇒ **carry 族的 int8 档本轮不测**（要写得另写量化前向）。因此本图给纯窗族的是**它自己最省的档**、
     给 carry 族的是 fp16 档 ⇒ 这对 carry 是**不利**的比较方向，若它仍不被支配，结论在该方向上稳健。
  2. carry 臂比纯窗臂多 **264,296 参数（+1.95%）**（`2639` 已登记） ⇒ 同字节比较带参数混杂，本实验只报
     `n_params` 列，不把同字节优势读成「纯机制」。

## 4 判据线（**预登记：写下后不得改**）

| # | 判据 | 判定线 | 该涨 / 该跌 / 必须不变 |
|---|---|---|---|
| ① | **复现门** | 11 个 fp16 格的 clean bpc 与 `2639::rows[*].bpc` **逐位相等**；不等 ⇒ 本实验作废 | **必须不变** |
| ② | **字节账（该跌）** | 每臂 `bytes_int8 / bytes_fp16 == 0.53125`（= 6528/12288），逐臂精确相等；解析值与实测架构逐位对账 | 该跌 |
| ③ | **质量腿（该不跌）** | 逐臂 `Δ_int8 = bpc(int8) − bpc(fp16)`，按窗口配对 bootstrap（10k 次）给 95% CI；`|Δ_int8| < 0.014` ⇒ **「本尺度无质量增量」**（禁写「无信号」）；`≥ 0.014` ⇒ 量化有可排序代价，如实报 | 该不跌 |
| ④ | **主判（支配）** | 新点集上重算：carry 点被支配 ⇔ 存在 `total_bytes ≤ 393,216` 且 `bpc ≤ 1.527595 − 0.014` 的点。若最小差距 < 0.014 ⇒ 「同一字节水平不可排序」 | 二选一如实报 |
| ⑤ | **网格缺口（必须报）** | 报出「决定性那一格」——int8 下 `k≈60`（391,680 B）——是否在盘上；**禁止在两点之间插值造点** | 必须报 |
| ⑥ | **口径** | 横轴 = 每位置缓存字节（值 + 块标尺，`2639` 同一口径）；配对 Δ 用 0.014 bpc 带、不跨量纲借用；`n=1` 的臂（除 `win16` 两 seed 与 `carry16` 两 seed）只能标「临时」；**墙钟不进判据** | 口径 |

## 5 否证条件

- 判据① 不成立 ⇒ 本实验作废（同一 checkpoint 同一函数应逐位复现，不复现即仪器或权重变了）。
- 判据③ 若 `Δ_int8 ≥ 0.014`（量化在纯窗族有可排序代价）⇒ 这是**允许**的判决，但要把「量化买字节的边际质量成本」
  写成结论的一半，且它同时改变前沿点位的合法性。
- 若判据④ 结果两向都不到 0.014 ⇒ 只许写「本网格上不可排序」，不许写成「carry 占优」或「carry 被支配」。
