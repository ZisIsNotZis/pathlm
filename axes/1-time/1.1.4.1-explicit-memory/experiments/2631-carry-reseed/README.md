## 1. 命题

**「delta 写（只搬上次没搬的）在搬运任务上稳定有效」这个结论，目前只是单次观测：
它来自 `2618-carry-channel-13m`（ticket 35）的 1 个种子，而且它的首验主判据是
单查询关联回忆、被问的 pair 距离 241–255，超过了训练能看到的最大查询距离 240
（训练分布外）。**

本线问两件事，都用**训练分布内**的腿来判：

1. **跨种子的极差与方向**：三臂（无通道 / plain 写 / delta 写）在 **≥2 个随机种子**上
   重训后，分布内多查询召回的读数各自差多少？「有通道 ⇒ 召回变好」「delta ⇒ 比 plain 好」
   这两个方向在**每一个种子上**都成立吗？
2. **delta 是否仍然最好**：若某个种子上 delta 不再最好，**如实推翻**，不修图。

一句话可证伪的形式：*把三臂在两个种子上各重训一次（配方逐字段一致、只有
`carry_rule` 与 `seed` 不同），在**训练分布内**的多查询关联回忆上评测；若 delta 相对
无通道臂的增益在**每个种子上都 ≥ +5pp 且聚类 95% CI 下界 > 0**，则「delta 写在该任务上
有效」记为**跨种子稳健**；否则记为**不稳健**并给出实际极差。*

## 3. 干预定义（写清是「实现」还是「标签」）

**单共享记忆槽**（`pathlm/depth_ar.py::CarryChannel` + `CarryChannelBlock`，本次**未改**引擎）：

```
写入（每位置一次，来自输入流 h0）：k̂ = normalize(W_k h0)，v = W_v h0，β = σ(W_β h0 + b_β)
  plain： S_t = S_{t−1} + β_t v_t k̂_tᵀ
  delta： S_t = S_{t−1}(I − β_t k̂_t k̂_tᵀ) + β_t v_t k̂_tᵀ = S + β(v − S k̂)k̂ᵀ
读出（每层各一次）： a ← a_SDPA(窗口掩码) + γ_ℓ ⊙ mem_t ，mem_t = S_t q_t（读后写）
```

- **恒等起步**：每层读出增益 `γ_ℓ` 零初始化 ⇒ 起步逐位等于无通道臂（SCHEMA §10）。
- **本线不写共享文件**：不改 `pathlm/**`、`train_depth_ar.py`、`tools/**`、`tests/**`
  （本轮并行写入者分工：`tools/**`+`tests/**` 属 L1、`catalog.yaml` 属 L2）。
  本线只新增实验目录内的代码。

### 4a. 执行时的操作性定义（不改判据，只把口径落定）

- **主腿（判据①）** = **分布内多查询关联回忆**：`tools/evalkit/longrange_tasks.py::assoc_recall_multi_batch`
  的 `(T=256, K=8, Q=8, gap=14, sym=64, filler=64, cue=205)` —— **与训练用的生成器、参数完全
  相同**（2618/2629 训练配方就是它）。被问 pair 的距离由布局唯一确定为 **107–240**，
  **≤ 训练可见的最大距离 240**（2618 首验用的单查询腿是 241–255，本线只作辅助腿）。
  评测走与训练同一个 `window_anchor_keep_mask(T,16,0)`；可见窗口内**不含任何键/值符号**
  ⇒ 局部先验 = chance。
  - 规模：64 批 × 批 64 序列 × 8 查询 = **4096 序列 / 32768 次提问**；数据生成器 seed 与
    模型 seed 无关 ⇒ 六臂**在同一批位置**上被问同一批问题（**配对**可比）。
- **统计口径（判据①的「不得当独立二项样本」）**：**主 CI = 按序列聚类的 bootstrap**
  （bootstrap 单位 = 一条序列的全部 8 个查询；B=2000，seed=2631，percentile 95%）；
  臂间差用**配对聚类 bootstrap**（两臂重采样同一组序列索引）。并报
  每条查询的 Wilson CI 作**对照**，显式标注「按独立二项样本算，偏窄（复核 B2）」。
- **判据①的判定线（预登记）**：`Δ(delta − none)` 的**聚类 95% CI 下界 > 0** 且
  点估计 **≥ +5pp**（沿用 2618 判据②的 5pp）；
- **判据③的判定线（预登记）**：`Δ(delta − plain)` 的聚类 95% CI 下界 > 0 且点估计
  **≥ +3pp**（沿用 2618 判据③的 3pp）。
- **判据②的口径**：每个种子上各算一次效应 ⇒ 报**逐种子效应表**、**极差**（max−min）、
  均值、样本 sd（n−1）、**方向一致性**（符号是否全体相同）。「跨种子稳健」= 两个种子上
  都过判据①的判定线。
- **判据④（毁源对照，强制）**：把源片段 `[0, 2K)` 换成全新随机符号（其余逐位不变）；
  操作化：任何一臂若**主臂聚类 CI 下界 > 4×chance = 6.25%**，则其**毁源臂聚类 CI 下界
  必须 ≤ 6.25%**，否则该臂读数**作废**（不是搬来的信息）。
- **辅助腿（不作判据，判据⑤）**：单查询关联回忆 `assoc_recall_batch(K=8)` ⇒ 距离
  **241–255**（训练分布外，§17.18）。该腿在 42-W2 已被同配置三跑量化过方差（极差
  10.840pp），本线只报数、只作辅助。
- **禁外推**：绝对水平只适用于「该任务 / 该尺度 / 12k 步快照」；不得读成
  「业界做不到/做得到」，不得外推到别的任务或更大规模。

## 8. 既有做法（prior art，SCHEMA §18）

1. **谁做过**：MQAR 基准（Zoology / Based，2023–24）用「多查询关联回忆」测线性注意力与
   注意力头的能力边界；线性注意力一族（Linear Attention / DeltaNet / GLA / Mamba 系）
   的核心分歧正是**写入规则**：累加式 `S += βvkᵀ`（Linear Attention）vs **移除式/残差写**
   `S ← S(I − βkkᵀ) + βvkᵀ`（DeltaNet 的 delta rule，2021；Gated DeltaNet 2024）。
2. **为什么这么设计**：有限状态是「容量固定」的，纯累加写在键重复出现时会互相干扰
   （同一 key 的新旧 value 叠加）；delta rule 先把状态里已有的该 key 分量扣掉再写，
   理论上给出「键值替换」而非「叠加」的语义，容量利用率更高。
3. **它的实测结果**：DeltaNet 一系在 in-context recall / MQAR 上优于同尺寸累加式线性注意力
   （论文口径：同参数量、同 FLOPs）。（`记忆·未核`——本环境联网不可用，未查原文。）
4. **我们的增量**：**不是**提出 delta 写；而是把「写入规则」作为**单因素**放进一个
   **13M 稠密主干 + 窗口掩码**的受控装置里，测**跨种子的可复现性**——
   业界报告多为单种子/单配置，本线问的是「这条结论在我们的装置上跨种子稳定吗」。
   已知的**我方反证**：48/47-W2 在非稠密 ragged 配方上 seed=1 的分布内腿为 **−3.26pp**；
   本线在稠密 + 窗口配方上给出第二种子的独立读数。

## 9. 失败决策树（测量 → 实现 → 规模 → 设计）

1. **测量**：无通道臂显著高于 chance ⇒ 先查窗口掩码是否生效（活性量 `keep_mask` 的可见
   位置数、局部先验读数），修设置再判。
2. **实现**：通道活性为 0（`read_share` / β / 状态范数任一为 0）⇒ 先跑变异验证（M1–M6）
   排除死开关与未来泄漏。
3. **规模**：通道活性非零但六臂都 ≈chance ⇒ 该任务/该尺度上「不划算」（SCHEMA §19：
   不得表述为「机制不可能」）。
4. **设计**：某臂主臂高、**毁源后不掉** ⇒ 该臂读数作废（判据④）。
