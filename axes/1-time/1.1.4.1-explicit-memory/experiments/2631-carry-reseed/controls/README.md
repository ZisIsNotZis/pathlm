# controls · 2631 的对照臂与方差界（索引）

本实验的对照**不另建独立目录**（对照臂本身就是被训练的臂 / 评测期的一次前向）；
落盘位置如下（SCHEMA §3 的 `controls/` 要求以本文件满足：三要素 + 方差界在这里写清）。

## 1. 对照臂 ①：无通道基线（`none_s0` / `none_s1`）

- **输入分布**：与同种子的 plain/delta 臂**完全相同**的合成任务批（同一生成器、同一
  `gen_seed`、同一 token 约定；生成器 seed 与模型 seed 无关 ⇒ 六臂在同一批位置被问同一批问题）。
- **要预测什么**：同一位置集上的同一个 token（关联回忆的答案）。
- **部署中对应什么**：不做任何显式搬运的 stock dense decoder-only transformer
  （本仓 13M 基线；与 2618 的 U0 逐字段相同）。
- **读数**：`results.json::main_leg.{none_s0,none_s1}`；前提校验见 `::premise_check`。

## 2. 对照臂 ②：毁源对照（每臂强制，评测期）

- **输入分布**：把源片段（`[0, 2K)` 的键值表）换成**同分布新随机符号**，其余逐位不变
  （`longrange_tasks.corrupt_span`）。
- **要预测什么**：同一个答案（问题不变，只是「被搬的东西」被毁掉）。
- **部署中对应什么**：「读数是不是真的来自那段远处内容」的判据；毁源后仍高 ⇒ 读数来自
  位置/局部规律 ⇒ **该臂判读作废**（契约判据④）。
- **判定操作化（读数前写下）**：主臂**聚类 CI 下界 > 4×chance = 6.25%** 的臂，其毁源臂
  聚类 CI 下界必须 ≤ 6.25%；见 `results.json::corrupt_control`。

## 3. 诚实对手 ③：plain 写臂（`plain_s0` / `plain_s1`）

- **输入分布 / 预测什么 / 部署对应**：与 delta 臂**逐位等参数、逐字段同配方**，唯一变量 =
  写入规则（`S ← S + βvkᵀ` vs `S ← S(I−βkkᵀ) + βvkᵀ`）。
- **用途**：判据③的对手——「delta 更好」必须与这个**同参数量、同算力**的臂比，
  不能只跟无通道基线比（SCHEMA §15）。
- **已知风险**：2618 观测到 plain 臂**双稳态**（同配置两次：0.0732% vs 3.3447%）⇒
  本线用**两种子**给它两个独立样本，正是要量化这件事。

## 4. 方差来源与不可排序线

| 量 | 值 | 来源 |
|---|---|---|
| 评测侧同权重同批位置重评 | **逐位相同**（`hits_1 == hits_2`） | `results.json::reproducibility` |
| **训练侧跨种子散布（本实验的主方差源）** | 见 `results.json::arm_accuracy_spread_across_seeds`（逐臂极差/sd） | 六臂训练 |
| 准确率的预登记实用阈值 | **1.4pp**（**预设阈值，不是已测方差**，C13） | `catalog.yaml` / 本目录 `reseed_arms.BAND_PP` |
| 统计口径 | 主 CI = **按序列聚类的 bootstrap**（同一序列的 Q 个查询共享 KV/记忆状态，不是独立样本，复核 B2）；Wilson 仅作偏窄对照 | `results.json::main_leg.*.clustered_ci` |

⇒ 判据②③按「点估计过阈值 **且** 配对聚类 95% CI 下界 > 0」判定，逐种子各判一次，
再用**极差 + 方向一致性**描述跨种子稳定性。

## 5. 仪器与退化点护栏

- **窗口掩码非退化**：`window_anchor_keep_mask(256, 16, 0)` 的可见对数 3976 < 因果对数
  32896（§17.16：排除恒等算子充当观测点）；`run.py` 运行时断言，`test_reseed_stats.py` 单测钉住。
- **主腿在训练分布内**：多查询生成器（K=8/Q=8/gap=14）的距离被布局唯一确定为 **107–240**
  ≤ 训练上限 240；`run.py` 断言 `d_max ≤ 240`，`reconcile_numbers.py` 由生成器重算核对。
- **辅助腿在分布外**：单查询腿距离 **241–255**（提问行 = T−1，训练从未出现）⇒ 只报数，
  不作判据（§17.18）。
- **逐位仪器自检**：释放版 vs 显式因果掩码 = 0.0；模型自带窗口掩码前向 vs
  `masked_logits + keep` = 0.0（训练/评测同一件仪器）。
- **单边零起步**：plain/delta 臂在 γ=0 起步时 logits 与无通道臂**逐位相同**（SCHEMA §10），
  且 `∂L/∂γ ≠ 0`（非鞍点）。
