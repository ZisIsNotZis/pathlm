# 2684 判读 · 窗外召回在整条窗口预算网格上：每个预算点都有第二轴数字了

## 0 人话摘要（先人话，数据在后）

**原本要回答什么**：`1.1.4.1` 的里程碑验收里有一条字面要求——前沿图上**每个**预算点都要有
「质量 + 可检索性」两轴数字。到上一轮为止，只有 393,216 B 这一个点有第二轴（`1.1.4.5` 的 `2661`：
同索引硬子集 10.226%、对撞 +9.522pp），其余预算点（窗口 16/17/18/24/32/60/64/128）只有质量轴。

**实际怎样**：把这台针仪器搬到整条网格上以后，**每个预算点都有第二轴数字了**，而且结论很干脆：

- 完备机制（窗口 16 + 逐层状态，`carrypl16_s0`）在一个**对每个臂都在窗外**的固定子集上
  （1206 针，距离 > 128，网格最宽的 win128 也看不见）召回 **6.4677%**（Wilson [5.21%, 8.00%]），
  配对地板 **0 命中**。
- 九个纯窗臂（窗口 16 → 128）在同一子集上全都停在 **0.33% ~ 0.91%**：单看数字，
  `carrypl16_s0` 比每一个都高 **+5.56 ~ +6.14pp，九个 95% CI 全部不含 0**。
- 退化实现（单共享槽、只从 h₀ 写、无门控）也停在 **0.83% / 0.91%**，与纯窗臂同量级，
  被完备机制甩开 **+5.64 / +5.56pp**（CI 分别 [4.16, 7.12] / [4.07, 7.04]）。

人话：**把前缀真的丢掉以后，纯注意力这条路上「把窗口开大」几乎换不回远处信息（本网格上是 0.3%→0.9%
的差别，而且不单调、CI 互相重叠）；能把它带回来的只有显式状态，而且必须是完备实现**——把
「逐层独立状态 + 内容写门」降级成单共享槽，召回就掉回纯窗水平。这正是质量轴想说而没说全的那件事：
393,216 B 上那 +0.030928 bpc 的优势不是「多给了参数」的副产品，而是「信息真的被搬回来了」。

**排除了哪些别的解释**：

- **不是仪器变了**：仪器复现门（判据①）把六个复用臂在窗口 16 可见性下的读数重算了一遍，
  同索引硬子集 **n=2699 且六个臂的命中数与 `2661` 逐位相同**（19/27/43/53/276/77）。
- **不是「窗口大就能看见」**：固定子集取的是距离 > 128 的针，比网格里最宽的 128 窗口还远，
  所以对每个臂都落在注意力看不见的地方。
- **不是「随便有个状态就行」**：退化实现与纯窗臂同量级（0.83% / 0.91% vs 0.33%–0.91%），
  只有完备实现跳到 6.47%。
- **不是记忆太短造成的假象**：γ=0.99 的完备臂（T=256 下只剩 7.6%）拿 **1.5755%**（19/1206），
  介于两者之间——方向与「记忆越短搬回的越少」一致，是旁证不是判据。

**没解决的**：仍是 enwik8 / T=256 / 13M / 12k 步 / seed 0 这一格；完备臂只有 seed 0（`carrypl16_s0`）；
`carrypl16d_s0` 是同一个 seed 的另一种 γ。召回口径是 6 字节短语的 top-1 命中，不等于自由生成的质量。

## 2 固定远端集的口径（为什么这样取）

- 桶是**逐臂**的：每臂用自己训练时的可见性（`window_anchor_keep_mask(T, w, 0)`）跑针，
  所以「距离 > 16」对窗口 60 的臂是可见的。跨臂比较因此**不能**用各自桶里的 beyond。
- 取固定集：**针距离 > 128**（网格最宽的 `win128_s0` 也看不见）∩ **十三臂 control 全部答不出**
  ⇒ 同一组索引上，任何臂都没有「看一眼就答出来」的机会，命中只可能来自被搬动的信息。
  4413 个距离 > 128 的针里，交完十三臂 control 全答不出剩 **1206** 个（地板在这 1206 个上逐臂 0 命中）。
- 与 `2661` 的关系：`2661` 的索引集是「距离 > 16 ∩ 六臂 control 全答不出」= 2699 个，
  所以同一台仪器上 `2661` 的 10.226% 与本轮的 6.4677% **不是同一组针**，不能相减；
  本轮更大的价值在于它把「每个预算点」都放进同一组针里。

## 3 它把什么说清楚了、没说什么

- **说清楚了**：⑴ 里程碑的字面缺口（每个预算点两轴）补上——九个窗口预算点 + 四个 carry 臂
  在**同一组针**上都有召回数字；⑵ 完备机制在每个预算点上都高于同窗口纯注意力（+5.56 ~ +6.14pp，CI 不含 0）；
  ⑶ 召回增益**归因到机制完备度**：退化实现（单共享槽）掉回纯窗水平；
  ⑷ 纯注意力这条路上「把窗口从 16 开到 128」换不回窗外信息（0.33%→0.91%，不单调、CI 重叠）。
- **没说**：不说「显式状态的召回率是 6.5%」这种脱离口径的话（它对着 1206 针的固定集、6 字节短语、
  top-1 命中）；不说窗口开大一定没用到远处信息（本网格只测了「针在窗外」这一种用法）；
  不说这是自由生成质量的证据。
- **不能说**：不能把本读数与质量轴直接相乘或相除（量纲不同：一端是 bpc，一端是率）。
  质量轴的家是 `2638` / `2639` / `2681`，本实验 0 个 bpc 读数。
