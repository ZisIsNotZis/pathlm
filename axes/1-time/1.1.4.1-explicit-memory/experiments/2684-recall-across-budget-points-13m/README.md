## 1 命题（一句话、可证伪）

`1.1.4.1` 的里程碑验收里有一条字面要求：**前沿图上每个预算点都要有质量与可检索性两轴数字**。
现在只有 393,216 B 这一个点有第二轴（`1.1.4.5` 的 `2661`：同索引硬子集 10.226%、对撞 +9.522pp）。
**可证伪形式**：把 `2661` 的同一台针仪器、同一 generator 序列、同一条桶规则搬到**整条窗口预算网格**上
（窗口 16 / 17 / 18 / 24 / 32 / 60 / 64 / 128 的纯窗臂 + 四种 carry 实现），每臂用**它自己训练时的可见性**
评测，在一个**对每个臂都在窗外**的固定索引集（距离 > 128，网格最宽窗口也看不见）上量召回。

若在这个固定集上，完备机制（`carrypl16_s0`）的召回 **不高于**某个更省字节或同字节的纯窗臂
（两比例差 CI 含 0 且差 ≤ 0）⇒ 「显式状态把远处信息带回来得更多」在**该预算点**上不成立，
必须写进 `project.yaml::conclusion`，不得降级成「不可排序」。否则 ⇒ 每个预算点都有第二轴数字，
且完备机制的第二轴读数高于同窗口的纯注意力。

## 2 单因素声明

- **基底**：与 `2634` / `2638` / `2639` / `2681` 逐字段同一 stock dense 规格（d256 × 12 层 × 8 头 × mlp6 × T256，
  13.54M，tied 读出 + 无 final LayerNorm + 顺序残差），同一数据（enwik8 末 10M 字符评测）、同一 `seq_len=256`。
- **唯一变量 = 每臂的可见预算**：窗口 w ∈ {16,17,18,24,32,60,64,128}（纯注意力），或「窗口 16 + 显式状态」
  （carry 族，三种实现：单共享槽 / 逐层状态 γ=1 / 逐层状态 γ=0.99）。
- **仪器不动**：针构造 `phrase_needle_batch`、针数（8 针/行）、`phrase_len=6`、placement `anchors=8`、
  generator `seed=3`、桶规则（`bucket_anchors=0`）、统计层全部是 `2661` 的同一份文件（sha256 见 `config.json`）。
- **本实验不改任何共享文件**（`pathlm/**`、`train_depth_ar.py`、`tools/**`）：纯推理，只调既有函数。

## 4 判据线（**预登记：写下后不得改**）

| # | 判据 | 判定线 | 该涨 / 该跌 / 必须不变 |
|---|---|---|---|
| ① | **仪器复现门** | 六个复用臂在**窗口 16 可见性**下的同索引硬子集读数与 `axes/1-time/1.1.4.5-implicit-vs-explicit/experiments/2661-implicit-vs-explicit-recall-13m/results.json::needle_leg` 逐位相等（`n_intersection` = 2699；hits `win16_s0` 19 / `win16_s1` 27 / `carry16_s0` 43 / `carry16_s1` 53 / `carrypl16_s0` 276 / `carrypl16d_s0` 77）；不等 ⇒ 本实验作废，判据线不改 | **必须不变** |
| ② | **主判（召回轴在固定集上成立）** | 固定远端集（针距离 > 128 且十三臂 control 全部答不出）上，`carrypl16_s0` 的植入召回 Wilson 95% 下界 > 0；并与它在**同一索引集**上的配对地板比（两比例差 CI 下界 > 0） | 该涨 |
| ③ | **决定性对撞** | 同一固定集上，逐纯窗臂报 `carrypl16_s0 − 该臂` 的两比例差（正 = carry 更高）与其 CI；**禁插值**；每个预算点的方向必须逐条写进判读，不许只报最好那一条 | 二选一如实报（正 ⇒ carry 把远处信息带回来得更多；≤0 或 CI 含 0 ⇒ 该点上不成立） |
| ④ | **网格单调性（结构自检，不作判据）** | 纯窗臂在固定集上的召回随 w 不降 —— 这是「窗口越大看得越多」的结构事实；若某处反常，如实报并回查仪器 | 必须报 |
| ⑤ | **完备度对照** | 退化实现（`carry16_s0` / `carry16_s1`，单共享槽、只从 h₀ 写、无门控）在同一固定集上的召回必须报出；若它与完备机制同量级 ⇒ 「召回轴能归因到机制完备度」不成立，必须如实写 | 必须报 |
| ⑥ | **口径** | 率类只走 Wilson 95% CI 与两比例差 CI（正态近似、未 pooling），**不跨量纲借 0.014 bpc 带**；墙钟不进判据；**本实验不新增任何 bpc 读数**（质量轴的家是 `2638` / `2639` / `2681`）；n=1 的臂只能标「临时」 | 口径 |

## 5 否证条件

- ① 不成立 ⇒ 本实验作废（同一 generator 序列、同一仪器应逐位复现 `2661`）。
- ③ 若某个纯窗臂在固定集上 **不低于** `carrypl16_s0`（差 ≤ 0，或 CI 含 0 且点估计 ≤ 0）⇒
  该预算点上「显式状态把远处信息带回来更多」不成立，必须逐条写进 `project.yaml::conclusion` 与
  `analysis.md`，不得写成「不可排序」。
- ⑤ 若退化实现与完备机制在固定集上无差别 ⇒ 召回轴在本网格上**不能**归因到机制完备度，
  只能报「有通道 vs 无通道」，也必须如实写。

## 6 成本

- 纯推理：13 臂 × 64 批 × 2（植入 / 控制）针批 + 13 次基线前向。

## 8 scope 声明与禁外推

单轴单格（`1.1.4.1`）；只沿本格主轴（每位置部署字节 / 可见预算）补第二轴读数，不开新机制、不改引擎。
**禁外推**：结论只适用于 enwik8 / T=256 / 13M / 12k 步 / seed 0（`win16` 与 `carry16` 有 seed 1）这一格；
`win128_s0` 的定义使「距离 > 128」成为全网格的窗外集，**不许**把某个预算点的召回外推到 T ≫ 256，
也不许把它当成「显式状态的召回率上限」——针是 6 字节短语、命中口径是 top-1，与自由生成的质量不是同一件东西。
