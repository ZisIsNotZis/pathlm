# controls — 对照臂与方差界（2619）

本实验的**每一个**格（4 臂 × 4 难度档 = 16 格）都同时跑下面三条对照。原始读数在
`../results.json::grid[<arm>_K<K>]`，机检在 `../reconcile_report.json`。

## 1. 毁源对照臂（强制，判据 ⑤）

- **做法**：`tools/evalkit/longrange_tasks.py::corrupt_span(task, 0, 2K)` —— 把
  `[0, 2K)` 的 key/value 全部换成**同分布随机符号**，查询行 / 答案标签 / 距离**逐位不变**。
- **为什么**：如果读数来自「搬过来的源信息」，毁掉源后必须掉回 chance；若仍高，
  说明读数来自位置/局部先验或仪器混杂 ⇒ **该格判读作废**（契约 U 的判据 ④）。
- **判据的**操作化**：作废条件 = 毁源读数的 **Wilson CI 下界 > 4×chance**（= 0.0625）。
- **结果**：16 格毁源读数全部落在 **0.0127–0.0173**（chance = 0.015625），
  **作废格数 = 0**。即：所有正读数都来自搬过来的信息。

## 2. chance（瞎猜基线）

- **任务**：多查询关联回忆，词表 64 个符号，同一行内 key 互不相同
  ⇒ 答案集合大小 = 64 ⇒ **chance = 1/64 = 0.015625**（全档位相同）。
- 各格的 `local_prior`（用最近 8 个位置能抄到的符号做预测）实测 **0.0078–0.0195**
  ⇒ 局部先验**退化到 chance** ，窗口确实把可抄的信号掐断了（SCHEMA §19 的
  「局部先验抗性」在评测侧的直接读数）。

## 3. 前提对照：查询键落在窗外

- 评测掩码 = 训练掩码 = `window_anchor_keep_mask(256, window=16, anchors=0)`。
- 被问的键与查询键的距离实测：**min 107 / median 175 / max 240** ≫ 窗口 16
  ⇒ 「不搬就真答不出」。这是判据 ① 的前置校验。

## 4. 对照的复用与不重复

- **不重训 no-channel 基线**：ticket 35（`../2618-carry-channel-13m/`）已实测
  无通道臂在该任务上 ≈ chance（0.0137 vs chance 0.015625）。本实验的对照是
  **chance 线 + 毁源臂 + 局部先验**（三者都对同一读数施压），不再重复花 GPU。
- **方差界**：本仓方法学（`harness/methodology.md`）规定 Δ < 0.014 不可排序。
  本实验里所有**结论性**的方向判断都同时满足「Wilson 95% CI 不重叠」——
  例如难度曲线相邻三段的 Δ 分别是 −16.9 / −25.8 / −5.1 pp，
  容量轴不可分辨段的 Δ ≤ 0.4 pp（远小于 0.014 的排序门槛）。
- **复现性**：anchor 格（`D32/K=8`）同 seed 整批重跑，逐位一致
  （`same_seed_rerun_max_abs_diff = 0.0`）。
