# stability · 2618 显式写入通道（U0/U1/U2，13M）

口径：全部数字来自 `results.json` / `divergence.json` / `train/<arm>/train_log.jsonl` /
`smoke/detA|detB` / `mutation_report.json`；报告数字由 `reconcile_numbers.py` 逐条回算。

## 0. 一句话

**评测侧完全可复现（同 seed 整批重跑逐位相同）；训练侧不可逐位复现（项目已知事实，量级
3e-4/步），而本实验观测到它的后果被放大成「学不学得动」的双稳态 —— plain 臂两次同配置同
seed 训练：一次没学到（答案行 CE 4.184 ≈ 瞎猜 4.1589、评测 0.0732%）、一次学到了
（2.2524、评测 3.3447%）；delta 臂一次就学到（1.4772、评测 9.4971%）。判据②（U2 远高于 U0）
稳健；判据③（delta 优于 plain）在**两支 plain 读数上都过**（正式 +9.42pp、重跑 +6.15pp，
两次区间都不重叠）。**

## 3. **plain 臂的双稳态**（本实验最重要的一条）

三次**同配置、同 seed、同代码、同数据流**的 plain 训练，答案行 CE 轨迹：

| step | U1（正式臂） | U1rep（重跑臂） | U2（delta，对照） |
|---|---|---|---|
| 0 | 5.523 | 5.523 | 5.523 |
| 800 | 4.328 | 4.370 | 3.121 |
| 1600 | 4.249 | 4.269 | 2.344 |
| 2400 | 4.221 | 4.235 | 2.039 |
| 3200 | 4.207 | 4.491 | 1.878 |
| 4000 | 4.198 | 3.990 | 1.778 |
| 4800 | 4.192 | 3.586 | 1.709 |
| 6400 | 4.185 | 3.045 | 1.618 |
| 7200 | 4.182 | 2.861 | 1.589 |
| 11999 | **4.184** | **2.2524** | **1.4772** |

- 三条轨迹在 step 0–2400 **几乎重合**（同数据、同初始化），此后 U1rep 在 step
  ~3000–4000 之间**起跳**（loss 0.506 → 0.3367），U1 没有起跳（loss 停在 0.5056）。
- 更早的一次试跑（per-layer 实装期间的 shared-slot 版本，同配置同 seed）在 step 5000 的（原写 3600 无留存支持）
  答案行 CE 已是 **3.5015** —— 与 U1rep 同一支路。⇒ plain 臂是**两态**（学到 / 没学到），
  不是连续散布。
- 由于两次训练直到 step ~2400 逐位相近（差异 ~3e-4/步，§2），这个分岔点**只能由训练侧的
  微小数值差异触发**：即「学不学得动」在本任务/本规模上是一个**临界现象**，不是确定性的
  函数关系。

**对判据的影响**：
- 判据②（U2 vs U0）：U0 从未学到（三次：4.237/4.24；U2 一次学到 1.477）⇒ 主判据的
  **方向稳健**（+8.13pp，CI 不重叠）。
- 判据③（U2 vs U1）：U1 没学到、U1rep 学到了，于是把两支都拿来比 delta：

| 比较 | 准确率（CI） | Δ | CI 重叠 | p |
|---|---|---|---|---|
| 正式 U1 vs U2 | 0.000732 [0.000249, 0.002151] vs 0.094971 [0.086368, 0.104333] | **+9.424pp** | 否 | <1e-8 |
| **重跑 U1rep vs U2** | **0.033447 [0.028363, 0.039406]** vs 0.094971 [0.086368, 0.104333] | **+6.152pp** | **否** | <1e-8 |
| 同配置两次 plain（U1 vs U1rep） | 0.000732 vs 0.033447 | **+3.271pp** | 否 | <1e-8 |
| U1rep vs U0 | 0.033447 vs 0.013672 | +1.978pp | 否 | <1e-8 |

  ⇒ 判据③在**两支 plain 读数上都成立**（+9.42pp / +6.15pp，均 ≥3pp 且 CI 不重叠）；
  「同配置两次 plain 差 +3.27pp」本身说明**训练侧不稳定是真实存在的一阶效应**。
  因此判据③判**过**，但「delta 规则本质必然更优」这类强表述**不作为结论**（每支 plain 只有
  n=1）；下一步应先建立多 seed + 预登记的「学习成功判据」（例如答案行 CE < ln64 − 0.5，
  即 < 3.66）再做规则对比。

## 4. 实现决策的成本/显存复核（SCHEMA §17.8）

| 实装 | U0 步时 | U1 步时 | U2 步时 | 峰值显存（训练，实测净） |
|---|---|---|---|---|
| per-layer 12 状态（出局） | 49–54 ms（基准）/ 63.2 ms（落盘日志） | 207 / **221.1 ms** | 396–425 / **410.5 ms** | 3.4–4.7 GB（delta C=256 达 9.2 GB ✗） |
| **单共享槽（采用）** | 49–54 ms（基准）/ 55.6 ms（最终日志） | **60.7 / 67.4 ms** | **73.1 / 81.3 ms** | **2015 / 2170 / 2282 MB** |

> 斜杠两侧分别是「实现期计时基准」与「落盘日志（`smoke/smoke_u*/train_log.jsonl`、
> 最终训练墙钟/步数）」两次测量；per-layer 那组两次相差 5–7%（3.5×/6.5× 量级不变），
> 单共享槽那组倍数 **1.21× / 1.46×**。同组内同口径可比，跨组不作精确比较。

- 出局原因 = **算子派发/autograd 节点开销**（每个算子 CPU 派发 60–150 µs、每个 autograd
  节点 ≈180 µs；per-layer 每步 ≈1000 算子），**不是 FLOPs**（单个 `solve_triangular`
  0.04 ms、单个 `bmm` 0.10 ms GPU 时间）。
- 单共享槽的实测步时倍数 **1.24×（plain）/ 1.49×（delta）**，三臂 + 评测总墙钟 ≈44 min，
  落在契约预算内 ✓。

## 6. 已知的仪器小疵（如实记录，不影响判据）

- `train/<arm>/results.json` 末尾的 `carry_liveness` 块里，`write_rel`/`n_chunks` 取自**最后
  一次前向**（那是 64 token 的形状探针 `_kv_head_liveness`）⇒ `n_chunks=1`、
  `write_rel_chunks=0`，`write_rel` 因此显示 0（该量在单块时**无定义**，见
  `carry_scan_chunked` 的注释）。**每 200 步写在训练日志同一行的活性量是权威口径**
  （T=256、4 块 ⇒ `write_rel` 有定义：U1 0.647、U2 0.408），`analysis.md` §5.3 用的就是日志口径。
- 该小疵在三个臂上完全一致（同代码同路径），不构成臂间不一致。
