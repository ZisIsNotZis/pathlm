# 2.3 深度的形状 · 分组

> 分组节点：只聚合子研究项，不写 `project.yaml`（`docs/structure.md` §13）。
> 轴：**2 深度轴** ｜ 用词以 `docs/structure.md` 为准。

普通 decoder-only transformer 每层同宽、每层都在全长 T 上。本分组问：**沿深度改变形状**
（每层的容量、每层处理的位置数/分辨率）能否在同总参数或同总 FLOPs 下提高质量-代价。

## 子节点

| 编号 | 研究项 | 目录 | 粒度 | 一句话 |
|---|---|---|---|---|
| 2.3.1 | 逐层容量变化：前大后小 / 逐渐放大 | [`2.3.1-layer-capacity`](../2.3.1-layer-capacity/) | 研究项 | 固定总参数下把容量按深度重分配 |
| 2.3.2 | 逐层分辨率：先粗后细、层级式（层级合并） | [`2.3.2-layer-resolution`](../2.3.2-layer-resolution/) | 研究项 | 浅层粗/短序列、深层细/全长的分辨率 schedule |

## 共同口径

- 对照 = 同尺寸 **stock uniform 全深度**（归一为 100%）。
- 判据 = clean bpc（序列级，该跌/可排序）+ 每层容量分布或每层处理 token 数（代价/结构列）+ 长程召回（2.3.2，防降采样丢信息）。
- 同预算对齐：比较时必须先对齐「总参数」或「总 FLOPs」，否则不可比。
- **墙钟不进判据**；代价 = 等效理论量（FLOPs / layer-passes / tokens-per-forward），考虑 pipelining。
- 边界：`2.3.1` 与 `3.1.2` 逐层宽度变化、`2.3.2` 与 `1.2.4` 动态合并机制重叠，须由 integrator 核一遍表述不重复、不矛盾。
