## 0. 人话摘要（先读这段）

**这一格在问什么。** 一个普通的、只做下一个字预测的变压器（decoder-only transformer），
层与层之间只有一条最朴素的接法：先注意力、再 MLP，一层串一层（顺序残差）。本实验只改这条
接线，试三种替代：

- **并行子层**（PaLM / GPT-J 式）：注意力与 MLP 同时读同一层的输入，层内不再一前一后；
- **并行子层 + 双 pre-LN**（等参数对照）：同上，但两个子层各带自己的 LayerNorm，
  参数量与普通接法**逐位相同**，用来把「并行带来的收益」与「参数账」解耦；
- **层间学习加权和**（DenseFormer 式）：每层输入＝对它之前**所有**层输出的学习加权和。

问题有两半：① 层间加权和能不能在相同预算下把质量做好（2.2.3）；② 并行子层要付多少质量代价、
换到的层内并行度值不值（2.2.4）。判据在跑之前就写死了：配对 bpc 差要越过 **0.014 bpc 的噪声带**
才算「说得出谁更好」。

**相对普通变压器改了什么、改了多少。** 只有接线。主干（d=256 / 8 层 / 8 头 / 序列 256 /
MLP 4 倍宽，约 696 万参数）逐字段不变。参数账：并行共享 LN 少 **4096**（= −8 层 × 2 × 256），
并行双 LN **0**（逐位等参数），层间加权和只多 **36** 个标量（= 8×9/2，相对主干 0.00052%）。

**怎么测的。** 四臂同一引擎、同一数据（enwik8 字符级）、同一 12000 步 × 批 32 × 序列 256 =
**9830 万 token** 的 matched-step 快照、同一评测电池；臂间唯一变量 = 接线。另外把 seed=0
（上一格 `2613`）的四臂读数并进来，凑成 **两个 seed**（n=2），用来区分「真差异」与「换种子
的抖动」。判据量是 clean bpc（每字符比特数，**越低越好**），配对差 = 该臂 − 普通接法。

**测出来多少（质量面，越低越好；括号里是相对普通接法、以及它是噪声带的几倍）。**

| 接法 | seed=0 bpc | seed=1 bpc | 相对普通接法（两 seed） | 结论 |
|---|---|---|---|---|
| 普通（顺序残差，基线） | 1.5254 | **1.5288** | — | 参照系 |
| 层间学习加权和（`dense`） | 1.5246 | **1.5273** | −0.0008 / −0.0015（都是噪声带的 6% / 11%） | **说不出差别** |
| 并行子层（共享 LN） | 1.5712 | **1.5710** | +0.0458 / +0.0422（3.27× / **3.01×** 带） | **明显更差** |
| 并行子层（双 LN，等参数） | 1.5656 | **1.5662** | +0.0402 / +0.0374（2.87× / **2.67×** 带） | **明显更差** |

读法：换一个 seed 会让普通接法自己漂 **0.0034 bpc**（噪声带的 24%）。层间加权和的两个偏差
（0.0008 / 0.0015）都小于这个漂移，方向一致但幅度在噪声里 —— 所以「它更好」这句话在本尺度
**说不出口**。并行子层的两个偏差是噪声带的 2.7–3.3 倍，且两个 seed 同号 —— 所以「它更差」
这句话**说得出口**，而且不是种子抖出来的。

**并行子层买到了什么（代价面，纯解析的等效量，不含任何时间量）。**

| 接法 | 层内串行依赖 | 每 token 串行步数 | 全栈算力（MACs/token） | 相对基线 | 参数 Δ |
|---|---|---|---|---|---|
| 普通（基线） | 2 段（注意力 → MLP） | 16 | 7,400,960 | 100.000% | 0 |
| 并行（共享 LN） | **1 段** | **8** | 7,396,864 | **99.945%** | **−4096** |
| 并行（双 LN，等参数） | **1 段** | **8** | 7,400,960 | 100.000% | **0** |
| 层间加权和 | 2 段 | 16 | 7,408,128 | 100.097% | +36 |

也就是说：并行子层把「一层之内必须先算完注意力才能算 MLP」这条串行链**砍半**
（每 token 串行步数 16 → 8，同一时间能并起来的活儿多一倍），算力几乎不变（差 0.055%，
就是少一个 LN 的那 4096 个参数；等参数臂是 0 差）。

**结论与下一步（人话）。**

- **2.2.3 层间学习加权和：本尺度没用。** 两个 seed 的配对差都落在噪声带内（−0.0008 / −0.0015），
  而且它**没有**换来更好的中间深度——中间各层的 bpc 反而**一致地更差**（seed=1 的 depth 1–7 差
  +0.27 ~ +0.61 bpc），只有最后那一层回到基线水平。干预确实是活的（层权全部非零、第一层输入
  被放大 2.24×），所以这不是「机制没跑起来」。⇒ 判**无净增量**，机制提案被本地证据否证；
  下一步的最小实验是更大规模点（本尺度只有 8 层、可聚合的源太少），见 §10。
- **2.2.4 并行子层：不是免费的，是否采纳取决于场景。** 质量面要付**说得出口的代价**
  （+0.0422 / +0.0374 bpc，两 seed 同号、越带），换到的是**层内并行度翻倍**（串行链 2 段 → 1 段）
  与几乎不变的算力。要吞吐/流水的人会觉得值，要质量的人不会——这条权衡在本尺度上没有免费的答案。
- 两项结论都只在 13M / 12k 步 / matched-step 快照上成立，**不越尺度外推**（§10）。

## 4. 配对 Δ 表（判据）+ 窗口级 SE

判据线（逐字来自 `README.md::§4` / ticket 61 §9.2）：配对 Δ 越 **0.014 bpc 带**才算可排序；
两 seed 同号且都越带 ⇒ 可排序；不越带 ⇒ 无差异。

符号约定：Δ = `clean_bpc(该臂) − clean_bpc(sequential)`，**正 = 该臂更差**。

| 配对 | s0 Δ | s1 Δ | 两 seed 判定 |
|---|---|---|---|
| `dense` − `sequential` | **−0.0008** | **−0.0015** | 同号，但**两 seed 都未越带** ⇒ **无差异**（`dense_sortable_two_seed = false`） |
| `parallel` − `sequential` | **+0.0458**（3.27× 带） | **+0.0422**（3.01× 带） | 同号且都越带 ⇒ **可排序**（更差） |
| `parallel-dual-ln` − `sequential` | **+0.0402**（2.87× 带） | **+0.0374**（2.67× 带） | 同号且都越带 ⇒ **可排序**（更差） |

出处：`results.json::cross_seed_s0_s1`（含 `same_sign` / `both_exceed_band` /
`sortable_two_seed`）与 `cross_seed_summary`；`results.json::reconciliation.arithmetic.delta_bpc`。

**配对窗口级 SE（seed=1，20 个窗口逐窗配对；`results.json::paired_delta_s1`）**：

| 配对 | Δ 窗口均值 | 窗口级 SE | 前一半 / 后一半 |
|---|---|---|---|
| `parallel` − `sequential` | +0.042188 | 0.003220 | +0.039691 / +0.044685 |
| `parallel-dual-ln` − `sequential` | +0.037404 | 0.002680 | +0.036763 / +0.038044 |
| `dense` − `sequential` | −0.001556 | 0.003056 | +0.001489 / **−0.004601** |

读法：并行两臂的窗口级 SE（0.0027–0.0032）比它们与带的距离小一个量级，两半样本同号；
`dense` 的偏差比它自己的窗口噪声还小，而且**两半样本符号相反**（前半更好、后半更差）
⇒ 这是抽样噪声的形状，不是一条小而稳定的收益。

## 5. 2.2.4 代价面同框表（等效理论量，**不含任何时间量**）

公式见 `run.py::topology_cost_face`（注意力 = 4d² + 2T·d；MLP = 2·mlp_mult·d²；
一个 pre-LN ≈ 2d MACs/token；读出 = d·vocab；`dense` 另加层间加权和 Σ(k−1)·d）。
参数 d=256 / L=8 / mlp_mult=4 / T=256 / vocab=206。原始值：`results.json::cost_face_2_2_4`。

| 接法 | 层内串行依赖（段） | 每 token 全栈串行步数 | 每层 MACs/token | 全栈 MACs/token（含读出） | vs 基线算力 | 参数量 Δ |
|---|---|---|---|---|---|---|
| `sequential` | 2（attn → MLP） | 16 | 918,528 | 7,400,960 | 100.000% | 0（基线） |
| `parallel` | **1**（两分支同读块输入） | **8** | 918,016 | 7,396,864 | **99.945%** | **−4096** = −L·2d |
| `parallel-dual-ln` | **1** | **8** | 918,528 | 7,400,960 | 100.000% | **0（逐位等参）** |
| `dense` | 2（attn → MLP） | 16 | 918,528 + 896（层间加权和摊派） | 7,408,128 | 100.097% | **+36** = +L(L+1)/2 |

**同框读法**：并行子层买到的是「层内串行链 2 段 → 1 段」（每 token 串行步数 16 → 8），
算力只差 0.055%（那点差就是少了一个 pre-LN 的 4096 个参数）；`parallel-dual-ln` 是**等参数
对照**——串行依赖同样砍半、参数量与基线逐位相同，把「并行的收益」与「参数账」解耦。
`dense` 的代价面可忽略（+36 个标量、+0.097% 算力），但它**不缩短**层内串行依赖
（仍 attn → MLP 两段），只是多了一条层间加权和，且推理需保留全部此前层输出。

**与质量面同框**（seed=1）：`parallel` / `parallel-dual-ln` 用 **+0.0422 / +0.0374 bpc**
的质量代价换「层内并行度翻倍」⇒ 见 §9.2 判词。

**（旁证）实测训练步时**（过程量，**不进判据、不进 `cost_model`**）：seed=0（`2613`）四臂
`seconds_per_step` = `sequential` 0.0325 s、`parallel` 0.0300 s（−8%，省一个 LN）、
`parallel-dual-ln` 0.0325 s、`dense` 0.0400 s（+23%，+36 个标量不应导致该量级，疑为 kernel
调度偶发）。seed=1 的对应值为 `parallel` 0.0325 s / `parallel-dual-ln` 0.0350 s / `dense` 0.0400 s
（`sequential` 臂本轮走 resume，未记步时），同向、同量级。

## 6. `SCHEMA.md` §12 三对账 + §13 对照三要素

### 6.1 §12 三对账

1. **算术对账**：clean bpc 理论下界 0；均匀预测参考值 log₂(206) = 7.69；四臂实测 1.53–1.57，
   均远低于该参考值（**log₂(206) 是参考值，不是分布数据的理论上界**；同仓已有 1322.98 bpc 的读数）。
   参数量账逐位精确（`results.json::reconciliation.arithmetic.params_delta_exact = true`）：
   `parallel − sequential = −4096 = −L·2d`、`parallel-dual-ln − sequential = 0`、
   `dense − sequential = +36 = L(L+1)/2`；`dense` 的新增参数占主干 0.00052%
   （`dense_params_added_frac = 5.17e-06`）。
2. **任务对账**：四臂同一 enwik8 字符级 AR 任务、同一 eval 切分（末 10M 字节）、同一位置集
   （全序列逐位置 × depth-8 读出）、同一目标定义（tokens 自移位）；同一 `run.py::run_battery`
   （同 20 个 eval 批、同 batch 16、同 eval seed=2）。对照臂只改「层与层之间的接法」，
   无额外输入、无真值泄漏。
3. **口径对账**：四臂同为 12000 步 / 9830 万 token / seed=1 的 matched-step 快照；s0 与 s1 的
   评测口径由 §3.1 的逐位等值门钉住。**墙钟一律不进判据或 `cost_model`**（`cost_model` 字段与
   §5 表均为等效理论量；`wall_min` / `seconds_per_step` 只作过程量落在实验产物里）。
   **收敛对账**（`results.json::reconciliation.convergence`）：末 25% 窗 loss 斜率四臂

## 9. 判词（口径预登记，**未事后改判据线**）

### 9.1 `2.2.3` 层间学习加权和

- **字面（预登记判据线）**：s0/s1 两 seed 的 `dense − sequential` 配对 Δ 是否越 0.014 bpc 带？
  **s0 = −0.0008，s1 = −0.0015，两 seed 同号但都未越带** ⇒ 按 `README.md::§4` 的字面判词：
  **「在本尺度（13M / 12k）+ 0.014 带下，层间学习加权和相对 stock 单残差无可排序差异（n=2，
  两 seed 皆落带内）」**，即「无差异」可下。
- **实质（falsification 全条件）**：本项 falsification = 「若不越噪声带（0.014）**且**
  逐深度可读性无改善 ⇒ 判密集跨层线性聚合在本尺度无净增量」。两条件**都成立**：
  - 不越带：|−0.0008| / |−0.0015| ≪ 0.014，且都小于基线臂自己的换 seed 散度 0.0034；
    配对窗口级 SE 0.0031 大于偏差本身，两半样本符号相反（+0.0015 / −0.0046）。
  - 逐深度可读性**无改善**（实测更差）：`dense` 的中间深度 bpc 在两 seed 上**一致高于**基线
    （s0 depth 1–7：+0.226 / +0.544 / +0.448 / +0.312 / +0.206 / +0.257 / +0.279；
    s1 同向且更大：+0.472 / +0.613 / +0.502 / +0.445 / +0.283 / +0.298 / +0.268），
    只有最终 depth 8 回到 −0.0008 / −0.0015。
  ⇒ 判**本机制在本尺度无净增量**。
- **`status`**：**`被否证`**（机制提案「密集跨层线性聚合在本尺度带来质量增益」被本地证据否证）。
  **边界**：这是**尺度受限**的否证（13M / L=8 / 12k 步），不是「DenseFormer 普遍无效」——
  更大规模与带中间深度监督的复核未做（§10）。
- **失败归因**（详见 `project.yaml::failure_analysis`）：
  - **结构问题（主因）**：本尺度 L=8 太浅，「逐层串联的信息瓶颈」这个 DenseFormer 要缓解的
    条件不成立；层间加权和自由地改动中间层表示（中间深度读出变差），最终层靠后续层重新学回
    parity。
  - **设计问题（次因、可修、非主因）**：本实现的 α **无单纯形约束**（≠ DenseFormer 严格凸
    组合语义），且无中间深度监督去约束层间混合。但干预活性成立，故 null **不能**归因于
    「干预没生效」。
  - **非 innovation 本身失败**：DenseFormer 族在更大规模有已报告增益；本项只判本尺度。

### 9.2 `2.2.4` 并行子层

- **字面（预登记判据线）**：`parallel` / `parallel-dual-ln` 相对 `sequential` 的质量代价是否
  越 0.014 带？**s0 = +0.0458 / +0.0402，s1 = +0.0422 / +0.0374，两 seed 同号且都越带
  ⇒ 代价可排序（更差）**；代价面（层内串行依赖 / 每层算力 / 参数量）齐备（§5）。
- **实质（falsification 全条件）**：本项 falsification = 「质量面有可排序代价 **且** 在等效
  代价面也拿不到可兑现的收益 ⇒ 判不划算」。第二条件**不成立**：代价面给出**真实收益**——
  层内串行链 **2 段 → 1 段**、每 token 串行步数 **16 → 8**，算力只差 **0.055%**
  （`parallel-dual-ln` 与基线**逐位等参**，差 0）。⇒ **不能**判「不划算」。
- **结论**：**以可排序的质量代价（+0.0422 / +0.0374 bpc）换层内并行度翻倍（串行 2 段 → 1 段）：
  本尺度上不是免费的，是否采纳取决于场景**（要吞吐 / 流水的人会觉得值；要质量的人不会）。
  n = 2 seed，不越尺度外推。
- **`status`**：**`已完成`**（本地实测有明确结论：代价可排序 + 代价面收益真实 + 权衡明确）。

## 10. 残余缺口（如实登记，附等效算力成本）

1. **更大规模点未跑**：2.2.3 的 milestone 要求「一个更大规模点」；本项只有 13M / L=8。
   成本随宽度与层数平方增长（层间加权和 ≈ O(L²·d)），最小可判定规模约为 4× 参数（~55M）。
2. **`dense` 的 α 无单纯形约束**：与 DenseFormer 严格凸组合语义的对照臂未做
   （成本 = 1 臂 9830 万 token）。
3. **`dense` 的「中间深度更差」是本项新观测**：与 2.2.1 残差形式 / 2.1.1 早退的耦合
   （「中间深度可读性」是它们的判据线之一）未做联合检验（组合留白，见 `SCHEMA.md` §4）。
4. **两份 s0 等值门的落盘**：本轮以 `--skip-s0-anchor` 省时，`results.json` 不含
   `s0_anchor_remeasured` 块，该门存证只有 `run_log-attempt1-crash.txt:3` 一行日志
   （要落成结构化字段需一次全跑 = 4 × 9830 万 token）。
5. **长度 / 层数外推未测**：并行子层的收益在更大层数下按层内串行链线性累加，本尺度只到 8 层。
