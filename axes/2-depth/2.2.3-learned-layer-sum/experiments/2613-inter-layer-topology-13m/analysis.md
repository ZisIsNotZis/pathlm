## 0. 人话摘要（先读这段）

**这一格在问什么。** 一个普通的、只做下一个字预测的变压器（decoder-only transformer），
层与层之间只有一条最朴素的接法：把上一层的输出直接喂给下一层，每层内部「先做注意力、
把结果加回去，再做 MLP、再加回去」。这一格问的是：**把层与层的接法换一换，质量会变好吗？**
我们试了两种换法：

1. **并行子层**：一层内部的注意力和 MLP **同时**读这一层的输入（而不是 MLP 读注意力
   写回之后的状态）。这是 PaLM / GPT-J 用的接法。
2. **层间加权和（DenseFormer 式）**：每一层的输入不再是「上一层输出」，而是对**它之前
   所有层的输出**做一次学习出来的加权相加；权重一开始只选紧邻的上一层，所以**起步与
   普通变压器逐位相同**，随后自己学怎么混。

**怎么测的。** 四个模型除了「层间接法」这一个因素**逐字段完全一样**（同宽 256、同 8 层、
同 98.3M token、同 seed=0、同数据切分），各自训练 12k 步，然后在最后 1 千万字节上测
**clean bpc**（每字符比特数，越低越好；普通变压器同尺寸同预算的参照是 **1.5254**）。

**测出来多少。**

| 接法 | clean bpc（越低越好） | 相对普通接法 | 参照系与量级 |
|---|---|---|---|
| 普通（顺序残差，基线） | **1.5254** | — | 这一档的同尺寸参照；历史同配置 run 是 1.5287（差 0.0033 = 重跑散度） |
| 层间加权和（`dense`） | **1.5246** | **−0.0008**（中性） | 差 0.0008 远小于「可排序阈值」0.014 ⇒ **说不出差别** |
| 并行子层（`parallel`） | 1.5712 | **+0.0458**（更差） | 比基线差 0.046 bpc，是判据阈值的 3.3 倍 ⇒ **明显变差** |
| 并行子层（等参数版） | 1.5656 | **+0.0402**（更差） | 与上一行差 0.0056（说不清谁好谁坏），结论相同 |

**结论。** 在这一档规模（13M、12k 步、98.3M token）上，**两种「换接法」都没有带来质量
改善**：层间加权和跟普通接法**说不出差别**（这一子项没有头寸）；并行子层**明显更差
（+0.04 bpc）**，这是**设计层面的负结果**（不是「没调好」——实现正确、干预活着、四臂
同口径）。§4 与 §8 按预定判据线把两条分开记录。反过来说，这也是有用的负面结论：
**「层间除了单条残差还有别的接法」在这档规模上不是免费的午餐**，并行接线要付出约
0.04 bpc 的代价。

**两个必须说清的边界。**
① **tf@4 ≥ 0.95 这条并列判据在本形态上不可达**：tf@4 是「用前 4 层当草稿、被全深度
接受的比例」（越低说明浅层状态越不能提前下结论），普通 stock 形态**没有给浅层加监督**
（中间深度的读出无监督），所以连历史基线也只有 **0.444**；四个臂在 0.31–0.46 之间，
没有任何一臂可能达到 0.95。**我们不改判据线**，如实报「该并列条件在本形态不可达」。
② **干预是活的**：层间加权和这边，权重确实被学起来了（第 1 层的输入被放大到 2.36×、
第 8 层对更早层的权重到 −0.17～0.09，全部 36 个权重都非零），但**质量没动**——这排除了
「因为干预没生效才没差别」的替代解释。

| 1 | **2.3615** |
| 2 | 0.2646, 0.9919 |

| 5 | −0.1586, 0.0656, 0.0345, −0.0700, 0.8539 |
| 6 | −0.2289, 0.0389, 0.0344, 0.0173, −0.0419, 0.9164 |
| 7 | −0.2706, 0.0666, 0.0933, 0.0889, 0.0421, −0.0506, 0.8589 |
| 8 | −0.1694, 0.0067, −0.0515, −0.0707, −0.0730, −0.0898, −0.0932, 0.7880 |

**一句话：干预活着，而且活得很大** —— 模型把第 1 层的输入**放大到 2.36 倍**，深层对最早
的输入（源 0）稳定地学到**负权 −0.17～−0.27**（像一次固定的去趋势/去均值），对紧邻上层的
权重被压到 0.69–0.92。它显然「想用」层间加权，却在质量上**没有任何可测量的收益**（Δ = −0.0008）。
20 步冒烟里 α 已经离开起步（`max_dev_from_identity_init = 0.0011`），也是活的。

### 3.2 `parallel` / `parallel-dual-ln`：无专属参数，用「接线改变了多少计算」当活性量

| 臂 | 参数量 Δ | 接线相对偏差 vs 同权重走顺序接线（逐层，`wiring_rel_dev_vs_seq`） | 分支增量相对幅度（逐层，attn / mlp） |
|---|---|---|---|
| `parallel` | −4096 | 0.373 / 0.016 / 0.053 / 0.110 / 0.135 / 0.116 / 0.086 / 0.065 | 0.135–36.2 / 0.058–17.5 |
| `parallel-dual-ln` | **0** | 0.366 / 0.015 / 0.053 / 0.126 / 0.134 / 0.126 / 0.104 / 0.057 | 0.123–36.4 / 0.055–17.1 |

口径：`wiring_rel_dev_vs_seq` = 把**同一套权重**（该臂训完的权重）放进一个顺序接线的
`Block` 里，同一输入下两种接线的输出相对差；非零即「接线真的在改变计算」。
（第 1 层的相对幅度偏大是因为 depth-0 输入态被 `norm_cap=1` 归一化、分母很小。）

`intervention.alive` 对无专属参数的并行臂只是结构性的布尔（“这不是基线臂”），
**真正的活性证据是上表的逐层接线偏差与分支增量**；对 dense 臂才有参数化的活性量（§3.1）。
活性块另外两个可逐位核对的布尔量：`params_identical_to_sequential`
（sequential/parallel-dual-ln = true）、`start_bitwise_equals_sequential`
（sequential/dense = true）；`params_added` 与实测参数量增量逐位一致
（单测 `test_topology_liveness_params_added_matches_param_delta`；等价重算见
`MODEL.md` §2 `rederive_liveness.py`）。

## 4. 判据线判读（预先写下，逐字未改）

| 判据（契约 E 原文） | 实测 | 触发 |
|---|---|---|
| 任一变体相对基线改善 ≥0.014 ⇒ 成功 | 最好的是 `dense` **−0.0008** | ✗ 不触发 |
| \|Δ\| < 0.014 ⇒ 中性 | `dense` −0.0008 | **✓ 触发（dense 中性）** |
| Δ ≥ +0.014 ⇒ 失败 | `parallel` +0.0458、`parallel-dual-ln` +0.0402 | **✓ 触发（并行两臂失败）** |
| 并列：tf@4 ≥ 0.95 | 0.4560 / 0.3486 / 0.3149 / 0.4538 | ✗ 四臂全不满足（**形态不可达**，见 §7.2） |
| 必须附三臂同方法 loss 斜率 | 见 §6.4（四臂同方法，末 25% 窗） | ✓ |

**裁决**：

- **主判据 = 无成功臂**（没有任何变体达到 ≥0.014 的改善）；
- **`dense`（层间学习加权和）= 中性**：Δ = −0.0008，落在方差界内 ⇒ 在 13M / 12k 步 /
  1 seed 下**与基线不可排序**（既不能说它更好，也不能说它更差）；
- **`parallel` / `parallel-dual-ln`（并行子层）= 失败（否证）**：Δ = +0.0458 / +0.0402，
  都超过阈值 3 倍以上，且与等参数位点无关（两臂差 0.0056 < 0.014，同一个结论）。

## 6. 对账（SCHEMA §12 三道 + §16 收敛）

**被支持/被报出的数字 = 四个 Δbpc 与四个参数量。**

### 6.1 算术对账

- Δ 定义一致：`bpc_arm − bpc_sequential`，同一个 `depth_curve` 的 depth-8 读数、同 20 个
  eval batch：1.5246 − 1.5254 = **−0.0008**；1.5712 − 1.5254 = **+0.0458**；
  1.5656 − 1.5254 = **+0.0402** ✓
- 参数量（逐位）：6,958,592 − 6,962,688 = **−4096** = −L·2d；6,962,688 − 6,962,688 =
  **0**；6,962,724 − 6,962,688 = **+36** = L(L+1)/2 ✓（`params_delta_exact = true`）
- 阈值与方差界：判据阈值 0.014 **就是**方差界 ⇒ 无「阈值 < 噪声」的错配；
  本轮实测同配置重跑散度 0.0033（§1）也 < 0.014 ✓
- 边界：clean bpc 下界 0；**均匀预测参考值** log₂(206) ≈ 7.69（每符号等概率时的每字符比特数）——**它是参考值，不是分布数据的理论上界**（同仓已有 1322.98 bpc 的读数）。四臂实测 1.52–1.57，均远低于该参考值。

### 6.2 任务对账

- 四臂测的是**同一件事**：同一 enwik8 char 级 AR 任务、同一数据切分（前 90M/末 10M）、
  **同一位置集**（全序列逐位置 × depth-8 读出）、同一目标定义（`tokens` 自移位，行 i 预测
  t_{i+1}）；四臂用**同一评测函数**（同 `n_batches=20`、同 eval seed、同 batch_size）。
- **无「假上下文 + 真目标」式对照**：四臂前向只依赖模型自身状态，无真值泄漏；输入分布 =
  同一训练/评测数据流。
- 部署对应：四臂都是标准 AR 前向（`logits = h·Eᵀ`），对照只改层与层之间的接法。

### 6.3 口径对账

- 四臂同为 **12000 步 / 98.3M token / seed 0 的 matched-step 快照**（非渐近、非墙钟、
  非 FLOPs）；同一 GPU、串行提交、相同 batch/lr/调度。
- 历史锚（1.5287）用**当前代码**重测逐位复现，故「税分母」口径与本次一致。
- 报「失败/中性」的数字同样按此口径；不利数字一并列出（§2）。

### 6.4 收敛对账（§16，四臂同方法）

方法：每臂 `train_log.jsonl` 的**末 25% 窗**（step 9000–11999，16 个采样点）对 loss 做
**同一最小二乘**斜率（nats / 1k 步）；窗口比例与算法四臂完全相同。

| 臂 | 窗内 loss 首 → 末 | 斜率（nats/1k 步） | 窗内后半斜率 | 窗内水平 gap vs 基线（首 → 末） |
|---|---|---|---|---|
| `sequential` | 1.0410 → 1.0392 | **+0.00251** | +0.0177 | — |
| `parallel` | 1.0746 → 1.0699 | +0.00390 | +0.0192 | +0.0336 → +0.0307（收窄 0.0029） |
| `parallel-dual-ln` | 1.0656 → 1.0647 | +0.00452 | +0.0250 | +0.0246 → +0.0255（不变） |
| `dense` | 1.0403 → 1.0401 | +0.00450 | +0.0215 | −0.0007 → +0.0009（≈0） |

**读法（含口径警告）**：四臂斜率近似相同（极差 0.0020 nats/1k 步），且都接近 0/噪声主导
（日志 loss 是**单个 batch** 的估计，不是评测集 loss）⇒ 臂间差异**主要不是收敛速度差**，
而是**水平差**：并行两臂在末窗内始终比基线高 0.025–0.034 nats，且窗口内基本不收窄
（最多 0.0029 nats ≈ 0.004 bpc）。因此「+0.046/+0.040 bpc 更差」是质量差，不是「还没追上」。

**更长训练点（2×=24k）未做**，两条理由：① 本实验**没有报任何增益**（主判据无成功臂），
§16 的「更长训练点」要求是针对**报增益**的情形；② 契约 E 写明的收敛对账就是「各臂同方法
loss 斜率」，已在上面给出；③ 契约预算 40 min 已被四臂 27 min 用掉，2× 双跑（≈26 min）
会超预算 ⇒ 若要补，属另一次授权（见 §9）。

## 7. 口径、局限与风险（如实记录）

1. **n = 1 seed**。差值 0.0008 / 0.0458 / 0.0402 中，前两个在阈值附近或阈值内，只有并行
   两臂远超阈值（3 倍以上），故「并行更差」是**可排序**结论；「dense 与基线无差别」是
   **不可排序**的「说不出差别」，不是「等价证明」。
2. **并列判据 tf@4 ≥ 0.95 在本形态不可达（如实报，不改判据）**：stock `--dense` 形态只监督
   最终深度，浅层状态无监督（`docs/design.md` 不变量 3：纯 dense trunk 没有浅层截断资产）。
   历史同配置 dense 基线实测 tf@4 = **0.444**，本实验四臂 0.31–0.46 ⇒ 该并列条件与「哪个臂」
   无关，四臂同不可达，**不作为区分量**；它要成立需要全深度并行监督（depth-ar 形态，历史
   tf@4 ≈ 0.97），那是另一个形态、不是本格的因素。
3. **§15 等参数对照的处理（自陈）**：
   - 并行族：`parallel` 参数 **−4096**（减参不是增参，容量归因本来就不成立）；且额外跑了
     **参数量逐位相同**的 `parallel-dual-ln`（Δ = 0），得到**同一个结论**（+0.0402 vs
     +0.0458，两臂差 0.0056 不可排序）⇒ 并行族的负结果**在严格等参数下依然成立**。
   - `dense` 族：**严格按字面的「去掉该结构且参数量相同」对照臂在这条干预上不存在**——
     结构本身就是那 36 个层权标量（0.00052% 的参数）。我们给的是三条替代证据：
     ① 把 α 冻结在 identity 时 dense 臂与基线**逐位等价**（单测
     `test_dense_identity_start_bitwise_equals_sequential` 钉住，训练侧佐证：第 0 步
     loss/gnorm 与基线完全相同）⇒ Δ 只能来自 α 离开 identity，而活性量显示它离开得很大；
     ② 容量量级算术：36 个标量 = 5.2e-6 相对量，而 ticket 29 里「容量驱动」的增益
     （−0.0888 bpc）伴随的是 131,072 个参数（1.9%，3640 倍）；③ 本实验**没有增益可归因**
     （Δ = −0.0008 落在方差界内），归因问题本身不成立。
4. **中间深度的 bpc/tf/ECE 在 stock 形态下是「无监督读出的副作用」**，只是形态诊断
   （如 §2 的机制假设），不作判据。
5. **`dense` 的结构性代价未用质量收益抵消**：推理/解码需要保留全部此前层输出
   （(L+1)·d = 9×256 浮点/token，比基线多 8×256），且它**破坏 RAP「skip = 恒等」不变量**的
   严格性（α 对角 0.69–0.92，早退会丢掉非对角项）。既然质量中性，**没有理由引入**。
6. **未测的探针是刻意不测**：`workspace_probe` / `generation_quality` 依赖顺序接线的
   `_gated_step` 与 `DepthARDecoder` 语义，在并行/dense 拓扑下**未定义**（已在
   `pathlm/depth_ar.py::_gated_step` 加显式守卫）。缺这两项不是遗漏。
7. **性能数字口径**：训练步时/显存来自共享卡实测（`seconds_per_step`、`peak_child_mem_gb`），
   只作量级参考（共享卡被其他任务占用，绝对值会浮动）。

## 8. 失败决策树（契约 §8）触发情况

| 症状 | 契约处置 | 本轮实际情况 |
|---|---|---|
| 当前代码不能复现历史 1.5287 / 单测红 | 先修实现 | **未触发**：历史锚逐位复现（1.5287/0.6894），单测 159 全绿 |
| 干预死（α 停在 identity） | 不判机制 | **未触发**：α 明显离开 identity（§3） |
| 参数量账不符 | 修到逐位相同 | **未触发**：Δ = 0 / −4096 / +36 逐位符合（`params_delta_exact`） |
| 变体更差 ≥ +0.014 | 记为否证 + 写清生效条件 | **触发（并行族）**：见下 |
| 全部变体 \|Δ\| < 0.014 | 无头寸，换尺度/判据 | **部分触发（dense）**：见下 |
| 结果不可重复 | 补 seed | 未触发（同配置重跑散度 0.0033，量级小） |

**并行族的否证与生效条件（按 §14 决策树「收益为负、实现正确 ⇒ 设计在该设定下无效」）**：
在 13M / 8 层 / 12k 步 / 无浅层监督的 stock 形态上，把层内两子层改成**同读块输入**会付出
+0.04 bpc；它要有可能划算，需要满足至少一条：(i) 有浅层全深度监督（让中间状态也被目标
塑形，因为并行接线最受损的正是中间深度：depth 1–3 差 0.4–1.5 bpc）；(ii) 更深的堆叠
（顺序工作量被摊薄的问题随层数下降）；(iii) 训练更长（末窗 0.0029 nats 的收窄方向是正的，
但远不足以填平 0.03 nats 的水平差）。**本实验不声称它一定无效**，只声称「在上述设定下无效」。

**dense 的中性与下一步（按「机制在此规模无头寸」）**：层间加权和**被学起来了但换不来质量**。
下一步应先做**判据/尺度**的改变（换监督形态或换更长的训练），**不叠加第二个机制**。

**回归**：`python3 -m pytest tests/ -q` = **159 passed**（基线 150 + 本实验新增 9 条单测）。
变异验证三处全部抓红（§5）。

## 9. 下一步（最小实验，不叠加第二机制）

1. **机制假设的直接检验（≈13 min）**：给四臂加**全深度并行监督**（`--dense-aux`，每个深度
   都有 CE，即 depth-ar 的形态）后重比并行接线。若并行接线的劣化主要来自「中间深度没被
   塑形」，加监督后 Δ 应显著收窄；若不收窄，则「并行接线本身损失顺序计算量」成立。
2. **尺度/判据**：dense 拓扑在 12k 步中性、无增益 ⇒ 换判据（例如 24k 快照）+ 换尺度
   （29M）再判一次，仍按单因素（**不叠加**）。
3. **真正的 DenseFormer 语义**：当前 α 无约束（layer 1 放大到 2.36×）。把每层 α 约束在
   **单纯形**上（非负、和为 1 = 对历史层的凸组合）才是原论文语义，也是对「层间加权和」更
   干净的实现；这条与第 2 条互斥，先做哪条由主 Agent 定。
4. **若要接进 RAP**：`dense` 破坏「skip = 恒等」，需要先把早退的等价性（非对角项的处置）
   定义清楚，再谈它在本项目里的用法；在此之前**不建议采纳**。
5. **catalog / 课题页**：本格首次探索的结论（并行接线失败、层间加权和中性、tf@4 并列判据
   在 stock 形态不可达）需由**主 Agent** 写入 `catalog.yaml` 与
   `archive/wiki-legacy/axes/C-vertical/C3-inter-layer-topology/README.md`（本执行者不碰这些文件）。
