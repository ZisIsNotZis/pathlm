# 2692 · 循环深度四臂的 seed 1 复本 · 判读（analysis）

## 0 人话摘要

**换一个训练随机种子，`2691` 的两条可排序结论都同向、同量级地复现了。**

- **问一（同算力）**：循环臂比 12 层稠密差 **−0.038268**（配对逐窗口 Δ、SE 0.002318、
  两半 −0.036973 / −0.039564，越 0.014 带 **2.73 倍**）；seed 0 是 **−0.040033**（2.86 倍）
  ⇒ 两 seed 同号、量级差 0.0018 bpc。
- **问二（同参数）**：循环臂比 6 层稠密好 **+0.024240**（SE 0.002369、两半 +0.025842 / +0.022639，
  越带 **1.73 倍**）；seed 0 是 **+0.021021**（1.50 倍）⇒ 两 seed 同号、量级差 0.0032 bpc。
- **诊断（同参数同算力）**：「只重复后半段」对「整栈重复一遍」是 **−0.002174（带内、
  两半 −0.003641 / −0.000708）**；seed 0 是 **+0.001023（带内）** ⇒ **两个 seed 都不可排序、
  而且符号相反**：没有可排序的「重复层位」效应；两 seed 一致地不给「重复层位」记亏损，但不区分
  「6 组容量不足」与「重复更难优化」。

按预登记 P3（`README.md` §4）：两条主判 Δ **两 seed 都越带且同号** ⇒ 从 n=1 抬到 n=2；
诊断 Δ 两 seed 都不越带且符号相反 ⇒ **不得**写成「后半段重复更好」或「更差」，只能写「不可排序」。

## 1 六问（与 `2691` 同一设计，只换种子）

1. **它是干什么的**：同 `2691`——同一组层参数重复前向若干遍，用算力换参数。
2. **相对普通 decoder-only 改了什么**：同 `2691`——6 组参数按调度表跑 12 次（`repeat2x`），
   参数不变、每 token 层传递翻倍。
3. **为什么要改**：不是新问题，而是**复本**：`2691` 的两条越带结论都只有 1 个训练种子，
   按 `harness/methodology.md` §2（n=1 的正结论默认不可采信）需要换种子复现。
4. **怎么测的**：与 `2691` 逐字段相同的四臂（`dense6` / `dense12` / `repeat2x` /
   `repeat2x-tail`）、同 token 预算（98.3M）、同评测入口（20 窗口、`EVAL_SEED=2`）、
   同判据线；**唯一变量 = 训练种子 1**。
5. **测出来多少**：`dense6` **1.559499** → `repeat2x` **1.535259**（同参数，好 **+0.024240**）
   → `dense12` **1.496991**（同算力，比循环臂**低 0.038268**）。
6. **结论与下一步**：两条主判在两 seed 上同向且都越带 ⇒ 可在 n=2 上说「可排序」；
   诊断腿两 seed 都带内、符号相反 ⇒ 重复层位无效应的结论也复现。残余仍是步嵌入与
   第二个重复次数点（`project.yaml::gaps`）。

## 4 口径与边界

- matched-step（12k 步 / 98.3M token）、T=256、enwik8、seed 1 一点；与 `2691` 合成 **n=2** 的
  方向与量级判决。不外推到更大规模、更长 T、更多重复次数。
- 判据符号：`Δ(候选 vs 对照) = bpc_对照 − bpc_候选`（正 = 候选更好）；0.014 带只用于配对逐窗口 Δ。
- **墙钟不进判据**；四臂墙钟 5.78 / 7.58 / 7.56 / 7.08 min 只作过程量。

## 5 复本对判词的影响

- `2691` 的两条越带 Δ 从 **n=1** 抬到 **n=2**：方向、符号、量级区间都稳定
  （问一 [−0.040033, −0.038268]、问二 [+0.021021, +0.024240]）。
- 「多花一倍算力的重复只买到换新层收益的 **34.4%（seed 0）/ 38.8%（seed 1）**、
  两 seed 均值 **36.6%**」这条读法在第二个种子上成立（推断：两个两点之比，不是多点拟合）。
- 诊断腿的**方向**不可复现、**量级**都在带内 ⇒ 判词保持「重复层位无可排序效应」，
  不改 `2691` 的归因。

## 6 定序披露与已知缺陷

- 契约在训练前绑定（`prereg_binding.json`，`bound_at` 早于全部读数）；本实验无重绑。
- 已知缺陷（与 `2691` 同一个、不影响判据）：`results.json::arms.<臂>.shared_train.gnorm_skipped_steps`
  读错训练器键名（真名 `grad_skips`）⇒ 恒为 null，真值在 `runs/<臂>-12k-s1/results.json::gnorm_monitor`。
- **自测不是独立验收**：单测、冒烟、P0 重评都是 writer 自测；fresh 独立复核未派。
