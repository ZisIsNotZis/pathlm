# W3-kv-head-sharing · KV 头共享

> 轴：**W 宽度** ｜ 状态：**✅ judged**

> **判读**：参考线已补齐**：GQA（KV −75%）实测 damage **+0.0143**、同 seed 重跑 +0.0139（**跨在门槛两侧**，散度仅 0.0004 ⇒ 依预登记规则该臂判读作废、**不写入「近无损」参照线**）；MQA（−87.5%）为 +0.0118（形式进门槛，但与 GQA 只差 0.0025 ≪ 0.014 ⇒ **不可相互排序**）。同 −75% 档位下 **GQA 比 int4 KV 便宜 ≈3.2×**。

## 1. 命题

用更少的 KV 头降低推理内存/带宽。

## 2. 选项枚举（本格全部可能取值）

1. `MHA（本项目）`
2. `MQA（1 个 KV 头）`
3. `GQA（G 个 KV 头）`
4. `MLA（低秩压缩 KV）`

## 3. 状态（我们做了什么 / 行业做了什么）

**本地已测**：解析 KV 内存 12288 → **3072 B/位置（−75.00%）** / **1536 B（−87.50%）**（与预登记数值逐位一致）；参照线对照：int8 −50%/+0.00015（近无损）、int4 −75%/+0.0457 ⇒ **同 −75% 档 GQA 便宜 ≈3.2×**

**行业口径**：KV 内存降数倍、质量近无损，GQA/MQA/MLA 已被全行业采纳。

## 4. 结论与数字

- **税**：clean bpc：mha **1.4820** / gqa **1.4963**（damage +0.0143）/ gqa 重跑 1.4959（+0.0139）/ mqa **1.4938**（+0.0118）
- **收益**：解析 KV 内存 12288 → **3072 B/位置（−75.00%）** / **1536 B（−87.50%）**（与预登记数值逐位一致）；参照线对照：int8 −50%/+0.00015（近无损）、int4 −75%/+0.0457 ⇒ **同 −75% 档 GQA 便宜 ≈3.2×**
- **判读**：参考线已补齐**：GQA（KV −75%）实测 damage **+0.0143**、同 seed 重跑 +0.0139（**跨在门槛两侧**，散度仅 0.0004 ⇒ 依预登记规则该臂判读作废、**不写入「近无损」参照线**）；MQA（−87.5%）为 +0.0118（形式进门槛，但与 GQA 只差 0.0025 ≪ 0.014 ⇒ **不可相互排序**）。同 −75% 档位下 **GQA 比 int4 KV 便宜 ≈3.2×**。

## 5. 失败路径与原因

1. **GQA 跨门槛、判定分裂**：+0.0143 与重跑 +0.0139 分居 0.014 两侧 ⇒ 按预登记规则该臂判读作废，**不写入近无损参照线**（机器可读 verdict 曾与规则相反，已由主 Agent 修正）
2. MQA 与 GQA 差异 0.0025 ≪ 0.014 ⇒ 不可相互排序
3. 缺等参数对照臂（代价混着 −8.75%/−10.25% 容量差）；无 2× 训练点；n=1 种子；长上下文吞吐未测

## 6. 判据与判决实验设计

- **判据**：质量（bpc）+ KV 内存 + 长上下文吞吐
