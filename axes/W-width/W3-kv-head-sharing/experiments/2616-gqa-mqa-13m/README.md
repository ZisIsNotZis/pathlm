## 1. 动机（**逐字**抄录契约「背景」段）

> 背景：我们已有「KV 量化」的价签（int8 近无损、省一半内存）。工业界另一条同分叉路线是减少 KV 头数（GQA/MQA）。地图上 W3 是空白；补上它，「省 KV 内存」的参照线才完整。

## 2. 命题（摘要，由契约 §1 动机改写）

**把注意力的 K/V 头数从 8 减到 2（GQA）或 1（MQA），KV cache 的内存按同一比例下降
（−75% / −87.5%），质量代价是多少？** 这是「省 KV 内存」参照线的第二条腿：与
`R1`（int8 KV：近无损、−50%）并列，所有后续「省内存」主张必须打败这两条现成路线。

## 3. 干预与单因素声明

**唯一变量 = KV 头数**。契约原文（**逐字**）：

> 干预（唯一变量 = KV 头数）：`mha`（基线，8 个 KV 头）vs `gqa`（2 个 KV 头）vs `mqa`（1 个 KV 头）。其余逐字段一致（`--dense`、seed=0、12k 步）。

其余字段（摘要）：`d=256 / layers=12 / heads=8 / seq=256 / mlp_mult=6 / dense`、
seed 0、12k 步、bs32、lr 1e-3、AdamW+余弦（warmup 200 步）、exit_mode=uniform、
fill_kv 开、topology=sequential、无读出干预、无稀疏/线性/窗口开关、数据切分前 90M 训练。
**评分头数（query 头数）恒 8、头维度恒 32**：GQA/MQA 只减 K/V 的**头数**（不是头维度）。

**实现**（摘要）：`GQABlock` 把 qkv 投影的输出宽度从 `3d` 改成 `d + 2·n_kv_heads·dh`
（GQA：384；MQA：320 行），K/V 以 `[B, n_kv_heads, T, dh]` 进
`scaled_dot_product_attention(..., enable_gqa=True)`（内核按组广播，**不物化**复制到 8 个头）。
`n_kv_heads` 缺省 `None`（= `n_heads`）时**完全不创建**该类，仍走 stock `Block`
⇒ 缺省路径逐位还原 v1（单测 `test_kv_heads_default_off_matches_v1_bitwise`）。

**剪枝类混杂声明（摘要）**：这是**减参数**的干预（不是等参数）：K/V 投影半边变窄 ⇒
总参数 −1,184,256（GQA，8.7%）/ −1,381,632（MQA，10.2%）。按 SCHEMA §15 的例外条款，
它属于「剪枝/减参」方向；本实验按契约只跑三档头数，**不含等参数对照臂** ⇒
臂间差异里混着「头共享」与「容量减少」两项，判读时必须带上这句话（见 `analysis.md`）。

## 4. 判据线（**逐字**抄录契约「判据」，未改一字）

> - **判据（预登记）**：给出三臂 clean bpc 与**解析** KV 内存下降（GQA −75%、MQA −87.5%）；
>   若 |Δbpc| < 0.014 ⇒ 记「近无损」并写入参照线（与 int8 KV 的近无损 −50% 对照）；
>   若越界 ⇒ 记其代价。必须附三臂同方法斜率与重跑散度。活性证据必须是**实际 KV 张量形状**。

**执行前的操作性定义（不改判据，只把符号与口径落定；全部在训练开跑前写定）**：

1. **符号**（SCHEMA §17.3）：`Δ_schema = bpc_对照 − bpc_实验`（正 = 实验臂更好）；
   `damage = −Δ_schema`。本实验「对照」= `mha` 臂（自训，同为 12k 步快照）。
2. **「解析 KV 内存」**：按**实际张量形状**算 `n_layers · 2 · n_kv_heads · head_dim`
   个元素/位置，fp16 时 ×2 字节。MHA = 12288 B/位置（与 `R1` 的 int8 参照线同一口径、
   同一模型规格），GQA = 3072 B（−75%）、MQA = 1536 B（−87.5%）。评测期**实测显存**
   另报，且不主张按比例下降（见 §7 口径）。
3. **「近无损」**：`|Δ_schema| < 0.014`（= 方差界，methodology §2）。越界且方向为**变差**
   ⇒ 记代价；越界且方向为**改善** ⇒ 按 SCHEMA §16 只记「快照、疑为收敛加速」，**不算**
   收益（需要等参数对照 + 更长训练点，本实验预算不含）。
4. **重跑臂选择规则**（预登记）：重跑 `gqa`（三个干预档的中间档）。判定规则：
   `|Δ_schema|` 是否 < 0.014 这一点在 gqa 与 gqa_rep 上必须一致，否则该臂判读作废。
5. **预算不够时砍什么**（SCHEMA §8/§17.7）：砍重跑臂 → 砍评测批数，**不砍判据线**。

## 5. 对照与方差

- **对照 = `mha` 臂**（同一 runner、同一配方、同 seed、同 12k 步、同一评测电池；
  `n_kv_heads=None` ⇒ 走 stock `Block`，与 v1 逐位一致，单测钉住）。**自训**，不复用历史
  checkpoint ⇒ 不涉及 SCHEMA §9 的跨 run 复用混杂。历史 `2610` 主干（13,536,768 参数、
  clean bpc 1.4836）作为**交叉核对锚**另行列出（同规格、同评测窗口序），不作为判据。
- **方差界**：Δ < 0.014 不可排序（methodology §2）。本实验另给**重跑散度**（gqa 重训一次）
  与**评测侧第二条独立路径**（`retention.masked_bpc` == `depth_curve`，4 位小数逐位相同）。
- **种子**：训练 seed = 0（四臂一致）；评测窗口 seed = 2 + 24×16（与 2610/2614/2615/2616-Q
  同一数据流与位置集）；n_seed = 1 + 1 重跑（非 2 个独立种子；重跑是**同 seed**，
  量的是 run-to-run 数值不确定性）。

## 7. 口径标注（摘要）

- **bpc**：clean bpc（每字符比特数，越低越好）= 最终深度读出的因果移位 CE token 平均；
  matched-step **快照口径**（12k 步、98.3M tokens、未收敛）；非渐近、非墙钟、非 FLOPs。
- **内存**：**解析** KV cache 字节数（部署关心的量，按实际张量形状算）与**实测**显存
  （`torch.cuda` 峰值 + 子进程采样）**分开报**。评测实装把 K/V 交给 SDPA 内核按组广播、
  分数矩阵仍是 `T×T`，且峰值由激活主导 ⇒ **实测峰值不按 KV 比例下降**，本实验不主张实测
  显存收益。
- **参数量**：四臂参数量差 = 剪枝公式 `−2·(d − n_kv_heads·dh)·(d+1)·n_layers`（含 qkv
  偏置半边差），三方对账见 `results.json::reconciliation::arithmetic`。
- **§16 收敛对账**：四臂同一窗口（末 25% = 步 9000..11999）、同一最小二乘算法；4× 更长
  训练点（48k）**未跑**（契约预算 = 3 臂 + 1 重跑，不含 2× 点）⇒ 任何「改善」读数只能记
  快照；本实验的主结论是**代价/近无损**与**解析内存**，不依赖收敛性。

## 8. 成本（唯一数字 = 契约「成本」行）

- 契约写的预算（**逐字**）：`成本：3 臂 × ≈7 min + 重跑 1 臂 ≈7 min ⇒ ≈35 min`。
- **实测步时**（本实验 200 步探针，SCHEMA §17.8）：mha/gqa **45.2 ms/step**、
  mqa **42.2 ms/step**（共享卡同期他人占用 ≈6.9 GB）；净峰值显存 2.1–2.2 GB
  （≤5 GB 净预算内）。20 步冒烟那次的墙钟被进程启动主导，**不作外推依据**（§17.5）。
- 全跑（4 臂 × 12k 步 + 每臂评测电池）实测墙钟见 `analysis.md §实测成本` 与
  `results.json::cost`。
- 可中断性：`run.py --train` 逐臂串行、已存在 `model.pt` 的臂自动跳过。
- 冒烟计划：`smoke.py`（三臂 × 20 步冒烟 + 三臂 × 200 步步时/显存探针）。

## 9. 结果（判据线未改；详细数据见 `analysis.md` / `results.json`）

| 臂 | clean bpc | Δ_schema | damage | \|Δ\| < 0.014 | 解析 KV 字节/位置 | 参数量 |
|---|---|---|---|---|---|---|
| mha（基线，8 KV 头） | 1.4820 | — | — | — | 12288（—） | 13,536,768 |
| gqa（2 KV 头） | 1.4963 | −0.0143 | **+0.0143** | **否（≥0.014）** | 3072（−75.00%） | 12,352,512 |
| gqa_rep（同 seed 重跑） | 1.4959 | −0.0139 | +0.0139 | 是 | 3072（−75.00%） | 12,352,512 |
| mqa（1 KV 头） | 1.4938 | −0.0118 | **+0.0118** | **是（近无损）** | 1536（−87.50%） | 12,155,136 |

- **GQA 的两次重跑跨在 0.014 门槛两侧**（+0.0143 / +0.0139，散度 0.0004）⇒ 保守读法：
  「≈+0.014 bpc、贴方差界、不足以判定近无损」，**不写进「近无损」参照线**；
  MQA 形式上进门槛（+0.0118），但两者只差 0.0025 ≪ 0.014 ⇒ **不得相互排序**。
- 参照线对照（同规格同口径）：int8 KV −50% 内存 / +0.00015 bpc（近无损）；
  int4 KV −75% 内存 / +0.0457 bpc ⇒ **同 −75% 档位 GQA 比 int4 便宜约 3.2 倍**。
- 活性证据（实际张量形状）：K `/` V = `[8, 2, 256, 32]`（GQA）/ `[8, 1, 256, 32]`（MQA），
  query 恒 `[8, 8, 256, 32]`；`qkv` 权重宽度 768 → 384 / 320；每 200 步活性量 61 行。
- 同方法斜率（末 25% 窗）：+1.492e−06（mha）/ +9.000e−07（gqa）/ +1.025e−06（mqa）
  nats/step ⇒ 四臂都已进平台（快照口径，无 24k 点）。
- 实测成本：训练 **35.52 min**（四臂 8.44 / 9.02 / 9.06 / 9.00）+ 评测电池 **6.73 s**
  = **35.63 min**（契约预算 35 min）；判据与预算都没砍。

## 10. 失败决策树（摘要，methodology §14）

| 症状 | 诊断 | 处置 |
|---|---|---|
| 三臂 bpc 差 < 0.014 且 KV 下降比 ≠ −75%/−87.5% | **测量/实现 bug** | 先跑 `mutate.py` 变异验证 + 单测；张量形状断言不允许「只改标签」 |
| 形状对了但重跑散度 ≥ 0.005 | **方差** | 加大评测批数（不砍判据线）；必要时给区间而非点值 |
| GQA/MQA 显著变差（damage ≥ 0.014） | 设计在该设定下无效 | 记为代价；写清「在什么条件下（更大模型/更多步/GQA 头数更多）才可能回本」 |
| GQA/MQA 显著**变好**（Δ ≥ +0.014） | 快照/收敛加速 + 容量混杂 | 按 §16 只记快照；不给归因结论（需等参数对照） |
| 解析内存下降但实测不降 | **口径**（不是失败） | 双报，两套口径都写清 |
