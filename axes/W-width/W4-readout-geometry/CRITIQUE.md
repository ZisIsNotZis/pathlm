## ① 它是什么（我的理解）
本格问「状态 → token 概率」这一步的几何能不能解耦：用 gated / 线性残差 / 逐深度 / 更宽的重参数化替代 tied 线性读出，能换回多少质量与多少 workspace 自由度，会不会破坏 prob0 校准、软提交与传输语义。

## ② 对着什么 sota / 我们偏离在哪
- **sota**（本仓 PRIOR_ART §W4，`记忆·未核`）：Press & Wolf 2017 / Inan 2017（权重绑定省参数、小模型近中性）；GLU/SwiGLU（Shazeer 2020）作为通用重参数化。
