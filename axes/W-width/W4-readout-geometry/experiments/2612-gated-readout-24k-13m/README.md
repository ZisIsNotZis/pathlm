# 2612 · gated 读出 24k 收敛复测（两臂）· 13M · depth-ar

## 0. 本契约来源（ticket 29 契约 C，逐字抄录）

> ## 契约 C：gated 读出 24k 收敛复测（两臂）
>
> - 目录：`axes/W-width/W4-readout-geometry/experiments/2612-gated-readout-24k-13m/`
> - 文件所有权：只写本实验目录（复用既有代码，不加新开关）。
> - **干预**：把 2610 的 A 臂（tied 线性）与主臂（gated）都跑到 **24k 步**（其余配置逐字段一致）。
> - **判据（预登记）**：
>   - Δbpc(24k) ≤ −0.05 ⇒ 增益在更长训练下保持（成功）；
>   - |Δ| ≤ 0.014 ⇒ 12k 的增益是欠拟合伪影（撤回）；
>   - 中间情况如实报，并附**收敛证据**：两臂末 1000 步 loss 斜率（用同一方法计算并列出）。
> - **成本**：两臂 ≈50 min。交付：契约 README / `run.py` / `results.json` / `analysis.md` / 两臂日志。

**背景（契约原文）**：12k 步时两臂都未收敛（主臂末 25% loss 斜率 −0.0298/1k，
A 臂 −0.0054/1k），所以 2610 的 Δ 只是快照口径。

> 说明（执行者核对，见 `results.json::reconciliation::background_slope_audit`）：
> 背景里这两个斜率的**窗口不一致**——−0.0054 是 A 臂**末 25% 窗（9000–12000）**
> 的斜率，而 −0.0298 是 gated 臂**末 50% 窗（6000–12000）**的斜率（末 25% 窗同法
> 只有 −0.0039）。故该「主臂下降快 5.5×」的比较不成立；本实验用**同一方法**
> （末 1000 步）重算两臂斜率。**判据线不受影响、未修改。**

## 1. 命题

把 gated 残差读出的 12k 快照增益（2610 测得 Δbpc = −0.0812）放到 **同一配方、
同一 seed 的 24k 步**上：若增益保持（Δbpc(24k) ≤ −0.05），则 2610 的结论在
「更长训练」这一维上成立；若 Δ 收缩到方差界内（|Δ| ≤ 0.014），则 12k 增益是
**欠拟合伪影**，应撤回。

## 2. 单因素声明

**唯一变量 = 读出几何**：`train_depth_ar.py` 的 `--readout-gated` 开 / 关。

- **A 臂**（基底，契约 2610 的 A 臂）：tied 线性读出 `logits = h·Eᵀ`
  （`readout_gated=False`，逐位还原 v1）；
- **gated 臂**（2610 主臂）：读出前非线性状态变换
  `h' = h + SiLU(W1 h) ⊙ (W2 h)`，再走 tied 线性读出；init
  `W1 ~ N(0, 0.02), W2 = 0`（严格恒等起步、非鞍点）；新增参数 2·d² = 131,072。

其余全部逐字段一致：同 seed（0）、同步数（24k，含 24k cosine LR 调度）、同 batch
（32）、同 lr（1e-3）、同数据切分、同 `--exit-mode uniform` + `fill_kv` + carry 门、
同评测电池（同 `n_batches`/种子/批大小）。两臂都在本脚本内**全新训练**（不是从
2610 的 12k checkpoint 续训——历史 run 不含 optimizer state；两臂同为 fresh-24k
才能保证逐字段一致，SCHEMA §9「宁自包含双跑」）。逐字段对照表见 `analysis.md` §1。

基底 = RAP 共享底座（三条必要偏离，见 `docs/design.md` §2），不引入第二个非标准
因素。**非必要性例外**：无。

## 4. 判据线（预先写下，不得修改）

- **成功**：Δbpc(24k) ≤ −0.05 ⇒ 增益在更长训练下保持；
- **撤回**：|Δbpc(24k)| ≤ 0.014 ⇒ 12k 的增益是欠拟合伪影；
- **中间情况**：−0.05 < Δbpc(24k) < −0.014（弱正向）或 Δbpc(24k) > +0.014
  （反转）⇒ 如实报，不裁决；
- **收敛证据（强制）**：两臂末 1000 步 loss 斜率（同一方法：训练日志每 200 步
  一落，取末 6 个采样点做最小二乘线性拟合，斜率 ×1000 = 每 1000 步的 loss 变化），
  并另报末 25% / 末 50% 窗与末深度 CE 斜率作交叉核对。

## 5. 对照与方差

- **对照臂 = A 臂（tied 线性）**，与主臂同配方同 seed 同 24k（自包含双跑）；
- 12k 快照口径的参照数字（Δ = −0.0812）来自 2610/2611 同代码重测，仅作「12k→24k
  的变化量」参照，不作为本实验的对照；
- **seed 数**：n = 1（seed 0）。若 |Δ| 落在判据线 ±0.02 内，补第 2 个 seed 的说明
  写入 `analysis.md`（本实验预算内不补跑，除非判据悬而未决）。
- 方差界：Δ < 0.014 不可排序（`docs/methodology.md` §2）。

## 8. 失败决策树

| 症状 | 诊断顺序 | 处置 |
|---|---|---|
| Δ 收缩到方差界内 | ① 12k 是欠拟合伪影 | 撤回 2610 的结论，交由主 Agent 同步 `catalog.yaml` |
| Δ 保持但更小 | ② 部分保持 | 如实报中间情况 + 两臂斜率；说明仍属快照口径、不外推渐近 |
| Δ 反转（> +0.014）且实现可疑 | ③ 实现 bug | 先跑冒烟 + 复用单测（关闭开关逐位还原）；bug 未排除不判机制 |
| Δ 反转、实现正确 | ④ 设计在该步数下无效 | 否证并写清「在什么条件下才会有头寸」 |
| 两臂斜率仍显著为负 | ⑤ 仍未收敛 | 明示「24k 仍非收敛点」，Δ 仍只是快照口径，不外推 |
| 结果不可重复 | ⑥ 方差 | 补 seed；仍不可排序则撤回 |
