# 2612 · gated 读出 24k 收敛复测（两臂）· 13M · depth-ar —— 判读

> 契约：`README.md`（判据线逐字抄录、预先写下、未改）。入口：`run.py`。
> 原始结果：`results.json`。两臂训练日志：`train_log_{A,gated}-24k-s0.jsonl`。
> GPU 墙钟合计 **44.61 min**（A 臂训练 21.03 + gated 臂训练 22.70 + 两臂评测 0.85）；
> **峰值子进程显存 2.14GB（净）**。seed = 0，n = 1。

## 0. 人话摘要

这个实验要回答一个很朴素的问题：**在 12k 步时看到的「给读出加一个非线性小变换能降低
bpc」这个好处，多训一倍步数后还在不在？** 我们在完全相同的配方、相同的随机种子下，
把「普通 tied 线性读出」和「在读出前加非线性状态变换」两条路都从头训到 24k 步，然后
比较两者的最终 bpc。

结果：**好处缩小了，但没消失。** 12k 步时两者相差 **0.0812 bpc**（非线性臂更好），
到 24k 步缩到 **0.0463 bpc**——只剩原来的 57%。按预登记判据，「保持」的门槛是差距
≥ 0.05，我们差 0.0037 没过线；「撤回」的门槛是差距 ≤ 0.014，我们远没到。所以这是一个
**如实报的中间结果：弱正向，不裁决**——不能宣布成功，也不能宣布撤回。

为什么会缩小？因为**基线臂在 12k 时欠拟合更严重**：基线从 12k 到 24k 降了 0.1644 bpc，
非线性臂只降了 0.1295 bpc——多出来的训练时间，基线吃得更多。换句话说，2610 那个 12k
的差距里，**至少有一部分是「基线还没训够」造成的**，但不是全部：24k 后差距仍有 0.0463，
是噪声界（0.014）的 3.3 倍。

还有两条必须一起看的证据：① 24k 时两臂**都还在缓慢下降**（末 25% 的 loss 斜率都约
−0.011/1000 步），所以 24k **仍不是收敛点**，这个 Δ 仍只是快照口径；② 平行线 2611
（契约 B）已经测出：一个**纯线性**的等参数对照臂拿到 Δ = −0.0888，和 gated 的 −0.0812
几乎一样——所以就算这 0.046 稳住了，最可能的解释也是「**多加了 2·d² 参数的副作用**」，
而不是「非线性本身有用」。

## 4. 判据线判读（预先写下，未改）+ 收敛证据

**判据线**（`README.md` §4 逐字抄自 ticket 29 契约 C）：

| 判据（预先写下） | 实测 | 判定 |
|---|---|---|
| Δbpc(24k) ≤ −0.05 ⇒ 增益保持（成功） | **Δ = −0.0463**（差 0.0037） | ✗ 未达 |
| \|Δ\| ≤ 0.014 ⇒ 12k 增益是欠拟合伪影（撤回） | \|Δ\| = 0.0463（3.3× 界） | ✗ 未达 |
| 中间情况如实报 + 附末 1000 步斜率 | 落 **−0.05 < Δ < −0.014** 中间带 | **如实报，不裁决** |

**收敛证据（契约强制；两臂同一方法）**——方法：训练日志每 200 步一落，取
`[steps−1000, steps]` 区间内的 6 个采样点做最小二乘线性拟合，斜率 ×1000 =
每 1000 步的 loss 变化：

| 臂 | 末 1000 步 loss 斜率（/1k） | 末 25% 窗（/1k） | 末 50% 窗（/1k） | 末 1000 步末深度 CE 斜率（/1k） | 末 25% 窗末深度 CE（/1k） |
|---|---|---|---|---|---|
| A 臂 | **+0.0777** | −0.0110 | −0.0109 | +0.1522 | −0.0069 |
| gated 臂 | **+0.0589** | −0.0111 | −0.0094 | +0.1188 | −0.0083 |

**怎么读这张表**：末 1000 步的斜率是**正的**（loss 在最后一个 1000 步窗反而微升），
这不是发散——它被单 batch 的「随机退出混合 loss」逐点噪声（~±0.05）主导，6 个点拟出
的斜率不可当作趋势。更稳的窗口（末 25% / 末 50%）两臂都为**小负值 ≈ −0.011/1k**，
即**两臂都还在缓慢下降、速度几乎相同**。

收敛判定：**24k 仍不是收敛点**。佐证：① 末 25% 斜率仍为负（≈ −0.011/1k）；
② 训练 loss 的 12k 窗 → 24k 窗均值两臂都降了 ~0.10；③ eval clean bpc 12k → 24k
两臂仍大幅下降（A −0.1644、gated −0.1295）。因此 **Δbpc(24k) = −0.0463 仍是快照口径，
不外推渐近**。

**契约背景数字的口径审计**（执行者核对，见
`results.json::reconciliation::background_slope_audit`）：契约背景写「主臂末 25% loss
斜率 −0.0298/1k、A 臂 −0.0054/1k」。复核发现**两条腿的窗口不一致**：
−0.0054 确是 A 臂**末 25% 窗（9000–12000）**的斜率；−0.0298 却是 gated 臂
在**末 50% 窗（6000–12000）**的斜率（gated 末 25% 窗同法只有 **−0.0039**）。
所以背景里「主臂下降快 5.5×」的比较**不成立**。本实验用同一方法（末 1000 步 +
末 25% 窗）对两臂重算，结果见上表：**两臂下降速度几乎相同**。判据线本身不受影响。

## 5. 对账（SCHEMA §12 三道，`results.json::reconciliation`）

1. **算术对账**：参数量差 = 7,093,760 − 6,962,688 = **131,072 = 2·d²**（唯一新增参数，
   与读出几何声明一致）。Δbpc 定义 = bpc_gated − bpc_A = 1.6475 − 1.6938 = **−0.0463**。
   与方差界 0.014 比：\|Δ\| = 0.0463 = **3.3× 界**（可排序）；与两个判据阈值比：
   −0.0463 落在 (−0.05, −0.014) 中间带。12k 参照 Δ = −0.0812 ⇒ **Δ 从 12k 到 24k
   变化 +0.0349（缩小 43.0%）**。粗外推核对：若按两臂末 1000 步斜率差 ×12 预测，
   Δ 变化应 ≈ (0.0589 − 0.0777)×12 = −0.2256，与实测 +0.0349 **方向相反**——这正说明
   **单点斜率是噪声**（已在 §4 说明），故 Δ 变化改由更稳的窗口均值 / 12k→24k bpc
   变化解释（见下条）。
2. **任务对账**：两臂测的是**同一件事**——同一 enwik8 char 级 AR 任务、同一 eval 切分
   （末 10M）、同一位置集（全序列逐位置）、同一目标定义（tokens 自移位）、同一评测电池
   （同 `n_batches` / 种子 / 批大小）。对照臂三要素（SCHEMA §13）：**输入分布** =
   相同训练数据同一 seed 下的 minibatch 流；**预测什么** = 与主臂逐位相同的 next-token
   CE；**部署对应** = 都是 depth-AR 的标准读出路径，无额外输入、无真值泄漏。唯一差别 =
   读出前是否加非线性状态变换。
3. **口径对账**：两臂同为 **fresh 24k / 196.6M token / seed 0 / matched-step 快照**
   （非渐近、非墙钟、非 FLOPs），LR 调度同为 24k cosine。12k 参照数字（−0.0812）来自
   2610 的 12k checkpoint 在 2611 当前代码下重测，仅用来量「12k→24k 的变化」，**不作为
   本实验的对照臂**。

**对账结论：三道均过**，无需要撤回首论的数字。**12k 差距的缩小有明确算术来源**：A 臂
从 12k 到 24k 的 bpc 改进（−0.1644）大于 gated 臂（−0.1295），差 0.0349，恰等于
Δ 的缩小量（−0.0812 → −0.0463）。

## 6. 口径、局限与风险（如实记录）

1. **n = 1 seed**。Δ = 0.0463 远超方差界 0.014（3.3×），但仍是单 seed 快照。
2. **24k 仍非收敛点**（§4）：两臂末 25% loss 斜率 ≈ −0.011/1k 且 bpc 仍在降。
   Δ = −0.0463 不外推渐近/规模。
3. **两臂都是 fresh 24k**（不是从 2610 的 12k 续训）：这保证逐字段可比，但意味着
   「12k Δ = −0.0812」与「24k Δ = −0.0463」来自**两次独立训练的不同调度位置**
   （12k 是 24k 调度的中点、24k 是终点），比较的是两个快照口径的变化，不是同一条
   训练轨迹的同一时刻。
4. **平行线耦合（重要）**：契约 B（2611）已测出**纯线性等参数对照臂** Δbpc =
   **−0.0888**，与 gated 的 12k Δ = −0.0812 几乎相同（差距 0.0076 < 0.02 判据）。
   因此即便本实验的 24k Δ = −0.0463 稳住，最可能的解释仍是「**多 2·d² 参数的副作用**」，
   而非非线性本身。本实验只回答「12k 的增益在 24k 是否保持」，**不重复契约 B 的
   参数量归因**；两条线合读时须以 2611 为准。
5. **gated 臂 gnorm 尖峰**：`gnorm_monitor` max = 17.4（A 臂 6.8），但 mean = 0.796
   （A 臂 1.269）、grad_skips = 0、无 NaN、无 loss 突跳 > 0.25。属单点尖峰，未影响
   收敛与判读。
6. **税分母 1.5287** 是历史 `23d-dense-B-12k`（同引擎同 token 预算的 dense AR），
   为 12k 口径的 dense 参照；本实验两臂是 24k，24k dense 参照未测，故 §2 的
   「收回 28.0% 税」用的是 12k dense 分母（快照混口径，仅作量级参考）。
7. **latent 直通**在 gated 臂仍偏差（depth8 latent rescore 10.11 vs A 臂 1.60），
   与 2610 同向；非本契约判据项，如实记录。

## 7. 失败决策树（契约 §8）触发情况

| 症状 | 是否触发 | 处置 |
|---|---|---|
| Δ 收缩到方差界内 ⇒ 12k 是欠拟合伪影 | 否（\|Δ\|=0.0463 ≫ 0.014） | 未触发，2610 结论**不撤回** |
| Δ 部分保持（中间带） | **是** | 本报告如实报弱正向（−0.0463），不裁决 |
| Δ 反转且实现可疑 | 否 | 实现正确（冒烟 + 复用单测 + 逐字段门均过），无需变异验证 |
| 仍未收敛 | **是** | 已在 §4 明示「24k 仍非收敛点」，Δ 不外推 |
| 不可重复 | 否 | n=1，但 Δ 远超方差界 |

## 8. 下一步（最小实验，不叠加第二机制）

- **把两臂再训到 48k**（同配方同 seed），看 Δ 是继续收缩到方差界内（则 12k/24k 都是
  欠拟合伪影），还是稳在 ~0.04–0.05（则是一个真实的参数效应）。这是唯一能区分
  「欠拟合伪影」与「参数效应」的廉价实验。
- **与契约 B 合读**：既然纯线性等参数臂已拿到 −0.0888，更该问的是「**为什么多参数**
  就能降 bpc」——怀疑是读出前的额外容量提高了浅层出口质量（本实验 depth 0 的 bpc
  从 5.01 降到 3.99）。可做「只加参数不加变换」的容量对照（例如给 A 臂的 trunk 加等量
  参数）来定位这 0.046 的来源。
- **补 seed**：若要把 Δ = −0.0463 写进状态灯，至少补第 2 个 seed 确认它远超方差界。
