## 5. 实现发现：零初始是鞍点（作废臂 → 机制账）

首轮主臂按契约原文「零初始化」实现，跑满 12k 步后 **W1 = W2 = 0（fro 范数 0.0，
非零元素 0）**，gated 读出逐位恒等于 tied 线性——**干预从未被激活**，实测的
Δ = −0.0154 落在 0.014 方差带边缘，实为**同配置重跑的浮点非确定**（历史已记同 story
复现差 ~0.03），不是机制效应。

梯度分析（已实测佐证）：

```
g(h) = h + SiLU(W1 h) ⊙ (W2 h)
∂L/∂W2 ∝ SiLU(W1 h) ⊗ h   → 在 W1=0 时 = SiLU(0) ⊗ h = 0
∂L/∂W1 ∝ diag(W2 h) · SiLU'(W1 h) · (h ⊗ I) → 在 W2=0 时 = 0
```

两端梯度同时为零 ⇒ W1=W2=0 是**鞍点，永不可学**。已实测：零初始 200 步仍 |W1|=|W2|=0；
改用 **W1 ~ N(0, 0.02)、W2 = 0** 后 200 步即逃逸（|W1|=5.34、|W2|=1.33）。

**修复**（仍严格单因素、起步逐位 == 基线 A）：W1 随机小值、**W2 = 0** ⇒ 起步
`SiLU(W1h) ⊙ 0 = 0`（严格恒等起步，单测钉住），而 `∂L/∂W2 = SiLU(W1h) ⊗ h ≠ 0`
（非鞍点）。该 init 规范已写死进 `pathlm/depth_ar.py` 与契约 `README.md` §1/§2。
作废臂证据保留在 `zero-init-saddle/`。

## 6. 口径、局限与风险（如实记录）

1. **A 臂是历史同配置 checkpoint**（不是本次新训），靠 §1 的等值性门 + 电池逐位复现
   保证口径一致；代价是「实验非完全自持」——复现需 `.scratch/23-depth-ar/evidence/` 的
   权重文件。
2. **n = 1 seed**。Δ = 0.0812 远超方差界，但仍是单 seed 快照（12k 步 = 1.0 epoch 口径），
   不外推渐近/规模。
3. **workspace 探针的 null 空间按 tied 表 U 定义**。主臂改变了 E 的谱（有效读出秩
   162 → 199、null_dim 94 → 57），**两次比较的 null 空间不同**（子空间本身变了），
   null 能量 −7.2pp 只有探索性意义，不能读成「同一子空间里能量迁移」。更强的信号是
   `control_same_row_max_dlogit` 从 **4.6e-5 → 0.603**：主臂下读出不再对 U-null 扰动
   免疫，**读出可见空间与状态空间的耦合被真实打开**（functional_dirs = 456 = 全部测试
   方向）。
4. **软提交 OOD 污染未解决**（soft rescore 5.71 vs hard 0.47，≈12×，与 A 臂同向）。
   **latent 传输变差**（depth8 9.69 vs A 3.17）——非线性读出把「退出深度状态」与读出
   解耦得更开，latent 直通口径预期受影响；这不是本实验的判据项，如实记录。
5. **对照 dense 分母 1.5287** 是历史 `23d-dense-B-12k`（同引擎同 token 预算的 dense AR），
   非本次实测；税口径为 matched-step 快照。
6. 读出变换幅度很大（depth≥1 相对幅度 ~0.88），「保 tied 桥」是指**读出基仍为 E**（概率
   = 状态对 token 方向的投影），**不**是指有效读出状态的分布未变；prob0/ECE 与 tf 均未
   退化，但下游对 `h` 做线性假设的用法（如 latent 直通）需重新校准。
