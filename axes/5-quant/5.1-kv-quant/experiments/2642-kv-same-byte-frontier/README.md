## 0. 人话摘要

**这是干什么的。** 5.1 已判定：8 位 KV 量化（块标尺）近无损且省约一半内存。但那条判定是按**单一族**
（同一个 trunk 模型只改 KV 数值）读的。要回答「量化到底值不值」，必须把**不同省 KV 的机制**
（量化、头共享 GQA/MQA、窗口保留）放到**同一条「每位置部署字节」横轴**上，看谁在同样的内存下
质量更高——这正是本仓记的**未补缺口**（55-review W-08，跨家族同字节图建立在已作废的逐值标尺 int4 上）。

**本实验做什么。** ① 从落盘的 27 臂里**独立重算**每位置部署字节（值 + 标尺），与 `2632` 记录的数字
逐位对账（对不上就作废）；② 用**部署字节口径**把跨家族的点按「同字节」分组，给出每条字节水平上
各机制的两腿读数（clean bpc + 合成长程 copy 召回）；③ 把**头共享族的参数量混杂**用磁盘上 checkpoint 的
真实参数量拆开（此前只记「未拆」）；④ 把 fp8 的解析价签（质量未测）放进同一条轴。

**为什么不能靠插值。** bpc-字节前沿不是光滑单调曲线（不同机制的损伤机理不同），在两点之间插值等于
编造数据 ⇒ 只有**恰好同字节**的点才能直接比。

## 1. 命题（可证伪）

- **P1｜口径对账**：用解析式 `部署字节/位置 = 2·L·n_kv_eff·head_dim·(值字节 + 标尺字节/值)·(kept/T)`
  独立重算的 27 臂部署字节，与 `2632-kv-block-scale/results.json::deployment_caliber.per_arm[*].primary.bytes_per_position`
  **逐位相等**（`max|Δ| = 0`）。
- **P2｜两个口径不可混**：`2632-kv-block-scale/results.json::points[*].bytes_per_position` 是**仅值口径**（不含标尺），
  量化臂上它比部署口径小（int8: 6144 vs 6528）；凡跨家族比较**必须**用部署口径。
- **P3｜同字节可比的点对存在但稀疏**：在部署口径下，存在少量**跨家族、恰好同字节**的点对；这些点对
  给出不靠插值的直接比较；其余点对只能报「谁支配谁」。
- **P4｜头共享族的字节优势被参数量混杂**：GQA / MQA 的 checkpoint 参数量低于 MHA（磁盘实测），
  差额可由解析式 `L·(2·d_model+2)·(H−n_kv)·head_dim` 逐位复现 ⇒ 头共享在字节轴上的优势**部分是用更少
  参数换来的**，不是纯机制增益。
- **P5｜int8+块标尺不是 8 位方案里的字节最优**：fp8（解析 1 B/值、无标尺 = 6144 B/位置）比
  int8+块标尺（6528 B/位置）更省，且 fp8 质量本轴未测 ⇒ 只能报「解析更省、质量未知」。

## 2. 干预与单因素声明

- 本实验**不做任何前向**：没有新的干预、没有新臂、不训练、不改权重、不新增参数。
- 干预声明：本实验的**唯一改动**是把**读数口径**从「逐值标尺」（已作废，55-review W-08）与
  「仅值字节」统一到**部署字节（值 + 标尺 + staging）**，并把跨家族点分组到同一横轴。
- 因此本实验**不是**新模型实验，它的证据力上限 = 落盘读数的正确重排；**不得**当作新实测质量证据使用。

| 维度 | 指标 | 来源 |

| 运行账 | 解析字节 vs GPU 实测峰值**分列**（评测期立即反量化 ⇒ 峰值不随档下降） | `2632::memory_convention` |

## 4. 判据与门禁（逐字，运行前写入）

1. **门禁 G1**：`max|Δ部署字节| = 0`（独立重算 vs `2632` 记录）。不成立 ⇒ 本实验**作废**（字节账未被
   独立复现，任何跨家族结论无效）。
2. **门禁 G2**：进入前沿表的量化臂**全部**为块标尺口径（`scheme = block`、`G = 32`）；出现任何
   `per_value` 标尺的量化数字 ⇒ 口径混用，本实验作废（55-review W-08 / R8）。
3. **必须报**：每个点的 `(部署字节, bpc, copy 召回, 参数量, 族)` 五元组；同字节分组；
   被支配点清单；fp8 解析点（标 `quality_measured: false`）。
4. **必须不变**：非量化臂的 bpc 与召回与 `2632` 记录**逐位相同**（本实验不改数值）。
5. **不得**：在两点之间插值造点；把 `staging` 混进主横轴；把「仅值口径」当部署口径；用头共享族的
   字节优势下结论而不带参数量列。

## 5. 否证条件

- G1 或 G2 不成立 ⇒ 本实验作废（不是「结论反转」，是口径未被复现）。
- 若同字节分组为空（P3 假）⇒ 跨家族「同字节比较」在本网格上**不可做**，须补臂（登记为下一步最小实验 +
  等效算力成本），而不是放宽到插值。
- 若参数量解析式与磁盘实测不等（P4 假）⇒ 头共享族的混杂来源另有其因，须重查 checkpoint 定义。
