**口径**：13.5M 冻结 trunk（sha256 断言）、纯推理、不训练、**唯一改动因素 = 权重矩阵的 `(bits, scheme, group)`**；KV / 激活 / 偏置 / Norm / tied 读出逐位不动。横轴（主口径）= **每参数部署字节（值 + 标尺）**，按参数数加权，落在 `scope_linear_all`（模型里全部 60 个 `nn.Linear` 的权重矩阵）；标尺 fp16 存储 = 2 B/把。`fp16` 臂 = 权重 fp16 = stock 释放前向；本批 device=cpu ⇒ 其 bpc 与 **GPU** 口径的历史锚 1.483569 **并列报告**，跨设备不构成判据（浮点归约顺序不同 ⇒ 末位可能不同）；判据 = 同设备、同窗口序的配对 Δbpc。bpc 窗口：主表 = `window_seed=2` × 24×16（与历史锚同窗口序）；配对窗口 = [2, 3, 4, 5, 6]（每窗 8×16）。**在力排序带 = 0.014000 bpc**（本批 5 个窗口满足标准口径（≥5）⇒ 在力带 = 0.014 bpc，判决 = max|配对 Δ| vs 该带）
