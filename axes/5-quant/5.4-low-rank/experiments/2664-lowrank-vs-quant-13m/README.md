## 0. 人话版本（先说判什么、怎么做）

**它想解决什么**：模型生成文本时要把读过的每个历史位置的 key/value（KV）存起来，
存的东西随上下文长度线性膨胀。省这块记忆有两条路：一条是**低秩压缩**（MLA，DeepSeek-V2 式）——
把每位置的 K/V 先压成一条短向量、用时再展开，省的是**维度**；另一条是**直接量化**——
K/V 还是那些数、只是每个数用 8 位或 4 位存，省的是**精度**。

**它们从没在同一个字节预算下比过。** 本实验问的就是这一句：
**同样每个位置只花 6528 字节（或 3456 字节），谁的语言建模质量更好？各自在哪一档开始伤质量？**

**怎么做的**：同一条 13M 的 decoder-only 主干（12 层 × 256 宽 × 8 头 × mlp6，序列长 256），
所有臂同配方从零训 12000 步（98.3M token），只改 KV 的存法：

| 同一个字节水平 | 低秩那条路 | 直接量化那条路 |
|---|---|---|
| **6528 B/位置**（fp16 的 ×0.53125） | 潜维 272 的 fp16 潜向量 | MHA + int8 块标尺（G=32） |
| **3456 B/位置**（×0.28125） | 潜维 144 | MHA + int4 块标尺（G=32） |
| **3072 B/位置**（×0.25） | 潜维 128 | 头共享 GQA2（另一条省 KV 的机制，作对照腿） |

外加 fp16 参照（12288 B/位置）、低秩的等参数对照（潜维 272 + FFN 减宽 ⇒ 参数量与 MHA 相等）、
头共享的等参数对照（`gqa2_eq`），以及一次 MHA 的同 seed 复跑（引擎 run-to-run 噪声地板）。

**为什么不直接照抄业界数字**：业界按「比特位宽 / 压缩率」报，很少把**标尺开销与上投影计算**放进同一张账，
也没有人把「低秩的维度损失」与「量化的精度损失」摆在**同一每位置字节轴**上比（`2617` §3 记：未找到同一
KV 字节预算下最优分配的公开前例）。本实验只做这一件小事：13M 受控、同字节、两腿（clean bpc + 合成长程召回）、
上投影算力入账。**结论停在「该尺度该字节值不值」，不外推。**

**现在到哪一步**：运行前。臂表、字节轴、判据线、评测口径已写入本文件与 `config.json`（预登记绑定见
`prereg_binding.json`）；本实验目录下 `runs/` 里待训练的四支新臂与全部读数在跑完前一律写「未跑」。

## 2. 机制归属：相对 DeepSeek-V2 MLA 的增量

- 业界 MLA（DeepSeek-V2，`arXiv:2405.04434`：KV 联合低秩压缩 + decoupled RoPE，`head_dim=128`）
  **只作设计方向**，不作判据。本仓基底模型没有 RoPE（`pathlm/model.py` 用学习式绝对位置嵌入）
  ⇒ 「RoPE 会破坏低秩结构」这一问题在本尺度不存在，故本实现**不需要** decoupled RoPE 分量；
  字节账里没有 RoPE 项。这是与 DeepSeek-V2 的**实质结构差异**，如实写明。
- 本项相对 SOTA 的增量只有两条：① 把「每位置部署字节 → 序列级两腿质量」的低秩点与**直接量化点**
  放在**恰好同字节**的格上比（跨家族统一字节轴）；② 把低秩的独有代价入账（上投影的每 token
  等效解码 MACs + 须从零训练）。本实验不重造 MLA、不重复 5.1 的量化标尺判决。

## 3. 臂表与同字节格

**每位置部署字节（横轴，解析）**：量化臂 = `2·L·n_heads·head_dim·(value_bytes + 2/G)`，
G=32 ⇒ int8 = 1.0625 B/值、int4 = 0.5625 B/值；低秩臂 = `L·d_c·2`（fp16 潜向量，无标尺）。

| 臂 | 机制 | 每位置字节 | 参数量 | 来源 |
|---|---|---|---|---|
| `mha@fp16` | stock MHA，K/V 存 fp16（参照） | 12288 | 13,536,768 | 复用 `2616` `mha-12k-s0`（seed 0）+ 本实验训 `mha-s1`（seed 1） |
| `mha@int8` | 同上 + int8 块标尺 G=32 | **6528** | 13,536,768（不训练） | 同上两个 checkpoint |
| `mha@int4` | 同上 + int4 块标尺 G=32 | **3456** | 13,536,768（不训练） | 同上两个 checkpoint |
| `mla_c272` | 低秩潜向量 d_c=272 | **6528** | 14,464,512（+6.86%） | 本实验训练（seed 0/1） |
| `mla_c272_eq` | d_c=272 + FFN 减宽（1385×9 / 1386×3） | **6528** | 13,536,495（−273） | 本实验训练（seed 0/1） |
| `mla_c144` | 低秩潜向量 d_c=144 | **3456** | 13,284,864（−1.86%） | 本实验训练（seed 0/1） |
| `mla_c128` | 低秩潜向量 d_c=128 | **3072** | 13,137,408（−2.95%） | 复用 `2656` `mla-c128-s0/s1` |
| `gqa2@fp16` | 2 个 KV 头（头共享对照） | **3072** | 12,352,512（−8.75%） | 复用 `2616` `gqa-12k-s0` 与 `gqa-12k-s0-rep` |
| `gqa2_eq@fp16` | 2 个 KV 头 + FFN 加宽（1729×4 / 1728×8） | **3072** | 13,536,516（−252） | 复用 `2656` `gqa2-eq-s0/s1` |
| `mha_rep@fp16` | MHA 同 seed 同配方第二次运行 | 12288 | 13,536,768 | 复用 `2656` `mha-rep-s0`（噪声地板，不参与判决） |

**三个同字节格（判据落在这里）**：

| 格 | 低秩 | 对照 | 压缩档 | 参数混杂方向 |
|---|---|---|---|---|
| A | `mla_c272` 6528 B | `mha@int8` 6528 B | ×0.53125 | 低秩**多** +6.86% 参数（对低秩有利）⇒ 由 `mla_c272_eq`（等参数、同字节）夹住 |
| B | `mla_c144` 3456 B | `mha@int4` 3456 B | ×0.28125 | 低秩**少** −1.86% 参数（对低秩不利） |
| C | `mla_c128` 3072 B | `gqa2` 3072 B | ×0.25 | 头共享少 8.75% 参数（对头共享有利）⇒ 由 `gqa2_eq` 夹住 |

- **同字节的算式**：`12·272·2 = 6528 = 12·2·8·32·1.0625`；`12·144·2 = 3456 = 12·2·8·32·0.5625`；
  `12·128·2 = 3072 = 12·2·2·32·2`（`config.json::same_byte_groups`）。同字节由解析式给出，并由
  评测期实测张量形状核对（`results.json::points[].bytes_measured`），**不使用插值**。
- **不被同一格覆盖的档**：`mla_c128` 与 `mha@int4`（3456）不同字节、`mla_c272` 与 `mha@int8` 之外无字节点
  ⇒ 本实验不做跨档插值；README §9 把未覆盖的字节水平登记成缺口。

## 4. 判据线（运行前写下，不许事后调整）

**逐字抄自 `../../project.yaml`：**

> **objective_criteria**：该跌：每位置 KV 部署字节（潜维 + RoPE 分量）；该不跌/可排序：clean bpc
> （相对同字节头共享臂与 stock 基线，须越 0.014 噪声带）；该保持：合成长程召回（第二腿不塌）；
> 必须不变：因果性与可见性对数；必须报：上投影的每 token 等效解码计算、等参数对照。

> **falsification**：若 MLA 式低秩压缩在等参数对照下相对同字节头共享臂的 clean bpc 不占优
> （越噪声带变差或持平）⇒ 判低秩压缩在本尺度不产生新知识；若「从零训练」的收敛代价吃掉全部
> KV 收益（等字节下不占优）⇒ 判该路线在本尺度不划算；若上投影额外计算使每 token 等效 FLOPs
> 显著上升且未被 KV 收益补偿 ⇒ 判代价记账不利。 用哪个带（C1 裁决）：0.014 bpc 带（限配对 Δ、
> ≥5 窗口）为主判；长程召回等率类指标走配对 bootstrap / Wilson 95% CI、不跨量纲借用 0.014。

**C1 判据带声明（本实验的落地口径，与 `config.json::criterion.planar_rules` 同源）**：

- 主判 = **0.014 bpc 带**，只用于 **clean bpc 的配对 Δ**（同 `window_seed=2` 的 24 个评测窗口 ≥ 5、同 seed 对齐）
  ⇒ 前提满足；率类指标（召回 / 准确率）**不**借用 0.014，走 Wilson 95% CI + 配对 bootstrap。
- 方向：`Δ = 低秩臂 bpc − 同字节对照臂 bpc`（**正 = 低秩更差**）。
- 裁决：`|Δ| ≤ 0.014` ⇒ 本 n 下**不可排序（不可分）**；`Δ < −0.014` ⇒ 低秩占优；`Δ > +0.014` ⇒ 对照占优。
- n：每个同字节格两侧各 n ≥ 2（seed 0 / 1 配对；格 C 的头共享一侧是**两次独立 seed 0 运行**，
  如实标注为「n=2 但不同 seed」）。
- 不可判：若 n=2 的配对 Δ 跨带（一条越带、一条落带）⇒ 判「本 n 不可判」，并按观测散布给所需样本量
  `n_req = (2σ/0.014)^2`，不得只报符号。
- 两根门（不成立则本实验作废）：① 非量化臂的 fp16 前向与 `retention.masked_bpc` **逐位相等**；
  ② 量化臂（块标尺 G=32）的前缀不变性两条均为 True。
- **必须报**：每位置部署字节（值 + 标尺）与实测张量形状对账、参数量（含等参数对照的两臂）、
  上投影的每 token 等效解码 MACs / FLOPs、训练健康量（步数、grad_skips、末段 CE 斜率）。

**指标表（怎么算、判什么）**：

| 指标 | 该涨/该跌 | 口径 | 判据 |
|---|---|---|---|
| 每位置部署字节 | **该跌** | `config.json::axis_definition` 的解析式；由实测 K/V 张量形状与 `n_values/n_scales` 反算核对（逐位相等） | 报「臂 / fp16 MHA」倍率与省幅 |
| clean bpc | **该不跌 / 可排序** | `axes/5-quant/5.1-kv-quant/experiments/2619-kv-budget-chart/run.py::bpc_of`（24 批 × 16 × 256、`window_seed=2`），逐臂同一 `logits_fn` 接口 | 同字节配对 Δ vs 0.014 带 |
| 第二路径 bpc | 一致性 | `retention.masked_bpc` 独立路径 | 非量化臂逐位相等；量化臂只作参照（fp16 存储效应） |
| 合成长程召回 | **该保持** | copy（3 起点）/ induction（2 起点）/ var_recall（距离 16/32/64/128/192/255），附 `1/64` chance、局部先验地板与 Wilson 95% CI | 配对 bootstrap 95% CI；不借用 0.014 |
| 前缀不变性 | **必须不变** | 改未来 token / 改同批邻居 ⇒ 过去位置 logits 逐位不变（复用 `axes/5-quant/5.1-kv-quant/experiments/2631-kv-budget-causal/causal_check.py`） | 量化臂必须 True；低秩臂结构性 True（实测逐位） |
| 因果性/可见性对数 | **必须不变** | 低秩块不改变可见位置集合（`mla_arms.check_causality_invariance`） | `max|Δ| = 0.0` |
| 上投影每 token 等效解码计算 | **必须报** | `mla_arms.decode_macs`（MACs 与 FLOPs，逐层与每 token） | 与单层 FFN 的比值同框 |
| 等参数对照 | **必须报** | `mla_c272_eq`（同字节、等参数）、`gqa2_eq`（同字节、等参数） | 并列进同字节格，不单报 |

**预判（不作为判据）**：`5.1` 已测 MHA 上 int8 块标尺近无损（+0.000101）、int4 有损（+0.022522）。
故 A 格更像「低秩必须无损才不输」、B 格方向未知（维度损失 vs 4 位精度损失，本仓首次实测）。

## 5. 评测口径与仪器自检

- **同一评测入口**：本目录 `run.py` 一条路径跑完所有臂（同一 `bpc_of`、同一窗口序、同一任务批、
  同一 device），臂之间唯一的差别是 `logits_fn`。
- **存储精度口径（两族同一把尺）**：量化臂的 K/V 走 `quantize_kv` 往返（fp16 臂也走这条路径
  ⇒ 三个量化档之间唯一差别是 `mode`）；低秩臂的**潜向量**走 fp16 往返后再上投影
  （部署侧缓存的就是 fp16 的 `c`）。两族都是「fp16 存缓存」，字节账与数值口径一致。
- **仪器自检（落 `results.json::instrument`，全过才接读数）**：
  ① 低秩前向：`round_fp16=False` 与 `retention.masked_logits` **逐位相等**（证明这是同一个模型，
  只多了一步 fp16 存储往返）；
  ② 路径一致：`bpc_of` 与 `retention.masked_bpc` 在 MHA fp16 上逐位相等；
  ③ 跨实验同口径：把本入口跑在 `5.1` 的 trunk（`2610` 的 `trunk.pt`）上，fp16 / int8 / int4 三点
  必须复现 `2632` 的三个数（1.483571 / 1.483672 / 1.506093 ⇒ Δ +0.000101 / +0.022522）；
  ④ 字节对账：每个臂的解析字节与实测张量形状反算逐位相等；
  ⑤ 前缀不变性：每个臂两条 bool。
- **训练健康量**：`results.json` 里逐臂记 `steps_done`、`grad_skips`、`gnorm_max`、末段训练 CE 斜率。
  `steps_done < 12000` 或 `grad_skips > 0` 的臂判「未跑完」⇒ 该臂不参与判决（`harness/SCHEMA.md` §19）。
- **推理实现与部署实现的差别**：评测期实现会把 int8/int4 立刻反量化、把潜向量立刻上投影
  ⇒ 实测显存峰值不随档下降；这是**解析部署字节**与**实测峰值**的分野，两者分列，不混用。

## 6. 成本（等效理论量，不含时间量）

| 项 | MHA（fp16/int8/int4） | GQA2 | 低秩 c272 | 低秩 c144 |
|---|---|---|---|---|
| 每位置值数 | 6144 | 1536 | 3264 | 1728 |
| 每位置部署字节 | 12288 / 6528 / 3456 | 3072 | **6528** | **3456** |
| 解码期算出新位置 q/k/v 的 MACs / 层 / token | 196,608 | 98,304 | 274,432 | 176,128 |
| 其中上投影 MACs / 层 / token | 0 | 0 | 139,264 | 73,728 |
| 上投影 MACs / FLOPs 每 token（12 层） | 0 / 0 | 0 / 0 | 1,671,168 / 3,342,336 | 884,736 / 1,769,472 |
| 上投影占单层 FFN（786,432 MACs）的比 | 0 | 0 | **17.71%** | 9.375% |
| 量化臂新增参数 / 算力 | 0 / 0 | 0 / 0 | — | — |

- `layer-passes` 每 token 仍为 `L`；`tokens-per-forward` = 1；低秩不额外加层、量化不改算力。
- 严格前缀不变（pipelining）：上投影只依赖当前已生成位置的潜向量 ⇒ 不引入额外顺序依赖、
  不需要 staging（与沿 token 轴分块的量化不同）。
- 「须从零训练」的代价：全部臂同为 12k 步 / 98.3M token 从零训练（等预算记账），**不折算成小时数**。

## 8. 失败决策树

| 观察 | 判定 |
|---|---|
| A 格 `Δ = mla_c272 − mha@int8 > +0.014` | 判「8 位直接量化在同字节上优于低秩」；若 `mla_c272_eq` 仍更差 ⇒ 与参数混杂无关 |
| A 格 `Δ < −0.014` | 判「低秩在同字节上优于 8 位量化」；必须同时报上投影算力（+17.71% FFN）作为代价 |
| A 格 `|Δ| ≤ 0.014` | 判「不可分」；附 `mla_c272_eq` 的读数说明参数混杂是否解释了残余方向 |
| B 格同 A 格三种情形 | 4 位档的失效模式：`mha@int4` 的损伤（−fp16）与 `mla_c144` 的损伤同框 ⇒ 谁先越带 |
| 低秩在某档开始越带、量化不到该档 | 记「低秩的失效点在 rank r*」并给相邻两档的读数；不得外推到中间未测档 |
| 量化在某档越带、低秩不到 | 记「量化的失效点在位宽 b*」；不得写成「量化不可用」 |
| C 格（低秩 vs 头共享）低秩更差且等参数臂也差 | 判「低秩在本尺度不产生新知识」（对应 SSOT 的否证条件之一） |
| 上投影 FLOPs 上升而 KV 收益未补偿 | 判「代价记账不利」；报每 token 等效 FLOPs 与 FFN 的比值 |
| 训练健康量不过（步数不足 / grad_skips > 0） | 该臂判「未跑完」，不参与判决，先重跑该臂 |
| 仪器自检任一条不过 | 停在实现层：先修，**不得**用不等价的读数作判据 |

## 9. 非目标与未覆盖

- **不测**：低秩 × 量化的**叠加**（组合默认留白，`harness/SCHEMA.md` §4）、decoupled RoPE（基底无 RoPE）、
  T > 256、更大尺度（>13M）的外推、MLA 之外的吸收式变体（`W_UV` 融合等）、真实实现的内存峰值下降。
- **未覆盖的字节水平**：`mla_c64`（1536 B）、`mla_c256`（6144 B）未训；若两个主判格都不可分，
  这些是下一轮加密的最小臂（每档 2 seed）。
- **n=2 的上限**：本实验 n=2（格 C 的头共享一侧为两次 seed 0 运行）；配对 Δ 跨带即判「本 n 不可判」
  并按散布给 `n_req`。
