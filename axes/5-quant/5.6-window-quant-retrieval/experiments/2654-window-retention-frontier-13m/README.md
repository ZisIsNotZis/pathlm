# 2654 · WP1：按保留预算的窗口曲线 × 窗口 × int8/int4 块标尺组合（13M，CPU 口径）

> 契约来源：`.scratch/66-axis5-quant/DISPATCH-5.6.md`（Phase B）+ `DISPATCH-5.6-PHASEC.md`
> （Phase C，冲突以其为准）。研究项 SSOT：`axes/5-quant/5.6-window-quant-retrieval/project.yaml`

## 1. 命题（要判什么）

在 13M / T=256 的 stock decoder-only trunk 上，`全因果基线 → 只保留最近 W 个位置` 的
clean bpc 损伤**是否随保留预算单调**（W=32→192），以及把**窗口**与 **int8/int4 块标尺量化**
组合后，能否落在 `5.1::2642` 给出的同一「每位置**部署**字节」水平上、并给出与**单用其一**
可比的读数。

**要回答的三问（契约 `falsification`）**
1. 窗口 bpc 损伤是否随保留预算单调（keep32 ≈ +0.212 → keep192 ≈ +0.004）？若是，旧「窗口代价
   几乎为零」判读被否证。
2. 窗口 + 量化组合在**等字节**下是否优于**单用其一**（只用窗口 / 只用量化）？
3. 与 M2 ERRATA（keep32 = +0.212、keep64 = +0.081）是否**逐数字**一致？

## 2. 单因素声明

- 唯一改动 = 评测期的**可见性掩码**（窗口 W）与 **KV 存储精度/标尺方案**（int8/int4 块标尺 G=32）；
  基底恒为 stock trunk，**不训练、不加参数、不改权重**（checkpoint 只读 + 运行时断言 sha256）。
- 组合臂（`window × int8/int4`）只叠加**两个已单测的因子**，是 `SCHEMA` §4 的**例外条款**授权
  （组合留白是本项目的默认，本批组合臂由轴 5 契约显式授权）。
- 量化腿口径**唯一**：`5.1` 的**块标尺**（`tools/evalkit/kv_quant.py::quantize_kv(scheme="block",
  G=32)`，沿 `head_dim` 摊薄，严格前缀确定）⇒ int8 1.0625 B/值、int4 0.5625 B/值。
  **禁止**引用已作废的逐值标尺数字。

## 3. 指标与判据线（逐字）

| 项 | 内容 |
|---|---|
| 横轴 | 每位置**部署**字节 = `2(K,V)·L·n_kv_heads_eff·head_dim·(值字节 + 标尺字节/值)·(kept/T)`；T=256；fp16 全因果 = 12288 B/位置 |
| 两腿 | ① clean bpc（越低越好，**主判**）② 合成长程召回（copy 汇总准确率 + Wilson 95% CI + `at_floor`） |
| 判据带（C1） | **0.014 bpc 带，限「配对 Δ、≥5 窗口」**；主表 `window_seed=2`（24×16），另跑 `seeds=[3,4,5,6]`（`n_batches=8`）⇒ 5 个评测窗口。跑不满 ⇒ 显式声明并退用单臂跨窗口极差，**两带不混用** |
| 率类指标 | 走 Wilson 95% CI（对照 chance = 0.0156 与同掩码地板）；**不跨量纲借用 0.014** |
| `at_floor` | `recall ≤ chance + 2σ_wilson(chance)` ⇒ 该任务上**不可分辨**，**不得**写成「机制无效」 |
| 同字节水平 | 组合臂必须**精确命中** `2642` 的 7 个水平（432/768/816/864/1536/1632/3072 B/位置）之一或另立水平并说明；**禁插值** |
| 该跌 / 该不跌 | 部署字节随保留预算下降（该跌）；clean bpc 与召回不塌（该不跌/可排序，须越带） |
| 必须不变 | 严格因果、同拓扑 fp16 基线、窗口臂的**非量化**读数与其历史来源（逐位/带内） |

## 4. 既有做法（prior art；只作设计方向，**不作判据**）

- **生产默认组合拳**：滑动窗口 + sink/锚点 + KV 量化 + RAG 是长上下文的生产默认答案
  （`记忆·未核`，本仓无一手测点）。
- **量化腿 SOTA 口径**（标题本轮联网核实 HTTP 200，仅作设计方向）：KIVI `arXiv:2402.02750`、
  KVQuant `arXiv:2401.18079`、Atom `arXiv:2310.19102`。
- **本地已落实的对手**：窗口/锚点（`.scratch/07-x1-x3/evidence`）、M2 保留曲线 `2614`（keep32 =
  +0.212、keep64 = +0.081，**ERRATA 修正后**）、`5.1` 的预算图 `2619/2621/2632` 与同字节前沿 `2642`。
- **本项最高风险**：把兄弟线的单点重绘当新发现 ⇒ 本实验的每个判据点都在本机 CPU 同口径**自跑**，
  历史值只作 `source` 注明的对照（`prior_xcheck`）。

## 5. 臂（全部 stock trunk；`win_arms.py::SPECS` 是唯一 home）

| 臂 | 语义 | 值字节 | 部署字节 | 2642 水平 |
|---|---|---|---|---|
| `full` | 全因果基线（fp32 恒等） | 12288 | 12288 | — |
| `win16/32/64/96/128/160/192` | 只保留最近 W 个位置（fp16） | 48·W | 48·W | 768（W=16）、1536（W=32）、3072（W=64） |
| `win32_int8` | 窗口 32 × int8 块标尺 | 768 | 816 | **816** |
| `win64_int8` | 窗口 64 × int8 块标尺 | 1536 | 1632 | **1632** |
| `win32_int4` | 窗口 32 × int4 块标尺 | 384 | 432 | **432** |
| `win64_int4` | 窗口 64 × int4 块标尺 | 768 | 864 | **864** |

执行顺序 = 优先级（被 30 min 硬上限切断时，前面的必须已落盘）：
`full, win16, win32, win64, win96, win32_int8, win64_int8, win192`（主表）→ 5 窗口配对带 →
`win128, win160, win32_int4, win64_int4`（补跑）。`keep96` 是 keep32→192 里**历史唯一缺失**的保留预算点。

## 6. 对照与方差

- **对照**：`full`（本机基线）；他设备历史点（`2615/2619/2621/2632`，`prior_xcheck` 表）；
  局部先验（`local_prior_accuracy(k=8)`）与 chance（1/64）；**毁源对照**（copy 源片段换随机符号）
  只在信息量最大的 3 臂（`full`/`win64`/`win64_int8`）上跑（预算受限，登记见 §8）。
- **方差**：配对 Δ（同一臂对 × 5 个评测窗口）；配对口径未达标时退用单臂跨窗口极差。
- **等价性证据**（跨设备不作判据）：本机 CPU 复现 `full` 与 GPU 历史锚 `1.483569`
  （|Δ| 记录在 `results.json::points[*]`，见分析）。
- **两条独立路径逐位一致**：`bpc_of` vs `retention.masked_bpc`；`block_arms(per_value)` vs
  `rest_arms`（⇒ 量化腿唯一改动 = 标尺方案）。

- **设备 = CPU**（`/tmp/pathlm_gpu.lock` 被其它轴训练占用；F5 已批准纯推理走 CPU；`SCHEMA` §20 不适用

## 8. 失败决策树

| 现象 | 处置 |
|---|---|
| 曲线非单调 | 如实报并给违例点；先查掩码语义（`recent_keep_mask`）与 bpc 路径，再查是否单 seed 抖动 ⇒ 用配对带判 |
| 与 M2 ERRATA 不一致 | 逐数字报差异 + 给本机口径证据；不修改历史值，不改 `project_info` |
| 组合臂超出预算未跑完 | `partial: true` + `arms_completed/arms_pending`，**不伪造**；未跑的组合臂写进 `analysis.md` 的 gaps |
| 召回腿落在地板 | 记 `at_floor`，写「该任务上不可分辨」，不写「机制无效」 |
| 单臂等字节无对照点 | 只报「本机同字节的臂」与「他设备同龄臂」，**不插值**、不把跨设备数字当判据 |

## 9. 明示的非目标（non-goals）

- 不做检索腿（WP2）；不做头共享/权重/激活量化；不做 T>256；不做真 cache 的实测显存；
  不外推「结构优劣」（单 seed 冻结 checkpoint）。
