# 2652 · 激活量化最小判决（13M · int8 / 4 位激活，含 per-token 动态标尺）

**横轴（主口径）**：`bytes_per_token_activation = Σ_tensor in_features·bits/8·L + (整型档 ? 2·4·L : 0)`；张量集 = 每层 `qkv`/`proj` 输入的 d + FFN 两个 matmul 输入的 d 与 `mlp_mult·d`（L=12, d=256, mlp=6 ⇒ 27648 元素/token；fp16 = 55296 B/token）。**这是激活账，与 5.1 的 KV 每位置 字节（fp16 12288 B/位置）不同量纲，两者不混排**。权重字节只对组合臂 `W8A8` 单列（整模型口径，非每 token）。

**判据带**：主判 = **0.014 bpc 带**，口径 = **配对 Δ**（同臂同 window_seed）跨 **5 个窗口**（seed = [2, 3, 4, 5, 6]）的 **max|配对 Δ|** ⇒ **满足 ≥5 窗口**，故直接用预登记常数 0.014（非本批自测带 ⇒ 不构成循环论证）。召回等率类指标走 Wilson 95% CI、不借用 0.014。召回地板：chance = 0.0156（1/64）、 局部先验 = 0.0176（copy）。

- **锚口径单点（24×16@seed2，本轮补跑）**：`bpc_of` = **1.483568730**；独立路径 `masked_bpc` = 1.483568730（逐位 = True）；历史锚 1.483569 的 |Δ| = 2.70e-07。

**(3) 配对 Δ ↔ 判据带**

- *A8*：max|配对Δ| = 0.003530 ≤ 0.014 ⇒ 不越带（代价落在预登记噪声带内）

- *W8A8*：max|配对Δ| = 0.002955 ≤ 0.014 ⇒ 不越带（代价落在预登记噪声带内）
