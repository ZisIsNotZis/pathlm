# 2619 · 判读（重建训练信号：无通道模型能否被「逼着学会搬运」）

> 契约：同目录 `README.md`（判据线**逐字**抄录）。原始读数：`results.json`；
> 逐步日志：`run_log.txt` / `run_log.jsonl`；训练日志：`train/<arm>/train_log.jsonl`。
> 口径：**快照（matched-step，12k 步）**；判据用**准确率 + 二项 95% CI**（不用 bpc）。

---

## 0. 人话摘要（先讲结论，数据在后面）

**我们干了什么**：给一个 1350 万参数、**没有口袋**（没有任何记忆槽位）的普通变压器
出了一道「必须记很久」的题：开头给 8 组「暗号 → 号码」（每组两个随机符号），中间塞
两百多个无意义的填充符，最后再问其中几组的号码；而这个模型往前只能看 **16 格**，
问的时候暗号早就掉出视野了。瞎猜命中率是 1/64 = 1.56%。接着我们在训练里**加了一条
罚则**：每一格必须能「说出刚刚掉出它视野的那一格是什么」（位置 i 要重建 `tokens[i−16]`），
并给它配一个小的解码头。对照组除了不加这条罚则以外，**逐字段完全一样**（同 seed、
同参数量、同初始化——不加罚则的那一臂连解码头都建了，只是从不训练它）。

**测出来**：

- **罚则被完美学会了**：有罚则的臂重建「刚掉出视野的那一格」的命中率 **≈ 1.00**
  （99.0% / 100%，随机解码头是 0.0016）；也就是说模型**确实学会了「交班」这一动作**。
- **但长程回忆一点没长**：有罚则臂在**关联回忆**上的命中率 **0.0137**（13.7‰），
  不加罚则的对照臂是 **0.0161**（16.1‰）——两个都在**瞎猜线 1.56%** 上（差 −0.244pp，
  置信区间重叠）。所以**主判据没过**：预登记的判定是「**在 13M / 12k 步 / 这件任务上
  不成立**」。
- 更要紧的是**它连 3pp 都测不稳**：把有罚则的那一臂**同配置再跑一遍**，结果是
  **4096 次提问一次都没答对**（0.0000%，置信区间与第一跑不重叠）。也就是说同一份
  配方能落到「≈ 瞎猜」和「一次不出手」两个不同的坑里——**训练侧的抖动比预登记的
  3pp 判据还大**，在这个尺度上根本分不出 3pp。

**为什么「学会了交班」却「没学会搬运」**（这是本次最有价值的诊断）：
这条罚则只要求**把信息往前递一格**——位置 i−1 自己就看得见那一格，把它的身份写进
自己的隐状态、位置 i 再读出来即可；**不需要**把两百格以前的那张暗号表**一直维持住**。
我们的实测正好卡在这个差别上：**一格交班 ≈ 100% 命中**，而**两百格外的按暗号取值 ≈
瞎猜**（答案行的交叉熵 4.20 / 4.18 / 4.19，而纯瞎猜是 ln64 = 4.1589）。
⇒ 结论不是「机制不可能」，而是「**这一条训练信号在 13M / 12k 上不划算**」：
它给的是「接力棒别掉」的激励，不是「把整张表背下来」的激励（SCHEMA §19）。

**用在哪里**：这条负结论**支持**把后续力气放在「显式载体」（有地址的槽位/固定状态）
那一侧——`2618` 的 delta 写通道在**同任务同尺度**下把命中率抬到 **0.0950**（+8.13pp，
毁源后掉回 0.0081），而本线的训练信号**一点没抬**。两条读数合起来说：**在这个尺度上，
「给路径」比「给信号」有用**（都是单因素对照，口径相同：同任务、同窗口、同 12k 步）。

## 2. 六问（AGENTS.md 的汇报纪律）

1. **它是干什么的**：让一个**没有记忆槽**的模型，只靠一条训练时的罚则，
   学会把「已经滑出视野的信息」继续带在身上，以便很久以后再被问到还能答出来。
2. **相对普通 decoder-only transformer 改了什么**：**前向结构一点没改**
   （12 层 × d256 × 8 头 × mlp6，tied 读出、无 final LayerNorm、顺序残差，13,589,504
   参数）。新增的是一个**训练用的解码头**（单层线性 d→V = **52,736** 参数，+0.39%，
   两臂都有、只在有罚则那一臂被训练）与一条辅助损失
   `loss = CE + λ·CE(recon_head(h_i), tokens[i−16])`，λ = 1.0。算力增量 ≈ 一个
   `[B,240,256]→[B,240,206]` 的线性前向 + 反向（实测墙钟 9.85 vs 8.78 min/臂，+12%）。
3. **为什么要改**：长程记忆的梯度缺口——只看最终 CE 时，「当场读源」是最短路径，
   没有任何梯度奖励「先写进载体再读出来」（`2617-design-rightcarry` §1.1 的记录）。
   重建/充分性损失就是人为补上这条梯度（业界已有成熟前例，见 README §11）。
4. **怎么测的**：对照组 = **同 seed、同参数量、同初始化、同数据、同步数**的 λ=0 臂
   （只差这条损失）；指标 = **关联回忆 top-1 准确率**（K ∈ {4,8,16}，n = 4096/档）
   + **毁源对照臂**（把对的暗号表换成随机符号）+ **变距离回忆**距离腿；口径 =
   **matched-step 快照（12k）**，二项 95% Wilson CI。不用 bpc（合成任务 CE 是混合量，
   且训练侧 bpc 噪声 ~0.0156 已超方差界）。
5. **测出来多少**：见 §0 人话摘要与 §4–§8 的数据表。三个关键对照系：
   ① 瞎猜 = 1/64 = **0.015625**；② 无损失臂 = **0.016113**（≈ 瞎猜）；
   ③ 有损失臂 = **0.013672**（≈ 瞎猜）；④ **同任务同尺度**的 delta 写通道（`2618`）= **0.094971**。
   ⇒ 训练信号相对「给通道」在这个尺度上**差 8.1pp**。
6. **结论与下一步**：**不采纳这条训练信号作为「造出搬运」的手段**（本尺度）；
   不是设计不可行，而是**罚则的形态选错了**——「重建刚掉出视野的那一格」只要求
   一格的交班，不要求前缀维持。下一步（若继续）：**把重建目标改成「多格 / 变距
   离」**（例如同时重建 `i−16` 与 `i−64`，或随机采样一个窗外偏移）以强迫累积状态，
   或直接走「有地址载体 + 训练信号」的组合（组合属产品方 scope，本仓不做组合实验）。

## 9. 失败路径与原因（列表；含排除了哪些替代解释）

1. **训练信号形态不覆盖「前缀维持」**（本实验的机制解释，与方法学记录一致）：
   重建 `tokens[i−16]` 只要「上一位把它看见的那一格交班给我」。**排除了**「信号太弱」：
   重建符号命中率 ≈ 1.00。**排除了**「梯度没到主干」：`embed.weight.grad ≠ 0`
   （单测）且主干 CE 会随训练下降。
2. **任务确实需要搬运**：`A` 在 chance 线上（0.016113，CI 上界 0.020447 < ceiling
   0.046875），局部先验 0.0，查询-key 距离 241–255。**排除了**「窗口没生效」：
   自检 ② 零违例（240/240 行「i 不可见、i−1 可见」）+ `window_mask.alive = true`
   （掩码开/关的 logit 差 2.106）。
3. **训练侧双稳态吃掉判据**：同配置两次 0.013672 vs 0.000000（CI 不重叠）。
   ⇒ 本尺度**不可分辨**；**排除**了「+3pp 的差异一定可测」这一假设。
4. **不是「机制不可能」**（SCHEMA §19）：本结论只覆盖 13M / 12k / 本任务；
   同任务同尺度上**给通道**（`2618` delta 写）能到 0.094971 ⇒ 需求与仪器是通的，
   差别在「有没有把信息搬过去的路」，而不是「任务根本不可解」。
5. **未测因而未排除**：λ 的其他取值（只有 1.0）、更长训练（只有 12k）、
   更大规模、**重建目标的形态**（只测「偏移恰为窗口 W」的单点，没测多格/变距离）。
