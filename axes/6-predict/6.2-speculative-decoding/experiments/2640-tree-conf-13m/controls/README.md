# 2640-tree-conf-13m · 对照物清单

> 本文件列本实验的**对照物**（谁也不许把对照当结论）。判读见 `../analysis.md`，契约见 `../README.md`。

| 对照物 | 是什么 | 口径 | 本实验是否已跑 | 在结论里的角色 |
|---|---|---|---|---|
| `native` | `pathlm.decode.decode(Decoder.step)` 逐 token 贪心解码（走生产 `Decoder.step`） | 归一 100%：每 token 1 次前向，`α₁`/τ 无意义（`tokens_per_forward ≡ 1`、`R ≡ 1` 为定义） | **已跑**（3 个 checkpoint） | ① 所有臂发出流的**逐位基准**（无损性门禁 P4）；② 接受率口径的参照（每轮最多少吐 γ+1 个） |
| 诚实对手（1-step AR，两次前向） | 「一次前向只草拟 1 个 token、再前向验证」的朴素投机解码——不加树、不加多候选 | 墙钟 **不测**（禁墙钟判据）；口径为解析的每 token 顺序前向次数 | **未跑**（本实验无此臂） | 属 `6.2.3` / `6.2.1` 的对照，**不在本实验结论内**；本实验内的**单候选臂** `direct1` / `chain1` / `combined_fixed` / `combo_pw` 即「每轮只送 1 行验证」的对照（见 `../README.md` §3） |
| `oracle_accept` | 候选 = 目标**真值** argmax（从 native 贪心流取第 L+1 位）⇒ `α₁ ≡ 1` | 解析量；**只作 τ 的绝对上界附报** | **已跑**（13m_s0 / 13m_s1） | **不作判据**（`harness/SCHEMA.md` §11）：τ=1.767/1.766 只是「该实现能把 τ 抬多高」的上界，不用来判有效性 |

## 说明

- **`native` 是唯一的归一化参照**：所有臂的 `α₁` / `α₂|₁` / τ / tok-fwd 与它无关，但「发出流逐位
  相等」是对它的直接比对（P4）。`native` 的 `α₁` 记为 `None`（无「接受」概念）。
- **诚实对手（1-step AR）不在本实验**：本实验只回答「在**已有 2631 单候选臂**之上，把草稿换成
  多候选 / 树能否抬 α₁/τ 且无损」；「树 vs 朴素 1-step 投机」属退化对照，由 `6.2.3` / `6.2.1`
  承担，避免在 60 min GPU 盒里重复。
- **`oracle_accept` 只作上界**：它用真值当候选，物理上不可部署；任何「树臂已接近 oracle」的说法
  只用于说明**余量**，不得当作有效性判据。
