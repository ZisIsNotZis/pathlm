# analysis — 2660-latentreg-vs-disc-13m（阶段 1：直接发 / teacher-forced）

## 人话摘要

我们在**同一份冻结的 13M 主干**上，只改「未来位置怎么产出」这一件事：一种是直接把主干隐状态经几个小变换头**分类到词表**（离散臂），另一种是让这些头**回归到主干在未来位置的真实隐状态**（回归臂，多一个 λ·MSE 项把输出拉向真值隐状态），两者共用同一份 tied 读出、同一参数量、同一训练预算（3000 步）。
结果：同参数量下，离散臂在 t+2 命中率 0.457、t+3 命中率 0.335；冻结主干自己的 AR 下一 token（t+1）命中率是 0.671。
把回归监督项 λ 打开后，t+2 命中率升到 0.469（λ=0.1）和 0.488（λ=1.0）——**配对差都在 95% CI 里明确不含 0**，且两个种子、第二个主干点、k=4 全部同向。

- **L0（实现保真硬门）**：**通过** —— `lat_k2_lam0` 与 `disc_k2` 同种子逐位相同（命中率 / CE / 头权重
  ）；冻结主干 `requires_grad=False` 且一次 backward 后 `.grad is None`。
- **L1（主判，路径 (i) 直接发）**：采纳（t+2 配对 95% CI 不含 0：lat_k2_lam01,lat_k2_lam1）
  - `lat_k2_lam01` vs `disc_k2`：t+2 Δ=+0.01140 CI[+0.01006,+0.01274] 不含0；t+3 Δ=+0.00853 CI[+0.00729,+0.00981] 不含0
  - `lat_k2_lam1` vs `disc_k2`：t+2 Δ=+0.03125 CI[+0.02955,+0.03302] 不含0；t+3 Δ=+0.02935 CI[+0.02764,+0.03108] 不含0
- **L3/L5**：reported（等效理论量，不作判据）；reported（λ>0 的 CE/MSE 轨迹落盘）

> 口径提醒：率类指标走**配对 bootstrap / Wilson 95% CI**（不跨量纲借用 0.014 bpc 带）；`results.json` **无任何墙钟字段**。

### 对契约 §2「预登记预言」的结论

契约 §2 预言「若 λ>0 无增益」则应把 6.3.3 的标题式描述降级为「同一参数化上的辅助监督项」。
**本尺度下该预言被否证**：λ∈{0.1,1.0}、k∈{2,4}、两个主干点、两个种子，t+2 配对 CI 全部不含 0 且
Δ 随 λ 增大而增大（+0.011 → +0.031）。故**不建议**把 6.3.3 的描述降级；是否按本结论修订 `project.yaml`
的 `innovation`/`method` 由 lead 决定（执行方不自改）。阶段 2 的 L2（当草稿接受率 α₁/τ）仍待测——
路径 (i) 的命中率增益**不自动等于**路径 (ii) 的接受率增益（两者代价口径不同，63-F4）。

**归因边界**：本条增益可归因于**同一参数化（共用 `z_j = TransformHead_j(h_i)` 与 tied 读出）上的辅助
MSE 监督**；本实验**未**把「回归产出方式」与「其它辅助监督」区分开（两臂唯一自由度就是 λ·MSE 项）
⇒ **不得**读成「回归机制优于分类机制」。

# 阶段 2：当草稿再验证（路径 (ii)，L2）

## 人话摘要

阶段 1 量的是「直接发」（老师强制下的 t+2 命中率），阶段 2 量的是「**当草稿再验证**」：把回归臂
**第一个变换头**的输出当作位置 N+2 的草稿，塞进**生产解码器**做单候选投机解码，看它提出的下一 token
被主干接受的概率（α₁）和每轮平均多推进几个 token（τ）。**单因素 = 位置 N+2 的草稿来源**，N+3 每个臂
都固定用引擎自带头（与 2640/2631 背景一致），协议与 2640/2631 逐字相同（enwik8 val、stride 5000、
32 长度 prompt × 12、每 prompt 生成 200 token、温度 0、每轮验证 2 个草稿位）。

**保真硬门先过**：同一 harness 里用 2640/2631 的 `direct1` 草稿定义（= 引擎默认）跑一臂，其 12 个
prompt 的**逐轮接受数逐位复现** 2640 的 `direct1`（α₁ = 0.802243、τ = 1.453619，逐位相同）——说明
本 harness 与 2640/2631 等价，新读数可信。因此结论：**回归臂当草稿也更好**——同参数量下，回归臂把
α₁（一轮至少接受一个草稿的概率）从约 0.64–0.67 抬到约 0.73–0.75、把 τ（每轮平均接受草稿数）从约
1.20–1.24 抬到约 1.34–1.38：即每个 token 需要的顺序前向次数更少。**L2 判词 = 采纳**（配对 95% CI 不含 0，
Δα₁=+0.092、Δτ=+0.146）。与 2640 `direct1`（主干内联合训练头，α₁≈0.80）相比回归臂仍偏低，但这属于
训练 regime 不同，**不作判据**，只作参考。

## 口径与接线（契约 §4 L2）

- 协议：enwik8 val、stride 5000、`PROMPT_LEN=32`、12 prompt × `n_new=200`、B=1、温度 0、γ=2。
- 位置 N+2 草稿 = `argmax( head0(nodes[0]["latent"]) @ model.embed.weight.T )`；`nodes = dec.last_nodes`，
  `nodes[0]["latent"]` = 主干最终隐状态，`head0` = 训练时 j=1 ⇒ t_{i+2} 的那个头。
- 其余草稿位（N+3）固定 = 引擎自带 `nodes[3]["logits"].argmax()`。
- 统计：α₁ = 接受≥1 的轮占比；τ = 平均接受数；Δ = `lat_* − disc_*`，**按 prompt 聚类**的配对
  bootstrap 95% CI（B=2000、seed=2660、percentile95）。

## 代价轴（契约 §4 L3，不作判据，禁墙钟）

- 路径 (i) 每 token 主干等效 FLOPs ≈ `L/k`（k=2 ⇒ ≈ L/2）；

- 头部参数与 MAC 占比见 `results.json::L3`（阶段 1）。

## 未测 / 边界

- 只做主干的 N+2 草稿源单因素；N+3 固定为引擎头，不构成组合实验授权。
- 结论只适用于本冻结 ckpt / char enwik8 / k=2（及可选 k=4 头0）/ 该训练预算。
