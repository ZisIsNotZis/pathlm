# M1-carrier-type · 状态载体类型

> 轴：**M 状态载体** ｜ 状态：**✅ judged**

> **判读**：**载体类型首验（ticket 35）：显式写入通道成立**——在「关联回忆 + 窗口 16（key 100% 落在窗外）」的合成任务上，13M/12k 步：无通道 U0 = 0.0137（≈chance，前提校验过）→ **delta 写 U2 = 0.0950（6.08× chance，+8.13pp，CI 不重叠；毁源后掉到 0.0081 ⇒ 读数确来自被搬运的信息）**；plain 写 U1 双稳态（0.0007 / 0.0334）且比 U2 低 9.42pp ⇒ **「只搬增量」的 delta 写是稳定有效的那一支**。绝对水平仅 9.5%（13M/12k）⇒ 按 SCHEMA §19 不得外推为「业界做不到/做得到」。 同时 ticket 34 造出「不靠语言先验」的长程天平并给出关键诊断：13M 主干长程能力**分任务型**——关联回忆 0.0061、变距离回忆 0.005–0.010（≈或低于 chance）⇒ 检索类彻底缺席；复制 0.1333（距离 223 仍 0.118，毁源→0.0125）、induction 0.0586（毁源→chance）⇒ 真实但弱。

## 4. 结论与数字

- **税**：ticket 35 的通道为**旁路**（`+264,296` 参数，U1/U2 逐位相同；单共享槽在输入流上，每层用自己的 query 读）——为对齐 MQAR/线性注意力标准形态而选择（per-layer-12 实装实测 221/410 ms/step 出局，根因是算子派发/autograd 节点开销而非 FLOPs）；解析状态 8192 floats（与 T 无关）vs 实测峰值 2015/2170/2282 MB（分开报）
- **收益**：**delta 写（S ← S·(I−βkkᵀ)+βvkᵀ，「只搬上次没搬的」）在关联回忆上 6.08× chance、且毁源后崩到 chance** ⇒ 「信息被搬到可检索处」首次被直接证实；读取量证据：U2 读分享 →0.7078、U0 为 0；距离腿六档全部 > chance（最远 d=255 为 0.5947，曲线非单调、不外推）；per-layer KV + 位置散点填充仍支持「变深度 + 不重 prefill」（与并行 forward 逐位一致）
- **判读**：**载体类型首验（ticket 35）：显式写入通道成立**——在「关联回忆 + 窗口 16（key 100% 落在窗外）」的合成任务上，13M/12k 步：无通道 U0 = 0.0137（≈chance，前提校验过）→ **delta 写 U2 = 0.0950（6.08× chance，+8.13pp，CI 不重叠；毁源后掉到 0.0081 ⇒ 读数确来自被搬运的信息）**；plain 写 U1 双稳态（0.0007 / 0.0334）且比 U2 低 9.42pp ⇒ **「只搬增量」的 delta 写是稳定有效的那一支**。绝对水平仅 9.5%（13M/12k）⇒ 按 SCHEMA §19 不得外推为「业界做不到/做得到」。 同时 ticket 34 造出「不靠语言先验」的长程天平并给出关键诊断：13M 主干长程能力**分任务型**——关联回忆 0.0061、变距离回忆 0.005–0.010（≈或低于 chance）⇒ 检索类彻底缺席；复制 0.1333（距离 223 仍 0.118，毁源→0.0125）、induction 0.0586（毁源→chance）⇒ 真实但弱。

## 5. 失败路径与原因

1. 早期缓存 bug：逐位置早退导致 per-layer cache 长度失步（已修为 per-layer 位置列表；持续单测）
2. **长程检索能力缺席（ticket 34-A 仪器实测）**：关联回忆 0.0061、变距离回忆六档 0.005–0.010，均≈或低于 chance 且无距离依赖 ⇒ 此前所有「没搬」读数，至少相当部分来自**模型本来就没有该能力**，而非「机制搬不动」（SCHEMA §19）
3. **仪器落地（`tools/evalkit/longrange_tasks.py`）**：四任务 + chance/局部先验基线 + 距离曲线 + `recall_under_visibility`（复用 retention 掩码）+ 毁源对照臂；自证：局部先验基线 0.0098–0.0217（chance 上限 0.0469）、毁源/打乱答案均掉回 chance、前向逐位一致
4. 不确定项：induction 每点 n=128 不支持斜率；assoc/var 低分含分布外成分（**不得**外推成「训练也学不会」）；copy 13% 的机制未定位
5. **搬运 × 深度监督首次同台（ticket 44-X2，13M 2×2 四格、同数据同步数同 seed；深度因子因引擎互斥降为 `--dense-aux`）**：主腿（训练分布内多查询关联回忆，n=16384/臂、chance 1.56%）= base **1.48%** / carry **35.78%** / depth **1.47%** / both **36.16%** ⇒ ① **carry 一开成绩 ×24（+34.30pp，CI 不重叠）**；② **浅层监督单独对召回毫无作用（−0.006pp）**；③ **2×2 交互项 +0.385pp（落在 1.4pp 带内）⇒ 在召回目标上两资产可加、不打架**（判据⑤「负增量」未触发）；④ **出口资产 tf@4（分布内）**：87.84（base）→ **99.84%**（仅 depth）；两者同开 94.47% ⇒ **tf@4 交互项 −6.06pp（通道在开会吃掉一小块出口）**；⑤ **质量代价**（enwik8 跨分布）55.07 / 52.36 / **125.74** / **1322.98** bpc ⇒ 浅层监督在真实文本上代价极大。**未测因子（禁外推）**：ragged 随机退出 + proj-fill 的冻结/混合 KV 语义（即产出 100M tf@4=0.9726 的那条配方）⇒ 已立 ENG2
6. **近 OOD 判决腿的方差量化（ticket 42-W2，同配置 n=3 独立重训）**：该腿（单查询关联回忆、距离 241–255、**超训练上限 240**）三跑 **0.928 / 6.934 / 11.768%** ⇒ **极差 10.840pp ≥ 结论效应 3pp** ⇒ **永久降级为辅助腿**（已写入账本）；**对照：训练分布内腿（多查询、距离 107–240）三跑 35.718 / 36.939 / 36.206%、极差仅 1.221pp（< 1.4pp 方差带）** ⇒ 任务本身可用，降级只针对超训练距离档——**§17.18 由此获得实证**。n=3 小样本、6k 未收敛、快照口径、禁外推；另设「同 seed 第二跑」参照臂验证方差来自**训练运行本身**而非 seed 标签
7. **三补点（ticket 41-Z2）**：① **容量括号 + 插值**——任务腿上容量是**平的**（±11.6% 参数 ⇒ 变化 0.10–0.45pp ≪ 1.4pp 带），GQA 相对「插值到同参数的 MHA」只高 0.27–0.53pp（不可排序）⇒ **「参数少」不是 GQA 差距的解释**；但 clean bpc 轴上括号**不平**（GQA 差 +16.4 bpc）⇒ 口径分歧**已显式写出**（未读成「等参数下 GQA 更优」）；② **无泄漏 Q=7**：上轮末块 Q=K 消除泄漏被量清——整体读数 35.0–36.2% → **26.1–27.3%**（−8.7~−8.9pp，CI 不重叠），但 Q=7 末块仍有 **+25.5~+30.6pp 残余抬升** ⇒ 报告采最保守口径（**前 6 块 22.1–22.9%**），**未**称「完全无泄漏」；③ **carry 增益保持**：6k 的 +15.527pp → 10k 的 **+14.697pp**（−0.830pp，不可排序 ⇒ 保持），两点均为快照。550 项对账全过；pytest 468
8. **搬运 × 压缩的质量腿（ticket 41-Z3）**：**评测期 int8 与 fp16 的召回逐位相同（0.928%→0.928%，命中 19/2048 一致）** ⇒ **int8 不破坏 GQA+carry 通道**（确定性评测、同一权重）；次要项 GQA vs MHA 两条腿相反（近 OOD −3.03pp / 同分布 +0.90pp）⇒ n=1、不可排序、且含 −8.58% 参数混杂。**方法学发现**：该近 OOD 腿（距离 241–255 > 训练上限 240）同配置两次独立训练差 **15×**（0.93% vs 15.33%），四类解释（仪器/配置/能力/接线）逐一排除 ⇒ 该腿**不得作主判据**（已立 §17.18）；下一步 = 两臂 seed=1 复现量化方差
9. **ENG1 解锁的四臂阶梯（ticket 40-Y1，6k 步 / 49M token 臂间严格相等；stock / +GQA / +GQA+carry / +GQA+carry+window）**：**GQA 近乎免费**（参数 −8.748%，两腿增量 CI 重叠：判定腿 +0.146pp、分布内腿 +0.91pp）；**carry 通道在「距离外推腿」上贡献 +15.527pp（CI 不重叠）**、净 +15.332pp；**窗口 −0.342pp（CI 重叠 ⇒ 有通道时不额外伤）**。**关键限定（执行者自报）**：判定腿的距离 241–255 **超过训练上限 240** ⇒ carry 的增益是**距离外推效应**而非分布内质量；分布内腿（无泄漏）四臂 25.7–27.1% **增量全部 CI 重叠、净 −0.279pp**；6k 为快照口径（答案 CE 斜率仍降）；clean bpc 对合成训练模型无意义。**未测**：GQA 的 §15 等参数对照、无泄漏 Q=7 任务、carry 双臂 12k 复跑
10. **容量轴在收敛后重判（ticket 37-V2，3 臂 × 24k 步）**：**状态 4096→32768 浮点（×8）后答对率一动不动**——K=8 为 0.3686 vs 0.3677（Δ=−0.093pp，CI 重叠），四个难度档全部不可分辨；**U1 里唯一那个「容量效应」（大板 K=4 差 11pp）跑满步数后消失**（0.4218→0.5267，+10.49pp）⇒ 是训练伪影而非容量代价。门禁（答案行 CE 末窗斜率，按裁决口径）S16 −0.006963/1k、S128 −0.005449/1k 两臂都过；重跑散度 +0.22pp（CI 重叠）；毁源对照 12 格全 ≈chance ⇒ 作废 0 格。⇒ U1 的结论**加固**为「该任务/该尺度上状态 16→128 不划算」（§19），**不是**「容量不可能」
11. **容量×难度曲线（ticket 36-U1）**：难度曲线成立——K=4/8/16/32 准确率 0.535/0.366/0.107/0.056（分别 34.2×/23.4×/6.9×/3.6× chance），相邻档 95% CI 两两不重叠，**8→16 有明显拐点**（跌 25.8pp，而 16→32 仅跌 5.1）；**容量曲线不成立**——状态维度 4096→32768（×8）在 K=8/16/32 上准确率几乎不动（0.0573/0.0563/0.0563/0.0578，CI 全重叠），K=4 上最大状态反而更差（0.422 vs 0.531，−11pp，原因未定论）；四臂到 1 万步**均未收敛**（loss 斜率 −0.065~−0.051）⇒ 最可能是**瓶颈在训练而非容量**；按 SCHEMA §19 只能读作「该尺度加大状态不划算」，**不得**外推为「容量机制不可能」。活性已证：状态浮点随开关 4096→32768 精确变化、读出占比 0.67–0.75、**毁源后 16 格全部掉回 chance（最大 0.0173 vs 0.0156）**
12. **搬运 × KV 压缩叠加（ticket 38-W3，评测期、复用 ticket 35 的 U2 检查点）**：**int8 KV 不破坏搬运通道**——召回 Δ(int8−fp16) = **−0.098pp（CI 重叠，未过「崩」阈值 −3pp）**、字节/位置 12288→6144（−50%）、毁源后各模式掉到 0.73%（< chance）、量化活性 rel_err 1.76e-4→4.36e-3；**GQA/MQA/int4 因子本轮未测**（当时引擎硬互斥：`carry_rule ⊕ n_kv_heads<n_heads`、`n_kv_heads<n_heads ⊕ train_window>0`），禁止外推；**该限制已在 ticket 39-X2（ENG1）解除**——KV 头投影已解耦为 `KVHeadProjectionMixin`、窗口掩码改为正交装饰层、新增 `ComposableBlock`，三者可组合（缺省逐位还原 v1，394 测试绿）⇒ 组合的质量实验已列入下一步
13. **训练信号（ticket 36-U2，见 F4）**：重建/充分性损失被完美学会（重建命中 ≈1.00）但**长程回忆一点没长**（有 λ=1.0 0.0137 vs 无 λ 0.0161，−0.244pp、CI 重叠；重跑 4096 次提问 **0 命中**）⇒ 该尺度上「给路径（显式写通道 0.0950）」远优于「给信号（重建损失）」
14. **ticket 35 的边界**：绝对水平仅 9.5%（13M/12k 步）⇒ 只能读作「在该任务/该尺度上成立」；**plain 写（U1）双稳态**（同配置同 seed 两次 0.0007 vs 0.0334，答案行 CE 4.184 vs 2.252，重跑散度 +3.271pp）⇒ 判据③只在「两支 plain 读数」上成立，**强表述（delta 优于 plain）不作为结论**；距离曲线受训练位置结构混杂；未做 ④ 训练信号（重建/充分性损失）与 ③ 容量压力（更小状态）
15. **因果性护栏（本设计最致命的风险）已钉死**：分块 WY 形与顺序参考在 fp64 下 <1e-12 逐位一致（chunk ∈ {1,2,3,5,8,24}）、扰动 t≥10 时 t<10 输出 `torch.equal`、读后写约定有专测、变异 M1（释放块内 mask 造成未来泄漏）被抓住
