# M1-carrier-type · 状态载体类型

> 轴：**M 状态载体** ｜ 状态：**✅ judged**

> **判读**：**入口判读（本格当前结论，本地实测）**：
1. **通道活着且被读**：真实文本口径下 `read_share` 0.30–0.42、读出增益已逃离单边零、同权重关掉通道前向偏差 0.46、且关掉后 bpc 从 1.625 崩到 4.51。
2. **敏感度（必要条件）成立**：把被评行 ≥180 个位置之前的前缀毁掉，无通道臂被评行 logits **逐位不变**（前提①），带通道臂 `Δbpc_far = +0.0158 / +0.0141`（配对聚类 CI 排除 0、> 本格自测 `σ_far=0.0017`），通道消融后恰好归零 ⇒ 「信息被搬到现在」在**真实文本**口径上成立——注意这是**敏感度（必要条件）**，不是收益、也不是可检索。
3. **质量收益 ≈0.2%，且一个种子的配对 CI 跨 0**：窗口 16 口径 clean bpc 1.6281/1.6291 → 1.6249/1.6266（Δ = +0.0031 / +0.0025 bpc，两种子同号、> 本格 `σ_cell=0.0017`；seed1 配对 CI [−0.0004, +0.0054]）。
4. **可检索性未证**：真实文本短语针（needle v3）整体 `beyond` 桶「植入 vs 配对无针地板」差 ±0.05~0.16pp（CI 跨 0）；仅在「四臂无针地板**全部**答不出」的**同索引硬子集**（n=2974）上通道臂高 **+1.379pp [0.717, 2.041] / +1.042pp [0.380, 1.705]**（绝对水平 2.42%/2.53% vs 1.04%/1.21%，约 2.2×）。⇒ 措辞是「**弱证据、未证**」，**不写**「通道能检索」、也**不写**「可检索性不成立」。

**适用域与禁外推**：enwik8 真实文本 / 13M 稠密主干 / 窗口 16 + 锚点 0 / 12k 步（98.3M token）快照 / delta 写这一种写入规则。真实文本的局部先验本来就能补全绝大部分（窗口 16 模型训练末 loss 1.055 nat ≈ 1.52 bit/byte）⇒ 搬运的价值本来就小（SCHEMA §19 的局部先验抗性在真实文本上被直接量到）。

**感受野边界（对本格此前说法的更正）**：窗口 16 的 **12 层**模型，其跨层多跳感受野是 `L·(w−1) = 180`（`rf_scan.json` 实测：首个逐位不敏感行 243，公式上界 244）⇒ 合成腿的距离档 107–240 里 **107–180 可达（74/134 ≈ 55%）、181–240 不可达**；越界辅助腿 **241–255 仍不可达**。**可达 ≠ 可检索**（多跳只是传播：12 层无通道臂在 2631 上仍是 chance 1.55–1.65%）。因此「窗口 16 ⇒ 窗外内容 100% 看不见」不准确，机制解释应写成「**信息可达（需学习中转）但用不上**」。

**合成口径三种子判决**：`delta − none` 跨种子稳健（+34.927 / +34.323 / +35.080pp，配对 CI 下界 > 0，极差 0.757pp）；**`delta − plain` 不成立**（+0.369 [−0.150, +0.900] / +34.064 / +35.187，极差 **34.818pp**）——机制是 **plain 双稳态**（三跑 36.108 / 1.907 / 1.498%，塌回地板 2/3，Wilson [0.208, 0.939]；仅 seed0 学到），delta 稳定（36.478 / 35.971 / 36.685%，极差 0.714pp），逐种子最好臂 3/3 = delta。**判据的正确形式是「方向一致性 / 塌回地板比例」**：把「delta 比 plain 高 3pp」当**均值**问题需 ≈689 个种子（超出一个批次的预算），把「塌回比例」估到 ±20pp 约需 **≈20 个种子**；而方向一致性 **n=3 已足以证伪**「一贯优于」。

**递归/线性载体（载体枚举里的第 2 类）**：该**实现**在该**配置**下**不可训练（数值发散）**——3000 步里 **1854 步被梯度门跳过**（`gnorm_max` 5.7e8、`den_min` 触 clamp 1e-6、`state_norm` 476），质量腿读数（stock 1.7704 vs linear 5.9238 bpc）只能作**发散步**参考。**可复用教训**：「**日志停写 ≠ 进程停摆**」——训练器只在**未被跳过的步**写日志，步数对账（1854+1146=3000）与终点产物证明进程其实跑完；这条同时是 2616「实现层停摆」判定的**待复核假设**。另：「窗口 + 线性载体」组合因引擎硬互斥（`attn_linear ⊕ train_window`）**不可测**；「线性注意力这一族可不可行」的权威叙事在 A 轴（A6 / `2637-linear-attn-quality`）。

**历史本地读数（保留，明细见 §9 复现手段）**：ticket 35 首验「delta 写 6.08× chance」主腿在训练分布外（已永久降级为辅助腿）、绝对水平仅 9.5%；ticket 47-W1/W2 唯一跨种子稳健的是**出口资产保持**（−0.98 / +0.11pp 带内），而越界腿与分布内召回在 n=2 下均不稳健；ticket 44-X2 的 carry×depth 2×2 在召回目标上可加、但 tf@4 交互项 −6.06pp；ticket 41-Z2 无泄漏 Q=7 口径下 6k→10k 的 carry 增益保持（+15.527 → +14.697pp）；ticket 36-U1/U2 里难度曲线成立、容量与重建信号不成立；ticket 41-Z3 评测期 int8 不破坏搬运通道。**这些读数都是快照口径、只在各自的任务/尺度上成立。**

- **判读**：**入口判读（本格当前结论，本地实测）**：
1. **通道活着且被读**：真实文本口径下 `read_share` 0.30–0.42、读出增益已逃离单边零、同权重关掉通道前向偏差 0.46、且关掉后 bpc 从 1.625 崩到 4.51。
2. **敏感度（必要条件）成立**：把被评行 ≥180 个位置之前的前缀毁掉，无通道臂被评行 logits **逐位不变**（前提①），带通道臂 `Δbpc_far = +0.0158 / +0.0141`（配对聚类 CI 排除 0、> 本格自测 `σ_far=0.0017`），通道消融后恰好归零 ⇒ 「信息被搬到现在」在**真实文本**口径上成立——注意这是**敏感度（必要条件）**，不是收益、也不是可检索。
3. **质量收益 ≈0.2%，且一个种子的配对 CI 跨 0**：窗口 16 口径 clean bpc 1.6281/1.6291 → 1.6249/1.6266（Δ = +0.0031 / +0.0025 bpc，两种子同号、> 本格 `σ_cell=0.0017`；seed1 配对 CI [−0.0004, +0.0054]）。
4. **可检索性未证**：真实文本短语针（needle v3）整体 `beyond` 桶「植入 vs 配对无针地板」差 ±0.05~0.16pp（CI 跨 0）；仅在「四臂无针地板**全部**答不出」的**同索引硬子集**（n=2974）上通道臂高 **+1.379pp [0.717, 2.041] / +1.042pp [0.380, 1.705]**（绝对水平 2.42%/2.53% vs 1.04%/1.21%，约 2.2×）。⇒ 措辞是「**弱证据、未证**」，**不写**「通道能检索」、也**不写**「可检索性不成立」。

**适用域与禁外推**：enwik8 真实文本 / 13M 稠密主干 / 窗口 16 + 锚点 0 / 12k 步（98.3M token）快照 / delta 写这一种写入规则。真实文本的局部先验本来就能补全绝大部分（窗口 16 模型训练末 loss 1.055 nat ≈ 1.52 bit/byte）⇒ 搬运的价值本来就小（SCHEMA §19 的局部先验抗性在真实文本上被直接量到）。

**感受野边界（对本格此前说法的更正）**：窗口 16 的 **12 层**模型，其跨层多跳感受野是 `L·(w−1) = 180`（`rf_scan.json` 实测：首个逐位不敏感行 243，公式上界 244）⇒ 合成腿的距离档 107–240 里 **107–180 可达（74/134 ≈ 55%）、181–240 不可达**；越界辅助腿 **241–255 仍不可达**。**可达 ≠ 可检索**（多跳只是传播：12 层无通道臂在 2631 上仍是 chance 1.55–1.65%）。因此「窗口 16 ⇒ 窗外内容 100% 看不见」不准确，机制解释应写成「**信息可达（需学习中转）但用不上**」。

**合成口径三种子判决**：`delta − none` 跨种子稳健（+34.927 / +34.323 / +35.080pp，配对 CI 下界 > 0，极差 0.757pp）；**`delta − plain` 不成立**（+0.369 [−0.150, +0.900] / +34.064 / +35.187，极差 **34.818pp**）——机制是 **plain 双稳态**（三跑 36.108 / 1.907 / 1.498%，塌回地板 2/3，Wilson [0.208, 0.939]；仅 seed0 学到），delta 稳定（36.478 / 35.971 / 36.685%，极差 0.714pp），逐种子最好臂 3/3 = delta。**判据的正确形式是「方向一致性 / 塌回地板比例」**：把「delta 比 plain 高 3pp」当**均值**问题需 ≈689 个种子（超出一个批次的预算），把「塌回比例」估到 ±20pp 约需 **≈20 个种子**；而方向一致性 **n=3 已足以证伪**「一贯优于」。

**递归/线性载体（载体枚举里的第 2 类）**：该**实现**在该**配置**下**不可训练（数值发散）**——3000 步里 **1854 步被梯度门跳过**（`gnorm_max` 5.7e8、`den_min` 触 clamp 1e-6、`state_norm` 476），质量腿读数（stock 1.7704 vs linear 5.9238 bpc）只能作**发散步**参考。**可复用教训**：「**日志停写 ≠ 进程停摆**」——训练器只在**未被跳过的步**写日志，步数对账（1854+1146=3000）与终点产物证明进程其实跑完；这条同时是 2616「实现层停摆」判定的**待复核假设**。另：「窗口 + 线性载体」组合因引擎硬互斥（`attn_linear ⊕ train_window`）**不可测**；「线性注意力这一族可不可行」的权威叙事在 A 轴（A6 / `2637-linear-attn-quality`）。

**历史本地读数（保留，明细见 §9 复现手段）**：ticket 35 首验「delta 写 6.08× chance」主腿在训练分布外（已永久降级为辅助腿）、绝对水平仅 9.5%；ticket 47-W1/W2 唯一跨种子稳健的是**出口资产保持**（−0.98 / +0.11pp 带内），而越界腿与分布内召回在 n=2 下均不稳健；ticket 44-X2 的 carry×depth 2×2 在召回目标上可加、但 tf@4 交互项 −6.06pp；ticket 41-Z2 无泄漏 Q=7 口径下 6k→10k 的 carry 增益保持（+15.527 → +14.697pp）；ticket 36-U1/U2 里难度曲线成立、容量与重建信号不成立；ticket 41-Z3 评测期 int8 不破坏搬运通道。**这些读数都是快照口径、只在各自的任务/尺度上成立。**

## 5. 失败路径与原因

1. 早期缓存 bug：逐位置早退导致 per-layer cache 长度失步（已修为 per-layer 位置列表；持续单测）
2. **长程检索能力缺席（ticket 34-A 仪器实测）**：关联回忆 0.0061、变距离回忆六档 0.005–0.010，均≈或低于 chance 且无距离依赖 ⇒ 此前所有「没搬」读数，至少相当部分来自**模型本来就没有该能力**，而非「机制搬不动」（SCHEMA §19）
3. **仪器落地（`tools/evalkit/longrange_tasks.py`）**：四任务 + chance/局部先验基线 + 距离曲线 + `recall_under_visibility`（复用 retention 掩码）+ 毁源对照臂；自证：局部先验基线 0.0098–0.0217（chance 上限 0.0469）、毁源/打乱答案均掉回 chance、前向逐位一致
4. 不确定项：induction 每点 n=128 不支持斜率；assoc/var 低分含分布外成分（**不得**外推成「训练也学不会」）；copy 13% 的机制未定位
5. **同口径判决 + 跨种子复现（ticket 47-W1/W2）**：① **出口资产（同口径：enwik8 训练 + enwik8 评测）**：`base 0.9711 → carry 0.9635`，**Δ = −0.76pp（带内 ⇒ holds）**、tf@6 −0.10pp ⇒ **「carry 不弄坏出口资产」在正确口径下成立**；反口径诊断（enwik8 训练模型评 synth）为 −28.89pp ⇒ 46-W1 的「两口径相反」是**跨分布伪影**（两个内分布口径都保持，两个偏移分布口径都退化）。② **跨种子复现（n=2）⇒ 越界腿与分布内召回结论均不成立**：越界腿 seed=0 **+6.05pp**（CI [4.67,7.44]）vs seed=1 **−2.44pp**（CI [−3.67,−1.22]）⇒ **差 8.50pp > 效应本身**，「通道在搬」**降级为单种子观测**；分布内召回 seed=0 +0.36pp（CI 跨 0）vs seed=1 **−3.26pp**（显著）⇒ 「通道对召回冗余」**在 n=2 下不成立**。**唯一跨种子稳健的 = 出口资产保持**（−0.98 / +0.11pp 均在带内）。附带：46-W1 的「enwik8 红灯」被证为**代理噪声**（同一基准臂换 seed 自身从 93.69→68.88，差 24.81pp）；seed=1 的 carry 臂更欠拟合（答案 CE 3.18 vs 2.56）⇒ 负 Δ 可能部分属收敛问题，**已如实标注、未当纯机制结论**
6. **ENG2：carry 现可跑非 dense ragged 路径（ticket 45-E1，引擎级）**：解耦 `carry` 的 `dense=True` 硬校验，让写入通道在 **ragged / 随机退出 / fill / proj-fill** 路径可用，并定义**混合填充语义下的写入时机**；缺省路径逐位还原 v1（549 测试绿、变异 M1–M5 抓红且逐字节还原、20 步 GPU 冒烟 `non-dense + carry delta + proj_fill + uniform exit` 通过、峰值 861 MB）。⇒ **产品上真正有意义的那对「carry × 随机退出 × proj-fill」（100M tf@4=0.9726 的配方）从此可测**。**未解**：增量解码（`DepthARDecoder`）显式拒绝 carry ⇒ 解码侧通道是下一步；`carry × GQA × non-dense` 仍不可测
7. **搬运 × 深度监督首次同台（ticket 44-X2，13M 2×2 四格、同数据同步数同 seed；深度因子因引擎互斥降为 `--dense-aux`）**：主腿（训练分布内多查询关联回忆，n=16384/臂、chance 1.56%）= base **1.48%** / carry **35.78%** / depth **1.47%** / both **36.16%** ⇒ ① **carry 一开成绩 ×24（+34.30pp，CI 不重叠）**；② **浅层监督单独对召回毫无作用（−0.006pp）**；③ **2×2 交互项 +0.385pp（落在 1.4pp 预登记阈值内；**1.4pp 为**预登记实用阈值**、非已测准确率方差）⇒ 在召回目标上两资产可加、不打架**（判据⑤「负增量」未触发）；④ **出口资产 tf@4（分布内）**：87.84（base）→ **99.84%**（仅 depth）；两者同开 94.47% ⇒ **tf@4 交互项 −6.06pp（通道在开会吃掉一小块出口）**；⑤ **质量代价**（enwik8 跨分布）55.07 / 52.36 / **125.74** / **1322.98** bpc ⇒ 浅层监督在真实文本上代价极大。**未测因子（禁外推）**：ragged 随机退出 + proj-fill 的冻结/混合 KV 语义（即产出 100M tf@4=0.9726 的那条配方）⇒ 已立 ENG2
8. **近 OOD 判决腿的方差量化（ticket 42-W2，同配置 n=3 独立重训）**：该腿（单查询关联回忆、距离 241–255、**超训练上限 240**）三跑 **0.928 / 6.934 / 11.768%** ⇒ **极差 10.840pp ≥ 结论效应 3pp** ⇒ **永久降级为辅助腿**；**对照：训练分布内腿（多查询、距离 107–240）三跑 35.718 / 36.939 / 36.206%、极差仅 1.221pp（< 1.4pp 预登记阈值）** ⇒ 任务本身可用，降级只针对超训练距离档——**§17.18 由此获得实证**。n=3 小样本、6k 未收敛、快照口径、禁外推；另设「同 seed 第二跑」参照臂验证方差来自**训练运行本身**而非 seed 标签
9. **三补点（ticket 41-Z2）**：① **容量括号 + 插值**——任务腿上容量是**平的**（±11.6% 参数 ⇒ 变化 0.10–0.45pp ≪ 1.4pp 预登记阈值），GQA 相对「插值到同参数的 MHA」只高 0.27–0.53pp（不可排序）⇒ **「参数少」不是 GQA 差距的解释**；但 clean bpc 轴上括号**不平**（GQA 差 +16.4 bpc）⇒ 口径分歧**已显式写出**（未读成「等参数下 GQA 更优」）；② **无泄漏 Q=7**：上轮末块 Q=K 消除泄漏被量清——整体读数 35.0–36.2% → **26.1–27.3%**（−8.7~−8.9pp，CI 不重叠），但 Q=7 末块仍有 **+25.5~+30.6pp 残余抬升** ⇒ 报告采最保守口径（**前 6 块 22.1–22.9%**），**未**称「完全无泄漏」；③ **carry 增益保持**：6k 的 +15.527pp → 10k 的 **+14.697pp**（−0.830pp，不可排序 ⇒ 保持），两点均为快照。550 项对账全过；pytest 468
10. **搬运 × 压缩的质量腿（ticket 41-Z3）**：**评测期 int8 与 fp16 的召回逐位相同（0.928%→0.928%，命中 19/2048 一致）** ⇒ **int8 不破坏 GQA+carry 通道**（确定性评测、同一权重）；次要项 GQA vs MHA 两条腿相反（近 OOD −3.03pp / 同分布 +0.90pp）⇒ n=1、不可排序、且含 −8.58% 参数混杂。**方法学发现**：该近 OOD 腿（距离 241–255 > 训练上限 240）同配置两次独立训练差 **15×**（0.93% vs 15.33%），四类解释（仪器/配置/能力/接线）逐一排除 ⇒ 该腿**不得作主判据**（已立 §17.18）；下一步 = 两臂 seed=1 复现量化方差
11. **ENG1 解锁的四臂阶梯（ticket 40-Y1，6k 步 / 49M token 臂间严格相等；stock / +GQA / +GQA+carry / +GQA+carry+window）**：**GQA 近乎免费**（参数 −8.748%，两腿增量 CI 重叠：判定腿 +0.146pp、分布内腿 +0.91pp）；**carry 通道在「距离外推腿」上贡献 +15.527pp（CI 不重叠）**、净 +15.332pp；**窗口 −0.342pp（CI 重叠 ⇒ 有通道时不额外伤）**。**关键限定（执行者自报）**：判定腿的距离 241–255 **超过训练上限 240** ⇒ carry 的增益是**距离外推效应**而非分布内质量；分布内腿（无泄漏）四臂 25.7–27.1% **增量全部 CI 重叠、净 −0.279pp**；6k 为快照口径（答案 CE 斜率仍降）；clean bpc 对合成训练模型无意义。**未测**：GQA 的 §15 等参数对照、无泄漏 Q=7 任务、carry 双臂 12k 复跑
12. **容量轴（ticket 37-V2，3 臂 × 24k 步）**：**状态 4096→32768 浮点（×8）后答对率一动不动**——K=8 为 0.3686 vs 0.3677（Δ=−0.093pp，CI 重叠），四个难度档全部不可分辨；**U1 里唯一那个「容量效应」（大板 K=4 差 11pp）跑满步数后消失**（0.4218→0.5267，+10.49pp）⇒ 是训练伪影而非容量代价。门禁（答案行 CE 末窗斜率，按裁决口径）S16 −0.006963/1k、S128 −0.005449/1k 两臂都过；重跑散度 +0.22pp（CI 重叠）；毁源对照 12 格全 ≈chance ⇒ 作废 0 格。⇒ U1 的结论**加固**为「该任务/该尺度上状态 16→128 不划算」（§19），**不是**「容量不可能」
13. **容量×难度曲线（ticket 36-U1）**：难度曲线成立——K=4/8/16/32 准确率 0.535/0.366/0.107/0.056（分别 34.2×/23.4×/6.9×/3.6× chance），相邻档 95% CI 两两不重叠，**8→16 有明显拐点**（跌 25.8pp，而 16→32 仅跌 5.1）；**容量曲线不成立**——状态维度 4096→32768（×8）在 K=8/16/32 上准确率几乎不动（0.0573/0.0563/0.0563/0.0578，CI 全重叠），K=4 上最大状态反而更差（0.422 vs 0.531，−11pp，原因未定论）；四臂到 1 万步**均未收敛**（loss 斜率 −0.065~−0.051）⇒ 最可能是**瓶颈在训练而非容量**；按 SCHEMA §19 只能读作「该尺度加大状态不划算」，**不得**外推为「容量机制不可能」。活性已证：状态浮点随开关 4096→32768 精确变化、读出占比 0.67–0.75、**毁源后 16 格全部掉回 chance（最大 0.0173 vs 0.0156）**
14. **搬运 × KV 压缩叠加（ticket 38-W3，评测期、复用 ticket 35 的 U2 检查点）**：**int8 KV 不破坏搬运通道**——召回 Δ(int8−fp16) = **−0.098pp（CI 重叠，未过「崩」阈值 −3pp）**、字节/位置 12288→6144（−50%）、毁源后各模式掉到 0.73%（< chance）、量化活性 rel_err 1.76e-4→4.36e-3；**GQA/MQA/int4 因子本轮未测**（当时引擎硬互斥：`carry_rule ⊕ n_kv_heads<n_heads`、`n_kv_heads<n_heads ⊕ train_window>0`），禁止外推；**该限制已在 ticket 39-X2（ENG1）解除**——KV 头投影已解耦为 `KVHeadProjectionMixin`、窗口掩码改为正交装饰层、新增 `ComposableBlock`，三者可组合（缺省逐位还原 v1，394 测试绿）⇒ 组合的质量实验已列入下一步
15. **训练信号（ticket 36-U2，见 F4）**：重建/充分性损失被完美学会（重建命中 ≈1.00）但**长程回忆一点没长**（有 λ=1.0 0.0137 vs 无 λ 0.0161，−0.244pp、CI 重叠；重跑 4096 次提问 **0 命中**）⇒ 该尺度上「给路径（显式写通道 0.0950）」远优于「给信号（重建损失）」
16. **ticket 35 的边界**：绝对水平仅 9.5%（13M/12k 步）⇒ 只能读作「在该任务/该尺度上成立」；**plain 写（U1）双稳态**（同配置同 seed 两次 0.0007 vs 0.0334，答案行 CE 4.184 vs 2.252，重跑散度 +3.271pp）⇒ 判据③只在「两支 plain 读数」上成立，**强表述（delta 优于 plain）不作为结论**；距离曲线受训练位置结构混杂；未做 ④ 训练信号（重建/充分性损失）与 ③ 容量压力（更小状态）
17. **因果性护栏（本设计最致命的风险）已钉死**：分块 WY 形与顺序参考在 fp64 下 <1e-12 逐位一致（chunk ∈ {1,2,3,5,8,24}）、扰动 t≥10 时 t<10 输出 `torch.equal`、读后写约定有专测、变异 M1（释放块内 mask 造成未来泄漏）被抓住
