## 0. 人话摘要（先看这段）

我们想知道：**让模型额外带一个「固定大小的本子」，把远处看到的东西写进去、需要时再翻出来，
到底有没有用？如果写的时候「先把同一个键的旧笔记擦掉再写新的」（delta 写），是不是比「闷头
往上叠」（plain 写）更靠谱？**

- **带本子有没有用：有，而且很稳。** 不带本子的模型在这个「多查询关联回忆」任务上只会瞎猜
  （答对 1.55% / 1.65%，而随机猜是 1.5625%——两者是一回事）。带本子的两支都能答对约 **36%**，
  比瞎猜高 **约 34.5 个百分点（pp）**，两个随机种子都是这个数（36.5% / 36.0%）。
  这就是「显式搬运通道有效」的直接证据，而且是**训练分布内**量的（见 §4）。
- **delta 写是不是一贯比 plain 写好：不是。** 在种子 1 上 delta 大胜 plain（35.97% vs 1.91%，
  高 34.1pp）；但在种子 0 上两者**打平**（36.48% vs 36.11%，只差 0.37pp，统计上分不出来）。
  所以预登记的「delta 一贯显著优于 plain」判据 **不成立**。
- **那谁最好？两个种子上都是 delta**（种子 0 只以 0.37pp 领先，落在噪声内；种子 1 大幅领先）。
  所以 2618「delta 是稳定有效的那一支」**不予推翻**，但要**说清它稳在哪**：
  **delta 跨种子几乎不动（36.48%→35.97%，极差 0.51pp），plain 会塌（36.11%→1.91%，极差 34.2pp）。**
  真正的差别是「plain 时好时坏（双稳态），delta 不会塌」，而不是「delta 每次都明显赢 plain」。
- **读数是真的来自「远处内容」吗：是。** 把要搬的源内容换成随机符号后，所有臂都掉回瞎猜
  （≈1.5%，见 §6）——说明 36% 的成绩确实来自「从远处搬信息」，不是位置规律或局部先验。
- **一句话答案（必答）**：跨两个种子，**「delta 写优于 plain」不成立为稳健结论**（种子 0 打平、
  配对 95% 置信区间跨 0）；**「delta 写优于无通道」成立**（+34.9/+34.3pp，CI 下界 > 0）。
  合取起来「delta 写优于 plain/无通道」**不成立**——但请拆开读：**delta 仍是三臂中最稳、
  且两种子上都是最好的那一支**，只是它相对 plain 的优势不稳定。

## 1. 六个必答问题

1. **它是干什么的**：给 transformer 加一个**固定大小的显式记忆槽**——模型把每个位置看到的内容
   （键 = 方向、值 = 内容）写进这个槽，之后需要回忆远处的键值对时，直接从槽里读出来，而不依赖
   局部注意力窗口（本装置窗口只有 16，看不到远处的键值表）。
2. **相对普通 decoder-only transformer 改了什么**：基线是标准稠密 decoder-only（tied 读出、
   无 final LayerNorm、顺序残差，13.5M）。通道臂在**每一层**加一个读出增益 `γ_ℓ`（零初始化）
   和**共用的一本记忆槽** `S`（8192 个数，与序列长度无关）：
   - plain 写：`S_t = S_{t−1} + β_t v_t k̂_tᵀ`（累加）；
   - delta 写：`S_t = S_{t−1}(I − β_t k̂_t k̂_tᵀ) + β_t v_t k̂_tᵀ = S + β(v − S k̂)k̂ᵀ`
     （写之前先把槽里同一个键的旧分量扣掉）。
   参数量 +264,296（13.54M → 13.80M，+1.95%）；计算量只多一个 8192 规模的状态更新，
   **与 T 无关**。两臂**逐字段同配方、逐位等参数**，唯一差别是上面的更新式。
3. **为什么要改**：有限容量的记忆在「同一个键反复出现」时会互相干扰——纯累加写会把同一键的
   新旧值叠在一起。delta 写先把旧的扣掉，理论上给出「替换」而非「叠加」的语义，容量利用率更高
   （DeltaNet 一系，prior art 见 README §8）。本线**不是**提新机制，而是问：**这条结论在我们的
   装置上跨随机种子稳不稳**——2618 只跑过 1 个种子，且首验主判据落在训练分布外。
4. **怎么测的**：**唯一变量 = 写入规则 × 随机种子**（6 臂 = 3 规则 × 2 seed，其余逐字段一致）。
   主腿 = **训练分布内**的多查询关联回忆（`assoc_recall_multi_batch`，K=8/Q=8/gap=14，与训练
   同一生成器，被问键值对距离 107–240 ≤ 训练上限 240），64 批 × 64 序列 × 8 查询 = 32768 次提问；
   生成器种子与模型种子无关 ⇒ 六臂**在同一批位置被问同一批问题（配对可比）**。
   指标 = 答对率（越低↔越高：越高越好）。统计口径：**主 CI = 按序列聚类的 bootstrap**
   （复核 B2：同一条序列的 8 个查询共享同一份 KV/记忆状态，不是独立二项样本）+ **配对聚类
   bootstrap** 算臂间差；每条查询的 Wilson CI 只作**偏窄对照**。对照组 = 无通道臂（基线）+
   plain 写臂（诚实对手，等参数）+ 毁源对照（把源内容打乱）。
5. **测出来多少**：见 §4/§5 的表。参照系就是本装置内的三条线：**瞎猜 1.5625%** / **无通道
   基线 1.55–1.65%** / **带通道 36%**。人话量级：带通道把「几乎完全不会」提到「三分之一强会」，
   而 delta 相对 plain 的**稳定性**差异（极差 0.51pp vs 34.2pp）比它们的**平均优劣**更站得住。
6. **结论与下一步**：见 §11。一句话：**「显式搬运通道有效」跨种子成立；「delta 一贯胜过 plain」
   不成立；但 delta 是三者中最稳、且两种子上都最好的那一支。** 下一步要把 plain 的双稳态
   用**更多种子**（≥4）钉死，并确认它在 2618 的配方下是否同样双稳。

## 5. 效应与跨种子稳健性（判据②③）

配对聚类 bootstrap（两臂重采样同一组序列索引），pp = 百分点（percentage point）：

| 对比 | seed0 Δ (CI) | seed1 Δ (CI) | 极差 | 同号 | 稳健？ |
|---|---:|---:|---:|:--:|:--:|

| `delta − plain` | +0.369pp [−0.150, 0.900] | +34.064pp [33.633, 34.509] | 33.695pp | ✅ | **❌ 不成立** |
| `plain − none` | +34.558pp [34.137, 35.013] | +0.259pp [0.055, 0.458] | 34.299pp | ✅ | （对照） |

| 臂 | seed0 | seed1 | 极差 | 均值 | 样本 sd(n−1) |
|---|---:|---:|---:|---:|---:|
| 无通道 | 1.550 | 1.648 | 0.098pp | 1.599 | 0.069 |

## 9. 自检 / 复现性 / 成本

- **仪器自检**：释放版（`is_causal`）vs 显式因果掩码 `max|Δlogit| = 0.0`；模型自带窗口掩码前向
  vs `masked_logits + keep` 掩码仪器 `max|Δlogit| = 0.0`（训练/评测同一件仪器）；
  窗口掩码非退化（可见对 3976 < 因果对 32896）；plain/delta **逐位等参数**（13801064，188 张量
  全同）；通道臂主干逐位 == 无通道臂（+264296 参数）；单边零起步（γ=0）logits 与无通道臂逐位相同。
- **复现性**：同权重、同批位置把主腿第一批再评一遍 ⇒ **逐位相同**（纯推理确定性）。
- **成本**：评测墙钟 **1.57 min**（含六臂加载 + 全电池），`n_forward_batches = 960`；
  评测峰值显存 **528.7 MB**；训练墙钟 8.57–15.79 min/臂（none/plain/delta），
  训练峰值显存 2015–2283 MB（**< 5GB net**，§20.3）。整程持锁 <10 min（§20.1 允许）。

## 11. 失败与局限（诚实清单）

1. **判据③不成立**：`delta − plain` 在 seed0 只有 +0.37pp（配对 CI[−0.15,+0.90] 跨 0）。
   这不推翻「delta 最好」，但**推翻**「delta 一贯显著胜过 plain」这一强读法。
2. **plain 双稳态**：seed0 36.11% vs seed1 1.91%。**n=2 不足以定量**其方差；极差 34.2pp 只是
   描述量，**不是方差上界**（诚实对照见 controls/README §4）。这正是需要 ≥4 种子钉死的地方。
3. **辅助腿（241–255）方差已知极大**：delta 9.96%/4.20%，**只作辅助**，不作任何结论。
4. **与 2618 不能称「同一次训练」**：`divergence_vs_2618.py` 显示同 seed=0 重训**非逐位复现**
   （max|Δloss|：none 0.0161 / plain 4.1523 / delta 0.0167），差异来源为**代码修订（ENG1/ENG2 之后）
   与训练非确定性**的混合，**不能单独归因**。故本线与 2618 是**两次独立观测**，不是复现。
5. **无参数量匹配的更大规模点**：只在 13M 一点上测；不外推到更大规模或别的任务。
6. **未测 2618 配方下的 plain 是否也双稳**：本线用「稠密 + 窗口 16」配方，与 2618/48-W2 的
   reagged（非稠密）配方不同，跨配方结论待补。

## 12. 禁外推声明

本结论只适用于：**该合成任务（多查询关联回忆）/ 该可见性（窗口 16 + 锚点 0）/ 13M 稠密主干 /
12k 步快照**。不得读成「业界做不到/做得到」，不得外推到真实文本、更大规模、别的窗口或别的
训练预算。Δ < 0.014（1.4pp）在仓库预登记口径下**不可排序**——本线出现的显著差异（≈34pp）
远大于该阈值；但 plain seed0 与 delta seed0 的 0.37pp **在此阈值内 ⇒ 不可排序**。
