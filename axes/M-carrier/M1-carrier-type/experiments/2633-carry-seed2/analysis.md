## 0. 人话摘要（先看这段）

**问题**：给模型一个「固定大小的本子」有用（这条上一轮已经量到），那**写本子的方式**哪种好？
「delta 写」= 写之前先把同一个键的旧笔记擦掉；「plain 写」= 闷头往上叠。上一轮只跑了
**两个种子**，结论是「delta 一贯更好**不成立**」，但说不清为什么、也说不出要多少种子才能判。

**这一轮把种子补到三个，判死了：**

- **三种子读数的原样**（同一个「不靠局部先验」的关联回忆任务，越高越好，瞎猜是 1.56%）：
  「无通道」三跑 1.55 / 1.65 / 1.61%；「plain 写」三跑 **36.11 / 1.91 / 1.50%**；
  「delta 写」三跑 **36.48 / 35.97 / 36.69%**。
- **「delta 写比无通道好」跨三个种子稳健成立**（+34.9 / +34.3 / +35.1 个百分点，配对置信区间
  都不含 0，跨种子极差只有 0.76pp）。
- **「delta 一贯优于 plain」不成立**（预登记判据③不通过）：种子 0 上两者打平（+0.37pp，
  置信区间跨 0），种子 1、2 上 delta 大胜（+34.1 / +35.2pp）——**极差 34.8pp**。
- **原因这次说清了：不是 delta 好得离谱，是 plain 会塌。** plain 在 3 个种子里有 **2 个**
  塌回瞎猜（1.91% / 1.50%），delta 三个种子**都在 36% 附近**（极差 0.71pp）。
  「三种子里哪一种最好」的答案是 **delta、delta、delta**（3/3）。
- **要多少种子才能判？（判据⑥）** 如果把「delta 比 plain 高 3pp」当**均值**问题，按 plain
  的跨种子散布（样本 sd ≈ 19.9pp）算，需要 **≈689 个种子**——**在预算内不可行**；
  但如果问的是「塌回地板的**比例**」或「方向一致性」，**n=3 已经足够证伪「一贯」**，
  要把它估到 ±20pp 也只需 **≈20 个种子**。⇒ 判据该写成「比例/方向」而不是「均值差」。
- **读数是真的搬来的吗**：把要搬的源内容换成随机符号后，所有高读数臂都掉回瞎猜
  （1.54–1.66%）⇒ 36% 确实来自「把远处内容搬过来」。

**一句话**：**「显式通道有效」跨 3 个种子稳；「delta 写一贯优于 plain 写」被证伪；
真正稳的差别是「plain 会塌、delta 不会」。**

## 1. 六个必答问题

1. **它是干什么的**：给 transformer 一个固定大小的显式记忆槽——把每个位置看到的
   （键 = 方向、值 = 内容）写进去，之后需要回忆远距离的键值对时直接读出来，不依赖
   局部注意力窗口（本装置窗口只有 16，远处的键值表看不见）。
2. **相对普通 decoder-only transformer 改了什么**：基线是标准稠密 decoder-only
   （tied 读出、无 final LayerNorm、顺序残差，13.54M）。通道臂每层加一个读出增益 `γ_ℓ`
   （零初始化）与**共用的一本记忆槽**（19200 个数… 见 §3 的解析口径：`H·dh·dh = 8192` floats）：
   - plain 写：`S_t = S_{t−1} + β_t v_t k̂_tᵀ`（累加）；
   - delta 写：`S_t = S_{t−1}(I − β_t k̂_t k̂_tᵀ) + β_t v_t k̂_tᵀ = S + β(v − S k̂)k̂ᵀ`
     （写之前先把槽里同一个键的旧分量扣掉）。
   参数量 +264,296（13.54M → 13.80M，+1.95%）；计算量只多一个与序列长度无关的状态更新。
   两个通道臂**逐位等参数**（同一组张量、只改更新式）。
3. **为什么要改**：有限容量的记忆在「同一个键反复出现」时会互相干扰——纯累加写会把同一键的
   新旧值叠在一起。delta 写先扣除旧分量，理论上给出「替换」而非「叠加」的语义
   （DeltaNet 一系，prior art 见 2631 README §8；`记忆·未核`）。
   **本线的问题不是「提机制」，而是「这条机制排序在种子方向上稳不稳、要多少种子才判得出」**。
4. **怎么测的**：**唯一变量 = 写入规则 × 训练种子**（九臂 = 3 规则 × 3 种子；seed0/1 六臂
   复用 2631，seed2 三臂本实验新训，§6 给复用证据）。主腿 = **训练分布内**多查询关联回忆
   （`assoc_recall_multi_batch`，K=8/Q=8/gap=14，被问键值对距离 107–240 ≤ 训练上限 240），
   64 批 × 64 序列 × 8 查询 = **32768 次提问/臂**；九臂在**同一批位置**被问同一批问题（配对）。
   指标 = 答对率；主 CI = **按序列聚类的 bootstrap**（复核 B2：同一序列的 8 个查询共享
   同一份 KV/记忆状态，不是独立二项样本），Wilson 只作偏窄对照；臂间差用配对聚类 bootstrap。
5. **测出来多少**：见 §4/§5 的表。参照系：瞎猜 1.5625% / 无通道 1.55–1.65% /
   带通道 1.5–36.7%（plain 双稳态、delta 稳）。
6. **结论与下一步**：见 §11。

## 6. 判据⑥：要多少样本才能判？（本实验新增）

1. **均值口径**（把「delta − plain ≥ 3pp」当均值问题）：用 plain 的样本 sd（19.865pp）
   代入 `n = ⌈2(z_{0.975}+z_{0.8})²σ²/Δ²⌉` ⇒ **≈689 个种子**；用 delta 的 sd（0.367pp）
   ⇒ **≈1 个种子**。两者的巨大反差正是「这个判据不该写成均值差」的证据。
2. **比例口径**（plain 的双稳态才是正确统计量）：三跑里塌回地板（< 4×chance = 6.25pp）的
   比例 = **2/3 = 0.667，Wilson 95% CI [0.208, 0.939]**；delta = 0/3（CI [0, 0.562]）；
   无通道 = 3/3（CI [0.438, 1.0]）。把这个比例估到 ±20pp 约需 **n ≈ 20 个种子**；
   估到 ±10pp 约需 **n ≈ 96**。
3. **方向一致性口径**：n=3 已足以**证伪**「delta 一贯优于 plain」（只要有 1 个种子上打平）。
   ⇒ **判据的正确形式是「每次都是最好的那支 / 塌回地板的比例」**，不是「均值差 ≥ 3pp」。
   （本实验不改判据③的判定，只把它为什么不可达写清楚；这是 §4a⑥ 的作用。）

## 11. 失败与局限（诚实清单）

1. **判据③不成立**是**结论本身**（不是失败）：三跑里种子 0 打平 ⇒ 「delta 一贯显著优于 plain」
   被证伪。**不推翻**「delta 是三种子里最好的那支」（3/3），但**推翻**强读法。
2. **plain 的双稳态只有 3 个样本**：塌回地板比例 2/3 的 Wilson CI 是 [0.208, 0.939]，
   **很宽**；「plain 会塌」的**比例**尚未定量。
3. **判据⑥的样本量估计建立在「跨种子近似正态、σ 由 n=3 估出」的未验证假设上**：
   只作规划量级，不作断言。
4. **与 2631 的 seed0/1 是两次独立观测（非复现）**：2631 已证「同 seed 重训非逐位复现」
   （`divergence_vs_2631`），本实验通过 §9 的两级实现等价证据保证**可比性**，但不声称逐位复现。
5. **只在 13M / 12k 步 / 稠密 + 窗口 16 / 合成任务上测**；`48/47-W2` 的**非稠密 ragged 配方**
   上 seed=1 分布内腿为 −3.26pp ⇒ **跨配方结论未测**。
6. **辅助腿（241–255）**方差极大（本实验三种子里出现一个 0.000），永久只作辅助。

## 12. 禁外推声明

本结论只适用于：**合成多查询关联回忆 / 窗口 16 + 锚点 0 / 13M 稠密主干 / 12k 步快照 /
