## 0. 「往右搬」在这份文档里指什么（先定义，防歧义）

**用户的目标**：模型在处理一段长上下文时，把「已经被看过的信息」主动**搬进一个更近、
更耐用、更省的载体**（固定状态 / 少量槽位 / 压缩摘要），从而**旧的历史前缀可以真丢掉**
而质量与可检索性不掉。用本项目的话说：**「丢了」，但「搬了」**（而不是「丢了就算了」）。

**本地现状的一条硬事实（决定了整份文档的出发点）**：
我们已经直接测过「靠训练注意力掩码逼模型只用近处」这条路，结论是**只丢不搬**——
`本地实测`：`axes/A-mixing/A9-old-info-retention/experiments/2615-window-trained-retention-13m/analysis.md`
（窗口 32 训练后，窗外针召回 0.4588 vs 无记忆地板 0.4545，差 **+0.0043**）；
`axes/M-carrier/M3-cross-step-assumption/experiments/2616-window192-trained-13m/analysis.md`
（窗口 192 训练后，**整段都在窗外的 494 根针差值恰好 0.000**）。
所以这份文档不再讨论「掩码逼出局部依赖」，而是设计**显式的搬运算子**。

**来源类型图例**（全文遵守）：
`本地实测` = 本仓库文件路径可查；`记忆·未核` = 我看不到链接，只能作**设计方向**，
**不得当判据**（SCHEMA §18）；`不确定` = 承认不知道，附「要查什么」。

## 1. 为什么现架构**不鼓励**「往右搬」

三个机制，每一个都对着一条本地实测数字。

### 1.1 梯度侧：直连注意力的信用分配路径**更短**，搬运是**额外的信息瓶颈**

当远处的源片段还在可见窗口里时，模型要回答「源片段的下一个字符」，**最短路径就是
直接让注意力读到源 KV**——一步可微、无中间损失。把它先写进一个固定状态、再从状态读出来，
等于**在信息通路上多塞一个瓶颈**：瓶颈只能丢信息、不能增信息，所以在只看最终 CE 的
目标下，**没有任何梯度会奖励「搬运」这件事**；反而状态写入算子的任何近似都会带来小代价。
证据：`本地实测` 2617 电池——模型**有**弱但真实的「直连复制」能力（复制任务 0.1333，
源片段放到距离 223 仍有 0.118），但**一旦源片段被毁掉就回 chance**（0.1333→0.0125），
说明这 13% 是**当场从可见源读的**，不是从任何「搬过来的状态」里取的。
`本地实测`：`axes/M-carrier/M1-carrier-type/experiments/2617-longrange-task-battery/analysis.md`。

### 1.2 容量侧：残差流是**无地址**的共享空间，远处信息没有专属写入位置

现架构只有一个残差流 + 无 final LayerNorm 的 tied 读出（`docs/design.md` 共享底座 #1）。
「往右搬」要求把某条具体的远处信息**存到一个不会立刻被冲掉的位置**；但残差流没有写地址，
新 token 的表示会把旧信息推走。两条读数刻画这个容量约束：

- `本地实测` 2614——删除**单个距离**的 KV 时，距离 ≥32 的 KV 代价 ≤0.0037 bpc（看似可丢）；
  但**累计**版本（把所有 ≥32 的 key 一起删）实测 **+0.212 bpc**，是单点读数的 **15 倍**
  （`axes/M-carrier/M2-carrier-compression/experiments/2615-retention-retrieval-leg-13m/analysis.md`）。
  ⇒ 信息**不是冗余到可以随便丢**，只是「删一条时别的 key 顶上」——说明没有任何单一位置
  是那条信息的**专属载体**。
- `本地实测` 2615——即便**全注意力**、一根针都不删，检索腿自己的动态范围也只有
  **25.4pp**（基线 0.687 − 无针地板 0.4331）：**43% 的召回本来就靠语言先验**。
  ⇒ 在这个尺度上，模型真正「搬运/存储」的净信息量很小，容量预算被语言先验吃掉了。

### 1.3 任务侧：enwik8 的局部先验**太强**，13M 又弱，**「不需要」压过「搬不动」**

按 SCHEMA §19 与用户 2026-10-01 洞察：越小越弱的模型对远距离 context 越不敏感，因为
大部分靠语言先验补强，从未涌现真正的长程需求。本批 A 线的合成电池把「任务类型」这个
混杂剥出来了（`本地实测` 2617 电池）：

| 任务类型 | 13M 零样本读数 | 读法 |
|---|---|---|
| 关联回忆（要记住 key→value 再去取） | **0.0061**（≈/低于 chance 0.0156） | 长程**检索/关联**完全缺席 |
| 变距离回忆（单对，六档距离） | **0.0052**（全档 ≈chance） | 同上 |
| 复制（远处片段原样搬出） | **0.1333**（距离 223 仍 0.118） | 长程**复制**弱但真实 |
| induction | **0.0586** | 弱且随距离衰减 |

⇒ **「没搬」不是全局结论**：靠「当场读源」就能完成的复制/induction 还有痕迹，
而需要「把 key 存住、后来按 key 取」的关联回忆彻底为零。**这正说明梯度与容量都偏向
「能当场读就别存」**——所以显式搬运要想成立，要么**给搬运一个训练信号**，
要么**把源拿掉、逼它必须存**（§2d / §2e）。

## 2. 显式鼓励「往右搬」的结构清单

**成本口径（全文统一）**：13M（d256×12 层）、12k 步、单卡共享 4090、**≤25 min**。
`本地实测` 步时锚：13M dense 12k 步 ≈ **6.5–8.4 min/臂**（`2614/2615/2616` 记录
39.0–42.1 ms/step）。故 25 min 预算内实操约 **2–3 臂**（含重跑）。
每臂判据默认走 2617 电池（关联回忆 / 变距离回忆为主腿，copy/induction 为辅助腿），
**每臂都必须带「毁源对照臂」**（§4）。

### (a) 单状态极限（固定状态 + 丢历史）

- **改什么**：用**固定大小的递归状态**取代（部分）KV——注意力不再回看历史 key，
  历史只经状态向前传。极端形态 = 单状态（如一个门控线性状态层）。
- **为什么可能有用**：它**物理上强制**「必须搬」（没有别的路），直接检验容量假设。
- **最小可判定实验**：把 12 层里 **k 层**换成「门控线性状态层 + 少量全注意力层」的混合，
  训 12k 步；扫 k∈{全状态, 半, 对照=全注意力}（2–3 臂）。
- **预期代价与收益**：代价 = clean bpc 税（`本地实测`：任何侵入主干的结构都先假定付税，
  playbook 定律 7）；收益 = 在 2617 关联回忆上从 ≈chance 抬到 **>chance 且能过源对照臂**。
- **如何证伪**：(i) 关联回忆仍 ≈chance；或 (ii) 关联回忆升了但**毁源对照臂不下降**
  （说明升的不是源信息、是位置/构造伪命中）；或 (iii) bpc 税吃掉全部收益。
- **既有做法**：`记忆·未核` 线性注意力 / SSM / Mamba / RWKV / RetNet 及其「混合少量
  注意力层」的收敛（Jamba/Zamba/Samba 等）；`Zoology/MQAR` 的「容量 vs 召回」曲线。

### (b) 有限槽位 + 显式写/读通道

- **改什么**：加 **M 个 d 维槽位**作为专用记忆；**写头**（从当前 hidden 生成写内容与门）
  与**读头**（cross-attention 读槽位）挂在主干外。槽位是**有地址**的，绕开 §1.2 的
  「无地址共享空间」问题。
- **最小可判定实验**：M∈{8,32} 两档 + 无槽位对照，同 seed 同步数（2–3 臂）；
  写门与读注意力是**旁路**（playbook 定律 7：旁路判断头实测零税）。
- **预期代价与收益**：代价 = 参数量增加需过 SCHEMA §15 等参数对照（用「同参数但去掉
  写/读通道」的对照臂）；收益 = 关联回忆过 chance + 可重建。
- **如何证伪**：槽位活性量（写门均值、读注意力熵、槽位使用率）若长期≈0 ⇒ 结构没被用；
  或等参数对照吃掉增益 ⇒ 增益来自容量/重参数化而非「搬运」。
- **既有做法**：`记忆·未核` NTM/DNC（可微外部记忆 + 读/写头 + 基于使用的分配）、
  Block-Recurrent Transformer（跨块递归状态）、RMT（memory token）。

### (c) LRU / 增量搬运 —— **delta 写入算子**（本文最贴近用户原话的一条）

**先纠正对应物**：上一轮情报（`2617-prior-art-memory/PRIOR_ART.md` §4，`记忆·未核`）
提出——用户说的「LRU / 只搬上次没搬的」，其严谨对应物**不是「驱逐调度」**
（哪块 KV 该删，`A10` 已在 13M/256 上测出净增益不存在，`本地实测`），
而是**状态写入算子**。把它形式化：

$$
S_t \;=\; S_{t-1} + \beta_t\,\bigl(v_t - S_{t-1}k_t\bigr)\,k_t^{\top},
\qquad y_t = S_t\,k_t
$$

- `S ∈ R^{d_k×d_v}` 是状态矩阵；`k_t,v_t` 是写键/写值（线性注意力的 key/value）；
  `β_t∈(0,1)` 是写门。
- **人话**：`S_{t-1}k_t` 是「状态现在已经能预测出的那部分 value」，`v_t − S_{t-1}k_t`
  是**残差**——**只把状态猜不出的那部分写进去**，猜得出的部分不重复占位。
  这就是「只搬上次没搬的」的机器版本。
- **为什么可能有用**：加法写入（plain）会把同一信息反复叠加、互相干扰；delta 写入
  用残差**去重**，在有限状态下提高有效容量——直接对准 §1.2。

**同参数 / 同 FLOPs 的线性对照（SCHEMA §15 硬要求）**：

| 臂 | 写入规则 | 参数 | 备注 |
|---|---|---|---|
| A：delta | `S ← S + β(v − Sk)kᵀ` | 读/写投影同尺寸 | 主臂 |
| B：plain 加法（**等参数**对照） | `S ← S + β v kᵀ` | **与 A 逐位同参数量** | 去掉残差修正项 |
| C：门控衰减（历史 X2 带内） | `S ← γ S + β v kᵀ` | 同上 | 次级对照 |

- **归因纪律**：若 A 与 B 的差 < 0.014（bpc 方差界）/ 或关联回忆差落在二项 CI 内，
  ⇒ 归因于**重参数化/容量**，**不得**归因于 delta 算子（SCHEMA §15）。
- **FLOPs 诚实说明**：delta 比 plain 多一次 `d_k×d_v` 的 matvec（算 `Sk`）。严格等 FLOPs
  需另设对照（如给 plain 臂加一次廉价线性步）；本设计**先做等参数对照**，
  并**同时报 FLOPs 差**，不假装两者同 FLOPs。
- **最小可判定实验**：A/B/C 三臂，12k 步，2617 电池（2–3 臂 ≈ 20–25 min）。
- **预期代价与收益**：代价 = clean bpc 税（先假定付税）；收益 = 关联回忆 / 变距离回忆
  过 chance，且**毁源对照臂掉回 chance**。
- **如何证伪**：A 不超过 B（等参数对照）⇒ delta 无额外贡献；或过 chance 但毁源不掉
  ⇒ 不是搬运；或关联回忆仍 ≈chance ⇒ 在该尺度/任务不划算（**不得**写「机制不可能」，
  SCHEMA §19）。
- **既有做法**：`记忆·未核` DeltaNet / Gated DeltaNet / DeltaProduct（约 2024–2025）
  把残差写入做成可并行训练，并报告在 MQAR/长程回忆上优于 Mamba-2 类；`不确定`具体数字。
  我们的增量 = 13M + 局部先验抗性任务 + 单因素受控（不是首次提出）。

### (d) 强制搬运的训练信号（重建 / 充分性损失）

- **改什么**：除主任务 CE 外，加一条**辅助损失**，逼模型「从搬过去的载体里重建被丢掉的
  内容」（重建 / sufficiency），从而**创造梯度**去奖励搬运（补 §1.1 的缺口）。
- **⚠️ 措辞纪律（SCHEMA §18）**：**这条路业界已有成熟前例，我们不得声称「无人占位」**。
  `记忆·未核`：Compressive Transformer（约 2019，压缩记忆 + **compression loss** 重建原始
  记忆——信心较高但**未核**）、AutoCompressors（约 2023，summary 向量重建）、
  ICAE（约 2024，slot 自编码）、RECOMP（约 2023，重建 vs 蒸馏）、DMC（约 2024，KV 压缩
  需继续训练/蒸馏）。我们的增量只能是：**13M + 局部先验抗性任务 + 单因素受控对照**。
- **最小可判定实验**：A/B 两臂——同 13M、同 seed、同数据，A = 纯 CE，B = CE + λ·重建损失；
  共 2 臂 ≈ 16 min。
- **预期代价与收益**：代价 = 额外解码路径算力/显存；辅助损失与主任务抢容量
  （playbook 定律 6「整形 vs 自适应是同一梯度的两面」的实例）；收益 = 搬运腿（窗口外/
  远处的可重建性）抬升。
- **如何证伪**：(i) 主任务 bpc 明显变差且搬运腿不升 ⇒ 只有反噬；
  (ii) 搬运腿升但**毁源对照臂不下降** ⇒ 学的是编造。
- **实现风险**：负/奖励类损失在 bf16 下**必须 float32 + pre-step grad-norm gate**
  （playbook 定律 5、SCHEMA §10）；本地先例 `F4` 的 consistency loss **中性**（`本地实测`）
  ⇒ 不能想当然有收益。必须做「λ=0 逐位等价」单测（SCHEMA §9）。
- **既有做法对应**：同上（Compressive Transformer / AutoCompressors / ICAE / RECOMP）。

### (e) 任务侧课程（把必将被丢的内容**后置提问**）

- **改什么**：不改模型，改任务时序——先给源信息，中间插入长 filler，**在源必然会被
  按预算丢掉之后再提问**；这样「当场读源」这条路被物理切断，**逼**模型必须搬运
  （与 2617 电池的变距离回忆同构，但把「预算」与「提问位置」做成可调）。
- **为什么可能有用**：它是 §1.3「不需要压过搬不动」的解药——把「需要」做成旋钮。
- **最小可判定实验**：复用 `tools/evalkit/longrange_tasks.py` 的任务接口，加「预算曲线」：
  横轴 = 源与提问之间的可见预算，纵轴 = 召回；同模型同 seed 对比训练前后（2 臂）。
- **预期代价与收益**：代价 ≈0（纯任务构造，纯推理）；收益 = 给 §2a–d 的所有臂一条
  **共用的、能分离「不需要」与「搬不动」的判据**。
- **如何证伪**：若在「源必然被丢」的构造上模型仍高于 chance 且**毁源不掉** ⇒ 任务被
  语言先验污染；或所有结构都掉回 chance ⇒ 该尺度不划算。
- **既有做法**：`记忆·未核` MQAR（把「需回忆的关联数」当旋钮）、RULER（变距离检索）。

## 3. 哪些结构会**破坏 `docs/design.md` 的三条共享底座**

三条共享底座（`docs/design.md` §2）：① tied 读出 + 无 final LayerNorm（同空间几何）；
② 变深度增量解码的填充语义；③ 全深度重打分的定稿不变量。逐条给风险：

| 设计 | 是否触碰共享底座 | 机制 |
|---|---|---|
| §2a 单状态替换若干层 | **部分风险** | 状态层若不再把表示留在 embedding 空间（例如内部维度/几何不同），破坏底座①的「同空间、skip=恒等」前提；跨**段**递归会与底座②的 KV 填充语义冲突 |
| §2b 有限槽位 + 写/读 | **高风险，需隔离** | 若槽位是**另一套几何**（独立 d_mem ≠ d_model）或在读出处强加 workspace 边界 ⇒ 直接命中底座①。`本地实测`/playbook 定律 7：「读出结构切分」实测**恶化 −50.4%**。**缓解**：槽位读写都经投影回到同一残差流，不新建读出边界 |
| §2c delta 写入算子 | **低风险（若载体是旁路）** | 作为**旁路**记忆/状态、读结果经投影 add 回残差流，可不动主干几何；若替换主干注意力层则回到 §2a 的税问题 |
| §2d 重建辅助损失 | **低风险（不改几何）** | 只加损失项，不动前向几何；风险在**优化**（负/奖励类，定律 5）而非底座，但注意 SCHEMA §17.1：不要把「需深度监督才存在的指标」写进 stock dense 判据 |
| §2e 任务课程 | **不触碰** | 纯任务构造 |

**判据**：任何新设计落地时，**必须显式声明它属于哪一列**，并写明若触碰底座①/②/③
打算如何避开（例如「槽位读写经 projection 回 embedding 空间」）。若有任何实验**回退
融合核或新建读出边界**，按 SCHEMA §17.8 预估内核回退倍数。

## 4. 先做哪两个（排序理由 + 预登记判据线草案）

排序 = **成本 × 信息量 × 与「往右搬」目标的相关性**。

### 🥇 首选：§2c delta 写入算子的单状态载体（A/B/C 三臂）

- **为什么第一**：① 它**直接形式化用户原话**（「只搬上次没搬的」），相关性最高；
  ② 是**纯写规则单因素**，有 SCHEMA §15 的等参数对照，归因干净；
  ③ 成本 2–3 臂可进 25 min；④ 即使失败也是干净的高信息负结论（区分「重参数化」与「算子」）。
- **风险**：需要线性注意力实现（可能离开 SDPA 融合核，SCHEMA §17.8 要预估回退倍数）。

### 🥈 次选：§2b+§2d 有限槽位 + 重建强制搬运（A/B 两臂）

- **为什么第二**：① 它直接回答「**只给信号、强制搬运，能不能造出搬运**」（补 §1.1 的
  梯度缺口）；② 旁路槽位实测零税，风险低；③ 2 臂 ≈16 min，最便宜；④ 重建损失虽有
  业界前例，但「接到**往右搬的载体**上 + 13M + 局部先验抗性任务」是我们的增量。
- **风险**：辅助损失可能只反噬主任务（`F4` 中性的先例）；必须过 λ=0 逐位等价单测。

### 预登记判据线草案（两个臂共用，**必须在跑之前写死**）

**主腿（局部先验抗性任务，SCHEMA §19）——用 2617 电池：**

- **主判据 P1（关联回忆）**：实验臂的关联回忆 top-1 准确率 **> 该臂 own chance 的 3 倍**
  且其 95% 二项 CI 下界 > chance（chance = 1/64 = 0.015625）。
- **主判据 P2（变距离回忆）**：六档距离的**加权均值** > chance 的 3 倍，且**至少 4/6 档**
  单独 > chance。**禁止**用单点外推（SCHEMA §17.11）。
- **辅助腿（copy / induction）**：只作**正向对照**——要求它们**不低于** 2617 零样本基线
  （copy 0.1333 / induction 0.0586）；若下降，说明结构损害了「当场读源」能力，附注。
- **源对照臂（**预登记的强制条件**，缺此则 P1/P2 一律不可采信）**：
  在关联回忆 / 变距离回忆上，用 `corrupt_span` **毁掉源片段**后，实验臂准确率
  **必须掉回 chance 带**（≤ max(3·chance, 0.02) = 0.046875）。若毁源后仍显著高于 chance
  ⇒ 判 P1/P2 **伪命中**（读的是位置/构造，不是搬来的信息）。
- **质量税对照**：clean bpc（每字符比特数，越低越好）相对同尺寸全注意力对照的 Δ；
  **Δ ≥ +0.050 ⇒ 记为「有显著税」**；|Δ| < 0.014 才可称「近零税」。口径 = 快照
  （matched-step 12k），并注明是否疑为收敛加速（SCHEMA §16）。
- **等参数守门（SCHEMA §15）**：§2c 的 delta 臂必须与 plain 加法对照**逐位同参数量**；
  差异 < 0.014 或落在二项 CI 内 ⇒ 判「归因重参数化，非算子」。
- **活性量（SCHEMA §10）**：写门均值、状态/槽位使用率、读注意力熵，**每 200 步落盘**
  （SCHEMA §17.4）。若长期 ≈0 ⇒ 结构没被用，直接毙。
- **稳定性（playbook 定律 5）**：任何负/重建类损失 **float32 + pre-step grad-norm gate**。
- **预算不足时砍什么（SCHEMA §17.7）**：砍臂数与档数、砍 n_pairs/n_batches，
  **不砍** P1/P2、源对照臂、等参数守门三条。

## 5. 我不确定的地方（诚实清单）

1. **全部外部内容为「记忆·未核」**：delta 规则（DeltaNet 系）与「LRU 对应物是写入算子」
   是**上一轮情报的解释**，不是论文原话；我**未在线核**任何一条。
   `要查`：`DeltaNet delta rule residual write`、`Gated DeltaNet MQAR`、
   `Compressive Transformer compression loss reconstruction`。
2. **最该优先核证的一条**：Compressive Transformer 是否真用了「压缩/重建损失」——
   若为假，§2d 的「业界已有先例」措辞需重写（`2617-prior-art-memory/PRIOR_ART.md` §9.2
   已列为最该核证项）。
3. **单状态可回忆信息量 vs 状态维度的确切函数形式**（线性/次线性）与常数未知。
   `要查`：Zoology MQAR 容量曲线、Mamba-2 state size 消融。
4. **本地没有线性注意力/delta 的可复用实现**（据我读到的代码布局）：§2c 落地的
   首笔成本是**实现 + 离开 SDPA 融合核的开销**，我没有实测步时，**不得**先写死预算。
5. **训练侧噪声下限**：`本地实测`（2615 §3）同配置两次重跑的 loss 差 ≈ **0.0156 bpc**，
   即跨臂可分辨下限 ≥ ~0.015 bpc —— 这比 bpc 方差界 0.014 略大，意味着**训练臂之间
   的小 bpc 差可能测不出**；关联回忆是**准确率**口径，用二项 CI 判，不受这条限制。
6. **「13M + 12k 步」是否足以涌现任何搬运能力，我完全不确定**：本批 A 线是在**未训练**
   的 13M 上取的零样本基线；训练后能否学会搬运**没有任何本地先验**。
7. **§2b 的槽位几何是否真能与底座①兼容**（读结果经 projection 回 embedding 空间是否
   足够）我没有证据，只有 playbook 定律 7 的「旁路免费 / 读出切分 −50.4%」作为方向。
8. 本文件**未做任何训练/评测**，无 `results.json`，**不是实验证据，只是设计**。
