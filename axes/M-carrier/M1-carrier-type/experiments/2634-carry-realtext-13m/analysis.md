# 2634 · 判读：真实文本口径——显式写入通道能不能把窗外真实文本搬进来？

> 契约：同目录 `README.md`（§4 判据线**预登记、未改一字**）。原始结果：`results.json`、
> `needle_raw.json`（逐针原始记录）、`reconcile_report.json`、`train_roll.log`。
> **快照口径**：enwik8 真实文本、13M 稠密主干 + 窗口 16（锚点 0）、12k 步 / 98.3M token。
> **禁外推**：绝对水平只适用于「该数据 / 该可见性 / 该尺度 / 该快照」。

## 0. 人话摘要（先看这段）

**问题**：给模型一个「固定大小的本子」（显式写入通道：把看到的东西写进去、需要时翻出来），
在**真实英文文本**上，它能不能把注意力窗口（只看最近 16 个字节）之外的内容搬过来用？

**结论一句话**：**通道活着且被读（远处内容确实影响预测；敏感度是必要条件）**——但它换来的
质量收益只有**一丁点**（每字节 0.003 比特，约 0.2%，且一个种子的配对 CI 跨 0），
而**可检索性未证**：把一条事实埋在远处再问它，**整体 beyond 桶的埋与不埋没有区别**；
只有在「所有无记忆运行都答不出」的**同索引硬子集**上，通道臂才高出约 **1.0–1.4 个百分点**
（≈2.2×，两种子同向、CI 排除 0）。

三个读数，逐个说人话：

1. **搬没搬（主判据，仪器 = 毁源式敏感度探针）**：我们把被评行**180 个字节之前**的前缀
   换成随机字节。无通道的模型对这个破坏**完全无感**（被评行 logits **逐位不变**：窗口 16 + 
   12 层多跳的感受野上限 180 也够不到）；带通道的模型**明显有感**：被评行的损失升高
   **+0.0158 / +0.0141 比特每字节**（两种子方向一致、按窗口聚类的配对 95% CI 都排除 0，
   > 本格自测噪声界 `σ_far = 0.0017`），而且**关掉通道后这个敏感度恰好归零**。
   ⇒ **被毁掉的远处内容确实通过记忆槽到达了当前预测**。这是本主线第一次在**真实文本**上
   拿到「信息被搬动」的直接证据。**口径**：这是**敏感度**（信息「有影响」的**必要**条件），
   不是「帮上了忙」（那看第 2 条），也不等于「能取回」（那看第 4 条）。
2. **值不值（质量腿）**：同样在窗口 16 下，带通道的模型 clean bpc 从 **1.6281 → 1.6250**
   （种子 0）、**1.6291 → 1.6266**（种子 1）——**通道更好 0.0031 / 0.0025 比特每字节**，
   两个种子同号，且**大于同配置换种子的极差（0.0017）**。但绝对值很小：**约 0.2%**；
   而且配对置信区间在种子 1 上跨 0。⇒ 只能说「**有**、且**一致为正**、但**很小**」，
   不能说「显著且有用」。
3. **模型靠通道吃饭吗（消融）**：把通道的读/写通路在评测期关掉（权重不变），带通道模型
   的 bpc 从 **1.625 崩到 4.51**（几乎不可用），而无通道模型不变。⇒ 通道不是装饰：
   在窗口 16 这个设定下，**模型的质量主要靠通道**。附带一个 release 口径的旁证：
   把可见性放开到全因果时，无通道模型 bpc 4.56（没见过这么长的上下文，崩），
   带通道模型 2.01（仍可用）。
4. **它学会「检索」了吗（离散答案探针）**：把一段真实文本短语埋在远处、再用它的前 6 个字节
   提问，**整体 beyond 桶：埋与不埋差 ±0.05~0.16 个百分点（n=8178 根针/臂）** ⇒ 该探针
   在整体上**没有区分力**（地板高达 ~46–50%：线索是真实文本的前 6 字节，语言先验本身
   就能续出下一个字节）。但在**同索引硬子集**（四臂的 `plant=False` 地板**全部**答不出的
   2974 根针——命中只可能来自「把远处的内容取回来」）上，通道臂比无通道臂高
   **+1.379pp（CI [0.717, 2.041]）/ +1.042pp（CI [0.380, 1.705]）**，绝对水平
   **2.42%/2.53% vs 1.04%/1.21%**（约 2.2×，两种子同向）。⇒ 结论写成：
   「**整体无区分力；硬子集上有弱证据、可检索性未证**」——**不**写「可检索性不成立」。

**一句话**：窗口压到 16 时，显式通道**确实搬**了真实文本的远处内容、且模型**依赖**它，
但它带来的质量收益**小到 0.2%**，而「能不能把远处的事实取回来」**只在一个很窄的同索引
子集上看到弱证据（+1.0~1.4pp，绝对水平 2.4%）**，**整体上未证**。

## 1. 六个必答问题

1. **它是干什么的**：给 transformer 一个固定大小的显式记忆槽（8192 个数，与序列长度无关），
   每个位置把内容写进去、每层按自己的 query 读出来；目的是**在不扩大注意力窗口的前提下**，
   把窗口外的信息带到现在。
2. **相对普通 decoder-only transformer 改了什么**：唯一的差别是**有无该通道**。
   通道臂每层加一个读出增益 `γ_ℓ`（零初始化），共享一个状态 `S`：
   `k̂ = normalize(W_k h0)`、`v = W_v h0`、`β = σ(W_β h0 + b_β)`，
   `S_t = S_{t−1}(I − β_t k̂_t k̂_tᵀ) + β_t v_t k̂_tᵀ`（delta 写：写之前把同一个键的旧分量扣掉），
   读出 `a ← a_SDPA(窗口掩码) + γ_ℓ ⊙ (S_t q_t)`。参数量 +264,296（13.54M → 13.80M，+1.95%）；
   计算量与序列长度无关。
3. **为什么要改**：本研究的问题是「窗口外信息能不能被显式搬到现在」，而**此前所有正面读数
   都来自合成任务**（关联回忆，随机符号）。SCHEMA §19 明确要求「真实文本口径的同口径复现」；
   本实验就是补这一格，并配一台能分辨「搬没搬」的仪器。
4. **怎么测的**：四臂 = {无通道, delta 写} × seed {0,1}，**唯一变量 = 有无通道 × 种子**；
   数据 = enwik8（真实文本，前 90M 训练 / 末 10M 评测），训练与评测都用
   `window_anchor_keep_mask(256, 16, 0)`；12k 步 × bs32 × T256 = 98.3M token/臂。
   三条腿：① clean bpc（窗口掩码下，96×16 窗口）；② **毁源式窗外源敏感度探针**
   （被毁前缀 [0,64)、被评行 [244,255)，见 §5）；③ 真实文本短语针（needle v3，埋/不埋配对）。
   另加评测期**通道消融**（`gate_w=carry_scale=0`）作归因对照。
5. **测出来多少**：见上面的人话摘要与 §4–§6 的表。参照系：无通道臂 1.628/1.629 bpc；
   带通道臂 1.625/1.627 bpc；同配置换种子的极差 **0.0017 bpc**；**同预算**的全注意力参考
   **1.4836 bpc**（`2610` 的 trunk：同尺寸 13,536,768、**同预算** 12k 步 × bs32 × T256 =
   98.3M token、全因果；由 `2616` 当 full 臂评测过，`window_seed=2`、24×16 口径）。
   ⇒ 与四臂的差别是**可见性**而非预算（口径差异见 §4 脚注）。
6. **结论与下一步**：见 §11。

## 4. 质量腿（窗口 16 掩码下的 clean bpc）

口径：96 批 × 16 窗口 × 255 目标 = **391,680 token/臂**；`window_seed=2`
（与 2614/2615/2616 同一窗口序，但批数不同 ⇒ **不与它们逐位可比**）。

| 臂 | `bpc_win16` | release 口径（全因果，**诊断**） | 通道消融后 `bpc_win16` |
|---|---:|---:|---:|
| `rt_none_s0` | 1.628110 | 4.555570 | 1.628110（无通道可消融） |
| `rt_delta_s0` | **1.624979** | 2.008900 | 4.509767 |
| `rt_none_s1` | 1.629093 | 4.654019 | 1.629093 |
| `rt_delta_s1` | **1.626640** | 1.970905 | 4.553643 |

- **Δbpc = bpc_none − bpc_delta**：**+0.003131（seed0）/ +0.002453（seed1）**（正 = 通道更好）；
  配对（同窗口序）95% CI：**[+0.000252, +0.006254]（seed0）/ [−0.000416, +0.005449]（seed1）**。
- `σ_cell`（本格自测 = 同配置换种子极差）= **0.001661**（2 样本 ⇒ 描述量，**不是方差上界**）。
- **读法**：两个种子同号为正、且都大于 σ_cell ⇒ 通道在真实文本上**有小而一致的净收益**；
  但幅度只有 **0.0031/0.0025 比特每字节 ≈ 0.2%**，且 seed1 的配对 CI 跨 0 ⇒ 按仓库口径
  **不得**升级为「显著有用」。
- **通道消融（归因）**：把 `gate_w` 与每层 `carry_scale` 置零后，通道臂的 bpc 从 1.625
  **崩到 4.51/4.55**（无通道臂不变）⇒ 通道臂的质量**绝大部分由通道读出贡献**，不是
  容量/重参数化（这不是「等参数对照」，而是「同权重、只断开通道」的归因）。
- **release 口径诊断（不作判据）**：把可见性放开到全因果（训练时没见过）时，无通道臂
  崩到 4.56/4.65，而带通道臂仍在 2.01/1.97 ⇒ 通道让模型**对可见性变化更鲁棒**。
  这一条只在「同权重、只改评测掩码」的口径下成立，**不得**读作部署收益。
- **参考尺度（同预算、不同可见性）**：2616 的 full 臂 = 复用 `2610` 的 trunk
  （**同尺寸** 13,536,768、**同预算** 12k 步 × bs32 × T256 = 98.3M token、全因果），
  评测口径 `window_seed=2`、24×16 ⇒ bpc **1.4836**。⇒ 窗口 16 训练模型（1.628）与全注意力
  模型的差距约 **+0.145 比特**，通道只回收了其中约 **2%**。
  **口径脚注**：批数（96×16 vs 24×16）与训练 run 不同（2610 的 trunk 是另一次 12k 训练，
  同配方同 seed 0），因此这条只作**尺度感参考**；要把它变成同口径判据只需用本实验的
  96×16 口径重跑一次纯评测（见 §10 未测项）。

## 5. 主判据：毁源式窗外源敏感度探针（`Δbpc_far`）

**仪器**（契约 §4a）：同一批真实文本窗口造两份输入——原件 `x` 与「前缀 `[0,64)` 换成随机
字节」的 `x_corrupt`；在同一窗口掩码下各前向一次，只在被评行 `[244,255)` 上算 CE。
被评行必须满足 `eval_lo − rf ≥ corrupt_hi`，其中 **`rf = L·(window−1) = 12·15 = 180`**
是 L 层窗口 w 的因果注意力的**跨层多跳感受野**（`i` 行能看到 `[i−180, i]`）。
⇒ 被毁前缀距被评行 **≥180 个位置**，**单层窗口（16）与多层多跳（180）都够不到**：

| 臂 | `Δbpc_far` | 配对聚类 95% CI | 被评行 `max|Δlogit|` | 通道消融后 |
|---|---:|---|---:|---:|
| `rt_none_s0` | **0.000000** | [0.0, 0.0] | **0.0**（逐位） | 0.000000 |
| `rt_delta_s0` | **+0.015784** | [0.012621, 0.019035] | 8.95 | **0.000000** |
| `rt_none_s1` | **0.000000** | [0.0, 0.0] | **0.0**（逐位） | 0.000000 |
| `rt_delta_s1` | **+0.014132** | [0.010780, 0.017523] | 6.54 | **0.000000** |

- **前提①被逐位证明**：无通道臂的被评行 logits 在毁源前后**完全相同**（不是「近似」），
  ⇒ 探针测到的变化**只可能**来自记忆槽（这条也顺带给出「窗口 16 + 12 层」的
  真实感受野上界：对 ≥180 之外的内容零敏感，实测而非假定）。
- **`rf` 与布局的可复核产物**：`rf_scan.py` → `rf_scan.json`（确定性扫描）。canonical 配置
  下**首个逐位不敏感行 = 243**（公式预测 244 ⇒ `rf = L(w−1) = 180` 是**保守**上界）；
  小配置 `L2/w16` 与 `L4/w8` 的实测与公式**逐行吻合**（62 / 44）；
  **旧布局**（被毁 `[0,128)`、被评行从 144 起）在 canonical 配置下**确实不为零**
  （被评行 `max|Δlogit|` ≈ 7e-8 ⇒ 严格意义上是泄漏，只是量级小）——这就是布局必须满足
  `eval_lo − rf ≥ corrupt_hi` 的原因，也是执行期把布局改成 `[0,64)`/`[244,255)` 的依据。
- **接线护栏（复核 P1-1）**：`rf` 是 `far_source_probe` 的**必填**关键字参数；`run.py` 的
  两个调用点都走 `rp.probe_kwargs(cfg)`（`rf` 由模型规格派生 + 与 config 交叉校验），
  单测 `test_run_py_calls_probe_only_via_probe_kwargs` 钉住接线、`test_far_source_probe_requires_rf`
  钉住「漏传/传 0 必须报错」。
- **主判据通过**：带通道臂两个种子的 `Δbpc_far` 都为正、都大于 `σ_far = 0.001652`、
  配对聚类 CI 下界都 > 0 ⇒ **「通道把 ≥180 个位置之前的内容搬进了当前预测」在真实文本上成立**。
- **归因干净**：写入只由输入流 `h0` 决定（`S_t` 是 `h0[0..t]` 的函数），所以在行 244–254
  处改变预测的**唯一**通路就是前缀 `[0,64)` 的写入 ⇒ 因果链无第二解释。
- **消融对照**：关掉通道读写后 `Δbpc_far` **恰好为 0**（且 bpc 崩到 4.5）⇒ 敏感度来自通道本身。
- **口径限制（必须写出来）**：`Δbpc_far` 测的是**敏感度**（信息「有影响」的**必要**条件），
  不是「帮上了忙」（那看 §4 的 bpc）；也不等于「能被检索」（那看 §6）。

## 6. 毁源对照（离散答案探针）：整体**无区分力**，同索引硬子集上**弱证据**

构造（`retention.phrase_needle_batch`，needle v3）：把一段**真实文本短语**（长 7）植入窗口，
尾块给出「标记 + 前 6 个字节」作线索，答案 = 短语的下一个字节；`plant=False` 的**配对**
控制臂（同一生成器序列、同一针位）不植入短语 = **无记忆地板**。
可见性 = 窗口 16 + 锚点 0 ⇒ 桶只有 `window`（短语全可见，14/8178）与 `beyond`（其余）。

⇒ **整体桶无区分力**（地板高达 ~46–50%：线索是真实文本的前 6 字节，**语言先验本身**就能

才算该腿有区分力，聚合规则见 `results.json::needle_leg.criterion_rule`）⇒ **不通过**。
（复核 P1-4 的修正：旧实现把 `two_proportion` 的参数顺序传反 ⇒ 判的是「地板显著高于植入」，
该判据**永远不可能通过**；现在方向固化在 `needle_stats.beyond_above_floor`，
并有单测用「应通过」的构造输入验证它真能通过。）

### 6.2 同索引硬子集（**索引集在四臂之间固定**，复核 P1-2）

索引集由 `needle_stats.hard_index_sets` 定义并**在四臂上共用**：
`intersection`（n = **2974**）= 四臂的 `plant=False` 地板**全部**答不出的针（命中只可能来自
「把远处内容取回来」）；`union`（n = 5544）= 至少一臂答不出。**同一索引**上的植入召回：

| 臂 | 植入召回（n=2974） | Wilson 95% CI |
|---|---:|---|
| `rt_none_s0` | 0.010424 | [0.007353, 0.014757] |
| `rt_delta_s0` | **0.024210** | [0.019269, 0.030378] |
| `rt_none_s1` | 0.012105 | [0.008756, 0.016712] |
| `rt_delta_s1` | **0.022529** | [0.017779, 0.028510] |

**同索引跨臂比较（通道 − 无通道）**：

| 对比 | Δ（同索引） | 95% CI | z / p | 通过？ |
|---|---:|---|---:|---|
| `rt_delta_s0 − rt_none_s0` | **+1.379pp** | [+0.717, +2.041] | 4.08 / 4.6e-5 | ✅ |
| `rt_delta_s1 − rt_none_s1` | **+1.042pp** | [+0.380, +1.705] | — | ✅ |

⇒ **结论（修正后的口径）**：
1. **整体 `beyond` 桶无区分力**（判据④不过）；
2. 在**「所有无记忆运行都答不出」的同索引子集**上，通道臂比无通道臂高 **约 1.0–1.4pp**
   （绝对水平 2.42%/2.53% vs 1.04%/1.21%，约 **2.2×**；两种子同向、CI 排除 0）
   ⇒ 这个子集上**存在一个小的、跨种子一致的可检索性信号**；
3. 但**不得**把它读成「通道给了模型检索能力」：绝对水平只有 ~2.4%，子集本身由「模型答不出」
   定义（非外部定义），且**整体桶上没有区别** ⇒ 本格措辞是「**可检索性未证**」，
   **不写**「可检索性不成立」，也**不写**「通道能检索」。

`[64,128)` 0.4907、`[128,256)` 0.5016——**无距离趋势**，与「整体上只有局部先验在起作用」一致。

## 7. 干预活性（SCHEMA §10）

| 臂 | `read_share`（末次训练日志） | 评测期 `read_share_per_layer` | `read_scale_absmean` | 状态范数 | `β` 均值 | 反事实 |
|---|---:|---:|---:|---:|---:|---|
| `rt_delta_s0` | 0.4165 | 0.3017 | 0.1089 | 5.63 | 0.435 | 关通道 ⇒ 前向偏差 0.468 |
| `rt_delta_s1` | 0.4183 | 0.3038 | 0.0977 | 5.66 | 0.435 | 关通道 ⇒ 前向偏差 0.459 |
| `rt_none_*` | — | — | — | — | — | 无通道（`enabled=False`，读出量 0） |
| `write_rel`（全臂） | **无定义**（`write_rel_chunks = 0`，单块） ⇒ 不进活性判定（见下） | | | | | |

- `read_share > 0`、γ 已逃离单边零、状态非零、且同权重关掉通道会改变前向 ⇒ **干预活着且被读**。
- **`write_rel` 的定义域（复核 P2-10：**不是**怪值，是无定义）**：引擎把它定义为**块间**状态
  相对改动 `‖ΔS‖/‖S‖`，并明确「只在 `T > chunk`（≥2 块）时有定义；单块时该量无定义（0），
  不参与『是否活着』的判定（口径随 `write_rel_chunks` 落盘）」（`pathlm/depth_ar.py` 的
  `carry_liveness` 文档 + `write_rel_ok = (write_rel_chunks == 0 or write_rel > 0)`）。
  本实验（与 2618/2631 的通道臂）实测 `write_rel_chunks = 0`、`n_chunks = 1` ⇒ 该量
  **无定义**，**不是**「写入没有改变状态」的证据。⇒ 本表的活性结论**不引用**它；
  活着的证据是四件：状态非零、γ 已逃离单边零、`read_share > 0`、反事实偏差 > 0。

## 8. 三道对账（SCHEMA §12）

1. **算术对账**：`Δbpc_far` = 逐行 CE 均值之差（`reconcile_numbers.py` 由 `ce_by_row_*` 重算，
   容差 5e-7）；`bpc_win16` = 逐窗口比特和的加权平均（配对 CI 由逐窗口比特重采样）；
   `σ_cell` = 同配置换种子极差的最大值（由原始 bpc 重算）。全部一致。
2. **任务对账**：四臂在**同一批窗口**（同一 `window_seed`、同一生成器序列）上评测；
   探针的两份输入共用同一 `x`（除被毁前缀外逐位相同）；needle 的植入/控制臂针位**逐一相同**
   （`reconcile_numbers.py` 断言 `dist` 序列相等）。毁源探针的输入分布 = 真实文本窗口分布。
3. **口径对账**：本实验只做**臂间**比较，绝对 bpc 声明为「本实验批数口径」，不与 2616 的
   24×16 读数逐位可比；release 口径读数明确标注为**诊断**（训练时未见过全因果）；
   参考线 1.4836 标注为「**同预算、不同可见性**、不同训练 run、24×16 口径」。
   同索引硬子集的两比例差方向已固化（`needle_stats.beyond_above_floor`：
   `two_proportion(control, planted)` ⇒ diff = 植入 − 地板），与 `paired_beyond_vs_floor`
   里直写的 `delta_pp`（植入 − 地板）**符号一致**（复核 P1-4 前两处符号相反）。
4. **对账脚本**：`reconcile_numbers.py` 全部由 raw 产物重算（`Ledger`，derived 计数），
   见 `reconcile_report.json`。

## 9. 失败与局限（诚实清单）

1. **质量收益很小**（+0.0025~0.0031 bpc ≈ 0.2%），且 seed1 的配对 CI 跨 0；
   `σ_cell` 只有 2 个样本 ⇒ 「> σ_cell」是弱证据。
2. **离散答案探针在整体桶上无区分力**（判据④逐臂不通过）⇒ 「通道没有让模型获得可检索的
   事实记忆」这一强读法**不成立**：同索引硬子集上确有 +1.0~1.4pp 的弱证据（§6.2）。
   但该证据的**适用域很窄**：子集由「四臂地板全失败」定义（非外部定义）、绝对水平仅 ~2.4%、
   且**未做按距离的同索引分解**；更强探针（更长线索、更低先验地板、外部定义的硬集）未测。
3. **只在 13M / 12k 步 / 窗口 16 上测**：窗口 16 是极端设定（局部先验之外还有 180 的多跳
   感受野）；窗口 32/64/192 的档位未测，禁外推。
4. **同预算的全注意力参考臂已存在但没有同口径读数**：`2610` 的 trunk 与四臂**同尺寸同预算**
   （12k × bs32 × T256 = 98.3M、全因果），但它的 1.4836 是 **24×16** 口径且是另一次训练 run
   ⇒ 只能作尺度感参考。要把它变成同口径判据 = 用本实验 96×16 口径**重跑一次纯评测**
   （≈5 min GPU，见 §10）。
5. **训练种子方差支配单臂比较**（末 loss 0.090 nat 的种子间差 vs 0.005–0.010 的臂间差）
   ⇒ n=2 只能支撑「方向一致性」级别的结论。
6. **探针的 `Δbpc_far` 只覆盖距离 ≥180 的区间**（被评行 [244,255)、被毁前缀 [0,64)）：
   它证明的是「≥180 之外的内容影响预测」，**不是**任意距离曲线；
   且「被毁 = 随机字节」只是毁源的一种实现。

## 11. 结论与下一步

- **本格入口判读（按复核口径改写）**：在**真实文本 + 窗口 16 + 13M + 12k 步**这个口径上：
  **① 通道活着且被读**——`read_share` 0.30~0.42、γ 逃离单边零、反事实偏差 0.46、且关掉通道
  后 bpc 从 1.625 崩到 4.51；**② 敏感度=必要条件成立**——无通道臂对被毁前缀**逐位不敏感**、
  带通道臂 `Δbpc_far` +0.0158/+0.0141（配对 CI 排除 0、> 本格 `σ_far`）、消融后恰好归零；
  **③ 质量收益 ≈0.2% 且一个种子 CI 跨 0**（+0.0031/+0.0025 bpc，seed1 的配对 CI
  [−0.0004, +0.0054]）；**④ 可检索性未证**——整体 beyond 桶无区分力，同索引硬子集上只有
  +1.0~1.4pp 的弱证据（绝对水平 ~2.4%）。
- **明确不成立**：① 「通道让模型获得可检索的事实记忆」（整体桶无区别；硬子集只给弱证据）；
  ② 「收益在部署意义上有用」——0.2% 的 bpc 改善、且一个种子的配对 CI 跨 0。
- **与合成任务口径的关系**：合成腿（2631/2633）量到的是「召回率从 ≈chance 抬到 36%」，
  真实文本腿量到的是「敏感度显著 + 0.2% 质量」。两者**不冲突但货币不同**：
  合成任务里「搬运」是唯一通路，所以收益是数量级级别的；真实文本里局部先验已能补全绝大部分
  （窗口 16 的模型在训练集上 loss 1.055 nat ≈ 1.52 bit/byte），所以**搬运的价值本来就小**
  （SCHEMA §19 的局部先验抗性在真实文本上被直接量到）。
- **修正本格此前的一个隐含说法（并给出边界）**：「窗口 16 ⇒ 窗外内容 100% 看不见」在
  **12 层**模型上不准确：每层窗口 16 的因果注意力可**跨层多跳**传播，L 层窗口 w 的有效
  感受野是 **`rf = L(w−1) = 180`**（`rf_scan.json` 实测：canonical 配置的**首个逐位不敏感行
  = 243**，公式上界 244 ⇒ 180 是保守值；小配置 `L2/w16`=62、`L4/w8`=44 与公式逐行吻合）。
  边界的准确写法：
  1. 合成腿的距离档 **107–240** 里，**107–180（74/134 ≈ 55%）落在多跳可达范围内**，
     **181–240 不可达**；越界辅助腿 **241–255 仍在 180 之外**（照样不可达）；
  2. 「可达」**只是传播**（信息能经多层中转影响到该位置），**不等于可检索**：同一个 12 层
     模型在 2631 的无通道臂上仍是 **chance**（1.55–1.65%），本实验的整体 needle 桶也没有
     可检索性证据（§6）。合成腿的机制解释因此是
     「**信息可达（需学习中转）但用不上**」，而不是「够不到」。
  **这三条已按复核要求写进 SSOT（`catalog.yaml` 的 M1 条目）。**
