# 2634 · 真实文本口径：显式写入通道能不能把窗外真实文本搬进来？· 13M · dense + 窗口 16

> 契约来源：主线一（信息右移）工作项的**真实文本口径验证**——本格此前所有「通道能搬」
> 的证据都来自**合成任务**（关联回忆），真实文本口径**从未验证**（SCHEMA §19 把
> 「真实文本上的同口径复现」列为待办）。
> 入口：`smoke_steptime.sh`（先测步时）→ `train_realtext.sh`（4 臂，按臂释放锁）→
> `run.py`（真实文本三条腿 + 毁源/消融对照）；语义层 `realtext_probe.py`；本地单测
> `test_realtext_probe.py`；原始结果 `results.json`；判读 `analysis.md`；权重清单 `MODEL.md`。

## 1. 命题

**在真实文本上，给 13M 主干一个显式写入通道（记忆槽），它能不能把注意力窗口（16 个位置）
之外的**真实文本内容**搬到当前预测里用？**

一句话可证伪的形式：*在 enwik8（真实文本）上训练四臂（无通道 / delta 写 × seed 0/1），
训练与评测都用窗口 16 + 锚点 0 的可见性；在**成对**评测上量「把窗口外的前缀内容毁掉后，
被评位置的损失变化 `Δbpc_far`」——无通道臂的 `Δbpc_far` 必须**逐位为 0**（窗外内容本来就
看不见，这是探针有效性的前提），而 delta 臂若**在两个种子上都** `Δbpc_far > 0` 且超过本格
自测的 bpc 噪声界，则「通道在真实文本口径上搬了窗外信息」成立；否则记「该口径下**搬不动**
或**不可判**」并给出具体原因。*

## 2. 单因素声明

- **基底**：stock dense decoder-only trunk（tied 读出 + 无 final LayerNorm + 顺序残差），
  13.54M（d256 × 12 层 × 8 头 × mlp6 × T256），与 2618/2631 **同一规格**。
- **唯一变量**：`carry_rule` ∈ {无通道 `none` / delta 写}（两层：写入规则 × 训练 seed 0/1）。
- 其余逐字段一致：数据（enwik8 前 90M 训练 / 末 10M 评测）、12k 步、bs32、lr 1e-3、
  AdamW+cosine、`--exit-mode uniform`、可见性 `train_window=16 / train_anchors=0`、
  评测协议。逐字段对照见 `analysis.md` §3。
- **必要性例外（显式记账）**：训练与评测都用 `window=16 / anchors=0` 的可见性掩码（既有
  开关，非第二个机制）——它制造「窗外信息必须靠通道搬」的需求。四臂完全相同。

## 3. 干预定义

与 2618/2631 完全同一实现（**本实验不改任何 `pathlm/**`、`train_depth_ar.py`、
`tools/**` 文件**，只新增目录内代码）：

```
写入（每位置一次，来自输入流 h0）：k̂ = normalize(W_k h0)，v = W_v h0，β = σ(W_β h0 + b_β)
  delta： S_t = S_{t−1}(I − β_t k̂_t k̂_tᵀ) + β_t v_t k̂_tᵀ = S + β(v − S k̂)k̂ᵀ
读出（每层各一次）： a ← a_SDPA(窗口掩码) + γ_ℓ ⊙ mem_t ，mem_t = S_t q_t（读后写）
```

- `carry_rule=None` 臂走 stock `Block`，逐位还原 v1；通道臂 +264,296 参数、γ 单边零初始化。
- **与 2631 的唯一差别 = 训练数据**：本实验用 **enwik8 真实文本**（2631/2618 用合成
  `assoc-mqar`）。这是本实验要验证的口径本身，不是第二个机制。

## 4. 判据线（预登记；写下后不得改）

| # | 判据 | 判定线 | 该涨/该跌/必须不变 |
|---|---|---|---|
| ① | **前提（探针有效）**：无通道臂对窗外前缀被毁**不敏感** | 两个 seed 上，被评位置（行 144–254）的 logits 与 clean 输入**逐位相同**（`max|Δlogit| == 0`） | 必须不变 |
| ② | **主判据（该涨）**：delta 臂把窗外前缀内容用起来 | 两个 seed 上 `Δbpc_far > 0` 且 > 本格自测 bpc 噪声界 `σ_cell`（见 §4a） | 该涨 |
| ③ | **质量腿（并列，非主）**：通道对窗口 16 口径的 clean bpc 是净收益还是税 | 报 `Δbpc_win16 = bpc_none − bpc_delta`（正 = 通道更好），带 §4a 的 `σ_cell` | 该涨（或如实报税） |
| ④ | **毁源对照（离散答案探针）**：真实文本短语针（needle v3）在 `beyond` 桶（窗外）的召回必须高于**配对无针地板** | 主臂 `beyond` 召回 > 同批 `plant=False` 地板，且差值 > 二项 95% CI 半宽 | 该涨/否则该腿无区分力（如实报） |
| ⑤ | **禁外推** | 结论只适用于 enwik8 / 窗口 16 / 13M / 12k 步快照 | — |

### 4a. 操作性定义（不改判据，只把口径落定）

- **`bpc_win16`**：`retention.masked_bpc(model, eval_arr, window_anchor_keep_mask(256,16,0),
  n_batches=96, batch_size=16, window_seed=2)`——**与训练同一掩码构造、同一函数**；
  评测窗口序与 2614/2615/2616 同一 `window_seed=2`（批数不同 ⇒ 绝对 bpc 不与它们逐位可比，
  本实验只做**臂间**比较）。token 数 ≈ 96×16×255 = 391,680。
- **`Δbpc_far`（主判据的仪器）**：同一批窗口 `x`（生成器 `window_seed=2`，与 `bpc_win16`
  同一批位置）构造两份输入：`x` 与 `x_corrupt`（把 `x[:, 0:128]` 里**所有**位置换成一组
  固定的随机字节，`x` 其余位置逐位不变）；模型在同一 window-16 掩码下各前向一次，
  只在**被评行** `i ∈ [144, 255)` 上算 CE（这些行的可见窗口 `[i−15, i] ⊂ [128, 256)`，
  **完全不含被毁前缀**⇒ 对无通道臂逐位相同）：
  `Δbpc_far = mean_CE_{i∈[144,255)}(x_corrupt) − mean_CE_{i∈[144,255)}(x)`，
  单位 bits/byte。**配对**（同一批位置、同一模型）。正 = 窗外前缀内容对该模型有用。
- **`σ_cell`（本格自测噪声界，禁套全局 0.014）**：本格同配置换种子（`none_s0` vs `none_s1`、
  `delta_s0` vs `delta_s1`）在 `bpc_win16` 上的**极差的最大值**；`Δbpc_far` 一类
  「同配置换权重」的量用同一值作界。**这是 2 样本极差，是描述量、不是方差上界**（显式标注）。
- **`needle` 腿**：`retention.phrase_needle_batch`（needle v3，真实文本短语针；`n_needles=8,
  phrase_len=6, seed=3`，批 16 × 64 批 ⇒ 8192 根针/臂/条件）+ `needle_recall(..., anchors=0)`
  ⇒ 桶只有 `window`（短语全可见）与 `beyond`（有位置不可见）。`beyond` 桶在窗口 16 下占绝大多数。
  **地板 = 同一生成器序列、`plant=False` 的配对控制臂**（不植入短语 ⇒ 只有语料先验）。
- **通道消融（诊断，不作判据）**：把通道臂的 `gate_w` 与每层 `carry_scale` 置零后重测
  `bpc_win16` ⇒ 前向退化为「同架构无通道」的纯主干路径，用于分离「通道读出的贡献」与
  「容量/参数量的贡献」。**不改权重文件**（内存里改、改完恢复）。

**预算不够时砍什么**（SCHEMA §17.7 / §20.3）：**四臂一起**砍步数（12k → 6k，保持臂间同

## 8. 既有做法（prior art，SCHEMA §18）

1. **谁做过**：显式记忆 / 检索增强（kNN-LM、RETRO、Memorizing Transformer）、状态空间与
   线性注意力（S4/Mamba/RWKV/GLA、DeltaNet）、以及长上下文评测（needle-in-a-haystack、
   RULER）。`记忆·未核`：本环境**无联网检索**，未查原文链接。
2. **为什么这么设计**：局部注意力的信息在窗口外即丢失；显式记忆/递推状态把「过去」压进
   一个与长度无关的载体，从而在不扩大窗口的前提下取回远距离信息。
3. **它的实测结果（记忆·未核）**：检索增强在**大模型 + 大语料**上有效；线性/递推状态在
   记忆受限任务上逊于同尺寸注意力；在**小模型 + 强局部先验**的真实文本上，长程机制常常
   量不出收益（与本仓 SCHEMA §19 的「局部先验抗性」一致）。
4. **我们的增量**：不是提出机制，而是**把「显式写入通道能不能在真实文本口径上搬运」
   做成可判定实验**：同窗口、同 token 预算、臂间唯一变量 = 有无通道；主仪器是
   **毁源式 `Δbpc_far` 探针**（窗外前缀被毁 ⇒ 损失变化），配「无通道臂必须不敏感」的
   前提校验 —— 直接对准「信息有没有被搬过来」而不是「损失有没有变好」。
   我们的设定与业界的实质差异：13M、单卡、12k 步快照、窗口压到 16、只用真实文本。

## 9. 失败决策树（测量 → 实现 → 规模 → 设计）

1. **测量**：前提①失败（无通道臂对毁源敏感）⇒ 说明有越窗泄漏（掩码/仪器问题），先修仪器再判。
2. **实现**：通道活性为 0（`read_share`/β/状态范数任一为 0）⇒ 先跑 2618/2631 的变异验证排除
   死开关；评测期反事实探针（关通道 / 换规则 → 前向变化）证明干预活着。
3. **规模**：`Δbpc_far ≈ 0` 且 `bpc_win16` 两臂不可分辨 ⇒ 该口径/该尺度上**没有搬动**；
   按 SCHEMA §19 只读作「不划算」，**不得**写成「机制不可能」；下一步 = 更大步数/规模、
   窗口档位（32/64）扫描（列成待测项与成本）。
4. **设计**：`Δbpc_far > 0` 但 `bpc_win16` 变差 ⇒ 区分「搬了但代价抵消」（SCHEMA §17.17 分量分解）。
