# 2625 · 对照臂与方差说明（controls/）

契约：`../README.md`（§4 判据线逐字抄录 W2）。原始结果：`../results.json`。

## 1. 对照的构成

本线的结论是「**同一条腿跨独立训练的读数抖动有多大**」，所以「对照」不是某个更弱的臂，
而是**同一配置的多跑本身**（run-to-run）。另有两条口径对照用来定位抖动的来源：

| 对照 | 是什么 | 回答什么 |
|---|---|---|
| **参照臂 `y1_gqa_carry_win_s0`** | 复用 Y1（2623）的 `gqa_carry_window`：与主集**同配置、同 seed=0**、但一次**独立训练** | 「方差来自 seed 标签，还是来自训练运行本身？」——同 seed 两跑差 15× ⇒ 是后者 |
| **训练分布内腿**（多查询 assoc-mqar，距离 107–240） | 与判决腿**同臂**、不同评测任务 | 「抖动是任务级还是距离档级？」——分布内极差 1.2pp ⇒ 是**距离档**级 |
| **全因果交叉口径**（keep_mask=None，距离 241–255） | 去掉窗口需求后重评同一批 | 「抖动来自窗口/搬运，还是距离本身？」——极差 11.9pp ⇒ 是**距离**本身 |
| **毁源对照**（`corrupt_span([0,16))`） | 把源 KV 段替换成同分布新符号 | 「读数是不是真来自被搬运的信息？」——三臂毁源后 CI 下界 ≤ 4×chance ⇒ 有效 |

## 2. 方差界与判据

- **方差带 = 1.4pp**（`docs/methodology.md`）：用于「两个读数是否可排序」。
- **结论效应阈值 = 3pp**（W2 明文「如 ≥3pp」）：**只用于**判据 ②（降级判定），只看**极差**。
- **极差** = `100×(max − min)`（pp）。主集 n=3（seed=0/1/2）；参照臂**不并入** n=3。

## 3. 同批位置（§对照复用规则 2/3 的落地）

四条臂在每条腿上用**同一组数据生成器 seed**（与臂无关，钉在
`ood_variance_arms.eval_batch_seeds`）：单查询腿 `1056+i`、多查询腿 `2112+i`、
距离曲线 `5000+i`——与 2624 的评测仪器同基准（`reconcile` 的「任务对账」逐字段核过）。

## 4. 复用的前提（SCHEMA §9）

复用 Z3（2624 `carry_gqa`）与 Y1（2623 `gqa_carry_window`）的 checkpoint 作 s0 / 参照臂，
满足三条：

1. **实现层 equality**：本 harness 的 `fp32` 档与释放版前向**逐位相等**
   （`results.json::instrument_selfcheck.fp32_bitwise` 四臂全 True）；
2. **配置层 equality**：逐字段对照见 `../analysis.md §3`（只有 seed / 权重来源不同）；
3. **口径标注**：s0 复用 6k 快照口径、与 Z3 的 `carry_gqa_fp16` 读数**逐位复现**
   （0.9277%）；参照臂**逐位复现** Y1 的 15.332%。
