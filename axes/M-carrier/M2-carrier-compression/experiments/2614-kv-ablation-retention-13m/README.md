## 1. 命题

**把某些位置的 KV 从注意力可见集里删掉（评测期，不重训），质量掉多少？**
这件天平要能回答三件事：① 与查询距离为 d 的 KV 值多少（距离曲线）；
② 丢掉最远的 N 个位置值多少（左前缀截断曲线，直接回答「左前缀能丢多少」）；
③ 删一段连续位置值多少（按位置 vs 按内容）。仪器类实验的判据 = **仪器是否可信 + 基线数字**。

## 2. 单因素声明

唯一因素 = **注意力可见集**（哪些 (query, key) 对参与注意力）。被测量模型、
checkpoint、数据流、评测窗口、位置集、读出全部逐字段一致；不改权重、不训练、
不引入任何新参数（`results.json::intervention.params_added = 0`）。
基底 = 主流标准 decoder-only transformer（`DepthARModel(dense=True)`，12 层 × 256 宽 × 8 头，
tied 读出、无 final LN）。无「必要性例外」。

**干预实现**：`attention_mask` 上把被删 key 置为不可见（`keep[i,j]=False`），
即训练/推理的真实注意力可见集被改写，不是事后对 logits 做手脚。

## 3. 方法（**逐字**抄录契约「方法」段）

> - 方法（同一数据流、同一位置集、只改「哪些位置的 KV 被删」）：
>   1. **距离曲线**：对每个距离 d ∈ {1,2,4,8,16,32,64,128,255}，删除「与查询距离恰为 d」的位置的 KV，测 Δbpc；
>   2. **前缀截断曲线**：删除最远的 N 个位置（N ∈ {8,16,32,64,128,192,255}），测 Δbpc → 这是「左前缀可丢多少」的直接答案；
>   3. **连续段删除**：删一段连续位置（随机起点，长度 L ∈ {4,16,64}），测 Δbpc（区分「按距离」与「按内容重要性」）；
>   4. 可选：同一实验下的 attention-mass 统计（哪些位置真的被读到）。

**实现口径（摘要，执行时的落地细节，不改判据）**：

- 位置语义：③ 的「随机起点」= 固定 `start_seed=11` 的生成器抽 8 个起点/长度（可复现；
  详见 `config.json::curves.segment`，逐点结果在 `results.json::curves.segment_by_start`）。
- **恒含因果**：`keep[i,j]=False` 当 `j > i`（不许看未来）。
- **对角线恒保留** `keep[i,i]=True`：否则「自身位置落在被删前缀/段里」的 query 行会
  全掩码 ⇒ softmax 全 −inf ⇒ NaN。该约定只影响前缀/连续段删除（距离曲线 d ≥ 1
  蕴含 `j = i−d < i`，不触对角线）；它使这些 query 退化成「只看自己」，
  这正是「前缀被整个砍掉」的诚实语义。单测钉住，变异 M4 证明它抓红。
- ④ attention-mass 统计：**未做**（契约标注为「可选」）。原因：需要另写一条
  softmax 权重采集路径（`Block` 只在 `dist_pen>0` 的旁路里返回注意力统计），
  与本次判据线无关，留作后续；本实验改用「按距离的 damage 曲线」间接反映哪些
  位置被读到。
- 「若预算允许再加一个 depth-ar 形态的 checkpoint 作对照」：**未做，并说明原因**。
  预算确实允许（全电池 43 s），但该形态（`dense=False`）走**门控 + 混合深度 KV
  填充**路径（`fill_kv`），本仪器的掩码前向只定义在 stock dense 路径上（与 2610
  主干同一路径）。在 fill 语义下「删掉的 KV」会被冻结表征回填，**删除是否真的
  生效本身就是一个未裁决的设计问题**——这超出本契约授权范围，且会给本实验
  引入第二条前向路径与对应的单测/变异，破坏单因素结构。仓库内当前没有带
  sha256 的 depth-ar 形态 checkpoint 落在 `axes/` 下（`.scratch/` 里的历史权重
  属只读归档、口径不同）。建议需要时单开一条实验（含独立判据线）。

## 4. 判据线（**逐字**抄录契约「判据」段，未改一字）

> - **判据（预登记；仪器类，判据是「仪器是否可信 + 基线数字」）**：
>   - (a) 三条曲线**单调**（距离越远/丢得越多，损伤不应更小）；
>   - (b) **复现性**：同 seed 重跑 Δbpc 差异 < 0.005；
>   - (c) 输出两个基线数字：**安全丢弃半径** d*（Δbpc < 0.014 的最大 d）与**「丢最远 N 个位置」的 Δbpc 曲线**；
>   - (d) 若任一曲线非单调且无法用噪声解释 ⇒ 仪器不可信，先修仪器（记 ERRATA）。

**执行时的操作性定义（不改判据，只把两个符号落定）**：

- 符号统一为 SCHEMA §17.3：`Δ = bpc_对照 − bpc_实验`（正 = 改善）；本实验的
  「实验」= 删 KV，所以 Δ ≤ 0。同时报 `damage = bpc_实验 − bpc_对照 = −Δ`（正 = 变差），
  单调性检查跑在 damage 上（「丢得越多损伤不减」是 damage 的自然方向）。
- (a) 三条曲线的方向：距离曲线 damage **非增**（越远越不值钱）；前缀/连续段曲线
  damage **非减**（丢得越多越疼）。契约括注里「距离越远……损伤不应更小」按字面读
  与物理预期相反；**我们两种读法都跑、都如实报**（见 §6 与
  `results.json::criteria.a_distance_literal_direction`），不改判据。
- (b) 「同 seed 重跑」= 同一 `window_seed`、同一代码、同一设备把整个电池重跑一遍，
  逐配置比较 damage 差；阈值 0.005 取自契约。
- (c) 「最大 d」按字面取；但曲线单调递减时该读法退化（集合最大值恒为最大测试距离），
  因此**并列**给出可操作读法：从哪个距离起「更远的 KV 全部可丢」（见 §6）。

## 5. 对照与方差

- **对照 = 同一模型的全注意力自身**（`keep_mask=None`，走释放版 `is_causal=True` 路径）。
  身份（精确因果）掩码与它**逐位相等**（`abs_diff = 0.0`），所以删除曲线与基线同引擎、
  同数据流、同窗口、同位置集——**不是**跨 run 对照（无 §9 复用问题）。
- 方差界：Δ < 0.014 不可排序（methodology §2）。本实验另测**跨评测窗口 seed**
  的成对 damage 散布作为仪器噪声底（`results.json::noise_floor`）。
- 种子：评测窗口 seed = 2（与 2610 的 `depth_curve` 基线同序）；复现性 = 同 seed 重跑。

## 7. 成本（唯一数字 = 契约 §「成本」行）

- 契约写的预算是**纯推理 ≈15–25 min**（T=256，20 个 eval batch 级别）。
- **实测**：墙钟 **43.4 s（0.41 min）**，137 次评测（每次 24×16 窗口），
  峰值显存 **140 MiB（net）**——远低于契约预算与 ≤5GB 净预算。
  共享卡（实测时已被 llama-server 占 8.7GB）上串行运行，无排队。
- 可中断性：是（纯推理，无训练状态；重跑成本 25 s）。
- 冒烟计划：`python3 run.py --smoke`（2 个窗口批次 + 少量配置，实测步时/显存，
  **不外推时间字段**，遵循 SCHEMA §17.5）。预算不够时砍「连续段起点数 → 噪声底 seed 数」，
  **不砍判据线**。

## 9. 失败决策树

| 症状 | 诊断顺序 | 处置 |
|---|---|---|
| 曲线非单调 | ① 位置集合实现 bug（变异验证 + 单测）② 评测窗口/CE 口径错 ③ 噪声 | 先跑 `mutate.py` 与单测；再对照 `noise_floor` 的 σ；非噪声时记 ERRATA 并修仪器 |
| Δbpc 出现**负损伤**（删 KV 反而更好） | ① 配对口径错（两臂窗口不同 / 位置集不同）② 真效应（老前缀是干扰） | 检查 `window_seed`/`query_min` 配对；真效应则如实记录并标注可能机制 |
| 复现性不过 | GPU 非确定性 / 代码路径有未固定随机源 | 固定 seed 后重跑；仍不过则升级为仪器缺陷 |
| 身份掩码 ≠ 释放版基线 | 掩码语义（True/False）或对角约定错 | 停：仪器不可信，先修（本实验实测逐位相等） |
| 与 2610 锚 bpc 1.4836 差很多 | 窗口/评估口径不一致 | 用同一 `window_seed` + `n_batches` 复算（本实验实测差 3.1e-05，仅来自锚的 4 位小数） |
