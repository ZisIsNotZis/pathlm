# 2614 · KV 消融保留曲线 · 13M —— 稳定性专报

> 数据源：`results.json::instrument / reproducibility / noise_floor / criteria`（由 `run.py` 生成）。
> 契约：`README.md` §4（判据 (b) 复现性）与 §5（对照与方差）。
> 本实验无训练，故本报告不写 loss/梯度稳定性（那是训练专报的内容），只写
> **测量本身的稳定性**：确定性、窗口噪声底、单调性余量、仪器自检。

## 0. 人话摘要

这台天平**很稳**。(1) **同一 seed 重跑整个电池（137 次评测里 40 个配置重跑），
逐配置 damage 的最大差是 4.9e-07 bpc** —— 判据 (b) 的门槛是 0.005，实测比门槛小
四个数量级，等于「完全可复现」。(2) 换成**不同的评测窗口**（seed 3–8）时，
成对 damage 会有 0.0025–0.015 的散布，最大的那个（前缀 N=192，3.55 bpc 的大改动）
也只有 0.015——所以**大改动很稳，小改动的读数必须靠"同一批窗口"的成对比较**，
这也是本实验全程的纪律。(3) 三条曲线**在不加任何容差时就严格单调**，
用 2σ = 0.030 的容差复检仍然单调。结论：(a)(b) 两条仪器判据都站得住。

## 1. 确定性（判据 (b)：同 seed 重跑）

| 项 | 值 |
|---|---|
| 重跑配置数 | 40（距离 9 + 前缀 7 + 连续段 24） |
| 最大 \|damage_run1 − damage_run2\| | **4.94e-07 bpc** |
| 契约阈值 | 0.005 |
| 判决 | **通过**（差 4 个数量级） |

口径：同一代码、同一 `window_seed=2`、同一 GPU、同一进程内先后两次评测。

**跨进程重跑**（同一修订、三次独立进程，含一次两进程并发）：40 个配置的 damage
**逐个位等于 0.0**（`/tmp/rep1`、`/tmp/rep2` 与正式 `results.json` 三方互比）。
把「不同代码修订」的会话也放进来比，最大差约 1e-5 bpc（例如 `distance:d=16` 的
1.500078 vs 1.500084）——量级仍是 0.005 门槛的 1/500，且判据 (b) 的口径是
「同一修订同 seed 重跑」。

## 2. 窗口噪声底（跨评测窗口 seed 的成对 damage，n = 6）

| 配置 | 平均 damage | σ（跨窗口） | 6 个 seed 的 damage |
|---|---:|---:|---|
| `distance:8` | 0.088715 | 0.002984 | 0.0926 / 0.0856 / 0.0880 / 0.0855 / 0.0890 / 0.0916 |
| `prefix:64` | 1.245362 | 0.002503 | 1.2446 / 1.2429 / 1.2476 / 1.2446 / 1.2432 / 1.2492 |
| `prefix:192` | 3.553725 | **0.015086** | 3.5681 / 3.5695 / 3.5526 / 3.5426 / 3.5307 / 3.5588 |
| `segment:L16@40` | 0.406486 | 0.008477 | 0.4155 / 0.4046 / 0.4074 / 0.3978 / 0.4168 / 0.3969 |

- σ 中位数 0.0085、最大 0.0151。**这比同 seed 复现性（5e-07）大 4–5 个数量级**——
  说明「换一批评测窗口」才是这台天平的主要不确定性来源，而不是 GPU 非确定性。
- **纪律含义**：判据 (c) 的 0.014 阈值在同一批窗口的成对比较下才有意义；
  本实验的 Δ 一律是同窗口成对差（同一 `window_seed`），跨窗口数字只作噪声底参考。
- 单调性复检用的容差 = 2 × σ_max = **0.0302**（保守取最大 σ）。

## 3. 单调性余量（判据 (a)）

| 曲线 | 方向（damage 口径） | 相邻点最小间隔（最"紧"的一处） | 是否逆序 | tol=0 | tol=0.0302 |
|---|---|---|---:|---|---|
| 距离 | d 增大 → damage 非增 | d=255 处 +0.000000 对 +0.000483 | 无 | ✓ | ✓ |
| 前缀 | N 增大 → damage 非减 | N=8→16：+0.197 → +0.345 | 无 | ✓ | ✓ |
| 连续段 | L 增大 → damage 非减 | L=4→16：+0.114 → +0.399 | 无 | ✓ | ✓ |

距离曲线在两端（d = 128 → 255）的间隔是 0.0005，**小于跨窗口 σ（0.002–0.015）**；
但因为是同窗口成对测量，复现性 5e-07，所以这个 0.0005 的次序**在本次口径下是可靠的**，
只是在跨窗口口径下不可排序（如实标注）。

## 6. 结论

判据 (b) 通过（4.9e-07 < 0.005）；判据 (a) 通过（tol=0 与 tol=2σ 下三条曲线均单调）；
仪器自检逐位相等。唯一的稳定性限制是**跨窗口**读数的 σ（0.002–0.015），
已在 `analysis.md` §8 口径表与本报告 §2 显式标注。
