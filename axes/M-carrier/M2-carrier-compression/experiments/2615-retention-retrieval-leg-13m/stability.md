# 2615 · 稳定性与噪声底专报（检索腿）

契约：同目录 `README.md`。原始数据：`results.json::reproducibility` / `::noise_floor`。
所有数字来自同一次全电池（`run.py`，墙钟 56.98 s，1425 次评测，峰值显存 142.7 MiB）。

## 1. 复现性（同 seed、同进程重跑）

- 6 个配置（`full` / `prefix` N=8/16/32/64/128）的依赖腿各重跑一遍：
  **最大 \|Δbpc 差\| = 0.0**（逐位相同），契约阈值 0.005 ⇒ **通过**。
- 检索腿的配对控制臂在运行时断言：`plant=False` 与 `plant=True` 在**同一 generator 状态**下
  `meta` 逐字段相同（`run.py` 的 `assert meta0 == meta`）⇒ 不存在「地板与主臂不是同一批针」的错配。

## 2. 噪声底（三条独立来源）

| 来源 | 设定 | 实测散布 |
|---|---|---|
| 依赖腿 · 跨**评测窗口 seed** | seed ∈ {3,4,5,6}（n=4），成对 damage | `recent:d=128`：均值 0.019522，**σ = 0.001401**；`prefix:N=32`：均值 0.637487，**σ = 0.004157** |
| 检索腿 · 跨**针 seed** | seed ∈ {3,13,23}（n=3，各 512 根针） | `full`：0.6797 / 0.7305 / 0.6777，**σ = 0.0299**；`recent:d=128`：σ = 0.0258；`recent:d=192`：σ = 0.0351 |
| 检索腿 · 二项抽样（解析） | n=4096 根针，p ≈ 0.687 | SE = √(p(1−p)/n) = **0.0072（0.72pp）**；n=508 的桶 ⇒ 2.1pp |

**读法**：

- 依赖腿的「几乎无伤」判定门槛 0.014 比跨窗口 seed 噪声（σ ≤ 0.0042）**大 3.3 倍以上**，
  所以 `recent:d=144` 的 −0.01376 虽然贴着门槛，仍与「无伤」不可区分地接近；本报告没有据此
  宣称任何排序。
- 检索腿的跨 seed 散布（σ ≈ 2.6–3.5pp）**略大于**同规模二项 SE（2.0pp，n=512），
  说明还有一点针位抽样的结构差异；但两条腿的比较全部是**同一批针、逐针配对**的
  （`paired_*` 字段），配对后共享 seed 噪声，比跨 seed 散布小得多。
- 判据跨度 30pp ≈ 10σ（跨 seed）⇒ 主判据「未达成」不是一个噪声边缘结论，而是结构性的。

## 3. 内部一致性检查（比复现性更强的活性证据）

| 检查 | 结果 |
|---|---|
| 身份因果掩码 vs 释放版前向 | bpc 1.483569 == 1.483569（**逐位**） |
| `masked_bpc` vs `row_bpc` 的行均值（算术对账） | 39/39 配置 < 1e-6（实测 ~1e-8） |
| 桶计数闭合 | `n_window + n_anchor + n_beyond == 4096`，39/39 成立 |
| `n_deleted` 与桶口径闭合 | `n_deleted == 被删的锚针 + n_beyond`，39/39 成立 |
| 可达针的召回**不随其他位置的删除而变** | `prefix:N=8` 的窗口内桶 0.6943 vs 全保留 0.6945（差 0.0002） |
| 被删针的召回落到地板 | `prefix:N=8` 的锚区桶 0.4587 vs 无针地板 0.4331（差 0.0256） |
| 恒等配置 | `recent:d=256` 与 `full` 的三个口径**全部为 0** |

## 4. 已知的不稳定来源与处置

1. **针位抽样的结构差异**（σ ≈ 3pp/512 根针）：通过**逐针配对**（主臂与地板同批同序）
   消除；跨配置比较一律用同一批针。
2. **`segment` 起点覆盖查询块**（8 个配置）：不是数值噪声，而是**任务被改**（线索被删）。
   逐配置标记 `overlaps_query_block`，判据扫描并列「排除后」的一档。
3. **`recent:d` 大范围贴门槛**（d=144 的 Δbpc = −0.01376，门槛 0.014）：已按 §2 的
   跨窗口 seed σ 说明「贴门槛不等于可排序」，并**没有**用这个排序做任何结论。
4. **小样本桶**：`recent:d=32` 的窗口内桶只剩 83 根针（0.7952）；任何用该桶的陈述都标了 n。

## 5. 与原实验（2614）的稳定性对照

2614 报「同 seed 重跑最大差 4.94e-07、跨窗口 seed σ 0.0025–0.0151」。本实验在同一件仪器上
重算 `prefix` 曲线得**逐位相同**（差 0.0），跨窗口 seed σ ≤ 0.0042 —— 与 2614 同量级或更小。
两批数字的差别只在「跑了多少个 seed、跑在哪个配置上」，不是实现差异。
