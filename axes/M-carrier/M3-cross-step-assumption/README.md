# M3-cross-step-assumption · 跨步假设

> 轴：**M 状态载体** ｜ 状态：**✅ judged**

> **判读**：有界内存的价签已测两档：**窗口 192 的训练税 −0.0028（近零）**、窗口 32 为 +0.0866；但 192 档**本就没有头寸**（未重训限制到 192 只 +0.0029），真正的「训练补回」只在 32 档被测到（+0.1495 → +0.0866，补回 42%）。**窗口外信息仍是「丢了」不是「搬了」**。

## 1. 命题

相邻 token 之间的状态关系——每 token 独立算，还是段级递归。

## 2. 选项枚举（本格全部可能取值）

1. `每 token 独立（标准 AR）`
2. `段级递归（Transformer-XL 式）`
3. `全量重算`

## 3. 状态（我们做了什么 / 行业做了什么）

**本地已测**：有界内存的**两档价签**：限制到 192 几乎免费；限制到 32 要付 +0.087。解析 KV 位置 256 → 200（−21.9%），实测显存不下降（分开报）。步时 1.05×（600 步实测）

**行业口径**：见 `docs/playbook.md` 与参照线 `R-references/`。

## 4. 结论与数字

- **税**：窗口 192 训练税 **−0.002813**（1.483569 → 1.480756；重跑 +0.000673 ⇒ 只能报「近零」不能报「更好」）；窗口 32 训练税 **+0.086566**；评测期（全注意力模型）recent:d = 32/64/128/192 → **+0.211815 / +0.080508 / +0.020065 / +0.004175**；带 8 锚点的同族口径 +0.149528 / +0.059563 / +0.014677 / +0.002851
- **收益**：有界内存的**两档价签**：限制到 192 几乎免费；限制到 32 要付 +0.087。解析 KV 位置 256 → 200（−21.9%），实测显存不下降（分开报）。步时 1.05×（600 步实测）
- **判读**：有界内存的价签已测两档：**窗口 192 的训练税 −0.0028（近零）**、窗口 32 为 +0.0866；但 192 档**本就没有头寸**（未重训限制到 192 只 +0.0029），真正的「训练补回」只在 32 档被测到（+0.1495 → +0.0866，补回 42%）。**窗口外信息仍是「丢了」不是「搬了」**。

## 5. 失败路径与原因

1. **限制可见范围不会让信息右移**（检索腿）：窗口外整桶召回 0.475954 vs 同掩码无记忆地板 0.444444（+3.2pp < 10pp 门槛）；拆开后**整段都在窗口外的 494 根差恰好 0.000**，那 +3.2pp 全部来自尾巴仍有 1–6 字符在窗内的 109 根（+17.4pp）；窗内阳性对照 +28.2pp ⇒ 是「丢了」不是「搬了」
2. **不得用两点定趋势**：训练侧只有 32 与 192 两点，悬崖形状/位置**不可判定**（SCHEMA §17.11）；要定位须再补 64/128 两个训练点
3. 训练侧 run-to-run 噪声 0.003486 与「税 ≈0」同量级 ⇒ 只能报近零
4. 无 ring-buffer 实现 ⇒ 不主张实测显存/算力收益；未跑 24k 点

## 6. 判据与判决实验设计

- **判据**：质量 + 内存 + 不重 prefill 能力
