# CRITIQUE · M3-cross-step-assumption（跨步假设）— 独立批判审计（2026-10-04）

## ① 这是什么（我的理解）

研究「相邻 token 之间的状态关系」——每 token 独立还是有界窗口；本仓测的是
「把训练时的注意力可见集砍到最近 N（+8 锚点）后，质量税是多少，窗口外信息是否被搬运」。

## ② 对着什么 sota，我们偏离在哪

- 业界标准：滑动窗口注意力（Longformer / Mistral 系）与 StreamingLLM（窗口 + sink）
  ——「**大窗口训练税近零、小窗口要付质量**」是既有共识；本仓 `axes/M-carrier/PRIOR_ART.md:132`
  自己判 M3 主结论应改 `reference`。
- 偏离：我们把「窗口 N」当杠杆，而 sota 的问题是「窗口 + sink + 有效上下文」；
  本仓的锚点（前 8 个位置）正是 sink 的复现（`2617-prior-art-memory/PRIOR_ART.md` 块⑤
  自己承认「锚点不是我们的发明」）。

## ③ 五类问题逐条判定

1. **开倒车：有（主结论层面）。** 见 ②。

2. **过程错误：有。**
   - **只有两个训练点**（32 / 192），`2616.../analysis.md` §1/§8 自认「不得内插也不得外推」，
     「悬崖形状/位置不可判定」——这是**本仓自己的 §17.11 违规预防**，做得对；
     但它同时意味着本格的 `verdict`（`M3-.../README.md:7`）在讲一个**它自己说不能讲**的趋势。
   - **训练侧噪声与效应同量级**：`2616/analysis.md` §3「本实验整条 12k 重跑（同 seed 同配方）
     给出 native 口径差 **0.003486**」；而主读数是 **−0.002813**（§4 判据①）。
     ⇒ 税的两个读数（−0.0028 / +0.0007）都落在**重跑噪声**内。作者如实写了「只能报近零」，
     但 `catalog.yaml:1085` 的 `tax` 仍是带符号的负值。

3. **结论错误：有（措辞层面）。**
   - 「有界内存的**两档价签**：限制到 192 几乎免费」（`M3-.../README.md:7`）——
     但同一文件 §1 第 2 点已写「**192 这一档本来就不疼**（不重训也 +0.0029）」，
     即「192 免费」不是训练的功劳，而是**没有头寸**（只砍掉 4.85% 可见性对）。
     把「没头寸」写成「有界内存可近零代价」会给读者一个错误的可用预算。
     **正确结论应该是**：「在本尺度（13M/T=256）上，把可见集限到 192 只砍掉 4.85% 的可见性
     对，因此无论重训与否都不痛；**训练补回只在 32 档被直接测到**（0.1495 → 0.0866，补回 42%）；
     窗口长度是否是带悬崖的杠杆，本批**不能判定**」。
   - 「窗口外信息仍是『丢了』不是『搬了』」（`catalog.yaml:1086`）——这条是**真结论**，
     且证据干净（整段在窗外的 494 根差恰好 0.000，`2616/analysis.md` §5.4）。
     它是本轴（乃至整条「信息右移」主线）**唯一跨条件稳定**的结论。

4. **无意义：是（本格的主命题层面）。** 「每 token 独立 vs 段级递归」在 13M 上是行业内置
   旋钮，且本地两点的读数已被自己判定「不可排序/无头寸」。⇒ 建议把 M3 收敛成
   一条 `reference` 记录 + 一条本地负结果（「掩码逼不出搬运」），**不再作为独立研究格续做**。

5. **值得做：低优先。** 若确需定位悬崖，补 64/128 两个训练点（≈ 2 × 8 min）；
   但先要证明该问题会改变任何部署判断——目前看不出。
