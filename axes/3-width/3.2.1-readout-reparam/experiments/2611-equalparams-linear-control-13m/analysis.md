## 0. 人话摘要

W4 这一格原来的结论是「在 tied 线性读出前面加一个**非线性**状态变换，能把
『读出几何』造成的质量损失收回约四分之一」。这一节问一个很朴素的问题：那个增益
到底是**非线性**带来的，还是仅仅因为**多花了 131072 个参数**（2·d²）？

于是我们造了一个「花一样多的参数、但数学上完全是线性」的对照臂：读出前做
`h' = h + P·(Q h)`（P、Q 各 d×d，整体等价于一个线性映射），其它一切与 gated 臂
逐字段相同（同数据、同步数、同 seed、同批大小、同学习率）。

**结果：这个纯线性对照臂与 gated 臂**无差异（不可排序）**了会做非线性的 gated 臂。**
干净 bpc（每字符比特数，越低越好）：基底 tied 线性 **1.8582** → gated **1.7770**
（改善 0.0812）→ 纯线性对照 **1.7694**（改善 0.0888）。两者与基底的差距只差
**0.0076**，远小于预先登记的 0.02 判据阈值。

**所以判据触发的是「降级」那一条**：gated 读出的收益**来自多出来的参数量/读出
重参数化自由度，而不是来自它的非线性**。原来「非线性状态变换打开读出可见空间」
的说法要改写成「把 tied 读出松一松（哪怕只松成线性）就能拿到这些收益」。

需要说清楚的边界：这个对照臂等价于「把 tied 读出表 E 换成 `(I+PQ)ᵀE`」，也就是
一次**自由线性读出重参数化**（131072 个新参数，等价 d² = 65536 个有效自由度）。
它证明的是「线性重参数化够用」，**不是**「随便在哪里加 131k 参数都能赚 0.08 bpc」
——后者没有被本实验证明（见 §9 下一步）。而且它仍然是一个比 gated 更弱的函数类
（无任何非线性），却拿到了同样的收益，这一点让「非线性是必要条件」的说法更站不住。

代价与风险：三臂全是 tied 表 E 仍然是唯一读出基（凸包/投影语义不变，因为
`(I+PQ)` 是线性映射）；出口资产 tf@4（用前 4 层当草稿、被全深度接受的比例）三臂
都在 0.966–0.969（都 ≥ 0.95），校准 ECE（置信度校准误差，越低越好）三臂都在
0.005–0.007；没有任何一臂出现 NaN 或梯度尖峰。**结论：2610 的 gated 结论降级为
「加参数的同价效果」**，主线应据此改写。

## 4. 判据线判读（预先写下，未改）

契约 B 判据（逐字）：

- ① 若本对照臂 Δbpc 与 gated 臂差距 **< 0.02** ⇒ 增益来自参数量而非非线性，gated
  结论降级。
- ② 若本对照臂 **Δbpc ≥ −0.014** 而 gated **≤ −0.05** ⇒ 非线性本身有效，结论加固。

实测：

| 量 | 值 |
|---|---|
| Δbpc(gated vs A) | **−0.0812** |
| Δbpc(linear vs A) | **−0.0888** |
| 差距 \|Δ_linear − Δ_gated\| | **0.0076** |
| ① 是否触发 | **是**（0.0076 < 0.02） |
| ② 是否触发 | 否（Δ_linear = −0.0888，远小于 −0.014 门槛） |

**裁决：增益来自参数量而非非线性 ⇒ gated 结论降级为「加参数的同价效果」。**
（catalog 的 W4 判读/税栏需要据此改写——**catalog.yaml 归主 Agent**，本执行者不改。）

判据纪律说明：阈值 0.02 > 方差界 0.014（`harness/methodology.md` §2），所以这条判据
在单 seed 下是**可判定**的：0.0076 落在方差界内 ⇒ 「两臂没有可排序的差异」，
「拿不到非线性的额外收益」这一结论成立。反过来，若差距落在 [0.014, 0.02) 则属
方差边界、不应裁决——本次未落入该区间。

## 6. 对账义务（SCHEMA §12，三道）

**被支持的数字 = Δbpc(linear) = −0.0888 与差距 0.0076。**

1. **算术对账**：
   - Δ 定义一致：`bpc_arm − bpc_A`。1.7694 − 1.8582 = **−0.0888**；
     1.7770 − 1.8582 = **−0.0812**。
   - 差距：\|(−0.0888) − (−0.0812)\| = **0.0076** < 0.02 ✓。
   - 参数量：7093760 − 6962688 = **131072** = 2·256² = 2·d²，两臂**逐位相等**
     （`reconciliation.arithmetic.params_extra_equal = true`）✓。
   - 判据阈值 0.02 > 方差界 0.014 ⇒ 可判定（阈值本身在下界问题上有对账）。
   - 边界收口：clean bpc 的理论下界为 0；本实验三臂均落在 (1.76, 1.86)，不存在
     越界或口径混淆（同一条 depth_curve 的 depth8 读数）。
2. **任务对账**：三臂测的是**同一件事**——同一 enwik8 char 级 AR 任务、同一数据
   切分（前 90M/末 10M）、**同一位置集**（全序列逐位置、depth-L 读出）、同一目标
   定义（`tokens` 自移位，`targets` 缺省 = tokens）。没有「假上下文 + 真目标」式
   对照：三臂读出**只依赖模型自身状态**，无任何真值泄漏。
3. **口径对账**：三臂同为 **12k 步 matched-step 快照**、98.3M token、seed 0、n=1、
   同 batch/lr、同一 `run_battery`（同 n_batches=20 / eval seed / batch_size）。
   非渐近、非墙钟、非 FLOPs。

**三道全过。** 不利数字同样如实报（见 §2.1 逐项表）：gated 臂在 tf@4/tf@6/ECE 上
略优于线性臂（+0.0024 / +0.0010 / −0.0012，均为方差级）；但**「非线性带来额外收益」
的正面证据在任何一项上都不存在**——线性臂在 clean bpc（主指标）与全部传输/提交资产
上都不劣于 gated 臂。

## 7. 口径、局限与风险（如实记录）

1. **n = 1 seed**。差值 0.0076 < 0.014 方差界 ⇒ 两臂**不可排序**，正是判据①
   所要编码的「没有本质差异」。不解锁 seeds 就不外推更细的排序。
2. **等参数 ≠ 等函数类**。线性臂的有效自由度只有 d²（`PQ` 复合），gated 臂名义
   2d² 且非线性更强。线性臂以**更弱的函数类**拿到同等收益，这加强了降级结论，
   但也意味着本对照**不能**回答「非线性是否有任何边际价值」（没测更强非线性）。
3. **本对照臂等价于一次自由线性读出重参数化**：`logits = h·[(I+PQ)ᵀ E]ᵀ`，即把
   tied 表 E 替换为 `(I+PQ)ᵀ E`（131072 参数 ≙ d² 有效自由度）。因此降级后的
   说法应写成「**tied 约束的线性解耦**（哪怕是等价的自由线性读出）就足以收回
   这批税」，而不是「任意位置加参数即可」（未测，见 §9）。
4. **A 臂是历史同配置 checkpoint**（不是本次新训），靠 §1 等值性门 + 电池逐位
   复现保证口径；代价是复现需 `.scratch/23-depth-ar/evidence/` 的权重。gated 臂
   同样复用 2610 的 checkpoint（哈希见 `MODEL.md`）。
5. **workspace 探针的 null 空间按 tied 表 U 定义**，三臂的 E 谱不同
   （有效秩 162 / 199 / 206），所以 null 能量占比是探索性量，不能读成「同一子空间
   里的能量迁移」。
6. **dense 税分母 1.5287** 是历史 `23d-dense-B-12k`（同引擎同 token 预算 dense AR），
   非本次实测；税口径为 matched-step 快照。
7. **稳定性只覆盖采样点**：`train_log.jsonl` 每 200 步一落，尖峰次数按采样点统计；
   全程 12000 步的真值 max 见 `gnorm_monitor`（`stability.md` 已分清两套口径）。
