# 2613 · 读出重参数化在普通 dense 模型上的可迁移性 · 13M —— 判读

> 契约：`README.md`（判据线逐字抄自 ticket 30「契约 F」，**未改**）。入口：`run.py`。
> 原始结果：`results.json`（seed 0）/ `results-seed1.json`（seed 1，n=1 负结果复现）；
> 稳定性专报：`stability.md`；权重清单：`MODEL.md`；变异报告：`mutation_report.json`。
> seed = 0 与 seed = 1，共 2 seed（每个 seed 两臂自包含双跑）。

## 0. 人话摘要

之前我们有一条结论：在 **depth-ar 形态**（一个模型要在 9 个不同深度上共用同一张
读出表）里，只要在读出前加一层**纯线性**的状态变换
`h' = h + P·(Q h)`（多花 131,072 个参数），干净 bpc 就改善 **0.089**
（1.8582 → 1.7694；bpc = 每字符比特数，越低越好）。它已经被证明不是「非线性」的功劳，
而是「把 tied 读出松绑」的功劳。本节问一个更干净的问题：**把这个便宜的小结构搬到
普通的 dense 变压器上，还灵不灵？**

答案：**不灵。** 普通 dense 模型上，两臂干净 bpc：

| 臂 | 干净 bpc（越低越好） | 参数 |
|---|---|---|
| baseline（tied 线性读出） | **1.5257** | 6,962,688 |
| linres（tied 线性 + 线性重参数化） | **1.5312** | 7,093,760（+131,072 = 2·d²） |

Δbpc_improvement = 1.5257 − 1.5312 = **−0.0055**（方向甚至是**变差**一点点），
\|Δ\| = 0.0055 < 预登记方差界 0.014 ⇒ **「不可迁移」**：读出重参数化只在 depth-ar
形态内有效，不是与架构无关的通用配方。作为对照，同一 hyper、同 token 预算、同 seed
下 depth-ar 上的同一干预是 −0.0888，比这里大 **16 倍**。

而且这一次我们**看得到原因**：dense 上模型几乎不用这块新自由度。读出变换的相对幅度
`||P(Qh)|| / ||h||` 在 dense 上只有 **0.009–0.012**（约 1%），而 depth-ar 上是
**1.64–1.70**（164–170%）；Q 的 fro 范数从初始 **5.13** 被训练**收缩**到 **0.89**。
也就是说：dense 模型主动把这层线性变换拉回接近恒等，参数还在（活性门通过），
但功能上等于没加。反过来看，depth-ar 之所以受益，是因为同一张读出表要在多个
（训练不足的）深度上同时工作——这正是它特有的「形态缺陷」。

需要说清楚的边界：这是 13M / 12k 步快照、两个 seed（seed0 + seed1 复现）的结论。
两个 seed 的 Δ 同号且都在方差界内（−0.0055 / −0.0026），机制也复现（Q 从 5.13
收缩到 ~0.86，变换幅度 ~1%）。两臂的 loss 斜率相近（末 25% 分别为 0.00297 / 0.00179
每千步，都还在缓慢下降），所以不是「linres 收敛更慢」造成的假差异。副作用：出口代理 tf@4 0.4352→0.4375
（dense 形态无中间监督，这个量只是 proxy，不能和 depth-ar 的 0.97 比）；
校准 ECE 0.0056→0.0073（都在 0.01 内）；无 NaN、无梯度跳步。

## 3. 干预活性门（SCHEMA §10 强制项）

`results.json::linres_arm::intervention`（训练结束时，seed 0）：

| 量 | 值 | 参照（depth-ar 2611 同干预） |
|---|---|---|
| P（readout_p）fro | **1.451** | 12.26 |
| Q（readout_q）fro | **0.8918** | 19.74 |
| Q 初始 fro | 5.1253（N(0,0.02)） | 5.1253 |
| 非零占比 | **1.0** | 1.0 |
| P / Q 谱范数 | 0.6525 / 0.3350 | 3.93 / 8.22 |
| 读出变换相对幅度 \|P(Qh)\|/\|h\| | **0.0089–0.0124**（depth0 = 0.0124） | 1.64–1.70（depth0 11.23） |
| params_added | 131,072（= 2·d²） | 131,072 |

**干预是否活着**：活性门**通过**（P/Q 全元素非零、非零占比 1.0、P fro 1.45）；
但**功能上接近恒等**——变换相对幅度只有 ~1%，而 depth-ar 上是 ~164%。更关键的是
**Q 被训练收缩**（初始 fro 5.13 → 终值 0.89，缩小 5.7×），即 dense 模型主动把这块
自由度收回。**seed 1 完全复现**：P fro 1.3467 / Q fro 0.8579（同样从 5.13 收缩）、
变换相对幅度 0.006–0.012。20 步冒烟里 P 已从 0 逃逸（P fro 0.0 → 1.09，
`smoke/smoke.json`），所以这不是「零初始鞍点」那类死干预，而是**模型学到了「不用它」**。

这恰好给了「不可迁移」一个可检验的机制解释：dense 只有一个出口读出，多余的线性
重参数化没有压力去改变状态几何；depth-ar 的同一张读出表要服务 9 个深度（其中多数
监督不足），才产生对状态重参数化的需求。

## 4. 判据线判读（预先写下，未改）

契约 F 判据（逐字）：`Δbpc 相对 baseline ≥ 0.014 ⇒ 可迁移`；
`|Δ| < 0.014 ⇒ 不可迁移（只在形态内有效）`；`Δ ≥ +0.014 ⇒ 负迁移`。

定义 `Δbpc_improvement = bpc_baseline − bpc_linres`（正 = 改善）。实测：

| 量 | seed 0 | seed 1（复现） |
|---|---|---|
| bpc_baseline | 1.5257 | 1.5298 |
| bpc_linres | 1.5312 | 1.5324 |
| Δbpc_improvement | **−0.0055** | **−0.0026** |
| \|Δ\| < 0.014？ | 是 | 是 |
| 触发哪条 | **不可迁移** | **不可迁移** |

**裁决：不可迁移。** 读出重参数化在普通 dense 模型上不产生（也不损失）可排序的
改善；它的 −0.0888 增益是 depth-ar 形态特异的。n=1 负结果按纪律用 seed=1 复现：
两 seed 的 Δ 同号且都在方差界内（−0.0055 / −0.0026），机制也复现——seed 1 的
Q fro 同样从 5.13 收缩到 0.858、变换相对幅度同样只有 0.006–0.012（约 1%）。

## 6. 对账义务（SCHEMA §12，三道）

**被支持的数字 = Δbpc_improvement = −0.0055（「不可迁移」）。** 负结果不强制对账，
但同样如实做：

1. **算术对账**：
   - Δ 定义一致：1.5257 − 1.5312 = **−0.0055**；\|Δ\| = 0.0055 < 方差界 0.014 ⇒
     「两臂不可排序」成立（这正是「不可迁移」的定义）。
   - 参数量：7,093,760 − 6,962,688 = **131,072** = 2·256² = 2·d² ✓（逐位）。
   - 边界：bpc 理论下界 0、均匀预测上界 log2(206) = 7.687；实测 depth0 ≈ 7.41、
     depth8 ≈ 1.53，均落在界内。
   - 跨形态参照：depth-ar 同干预 Δ=−0.0888（seed0/12k/同数据），本实验 Δ=−0.0055，
     比值 ≈16×；两个 Δ 都来自同一评测代码（`depth_curve` 的 depth-L 读数）。
   - **底噪**：全新重训 baseline vs 历史同配置同 seed = −0.0030（run-to-run 数值
     不确定性）。Δ=0.0055 约为底噪 1.8×，但仍 < 0.014 方差界 ⇒ 不裁决方向。
2. **任务对账**：两臂测的是**同一件事**——同一 enwik8 char 级 AR 任务、同一数据切分
   （前 90M/末 10M）、**同一位置集**（全序列逐位置，最终深度读出）、同一目标定义
   （`tokens` 自移位）。没有「假上下文 + 真目标」式对照：两臂读出只依赖模型自身状态，
   无真值泄漏。**对照臂三要素**：输入分布 = 同一 train 流随机窗口；预测什么 = 下一字符；
   部署对应 = stock decoder-only 的标准读出路径（对照只改读出前状态变换）。
3. **口径对账**：两臂同为 **12k 步 matched-step 快照**、98.3M token、seed 0、n=1
   （另 seed 1 复现）、同 batch/lr、同一 `run_battery`（同 n_batches=20 / eval seed /
   batch_size）。非渐近、非墙钟、非 FLOPs。

**三道全过。** 跨形态比较的口径声明：2611（depth-ar）与本实验（dense）的 hyper、
token 预算、seed、数据完全一致，但**训练目标不同**（depth-ar 全深度混合监督 vs
dense 仅最终 CE）——这正是被判的「形态」因素，属跨实验比较，不是同一实验内的受控 A/B。

## 7. 口径、局限与风险（如实记录）

1. **n=1 负结果已用 seed=1 复现**（§4）；两 seed 都落在方差界内 ⇒ 结论稳定，
   但两个 seed 仍不足以给出更细的排序（Δ < 0.014 不可排序）。
2. **run-to-run 底噪 ≈0.003**：本卡为共享卡，CUDA bf16 归约非确定；同 seed 重训
   baseline 与历史值差 −0.0030。Δ=0.0055 与此同量级 ⇒ 只报「不可迁移/不可排序」，
   不报「linres 更差」的强结论。
3. **dense 形态的 tf@k 是 proxy**：dense 只有最终深度被监督，中间深度读出未训练，
   tf@4≈0.44 不能与 depth-ar 的 tf@4≈0.97 相比，只有在导出「出口资产」时才需另测。
4. **跨形态归因是观察，不是受控实验**：本实验的结论是「同一干预在 dense 上无效」；
   「为什么 depth-ar 有效」由 §3 的幅度证据支持（模型是否使用这块自由度），但
   「多深度共用读出表」这一机制的因果性未被单独操纵验证（需另设计实验）。
5. **同 seed 的差异极小**：seed0 与 seed1 的 baseline bpc 分别为 1.5257 / 1.5298，
   说明 12k 快照本身有约 0.003 的随机性；这不影响 0.014 判据。两 seed 的 linres
   终值也分别为 1.5312 / 1.5324（Δ 同号、同量级）。
6. **历史 dense 税分母 1.5287** 是 `23d-dense-B-12k`（同引擎同 token 预算），
   本实验的 baseline 是全新重训的 1.5257（差 −0.0030，底噪内）。
7. **不触发 SCHEMA §15（等参数对照）**：本实验不声称增益（结论是「不可迁移」），
   所以不需要「等参数去掉该结构」的对照。反过来，若 linres 在本实验里显著更好，
   则必须先补一个「同样 +131,072 参数但加在非读出位点」的对照才能归因于读出几何
   而非容量（2611 已为此做过等参数纯线性对照）。

## 8. 失败决策树（契约 §8）触发情况

未触发「起步非恒等 / 参数量不等 / 干预死」等实现分支（单测 + 变异全绿、
恒等起步逐位、参数差 = 2d²、活性非零）。触发的是**「|Δ| < 0.014」分支**：
报「不可迁移」——读出重参数化只在 depth-ar 形态内有效，不叠加第二个机制。

回归：`python3 -m pytest tests/ -q` = **159 passed**（当前仓库基线；本实验未改
`tests/`，因为复用既有开关），本目录单测 `test_dense_readout_reparam.py` = **5 passed**。

## 9. 下一步（最小实验，不叠加第二机制）

1. **确认机制**：在 dense 上把线性重参数化**放到 trunk**（例如给每层加一次
   `h ← h + P(Qh)`，参数远多于 2d²）或把读出解绑（`logits = h·W_uᵀ`，52,736 参数，
   比 131,072 更少）——若「解绑读出」在 dense 上已能改善，则说明 dense 的问题不是
   读出几何，而是别的（2611 §9 的后续）。
2. **形态对照的受控版**：同一 dense 主干分别接 (a) 单出口读出、(b) 多深度读出
   并行监督，再各自 ± 线性重参数化 → 直接检验「多深度共用读出表」是否就是
   重参数化生效的条件（本实验只能观察，不能操纵）。
3. **规模**：13M → 29M 复跑两臂，看「dense 上无效」是否随规模保持。
4. **catalog / W4 主线改写**：W4 的「读出几何」结论需注明——线性重参数化的
   增益是 **depth-ar 形态特异**，不可作为通用配方外推（catalog.yaml 归主 Agent）。
