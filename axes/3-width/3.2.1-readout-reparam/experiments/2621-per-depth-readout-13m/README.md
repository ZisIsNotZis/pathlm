# 2621 · 逐深度独立读出 vs 共享 tied 读出 · 13M · depth-ar

> 本文件即本实验的本地契约。判据线**预先写下**（§4），不得事后调整。
> 原始结果：`results.json`；对账：`reconcile_numbers.py`；判读：`analysis.md`；稳定性/权重：`MODEL.md`。

## 1. 命题（可证伪）

W4 已记录：**读出重参数化**（gated `h + SiLU(W1 h)⊙(W2 h)` 或等参数纯线性
`h + P(Qh)`）在本形态（depth-AR）上 Δ clean bpc **−0.0812 / −0.0888**（12k），
但在普通 dense 上只有 **−0.0055 / −0.0026**（2613），因此被归因为
**「补本形态的读出缺陷」**。本实验**直接检验该归因**：

> 若本形态的缺陷是「**一个共享读出要服务所有深度**」，那么给**每个深度一套自己的
> 线性读出头**（逐深度独立读出）应当有效——且应在**等参数对照**下仍然有效。

可证伪点：逐深度读出的 Δbpc 落在方差界内（|Δ| < 0.014）⇒ 「共享读出」不是缺陷，
该归因被否证。

## 2. 单因素声明

**唯一变量 = 读出是否逐深度独立**。三个臂共用同一配方（depth-AR：全深度并行监督 +
carry 门 + 随机退出 + fill_kv + 同 seed + 同 token 预算 + 逐字段一致的超参）：

| 臂 | 读出 | 新增参数 |
|---|---|---|
| **A**（基底） | 共享 tied 读出 `logits_k = h_k·Eᵀ`（所有深度同一张表） | 0 |
| **PD**（本实验主臂） | **逐深度**独立读出：读出前做逐深度线性变换 `h_k → h_k + P_k(Q_k h_k)`（k = 0..L 各一套 d×d），再走共享 tied 表 ⇒ 每个深度的有效读出头 `(I + P_kQ_k)ᵀEᵀ` 各不相同 | (L+1)·2d² = **1,179,648** |
| **EP**（§15 等参数对照臂） | **单个共享**线性变换 `h_k → h_k + A(B h_k)`（A [d,m]、B [m,d]，m=(L+1)·d），**名义参数与 PD 臂相等**、但无逐深度自由度 | 2·d·m = (L+1)·2d² = **1,179,648** |

**为什么 PD 用「逐深度线性变换 + 共享 tied 表」而不是「每深度一个独立 [V,d] 头」**：
d=256 > V=206 时 `(I + P_kQ_k)ᵀEᵀ` 是一个可满秩的 `[d,V]` 线性头，与「每深度一个
独立 `[V,d]` 头」**表征等价**（无损失），同时保住 tied 表（prob0 / 软提交 Σp·E /
传输语义不变，docs/design.md §2 偏离点 1）；还使 §15 的**等参数对照**在纯线性家族内
可构造（一个独立 `[V,d]` 头最多只有 d·V 参数，共享侧根本无法匹配 (L+1)·d·V）。

**EP 的诚实声明（§15）**：深度无关的线性映射最多只有 d² 个**有效**自由度，因此
EP 的「名义等参数」是靠**冗余**达成的（1,179,648 个参数只参数化一个 d×d 映射）。
这正是要检验的对比——**(L+1) 个独立 d×d 映射 vs 1 个共享 d×d 映射、同名义预算**；
但它不是「同有效容量」对照 ⇒ 结果含「有效容量」混杂，必须在结论里写清（见 §4 C2）。

基底 = RAP 共享底座（三条必要偏离见 `docs/design.md` §2），不引入第二个非标准因素。
**非必要性例外**：无。A 臂按 SCHEMA §9 复用历史 run（实现层开关关闭逐位等值单测 +
配置层逐字段对照 + 口径标注三道门）。

## 4. 判据线（预先写下，不得修改）

**符号约定（全篇一致）**：`Δbpc(X) = bpc(X) − bpc(A)`，**负 = 改善**。
方差界：Δ < 0.014 不可排序（`docs/methodology.md` §2）。

- **C1（归因主判据）**：逐深度读出是否有效。
  - `Δbpc(PD) ≤ −0.014` ⇒ 逐深度读出**有效** ⇒ **支持** W4 归因（缺陷 = 共享读出）；
  - `|Δbpc(PD)| < 0.014` ⇒ 逐深度读出**无效** ⇒ **否证**该归因（缺陷不是共享）；
  - `−0.014 < Δbpc(PD) < 0` ⇒ 落在方差界内，如实报「不可排序」。
  - 并列（不单独裁决）：tf@4 相对 A 下降 > 0.01 时，即使 bpc 过线也标注「出口资产受损」。
- **C2（§15 等参数对照 · 容量 vs 逐深度独立性）**：
  - `|Δbpc(PD) − Δbpc(EP)| < 0.014` ⇒ 增益**归因于容量**（共享的大变换已足够），
    逐深度独立性无额外贡献；
  - `Δbpc(PD) ≤ Δbpc(EP) − 0.014`（PD 明显更好）⇒ **逐深度独立性本身有效**；
  - **必须同时声明 EP 的有效容量混杂**（EP 的名义参数冗余 ⇒ 二者不等有效容量）。
- **C3（干预活性门，§10）**：两新臂的干预量在 12k 步后必须显著非零；每 200 步落盘。
  不过 ⇒ 不判机制，先修实现。
- **C4（参数量，§15）**：报 Δparams；PD/EP 各 +(L+1)·2d²；二者必须**逐位相等**
  （可失败单测钉住）。
- **C5（斜率，§16）**：A/PD/EP 三臂的**同方法** loss 斜率（同一末 25% 窗、同一算法）。
  本实验只有 12k 一个点、**无 2× 更长点** ⇒ 只作 matched-step 快照结论，
  **不外推**；缺更长点记为下一步最小实验（§23 七问第 6 条）。
- **副产品（不裁决）**：tf@4/tf@6、ECE、workspace 探针、深度-bpc 单调性。

## 5. 对照与方差

- **A 臂**（共享 tied 读出，`.scratch/23-depth-ar/evidence/23c-H2-w0-12k`，同配置同 seed）
  = Δ 的参照（§9 复用：开关关闭逐位等值单测 + 逐字段对照 + 口径标注）；
- **gated 臂**（2610 主臂，12k，共享非线性重参数化 2d²）与 **linear 臂**（2611，12k，
  共享线性重参数化 2d²）= W4 既有参照点，用当前评测代码同口径重测，用来把 PD 放在
  「共享小重参数化 → 逐深度」这条线上；
- **PD / EP** 各 1 seed（seed 0，契约未授权补 seed）；四臂同 seed。
- 方差界：Δ < 0.014 不可排序。

## 10. 既有做法（prior art，SCHEMA §18 必需）

> 检索方式：本线**无 web 工具**（环境未提供检索能力）⇒ 以下全部标注 `记忆·未核`，
> 只用于设计方向，**不得当判据**。检索词（记忆检索）：per-layer classifier head /
> multi-exit network / untied output embedding / deep supervision / per-depth readout /
> early-exit transformer classifier head。

1. **多出口 / 早退网络**（BranchyNet, Teerapittayanon et al. 2016；Shallow-Deep
   Networks, Kaya et al. 2019；MSDNet, Huang et al. 2018）：**每个出口/层各挂一个
   分类头**。为什么这么设计：提前出口的样本也要能产生输出，逐出口头是唯一直接做法。
   结果：逐出口头在分类网络上普遍有效（记忆·未核）。**我们增量**：这是工程标准，
   但**没有人把它当作「解释某种读出重参数化增益来自何处」的受控诊断**，也没有
   「共享读出 vs 逐深度独立读出、同参数预算」的对照。
2. **深度监督**（Deeply-Supervised Nets, Lee et al. 2015）：逐层辅助分类器改善
   梯度传播。记忆·未核。**我们增量**：我们把「逐深度头」当**读出几何**的单因素
   干预（同参数量对照），不是当训练技巧。
3. **输出嵌入解绑**（Press & Wolf 2017 "Using the Output Embedding to Improve
   Language Models"；Inan et al. 2016 tying）：tied vs untied unembed 的取舍——
   小数据上 tying 更正则化、大数据上可解绑。记忆·未核。**我们增量**：本实验不是
   tied vs untied（那会改词表侧参数量与带宽、破坏本形态的 tied 桥），而是**在 tied
   表不变的前提下**把读出前的线性映射做成逐深度——即「同一张表、逐深度读出头」。
4. **深度自适应 / 自 spec 的逐层置信头**（CALM, Schuster et al. 2022；
   self-speculative decoding, Zhang et al. 2023）：核心贡献是逐层置信度估计，
   readout 本身仍共享。记忆·未核。**我们增量**：我们的问题恰是「共享 readout 是否
   是本形态的缺陷」，这在其设定下未被检验。
5. **W4 本地事实**（本地实测，非记忆）：共享 2d² 重参数化在本形态 12k 有效
   （−0.0812 / −0.0888），在 stock dense 上几乎无效（−0.0055 / −0.0026，2613）
   ⇒ 归因「补本形态的读出缺陷」。**我们增量**：直接检验该归因的最小实验（逐深度
   读出 vs 共享，等参数对照）。

**分诊（§21）**：(b) 我们的设定实质不同（13M depth-AR 单因素受控 + 同参数对照 +
诊断目的）⇒ **做实验**；(a) 类仅作为设计方向，不进状态灯。
