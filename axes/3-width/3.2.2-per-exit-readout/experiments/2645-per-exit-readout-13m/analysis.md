# 2645 · 逐出口读出 · 分析（人话摘要 + 判据线 + 未跑清单）

## 0. 人话摘要

多出口模型里，每个出口都要把该深度的隐藏状态翻成一整张词表的概率。本实验问的是：
**九个出口共用一张表（tied）够不够，还是每个出口要自己一套映射**。四个形态都只改
「出口 → 词表」这一段，主干（8 层、256 宽、随机退出深度、混合填充）逐位不动：`T`
共用 tied 表；`PE` 共用表 + 每出口一个 256×256 变换（起步是恒等，等于从 `T` 出发学）；
`IND` 每个出口一整张 206×256 独立的表（起步就是另一套随机表）；`LR` 在共用表上加每出口
的秩 16 校正（起步也是恒等）。判据主看**浅出口的接受率 tf@k**（早退真正依赖的那一层），
再看末层质量有没有被拖坏、以及各臂多花了多少参数。

**本次没跑成任何 12k 臂**（原因见 §4：本单要求单条命令 ≤180 s，而一条 12k 臂在本机同规模
实测要 12.7 min，且引擎没有 `--resume` ⇒ 不能分块续训；GPU 锁亦被其它轴的长任务连续占用，
两次共 ~4 min 的等锁都没等到）。所以本文件**不给任何数字**，`results.json` 里每个臂的
`status` 一律是「未跑」。已经做成的部分是**可复核的地基**：预登记契约、四臂实现、17 项单测
（含能变红的变异门）、锚复用的三道门、以及一个可结论化的**表达力事实**（§3）。

## 2. §3 表达力事实（本尺度，跑臂前就能判）

V=206 < d=256 ⇒ 对**任意**目标出口头 `Y ∈ R^{206×256}`，都存在 `M` 使 `E·M = Y`
（`E` 满行秩，取 `M = E⁺Y`；数值残差 < 1e-5，单测 `T5`）。因此在本 tokenizer 尺度上：

* `PE` 的有效出口头族（`F_k = E·M_k`）**等于任意线性头族**，也就是**包含 `IND` 的表族**；
* 「`IND` 更表达力强」在本尺度**不成立**；`IND` 与 `PE` 的差别只剩**参数化与初始化**
  （恒等起步 vs 随机起步）与**参数账**（`IND` = 出口数 × V·d，随真词表线性膨胀，不可 scale）；
* 反过来，**V > d 时该等号消失**（`E·M` 只有 d 维自由度）⇒ 本结论**不外推到真词表**。

这条事实决定了 P4 第二行怎么读：若将来只有 `IND` 能提升而 `PE` 不能，那不是「表达力」
差异，而是**优化/初始化**差异（或噪声），因此**不构成采纳 `IND` 的理由**（它不可 scale）。

## 4. 未做 / 受阻原因（如实登记）

1. **12k 臂一条也没跑**。两条独立原因，任一条都足以阻断：
   * **单条命令 ≤180 s（本单硬约束）** vs 同规模实测墙钟：`2610` 的 12k depth-AR 训练
     `wall=12.69 min`（`axes/3-width/3.2.1-readout-reparam/experiments/2610-gated-readout-13m-depthar/run_log.txt`）。

     既跑不完也接不上；本单又禁止 `setsid`/`nohup`/后台驱动 ⇒ 前台无法承载。
   * **GPU 锁饥饿**：`/tmp/pathlm_gpu.lock` 在本次会话被其它轴的长任务连续占用
     （观察到 holder 由 `wp2655-layer-capacity` 换成 `wp6.3.1-mdiff-s0`），两次共约
     4 min 的前台等待（110 s + 140 s）均未取到锁；按本单规定**不杀他人进程、不回收他人锁**。
2. **冒烟（60 步，rc=0 前置）未做**：同样卡在锁上（冒烟也要取锁）。冒烟路径已实现并接线

   但**未执行**，故本文件的「可跑」不等于「已跑」。
3. **锚重测（`--stage anchor`）未做**：本不需训练，但仍需一次 GPU 前向电池（~1 min）与锁；

   `anchor.recheck_*` 字段为 `null`。§1 的 `T1`–`T8` 单测是 CPU 门，与锚重测不冲突。

## 5. 与 `3.2.1` 的边界（复核须核）

`3.2.1` 的 `2621-per-depth-readout-13m` 已有「逐深度独立读出」臂 `PD`
（`h_k → h_k + P_k(Q_k h_k)` 再走共享 tied 表），其有效出口头 `F_k = E(I + P_kQ_k)`
**落在 `PE` 的同一函数族内**（§2）。`3.2.1` 的判决是：`PD` 被**等参数「共享宽变换」对照
否证**（Δ −0.0759 vs −0.1313）。因此：

* 本实验若将来跑出 `PE` 读数，**不得**当作与 `2621` 独立的证据；两个读数必须同框，
  且要说明差别只在**参数化**（直接 `M_k`、恒等起步）与**主判据**（逐出口 `tf@k` 而非整体 bpc）；
* 本项的增量只在「**逐出口 `tf@k`** 这一列 + `IND` 的参数量单列」，不在「再证一次逐深度读出有用」。
