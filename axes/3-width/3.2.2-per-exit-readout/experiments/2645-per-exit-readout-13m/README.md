# 2645 · 逐出口读出（per-exit readout）· 13M · depth-AR

> 本文件是**预登记契约**（臂 / 判据线 P1–P4 / 否证线 / 带声明）：起跑后不改（口径差异
> 一律写进 `analysis.md` 声明）。研究项 = `axes/3-width/3.2.2-per-exit-readout`。

## 1. 人话摘要

**它是干什么的**：普通 transformer 只有一个出口（末层），一张单词表映射（tied 线性读出）
就够。早退 / 多出口模型每一步都要把「该深度的隐藏状态」映射到整张词表，于是出现一个
选择——**九个出口共用一张表，还是每个出口自己一张**？本实验就是判这一条。

**改了什么**：只改「出口 → 词表」的映射，主干（层数、宽度、注意力、FFN、门、退出采样）
逐位不动。四个形态：共用 tied 表（`T`）、共用表 + 每出口 d×d 变换（`PE`）、每出口独立表
（`IND`）、每出口低秩校正（`LR`）。

**为什么值得测**：共享 tied 表把所有出口绑在「概率 = 状态在 embedding 基的坐标」这条
约束上；浅出口质量（早退真正用到的那一层）可能因此被压低。代价一侧 `IND` 是词表 × 维度
（真词表 100k+ 时不可 scale），`PE`/`LR` 是每出口 d² 或 d·r（可 scale）。

**怎么测**：13M、d=256/L=8/变深度 + 随机退出 + `fill_kv`、12000 步、enwik8 字符级
（vocab=206）、同 seed；对照 = 同批重训的共享 tied 臂 `T`（若未跑则复用历史锚
`.scratch/23-depth-ar/evidence/23c-H2-w0-12k`，clean bpc 1.8582 / tf@4 0.9694 / tf@6 0.9938）。
主判据是**各出口 tf@k**（深度 1..7 的草稿被全深度出口接受的比例）+ 末层 clean bpc + 读出
参数量。

**测出来多少**：见 `analysis.md`（本次是否跑成，如实登记，不编读数）。

## 3. 臂（实验目录内实现，不改引擎）

| 臂 | 定义 | 每出口自有参数 | 9 出口合计 | tied 桥 |
|---|---|---|---|---|
| `T` | `logits_k = h_k·Eᵀ`（stock，共享 tied 表） | 0 | 0 | 有（= 100% 参照） |
| `PE` | `logits_k = (M_k h_k)·Eᵀ`，`M_k` [d,d]，`M_k = I` 起步 | d² = 65,536 | 589,824 | 有（`F_k = E·M_k`） |
| `IND` | `logits_k = tab_k(h_k)`，`tab_k` [V,d] ~ N(0,0.02) | V·d = 52,736 | 474,624 | **无** |
| `LR` | `F_k = E + A_k B_k`（`A_k` [V,r]=0、`B_k` [r,d]~N(0,0.02)，r=16） | V·r + r·d = 7,392 | 66,528 | 有 |
| `WIDE` | **等参数对照（第二批，§11）**：读出同 `T`（0 参数），**主干**每层 FFN 隐藏宽 1024 → 1168 | 0 | 0（主干 +590,976） | 有（逐位 = `T` 的读出） |

实现要点（全部写在 `run.py` 内，`pathlm/**` 不动）：

* `PerExitModel(DepthARModel)` 只覆写 `readout(h, depth)`；`T` 臂直接回落
  `super().readout(...)`（= stock 路径），单测 `T1` 钉住逐位相同。`WIDE` 的读出与 `T`
  **同一路径**（`NO_READOUT_ARMS`），它的干预在主干的 `cfg_for(arm)` 里。
* 起步恒等：`PE`（`M_k = I`）与 `LR`（`A_k = 0`）的起步读出**逐位等于** `T`
  （单测 `T1`），且非鞍点（`∂L/∂M_k ≠ 0`、`∂L/∂A_k ≠ 0`，单测 `T4`；`LR` 的
  另一侧 `∂L/∂B_k = 0` 是该结构的恒等式，一并钉住）。
* **表达力定理（本尺度）**：V=206 < d=256 ⇒ 对任意目标头 `Y ∈ R^{V×d}` 存在 `M`
  使 `E·M = Y`（`E` 满行秩，`M = E⁺Y` 即可）⇒ **`PE` 的有效出口头族 = 任意线性头族，
  ⊇ `IND` 的表族**。所以本实验的 `PE` vs `IND` 比的是**参数化 + 初始化**（`PE` 恒等起步、
  每出口 d² > V·d 参数），不是表达力；`IND` 的「不可 scale」是**参数量/真词表**问题
  （V·d·出口数），不是「只有它能表达」。数值证据见单测 `T5`（`lstsq` 解 `E M = Y`，残差 < 1e-5）。

## 4. 判据线（预登记，跑后不改）

* **P1（主判）**：各出口 `tf@k`（深度 1..7，全深度出口 8 为验证者）。
  逐臂相对参考臂（同批 `T`；无 `T` 则历史锚）做**同批配对差**，用按批 cluster
  bootstrap 95% CI 判「可排序 / 不可分」，同时报各臂水平的 Wilson 95% CI 与
  n（每批 16×255 = 4080 token、20 批 = 81,600）。**结论以「浅出口（1..4）是否出现
  可分且为正的 Δ」为核心**。
* **P2**：末层（全深度）clean bpc **不劣于**参考臂（不越 **0.014 bpc 带**，限配对 Δ），
  并单列读出参数量（`IND` = 出口数 × V·d = 9 × 52,736 = 474,624，判可否 scale）。
* **P3**：prob0 / 软提交语义仍可用——prob0 ECE 相对参考臂的差 ≤ **0.003**（承 2610 判据线，
  本实验声明为容差），并报「出口 logits 的 argmax 与 tied 表基坐标 argmax 的一致率」
  （`T`/`PE`/`LR` 构造性 1.0，`IND` 无 tied 桥、须实测）。
* **P4（否证线）**：
  - 若 `PE` 不能让浅出口 `tf@k` 可排序提升 ⇒ 判「**共享表够用**（本尺度）」；
  - 若只有不可 scale 的 `IND` 能提升、而 `PE`/`LR` 不能 ⇒ 判「该手段不实用」；
  - 若任何臂损末层质量（`Δ clean bpc > +0.014`）⇒ 判「**不成立**」。
* **P5（等参数对照／归因，第二批预登记）**：问的是「`PE` 的末层增益里，有多少能被
  **把同一笔参数花在主干上**复现」，即**参数是不是全部解释**。三个数（余部 arm − comparator，
  负 = 更好）：`Δ_W = bpc(WIDE) − bpc(T)`、`Δ_P = bpc(PE) − bpc(T)`、
  `R = bpc(PE) − bpc(WIDE)`（残余）。分支按 §4 的 0.014 带：
  - `|Δ_W| ≤ 0.014` ⇒ **`params_not_the_explanation`**：主干花这笔钱买不到可排序的质量
    ⇒ 增益不归「多了参数」这件一般事实，归读出结构本身（它的参数化）；残余 = `|R|`；
  - `|Δ_W| > 0.014` 且 `|R| ≤ 0.014` ⇒ **`params_explain_all`**：等参数对照追平，逐出口
    读出无额外收益；
  - `|Δ_W| > 0.014` 且 `R < −0.014` ⇒ **`params_explain_part`**：参数解释一部分，残余 `|R|`
    仍越带（`PE` 仍占优）；
  - `|Δ_W| > 0.014` 且 `R > +0.014` ⇒ **`trunk_better`**：这笔钱花在主干上更好 ⇒ `PE`
    作为「买容量」的手段也不成立。
  **n 规则同 §4**：两 seed 落同一分支 ⇒ n=2 出判词；分支不一致 ⇒ 判「本 n 下不可判」并给
  所需样本量 `n_req = ceil((2.9·sd/|mean − band|)²)`（`sd` 由 n=2 种子散布估，近似式），
  不取平均掩盖。`WIDE` 的 `tf@k` / ECE 只作**副判据报告**（P5 的判词只由 clean bpc 残余定）。
* **带声明**：clean bpc 差用 **0.014 bpc 带**（限配对 Δ）；`tf@k` / 一致率等**率类**指标走
  配对 cluster bootstrap / Wilson 95% CI，**不跨量纲借用** 0.014。
* **必须不变**：因果性（单测 `T6` + 评测里的 `causal` 列）、评测确定性（同 checkpoint
  两次 `depth_curve` 逐位一致，`reeval_bitwise_identical`）。
* **n 与升格路径**（`config.json::n2_rule`）：`PE` 与同批对照 `T` 各跑 **seed 0 与 seed 1**。
  判词规则只有这一条：同一深度上的 Δ 在**两 seed 各自可分**（tf@k 的配对 cluster bootstrap
  95% CI 不含 0；clean bpc 越 0.014 配对带）且**同向** ⇒ 该判据按 **n=2** 出判词；两 seed
  **不同向**（或任一 seed 不可分）⇒ 判「本 n 下不可排序」，`status` 停「进行中」，**不得**
  把不一致解释成噪声、不得对两 seed 取平均掩盖。同一臂跨 seed 的 clean bpc 之差 = 两个独立
  训练 run 之差，只作**参考线**，不与 0.014 配对带混用（`harness/methodology.md` §2）。
  `IND` / `LR` 两臂本轮不跑 ⇒ 它们在本轮只报「未跑」与解析参数量，不作任何推断。
  `WIDE` 与同批对照 `T` 也必须**两 seed 都跑**（seed 0 / seed 1），P5 的 n=2 规则同段末两句。

## 6. 每出口读出的等效理论量（MACs/token，不含时间量）

主干 = L·(4d² + 2Td) + L·2·mlp_mult·d²；出口读出每出口 = d·V（tied 表）+ 校正项
（`PE` +d²、`IND` +0 但参数 V·d、`LR` +d·r+r·V）。训练期每 token 在 9 个出口算 logits、
推理期只 1 个出口 —— 两列分开报（`results_PE_s0_12k.json::cost` 与 `results_T_s0_12k.json::cost`；
聚合 `results.json` 的 `arm_rows` 只有 bpc / tf / 参数，不带 cost 段）。出口读出**不重跑主干**，
layer-passes 每 token 不增加；tokens-per-forward = 1。

## 10. 边界与未测项（预登记）

* 单尺寸（13M / 8L / V=206）、2 个 seed（`T` / `PE` / `WIDE`）：量级与规模外推未测；**真词表（100k+）
  下 `PE` 的表达力优势消失**（V > d 时 `E·M` 只有 d 维自由度）⇒ 本项结论**不外推到真词表**。
  `IND` / `LR` 两臂本轮未跑，故「只有不可 scale 的独立表能提升」这一否证分支本轮无本地读数。
* `WIDE` 只把「这笔参数花在主干」实现为**一种**放法（每层 FFN 等宽加宽 144）；其它放法
  （加层、加宽 d_model、加宽 attention）未测 ⇒ P5 的「参数不是全部解释」不得读成「任何地方
  多参数都买不到质量」，只能读成「FFN 等宽加宽这一种放法买不到可排序的质量」。
* `WIDE` 改的是主干，因此它**不是** `T` 的逐位超集（加宽 FFN 改变 RNG 流 ⇒ 后续参数不同），
  它也不能与 `PE` 共享初始化；两臂比的不是同一个模型，而是「同一笔参数花在哪」。
* 「出口在哪一层」与「每 token 跑几层」归深度轴 `2.1.1`，本项只判「出口 → 词表」。
* 只测**训练期逐层监督**（aux 等权 1.0）下的出口质量；推理期早退调度不在本项。

## 11. 等参数对照臂 `WIDE`（第二批，预登记）

**要答什么**：`PE` 的末层增益（Δ clean bpc −0.0857 / −0.0811）是不是只因为**多了 9·d² =
589,824 参数**（相对 `T` 总参数 +8.5%）？即「多了参数所以更好」还是「读出结构本身有额外收益」。

**两个候选，择一**：

1. （**选**）**把同一笔参数给稠密基线的主干**：读出保持 stock tied 表，每层 FFN 隐藏宽
   1024 → 1168（`mlp_hidden_sched = [1168]×8`，引擎已有开关 E2/E4，不写新引擎代码）。
2. （不选）**把逐出口读出压到等参数**：要让 `PE` 的参数落到 `T` 的「0 个额外参数」上，那就是
   `T` 本身；中间形态（共享宽变换、降秩）要么在 V=206 / d=256 下绕开整数参数点，要么重新
   引入「名义等参数但有效自由度只有 d²」的混清（同一混清已在 `3.2.1` 的 `EP` 臂上被显式标注，
   见 `axes/3-width/3.2.1-readout-reparam/experiments/2621-per-depth-readout-13m/README.md` §2）。
   另：「参数总量是旋钮」已由 `3.1.1` / `3.1.4` 判定 ⇒ 本格**不重开那个问题**，只用它做对照。

**参数/算力记账**（逐位可验，单测 `T9` 钉住）：

| 项 | `T` | `PE` | `WIDE` | `WIDE` − `PE` |
|---|---|---|---|---|
| 参数总量 | 6,962,688 | 7,552,512 | 7,553,664 | **+1,152（+0.015%）** |
| 读出参数 / 主干增量 | 0 | 589,824 | 0 / 590,976 | −589,824 / +590,976 |
| 每 token 训练 MACs | 7,814,656 | 8,404,480 | 8,404,480 | **0（严格对齐）** |
| 每 token 推理 MACs | 7,392,768 | 7,458,304 | 7,982,592 | +524,288（对照臂占便宜） |
| 每层 FFN 隐藏宽 | 1024 | 1024 | 1168 | — |

**偏差的诚实声明**：① 参数上 `WIDE` 比 `PE` 多 **1,152**（+0.015% 总参数、+0.2% 增量）
——方向对**对照臂**有利，故若对照臂未追平 `PE`，结论不因这 1,152 翻转；若追平，也需记住
对照臂多了 0.2% 增量。② 算力上两者训练期严格相等，但 `WIDE` **推理期**多 524,288 MACs/token
（FFN 加宽在推理也要付）——同样对对照臂有利。③ `WIDE` 只代表「FFN 等宽加宽」这一种放法（§10）。

**不预置结论**：`3.1.4` 已测到「每省 1% 每 token 算力 ≈ +0.0014 bpc」的总量斜率，按它线性外推
+8.5% 参数只能买到约 −0.010 bpc（≈ `PE` 增益的 12%）；但这只是**先验**，不是读数，P5 的判词
只由本臂实测与 §4 的带规则出。
