# 2687 · 可学习通道选择器（打分器 + 负载均衡项）· 13M · dense

> 本文件是**预登记契约**：§1–§10 在起跑前写定，跑前 `python3 tools/prereg_bind.py
> . --contract README.md config.json run.py` 绑定；读数落 `results.json`，人话判读落 `analysis.md`。
> 它只回答一件事：上一轮判的「条件性有害」是**那个无参数实现**的毛病，还是「逐 token 条件选通道」
> **这个机制**本身的问题（`axes/3-width/3.1.5-channel-sparsity/project.yaml::gaps` 第一条）。

## 1 要回答的判决问题

上一轮（`2644`）在 13M / 12k 步上判：总参数不变、每 token 只算 512/1024 个 FFN 通道，代价是
+0.036～+0.110 bpc（越 0.014 带）；而把「算哪一半」交给**逐 token 按 `|pre-activation|` 挑**，
比**固定常开前一半**还差 **+0.0617**，且更费算力（`lin1` 必须全算）。那一轮的选择器**没有参数**
——没有任何训练信号教它「该选谁」。

本实验给它**参数**、**训练信号**与**负载均衡项**，问同一个问题的加强版：

* **H1**：可学习选择器（`L50`）相对无参数 `|pre|` 规则（`K50`）**可排序更优**（Δ ≤ −0.014）
  ⇒ 上一轮的负结论是**那个实现**的毛病，条件选通道这个机制没被否证；
* **H0**：两者**不可排序**（|Δ| < 0.014）⇒ 本尺度上「给选择器参数」不改变判断；
* **H2**：可学习选择器**可排序更差**（Δ ≥ +0.014）⇒ 给参数也救不回来，负结论从实现升级到机制。

**必须不变**：总参数逐臂逐位相等（7 044 608，四臂同一份打分器模块，只有 `L50` 训练它）、因果性、
`D` 臂前向与 stock 逐位相同、`L50` 初始选择集与 `K50` 逐位相同（嵌套性）。

## 2 单因素声明

**唯一变量 = 通道子集的选择信号**。其余逐字段相同：`d=256, layers=8, heads=8, seq=256,
mlp_mult=4, steps=12000, bs=32, lr=1e-3, seed`，enwik8 字符级（vocab 206，`data/enwik8_full.npz`），
`--dense --topology sequential --exit-mode uniform`，评测批 `depth_curve(n_batches=20, bs=16,
generator seed 2)`。

四臂：

| 臂 | 选择信号 | 每 token 激活通道 | 选择器参数 |
|---|---|---|---|
| `D` | 不选（全通道） | 1024 | 有但冻结、不用 |
| `K50` | 逐 token `|pre-activation|` top-k（**无参数**） | 512 | 有但冻结、不用 |
| `F50` | 固定常开前 512（**无条件性**） | 512 | 有但冻结、不用 |
| `L50` | 逐 token `s = |pre| · exp(g(x))` 的 top-k，**`g` 可学习** | 512 | **可训练** |

### 2.1 干预实现（为什么它不是「换了个模型」）

挂点 = 各 `Block.mlp`（`nn.Sequential(Linear(d,H), GELU(), Linear(H,d), Dropout)`，`H = 1024`）。
本实验在**实验目录内**把每个 `blk.mlp` 换成包装模块 `ScoredFFN`，前向为
`out = drop(lin2(gelu(lin1(x)) * mask))`，**不改引擎**（`pathlm/**`、`train_*.py` 一字未动）；
训练走共享 `train_depth_ar.main()`（同 `2644` 的工厂接线）。

- **打分器**（四臂都有，同一形状）：`g(x) = GELU(x A) B`，逐层 `A[d,r]`、`B[r,H]`，`r = 8`
  ⇒ 每层 10 240 参数 / 每 token 10 240 MACs；`B` **零初始化**。只有 `L50` 的 `A/B` 是
  `requires_grad=True`；其余三臂冻结且**前向不用它**（拿到预算但不花，记账以保持等算力位点）。
- **`L50` 的打分**：`s = |pre| · exp(g(x))`。`B ≡ 0` ⇒ `g ≡ 0` ⇒ `s = |pre|` **逐位**相同 ⇒
  第一选择集 = `K50`（单测 `T5`）。⇒ 臂间唯一差异 = **这份预算是否被训练**。
- **直通估计**：前向用硬 0/1 掩码（与 `K50` 同形，**不缩放**激活），反向经
  `p = softmax(s)` 的被选集归一概率把梯度送到打分器；残项 `t − t.detach()` 前向恒为精确 0
  （单测 `T6`），故前向值逐位等于硬掩码。
- **负载均衡项**（Switch 式）：`aux = Σ_j f̂_j · P_j`，`f̂_j` = 通道 j 的被选频率按 `H/k` 归一
  （均值 1）、`P_j` = `softmax(s)` 的逐 token 均值的通道均值；`α = 0.01`，`loss = CE + α·aux`，
  由实验目录内的 `SelectorModel.forward` 覆写加上（不改共享训练器）。完美均匀 ⇒ 1.0。
- **等值门**：`D` 臂掩码恒 1（`x * 1.0` 精确）⇒ 前向与 stock **逐位相同**（单测 `T1`），
  且 `T2` 钉住该门不是恒真。

## 3 臂定义与代价（等效理论量，不含任何时间量）

`d=256, H=1024, k=512`；每 token MACs = attention `L·(4d²+2Td)` + FFN（实现口径）+ 读出 `d·V`
+ **选择器预算 `L·(d·r + r·H)`（四臂同额）**：

| 臂 | FFN MACs（实现口径） | 选择器 MACs | 每 token 总 MACs | 相对 `D` | 总参数 | 可训练参数 |
|---|---|---|---|---|---|---|
| `D` | 4 194 304（×1.000） | 81 920 | 7 474 688 | ×1.000 | 7 044 608 | 6 962 688 |
| `K50` | 3 145 728（×0.750） | 81 920 | 6 426 112 | ×0.860 | 7 044 608 | 6 962 688 |
| `F50` | 2 097 152（×0.500） | 81 920 | 5 377 536 | ×0.719 | 7 044 608 | 6 962 688 |
| `L50` | 3 145 728（×0.750） | 81 920 | 6 426 112 | ×0.860 | 7 044 608 | 7 044 608 |

- **实现口径（primary）**：按内容选通道必须先算全部 pre-activation ⇒ `lin1` 省不掉，`K50`/`L50`
  只省 `lin2`；`F50`（固定前缀）能同时切两个矩阵。
- **等预算声明**：`D`/`K50`/`F50` 也记 81 920 MACs 的选择器预算（它们不花，但预算在账上）
  ⇒ `L50` 与 `K50` 逐位等算力、逐位等参数。**这条是本实验能回答「机制 vs 实现」的前提**：
  如果 `L50` 赢了，赢的不是「多给了参数或算力」。
- 选择器的比较/排序开销（每层每 token 一次 1024 元 top-k）不计 MACs，与 `2644` 同口径。

## 4 判据线（预登记，不可事后调整）

基准唯一且显式：`D` 臂（`2641` 的 `U4-s0`，本实验在同一代码路径上重评），`K50`/`F50` 复用
`2644` 的 checkpoint 并用同一段评测代码重评（复现门见 §5）。带 = **0.014 bpc**
（`harness/methodology.md` §2，限配对 Δ）。

- **G1（活性门，先于质量门）**：打分器在 `L50` 里是否真被训练动。两个量都要过，**两个 seed 都要过**：
  - `scorer_move_relative` = `‖θ_打分器(末) − θ_打分器(初)‖₂ / ‖θ_打分器(初)‖₂` **≥ 0.01**；
  - `flip_vs_init` = 评测集上「每个 (层, 位置) 的 `L50` 选择集 ≠ **初始打分器**在同一批激活上的
    选择集」的比例 **≥ 0.05**，且 Wilson 95% CI 下界 **> 0**。
  - 附带报 `flip_vs_pre`（`L50` 对 `|pre|` 规则的选择翻转率）与负载均衡项实测值（`aux`）。
- **G2（主判）**：Δ(`L50` − `K50`) 的 clean bpc 配对 Δ，逐 seed 算；两 seed **同向**且
  |Δ| ≥ 0.014 才算可排序。
- **G3（前沿门）**：Δ(`L50` − `D`)、Δ(`L50` − `F50`) 同一带；用于区分「比无参数规则好」与
  「在等预算前沿上占优」。
- **判决映射（预登记，写在这里、不按读数改）**：
  1. **G1 未过**（任一 seed 不过）⇒ **本尺度不可判**：打分器没动 ⇒ 机制没被检验到，
     结论停在「13M / 12k 步不足以检验」；同时报 `n_seeds_needed = ceil((2σ/0.014)²)`
     （σ = Δ(`L50`−`K50`) 的跨 seed SD）与实测的位移/翻转率。
  2. **G1 过 且 G2 可排序更差**（两 seed 同向、Δ ≥ +0.014）⇒ **机制不成立**：把选择信号从
     「既有激活幅度」换成「可学习打分器」之后结论不变、甚至更差 ⇒ 上一轮的负结论不是
     「无参数」这一个实现的毛病。
  3. **G1 过 且 G2 可排序更优**：若 G3 里 `L50` 相对 `D` 或 `F50` 至少一项**可排序更优**
     ⇒ **本实现不成立**（上一轮的负结论属于那个实现）；否则记「机制部分成立但不占前沿」。
  4. **其余**（G1 过但 G2 落带内，或两 seed 方向不一致）⇒ **本尺度不可判**，同样报所需样本量。
- **坍缩门（必须报，不作主判）**：逐 token 选择一致率 `mode_set_share`（`F50` = 1.0 是构造性上界）
  与归一化使用熵 `H/logH`（坍缩端 `log k/log H` = 0.9、均匀端 1.0）；率类指标走 Wilson 95% CI /
  batch 聚类 bootstrap，**不跨量纲借用 0.014**。
- **n≥2**：`L50` 两个 seed 各跑一次整程；负结论（`机制不成立` / 不可判）都以两 seed 为准。

## 8 单测与冒烟（含变异）

自包含单测 `test_2687_learned_selector.py`（不改共享 `tests/`）：

- `T1` 等值门：`D` 臂前向与 stock **逐位相同**；
- `T2` 变异：`K50`/`F50`/`L50` 的 logits 必须与 stock 不同（门不是恒真）；
- `T3` 参数同量：四臂总参数逐位相同 = 6 962 688 + 8×10 240；只有 `L50` 的 81 920 个可训练；
- `T4` 打分器梯度：`L50` 的 `B` 第一步就有梯度、`A` 在 `B ≡ 0` 时恰好为 0（`B ≠ 0` 后两者都有），
  其余臂的打分器**没有**梯度；
- `T5` 嵌套恒等：`L50` 初始掩码与 `K50` 掩码**逐位相同**（含整模型 logits）；
- `T6` 直通前向精确：`t − t.detach()` 前向恒 0，残项只在反向上存在；
- `T7` 计算账：`analytic_cost` 与 §3 表逐位一致；
- `T8` 因果性：改未来 token 不改变更早位置的 logits；
- `T9` 负载均衡项：均匀选择 ⇒ 1.0；`f` 与 `P` 不一致 ⇒ 偏离 1。

## 9 失败决策树

- 冒烟 rc≠0 ⇒ 修实现（bf16 autocast 下的 `exp/softmax`、`scatter` 形状），不跑 12k。
- 单测红 ⇒ 修实现；`T5` 或 `T2` 恒真（不变红）⇒ 门无效，重写门。
- 复现门不过（重评与本条不同）⇒ 先怀疑测量（数据切分 / eval generator / 键名改名 `adapt_state`），
  修好再读；**不许**把不一致解释成「新代码更好」。
- 锁等不到（>25 min）⇒ 按 `L50` s0 → `L50` s1 顺序跑；未跑臂如实写「未跑」，**不编读数**。
- `L50` 训练发散（grad-skip 暴涨 / loss 非有限）⇒ 先降 `α` 或改 `B` 初始化，并把改动记进
  `analysis.md` 的口径偏差节（判据线不动）。
- G1 未过 ⇒ 按 §4 判「本尺度不可判」，**不许**改判据线去凑一个判决。
