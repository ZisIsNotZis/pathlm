# 3.1 每 token 的激活宽度 · 分组

> 分组节点：只聚合子研究项，不写 `project.yaml`（`docs/structure.md` §13）。
> 轴：**3 宽度轴** ｜ 用词以 `docs/structure.md` 为准。

普通 decoder-only transformer 的宽度是全局常数：每个 token、每一层、每个位置都跑同样的 hidden 维、
同样的 FFN 隐藏比、激活全部通道。本分组问「每个 token 到底要用多少宽度跑完」，并把「非均匀宽度」
拆成五种读法（`docs/structure.md` §3 的 (a)–(e)）：逐层不同（3.1.2）、同层内位置不同（3.1.3）、
前馈隐藏比（3.1.4）、只激活部分通道（3.1.5），以及作为基线读数的 uniform 减宽（3.1.1）。

## 共同口径

- 对照 = 同尺寸 **stock 全宽全通道**（归一为 100%）；另给**等参数 / 等 FLOPs 对照**（`SCHEMA.md` §15），
  否则会把「容量变化」误读成「宽度分配」。
- 判据 = 序列级 clean bpc（质量，该不跌 / 可排序，须越 `docs/methodology.md` §2 的 0.014 噪声带）+ 每 token 等效算力 / 参数量（该跌）。
- **墙钟不进判据**；代价一律等效理论量（FLOPs / layer-passes / tokens-per-forward），考虑 pipelining。
- 「只激活一部分通道」（3.1.5）的对照必须报**活性**（通道使用率分布），防坍缩；「逐层/逐位置分配」
  的对照必须**总预算逐位对齐**，否则比的是参数多少而非分配方式。
- 每项有且仅有一个 `milestone`，推进过程见各自 `project.yaml` 的 work_packages（每条含独立 `review`）。
- 分格归属（防同一读数两处记账）：**d_model / 头维**整体缩小归 `3.1.1`；**FFN 隐藏比 r**（含其逐层变化）归 `3.1.4`（`d_model` 固定）；逐层**整体 d_model** schedule 归 `3.1.2`；同层内**位置**相关宽度归 `3.1.3`；**通道粒度**稀疏激活归 `3.1.5`（专家粒度的 MoE 归轴 `4`）。
- 「等预算」对照的位点：减宽 / 减 FFN 宽属**剪枝类**（参数与算力同时降）⇒ 按 `SCHEMA.md` §15 的例外取**同算力位点**（等 FFN 预算臂之间 Σ_l r_l、FFN 参数、每 token FFN 等效算力逐位相等），并同时报参数量与算力两列。
