## 0 人话摘要

**问题**：宽度轴上「非均匀」这半边（把同样的前馈（FFN）预算在第 1 到第 8 层之间重新分配），
到底能不能**白拿**——在**同一份算力/参数预算**下比等宽分配质量更好？

**做法**：13M / 8 层 / d=256 / 12k 步（matched-step，98.3M token，enwik8），四条臂
**共享同一次随机初始化**（trunk 与 FFN 权重逐位相同，只是每层保留多少中间通道不同）：

| 臂 | r_l（每层 FFN 隐藏维 / d） | 含义 |
|---|---|---|
| **U4** | 4,4,4,4,4,4,4,4 | stock（**代价 100%** 基准） |
| **U2** | 2,2,2,2,2,2,2,2 | **等宽**、FFN 预算砍半 |
| **PYR** | 4,3,2,2,2,1,1,1 | 金字塔（前宽后窄） |
| **APYR** | 1,1,1,2,2,2,3,4 | 倒金字塔（= PYR 的镜像） |

U2 / PYR / APYR 的 **Σr 与 FFN 参数、每 token FFN 算力逐位相等**（各 2,103,296 个参数 /
2.10M MACs·token⁻¹）⇒ 三者之间的差别**只有「怎么分」**，没有「分多少」。

**答案（一句话）**：在这个尺度上，**「怎么分」分不出来**；**「分多少」才分得出来**。

- **分多少（可排序）**：FFN 宽度砍半（U4→U2）质量从 bpc **1.5314 掉到 1.5709**（+0.0395，
  约为 0.014 噪声带的 **2.8 倍**），换来每 token 等效算力 **−28.4%**、参数 **−30.2%**。
- **怎么分（不可排序）**：同一份 FFN 预算在层间重排 ⇒ 相对等宽的差
  **PYR −0.0021 / −0.0139（两 seed 都更差）**、**APYR +0.0065 / +0.0010（两 seed 都更好）**，
  四个值**全部落在 0.014 噪声带内**，⇒ 按预登记规则判 **H0：逐层 FFN 分配在本尺度不是独立于
  FFN 总量的设计维度**。**边界（必须与结论一起读）**：其中 PYR-s1 的 |Δ| = **0.0139** 已贴在
  项目自认的种子散布上界（`harness/methodology.md` §2：种子散布 ≤0.0138）⇒ **不能排除幅度约 0.014
  的（负向）真实效应**；参考量另有本实验**同一臂换 seed** 的实测散列（U2 1.5709/1.5611 = 0.0098、
  APYR 0.0043、PYR 0.0020），但它是「同臂同 schedule 换 seed」的散列，**不能当作 |Δ| 的上界**。
  方向可复现（前宽后窄略差、后宽前窄略好），但幅度不足以支撑「采纳」；**没有任何 seed 显示非均匀
  分配更优**（PYR 两 seed 都更差、APYR 两 seed 都好但最大只 +0.0065）。
- **一个真信号（副产品）**：非均匀分配**确实改变了层间表征质量分布**——PYR 的**中间深度**
  bpc 明显更低（seed 0：第 6 层 1.9727 vs 等宽 2.3338、第 7 层 1.7492 vs 1.7887），但这份好处
  **没有传导到最终深度**（1.5730 vs 1.5709）。对早退（`2.1.1`）可能有用，对最终质量无用。

**判读**：宽度轴（`3.1.4`）的结论是「**总量是旋钮，分配不是**」；本项不再单独主张逐层分配有增益。
「逐层 d_model 变化」（`3.1.2`）是同一族问题的另一面（整体宽度而非 FFN），本读数按预登记并入深度形状结论。

## 4 前沿与量级（把人话数字摆在一起）

- **FFN 总量**是真旋钮：FFN 宽度 4→2（Σr 32→16）在 12k 快照上掉 **+0.0395 bpc**
  （1.5314 → 1.5709，**2.8× 噪声带**，可排序），同时省 **28.4%** 每 token 等效算力与 **30.2%** 参数。
  这是「宽度轴最直接的算力-质量兑换率」，可与深度轴/时间轴的同预算点同图比较。
- **FFN 的分配**在本尺度没有可排序的收益：四条等预算读数（PYR/APYR × 2 seed）相对等宽
  落在 **−0.0139 … +0.0065**，全部在带内 ⇒ 分配效应在预登记阈值下不可排序。注意两件事：
  ① 本实验**同臂换 seed** 的散列是 U2 0.0098 / APYR 0.0043 / PYR 0.0020，其中 U2 的 0.0098 与
  PYR-s1 的 |Δ| = 0.0139 同量级，**不能据此说分配效应已被排除**（0.0139 > 0.0098）；
  ② PYR-s1 的 |Δ| 已等于项目自认的种子散布上界 0.0138 ⇒ 「不可排序」是**阈值规则**的判词，
  不是「效应已被排除」的判词。
- **支配关系**：U4 在两轴上都不被支配（质量最好、代价最高），U2/PYR/APYR 彼此**不可排序**
  ⇒ 前沿上这三点可视为**同一个点**；「非均匀」没有把前沿往外推。
- **副产品（机制读数，不作判据）**：深度-bpc 曲线显示 PYR 的**中间深度**明显更好
  （seed 0：第 6 层 1.9727 vs U2 2.3338、第 7 层 1.7492 vs 1.7887；seed 1 同向但幅度小得多：
  第 6 层 1.9729 vs 2.0799、第 7 层 1.7324 vs 1.7584），APYR 则相反（第 6 层 2.4684/2.7209 = s1/s0）。
  ⇒ 「层间角色不同」这个直觉**有信号**，但它体现为**表征质量沿深度的分布**，而非最终深度质量。
  这一栏对早退（`2.1.1`：浅出口质量）可能有价值，本实验不主张、也不测早退可用性（见 §8）。

## 5 对照、等值性与活性（`harness/SCHEMA.md` §9/§10/§15）

### 5.1 臂间唯一变量 = 每层 FFN 保留的中间通道

- 全部臂都先按 `mlp_mult=4` 构造**同一个**模型（`train_depth_ar.main()` 的共享构造路径），
  再用 `narrow_ffn_prefix()` 对 `mlp[0]` 取前 `r_l·d` 行、`mlp[2]` 取前 `r_l·d` 列；
  GELU、Dropout、残差、attention、LN、embedding、tied 读出**全不动**。
- **等值性门 T1**（`test_2641_ffn_ratio.py`，13 passed；复跑记录 `gates_report.txt`）：把引擎原生
  `mlp_mult=2` 模型的权重装进「`mlp_mult=4` 构造 + 均匀 r=2 切片」的模型 ⇒ **最终深度 logits 逐位相同**。
  **口径**：T1 钉的是「同形、同类、同接线、同权 ⇒ 同前向」；**前缀语义**（切片取的是前 r·d 行/列、
  而不是任意 r·d 行/列）由 T2 钉住（T1 因为先 `load_state_dict` 整份覆盖参数，对**保形**的切片错误
  不敏感）。两者合成才给出「切片实现与引擎原生窄 FFN 实现等价」（不是「换了个模型」）。
- **初始化控制**（独立核验，CPU）：seed 0/1 下 U2/PYR/APYR 的 **trunk 权重与 U4 逐位相同**，
  且三臂的 FFN 权重是 U4 初始化的**逐位前缀**（由 `T2_prefix_slice_takes_first_rows_and_cols`
  与 `T3_mutation_wide_arm_differs_from_narrow_arm` 两条测试承载，并可据此复算）⇒ 臂间不是
  「两次不同初始化」在比。
- **变异验证 T3**：接线打错（GELU→ReLU）必须让 T1 变红；切错宽度必须让 `state_dict` 形状报错；
  少切一层必须让隐藏维审计与解析参数审计变红；`r=0`/`r>r_max` 必须报错 ⇒ 上述门**不是恒真断言**。

### 5.2 等 FFN 预算（`harness/SCHEMA.md` §15 在剪枝类上的位点）

`results.json::equal_ffn_budget_check.pass = True`：U2 / PYR / APYR 的 Σr = 16、FFN 参数 = 2,103,296、
每 token FFN MACs = 2,097,152 **三条逐位相等**。U4 的 **Σr（32）与每 token FFN MACs（4,194,304）
恰为其两倍**，但 **FFN 参数不是整两倍**（4,204,544，差 2,048 = 8 层 × `lin2` 偏置 `d=256`，
该项不随 r 缩放）⇒ 三者之间比的是**分配**，不是容量；U4 只作 100% 代价锚。
- **口径注（契约表 vs 落盘的「解析」同名不同值）**：`2641-ffn-ratio-frontier-13m/README.md` §3 表的「FFN 参数（解析）」
  列填 2,097,152/4,194,304 = 2·Σr·d²，**不含偏置**；研究项落盘的 `cost.ffn_params_analytic`
  含偏置（Σ(2·r·d² + r·d + d) = 2,103,296/4,204,544）。两处同名列口径不同，**已在此说明**；
  契约文件 `README.md` 保持冻结不动（它的价值正是「未被事后编辑」），差异登记在此与工单里。

### 5.3 评测确定性

`reeval_check.sh` 对 U4-s0 / U2-s0 做 **`--no-train` 重评**：`prev == now` **逐位相同**
（1.5314 / 1.5709）⇒ 评测口径（同 eval 批、同代码）确定。

### 5.4 活性（`harness/SCHEMA.md` §10）

`hidden_by_layer` 7/7 逐位等于 schedule；逐层 FFN 输出相对幅度**全为正**（7 臂合起来
0.299–2.08，最小 0.299 出现在 APYR-s1 第 2 层）⇒ 干预真的接在计算图上、且窄层被真用（不是死路径）。
注意幅度主要由**层号**决定（每臂首层最大），不是由宽度决定。
训练稳定性：`gnorm_max` 5.15–7.86、无 NaN/跳步（`gnorm_monitor` 随臂落盘）。

## 6 对账（`harness/SCHEMA.md` §12 三道）

1. **算术对账**：`Δ_up`/`Δ_down` 定义与 sign 一致（`1.5709 − 1.5730 = −0.0021` 等）✓；
   参数差 = 6,962,688 − 4,861,440 = 2,101,248 = 2·(4−2)·256²·8（权重，= 2,097,152）
   + (4−2)·256·8（`lin1` 偏置，= 4,096）= 2,101,248 ✓（`lin2` 偏置 8·d = 2,048 不随 r 缩放，
   故不在余项里）；
   bpc 落在理论界内（>0，< log₂206 = 7.687）✓；U4→U2 的 `+0.0395` 与噪声带 0.014 之比 = 2.82 ✓。
2. **任务对账**：全部臂同一 enwik8 字符级 AR 任务、同一数据切分（前 90M/末 10M）、同一位置集
   （全序列逐位置、最终深度读出）、同一目标定义；对照臂三要素 = 输入分布（同 train 流随机窗口）、
   预测什么（下一字符）、部署对应（stock decoder-only 最终深度读出）⇒ **同任务**✓。
3. **口径对账**：全部 12k 步 **matched-step / 同 token 预算（98.3M）** 快照、同 lr/batch/seed 集、
   同评测函数与 eval 批；**非渐近、非墙钟、非 FLOPs 折算的墙钟比**；代价只用解析 MACs ✓。
   **三道全过。**

## 7 归因（`harness/research-schema.md` §7 三分）

判负（「逐层 FFN 分配在本尺度没有可排序增益」）的归因：

1. **设计问题（主因）**：把「FFN 预算在层间怎么分」当作独立设计维度，在 13M / 8 层 / 12k 快照上
   没有头寸——四条等预算读数落在 **−0.0139 … +0.0065**，全部在 0.014 带内（**不是**「小于
   同臂换 seed 的散布 0.0098」：PYR-s1 的 0.0139 大于它，且约等于项目自认的种子散布上界 0.0138）。
2. **结构问题（次因，两条，带证据）**：
   - 本实验只覆盖**单调阶梯的两个极端**（PYR / APYR）；
     同多重集 {4,3,2,2,2,1,1,1} 的**排序共 1120 种**，本 WP 不搜索非单调 schedule
     ⇒ 「非均匀分配一律无用」这句话**超出本证据**，本实验只主张「两条对称的单调阶梯不可分」；
   - 在 Σr=16 这一档，attention 已占总 MACs 的 **59.4%**（3,145,728 / 5,295,616），
     FFN 只占 39.6% ⇒ 单位算力里可重分配的份额本来就窄，分配旋钮的杠杆空间受限。
   - **共享前缀初始化的混杂（不可由本证据排除）**：全部臂共享同一次初始化，且窄臂只保留
     **前 r·d 个**中间通道（`narrow_ffn_prefix` 取前缀行/列）⇒ 「换一个通道子集」这一自由度在各臂间
     恒定，本设计对「通道子集 × 深度位置」的交互**不可识别**。因此可排除的只是「通道子集运气大到能
     越过 0.014」，不能排除「换一次抽样/换通道子集后出现 0.01–0.014 量级的（负向或零）效应」。
     最小下一步：追加 1–2 臂「同 schedule + 中间通道固定随机置换」对照（≈15 min GPU），或把 U2/PYR
     的 seed 从 2 提到 4（≈30 min GPU）。
3. **innovation 本身失败？不适用**：本项没有引入新机制（FFN 隐藏比是业界既有旋钮，见契约 §10），
   因此这是「本尺度不产生新知识」的读数（55-review W-04 的造轮子风险在**逐层分配**这一维上的现实化），
   而不是「创新机制被否证」。

## 8 局限与没做的事（如实登记）

- **U4 只有 seed 0**（按契约 §6 的预算递减规则先砍 U4-s1）⇒ 100% 代价锚的单 seed；
  其同配置跨 run 散布用 4 个历史 dense 13M run 估计（极差 0.0057）。
- **尺度/任务**：13M / 8 层 / 12k 快照 / enwik8 字符级。不外推到更大规模、更多层、其他任务。
- **12k 仍未收敛**（7 臂 loss 斜率 0.0018–0.0058/1k 步仍在下降）⇒ 只读臂间增量，绝对水平是快照。
- **不测早退可用性**：§4 的「中间深度更好」副产品未接 `2.1.1` 的 tf@k 口径（本格单因素不含退出）。
- **非单调 schedule 未搜索**（见 §7.2）；**共享前缀初始化的混杂**未排除（见 §7 第 2 条末）。
- **PYR-s1 的 |Δ_up| = 0.0139 贴在项目自认的种子散布上界（0.0138）**（`harness/methodology.md` §2）
  ⇒ 判 H0 是**阈值规则**的判词，不等于「效应已被排除」；本项据此**不采纳**非均匀分配，但「反向有害」
  这一分支同样**未被确立**。
- **工程事件（不影响判据）**：`run.py` 在 U4-s0/U2-s0 训练后做了一次**只影响派生审计字段**
  的修正（`hidden_matches_schedule` 的单位：`r` → `r·d`）；两臂用最终版代码 `--no-train` 重评、
  bpc 逐位一致（§5.3）；修订前版本见 `git show 49f697f:<实验目录>/run.py`。细节见
  `.scratch/64-axis3-width/TICKET.md` §7.2.1。
- **未逐位复现历史**：U4-s0 = 1.5314 与历史锚差 +0.0027（训练含 CUDA 非确定性，2613 已记录同款现象）。
