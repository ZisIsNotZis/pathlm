# R7-existing-early-exit · 既有早退实现（CALM / LayerSkip / MoD）

> 轴：**R 参照线（必须打败的基线）** ｜ 状态：**✅ judged**

> **判读**：**本地实测（13M/enwik8/12k 步快照）**：三种标准实现都装好并跑通。① **CALM 式置信门控是真对手**：按 CALM 原式（全局阈值、退出流不一致率 ≤ ε）在形态臂上 ε=0.05 退到 3.43/8 层（一致率 0.959，墙钟 1.93–2.01×），普通主干只能退到 6.59/8；② **LayerSkip 式自草稿只省延迟不省算力**（γ=4、草稿深度 4：接受率 0.952、8.70 层×位置 vs 全深度 7.92、墙钟 1.99×，发出流与贪心流逐 token 相同）；③ **MoD 式 isoFLOP（L=16/放行 0.5）质量差 +0.398 bpc 且前向吞吐只有 stock 的 0.30×**。④ **C1 的 matched 税 +0.3291 不是「主目标降权」造成的**（2×2：换到无门形态同样「保权更差」0.1218，剂量单调 2.1185→1.9842→1.8575）——**浅层监督是补偿项不是税**；税来自混合深度形态与逐通道门（最好形态臂 = 无门×等权配方仍 +0.2573；门在两种配方下都让 trunk 更差 +0.0718/+0.2110）。

## 1. 命题

深度自适应的既有实现——我们的形态必须说清增量在哪。

## 2. 选项枚举（本格全部可能取值）

1. `CALM（置信度门控）`
2. `LayerSkip（自推测早退，逐层监督）`
3. `MoD（逐 token 路由深度）`

## 3. 状态（我们做了什么 / 行业做了什么）

**本地已测**：CALM 式门控在形态臂上省算力 2.3×（3.43/8 层，一致率 0.959）；出口资产 tf@4：stock 0.444 → 无门 0.840 → C1 现配方 0.972；LayerSkip 自草稿真实接受率 0.952–0.978、发出流与贪心逐 token 相同

**行业口径**：三者均有公开结果；共同点：需要深度维监督，且都报告质量-算力折中。

## 4. 结论与数字

- **税**：13M matched 税：C1 现配方 +0.3291（历史 +0.3295 复现）；拆分为「配方 −0.2610（保权更差）」+「形态 +0.5901」；最好形态臂（无门×等权配方）+0.2573；MoD isoFLOP +0.3980（快照口径）
- **收益**：CALM 式门控在形态臂上省算力 2.3×（3.43/8 层，一致率 0.959）；出口资产 tf@4：stock 0.444 → 无门 0.840 → C1 现配方 0.972；LayerSkip 自草稿真实接受率 0.952–0.978、发出流与贪心逐 token 相同
- **判读**：**本地实测（13M/enwik8/12k 步快照）**：三种标准实现都装好并跑通。① **CALM 式置信门控是真对手**：按 CALM 原式（全局阈值、退出流不一致率 ≤ ε）在形态臂上 ε=0.05 退到 3.43/8 层（一致率 0.959，墙钟 1.93–2.01×），普通主干只能退到 6.59/8；② **LayerSkip 式自草稿只省延迟不省算力**（γ=4、草稿深度 4：接受率 0.952、8.70 层×位置 vs 全深度 7.92、墙钟 1.99×，发出流与贪心流逐 token 相同）；③ **MoD 式 isoFLOP（L=16/放行 0.5）质量差 +0.398 bpc 且前向吞吐只有 stock 的 0.30×**。④ **C1 的 matched 税 +0.3291 不是「主目标降权」造成的**（2×2：换到无门形态同样「保权更差」0.1218，剂量单调 2.1185→1.9842→1.8575）——**浅层监督是补偿项不是税**；税来自混合深度形态与逐通道门（最好形态臂 = 无门×等权配方仍 +0.2573；门在两种配方下都让 trunk 更差 +0.0718/+0.2110）。

## 5. 失败路径与原因

1. LayerSkip 式自草稿在 L=8 上不省算力（8.70–11.20 层×位置 > 7.92），无门形态更差（接受率 0.855、11.0 层×位置）
2. MoD 式 isoFLOP 更差且更慢（bpc +0.398、前向吞吐 0.30×）——路由 gather/scatter 吃掉 FLOPs 优势
3. CALM 保守口径（逐深度条件一致率）在本尺度几乎不退（平均深度 7.97/8）：门控收益取决于标定口径，必须两套并报

## 6. 判据与判决实验设计

- **判据**：同 FLOPs 质量 + 出口资产 + 税（+ 配方 vs 形态的拆分）

## 7. 成本估计

- 13M 单臂 ~10 min（实测 6.8–19.2 min，含 MoD L=16）
