# R7-existing-early-exit · 既有早退实现（CALM / LayerSkip / MoD）

> 轴：**R 参照线（必须打败的基线）** ｜ 状态：**✅ judged**

> **判读**：**本地实测（13M/enwik8/12k 步＝1 epoch 快照、每臂单 seed、n=1）**：三种标准实现都装好并跑通。① **CALM 式置信门控**：两套标定口径**并报** —— 保守口径（逐深度条件一致率 ≥1−ε）在本尺度几乎不退（平均深度 7.97–7.996，θ_k≈1.0）；**CALM 原式口径（待核：无联网按机制描述实现；全局 θ 且 θ 常被网格下界 0.50 截断）** 在形态臂 ε=0.05 退到 **3.43/8 层**（一致率 0.959；该臂未测门控墙钟），普通主干只能退到 6.59/8；门控墙钟在测过的三条臂（c1-legacy/c1-fair/ls-fair）上是 **1.76–2.01×**（第二次调用、参考臂取自第一次）。② **LayerSkip 式自草稿只省延迟不省算力**：γ=4、草稿深度 4，窗口接受率 0.9109±0.0153（=Σ接受/(γ×轮数)，与 C1 的 2621 同定义；条件口径 0.9520 一并落盘）、每 token 8.70 层×位置（全深度 7.92）、墙钟 1.99–2.43×；发出流与全深度贪心流逐 token 相同。③ **MoD 式单点 isoFLOP（L=16/放行 0.5）质量差 +0.398 bpc、前向吞吐 0.301×（batch 8×256，与单流解码不可比）**；**质量差与吞吐差都未与参数 ×2 分离**（无等参数/等深度对照）⇒ 只报现象。④ **「C1 的税主要来自主目标降权」在本尺度被否证（n=1）**：2×2 与剂量的方向都相反（详见 C1 格的重拆）。

## 1. 命题

深度自适应的既有实现——我们的形态必须说清增量在哪。

## 2. 选项枚举（本格全部可能取值）

1. `CALM（置信度门控）`
2. `LayerSkip（自推测早退，逐层监督）`
3. `MoD（逐 token 路由深度）`

## 3. 状态（我们做了什么 / 行业做了什么）

**本地已测**：CALM 原式口径在形态臂上省算力 2.3×（3.43/8 层，一致率 0.959）；出口资产 tf@4：stock 0.4441 → 无门 0.8402 → C1 现配方 0.9719（等权配方下 0.9719/0.9645，贴天花板）；LayerSkip 自草稿窗口接受率 0.9109（条件口径 0.9520 一并落盘）、发出流与贪心逐 token 相同

**行业口径**：三者均有公开结果；共同点：需要深度维监督，且都报告质量-算力折中。

## 4. 结论与数字

- **税**：13M matched 税：C1 现配方 +0.3291（历史 +0.3295 复现）；配方轴反向（保权更差）：λ=0.1 −0.2610 / λ=1.0 −0.1267 / 无门形态 −0.1218；**同份额控制臂（additive λ=8，份额 1/9）与 renorm 打平**（1.8550 vs 1.8575，差 0.0025 落在噪声带内）⇒ 驱动量是「份额（= 浅层监督的量）」而非归一化形式（损失尺度未单独隔离）；形态税按配方分列：现配方 +0.3291 / λ=0.1 条件值 +0.5901 / 最好形态臂（无门×等权）+0.2573；门：λ0.1 +0.2110、等权 +0.0718（交互项 −0.1392 ⇒ 两轴不独立，拆解是记账恒等式）；MoD isoFLOP +0.3980
- **收益**：CALM 原式口径在形态臂上省算力 2.3×（3.43/8 层，一致率 0.959）；出口资产 tf@4：stock 0.4441 → 无门 0.8402 → C1 现配方 0.9719（等权配方下 0.9719/0.9645，贴天花板）；LayerSkip 自草稿窗口接受率 0.9109（条件口径 0.9520 一并落盘）、发出流与贪心逐 token 相同
- **判读**：**本地实测（13M/enwik8/12k 步＝1 epoch 快照、每臂单 seed、n=1）**：三种标准实现都装好并跑通。① **CALM 式置信门控**：两套标定口径**并报** —— 保守口径（逐深度条件一致率 ≥1−ε）在本尺度几乎不退（平均深度 7.97–7.996，θ_k≈1.0）；**CALM 原式口径（待核：无联网按机制描述实现；全局 θ 且 θ 常被网格下界 0.50 截断）** 在形态臂 ε=0.05 退到 **3.43/8 层**（一致率 0.959；该臂未测门控墙钟），普通主干只能退到 6.59/8；门控墙钟在测过的三条臂（c1-legacy/c1-fair/ls-fair）上是 **1.76–2.01×**（第二次调用、参考臂取自第一次）。② **LayerSkip 式自草稿只省延迟不省算力**：γ=4、草稿深度 4，窗口接受率 0.9109±0.0153（=Σ接受/(γ×轮数)，与 C1 的 2621 同定义；条件口径 0.9520 一并落盘）、每 token 8.70 层×位置（全深度 7.92）、墙钟 1.99–2.43×；发出流与全深度贪心流逐 token 相同。③ **MoD 式单点 isoFLOP（L=16/放行 0.5）质量差 +0.398 bpc、前向吞吐 0.301×（batch 8×256，与单流解码不可比）**；**质量差与吞吐差都未与参数 ×2 分离**（无等参数/等深度对照）⇒ 只报现象。④ **「C1 的税主要来自主目标降权」在本尺度被否证（n=1）**：2×2 与剂量的方向都相反（详见 C1 格的重拆）。

## 5. 失败路径与原因

1. LayerSkip 式自草稿在 L=8 上不省算力（8.70–11.20 层×位置 > 7.92），无门形态更差（窗口接受率 0.6682、11.0 层×位置）
2. MoD 式 isoFLOP 单点更差且更慢（bpc +0.398、前向吞吐 0.301×）；吞吐差未与参数 ×2 分离，不得归因给路由
3. CALM 保守口径（逐深度条件一致率）在本尺度几乎不退（平均深度 7.97/8）：门控收益取决于标定口径，必须两套并报；CALM 原式口径待核
4. 全部训练臂 n=1（seed-1 重复被预算砍掉）⇒ 负向结论按「方向反转、待跨种子复现」入账

## 6. 判据与判决实验设计

- **判据**：同 FLOPs 质量 + 出口资产 + 税（+ 配方 vs 形态的拆分）

## 7. 成本估计

- 13M 单臂 ~10 min（实测 6.8–19.2 min，含 MoD L=16；本波 8 臂 + 电池 ≈112 GPU min）
