# 判读 — 2623 标准早退实现（R7 · WI-16）

> 主格 `R7-existing-early-exit`｜引擎 depth-ar 13M（d=256 / L=8 / h=8 / mlp=4 / seq=256）
> ｜12k 步 = 98.3M tokens（≈1 epoch，**快照口径**）｜数据 enwik8｜单卡 RTX 4090（共享）
> ｜训练臂 8 条 + 推断电池 + 交错墙钟｜`results.json` / `run_log.txt` / `cycle_log.jsonl`

## 0. 人话摘要（先读这段，再看数据）

**1. 这条线在问什么。** 本仓 C1 的结论是「提前退出能用，但要付一笔形态代价（+0.33 bpc）」。
可我们从没把**业界标准做法**量出来——没有可测量的对手，「我们更好」这句话就没有依据。
本波把三种标准实现装进本仓引擎并真的跑起来：**CALM 式**（按置信度阈值在浅层退出）、
**LayerSkip 式**（浅出口当草稿、全深度验证）、**MoD 式**（逐 token 路由，跳过/不跳过某些块）。
同时按审计指出的**配方混杂**补了对照：C1 那套训练把主目标（最终深度 CE）归一化到只占
1/9 的权重，所以「+0.33 的税」里有多少是**配方自己造成的**、有多少是**形态本身**，必须拆开。

**2. 相对普通的 decoder-only transformer 改了什么。** 不变的主干是 stock（普通
pre-LN 残差栈，只监督最终深度）。三条标准臂各自只加一件事：
- CALM 式：**不加结构**，只在推理时按「浅层出口的 top-1 概率 ≥ 阈值」提前退出；
- LayerSkip 式：普通主干 + 训练期**随机退出深度**（layer dropout）+ **逐层损失**，
  推理用「深度 4 出口当草稿、8 层验证」的自投机解码；
- MoD 式：**16 层**普通块 + 每块一个路由器（每层只放行每序列 top-128/256 个 token，
  其余走残差旁路）⇒ 算力与 8 层 dense 相同（每 token 8 次块作用），参数 ×2。

**3. 测出来多少（四条腿，13M、同 token 预算、seed 0）。**

| 臂 | 形态 | 配方（主目标份额） | d8 bpc | tf@4 | 训练墙钟 | 峰值显存 |
|---|---|---|---|---|---|---|
| `stock` | 普通 transformer | 仅最终 CE（100%） | **1.5284** | 0.444 | 6.8 min | 935 MB |
| `c1-legacy` | C1：carry 门 + 随机退出 + fill | 等权平均（**1/9**） | **1.8575** | **0.9719** | 10.0 min | 1340 MB |
| `c1-fair`（λ=0.1） | 同上（逐字段相同） | 主目标 1 + 0.1·mean(浅层)（~91%） | **2.1185** | 0.9102 | 10.4 min | 1340 MB |
| `c1-fair-l1`（λ=1.0） | 同上 | 主目标 1 + 1.0·mean(浅层)（50%） | **1.9842** | 0.9614 | 10.1 min | 1340 MB |
| `ls-fair` | **无门**（−526k 参数）+ 随机退出 | 同 λ=0.1 | **1.9075** | 0.8402 | 9.7 min | 1204 MB |
| `ls-legacy` | **无门** + 随机退出 | 等权平均（1/9） | **1.7857** | 0.9645 | 8.6 min | 1205 MB |
| `c1-fair-share`（λ=8） | 同 `c1-fair` | **同份额控制**：主目标 1 + 8·mean(浅层)（**1/9** = legacy） | **1.855** | 0.9705 | 9.8 min | 1340 MB |
| `mod`（L=16, 放行 0.5） | MoD 路由（isoFLOP with stock） | 最终 CE + 0.01·路由损失 | **1.9264** | — | 19.2 min | 1330 MB |

- **复现**：`stock` 1.5284 vs 历史锚点 1.5287、`c1-legacy` 1.8575 vs 1.8582（Δ 0.0003/0.0007，
  远小于仓内 0.014 方差带）⇒ 流水线与历史入账同刻度；也给出**同配置跨 run 漂移**的实测界。
- **主判据被否证（方向相反）**：把主目标从 1/9 的份额「保权」**没有**让 trunk 变好——
  `bpc(c1-legacy) − bpc(c1-fair) = −0.2610`，且剂量单调（λ=0.1 → 2.1185、λ=1.0 → 1.9842、
  等权 → 1.8575、无浅层监督 1.5284）：**浅层监督在这套形态里不是「税」，它同时在买
  质量与出口资产**（tf@4 同步单调 0.910 → 0.961 → 0.972）。
- **门有代价（2×2 两个配方下 bpc 都更差）**：同配方下拿掉门，trunk 好 **0.2110 bpc**
  （λ=0.1：1.9075 vs 2.1185）、**0.0718 bpc**（等权配方：1.7857 vs 1.8575），而且门还多
  526k 参数 ⇒ 方向上排除了「容量不足」这一解释。**门也买出口资产**（λ=0.1：tf@4
  0.9102 → 0.8402），但「这份资产能否由配方替代」**本波不足以判定**：等权配方下两臂
  tf@4 = 0.9719 vs 0.9645（差 0.0074）**贴着天花板**（上界 1.0）⇒ 该差被压缩，
  只能标**待测**（见 §3 D1 与未测项）。
- **CALM 式真能退，但要付一致率**：按 CALM 原式校准（全局阈值、退出流自己的不一致率 ≤ ε）：
  ε=0.05 时最好的一条形态臂（无门 × 等权配方）平均退到 **3.43/8 层**（一致率 0.959）、
  C1 现配方 3.64/8（0.961）、普通主干只能退到 **6.59/8**（0.965）⇒ **标准 CALM 在本仓形态上
  是真对手**：用 2.3× 更少的算力换掉 4.1% 的 token 一致性。**墙钟口径分开报**：
  该臂（`ls-legacy`）**未测门控墙钟**；测过的三条（`c1-legacy` 1.928 / `c1-fair` 1.763 /
  `ls-fair` 2.009，第二次调用、参考臂取自第一次）落在 **1.76–2.01×**，低于其算力收益
  （7.92/3.23 = 2.45×，差额是逐层 Python 循环与每层 softmax 同步的开销）。
  而 C1 自己的自草稿反而**多花算力**（8.0–9.2 vs 7.92 层×位置/token）。
- **LayerSkip 式自草稿在 8 层上不省算力**：草稿深度 4、γ=4 时 C1 现配方
  **窗口接受率 0.9109 ± 0.0153**（Σ接受/(γ×轮数)：317/(4×87)；另一口径「被检验位的条件
  接受率」= 0.9520，两口径都落盘），每 token **8.70** 层×位置（普通全深度 7.92）——
  省的是**延迟**（墙钟 1.99–2.43×），不是算力；无门形态更差（窗口 0.6682、11.0 层×位置）。
  **发出流与普通全深度贪心流逐 token 相同**（质量零损失，4 prompt × 100 token 全部一致）。
- **MoD 式在本尺度全面更差**：等解析算力（8.0 层作用/token）下 bpc 1.9264（比 stock 差
  **+0.398**），且**前向吞吐只有 stock 的 0.301×**（101.7k vs 337.8k tok/s，batch 8×256
  前向吞吐口径——与同表的单流解码不可比）。**该吞吐差的归因未隔离**：MoD 臂同时有
  (i) 逐 token 路由的 gather/scatter 与 (ii) 参数 ×2（13.81M vs 6.96M）两个差异，
  本波没有「等参数/等深度」对照 ⇒ 只报现象，不归因。

**4. 结论。** 13M/enwik8、单 epoch 快照、**n=1（每臂单 seed）** 上：**「C1 的税主要来自
目标降权」的方向被否证**（2×2 与剂量都反向：浅层监督在这套形态里是补偿项；跨种子复现未做，
见未测项）；标准实现里 **CALM 式置信门控是候选真对手**（在形态臂上一致率 0.959 时算力降到
3.43/8 = 2.3× 更少、墙钟 1.93–2.01×），**LayerSkip 式自草稿省延迟不省算力**，
**MoD 式在等解析算力下既更差又更慢（吞吐差未隔离参数 ×2）**。
C1 形态的**出口资产仍在**（tf@4 0.97 vs stock 0.444，是 CALM 能退到 3.4 层的原因）；
换算力账时**赢家是门控策略而不是门**：门在两个配方下都让 trunk 更差（0.2110 / 0.0718），
它买的出口资产能否由配方替代**本波判不了**（等权配方下差异贴天花板，见 D1）。

## 1. 口径与协议

| 项 | 值 |
|---|---|
| 数据 | `data/enwik8_full.npz`（字符级，V=206）；train 段训练、val 段 10M 评测 |
| 解码 prompt | val 的 4 个固定 offset（1000/40000/90000/160000）× 16 字符 |
| token 预算 | 全部训练臂 12k 步 × bs32 × seq256 = **98.3M tokens**（≈1 epoch），seed 0 |
| 质量口径 | teacher forcing 的逐深度 **bpc** 与 **tf@k**（depth-k argmax == depth-L argmax）；真解码路径另报 CALM 一致率与草稿接受率 |
| spec 接受率口径 | **窗口口径**（`accept_rate_window` = Σ接受/(γ×轮数)，与 C1 的 2621 同定义）为**主口径**；另一口径（`accept_rate` = Σ接受/Σ被检验的草稿位，只统计到每轮第一次拒绝）系统性偏高，**只作对照**。两口径都在 `results.json`（含 `n_accepts` 与定义说明），派生见 `enrich_results.py`） |
| 算力口径 | **解析 layer-position / token**（每 token 的块作用次数）：全深度 8.0；固定退 4 层 4.0（末位 token 免费 ⇒ 实测 3.96）；CALM = 实测平均退出深度；LayerSkip = `L(γ+1)/(1+τ)`；MoD = `ratio·L` |
| 墙钟口径 | **同一进程内交错轮次**（3 轮 × 4 prompt × 每臂策略，n_new=100，batch 1）；比值 = 同轮同 prompt 对 `stock/full`；报中位与极差 |
| 噪声门限 | 同配置跨 run 实测漂移 0.0003–0.0007 bpc（两条臂各自复现历史值）；仓内种子带 ≤0.0138；`tf@` 类比例量的二项 SE：n=81600 时、两个比例的**差**其 2×SE =
`2·√(p₁(1−p₁)/n + p₂(1−p₂)/n)`（p₁=0.9102、p₂=0.8402）≈ **0.0033**（本波用的就是这个量，
不是 0.057；单个比例的 2×SE 只有 0.0020）。**seed-1 重复未跑**（预算，见 §7）⇒ 全部训练臂为 **n=1**，负结论按「方向反转、待跨种子复现」口径陈述 |
| 快照声明 | 12k 步单点，**不是渐近**；不做收敛对账（未测项 #7） |
| GPU 记账 | 训练臂逐臂实测（stock 6.8 / c1-legacy 10.0 / c1-fair 10.4 / c1-fair-l1 10.1 / ls-fair 9.7 / ls-legacy 8.6 / mod 19.2 / **share 臂 10.4**）= **85.2**；加步时探针 **3.0** 与推断电池/交错墙钟/逐臂插入 **≈16.0** ⇒ **≈104 min**；**另有两笔被丢弃的 GPU 时间**：① 首版规格事故的 d=256/L=4 玩具 run **269 s**（当时无护栏、rc=0，产物已删）；② 修 SPEC 后**在飞的旧进程**又跑了一次同款 L=4、**280 s**（被新加的规格自检判 rc=3）⇒ **真实占用 ≈104 + 9.15 ≈ 113 min ≤ 120 min 预算**。机器可读台账见 `config.json::gpu_wall_used_min` 与 `lock_ledger`（每臂取/放锁时刻 + 持锁分钟）。锁按臂释放、臂间 ≥60 s（`SCHEMA` §20.1）；峰值显存 ≤1.34 GB（礼貌线 5 GB 内） |

**2×2（门 × 配方）**：d8 bpc（同 seed、同 token 预算、同引擎）

| 形态 ↓ / 配方 → | 等权平均（主目标份额 1/9） | additive λ=0.1（份额 ~91%） | additive λ=8（份额 1/9） |
|---|---|---|---|
| **有门**（+526k 参数） | 1.8575（C1 现配方） | 2.1185 | 1.855（tf@4 0.9705） |
| **无门**（普通块） | 1.7857 | 1.9075 | —（未跑） |

**交互项（difference-in-differences）= (有门−无门 | 等权) − (有门−无门 | λ0.1)
= 0.0718 − 0.2110 = **−0.1392**（绝对量 0.1392，与「门」的主效应同阶）⇒ **两轴不独立**，
因此下面这张表是**逐项相消的记账恒等式**，不是可加的因果分解。

| 分量（**条件值**，记账恒等式） | 算式 | 值 |
|---|---|---|
| C1 现配方的 matched 税 | `bpc(c1-legacy) − bpc(stock)` | **+0.3291**（历史 +0.3295 ✓） |
| 配方（同形态=有门，等权 vs λ0.1） | `bpc(c1-legacy) − bpc(c1-fair)` | **−0.2610**（**符号相反**：保权反而更差） |
| 配方主效应（同形态=无门） | `bpc(ls-legacy) − bpc(ls-fair)` | **−0.1218**（同向） |
| 门（同配方=λ0.1） | `bpc(c1-fair) − bpc(ls-fair)` | **+0.2110** |
| 门（同配方=等权） | `bpc(c1-legacy) − bpc(ls-legacy)` | **+0.0718** |

**形态税必须按配方分列**（同一个 stock 基线，三个口径差 0.33 bpc）：

| 口径 | 算式 | 值 |
|---|---|---|
| C1 **现配方**（门/随机退出/填充 + 等权） | `bpc(c1-legacy) − bpc(stock)` | **+0.3291** |
| λ=0.1 配方下（门） | `bpc(c1-fair) − bpc(stock)` | **+0.5901**（**条件值，勿当「C1 的形态税」**） |
| 本波最好形态臂（**无门** + 等权） | `bpc(ls-legacy) − bpc(stock)` | **+0.2573** |

**配方轴不是干净单因素（复核 P1-4）——用同份额对照臂拆开**：`renorm` 除分母、`additive`
不除 ⇒ 换配方同时改了 (i) 主目标份额与 (ii) **全局损失尺度**。为此补了**同份额对照臂**
`r7-c1-fair-share-s0`（`--aux-mode additive --aux-weight 8` ⇒ `loss = CE + 8·mean(浅层 CE)`，
主目标份额 = 1/9，与 C1 现配方**同份额**；总损失尺度 ≈9× CE，**尺度仍未隔离**）。
实测 d8 bpc **1.855**、tf@4 **0.9705**（训练墙钟 9.76 min、峰值 1339.9 MB）、CALM 原式 ε=0.05 退到 3.6458/8 （一致率 0.9588）。
**读法**：同份额下 additive（1.8550）与 renorm（1.8575）**差 0.0025、落在噪声带内**
（同配置跨 run 漂移 0.0007、仓内种子带 0.0138）⇒ **驱动量是「主目标份额」（= 浅层监督的量），
不是归一化形式**；把主目标「保权」（λ=0.1，份额 91%）才是那条更差的臂（2.1185）。
尺度（additive λ=8 的总损失 ≈9× CE）在这一对同份额臂里**没有**造成可分辨差异，
但**仍未做尺度对齐的直接对照** ⇒ 机制读法保持「份额已隔离、尺度未单独隔离」。

**剂量曲线（同形态=有门）**：λ=0.1 → 1.0 → 8（同份额） → 等权 = 2.1185 → 1.9842 → **1.855**
→ 1.8575（**单调，末两点打平**：1.855 与 1.8575 差 +0.0025，落在噪声带内）；**末点 1.5284 是 stock（dense、无门、无退出机制）**，
与前四点是**不同形态** ⇒ 它只作基线，**不构成单调序列的同类点**。

## 3. 判据逐条判读（预登记见契约 §4，符号 `Δ = bpc_对照 − bpc_实验`）

| 判据 | 预登记 | 实测 | 判读 |
|---|---|---|---|
| **Z1**（primary） | `Δ_recipe = bpc(c1-legacy) − bpc(c1-fair) > σ_cell` ⇒ 税来自目标降权 | **−0.2610**（λ=0.1）；无门形态 −0.1218；λ=1.0 时 −0.1267；**同份额（λ=8）时 +0.0025（与 renorm 打平）** | **否证**（n=1）：方向相反且剂量单调、2×2 两轴都对 ⇒ 「目标降权」不是 C1 税的成分；浅层监督是**补偿项**。跨种子复现未做 ⇒ 按「方向反转待复现」口径 |
| Z2 | `tf@4(c1-fair) − tf@4(stock) > 0` 且与 legacy 同阶 | +0.4661（0.9102 vs 0.4441），legacy 0.9719 | **成立**：出口资产由早退配方造出，不是主目标的产物 |
| Z3 | 一致率 ≥0.95 时 CALM 平均深度应显著小于 L | 保守口径：7.97（不退）；CALM 原式：**3.64** | **成立（用原式口径）**：标准 CALM 在 C1 形态上退到 45% 的层数 |
| **D1** | 若 `bpc(ls-fair) ≤ bpc(c1-fair) + σ_cell` **且** `tf@4(ls-fair) ≥ tf@4(c1-fair) − σ_tf` ⇒ 门必须降级为「不必要」 | 第一条成立（bpc 好 0.2110）；**第二条不成立**：0.8402 < 0.9102 − σ_tf。**σ_tf 修正**：tf@4 的 n = 81600 个位置、两臂的 p 不同（0.9102 / 0.8402）⇒
**差比例的 2×SE** = `2·√(p₁(1−p₁)/n + p₂(1−p₂)/n)` ≈ **0.0033**（若误用单比例

| I2 | spec 发出的流 == 同 arm 全深度贪心流（逐 token） | 4 prompt × 100 token × 4×γ 全一致（`match_full_frac=1.0`） | **成立**（出过事故，见 §6） |

## 5. 三个标准实现的实现方式与可跑性（忠实度声明）

| 标准做法 | 本波怎么实现 | 可跑 | 与公开做法的差异（如实声明） |
|---|---|---|---|
| **CALM 式**（置信度门控） | 训练侧用早退损失（本仓形态自带逐深度读出）；推理侧在每个位置逐层看 top-1 概率，取最浅的 `conf ≥ θ` 深度退出。两套阈值口径都报：①**逐深度条件一致率**（保守，是本波实现里最严的界）；②**CALM 原式**（**待核**：无联网，按论文机制描述实现——全局阈值 θ，在 val 前一半批次上选满足「退出流与全深度流逐 token 不一致率 ≤ ε」的最小 θ，后一半批次核验） | ✅ | CALM 的**学习式出口分类器 / 对比路由**变体需要第二个模型或独立分类器另训 ⇒ **未实现**（未测项 #1）；阈值网格 0.50–0.995（C1 形态上网格下界绑定，真实可退深度可能更浅） |
| **LayerSkip 式** | 训练侧 = 普通主干 + 随机退出深度（layer dropout）+ 逐层损失；推理侧 = 真 draft-verify 循环（深度 4 草稿、全深度验证、接受前缀 + bonus 提交），KV/填充机械与其它臂**共用同一套** | ✅ | 草稿阶段的浅层 KV 用于提交前 k+1 个位置（已按「接受位置的自喂 token 与真值相同 ⇒ KV 逐位相同」论证，并由「流 == 贪心流」单测钉住）；**no-fill ragged 变体未测**（本波统一 fill，未测项 #5） |
| **MoD 式** | 每层每序列 top-k 容量路由（k = round(0.5·T)）+ 残差旁路 + 路由器二值损失（选中推向 1、未选中推向容量比例，α=0.01）+ 单个 isoFLOP 设计点（L=16/ratio 0.5 vs dense L=8） | ✅ | ①注意力只在**被放行子集内**（同序列 + 原位置因果；被旁路 token 的 K/V 不参与）——论文实装的细节在无联网环境无法核对（`记忆·未核`）；②路由器损失的具体系数为本地取值；③只测了一个 isoFLOP 点、且 MoD 臂参数 ×2（其设计点，但等参数对照未测，未测项 #4） |

## 6. 失败路径与排除（含本波自己抓到的实现事故）

1. **spec 流相对贪心流整体错位一格（实现 bug，已修 + 变异验证）**。第一轮电池里
   `match_full_frac` 只有 0.01–0.18，而接受率却有 0.95——两个数字**互相矛盾**，说明
   接受判定与发出的流不是同一件事。定位：`spec_decode` 漏掉了「prefill 末位的 argmax」
   这个由 prefill 免费给出的 token（C1 的 2621 循环里有这个不变量）⇒ 整条流错位一格。
   修的同一轮里：把单测从退化点升级为**非退化模型**（周期性任务训 80 步，断言贪心流有
   ≥3 个不同 token、再断言 spec 流逐 token 相等），并做**变异验证**（去掉那一次 append
   ⇒ 11 条测试红、文件逐字节还原）。教训与 `SCHEMA` §17.16 一致：先排除退化点，
   等价性断言才有区分度。
2. **臂规格漏 `--layers`（编排事故，已修 + 加护栏）**。首版 `run_arms.sh` 只写了
   `--d 256`，`--layers` 落到缺省 4 ⇒ stock 臂被训成了 d=256/L=4 的玩具（浪费 4.5 min）。
   修法：SPEC 显式写死 + 每臂跑完**回读 `results.json` 断言规格与步数**（不靠 exit code），
   该护栏随后真的挡住了一次（`n_layers (4, 8)`）。
3. **CALM 标定口径**：最严格的口径（逐深度条件一致率）在本尺度给「不退」；换到 CALM
   公开口径（联合不一致率）后 CALM 才显示出真实收益 ⇒ 两个口径都写进结果，避免用严口径
   把对手做弱（这是「诚实对手」的核心要求）。
4. **门活性**：无门臂的 `avg_train_gate_mean` 全 0 是**结构事实**（参数里没有门，
   −526k），不是死开关；`intervention` 块按臂分别落盘（`variable_depth_form` /
   `no_carry_gate` / `mod_token_routing`）。
5. **对账脚本的 spec 支路曾是死代码 + 接受率定义混淆（复核 P1-6，已修 + 自证）**。
   `reconcile_numbers.py` 原先遍历 `decode.items()` 里以 `spec_g` 开头的键——那样的键
   **不存在**（真实结构是 `decode["spec"][str(γ)]` + `decode["spec_g{γ}_pooled"]`）⇒ 四条
   spec 断言从未执行，而 docstring 声称已断言；且当时用的 τ = `n_drafts/n_cycles` 是**错量**
   （正确为 `n_accepts/n_cycles`，`n_accepts` 由 `layerpos_per_token_analytic` 逆解，
   `enrich_results.py` 用两条独立反推互检、容差 γ+1）。修法与自证：按真实键重写 + `--selftest` 对真实数据做
   5 处定向破坏（每条断言各一处），**5/5 都被抓到**；另把「窗口口径」与「被检验位条件口径」
   两个接受率都写进 `results.json`（含 `n_accepts` 与定义），派生脚本
   `enrich_results.py` 会核对两条独立反推（容差 γ+1，差额上界 = 末轮截断）。
6. **未出现**：显存超预算（峰值 1.34 GB）、数值发散（grad-norm gate 未触发跳步）、
   未出现锁泄漏（本线按臂释放；另见 §7）。

## 7. 未测项（每条 = 一个最小实验 + 成本）

1. **400M/100M 尺度**（**本格最贵的未答项**）：3 臂（stock / c1-legacy / c1-fair）× 32–40 min
   ≈ **110 min**。C1 在 100M 的形态税是 +0.4362；本波的拆分是 13M 的，**禁外推**。
2. **跨种子复现（n=1 的负结论必须复现后入账）**：`methodology.md` 明写「n=1 的负结果必须
   复现后入账」。本波全部训练臂 = **每臂单 seed**（seed-1 重复被预算砍掉，
   `config.json::noise.sigma_cell_measured = null`），改用「两条臂各自复现历史同配置值」
   （0.0003/0.0007）与仓内种子带 0.0138 作界 ⇒ **Z1/Z2/D2 的负向结论按「方向反转、待复现」
   陈述**。最小补做：`stock-s1` + `c1-fair-s1`（必要时加 `c1-legacy-s1`）≈ **28 min**。
3. **CALM 的学习式出口分类器 / 对比路由变体**（13M 1 臂 + 分类器另训 ≈ 12 min）：
   它是 CALM 相对「朴素置信门控」的增量所在。
4. **配方轴的「尺度」残余混淆**：同份额臂（additive λ=8）只对齐了**份额**（1/9），
   总损失尺度仍 ≈9× CE ⇒ 机制读法保持「点估计可信、机制未完全隔离」。最小补做：
   additive λ=8 再外层除以 9（尺度对齐）≈ 10 min。
5. **「门的出口资产可否被配方替代」**：等权配方下 0.9719 vs 0.9645（差 0.0074）且两者都贴
   上限 1.0 ⇒ 天花板压缩。最小补做：换不顶天花板的代理（tf@2/tf@3）或降低剂量
   （λ∈{0.3, 0.5}）≈ **10 min/点**。
6. **MoD 的等参数对照与第二 isoFLOP 点**（dense L=16 全深度 ≈14 min；L=32/ratio 0.25
   ≈30 min）：把「每 FLOP 换深度」与「参数换 FLOP」分开（本波的吞吐差与质量差都未隔离）。
7. **no-fill ragged 版 LayerSkip / 无门变体**（各 ≈9 min）：本波统一用 fill 语义。
8. **收敛对账（2× 步数、同窗口斜率）与生成质量腿**（本波只有 bpc 与一致率代理；
   12k 步 = 1 epoch 快照）：每臂 ≈20 min。
9. **batch>1 / 长上下文墙钟**（spec 收益在 compute-bound 下消失，ticket 20 宽轴先例 ≈15 min）。
10. **同份额臂与 `ls-legacy`/`c1-fair-l1` 的推断电池腿**（CALM/spec/墙钟，各 ≈4 min）：
    本波这三条臂只有训练侧电池（质量 + tf@k）。

## 8. 结论（一句话 + 适用域）

**一句话（n=1 快照口径）**：在 13M/enwik8/单 epoch 快照上，C1 形态那笔 **+0.3291** 的
matched 税**不是**训练配方把主目标降权造成的——把主目标**保权**（λ=0.1/λ=1 两个剂量）
或换到**无门形态**，trunk 都**更差**（−0.2610 / −0.1267 / −0.1218）；
把**份额对齐**到 C1 现配方（additive λ=8）后则与 renorm **打平**（差 +0.0025）⇒
**驱动量是浅层监督的量（份额），不是「主目标被降权」**，剂量在**同形态**内单调
（按份额排：2.1185 → 1.9842 → 1.855 ≈ 1.8575），方向在 2×2 两轴上都反向
（交互项 −0.1392，两轴**不独立**）；税来自**形态本身**，且必须按配方分列
（C1 现配方 +0.3291 / λ=0.1 条件值 +0.5901 / 本波最好形态臂 +0.2573）。
三种标准实现里，**CALM 式置信门控是候选真对手**（形态臂上一致率 0.959 时算力降到 3.43/8 =
2.3× 更少；门控墙钟在测过的三条臂上是 1.76–2.01×；在普通主干上只能退到 6.59/8），**LayerSkip 式自草稿只省延迟
不省算力**（窗口接受率 0.9109±0.0153、8.70 vs 7.92 层×位置、墙钟 1.99–2.43×），**MoD 式在等解析
算力下质量差 0.398 bpc 且前向吞吐 0.301×（吞吐差与质量差都未与参数 ×2 分离）**。
跨种子复现未做、配方轴的损失尺度未完全隔离 ⇒ 上述负向结论按「方向反转、待复现」入账。

**适用域与禁外推**：13M（d256/L8）、enwik8、12k 步（98.3M tokens）快照、
单卡 bs1 解码（墙钟）/ bs8×256（MoD 吞吐）、同引擎同配方。
**不得外推**到 100M 或生产规模（C1 已测出税随规模变化）、不得把快照当渐近、
不得把 MoD 一个 isoFLOP 点的结论当「MoD 机制不可能」、不得把 CALM 的一致率代价
当任务级质量（本波没有任务级评测）。

**下一步（派发建议）**：① 100M 三臂（stock / c1-legacy / c1-fair）≈110 GPU min ——本格最贵的
未答项；② CALM + C1 形态的**组合**（门控 + 出口资产）在 100M 上是否仍 2× 省算力（这是
R7 判据「同 FLOPs 质量」的真正落点）；③ MoD 的等参数对照。
