# CRITIQUE — R7-existing-early-exit（独立批判审计，fork=false）

## ① 是什么
深度自适应的既有实现（CALM 对比路由 / LayerSkip 自推测早退 / MoD 逐 token 路由），用来校准本仓深度自适应形态（C1/C5/C6）的"增量在哪"。

## ② 对着什么 sota，我们偏离在哪
业界标准（`记忆·未核`，`axes/R-references/PRIOR_ART.md` §1）：三者均有公开结果，共同点是**需要深度维监督**、都报质量-算力折中。我们的偏离：**本地对照只有"dense 全深度监督（LayerSkip 式）"一个臂**（`catalog.yaml:1291–1297`，evidence `.scratch/18-exit-probe`、`.scratch/21-exit-at-scale`），CALM 与 MoD 的本地对照**为零**。

## ③ 五类问题逐条判定
- **开倒车：无。**
- **过程错误：有。** "本地对照"把 LayerSkip 式的 dense 监督臂当成**三者的共同对照**；`benefit` 却写"本地形态的增量 = 逐通道 carry 门 + 随机退出深度 + 定稿不变量"——这个"增量"是**同引擎内的自比**（本形态 vs 本形态的 dense 监督臂），**没有同 FLOPs 的 CALM/MoD 臂**，因此不是对既有实现的增量（`SCHEMA.md §13`：对照臂必须同任务定义/同算力）。
- **结论错误：有（越证据）。** 把"我们的增量在哪"写成已证事实，实际是未测。`catalog.yaml:1291–1297` 的 "benefit" 应降级为**假设**。
- **无意义：否。** 它决定 C1 的"+0.4362 形态税"相对谁谈判——若既有实现对同 FLOPs 基线也付税，则 C1 的税不是新问题；若既有实现近零税，则 C1 的税是形态特异。
- **值得做：是（补一个同 FLOPs 的 dense 早退基线）。**

## ④ 建议动作：补做（最小可判定版本）
- 增加一臂"**同 FLOPs 的 dense 早退基线**"（例如固定前缀早退 / 深度-dropout，无 carry 门、无混合填充，同参数量或同 FLOPs，`SCHEMA.md §15` 二选一），与 C1 形态臂在同一 token 预算、同 seed 下比质量与 tf@4。
- 同步把 `benefit` 里的"增量"改写为"假设 + 待测"。

## ⑤ 正确的验证方式
- **该涨**：同 FLOPs 下本形态的质量应 ≥ 既有早退基线（否则"增量"不成立）。
- **该跌**：本形态的形态税（+0.4362 @100M）相对该基线不应更大。
- **必须不变**：出口资产（tf@4）、逐位一致门禁、以及"深度监督是出口资产前提"这条（`C6`）。
