# CRITIQUE — R3-pruning-sparsity（独立批判审计，fork=false）

## ① 是什么
删参数/删结构换速度（非结构化剪枝 / 结构化剪枝 / 稀疏激活），是"减容量"路线的现成答案。

## ② 对着什么 sota，我们偏离在哪
业界标准（SparseGPT / Wanda / movement pruning / lottery ticket，`记忆·未核`）：非结构剪枝+重训可达高稀疏；结构化剪枝收益依任务、通常需重训、"减结构=减容量"。本格**零本地剪枝实验**，唯一的"本地侧证"是 **W1 的读出切分（只读前 360 维）**（`catalog.yaml:1239–1247`，evidence `.scratch/25-tax-attribution/evidence`）。

## ③ 五类问题逐条判定
- **开倒车：无。**
- **过程错误：有（口径混用）。** 把"读出几何约束（只读前 360 维）"当"剪枝"的侧证：该实验改的是读出子空间（W1 的命题），不是删参数/删结构。用 W1 的 −50.4% 支撑 R3 的"减结构=减容量"属**跨命题借用**（`SCHEMA.md §13` 要求对照臂同任务定义）。
- **结论错误：有（越证据）。** R3 的结论"减结构 = 减容量，模型会绕开被约束的子空间"与 **W5-capacity-vs-compute**（`catalog.yaml:885–895`）的结论**同一句话**。即 R3 的结论不是独立测出来的，而是从 W1/W5 搬来的；R3 自己的判据"同 FLOPs 质量"**一个点都没测**。
- **无意义：是。** 与 W5 同格重复；且"剪枝值不值"在本项目不构成独立决策（W5 已给"减容量不买灵活性"）。不改变任何判断。
- **值得做：否。**
