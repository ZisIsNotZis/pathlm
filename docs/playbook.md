# Playbook — 已经测出来的约束（任何新格子都要过这几条）

这些不是观点，是本仓库的实测结论。每一条都给了出处与**适用边界**——
边界比结论更重要：本项目反复出现「方向随规模翻转」。

## 定律 1 · 元素税分割

**破坏 identity / 顺序结构的机制贵；保留或显式标记 identity 的近免费。**

| 元素 | 税 | 性质 |
|---|---|---|
| 层序 shuffle | **+0.545** | 破坏顺序（组合毒药） |
| skip | +0.175 | 破坏连续性 |
| wrong-token | +0.127 | 破坏 identity（但可识别） |
| `[mask]` | +0.059 | 显式「我不知道」标记 |
| redo | +0.044 | 保留 identity |
| 距离惩罚 | **−0.007** | 保留 identity（**落在 Δ<0.014 不可排序带内，只能称「未观察到超带损伤」，不称「唯一负税/改善」，C7**） |
| embedding noise | ±0.000 | 保留 identity |

出处：`.scratch/06-m2-sweep/`、`.scratch/07-x1-x3/`。
**边界**：在深度自适应形态上以「形态税 +0.44」再次应验（形态 = 改动主干本体）。

## 定律 2 · TTA 增益 ∝ 训练路径多样性

**确定性路径的 checkpoint，K 路径集成恰好得 0**；增益来自**练进去的多样性**
（capped −JS 的 DIVL1 同时改善 baseline 与集成斜率：−0.062 > −0.047）。
出处：`.scratch/08-tts-probe/`、`.scratch/09-m3-interactions/`。
**推论（对调度线是致命的）**：共享主干的多条线之间相关性太高——
集成增益仅 +0.0008~+0.0015。**【2026-10-02 更正（C9）】原文由此推论「beam search 的多线正落在死区里」——撤回**：本定律实测的是**确定性路径 checkpoint 的 K 路径集成**（8 条路径 logits 逐位相同，增益恰为 0），而 beam search 的候选**前缀不同**，属**另一个命题**；本实验**不能**否证 beam。

## 定律 3 · 组合有选择性

- **共享同一台机器 ⇒ 次可加**（损坏 × 修复：+0.087 < 0.277 之和）；
- **一方破坏另一方所需结构 ⇒ 拮抗**（shuffle × everything；整形 × retry）。
出处：`.scratch/09-m3-interactions/`、`.scratch/14-allocator/`、`.scratch/18-exit-probe/`。
**边界**：本项目**不做组合实验**；本定律只用于**解释**已观测到的耦合方向，
并写进各格子的 `deps` 字段。

## 定律 4 · 辅助输出是 fallback，不是 voter

按「修复/退出」训练的辅助输出（深度前缀、重试轮）混进预测会**退化**；
深度**集成**也失败——置信头只排序深度、不排序逐 token 可靠性。
出处：`.scratch/04-m1-runs/`、`.scratch/08-tts-probe/`。

## 定律 5 · 稳定性工程

bf16 autocast 下任何 **negative / reward 类损失**必须 **float32 +
pre-step grad-norm gate**（两次发散教会）；reward 门控需在更新前生效。
出处：`.scratch/09-m3-interactions/`（DIVL1）。

## 定律 6 · 整形 vs 自适应是同一梯度的两面

trunk 被浅层目标塑形（exit 质量好）就毁 retry 精炼；保 retry 就浅层贵。
**两全被证伪**，只能以 profile 选择；且**剂量响应随规模变化**
（dense 0.2 在 13M 温和、@100M corrupt 崩溃 +1.73）。
出处：`.scratch/18-exit-probe/`、`.scratch/21-exit-at-scale/`、`.scratch/24-depth-ar-100m/`。

## 定律 7 · 主干被改，税就来；旁路判断头可以免费

四个独立设计、两个规模、同引擎对照，全部指向同一结论：

| 设计 | 侵入方式 | 代价 |
|---|---|---|
| 回环 retry / corruption 族 | 重入 + 输入分布改变 | 税 +0.12~0.19 |
| dense-exit 整形 | 浅层目标塑形 trunk | 杀 retry（两全证伪） |
| 深度自适应 AR | 每层旁路精化 + 全深度监督 | **+0.44 bpc @100M（96% 干净归属）** |
| 读出结构切分 | 强加 readout/workspace 边界 | **恶化 −50.4%** |

而**不动主干**的路径实测零税：probe 式早退（1.5928 vs 1.5871 @100M）、
MTP 头（d×d 变换无 vocab 参数）。**【2026-10-02 更正（C8）】原文「速度只能走成熟旁路」降为倾向**——本格证据支持旁路零税，但不足以对「所有非旁路结构」下达普遍禁令。
出处：`archive/legacy-docs/retrospective.md` §8。
**边界**：这是**深度自适应形态**的判决；「税只能交易」是本形态下的结论，
不是对所有可能架构的普遍禁令——**当前证据的倾向**是新线先假定它会付税。

## 定律 8 · 规模会翻转方向（必须单独列一条）

- 回环族：税随规模**下降**（+0.122 → +0.082，渐近口径）；
- 深度自适应族：税随规模**上升**（13M +0.31 → 100M +0.44，同引擎）。

出处：`.scratch/19-asym-100m/`、`.scratch/24-depth-ar-100m/`。
**方法论推论**：**小模型只做机制与方向判决，不做量级判决**；
量级判决必须单独放大（且只放大一条线）。

## 定律 9 · 判据设计比实验本身更值钱

- 「局部先验让模型不需要信息」与「信息被保住了」在指标上无法区分 →
  保留类结论必须用 **KV 消融保留曲线**，不能用窗口外命中率（A4 的 90.3% 陷阱）。
- 「构造不好」会造出假失败（needle v1 信号饥饿全桶 0.0）。
- 「单货币记账」会造出相反结论（spec 墙钟 vs FLOPs）。

出处：`.scratch/07-x1-x3/evidence/SUMMARY.md`、`.scratch/05-m1-followup/`、
`.scratch/20-spec-scale/`。
