# Playbook — 已经测出来的约束（任何新格子都要过这几条）

这些不是观点，是本仓库的实测结论。每一条都给了**适用边界**——边界比结论更重要：
本项目反复出现「方向随规模翻转」，但**必须先排除口径与刻度差**（见定律 8 的边界）；
**动手前先过定律 10（变化空间前门）**。每条定律的证据锚点收在对应研究项 `project.yaml`
（`axes/**/project.yaml`，见 `docs/research-schema.md`）的 `experiments` / `evidence` 字段
（本文件只写定律本身，不重复锚点）。

## 定律 1 · 元素税分割

**破坏 identity / 顺序结构的机制贵；保留或显式标记 identity 的近免费。**

| 元素 | 税 | 性质 |
|---|---|---|
| 层序 shuffle | **+0.545** | 破坏顺序（组合毒药） |
| skip | +0.175 | 破坏连续性 |
| wrong-token | +0.127 | 破坏 identity（但可识别） |
| `[mask]` | +0.059 | 显式「我不知道」标记 |
| redo | +0.044 | 保留 identity |
| 距离惩罚 | **−0.007** | 保留 identity（**落在 Δ<0.014 不可排序带内，只能称「未观察到超带损伤」，不称「唯一负税/改善」**） |
| embedding noise | ±0.000 | 保留 identity |

**边界**：在深度自适应形态上以「形态税 +0.44」再次应验（形态 = 改动主干本体）。

## 定律 2 · TTA 增益 ∝ 训练路径多样性

**确定性路径的 checkpoint，K 路径集成恰好得 0**（8 条路径 logits 逐位相同，增益恰为 0）；
增益来自**练进去的多样性**（capped −JS 的 DIVL1 同时改善 baseline 与集成斜率：−0.062 > −0.047）。

**推论**：共享主干的多条线之间相关性太高——集成增益仅 +0.0008~+0.0015。

**边界**：本定律测的是**确定性路径 checkpoint 的 K 路径集成**；beam search 的候选**前缀不同**，
属**另一个命题**，本实验**不**否证 beam。

## 定律 3 · 组合有选择性

- **共享同一台机器 ⇒ 次可加**（损坏 × 修复：+0.087 < 0.277 之和）；
- **一方破坏另一方所需结构 ⇒ 拮抗**（shuffle × everything；整形 × retry）。

**边界**：组合**默认留白**（见 `SCHEMA.md` §4）；本定律只用于**解释**已观测到的耦合方向，
并写进各格子的 `deps` 字段。

## 定律 4 · 辅助输出是 fallback，不是 voter

按「修复/退出」训练的辅助输出（深度前缀、重试轮）混进预测会**退化**；
深度**集成**也失败——置信头只排序深度、不排序逐 token 可靠性。

## 定律 5 · 稳定性工程

bf16 autocast 下任何 **negative / reward 类损失**必须 **float32 + pre-step grad-norm gate**；
reward 门控需在更新前生效。

## 定律 6 · 整形 vs 自适应是同一梯度的两面

trunk 被浅层目标塑形（exit 质量好）就毁 retry 精炼；保 retry 就浅层贵。
**两全被证伪**，只能以 profile 选择；且**剂量响应随规模变化**
（dense 0.2 在 13M 温和、@100M corrupt 崩溃 +1.73）。

## 定律 7 · 主干被改，税就来；旁路判断头可以免费

四个独立设计、两个规模、同引擎对照，全部指向同一结论：

| 设计 | 侵入方式 | 代价 |
|---|---|---|
| 回环 retry / corruption 族 | 重入 + 输入分布改变 | 税 +0.12~0.19 |
| dense-exit 整形 | 浅层目标塑形 trunk | 杀 retry（两全证伪） |
| 深度自适应 AR | 每层旁路精化 + 全深度监督 | **+0.44 bpc @100M（96% 干净归属）** |
| 读出结构切分 | 强加 readout/workspace 边界 | **恶化 −50.4%** |

而**不动主干**的路径实测零税：probe 式早退（1.5928 vs 1.5871 @100M）、
MTP 头（d×d 变换无 vocab 参数）。

**边界**：这是**深度自适应形态**的判决；「速度走成熟旁路」是**当前证据支持的倾向**，
不是对所有非旁路结构下达的普遍禁令——**新线先假定它会付税**。

## 定律 8 · 规模会翻转方向（必须单独列一条）

- 回环族：**等训练渐近口径**下税随规模**下降**（13M 渐近 +0.122 → 100M 渐近 +0.082，2 seeds）；
- 深度自适应族：税随规模**上升**（13M matched +0.31 → 100M +0.44，同引擎）。

**两条轴不要混成一条。** 13M 上的 `+0.364@1k → +0.122@24k` 是**同规模内的训练进度**曲线（平台非衰减），
它只说明「1.1-epoch 快照是渐近值的上界、约高 20%」，**不是**规模证据；规模那条是 13M 渐近 `+0.122`
→ 100M 渐近 `+0.082`，两端都取 4.4-epoch 渐近口径。

**方法论推论**：**小模型只做机制与方向判决，不做量级判决**；
量级判决必须单独放大（且只放大一条线）。

**边界（重要）：「翻转」不都是真的。** 报「规模翻转」之前必须先排除口径与刻度差（墙钟/FLOPs 混用、
步数与退火刻度不同、token 预算不同、跨上下文绝对 loss 不可比）。多 token 预测的 FLOPs 口径
`R=(1+γ)/(1+τ)`：13M 1.065–1.253、100M 1.090–1.268，**两规模都 >1、不翻转**；该 >1 是 `τ ≤ γ` 的
范式定义性质（代价轴），**墙钟前向时间比不得当算力比**。

## 定律 9 · 判据设计比实验本身更值钱

- 「局部先验让模型不需要信息」与「信息被保住了」在指标上无法区分 →
  保留类结论必须用 **KV 消融保留曲线**，不能用窗口外命中率（「窗口外 90.3% 命中」的陷阱）。
- 「构造不好」会造出假失败（needle v1 信号饥饿全桶 0.0）。
- 「单货币记账」会造出相反结论（spec 墙钟 vs FLOPs）。

## 定律 10 · 先问「这个机制要有变化空间，设计上必须满足什么」

**任何实验的契约都必须先回答：要让这个机制产生可测效应，设计上必须满足哪几个条件？
本实验满足了哪几条、缺哪几条？** 缺的条件若无法满足 ⇒ 结论只能记为
「**本设计下无信号**」，**不得**读成「机制无效」（也不得读成「显而易见」）。

已实测到的「必须条件」样例：

| 条件 | 反例（设计没满足 ⇒ 结论无信号） |
|---|---|
| **信息确实超出可见范围** | 窗口 16 + 源信息落在窗外，记忆才有意义 |
| **训练信号迫使其使用** | 2634 真实文本收益仅 0.2%：无必要性损失、无干扰 ⇒ 通道可被忽略，**疑为设计无效** |
| **有真实核** | 稠密 bool 掩码下「窗口」仍算整矩阵 ⇒ 纸面省算力**兑现不了墙钟** |
| **等参数/等深度/等算力对照** | MoD 等解析算力但**参数 ×2** ⇒ 归因未隔离 |
| **判据量效应超过本格自测噪声** | 否则是「不可排序」，不是「无效应」 |

## 定律 11 · 算力与内存的口径

- **算力不得用墙钟**：多 token 预测每 token 算力 `R=(1+γ)/(1+τ)`（γ = 草稿位数、τ = 平均接受长度）。
  13M **1.065–1.253**、100M **1.090–1.268** ⇒ **两规模都 >1**（`τ ≤ γ` 的范式定义性质、代价轴，非「亏损发现」）；
  多猜几个词只省**前向次数**，不省算力。
- **省内存的必须打败的基线**：KV int8 + **沿 `head_dim` 每 32 值共用一把标尺** ⇒
  **6528 B/位置 = fp16 的 ×0.53（省 46.9%）**、近无损（Δbpc +0.0001）、**严格前缀不变**。
  **逐值标尺会反占内存（×1.50）**——那是实现的产物，不是量化的性质。（fp8 / 更大 `head_dim` 两个对手仍未测。）
- **纸面 ≠ 实测**：不换核（仍算稠密矩阵）时，窗口/稀疏的纸面 FLOPs 节省**不兑现**；
  实测墙钟不省、峰值显存反而更费且随 T 恶化。
