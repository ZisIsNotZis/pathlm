## 0. 用户直接指出的问题（最高优先级）

### P-01 目标错配：「并行多线」不是用户要的东西
- 用户原话要点：**跳层的多线肯定没有意义**，而且要多花很多算力。
- 现状：`G5-parallel-lines` 实测的是「同一条主干采 K 条随机跳层路径、再把 K 个输出集成」
  （结构零成本、代价 8× 推理）——**与用户的意图无关**。
- 判定：G5 的**结论在其自设命题下有效**（无部署价值），但**命题是执行方自设的**，
  不能代表「多线 / 投机」这条线。
- 处置：① G5 保留结论但标注「自设命题，非用户目标」；② 真正的投机研究列为主目标（P-02）；
  ③ 后续契约不得再用 G5 代表「多线」。

### P-02 用户真正要的 Spec：我们只覆盖了一半
- 用户要的是**投机解码 / 多 token 预测**里的**路径与概率组合**：
  > 「你要 Spec 这个 N+2，你可以用 N+1 再加一，你也可以直接用 N+2，它用概率组合。」
- 已有覆盖：
  - **H1 每步输出位置数**：多 token 预测的**税**（n_mtp 1→2 +0.041、2→3 +0.0166，递减）。
  - **H3 多位置预测的组合方式**：自门控组合**被实测否证**（门控混合 vs 直跳仅 +0.0020 < 噪声带；
    等参数无门对照更高）⇒ **门会坍缩成链式连跳（96.7%）**——这是「链式 vs 门控组合」的**部分答案**。
  - **C1 `2621-depth-draft-e2e`**：用 depth-4 出口当**草稿**、全深度验证（接受率 + tok/s）——
    **投机解码本体**，且实测端到端与贪心逐位相同。
  - **H5 验证机制**：批量验证可用、逐位一致。
  - **H4 头与主干**：挂头**零税**；跳跃头判中性。
- **缺口（本项即 TODO）**：
  1. 缺少「**N+1 再加一** vs **直接预测 N+2**」这一条**以概率组合为唯一变量**的显式实验；
  2. 缺少**树状 / 多候选草稿**的组合策略实验；
  3. 缺少 **100M 规模**的投机收益（当前只有 13M 的接受率与墙钟，且墙钟收益被判定为
     「13M/launch-bound 现象」）；
  4. 缺少「草稿成本 vs 验证节省」的**净账**（现有端到端只报了接受率与等效加速）。

### P-03 分类错误：「越远越衰减」不属于层序税
- 用户指出：越远越衰减（注意力上的软距离惩罚）**显然属于信息右移**，与跳层无关。
- 核实：`A4-soft-distance-penalty` 本身挂在 **A 轴（序列混合机制）**下、**归属正确**；
  错的是**主 Agent 的汇报表**，把它放进了「元素税 / 层序」那一行。
- 处置：更正汇报归属；在 A4 与信息右移相关格之间补一条「同族」说明（**只记录，不做组合实验**）。

## 1. 主 Agent 自审（用户未指出，但同样严重）

### P-10 单种子是系统性缺陷
- 事实：绝大多数结论是 **n=1**；而**唯二做过跨种子复现的两条全部翻案**——
  「显式通道在搬」跨种子**反号**（+6.05pp → −2.44pp）、「多线机制稳健」被补测**撤销**
  （两臂极差 0.0074 = 效应 51%）。
- 推论：**n=1 的正结论默认不可采信**；只有「效应远超噪声带」且「有机制性证据（含毁源对照）」
  才勉强站得住。
- 处置：把「跨种子复现」从可选项升为**关键格的前置条件**；给所有 n=1 结论加统一标签。

### P-11 合成任务与真实文本之间的口径裂缝
- 事实：信息右移一族（`M1-carrier-type`、`A9-old-info-retention`）几乎全部在**合成关联回忆**上测；
  真实文本代理口径的**自身噪声**（同一模型只换种子：24.81pp）**大于要测的效应**。
- 推论：「显式通道能修长程」的外推能力**很弱**，不能当作通用结论。
- 处置：明确标注该族适用域；把「真实文本上的同口径复现」列为 TODO。

### P-12 口径与判据的选择权集中在执行方
- 事实：出口资产用哪个口径、越界腿能否归因、band 阈值、形态税是否值得付——
  多处由执行者或主 Agent 自选，**用户未批准**。
- 处置：把这类「框架性取舍」集中列出（首个已落：`2629-carry-ragged-projfill/CALIBER_DECISION.md`），
  统一请用户裁决。

### P-13 「定律」级措辞证据不足
- 事实：「保留型近乎免费」来自 `A4` 的 **−0.007 单点**；「元素税定律」由少数元素支撑。
- 处置：降级为「当前证据支持的倾向」，或补点后再升级措辞。

### P-14 量化边界未定位
- 事实：8 位近无损、4 位亏（+0.0457）；**5/6 位**与**旋转 / 随机投影类量化**（TurboQuant 一族）**空白**；
  权重与激活量化也未测（只测了缓存）。
- 处置：补一段（成本低、能定位「从几位开始崩」）。

### P-15 递归 / 线性载体（SSM、Mamba、RWKV 一族）质量完全空白
- 事实：仅在候选枚举里；实测为零。唯一的**线性注意力**尝试因**实现层停摆**被判不可行
  （只有成本交叉点数据，没有质量数据）。
- 推论：这是「信息右移」**最根本**的一条路，我们**没做**。
- 处置：**最高优先级 TODO**。

### P-16 长 T 四点的口径不齐
- 事实：T=256/512/1024 是**半预算快照**、与旧点（98.3M token）**不可比**；T=2048 已补同收敛复测。
- 处置：统一标注口径；如需同预算则补跑。

### P-17 十二格「业界结论」未经核实
- 事实：联网检索不可用，`reference` 格全部标「记忆·未核」。
- 处置：保持标签；需要时请用户提供检索工具。

### P-18 测试基线漂移
- 事实：测试数 549 → 573 → 595，各线自行添加，无统一门禁管理。
- 处置：基线数字入账并声明归属；后续每波刷新。
