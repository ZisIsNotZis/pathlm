# 触主干就付税：小规模架构改动代价的可预判性

> 论文初稿。claim、结构与验收在 [`paper-plan.md`](paper-plan.md)；本文只引用已落盘的事实，
> 数字全部从 [`cost-table.md`](cost-table.md)（生成物）、[`playbook.md`](playbook.md)（定律正文与边界）
> 与各研究项的 `project.yaml` / 实验 `analysis.md` 搬来，**未重算、未换算口径、未翻转符号**。
> 一处具体数字、一个指针（文件 + 字段或标题），读者可以逐条回到原处。

## 摘要

在小规模、固定 token 预算、同引擎同配方的对照下，架构改动的质量代价首先由一件事决定：
**是否触碰主干本体**。触碰主干的形态付可排序的税；不触碰主干的旁路判断头不付税。
「免费」在这篇文章里只有一个意思：**差落在本仓的不可排序带内**，不是改善。不碰主干但**加容量**的改动
可以真的改善，但那时增益要归因到容量（等参数对照）而不是结构（第 4 节）。本文把这条主张拆成
四段可核的实测结果（触主干付税、旁路免费、旁路不当投票器、组合默认留白），再把读这张表必须先过的
四条口径写成检查单。**本文不声称跨规模外推**：方向随规模翻转已被实测，量级判决必须单独放大。

## 1 问题

架构改动的成本通常要在大规模上才量得出来，而大规模实验的代价让「先猜一猜」成为常态。
本文问一个更小、也更可操作的问题：**在小规模、同引擎、同配方、固定 token 预算的对照里，
哪些代价是可以预判的？**

回答之前先钉住三条限制。它们不是脚注，它们决定读者能拿走什么：

1. **char 级 enwik8。** 全部读数绑在字符级建模上，不绑在 BPE 词表上。换分词器后绝对数不可比，
   可比的只有「同引擎配对差」这一层。
2. **快照口径。** 部分读数是固定训练步数下的快照，快照是渐近值的**上界**而不是渐近值；
   凡引用这类读数，必须同时说明它处在哪个训练刻度。
3. **两个规模点。** 两个点给出一个斜率观测，不给出曲线；而且斜率符号在两条轴上相反（第 7 节）。
   这本身是本文的方法论结论之一。

本文的比较一律是**自建对照**（同一引擎、同一训练配方、只改被测的那一个因素），
不比较公开 checkpoint：跨来源的 checkpoint 会引入无法隔离的口径差。

本文不回答「哪个架构更强」；它回答「一个改动大概会让你掉多少质量，还是白改」，
以及**这句话在什么边界内成立**。

## 2 方法：同引擎对照、配对差与不可排序带

**单位。** 主指标是字符级交叉熵（clean bpc，每字符比特数，越低越好）。每个结论都写成
**配对差**：同一 seed、同一评测入口、同一批窗口下，实验臂减对照臂。绝对数只在它决定读法时出现。

**带。** 本仓的全部判读都先过一条**不可排序带**：配对差小于它，就只能说「不可排序」，
不能说「改善」也不能说「更差」。跨格参考带的来历与适用范围在
[`harness/methodology.md`](../harness/methodology.md) §2；个别格子有自己更严或更宽的在力带，
出现时随行注明。

**判据先于实验。** 每个实验在训练之前把契约、判据线、臂清单与评测入口绑定（`tools/prereg_bind.py`），
绑定之后读数才落盘；判据线事后不改，改了就重新绑定并披露。这条纪律在本文里不是道德要求，是
「配对差可以跨实验比较」的前提。

**算力口径。** 一律用等效理论量（FLOPs / layer-passes / tokens-per-forward），**墙钟不进判据**。
理由与反例都在第 7 节（定律 11）。

**结构。** 研究按轴切开：时间（可见范围与可见结构）、深度（按需深度、层间聚合、深度形状）、
宽度（激活宽度与读出）、专家、量化、预测；另有三条辅助线（参照线、工程纪律、backlog）。
逐项事实的 SSOT 是每个研究项自己的 `project.yaml`，跨格汇总在 `atlas/`。
46 个研究项的目录与状态见生成物 [`../docs/catalog.md`](../docs/catalog.md)。

**证据的两张表。** [`cost-table.md`](cost-table.md) 把「定律 ↔ 证据 ↔ 观测代价 ↔ 边界」逐行对上，
由 `tools/build_cost_table.py` 从 `project.yaml` 生成；[`repro.md`](repro.md) 逐实验回答
「run 在哪、重跑命令是什么、能不能字节级复现、缺什么」。本文的每张表都标复现等级，来源即这两张表。

## 3 主结果 A：触主干就付税

把「改动落在哪里」当成自变量，四个独立设计、两个规模、同引擎对照，方向一致：

| 设计 | 侵入方式 | 观测代价 | 来源 |
|---|---|---|---|
| 回环 retry / corruption 族 | 重入 + 输入分布改变 | 税在十分之一 bpc 量级（13M 渐近口径 +0.122；100M 渐近 +0.082） | [代价表定律 8](cost-table.md#定律-8--规模会翻转方向必须单独列一条)、[`playbook.md`](playbook.md) 定律 7 |
| dense-exit 整形 | 浅层目标塑形主干 | 整形换来浅层出口资产，却把 retry 关死（"两全"被证伪）；剂量响应随规模变化 | [代价表定律 6](cost-table.md#定律-6--整形-vs-自适应是同一梯度的两面) |
| 深度自适应 AR | 每层旁路精化 + 全深度监督 | 13M matched 口径 +0.31，100M +0.44（96% 干净归属） | [`playbook.md`](playbook.md) 定律 7、定律 8 |
| 读出结构切分 | 强加 readout / workspace 边界 | 税 +0.6863，且「恢复比例 −50.4%」是**反向恶化** | [代价表定律 7](cost-table.md#定律-7--主干被改税就来旁路判断头可以免费) |

表 A 的复现等级：**`not_reproducible`**。表内 `parallel-sublayer` 一行来自可重训的实验，
回环族、深度自适应与读出切分三行在仓内没有入口脚本或结果文件（缺什么见 [`repro.md`](repro.md)）；
一张表只要有一行不可重建，整张表就不能承诺可重建。

同一条主张在更细的「元素」尺度上重复出现。把「未来位置的 token 换成什么」做成一次扫描，
按代价排序，得到的是同一条分界：

| 元素操作 | 伤害 | 性质 |
|---|---|---|
| 层序 shuffle | +0.545 | 破坏顺序（组合毒药；eval 端 shuffle=1.0 时崩到 3.844） |
| skip | +0.175 | 破坏连续性 |
| wrong-token | +0.127 | 破坏 identity（但可识别） |
| `[mask]` | +0.059 | 显式「我不知道」标记 |
| redo | +0.044 | 保留 identity |
| 距离惩罚（全头共用斜率） | −0.0068 | 落在不可排序带内，**不得**称「改善」 |
| embedding noise | ±0.000 | 保留 identity |

来源：[`playbook.md`](playbook.md) 的定律 1 表；shuffle 与 `[mask]` 两行同时有生成物行
（[代价表定律 1](cost-table.md#定律-1--元素税分割)），其余行住在实验 README 与旧扫描的落盘证据里。
表 1 的复现等级：**`not_reproducible`**——这些旧扫描在仓内只有 README 与证据摘要，
没有入口脚本与结果文件（缺什么逐条列在 [`repro.md`](repro.md) 的总表里）。这是清单的覆盖边界，
不是数字的错误；但也意味着**这张表只能被引用，不能被重算**，读者应把它当方向证据而不是精确刻度。

两条边界必须与结论同读。第一，它们是**深度自适应形态**的判决；「速度走成熟旁路」是当前证据支持的
**倾向**，不是对所有非旁路结构下达的普遍禁令——新线应先假定自己会付税，再用对照把税量出来。
第二，税是**可排序**的，不等于巨大：回环族的税在小规模上是「十分之一 bpc」量级，
而它的方向随规模**下降**（第 7 节）；把一个可排序的税读成「这条路永远不划算」是过度外推。

## 4 主结果 B：旁路可以免费，但「免费」不等于「改善」

不动主干的路径，实测落在带内甚至恰好为零：

| 设计 | 侵入方式 | 观测代价 | 来源 |
|---|---|---|---|
| MTP 式跳跃头（冻结主干） | 只加旁路头 | 挂头前后同一冻结主干：Δ = 0.0000（冻结断言 `grad is None` 通过） | [代价表定律 7](cost-table.md#定律-7--主干被改税就来旁路判断头可以免费) |
| probe 式早退（100M） | 旁路判断头 | 与同规模同引擎基线差 0.0057，落在不可排序带内 | [`playbook.md`](playbook.md) 定律 7 |
| 并行子层 | 改层内串行链 | 质量代价 +0.0458（两 seed 同向），换层内并行度翻倍、算力几乎不变 | [代价表定律 7](cost-table.md#定律-7--主干被改税就来旁路判断头可以免费) |
| FFN 通道掩码（固定前缀 50%） | 改前向的通道集合 | +0.0364（两 seed 同向），换每 token 乘加下降 | [代价表定律 7](cost-table.md#定律-7--主干被改税就来旁路判断头可以免费) |

表 B 的复现等级：**`not_reproducible`**。MTP 头、并行子层与通道掩码三行来自可重训的实验
（`rebuildable_only`）；probe 式早退那一行只留下证据摘要，仓内没有入口脚本与结果文件，
按最严一档给整张表定性。

这张表里有两类行，读法不同。**旁路头**（MTP、probe 早退）是「零税」：不动主干，就不付主干税。
**改前向形状**的行（并行子层、通道掩码）不是免费的——它们付了可排序的税，换来的是**另一条轴**上的
收益（层内并行度、每 token 乘加）。把它们并排放，是为了让读者看到「触主干」的税不是一刀切，
而是与「换到了什么」一起定价。

「免费」还有一个容易读错的方向：带内**不是**改善。读出重参数化（旁路读出加非线性）报出
−0.0812 / −0.0888 的快照改善，但**等参数纯线性对照**与它不可排序，增益归因到**读出容量**
而不是非线性；同一个重参数化在 stock dense 上远小于带（模型主动不用这个自由度），
所以它不是通用改进（[代价表定律 10](cost-table.md#定律-10--先问这个机制要有变化空间设计上必须满足什么)、
`axes/3-width/3.2.1-readout-reparam/project.yaml::conclusion`）。
逐出口读出更贵：−0.0857（两 seed 同向）是真的，但代价是读出参数与每 token 训练算力一起上涨；
把同一笔参数改给主干 FFN 的等参数对照**没有一个 seed 追平它**——这支持「读出容量值得买」，
不支持「参数总量是旋钮」（同节，`axes/3-width/3.2.2-per-exit-readout/project.yaml::conclusion`）。

## 5 主结果 C：免费的旁路不当投票器

旁路输出可以读，但不能当第二个模型来投票。

- **确定性路径的集成增益恰为 0。** 同一个 checkpoint 上取 8 条路径做集成，8 条路径的 logits 逐位相同，
  增益恰为 0。增益只来自**练进去的**路径多样性：加了 capped −JS 多样性压力的臂，集成斜率为 −0.062，
  对照（纯 skip 臂）为 −0.047；即便如此，它的绝对数仍远高于同引擎基线 ⇒ 在 13M 上税仍占主导，
  集成不是免费增益来源。([代价表定律 2](cost-table.md#定律-2--tta-增益--训练路径多样性))
- **辅助输出混进预测会退化。** 把逐深度输出当 voter 混合，等权与置信度加权两臂都差于同 checkpoint
  的单路径；置信度加权只买到 −0.005，因为置信头只排序**深度**、不排序**逐 token 可靠性**。
  （[代价表定律 4](cost-table.md#定律-4--辅助输出是-fallback不是-voter)）

边界：这两条只否证「确定性路径 checkpoint 的 K 路集成」与「辅助输出当 voter」。beam search 的候选
**前缀不同**，属另一个命题，本文不否证它。把「集成没用」推广到所有搜索策略是过度外推。

## 6 主结果 D：组合默认留白

组合的代价不是各部件代价之和，方向取决于它们是否共用同一台机器：

- **共享同一台机器 ⇒ 次可加。** `[mask]` 损坏与上下文内修复组合的税为 +0.087，
  小于两者单独使用之和（+0.127 + 0.150）。（[代价表定律 3](cost-table.md#定律-3--组合有选择性)）
- **一方破坏另一方所需结构 ⇒ 拮抗。** 层序 shuffle × retry、全交互开满，绝对值分别崩到
  2.2293 / 2.2691，远超任何单一部件的税。（同节）

这两行给出的是**解释**已观测耦合方向的能力，不是「组合能省」的承诺。所以本仓的默认纪律是
**组合留白**：一次只动一个因素，组合需要单独授权（`harness/SCHEMA.md` §4）。
唯一的例外是量化轴上的组合格（窗口 + 量化 + 检索），它存在的理由是作为「信息右移」类主张必须打败的
对手基线，而不是为了凑一个组合实验。

比「组合要留白」更前置的一条，是**先问变化空间**：要让一个机制产生可测效应，设计上必须满足什么？
本仓已经撞过四种「设计没满足条件，于是结论只能记无信号」的坑：

| 必须条件 | 反例 |
|---|---|
| 信息确实超出可见范围 | 窗口 16 + 源信息落在窗外，记忆才有意义 |
| 训练信号迫使其使用 | 真实文本上通道收益仅 0.2%：无必要性损失、无干扰 ⇒ 通道可被忽略 |
| 有真实核 | 稠密 bool 掩码下「窗口」仍算整矩阵 ⇒ 纸面省算力兑现不了 |
| 等参数 / 等深度 / 等算力对照 | 解析算力相等但参数翻倍 ⇒ 归因未隔离 |
| 效应超过本格自测噪声 | 否则是「不可排序」，不是「无效应」 |

（[`playbook.md`](playbook.md) 定律 10；逐条证据见该节引到的研究项。）本表是条件清单而不是读数表：
表内唯一的数字（真实文本上的通道收益）只用来解释「为什么这次设计没满足必要性条件」，
它的家在定律 10 那一节引到的实验里。

## 7 怎么用这张表：四条读表检查

这一节是全文最可复用的部分。读到任何一个「某改动更省 / 更好」的数字，先过这四道门。

**第一道：报「规模翻转」之前，先排除口径与刻度差。** 回环族的税随规模**下降**
（13M 渐近 +0.122 → 100M 渐近 +0.082，两个 seed），深度自适应族随规模**上升**
（13M matched +0.31 → 100M +0.44，同引擎）。两条轴不能混成一条。特别地，
「1k 步 +0.364 → 24k 步 +0.122」是**同规模内的训练进度**曲线，只说明「快照是渐近值的上界」，
**不是**规模证据。报翻转前要排除的差包括：墙钟与 FLOPs 混用、步数与退火刻度不同、
token 预算不同、跨上下文的绝对 loss 不可比。还有一个反例：多 token 预测的算力比
R=(1+γ)/(1+τ) 在 13M 是 1.065–1.253、100M 是 1.090–1.268，**两规模都大于 1、不翻转**——
这个「大于 1」是 τ ≤ γ 的范式定义性质，不是亏损发现。（[代价表定律 8](cost-table.md#定律-8--规模会翻转方向必须单独列一条)）

**第二道：判据设计比实验本身值钱。** 保留类结论必须用 **KV 消融保留曲线**，不能用窗口外命中率：
「窗口外 90.3% 命中」可以完全由局部先验解释，与「信息被保住了」在指标上无法区分。
「构造不好」会造出假失败：needle v1 信号饥饿时全桶为 0.0。**单货币记账**会造出相反结论：
同一件事按墙钟看是加速、按 FLOPs 看是更贵。判据带必须先于排序：旧 retry 矩阵的格间跨度是
0.011，小于单格换 seed 的散布 0.0138，按预登记规则**全部格间排序撤回**——排出来的是噪声。
（[代价表定律 9](cost-table.md#定律-9--判据设计比实验本身更值钱)）

**第三道：先问变化空间，再读结论。** 见第 6 节的五条必须条件。缺条件时结论只能是
「本设计下无信号」，不得读成「机制无效」，也不得读成「显而易见」。

**第四道：算力与内存用对口径。** 算力不得用墙钟：线性注意力在 T=256 上纸面省算力，
实装后整模型一步耗时反而是全因果的 2.58 倍；窗口 / 稀疏在不换核时同样不兑现。
内存要打败指定的基线：

| 档位 | 每位置部署字节 | 质量代价（配对） | 来源 |
|---|---|---|---|
| fp16 KV | 12288 | 基线 | [代价表定律 11](cost-table.md#定律-11--算力与内存的口径) |
| int8 + 块标尺 G=32 | 6528（fp16 的 ×0.53） | +0.000101 | 同上，实验 `2632-kv-block-scale` |
| int4 + 块标尺 G=32 | 3456（省 71.875%） | +0.022522 | 同上，同实验 |
| fp8 E4M3（免标尺） | 6144 | 最大配对差 0.005363 | 同上，实验 `2653-fp8-vs-int8-13m` |
| int8 + 块标尺 G=128（head_dim=128） | 6240 | +0.000123 | 同上，实验 `2657-fp8-hd128-head-dim` |

表 3 的复现等级：**`rebuildable_only`**——四个来源实验都有入口脚本与结果文件，但重跑是
「重造一个同规模同配方的模型」，不是重算同样的字节（权重不入库、语料不入库）。

两行反例同样重要。**逐值标尺会反占内存**（×1.50）：那是标尺粒度的实现产物，不是量化的性质。
**省字节要按整笔账记**：低秩压缩（MLA 式）每 token 要付上投影算力，潜维 272 时是
1,671,168 MACs，等于单层 FFN 的 17.7083%；同字节轴上的胜负要看「质量 + 这笔算力 + 从零训练」，
不能只看省幅。fp8 的字节优势也随 `head_dim` 变大而趋近消失：`head_dim`=128 时只剩 96 B/位置。
（同节）

**读表顺序合成一句话**：这个数字在哪个规模与刻度上、判据是什么、变化空间满足了没有、算力与内存
按什么记账。四问答不全，数字不读。

## 8 代价表与复现等级

本文的两张主表都不是手写的。`atlas/cost-table.md` 由 `tools/build_cost_table.py` 从 46 份
`project.yaml` 的 `laws` / `cost_rows` 字段生成，每条代价事实带方向、规模、适用边界与出处；
手改它与生成结果必须逐字节一致，否则 `--check` 判红。`atlas/repro.md` 由 `tools/inventory_runs.py`
从磁盘生成，逐实验回答「能不能在克隆内重算」。

复现等级的现状（[`repro.md`](repro.md) 的汇总一节，生成时统计）：全部实验里
`reproducible`（克隆内可重算）为 0 个，`rebuildable_only` 为 109 个，`not_reproducible` 为 33 个；
入库权重为 0 个（`*.pt` 被忽略），有落盘结果文件的实验为 110 个。原因不是懒：训练权重与语料
都不入库，克隆里能拿到的只有结果文件与入口脚本，所以任何训练类读数只能「重训得到同类结果」。
**这意味着论文没有一张表可以标 `reproducible`**——本文的表只能在 `rebuildable_only` 与
`not_reproducible` 两档里选。复现等级不是免责声明，是结论的一部分：一张标不出等级的表不进正文。

## 附录 A 数值纪律与两处撤回

**A.1 数值纪律。** bf16 autocast 下任何 negative / reward 类损失必须走 float32，并在**更新前**
做 grad-norm 门控。这不是风格问题：同一配方不加门控时，一条臂在 step 4600 发散、另一条在 step 2200
静默 NaN（clamp 后梯度爆炸）；加了门控的版本跑完，并给出第 5 节引用的集成斜率。
（[代价表定律 5](cost-table.md#定律-5--稳定性工程)）

**A.2 撤回一：retry 矩阵的格间排序。** 旧矩阵在 6 个 cell 上排出「soft × mixture 最好」，
其格间跨度为 0.011，小于单格换 seed 的散布 0.0138。判据带必须先于排序，因此**全部格间排序撤回**，
包括那句「最好」。（[代价表定律 9](cost-table.md#定律-9--判据设计比实验本身更值钱)）

**A.3 撤回二：KV 逐值标尺的「更省」。** 早期实现给每个值单独存一把标尺，报出「量化更省内存」；
计入标尺后它反而占 ×1.50 的内存。那是标尺粒度的实现产物，不是量化的性质；规范做法是沿 `head_dim`
每 32 值共用一把标尺。（[`playbook.md`](playbook.md) 定律 11）

**A.4 一处必须与数字同读的旁证。** MoE 的四条臂在 13M 上都没买到可排序的质量，但同一批实验给出的
两个解释（「容量买到了但没喂饱」与「容量根本兑现不了」）在本 n 下分不开；等参数稠密旁证只说明
「光加参数不够」，不能读成「稀疏本身更差」。逐臂读数与逐层路由坍缩登记在
`axes/4-moe/4.1-sparse-experts/project.yaml::conclusion`，本文不替它下更强的结论。
