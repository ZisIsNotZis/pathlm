# Research Wiki — LM 算力路径设计空间的完备目录 + 单实验 Playbook

> 一句话：这里不是「一个模型」，而是**一张地图**——把语言模型的「算力路径设计空间」
> 按轴切开，每格一个课题，课题里记录**谁试过、结果如何、为什么失败、怎么复现**。
> 目录是完备的（每格都有页），内容是渐进的（大量格子仍是空白，等着被填）。
> 起点来自 PathLM 项目（25 个执行 ticket）的实测资产，见 `archive/`。

## 这是什么 / 不是什么

**是**：

- 一张**可机检的目录**（`SCHEMA.md`）：每个格子都有页；`tools/check_schema.py` 让
  「缺页 / 缺字段 / 已判却无证据」直接 fail。
- 一份**失败路径的账本**：不只写什么有效，更写**试过什么、为什么失败、排除了什么
  替代解释**——这是本项目最贵的资产。
- 一套**共享天平**（`docs/methodology.md`）：三列账本、方差界、口径标注、双货币记账、
  冒烟 + 变异测试、三种可复用的审计模板。

**不是**：

- **不是组合实验库**。本研究**只做单轴单格实验**，基底恒为 stock 对照；
  **不做组合实验**——组合留白是显式声明，不是遗漏。组合取舍属具体产品方 scope。
- **不是排行榜**。这里比较的是「同一格子内谁更值得做」，不是「哪个模型更强」。
- **不能只看结论**：所有数字都带口径（快照 / 渐近 / matched-step / 墙钟 / FLOPs），
  跨口径比较会得出相反结论。

## 三条已测的总规律（为什么值得读）

1. **主干被改，税就来；旁路判断头可以免费。** 四个独立设计、两个规模一致；
   而挂头（MTP / probe 判断头）@100M 实测零税。→ 「速度只能走成熟旁路」。
2. **元素税分割**：破坏 identity / 顺序的机制贵（shuffle +0.545、skip +0.175），
   保留或显式标记 identity 的近免费（mask +0.059、距离惩罚 **−0.007**）。
3. **判据设计比实验本身更值钱**：局部先验会让模型「不需要」信息，这与「保住了」
   在指标上无法区分——保留类结论必须用 KV 消融判据（详见 `docs/playbook.md` 定律 9）。

## 怎么读

| 想做什么 | 去哪 |
|---|---|
| 一眼看**哪里是空白**（状态灯） | **`INDEX.md`** |
| 读**一条轴的完整故事** | `axes/<轴>/README.md` |
| 接手/复现**一个格子** | `axes/<轴>/<格子>/README.md`（§6 判据、§9 复现）→ 同目录 `experiments/` |
| 学**方法论** | `docs/methodology.md` |
| 查**已验证的约束** | `docs/playbook.md` |
| 看**核心设计（RAP）与共享底座** | `docs/design.md` |
| 知道**旧项目发生了什么** | `archive/README.md` → `archive/legacy-docs/retrospective.md` |

轴的记号：`A` 序列混合 · `C` 垂直（深度）· `H` 视界 · `W` 宽度 · `F` 迭代 ·
`M` 状态载体 · `G` 策略与调度 · `R` 参照线（必须打败的基线）· `P` 修饰符。

## 目录结构

```
catalog.yaml       ← 目录枚举（完备性的唯一来源）
INDEX.md           ← 状态灯总表（自动生成）
SCHEMA.md          ← 课题页/实验的格式契约
docs/              ← 设计 + 方法学 + 定律
axes/              ← 大类（轴）→ 小类（格子）→ 实验目录
tools/             ← 生成器 + CI 校验
archive/           ← 旧项目（只读）
pathlm/ tests/     ← 共享底座与历史引擎（原地保留）
```

## 贡献

欢迎 PR（补一个空课题、加一次实验、修正一个结论）。硬性规则与流程见
`CONTRIBUTING.md`：改 `catalog.yaml` → `python3 tools/build_wiki.py` →
`python3 tools/check_schema.py` → 提 PR。

## 复现环境

```bash
python3 -m pytest tests/ -q          # 129 绿（共享底座语义）
python3 tools/build_wiki.py --check  # 目录与生成物一致
python3 tools/check_schema.py        # 格式/完备/证据锚点
```

数据 enwik8 自动下载；权重 `*.pt` 不入库（派生物，按 ticket 契约的命令重训）。
单卡 RTX 4090 24GB 包络：13M ≈ 5 min/6000 步、单臂全电池 11–30 min；100M ≈ 32–70 min/臂。
