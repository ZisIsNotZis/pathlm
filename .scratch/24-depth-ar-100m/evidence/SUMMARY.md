# Ticket 24 — 深度自适应 AR @100M：形态税的规模验证（SUMMARY）

> 日期 2026-09-28。契约 `.scratch/24-depth-ar-100m/issues/01-100m.md`（重大节点：
> 形态税是否随规模收缩——13M matched +0.31 → 100M ?）。形态 = ticket 23 定案的
> 100M 版：纯 AR 教师强制、全深度并行监督（fp32 头，权重均匀 + 最终深度 2×，契约
> 配方）、逐通道携带门（carry 初始化 σ(−2)）、随机退出深度 U{0..L} + proj-fill
> （恒等初始化逐层 KV adapter，ticket 23e 新最优臂）。代码 = `train_depth_ar.py`
> 规模化（additive：`--mlp-mult`/`--final-weight` CLI + gnorm 监控聚合）+
> `pathlm/depth_ar.py` forward 加 `final_weight` 参数（缺省 1.0 逐位还原 v1）。
> 单测 120 基线 + 2 新（final_weight 恒等还原 / 手工加权一致）= **122 全绿**。

## 0. 结论速览

| # | 项目 | 判据 | 结果 | 判定 |
|---|---|---|---|---|
| 主 | 形态税 @100M（1.1-epoch） | 本 run clean − B0_100M 1.4612 | **+0.4563**（1.9175 − 1.4612） | **未随规模收缩**：高于 13M matched +0.31，未过 +0.5 恶化线——落在「中性」与「恶化」档之间的空档，偏恶化侧；**缩放定律修正信号（契约「若反向」分支）** |

| 2 | 出口资产 tf@4+ | 半栈出口可用 | **tf@4 = 0.9726**、tf@6 = 0.9946 | **成立**且 13M 模式复现（13M 0.97–0.98） |

**一句话**：100M、1.1-epoch 同 token 预算下，形态机制照常工作（深度精化、出口
草稿命中、生成合法），但 depth-12 底座 1.9175 对 B0_100M 1.4612 的形态税
+0.456，**高于** 13M matched 的 +0.33（同 98.3M token 预算、12k vs 24k 步）——
ticket-19「税随规模下降」的经验**不适用于深度自适应形态的快照口径**；契约的
缩放定律修正分支被触发。残税归因含一个新配方混杂（最终深度 2×，见 §2.3）。

## 2. 主判读：形态税 @100M = +0.4563

### 2.1 对照表

| run | clean bpc | acc | 口径 |
|---|---|---|---|
| B0_100M（ticket 16，train_m1 引擎，无 dense 机制） | **1.4612**（s0 1.4663 / s1 1.4560 均值） | 0.7009 | 1.1-epoch 快照 |
| C1_100M（ticket 16） | 1.5871 | 0.6797 | 同上 |
| 13M 形态 matched（ticket 23d，98.3M tokens 同预算） | 1.8582（fill）/ 1.8356（proj-fill） | — | vs dense-B-12k 1.5287 → 税 +0.33/+0.31 |
| **本 run 100m-s0**（depth-12 读出） | **1.9175** | 0.6095 | 1.09 epoch 快照 |

**形态税 @100M = 1.9175 − 1.4612 = +0.4563**（若按 s0 单种子 1.4663 计：
+0.4512；两种子散布 0.0103 → 税不确定度 ~±0.01，结论不依赖种子口径）。

### 2.2 判据分档（契约三分档）

- 税 < +0.31 且 ≤ +0.15 → 改善：**否**；
- 税 ≈ +0.3 → 规模中性：**否**（+0.456 ≠ +0.3）；
- 税 > +0.5 → 规模恶化：**未过线**（差 0.044）。
- **落档：+0.31 < 税 ≤ +0.5 的空档，偏恶化侧**。契约未给该空档单列判语，
  如实记录为：**形态税未随规模收缩，方向与 13M→100M 的改善预测相反**；
  未过恶化阈值，但「缩放定律修正」信号（契约预设分支）已被触发。
  同 token 预算比较：matched 税 13M@98.3M-token +0.3295 → 100M@98.3M-token
  +0.456（+0.13，≈39%），**规模斜率为正**。

### 2.3 口径与混杂（如实记录，判读时必须携带）

1. **对照数字口径**：1.4612 = ticket 16 **两种子均值**（s0 1.4663 / s1 1.4560）；
   契约标注「（s0）」系标注误差，按契约数字 1.4612 执行，单种子口径已并列报出。
2. **跨引擎对照**：B0_100M 出自 train_m1 引擎（corruption/retry 站架构、未 tied
   读出细节不同）；23 系内部税对照（dense-B）是同引擎臂。本轮契约明确指定
   B0_100M 为对照 → 税含引擎差与形态差，不能全归因形态。契约口径如此，照办。
3. **配方混杂（新）**：本 run 按契约用「权重均匀 + 最终深度 2×」，而 13M matched
   +0.31 对照系**等权**（23b 定案配方）测得。23b 的方向证据（浅层相对权重越低
   底座越差：w 1.0→0.1→0.02 单调恶化 2.45→2.57→2.73）提示 final 2×
   （等效浅层相对权重 0.5）**可能贡献部分税**——+0.456 不能干净读作「规模使税
   变差」，规模效应与配方效应在本轮设计下不可分离（契约单臂设计，未设等权臂）。
4. **评测协议差**：本 run clean = depth_curve 末格（20×16×512 全深度前向，eval
   尾 10M）；B0_100M 出自 train_m1 评测电池。两者都在同 eval 尾部，但批次协议
   不同（23 系跨 ticket 对比同样存在此口径差，量级远小于本判读差 0.15）。
5. **单种子**：契约指定 seed 0 单 run；B0 侧种子散布 0.0103 不足以翻转 +0.15
   级别的档位差。

## 6. 门行为（副测量：训练均值 + 分布级探针）

- **训练均值**（gate_log.jsonl，全程均值→末步）：g0 0.070→0.070，g1 0.012，
  g2–g11 0.006–0.011——**全层远低于 carry 初始化 σ(−2)=0.119**，即训练把门
  **从 0.119 收小**而不是打开。与 13M 相反（13M：g0/g1 打开到 0.19–0.43，
  深层微开 0.04–0.09）。
- **分布级探针**（`gate_distribution.json`，全深度前向 batch 8）：逐层
  p90 = [0.131, 0.0099, 0.0055, 0.0037, 0.0008, 0.0009, 0.0002, 0.0001, ~0…]，
  frac>0.5 全层 ≤ 0.0004——**门不是双峰，是全局近闭合**；无任何「少数通道
  全开」结构。
- **判读**：100M 下精化动力学变成「layer 0–1 的小门 × 大 block delta」
  （g0 均值 0.070 仍为深层 10 倍；depth 曲线的一跳也集中在 0→1），深层门
  趋近恒等。机制无发散、carry 初始化按设计保底（tax 未爆到 >+0.5 或训练
  崩溃与此一致），但「门自学习读出/交棒分工」的图景在 100M/1.1-epoch/2× 配方
  下**未出现**——门收敛行为是规模、训练时长与配方哪一个的函数，本轮不可分
  （与 §2.3 混杂 3 同源）。

| 量 | 100m-s0 | （13M sanity-B 对照） |
|---|---|---|
| 有效读出秩 | **206/206**（无低频塌缩） | 194/206 |
| null 维 | 514 | 62 |
| null 能量占比（depth 0→12） | 5.9%→**51.7%** | 4.4%→10.1% |

- 状态能量的大多数（~52%）放在读出不可见子空间——**携带量轴成立**且远超 13M；
  但功能性判据为 0：沿 null 方向扰动 mid-depth 状态，后半栈 logits 响应全部

  在 720 维上过严（口径未冻结，Q1 延续）。本轮不裁决。

## 9. 判读汇总与对 stage-2 的推论

1. **主节点判读**：形态税 @100M（1.1-epoch 快照）= **+0.4563**，未随规模收缩、
   方向反向（13M matched 同 token 预算 +0.33 → +0.46）——**契约「缩放定律
   修正」分支触发**。附两项不可分离的混杂：跨引擎对照（B0_100M 出自 train_m1）
   与配方差（final 2× vs 13M 等权）。
2. **ticket-19 经验的边界**：回环时代「税随规模与训练下降」的规律对深度自适应
   形态**不外推**（至少在此配方/预算/引擎对照下）。23d 的 100M 渐近外推
   （+0.21 @4.4ep）建立在 13M 收缩轨迹 + ticket-19 系数上，本轮快照不支持其
   乐观分支。
3. **形态的不可替代资产在 100M 变厚**：出口资产 tf@4 0.973 / tf@6 0.995，
   墙钟 3.1×（exit-4）/ 1.8×（uniform-exit）实测兑现；半栈与全栈质量差
   0.0003 bpc——「买深度」在本形态里边际收益趋零，「买出口」的收益成立。
   交易目标若改写为「出口资产换底座税」（23d §11 预案），100M 数据支持该写法。
4. **stage-2 优先级修正**：(a) 配方等权臂 @100M（拆 final-2× 混杂，最便宜、
   直接决定 +0.46 的归属）；(b) 同引擎 dense-100M 臂（拆跨引擎对照混杂，
   23 系内部口径重建）；(c) 门收敛动力学的规模/时长归因（深层门趋 0 是欠拟合
   还是规模现象）；(d) 4.4-epoch 渐近 run（唯一能回答「快照税是否随训练收回」
   的实验，预算 ~2h）。

### 12.2 判读矩阵（契约 02，逐格）

### 12.3 副测量（契约必报）

1. **depth 曲线**：EQ 13 格单调不升（4.7697→2.0216→…→1.9200，形态与主 run 同款
   极端半栈平台，d6−d12 = 0.0003）；dense 中间深度**非单调**（7.58→4.83→4.87→…→
   2.88→1.48）——dense 中间读出无直接监督（仅最终 CE），系残差态 probe 读出，
   非精化曲线，非单调为预期。
2. **tf@4 / tf@6**：EQ **0.9699 / 0.9943**（≈主 run 0.9726/0.9946，**出口资产
   配方鲁棒**）；dense **0.1199 / 0.1598**（tf 全曲线 0.06–0.51）——**纯 dense
   trunk 无浅层截断资产**（dense tf 系无监督 probe 读出一致率，截断资产 proxy
   口径，如实标注）：**出口资产是全深度监督（形态）的产物，不是 dense trunk
   自带的**——「形态的不可替代资产 = 出口资产」再加一票。
3. **uniform-exit wall**（`24b-decode-wall-eq.json`，greedy hard commit，prefill
   64 + 96 new × 3 prompts，gen-only 口径；含 prefill 口径同向）：

   | 解码模式 | EQ tok/s | vs full | （24 主 run 参考） |
   |---|---|---|---|
   | full depth 12 | 93.60 | 1× | 76.3 |
   | fixed exit 4 | 264.22 | **2.82×** | 235.4（3.1×） |
   | uniform exit U{0..12} | 156.63 | **1.67×** | 137.8（1.8×） |

   dense 臂 uniform-exit wall **N/A**（引擎无退出机制，逐 position 混深截断在
   dense 语义下未定义）；dense full-depth 墙钟 142.99 tok/s ≈ 形态 full 的
   **1.53×**（形态引擎 full-depth 解码开销，Python 循环小 batch 方向性口径）。
   dense 增量解码器（逐层 KV、无门/无填充）与并行 forward 逐位一致
   （max|Δlogit| 9.2e-5，自检脚本内 assert）。
4. **门行为（EQ 副线）**：训练门均值 g0 0.069 / 深层 0.007–0.012——与主 run
   （0.070 / 0.006–0.011）同款：**「100M 门从 carry 收小」与 final-2× 无关**
