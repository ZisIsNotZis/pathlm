  **同量级** ⇒ 主判据符号未排除。**先修两个混杂，再判**：
  1. **修 gate 跳过混杂**：上一波该臂 42.7% 步被 grad-norm gate 跳过（实际只学 ~6900 步）
     ⇒ 必须让该臂**吃满更新**（放宽阈值 / 改 pre-step 缩放的数值口径 / 记录 skip 数为 0）；
  2. **换成表征级去相关**（而非输出 JS 罚则）：候选实现由你选一种并在契约写死理由
     （例如对同一 token 不同路径的隐状态做**正交/去相关罚则**、或对路径 logits 做**去偏的 pairwise 惩罚**、
     或 **hidden-state 级 variance/covariance 罚则**）；**禁止**直接沿用 capped-−JS 输出罚则。
- **判据（预登记，主 Agent 已定）**：
  - 主判据：`(K 路径集成 bpc) − (单线 stock bpc) < 0` 且 CI 不重叠 ⇒ 多线**首次成立**；否则记「仍不成立」；
  - 并列：`(去相关臂 K 路径集成) − (无去相关臂 K 路径集成) < 0`（机制是否起作用）+ 成对 JS（是否真的更不相关）；

  - **单点不外推**；若 50M 预算不够，**先在 13M 上把机制做对**（13M 单臂 ~13 min），
    机制成立再上 50M——**两个规模点都要有**才能谈趋势。
- 预算：13M 三臂 ≈40 min；若机制在 13M 成立则加 50M 两臂 ≈60 min（总计 ≈100 min，**可超本契约预算，先报数**）。
