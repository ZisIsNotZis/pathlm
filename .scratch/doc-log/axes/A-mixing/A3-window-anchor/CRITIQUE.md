## ① 这是什么
用硬窗口 + 常驻锚点/sink 把"左边前缀可以扔"变成结构事实，从而免重 prefill、把长上下文成本从 O(T²) 降到 O(T·w)。

## ② 对着什么 sota，我们偏离在哪
sota：**StreamingLLM**（保 sink + 滑窗即恢复流式困惑度，2023）、**Longformer / BigBird**（滑窗 + global token）、**gist token**（Mu 2023）、Mistral/Gemma 的 SWA。我们**没有机制层偏离**——锚点槽就是 global/sink token 的换名。唯一"偏离"是**测量口径**：我们不用困惑度，用"真删位置 j 的 KV 测损伤"的保留曲线（这正是价值所在）。`axes/A-mixing/PRIOR_ART.md` 自己给该格判 `(a) 业界已做透`。

## ③ 五类问题逐条判定
1. **开倒车：有**。机制结论层面整套是业界标准件的复算：税 `+0.058~0.121`（"滑窗近无损"的本地版）、锚通道 `76.8→93.3%`（"保 sink 即恢复"的本地版）。但该格 `status: judged`（`catalog.yaml:250`）并以本地数字示人，`prior_art_verdict` 只存在于**被注释掉的** YAML 里（`catalog.yaml:237`，且那行装的还是 A2 的文本）⇒ 读者看到的是"我们发现了窗口+锚点很便宜"，而不是"我们复算了业界结论"。
2. **过程错误：有（重）**。
   - **证据链断裂**：该格 evidence 只有 `.scratch/07-x1-x3/evidence @7b47555`、`.scratch/05-m1-followup/...`、`.scratch/13-four-experiments/...`（`catalog.yaml:264-266`）；仓内 `axes/.../A3/experiments/2505-m1-followups/README.md` 只是一个 9 行的 legacy 回填 stub（无 `results.json`/`run.py`/`analysis.md`）⇒ 头号数字**在本仓不可复核**，只在 `.scratch/07-x1-x3/evidence/SUMMARY.md`（20 行）里以表格存在。
   - **口径混用**：税写 `+0.121（原X2口径）/ +0.058（needle v2 重设计后——改善是测量不是机制）`（`catalog.yaml:254`）。同一个"税"因为**测量仪器**改了就从 0.121 变 0.058 ⇒ 这两个数不是同一个量，并列示人会被误读。
   - **组合冒充单因素**：真正带给该格的"真产物"锚通道 93.3% 来自 X3 = X1(距离惩罚) + X2(驱逐)（`.scratch/07-x1-x3/evidence/SUMMARY.md`），不是单因素；SCHEMA §4/C15 的例外清单里没有登记"惩罚×驱逐"。
   - 该格引用的 ERRATA 数字 `+0.212`（`catalog.yaml:252`）**出处是 A9 的实验**（`A9/.../2615-window-trained-retention-13m/analysis.md` §5.3 recent:32 = 0.2118），A3 自己的 evidence 里没有它。
3. **结论错误：有**。`axes/A-mixing/README.md`（由 `catalog.yaml:43` 渲染）写 **"丢前缀在 bpc 上很便宜（+0.058~0.121 @13M）"**，而 A3 的 verdict 写 **"并不便宜（只保留最近 32 个 = +0.212 bpc）"**（`catalog.yaml:252`）——同一轴上两句相反的话同时在线。**正确结论应该是**："窗口/锚点是业界标准件；**评测期**丢掉整个左前缀的 bpc 代价小（+0.06~0.12），但**累计预算**（只留最近 k）代价是它的 1.5–3.5 倍（k=32 → +0.212，k=64 → +0.081）；真正本地独有的不是机制，而是'用累计预算报代价'与'低损伤 ≠ 保住了'这两条测量方法。"把 `+0.121/+0.058` 并列、把锚通道当"真产物"都是过度陈述。
4. **无意义：无**（"窗口是价格上界"这个角色必须留）。
5. **值得做：有（中）**——但要做的是**方法学**不是机制：把保留曲线口径固化成工具，供所有"压缩/摘要/检索"线复用。
