**A1 · 「AR 算术下界」不是下界（方法学错误，且在 SCHEMA 里）**
- `SCHEMA.md:168–170` 写：下界 = `P(t+1命中) × P(t+2命中|真t+1)` = `0.6934×0.6953` = 0.4822。
- 实现处 `axes/H-horizon/H4-head-trunk-relation/experiments/2611-jumphead-ar-control-13m/analysis.md:61–72`
  实际乘的是两个**边际**（`trunk_t1_hit × oracle_t2_hit`），第二个**未条件于第一步正确**。
- 正确：`P(A∩B)=P(A)P(B|A)`，仅凭边际只能保证 `P(A∩B) ≥ max(0,a+b−1)` = **0.3887**。
- 危害：`0.5489 ≥ 0.4822 ⇒ 对账通过、实现正确` 无效；`0.3128 < 0.4822 ⇒ 构造错误铁证` 无效；
  `min(a,b)=0.6934` 当上界、`0.5489/0.6934=0.7916` 当条件命中率，同样无效。
- **实测 0.5489 本身不必撤**（代码层证据仍可证明对照臂不同），撤的是**数学证明**。

**A2 · 量化 scale 沿 batch+token 取 amax ⇒ 未来信息通路 + 跨请求耦合（部署价签失效）**
- `tools/evalkit/kv_quant.py:14–20` 自述「沿 batch 与 token 轴取 amax（= KIVI K 侧静态、全序列 amax）」；
  `:106–120` 代码 `reduce = 除 head(-3)/channel(-1) 外全部维度`。
- 后果：**过去位置的 K/V 反量化值会因未来 token 或同批其他请求而改变**，因果掩码挡不住。
  反例（无需训练）：过去值 1；无未来时 int4 反量化 = 1；加入未来值 1000 后反量化 = 0。
- 受害结论：int8「近无损省一半」、int4 +0.0457、GQA/MQA×int8/int4、窗口×量化的跨族 Pareto 排名。
  ⇒ 只能记为「**全序列、跨 batch 动态 scale 下的离线扰动实验**」，不能当部署 KV 压缩价签。
- `tests/test_kv_quant.py:39–44` 的「独立参考 scale」复制同一全归约，**未测前缀不变性**；缺两条必要测试：
  改未来 token 不改过去 logits；改同批其他请求不改本请求 logits。
- 注：**方向**（int8 ≪ int4）可能仍稳，但数字需在因果/流式量化下重测。
