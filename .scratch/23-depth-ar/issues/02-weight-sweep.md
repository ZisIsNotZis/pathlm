- **Status:** done（W1-W3 主判据全败且单调反向——监督加权轴关闭；归因改判入 SUMMARY §9；推荐配方 = v1 等权，W3 为 Pareto 次优）

## 假设

形态税来自**全深度等权监督稀释最终深度目标**。给浅层出口降权（aux 化）
即可把税压回 <0.05，代价是浅层出口质量变差——本 sweep 量化这对权衡，
并选出可用配方。

## 协议（全部复用 train_depth_ar.py，sanity-B 配置 d=256/L=8）

| run | 浅层 aux 权重（每深度） | 最终深度权重 | 备注 |
|---|---|---|---|
| W0 | 1.0（=ticket 23 复现点） | 1.0 | 对照，已知税 +0.68 |
| W1 | 0.1 | 1.0 | 主候选 |
| W2 | 0.02 | 1.0 | 激进 aux |
| W3 | 1.0 → 0.1 线性退火（最后 20% 步） | 1.0 | 先建梯子后抛 aux |

每 run 3600 步（同 ticket 23，~3 min），总 GPU ≤40 min。

## 测量与判据

- **主判据**：全深度 bpc 相对 dense-B（1.1719 同点对照）的税 < 0.05；
- **副判据**：depth-4 出口 bpc 不得劣于 W0 的 depth-4 超过 0.3（浅层出口
  仍需可用）；depth 曲线仍单调；
- 产出**权衡曲线**（aux 权重 × [tax, depth-4 bpc]），选出推荐配方；
- soft commit OOD 顺带复验：W 推荐配方下重跑 ticket 23 的 rescore 对照
  （soft 6.9 vs hard 1.2 是否复现）。
