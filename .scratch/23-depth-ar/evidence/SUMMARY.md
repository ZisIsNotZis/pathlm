## 3. workspace 探针（判据 2）

定义（可操作化，与契约措辞的对应见 Q1）：logit-Jacobian = tied U [V,d]；
SVD 奇异值 >1% 峰值计有效读出秩；null 空间 = d − rank 维 = 读出不可见携带余量。
**功能性判据**：把 mid-depth（⌊L/2⌋）状态沿每个 null 方向 ±ε（ε=5% 行范数），
重跑后半栈，depth-L logits |Δ| 的中位/最大；> δ=0.01 的 (batch,方向,符号) 条目数
= functional_dirs。**数值对照**：同方向当前行 depth-mid logits 变化应 ≈0。

| 量 | sanity-B (d=256) | sanity-C (d=128) | sanity-A (d=128,L=4) |
|---|---|---|---|
| 有效读出秩 | 194 | 128 | 127 |
| null 维 | **62** | **0（结构性）** | 1（阈值边缘，见下） |
| functional_dirs（超阈条目） | **26 / 496** | 0 / 0 | 8 / 16 |
| \|Δlogit\| 中位 / 最大 | 0.0034 / 0.0123 | 0 / 0 | 0.0381 / 0.0394 |
| null 能量占比（depth 0→L） | 4.4%→10.1% | 0 全部 | ≤0.13% |
| 对照（当前行 Δ，应≈0） | **3.4e-05** ✓ | — | 0.173 ✗（非真 null，见下） |

- **宽度假设成立**（判据 2）：B 的状态把 ~10% 能量放在读出不可见子空间，
  且其中部分方向**被后续计算功能性读取**（26 条 >δ 响应）；C 在 d<V 下无任何
  携带余量。26 > 0，判据满足。
- ⚠ sanity-A 的 null 维=1 是奇异值 1% 阈值的边缘产物（该方向 U·n≠0，对照
  0.17 失败），A 的 workspace 数字不可判读；宽度判读以 B vs C 为准。
- 读出秩 194 < V=206：16 个 token 读出方向奇异值偏小（低频字节读出弱），
  对词表级压缩的定量影响未测（Q5）。

## 4. 形态税与归因（判据 5，证伪 + 定位）

| run | depth-L bpc | 税 vs dense 1.7375 |
|---|---|---|
| sanity-B（均匀退出+填充+全深度监督） | 2.4161 | **+0.6786** |
| sanity-B-nofill（无退出/无填充，仅全深度监督） | 2.2496 | **+0.5121** |
| dense-B（仅 depth-L 监督） | 1.7375 | 0 |

- 判据 |tax|<0.05 **证伪**：v1 配方下形态税 +0.68。
- **归因分离**（nofill ablation）：+0.51 = 全深度并行监督的**梯度稀释**
  （depth-L 只拿 1/9 的监督信号，且浅层读出把残差流往浅层可读方向拖）；
  +0.17 = 随机退出 + 混合深度填充对 context 的扰动。
- **代码 bug 与假设错误分开**：填充/门控/解码器语义由单测逐位钉死
  （混合深度 = 手写规则一致、增量解码 == 并行 forward、全深度退化为裸堆叠、
  恒等门极限），dense arm 数值合理；因此这是**配方/假设层面**的证伪
  ——「等权全深度监督不伤底座」不成立，而非实现错误。
- 佐证细节：nofill 的浅层读出也更好（depth-1 2.6422 vs 2.6728）——混合填充
  同时污染浅层头的训练信号；nofill 门整体更大（深层 0.084 vs 0.041）——
  填充扰动让深层精化收益变小、门保持关闭。

### 判读

- **主判据（税 < 0.05）W1-W3 全败**，且响应**单调反向**：浅层监督越弱底座越差
  （2.45→2.57→2.73）——「浅层 aux 化即可归零税」假设**证伪**。
- 副判据：W1/W2 的 depth-4 劣化在 0.3 内（W2 +0.298 压线）、W3 −0.005；
  W3 曲线末位 2.4443→2.4444 为噪声级平（深度收益平台后测不出差）。
- **归因修正（ticket-23 §4「监督稀释 +0.512 主因」需改判）**：本轮证明浅层
  全深度监督是**表示正则**而非稀释源——降权让底座单调恶化（W2 与 W0 同退出/
  填充设置、只差监督权重，因果方向与「稀释」相反）。nofill 的 +0.512 剩余候选
  主因：**(a) carry 门乘性瓶颈**（g=σ(·)≤1 限制 depth-L 有效路径，vs dense 裸
  堆叠）；(b) 3600 步欠拟合下门控形态收敛慢。
- **soft OOD 复验（推荐配方 = v1 等权；W3 为 Pareto 次优）**：d4 soft 7.43 vs
  hard 1.23——**复现** ticket-23（6.89/1.17）「soft 提交把 OOD 期望嵌入注入
  context」。新信号：w 越低 soft 污染越小（W1 3.25、W2 4.20）但 hard 同步变差
  ——soft 污染幅度与浅层头质量耦合，支持「污染源 = 未经充分训练的读出分布」。

### 下一步假设（按判别力/成本排序）

1. **H1 门控税**：无门无退出 + 浅层 aux 读出（dense + aux-only，w∈{1, 0.2}）测
   「纯 aux 税」——若 ≈0（ticket 18 的 dense 0.2 负税先例支持），再加门复现税
   → 税定位到门控形态而非监督加权。最便宜、判别力最高。
2. **H2 步数/欠拟合**：同配方 12k 步——税若随训练收窄（ticket 11 先例：
   retry 税 1k→24k 收窄 ~3×），则 +0.7 是小步数伪影。
3. **H3 stop-grad 浅头**：probe 式浅头（trunk stop-grad，ticket 18 教训），
   若目标是浅层出口与底座兼得。

**对 stage-2 的推论**：监督加权轴**关闭**（等权即已知最优）；门控/退出形态
升级为税主嫌；出口资产（tf@4 0.93–0.97 全配方存活）依旧是本形态最强项。

  B-nofill 同时关掉了随机退出采样，退出项与填充项捆绑）。23c 的 +0.200 应读作
  「退出+填充捆绑项在短训下的代价」，非填充本身有害。

- **proj-fill（可选臂，时间允许已跑）**：1.8356，比 fill 好 0.0226（平局带内，

  62）、functional_dirs 272（fill 26）——状态分布形态随填充策略显著变化；
