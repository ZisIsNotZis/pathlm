## 一、研究结果

### A · H4 冻结主干 + 只训跳跃头（13M dense，12k 步冻结 + 头 2k×2 seed）

**预登记判据：失败；零税成立。**

| 判据 | 阈值 | 实测 | 判定 |
|---|---|---|---|
| t+2 命中 ≥ 0.81 × 直接 t+1 | 0.81 × 0.6934 = 0.5617 | **0.4667**（宽头 0.5081） | 未过 |
| \|Δ clean bpc\| < 0.014（挂头前后） | 0.014 | **0.0000**（1.4836 → 1.4836） | **过** |
| ECE ≤ 0.01 且分层单调（探索性） | — | 宽头 0.0064，10 桶 0.073→0.982 严格单调 | 宽头过 |

- 分母锚复现：契约锚 0.688 → 实测 0.6934；主干 bpc 1.4836 / t+1 acc 0.6979。
- 失败决策树全部排除：off-by-one（shift 单测 + `two_forward_oracle == trunk_t1` 恒等式）、
  冻结失败（Δbpc=0、grad is None）、头映射（直接 t+1 0.6951 ≈ 主干 0.6934）、
  步数与容量（宽头仅 +4.1pp 仍不达标）⇒ **归因设计在该设定下无效**
  （冻结表征只被 t+1 目标塑形，t+2 映射不可达；joint 锚 55.97% 是表征可用性差异）。
- **双口径（methodology §14）**：预登记用 oracle 两跳（0.6953）作分母 → 未过；
  真实等 FLOPs 对手（自己预测的 t+1 再前向）= **0.3128** → 跳跃头以半成本反超 **+15.4pp**。
  两结论并存，**以预登记为准**，反向如实记录。
- 口径缺陷如实标注：联合臂 lr 3e-4 把主干改坏（bpc → 1.8473），非干净对照，仅记录。
- 成本：GPU ≈19–20 min（预算 20）；峰值显存 **1630 MiB**；墙钟 ≈40 min。
- 证据：`axes/H-horizon/H4-head-trunk-relation/experiments/2610-frozen-trunk-jumphead-13m/`（`@1181cd4`）。

### 关键实现发现（跨线，已升格为规范）

**死干预事件**：契约原文「零初始化」使 `W1=W2=0` 成为**鞍点**
（∂L/∂W1 = ∂L/∂W2 = 0），首轮 12k 训练后 `fro=0`、干预恒为 0，
实测 Δ=−0.0154 只是同配置重跑的浮点噪声（子代理主动判为噪声，未当成功）。
修复 = **单边零**（`W1~N(0,0.02)`、`W2=0`）：严格恒等起步 + `∂L/∂W2 = silu(W1h)⊗h ≠ 0`，
200 步即逃逸（|W1|=5.34 / |W2|=1.33）。作废轮证据保在 `zero-init-saddle/`。
