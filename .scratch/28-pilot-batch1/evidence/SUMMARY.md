# SUMMARY — ticket 28 · 试点第一批（编排 + 两条线首验）

## 零、人话摘要（先读这段）

我们在这张「模型设计地图」上挑了两个最便宜的方向，各跑了一个小实验（13M 参数级、
一张共享的 4090 上总共约 46 分钟 GPU）。两件事和结论：

**第一件：给一个已经训练好、并且被冻住的普通小模型，外挂一个「跳两步」的小脑袋，
看它能不能用一次前向，顶上「老老实实跑两次」的效果。** 结论：不行——这个脑袋猜
下一个的下一个，只有 46.7% 猜对，而模型猜下一个的正确率是 69.8%；我事先定的及格线
是「至少要达到老实跑两次的 81%（约 56%）」，没到。但有个反转：如果对照的是**真实
的**两次前向（第二次只能吃自己第一次猜的错答案，正确率掉到 31.3%），那么一次前向
的跳跃脑袋反而更好，而且只用一半算力。所以这件事的价值不是「更准」，而是「更省」——
它是个便宜的草稿，不是真正的多步推理。附带确认了一件事：**给冻住的模型外挂脑袋
完全不伤害主干**（质量一个字没变）。

**第二件：把模型的「出口」从纯线性改成带一点非线性，但故意保留它和词表之间那根
唯一的线。** 结论：有效。每字符比特数（bpc，越低越好）从 **1.8582 降到 1.7770**；
同样条件下，一个普通的、不带我们这套灵活结构的变压器是 1.5287——所以差距（我们叫
「税」）从 **+0.33 缩到 +0.25，收回大约四分之一**。额外代价极小（只加 13 万参数，
7.09M → 7.09M+13.1万），而且没破坏别的东西：用前 4 层当草稿被接受的比率仍是 0.968，
置信度校准还略好了一点。**这说明「同一个空间」这个核心前提不用放弃**——
要动的是出口的读法，不是主干。

**顺带抓到一个大坑**：我写契约时建议「初始化成零」，结果那是个**鞍点**——
两端梯度同时为零，参数永远学不动。第一次 12 小时... 更正：第一次 12k 步训练跑完，
干预参数始终是 0，所谓「改善了 0.015」只是重跑噪声。子代理把这个坑抓出来了，
改成「只把输出侧置零、输入侧随机初始化」即可既严格等价于原模型、又能学起来。
这条已经写进规范（今后所有「从原模型出发」的新参数都必须报告「它到底动没动」）。

## 一、研究结果

### A · H4 冻结主干 + 只训跳跃头（13M dense，12k 步冻结 + 头 2k×2 seed）

**预登记判据：失败；零税成立。**

| 判据 | 阈值 | 实测 | 判定 |
|---|---|---|---|
| t+2 命中 ≥ 0.81 × 直接 t+1 | 0.81 × 0.6934 = 0.5617 | **0.4667**（宽头 0.5081） | 未过 |
| \|Δ clean bpc\| < 0.014（挂头前后） | 0.014 | **0.0000**（1.4836 → 1.4836） | **过** |
| ECE ≤ 0.01 且分层单调（探索性） | — | 宽头 0.0064，10 桶 0.073→0.982 严格单调 | 宽头过 |

- 分母锚复现：契约锚 0.688 → 实测 0.6934；主干 bpc 1.4836 / t+1 acc 0.6979。
- 失败决策树全部排除：off-by-one（shift 单测 + `two_forward_oracle == trunk_t1` 恒等式）、
  冻结失败（Δbpc=0、grad is None）、头映射（直接 t+1 0.6951 ≈ 主干 0.6934）、
  步数与容量（宽头仅 +4.1pp 仍不达标）⇒ **归因设计在该设定下无效**
  （冻结表征只被 t+1 目标塑形，t+2 映射不可达；joint 锚 55.97% 是表征可用性差异）。
- **双口径（methodology §14）**：预登记用 oracle 两跳（0.6953）作分母 → 未过；
  真实等 FLOPs 对手（自己预测的 t+1 再前向）= **0.3128** → 跳跃头以半成本反超 **+15.4pp**。
  两结论并存，**以预登记为准**，反向如实记录。
- 口径缺陷如实标注：联合臂 lr 3e-4 把主干改坏（bpc → 1.8473），非干净对照，仅记录。
- 成本：GPU ≈19–20 min（预算 20）；峰值显存 **1630 MiB**；墙钟 ≈40 min。
- 证据：`axes/H-horizon/H4-head-trunk-relation/experiments/2610-frozen-trunk-jumphead-13m/`（`@1181cd4`）。

### B · W4 gated 残差读出（13M depth-ar，12k 步）

**预登记判据：四项全过 → 成功。**

| 判据 | A 臂（tied 线性） | 主臂（gated） | 判定 |
|---|---|---|---|
| clean bpc ≤ A − 0.05 | 1.8582 | **1.7770**（Δ = **−0.0812**，5.8× 方差界） | ✓ |
| tf@4 ≥ 0.95 | 0.9694 | **0.9680**（tf@6 0.9933） | ✓ |
| ECE 不劣化 > 0.003 | 0.0066 | **0.0051** | ✓ |
| 自由度（探索性）≥5pp | null 能量 0.2703 | **0.1952**（−7.5pp） | ✓ |

- 机制（读出几何为唯一变量）：`logits = (h + SiLU(W1 h) ⊙ (W2 h)) · Eᵀ`，
  参数 +2·256² = 131072（6,962,688 → 7,093,760）；**全深度逐深度支配 A 臂**。
- 税拆解：同引擎 dense 分母 1.5287 → 形态税 **+0.3295 → +0.2483**（**收回 24.6%**）。
- **对照等值性门**（SCHEMA §9）：25 字段逐字段对照（d/L/H/seq/mlp/dropout/norm_cap/
  gate_bias_init/dense/exit_mode/aux_weight/final_weight/shallow_stopgrad/dense_aux/
  steps/batch/lr/**seed**/train_tokens/vocab/fill_kv/proj_fill/readout_dims）**全部 equal**
  ⇒ 复用 `23c-H2-w0-12k` 作 A 臂合法，且已在 analysis.md 记录等值性证明与已知口径。
- **干预活性门**（SCHEMA §10）：`w1_fro=30.50 / w2_fro=65.04 / nonzero_frac=1.0`。
- 成本：成功轮 ≈13.2 min（A 重测 0.33 + 主臂 12.69 + 电池 0.19）+ 作废轮 12.7 min
  = 累计 **≈27 min**（超 20 min 预算，**跑前由主 Agent 显式批准**）；峰值显存 2.12 GB net。
- 证据：`axes/W-width/W4-readout-geometry/experiments/2610-gated-readout-13m-depthar/`（`@cba2f39`）。

### 关键实现发现（跨线，已升格为规范）

**死干预事件**：契约原文「零初始化」使 `W1=W2=0` 成为**鞍点**
（∂L/∂W1 = ∂L/∂W2 = 0），首轮 12k 训练后 `fro=0`、干预恒为 0，
实测 Δ=−0.0154 只是同配置重跑的浮点噪声（子代理主动判为噪声，未当成功）。
修复 = **单边零**（`W1~N(0,0.02)`、`W2=0`）：严格恒等起步 + `∂L/∂W2 = silu(W1h)⊗h ≠ 0`，
200 步即逃逸（|W1|=5.34 / |W2|=1.33）。作废轮证据保在 `zero-init-saddle/`。
