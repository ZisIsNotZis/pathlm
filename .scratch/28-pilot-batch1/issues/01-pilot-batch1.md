# 01 — 试点第一批（ticket 28）：编排模式 + 两条线的首验

## 目的（双重）

1. **研究**：跑通两条最便宜的线，给 `H4`（头与主干关系）与 `W4`（读出几何）两格首次本地判决。
2. **编排**：验证「主 Agent 写契约 + Sub Agent 执行」这一模式是否可行、成本是否可控、
   契约是否足够严密（试点本身的价值一半在这里）。

## 试点设计（用户 2026-09-30 批准）

- 主 Agent 写契约（含预登记判据线、多维指标表、成本预算、失败决策树、数据与脚本清单），
  Sub Agent（worker）实现 + 冒烟 + 全跑 + 落证据。
- **GPU 串行**（共享 4090），一个 cwd 同时只有一个写入者（两条线文件所有权互斥）。
- 契约路径：
  - `axes/H-horizon/H4-head-trunk-relation/experiments/2610-frozen-trunk-jumphead-13m/`
  - `axes/W-width/W4-readout-geometry/experiments/2610-gated-readout-13m-depthar/`

## 结果（详见 evidence/SUMMARY.md）

| 线 | 判据（预登记） | 实测 | 判定 |
|---|---|---|---|
| A · H4 冻结主干 + 只训跳跃头 | t+2 命中 ≥ 0.81×直接 t+1（0.5617）且 \|Δbpc\|<0.014 | 0.4667（宽头 0.5081）；Δbpc = 0.0000 | **失败**（零税成立）；部署口径反向（半成本 0.4667 > 真实 rollout 0.3128） |
| B · W4 gated 残差读出（保 tied 桥） | Δbpc ≤ −0.05 且 tf@4 ≥0.95 且 ECE 不劣化 | Δ = **−0.0812**、tf@4 **0.9680**、ECE **0.0051** | **成功**（收回 24.6% 形态税） |

## 编排结论（本次试点最重要的产出）

| 观察 | 结论 |
|---|---|
| 契约严密性 | Sub Agent **两次抓出契约作者的错**：成本预算自相矛盾（§8）、零初始鞍点埋坑（§10） |
| 是否会放水 | 否。主动把「Δ=−0.0154」判为重跑噪声而非成功；主动标注联合臂口径缺陷 |
| 判据纪律 | 两次**都是停下向主 Agent 裁决，未自行改判据** |
| 成本可控性 | 单线 13–20 min GPU 可达；B 线因死干预 bug 超预算（27 min），根因在契约 |
| 交付质量 | 多维指标表 + 失败决策树走查 + 复现命令 + 权重哈希齐全，达 playbook 标准 |

## 由此产生的规范修订（已提交）

- `SCHEMA §8` 成本预算唯一性（一个数字；「预算不够砍什么」写明；冲突停下裁决）
- `SCHEMA §9` 对照复用规则（实现逐位一致 + resolved config 逐字段等值，否则回退自包含双跑）
- `SCHEMA §10` 干预活性判据（`results.json.intervention`；**恒等初始化 ≠ 零初始化**；
  单边零写法；每个语义开关要有活性测试）
