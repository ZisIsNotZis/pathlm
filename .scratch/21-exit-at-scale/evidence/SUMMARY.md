# Ticket 21 — 整形 vs 自适应定律 @100M 复测

日期：2026-09-19。C1_100M 协议 + {EX1: probe 头 / EX2: dense 0.2}，各 24000×8
单种子。对照：C1_100M（无 dense，clean 1.5871 / corrupt r1 2.015）与 13M
ticket 18。

## 终点

| | C1_100M（无 dense） | **EX1_100M（probe）** | **EX2_100M（dense 0.2）** |
|---|---|---|---|
| clean bpc | 1.5871 | 1.5928（**税 ≈0**） | **1.4724**（aux 正则更强） |

*C1_100M 的门控参照取 INT_100M（ticket 17）−0.0007 与 C1 forced-round −0.066 之间；
EX1 的 −0.0291 显著强于 13M probe 的 −0.0098。

## 判读：定律在 100M 复现且更锐利

1. **probe profile 在 100M 全面健康**：clean 税消失（+0.006）、retry 门控更强
   （−0.029 vs 13M −0.010）、门响应单调、conf 逐深度校准正常。trunk 不被
   深度监督触碰 → 与一切机制零干扰，且规模越大干扰本可越大而实际为零。
2. **dense 整形在 100M 恶化**：不只杀 retry（+1.73，旧引擎爆炸量级），连
   corrupt 输入处理也崩溃（off +0.85）——13M 时 0.2 剂量是温和负（+0.0146）。
   **剂量响应随规模变化**：同样 0.2 剂量，13M 温和、100M 灾难。
3. **exit 质量轴部分精确复现 13M**：probe 浅层贵（depth 6 +0.98）、dense 好
   （+0.14）——轴的形态跨规模稳定，只是代价在 100M 更极端。
4. 单种子 + 单剂量点（0.2）的限制：剂量-规模交互的完整曲线未扫；
   13M 与 100M 之间（如 29M/50M）未测。

## 结论

**整形 vs 自适应定律跨规模成立且更锐利**：100M 下 probe profile 是明确的
自适应形态赢家（零税 + 更强 retry 门控），dense 整形失去"质量 profile"地位
（corrupt 崩溃），仅剩 clean 单项优势与 exit 轴。形态即配置的原则再次加强。
