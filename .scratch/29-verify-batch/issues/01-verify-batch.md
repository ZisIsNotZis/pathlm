## 契约 A：跳跃头对照臂修正 + 接受率度量（纯推理）

- 目录：`axes/H-horizon/H4-head-trunk-relation/experiments/2611-jumphead-ar-control-13m/`
- 复用：`../2610-frozen-trunk-jumphead-13m/trunk.pt` 与 `head_s*.pt`（先核对 MODEL.md 哈希）。
- 文件所有权：可改 `train_jumphead.py`（新增 eval 模式）、`tests/test_jumphead.py`、本实验目录。

**要产出的量（同一位置集、同一目标定义）**

| 量 | 定义 | 用途 |
|---|---|---|
| `ar1_deploy_t2_hit` | 1-step AR：**只把位置 i+1 替换**为模型自己 pass-1 的 argmax，其余保持真值，再前向一次读 t+2 | 主对手（诚实、同成本） |
| `jump_t2_hit` | 一次前向 + 跳跃头 | 主角 |
| `accept_jump_t2` | `P(jump argmax == 主干自身 argmax 同位置)` | **草稿接受率（严谨指标）** |
| `oracle_t2_hit` | 喂真 t+1（仅上界参考，**不作判据**） | 上界 |
| `equiv_speedup` | 产出 1 token 的等效成本比（跳跃头 1 前向 vs AR 2 前向） | 收益口径 |

**判据（预登记，不得修改）**

- **对账（硬性）**：`ar1_deploy_t2_hit ≥ 0.4822`（= 0.6934 × 0.6953 算术下界）。不满足 → 实现仍有问题，**先修再判**。
- **主判据（成功）**：`jump_t2_hit ≥ 0.90 × ar1_deploy_t2_hit`（半算力打到诚实对手的九成）。
- **并列判据（草稿可用）**：`accept_jump_t2 ≥ 0.90`。
- 中性：主判据比值 ∈ [0.80, 0.90)。失败：< 0.80。
- **禁止**用 oracle 作判据；oracle 只作上界附报。
- 失败决策树：若对账不过 → 修实现；若实现正确但比值 < 0.80 → 结论「冻结主干跳跃头不如自回归两次」，并说明信息可用性差异。

**成本**：纯推理 ≈15 min。交付：契约 README / `run.py` / `results.json` / `analysis.md` / 单测。

## 契约 B：读出几何的等参数纯线性对照 + 稳定性报告

- 目录：`axes/W-width/W4-readout-geometry/experiments/2611-equalparams-linear-control-13m/`
- 文件所有权：可改 `pathlm/depth_ar.py`、`train_depth_ar.py`、`tests/test_depth_ar.py`、本实验目录。

**干预**：与 gated 臂**完全相同的参数量**（2·d²），但功能上是**线性**的：
`h' = h + P·(Q·h)`（P、Q 各 d×d；整体等价于一个线性映射，保留「严格恒等起步」的写法：
Q 随机初始化、P = 0，或等价地保证起步恒等且梯度可流——必须写活性判据）。
配置/seed/步数/数据与 2610 gated 臂逐字段一致。

**判据（预登记）**

- 若该对照臂的 Δbpc ≈ gated 臂的 Δbpc（差距 < 0.02）⇒ **增益来自参数量而非非线性**，
  gated 结论降级为「加参数的同价效果」，写入 `analysis.md` 并在 catalog 标注入账。
- 若该对照臂 Δbpc ≥ −0.014（无改善）而 gated ≤ −0.05 ⇒ **非线性本身有效**，结论加固。
- **稳定性报告（必交）**：两臂 + 本对照的 `gnorm` max / 中位数 / 尖峰次数、
  有无 NaN 或 loss 突跳、按深度 ECE 表（可从既有日志与重跑日志出）。
- 成本：≈13 min 训练（+ 复算日志近乎免费）。交付同上，另加 `stability.md`。
