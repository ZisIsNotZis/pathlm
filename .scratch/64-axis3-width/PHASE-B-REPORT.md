## 0 人话摘要（先读这段）

**这一轴问的事**：普通 transformer 的宽度「处处一样宽」。能不能**不处处一样宽**——把同样的算力/参数换个地方花，
从而同样质量更省算力、或同样算力质量更好？本轴拆成两个必须分开读的意思：**总量**（整体多宽 / FFN 多宽）与
**分配**（同一份总量怎么摊到 8 层、或摊到不同位置、或每 token 只激活一部分通道）。

**本轮做完并判过的**（3 项终局 + 1 项本轴此前的终局已闭合复核门）：

1. **前馈隐藏比（`3.1.4`）**：**总量是旋钮，分配不是**。FFN 宽 4→2 在 13M/12k 上 clean bpc（每字符比特数，越低越好）
   1.5314 → 1.5709（+0.0395 = 2.8× 噪声带 ⇒ 可排序），换来每 token 等效算力 −28.4%；把同一份 FFN 预算在 8 层间重排
   （金字塔/倒金字塔）的四个 Δ 全落在 0.014 带内 ⇒ 判「逐层 FFN 分配在本尺度不是独立设计维度」。
   第 2 轮独立复核（有 shell，实跑 6 项）= **PASS** ⇒ 本轴 Phase A 遗留的复核门**闭合**。
2. **uniform 减宽 / 弹性宽度（`3.1.1`）**：**减宽是真旋钮，弹性宽度不是**。d_model 256→192 使 clean bpc 1.5314 → 1.5841
   （+0.0527 = 3.8× 带 ⇒ 可分：减宽要付可排序的质量税），换来每 token 算力 −40.96%、参数 −43.4%；与另一只旋钮（FFN 减半）
   在**等算力位点不可排序**（斜率差对应 Δbpc 差 0.0132 < 0.014 带）⇒ 两只旋钮**互不支配**（FFN 旋钮更准、减宽更省）。
   嵌套宽度 dropout（一次训练、三档部署）虽然三档质量单调，但**每档都差于同宽单独训练的模型**（@192 差 +0.0486 = 3.5× 带）
   ⇒ 判**不成立**。独立复核两轮：第 1 轮 FAIL（1 条 blocking：把带内斜率差写成方向性结论）→ 最小修 → 第 2 轮 **PASS**。
3. **读出重参数化（`3.2.1`，本轴此前终局）**：增益归**容量/重参数化**、**非线性本身无额外贡献**（等参数纯线性对照与 gated 不可排序），
   且 12k→24k 缩减 43%、在 stock dense 上不可迁移 ⇒ 只补本形态缺陷，不作通用质量机制。

**本轮落实现、但臂因「单卡 GPU 互斥锁饥饿」没跑出读数**（如实登记为 `进行中`，不伪造任何读数）：`3.2.3` tied vs untied、
`3.1.5` 通道稀疏激活（预登记契约 + 实验目录内实现 + 单测含等值门/变异门已落盘）、`3.2.2` 逐出口读出（本轮末尾派单，结果见 §5）。

**仍未动的**：`3.1.2` 逐层 d_model schedule（实现前置未满足：引擎无逐层 d_model，E2 只覆盖逐层 FFN 宽；替代做法已写进契约）、
`3.1.3` 同层内位置相关宽度（本轮时间盒内未派到）。

## 2 判据与口径（本轴共同）

- 判据 = 序列级 **clean bpc**（该不跌 / 可排序，须越 **0.014 bpc 带**）+ **每 token 等效算力（MACs）与参数量**（该跌 / 该报）+ 必要的活性/损伤对照列；
  **墙钟/吞吐/日期一律不进判据与代价表述**（`docs/research-schema.md` §3）。
- 判据带声明（`docs/research-schema.md` §12.1）：本轴 8 项 `falsification` **逐项显式声明**用哪个带；
  脚本枚举 `.scratch/64-axis3-width/c1_band_audit.py` ⇒ **exit 0**（唯一实修 = `3.1.5`）。
- 剪枝类对照（§12.2）：减宽 / 减 FFN 宽的对照位点 = **等 FFN 预算 / 等算力位点**，并**并列报参数量与每 token 等效算力**
  （防把「减参数」记成「减宽度」）。
- C2 两读法：`milestone.acceptance` 的**字面成立 / 实质成立**并列写在 `conclusion` 里（`3.1.1`、`3.1.4` 均已写）。
- GPU：所有臂按 `SCHEMA.md` §20 **逐臂取/放** `/tmp/pathlm_gpu.lock`（臂间 ≥61 s），未整程独占、未杀他人进程、未回收他人锁。
