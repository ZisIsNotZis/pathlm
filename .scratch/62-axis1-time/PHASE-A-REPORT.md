## 0. 人话摘要

**为时间轴做了什么**：把轴 1 的 12 个研究项定下负责人（role_map 实名），逐项按契约过了一遍
（目的 / 创新 / SOTA 基线 / 相对 SOTA 的增量 / 方法 / 端到端判据 / 可否证条件 / 等效代价 /
单一 milestone / work packages），按「能不能改变我们对『某种算力路径值不值』的判断」给全部 WP
排了序、写了预算。然后只做了**排第一的那一个**：把「显式记忆」（模型能主动把看过的内容写进一个
固定大小的小本子、再读出来）放进出资人真正要的那张图——横轴「每位置占多少内存」、纵轴
「质量（bpc，越低越好）」，用普通全量注意力当 100% 参照。

**拿到什么结果：这笔账不值。** 小本子把窗口 16 的 bpc 从 **1.6281 压到 1.6250**（只补回
「窗口 16 → 全量」这段差距的 **2.5%**）；而**只要把窗口从 16 直接加宽到 17**（内存**更少**：
208,896 < 212,992 字节），bpc 就到 **1.6241——比小本子还好**。也就是说：**小本子买不到一个窗口
位置的等效上下文，花的钱还更多**；它被一个只宽 1 格的纯窗口**（点估计）严格支配**。
把窗口直接开到 128，差距补回 **91.5%**；开小本子只补 **2.5%**。

**值不值**：在本实现（单共享槽、只从输入流写、无门控/内容相关写入门）、本尺度（13M / 12k 步 /
真实文本 enwik8）下，**不值**——显式状态不是一条高效的信息右移路径。这**不是**说 delta 规则族
不可能：失败归因把主因归到**实现/设计退化**（前轮复核已指出引擎开销把它逼成单共享槽），
完整机制（逐层状态 + 门控 + 内容相关写入门）**未测**，且它需要改共享引擎（本轴不擅自改，已上报）。

| 做法 | 每位置等效内存 k_eff | bpc（越低越好） | 补回窗口→全量的差距 |
|---|---|---|---|
| 窗口 16（无小本子） | 16.00 | 1.6281 | 0% |
| **加小本子（显式状态）** | **17.33** | **1.6250** | **2.5%** |
| 窗口 17（只加宽 1 格） | 17.00 | **1.6241** | 3.2% |
| 窗口 18 | 18.00 | 1.6200 | 6.5% |
| 窗口 24 | 24.00 | 1.5999 | 22.5% |
| 窗口 128 | 128.00 | 1.5133 | 91.5% |
| 全量注意力（stock 全因果 = 100%） | 256.00 | 1.5027 | 100% |

### 1.2 旗舰 WP1：1.1.4.1 显式状态的质量-代价前沿（`a679170` → 后续修订）

`README.md`（预登记契约）/ `config.json` / `run.py` / `train_arms.sh` / `test_2638_frontier.py` /
`results.json` / `analysis.md` / `MODEL.md` / `train/win{17,18,24,32,128}/`。

- **设计（可否证）**：统一口径（同一 96×16 窗口序 `window_seed=2`，token 数 391,680）下 10 个臂
  按（每位置等效 KV 字节 = `n_layers×2×d×2×k`，clean bpc）落同一张图；对照 = stock 全因果（100% 锚）。
  该涨：carry 相对同窗无通道的 Δbpc 与毁源 `Δbpc_far`；该跌：显式状态点的每位置字节；
  必须不变：因果性、掩码可见对数、同 token 预算。
- **判决**：carry16_s0（212,992 B，1.624979）**被 win17_s0（208,896 B，1.624104）严格支配**
  （内存更少、质量更好）；下包络 = `[win16, win17, win18, win24, win32, win128, full]`，
  **carry16 不在其上**；同 `k_eff=17.33` 的纯窗口插值点 1.62272 也优于 carry。
- **必要条件成立**：carry 相对同窗无通道 Δbpc 两 seed 皆 >0（+0.003131 / +0.001470 跨 seed 口径；
  同 seed 配对 +0.002453），2634 的毁源 `Δbpc_far` +0.015784/+0.014132 >0 ⇒ 状态确实被读、
  确实搬了窗外信息（不是死开关）。
- **不依赖追加臂**：只用**预登记点集**（win16→win24 弦插值到 `k_eff=17.333` = **1.623401 > 1.624979**）
  同样判负。
- `1.1.4.1` 的 `status` → **`被否证`**（触发本项预登记否证条件 #2）；
  `failure_analysis` = **设计/实现问题为主因**（单共享槽退化实现，55-review M-05/M-06）
  + 结构问题次因（容量/未做同参数量对照）+ **非 innovation 本身失败**（完整机制未测）
